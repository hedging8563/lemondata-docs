## LemonData là gì?

LemonData là một nền tảng tổng hợp AI API, cung cấp cho bạn quyền truy cập hợp nhất tới **hơn 300 mô hình AI** từ các nhà cung cấp như OpenAI, Anthropic, Google, DeepSeek, Moonshot, MiniMax, và nhiều hơn nữa.

## Các khả năng được hỗ trợ

| Khả năng | Mô tả | Mô hình ví dụ |
|------------|-------------|----------------|
| **Chat & Suy luận** | Tạo văn bản, lập kế hoạch, công cụ | `gpt-5.4`, `claude-sonnet-4-6`, `deepseek-r1` |
| **Thị giác** | Hiểu hình ảnh và chat đa phương thức | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |
| **Tạo ảnh** | Chuyển văn bản thành ảnh và chỉnh sửa ảnh | `dall-e-3`, `flux-pro`, `midjourney` |
| **Tạo video** | Chuyển văn bản/hình ảnh thành video | `sora`, `runway`, `kling` |
| **Âm thanh** | TTS và chuyển lời nói thành văn bản | `gpt-4o-mini-tts`, `whisper-1`, `gpt-4o-transcribe` |
| **Embeddings** | Vector hóa văn bản | `text-embedding-3-small`, `text-embedding-3-large` |
| **Âm nhạc** | Tạo nhạc bằng AI | `suno` |
| **3D** | Tạo tài sản 3D | `tripo3d` |

## Điểm khởi đầu mặc định phù hợp

Đối với các dự án mới, hãy bắt đầu với OpenAI SDK cùng với **Responses API**:

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

</CodeGroup>
