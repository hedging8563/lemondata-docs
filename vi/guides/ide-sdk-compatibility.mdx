## Tổng quan

LemonData API được thiết kế để **tương thích thay thế trực tiếp** với tất cả các công cụ phát triển AI phổ biến. Hướng dẫn này ghi lại các tham số được hỗ trợ và các tích hợp đã được xác minh.

<Note>
  Tất cả tham số đều được xác thực nhưng được chuyển tiếp đến các nhà cung cấp upstream. Các tham số không được hỗ trợ cho các model cụ thể sẽ bị bỏ qua một cách âm thầm, đảm bảo khả năng tương thích tối đa.
</Note>

## Các định dạng API được hỗ trợ

| Endpoint | Format | Trường hợp sử dụng |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | Tương thích phổ quát |
| `/v1/responses` | OpenAI Responses | Hội thoại có trạng thái |
| `/v1/messages` | Anthropic Messages | Tính năng gốc của Claude |
| `/v1beta/models/:model:generateContent` | Google Gemini | Tính năng gốc của Gemini |

## Tham số Chat Completions

### Tham số cốt lõi

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Định danh model (bắt buộc) |
| `messages` | array | Tin nhắn hội thoại (bắt buộc) |
| `max_tokens` | integer | Số token đầu ra tối đa |
| `temperature` | number | Nhiệt độ lấy mẫu (0-2) |
| `top_p` | number | Lấy mẫu nucleus (0-1) |
| `stream` | boolean | Bật streaming |

### Gọi tool

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tùy chọn Tool Choice

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | Lựa chọn đơn giản |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | Ép buộc function cụ thể |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Định dạng gốc của Anthropic |

### Tham số nâng cao

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | `{ include_usage: true }` cho số lượng token |
| `reasoning_effort` | string | `"low"`, `"medium"`, `"high"` cho các model GPT-5 hỗ trợ reasoning |
| `service_tier` | string | `"auto"` hoặc `"default"` |
| `seed` | integer | Đầu ra xác định |
| `logprobs` | boolean | Trả về log probabilities |
| `top_logprobs` | integer | Số lượng top logprobs (0-20) |
| `logit_bias` | object | Bản đồ token bias (-100 đến 100) |
| `frequency_penalty` | number | Phạt lặp lại (-2 đến 2) |
| `presence_penalty` | number | Phạt chủ đề (-2 đến 2) |
| `stop` | string/array | Chuỗi dừng |
| `n` | integer | Số lượng completions (1-128) |
| `user` | string | Định danh người dùng để theo dõi |

### Tính năng nâng cao của OpenAI

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | `["text", "audio"]` cho đa phương thức |
| `audio` | object | Cấu hình đầu ra âm thanh (voice, format) |
| `prediction` | object | Đầu ra dự đoán để hoàn thành nhanh hơn |
| `metadata` | object | Các cặp key-value để theo dõi |
| `store` | boolean | Lưu trữ để truy xuất sau |

### Tùy chọn theo provider

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Tham số Responses API

### Tham số cốt lõi

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Định danh model |
| `input` | string/array | Nội dung đầu vào |
| `instructions` | string | Chỉ dẫn hệ thống |
| `max_output_tokens` | integer | Số token đầu ra tối đa |
| `previous_response_id` | string | Tiếp tục hội thoại |

### Tham số nâng cao

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` hoặc `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | Dành cho các model reasoning |
| `service_tier` | string | Cấp độ ưu tiên |

### Định dạng tool

Hỗ trợ cả định dạng tool của OpenAI và Anthropic:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## Tham số Gemini API

### Tham số cốt lõi

| Parameter | Type | Description |
|-----------|------|-------------|
| `contents` | array | Nội dung hội thoại |
| `systemInstruction` | object | System prompt |
| `generationConfig` | object | Cài đặt tạo sinh |

### Tools

```json
{
  "tools": [{
    "functionDeclarations": [{
      "name": "search",
      "description": "Search the web",
      "parameters": {...}
    }],
    "codeExecution": {},
    "googleSearch": {}
  }],
  "toolConfig": {
    "functionCallingConfig": {
      "mode": "AUTO"
    }
  }
}
```

### Cài đặt an toàn

```json
{
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_MEDIUM_AND_ABOVE"
    }
  ]
}
```

### Tham số bổ sung

| Parameter | Type | Description |
|-----------|------|-------------|
| `cachedContent` | string | Tham chiếu nội dung được cache |
| `responseMimeType` | string | `"text/plain"` hoặc `"application/json"` |
| `responseSchema` | object | JSON schema cho đầu ra có cấu trúc |

## Streaming

Tất cả endpoint đều hỗ trợ streaming Server-Sent Events (SSE):

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## Xử lý lỗi

LemonData trả về phản hồi lỗi tương thích với OpenAI:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

Xem [Hướng dẫn xử lý lỗi](/guides/error-handling) để biết chi tiết.
