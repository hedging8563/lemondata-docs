## Tổng quan

LemonData cung cấp nhiều định dạng API để các coding tool, SDK và framework phổ biến có thể tích hợp với rất ít glue code.

Trang này được cố ý định nghĩa hẹp hơn một ma trận marketing thông thường.

- **Được hỗ trợ** nghĩa là chúng tôi đã tài liệu hóa một đường cấu hình cụ thể và LemonData phơi bày protocol shape mà đường đó cần.
- **Đường native mạnh** nghĩa là repo cũng có bằng chứng trực tiếp ở cấp adapter / request-format cho họ giao thức đó.
- **Best-effort** nghĩa là tích hợp có thể hoạt động, nhưng client upstream không coi workflow gateway tùy chỉnh này là một hợp đồng ổn định.

<Note>
  Các trường không được hỗ trợ không được xử lý theo một cách duy nhất. Ở các đường tương thích, một số trường có thể bị bỏ qua hoặc chuẩn hóa. Ở các đường Responses native, có thể trả về lỗi `400` hoặc `503` rõ ràng nếu model đã chọn hoặc channel được route không hỗ trợ passthrough cần thiết.
</Note>

## Các định dạng API được hỗ trợ

| Endpoint | Format | Trường hợp sử dụng |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | Tương thích phổ quát |
| `/v1/responses` | OpenAI Responses | Hội thoại có trạng thái |
| `/v1/messages` | Anthropic Messages | Tính năng gốc của Claude |
| `/v1beta/models/:model:generateContent` | Google Gemini | Tính năng gốc của Gemini |

## Tương thích IDE & CLI

### Các đường công cụ đã được tài liệu hóa

| Công cụ | Mức hỗ trợ | Định dạng | Ghi chú |
|---------|------------|-----------|--------|
| **Cursor** | Được hỗ trợ nhưng có giới hạn | OpenAI-compatible | Phù hợp cho luồng BYOK chuẩn kiểu chat / editor, không có nghĩa là thay thế được các tính năng do Cursor quản lý như Tab Completion |
| **Claude Code CLI** | Đường native mạnh | Anthropic | Đường `/v1/messages` native với bằng chứng adapter cho thinking và `tool_choice` |
| **Codex CLI** | Được hỗ trợ nhưng phụ thuộc model / channel | OpenAI Responses | Tốt nhất khi cấu hình với `/v1/responses`; một số trường Responses-native phụ thuộc vào native passthrough của model / channel |
| **Gemini CLI** | Thử nghiệm / best-effort | Gemini | Luồng custom base URL với LemonData không phải là hợp đồng upstream ổn định |
| **OpenCode** | Được hỗ trợ | OpenAI-compatible | Trước tiên nên dùng provider OpenAI-compatible, chỉ chuyển sang provider Responses khi thực sự cần |

<Note>
  Nhiều editor / agent tool tương thích OpenAI khác cũng thường chạy được với cùng mẫu base URL, nhưng repo này hiện không duy trì regression riêng cho Windsurf, Aider, Continue.dev, Cline/Roo Code hay GitHub Copilot.
</Note>

### Ví dụ cấu hình

<Tabs>
  <Tab title="Cursor">
    ```
    Base URL: https://api.lemondata.cc/v1
    API Key: sk-your-lemondata-key
    ```
    Cursor sử dụng nội bộ định dạng tool kiểu Anthropic. LemonData hỗ trợ cả hai:
    - Định dạng OpenAI: `{ type: "function", function: { name, parameters } }`
    - Định dạng Anthropic: `{ name, input_schema }` (không có trường type)
  </Tab>
  <Tab title="Claude Code">
    ```bash
    export ANTHROPIC_BASE_URL="https://api.lemondata.cc"
    export ANTHROPIC_API_KEY="sk-your-lemondata-key"
    ```
  </Tab>
  <Tab title="OpenCode">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"
    export LOCAL_ENDPOINT="https://api.lemondata.cc/v1"
    ```
  </Tab>
  <Tab title="Aider">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"
    export OPENAI_BASE_URL="https://api.lemondata.cc/v1"
    aider --model gpt-5.4
    ```
  </Tab>
</Tabs>

## Tương thích SDK

### Các đường SDK / framework đã được tài liệu hóa

| SDK / Framework | Ngôn ngữ | Mức hỗ trợ | Ghi chú |
|-----------------|----------|------------|--------|
| **OpenAI SDK** | Python/JS/Go | Đường lõi được hỗ trợ | Tài liệu hóa Chat Completions, Embeddings và các luồng Responses phổ biến; một số trường Responses-native-only phụ thuộc vào model / channel passthrough |
| **Anthropic SDK** | Python/JS | Đường native mạnh | Đường Messages native với bằng chứng trực tiếp cho tools, thinking và prompt caching |
| **Vercel AI SDK** | TypeScript | Mẫu tích hợp được khuyến nghị | Ưu tiên `@ai-sdk/openai-compatible`, chỉ dùng `@ai-sdk/openai` khi thực sự cần Responses-native |
| **LangChain** | Python/JS | Hỗ trợ surface tiêu chuẩn | Phạm vi dự kiến bao gồm `ChatOpenAI` và `OpenAIEmbeddings`; các extra vendor-native nằm ngoài phạm vi |
| **LlamaIndex** | Python | Hỗ trợ qua `OpenAILike` | Với các gateway bên thứ ba như LemonData, hãy dùng `OpenAILike` thay vì các lớp OpenAI tích hợp sẵn |
| **Dify** | - | Được hỗ trợ nhưng có giới hạn | Đường dự kiến là provider OpenAI và luồng thiên về chat-completions; không bảo đảm hành vi Codex-specific Responses / WebSocket |

## Tham số Chat Completions

### Tham số cốt lõi

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Định danh model (bắt buộc) |
| `messages` | array | Tin nhắn hội thoại (bắt buộc) |
| `max_tokens` | integer | Số token đầu ra tối đa |
| `temperature` | number | Nhiệt độ lấy mẫu (0-2) |
| `top_p` | number | Lấy mẫu nucleus (0-1) |
| `stream` | boolean | Bật streaming |

### Gọi tool

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tùy chọn Tool Choice

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | Lựa chọn đơn giản |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | Ép buộc function cụ thể |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Định dạng gốc của Anthropic |

### Tham số nâng cao

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | `{ include_usage: true }` cho số lượng token |
| `reasoning_effort` | string | `"low"`, `"medium"`, `"high"` cho các model GPT-5 hỗ trợ reasoning |
| `service_tier` | string | `"auto"` hoặc `"default"` |
| `seed` | integer | Đầu ra xác định |
| `logprobs` | boolean | Trả về log probabilities |
| `top_logprobs` | integer | Số lượng top logprobs (0-20) |
| `logit_bias` | object | Bản đồ token bias (-100 đến 100) |
| `frequency_penalty` | number | Phạt lặp lại (-2 đến 2) |
| `presence_penalty` | number | Phạt chủ đề (-2 đến 2) |
| `stop` | string/array | Chuỗi dừng |
| `n` | integer | Số lượng completions (1-128) |
| `user` | string | Định danh người dùng để theo dõi |

### Tính năng nâng cao của OpenAI

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | `["text", "audio"]` cho đa phương thức |
| `audio` | object | Cấu hình đầu ra âm thanh (voice, format) |
| `prediction` | object | Đầu ra dự đoán để hoàn thành nhanh hơn |
| `metadata` | object | Các cặp key-value để theo dõi |
| `store` | boolean | Lưu trữ để truy xuất sau |

### Tùy chọn theo provider

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Tham số Responses API

### Tham số cốt lõi

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Định danh model |
| `input` | string/array | Nội dung đầu vào |
| `instructions` | string | Chỉ dẫn hệ thống |
| `max_output_tokens` | integer | Số token đầu ra tối đa |
| `previous_response_id` | string | Tiếp tục hội thoại |

### Tham số nâng cao

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` hoặc `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | Dành cho các model reasoning |
| `service_tier` | string | Cấp độ ưu tiên |

### Định dạng tool

Hỗ trợ cả định dạng tool của OpenAI và Anthropic:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## Tham số Gemini API

### Tham số cốt lõi

| Parameter | Type | Description |
|-----------|------|-------------|
| `contents` | array | Nội dung hội thoại |
| `systemInstruction` | object | System prompt |

### Tools

```json

    "functionDeclarations": [{
      "name": "search",
```

```json
{
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_MEDIUM_AND_ABOVE"
    }
  ]

```

### Tham số bổ sung

| Parameter | Type | Description |
|-----------|------|-------------|
| `cachedContent` | string | Tham chiếu nội dung được cache |
| `responseMimeType` | string | `"text/plain"` hoặc `"application/json"` |
| `responseSchema` | object | JSON schema cho đầu ra có cấu trúc |

## Streaming

Tất cả endpoint đều hỗ trợ streaming Server-Sent Events (SSE):

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## Xử lý lỗi

LemonData trả về phản hồi lỗi tương thích với OpenAI:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

Xem [Hướng dẫn xử lý lỗi](/guides/error-handling) để biết chi tiết.

## Thực tiễn tốt nhất

<AccordionGroup>
  <Accordion title="Sử dụng passthrough cho các tham số không xác định">

  </Accordion>

  <Accordion title="Ưu tiên stream_options để tính phí chính xác">

  </Accordion>

  </Accordion>
</AccordionGroup>
