## Tổng quan

LemonData cung cấp quyền truy cập vào các model tạo video từ 11 nhà cung cấp thông qua một API hợp nhất duy nhất. Việc tạo video là **bất đồng bộ** — bạn gửi một request, nhận về một task ID và `poll_url`, sau đó poll để lấy kết quả.

<Info>
Danh sách model được cập nhật thường xuyên. Để xem các model khả dụng mới nhất và giá cả, hãy truy cập [trang Models](https://lemondata.cc/vi/models) hoặc sử dụng [Models API](/api-reference/models/list-models).
</Info>

<Warning>
Audio behavior is model-dependent. In LemonData, Veo 3 family requests default to audio-on when `output_audio` is omitted. Some models are silent by default or silent-only. For passthrough-governed models, pass `output_audio=true` to make a best-effort upstream audio request.
</Warning>


### Quy trình bất đồng bộ

```mermaid
sequenceDiagram
    participant Client
    participant LemonData
    participant Provider

    Client->>LemonData: POST /v1/videos/generations
    LemonData->>Provider: Forward request
    Provider-->>LemonData: task_id + pending
    LemonData-->>Client: { task_id, poll_url, status: "pending" }

    loop Poll every 5-10s
        Client->>LemonData: GET poll_url
        LemonData->>Provider: Query status
        Provider-->>LemonData: Status update
        LemonData-->>Client: { status, video_url? }
    end
```

<CodeGroup>

```python Python
import requests
import time

API_KEY = "sk-your-api-key"
BASE = "https://api.lemondata.cc/v1"
headers = {"Authorization": f"Bearer {API_KEY}"}

# Step 1: Submit generation request
resp = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
create_data = resp.json()
task_id = create_data["task_id"]
poll_url = create_data["poll_url"]

# Step 2: Poll for result
while True:
    status = requests.get(f"https://api.lemondata.cc{poll_url}", headers=headers).json()
    if status["status"] in ("completed", "succeeded"):
        print(f"Video URL: {status['video_url']}")
        break
    elif status["status"] == "failed":
        print(f"Failed: {status.get('error')}")
        break
    time.sleep(10)
```

```javascript JavaScript
const API_KEY = 'sk-your-api-key';
const BASE = 'https://api.lemondata.cc/v1';
const headers = { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' };

// Step 1: Submit
const { task_id, poll_url } = await fetch(`${BASE}/videos/generations`, {
  method: 'POST', headers,
  body: JSON.stringify({
    model: 'sora-2',
    prompt: 'A calm cinematic shot of a cat walking through a sunlit garden.',
    operation: 'text-to-video',
    duration: 4,
    aspect_ratio: '16:9'
  })
}).then(r => r.json());

// Step 2: Poll
const poll = setInterval(async () => {
  const status = await fetch(`https://api.lemondata.cc${poll_url}`, { headers }).then(r => r.json());
  if (['completed', 'succeeded'].includes(status.status)) {
    console.log('Video URL:', status.video_url);
    clearInterval(poll);
  } else if (status.status === 'failed') {
    console.error('Failed:', status.error);
    clearInterval(poll);
  }
}, 10000);
```

### Định nghĩa khả năng

- **T2V (Text-to-Video)**: Tạo video từ một prompt văn bản
- **I2V (Image-to-Video)**: Biến một hình ảnh tĩnh thành video. Để có khả năng tương thích rộng nhất, hãy cung cấp `image_url` công khai.
- **Keyframe**: Điều khiển khung hình đầu và cuối bằng `start_image` + `end_image`
- **Extension**: Mở rộng thời lượng của một video hiện có
- **Editing**: Chỉnh sửa các khía cạnh cụ thể của một video hiện có

## Ví dụ sử dụng

### Text-to-Video (T2V)

Trường hợp sử dụng phổ biến nhất. Tất cả các model đều hỗ trợ điều này.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
```

### Image-to-Video (I2V)

Biến một hình ảnh tĩnh thành video. Để có khả năng tương thích rộng nhất giữa các model video, hãy host hình ảnh nguồn và truyền `image_url`.

```python
# Using image URL
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/portrait.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)

```

### Điều khiển Keyframe (Hình ảnh đầu + cuối)

Điều khiển cả khung hình đầu tiên và cuối cùng để có các chuyển cảnh chính xác. Hiện được hỗ trợ bởi Seedance 2.0.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night, city lights gradually turning on",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/city-day.jpg",
        "end_image": "https://example.com/city-night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```

### Mở rộng video

Mở rộng thời lượng của một video hiện có. Sử dụng các model có khả năng extension.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "kling-video-extend",
        "prompt": "Continue the scene naturally",
        "image_url": "https://example.com/last-frame.jpg"
    }
)
```

## Tham chiếu tham số

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | ID của model (mặc định: `sora-2`) |
| `prompt` | string | **Bắt buộc.** Mô tả văn bản của video |
| `image_url` | string | URL của hình ảnh bắt đầu (cho I2V) |
| `image` | string | Hình ảnh inline dưới dạng data URL. Được hỗ trợ bởi các model tương thích, nhưng `image_url` mang lại khả năng tương thích rộng nhất. |
| `duration` | integer | Thời lượng video tính bằng giây (1-60, phụ thuộc model) |
| `aspect_ratio` | string | `16:9`, `9:16`, `1:1`, v.v. |
| `resolution` | string | `1080p`, `720p`, `4k` |
| `fps` | integer | Số khung hình mỗi giây (1-120) |
| `negative_prompt` | string | Những gì cần tránh trong quá trình tạo |
| `seed` | integer | Seed ngẫu nhiên để tái lập kết quả |
| `cfg_scale` | number | Thang hướng dẫn (0-20) |
| `motion_strength` | number | Cường độ chuyển động (0-1) |
| `start_image` | string | URL của keyframe bắt đầu |
| `end_image` | string | URL của keyframe kết thúc |

<Warning>
Không phải mọi tham số đều được hỗ trợ bởi mọi model. Các tham số không được hỗ trợ sẽ bị bỏ qua một cách im lặng. Hãy kiểm tra tài liệu của model để biết các tham số được hỗ trợ.
</Warning>
