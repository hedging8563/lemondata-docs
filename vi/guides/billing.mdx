## Tổng quan

LemonData sử dụng **định giá pay-as-you-go**. Bạn chỉ trả tiền cho những gì bạn sử dụng, không có gói đăng ký hoặc cam kết tối thiểu.

## Cách Thanh toán Hoạt động

1. **Nạp credit** vào tài khoản của bạn
2. **Sử dụng API** - chi phí được trừ theo từng request
3. **Theo dõi mức sử dụng** trong dashboard của bạn
4. **Nạp thêm** khi số dư của bạn thấp

### Thanh toán cho Tác vụ Async (Video/Nhạc/3D)

<Warning>
  **Quan trọng**: Các tác vụ tạo video, nhạc và 3D được **tính phí tại thời điểm gửi tác vụ**, không phải khi hoàn thành.
</Warning>

Đối với các tác vụ tạo async (video, nhạc, model 3D):

1. **Thanh toán diễn ra ngay lập tức** khi bạn gửi tác vụ
2. Bạn sẽ nhận được một `task_id` để poll trạng thái
3. **Không có hoàn tiền tự động** nếu tác vụ thất bại

Điều này là do các nhà cung cấp upstream tính phí cho chúng tôi khi tác vụ được gửi, bất kể kết quả ra sao. Nếu bạn gặp lỗi tác vụ, vui lòng liên hệ support@lemondata.cc để được hỗ trợ.

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

task_id = response.json()["task_id"]
# Poll for status...
```

## Đếm Token

Token là đơn vị cơ bản của xử lý văn bản:

- ~4 ký tự = 1 token (tiếng Anh)
- ~1-2 ký tự = 1 token (tiếng Trung)
- 1 hình ảnh = thay đổi tùy theo kích thước và mức độ chi tiết

### Ước tính Token

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## Cảnh báo Số dư Thấp

Cấu hình cảnh báo khi số dư của bạn giảm xuống:

1. Đi tới **Dashboard → Settings → Notifications**
2. Đặt ngưỡng số tiền của bạn
3. Nhận thông báo qua email

## Nạp Credit

### Phương thức Thanh toán

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### Các bước

1. Đăng nhập vào [Dashboard](https://lemondata.cc/dashboard)
2. Nhấp vào **Add Credits**
3. Chọn số tiền và phương thức thanh toán
4. Hoàn tất thanh toán

Credit được cộng ngay lập tức sau khi xác nhận thanh toán.

## Giới hạn API Key

Bạn có thể đặt giới hạn chi tiêu cho từng API key riêng lẻ:

1. Đi tới **Dashboard → API Keys**
2. Nhấp vào một key để chỉnh sửa
3. Đặt **Usage Limit**

Khi đạt đến giới hạn, các request với key đó sẽ trả về `402 Payment Required`.

## Hóa đơn

Đối với tài khoản doanh nghiệp, hóa đơn có sẵn:

1. Đi tới **Dashboard → Billing**
2. Xem lịch sử giao dịch
3. Tải hóa đơn dưới dạng PDF
