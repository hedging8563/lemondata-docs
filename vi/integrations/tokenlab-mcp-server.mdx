[TokenLab MCP server](https://github.com/hedging8563/tokenlab-mcp-server) tạo ra các công cụ MCP từ hợp đồng OpenAPI công khai của TokenLab. Các tác nhân (agent) tương thích với MCP có thể khám phá các mô hình và giá cả, gọi các endpoint LLM gốc và tương thích với OpenAI, tạo phương tiện đa phương thức, tải lên tệp tin và quản lý các tác vụ bất đồng bộ.

Hãy sử dụng nó khi một tác nhân cần hợp đồng API TokenLab hiện tại thay vì danh sách công cụ được duy trì thủ công. Cấu hình `core` mặc định cung cấp 29 công cụ endpoint được tạo sẵn cộng với hai công cụ khám phá tổng hợp. Cấu hình `full` cung cấp 78 công cụ endpoint được tạo sẵn cộng với hai công cụ tổng hợp tương tự.

<Note>
Các công cụ danh mục và giá cả công khai không yêu cầu khóa API TokenLab. Hãy thiết lập `TOKENLAB_API_KEY` cho các hoạt động suy luận (inference), phương tiện, âm thanh, tệp tin, tác vụ, embedding, rerank và dịch thuật được xác thực. Không bao giờ đặt khóa API vào các đối số của công cụ.
</Note>

## Những gì nó cung cấp

- Khám phá mô hình trực tiếp từ `https://api.tokenlab.sh/v1/models`.
- Tra cứu chi tiết mô hình từ `/v1/models/{model}`.
- Tra cứu giá cả từ `/v1/models/{model}/pricing`.
- Tổng quan API mà tác nhân có thể đọc được từ `https://api.tokenlab.sh/llms.txt`.
- Chat Completions và Responses tương thích với OpenAI, Anthropic Messages và Gemini generateContent mà không làm phẳng cấu trúc yêu cầu gốc của chúng.
- Tạo và chỉnh sửa hình ảnh thông qua URL JSON, ID tệp tin TokenLab hoặc các tệp multipart cục bộ.
- Video, âm nhạc, 3D, giọng nói, phiên âm, dịch âm thanh, embedding, embedding đa phương thức, rerank và dịch văn bản.
- Tóm tắt tác vụ bất đồng bộ đã chuẩn hóa cho các hoạt động tạo hình ảnh, video, âm nhạc, 3D và thế giới.
- Đồng bộ hóa hợp đồng hàng ngày giúp lấy tài liệu OpenAPI công khai, tạo lại lược đồ công cụ, chạy các bài kiểm tra endpoint và tệp tin, và chỉ cập nhật `main` khi mọi kiểm tra đều vượt qua.

## Cài đặt từ GitHub

Sao chép kho lưu trữ công khai và cài đặt các phụ thuộc:

```bash
git clone https://github.com/hedging8563/tokenlab-mcp-server.git
cd tokenlab-mcp-server
npm install
npm test
```

Khởi động server qua stdio:

```bash
npm start
```

Biến môi trường tùy chọn `TOKENLAB_API_BASE` mặc định là `https://api.tokenlab.sh`. Hãy thiết lập `TOKENLAB_MCP_TOOL_PROFILE=full` khi client cần hiển thị API nhà phát triển rộng hơn thay vì cấu hình `core` mặc định.

## Cấu hình cho mọi client MCP stdio

Sử dụng cùng một bộ giá trị trong mọi client hỗ trợ server MCP stdio cục bộ. Client có thể hiển thị chúng dưới dạng trường biểu mẫu hoặc lưu trong JSON, TOML hay YAML; ý nghĩa của các trường không thay đổi. Hãy thêm từng đối số thành một mục riêng.

| Trường | Giá trị | Ghi chú |
|---|---|---|
| Tên server | `tokenlab-model-catalog` | Có thể dùng bất kỳ tên duy nhất nào. |
| Giao thức truyền | `stdio` | TokenLab MCP chạy dưới dạng tiến trình con cục bộ. |
| Lệnh khởi động | `npx` | Khởi động gói npm đã phát hành. |
| Đối số | `-y`, sau đó `@tokenlabai/mcp-server` | Dùng `@tokenlabai/mcp-server@0.6.14` để ghim bản phát hành hiện đã được xác minh. |
| Biến môi trường | `TOKENLAB_API_KEY` = `<TOKENLAB_API_KEY>` | Không bắt buộc cho danh mục công khai nhưng bắt buộc cho công cụ suy luận và đa phương tiện. |
| Chuyển tiếp biến môi trường | Để trống hoặc nhập `TOKENLAB_API_KEY` | Chỉ dùng tên biến khi khóa đã được xuất trong môi trường cục bộ của client. Không cấu hình cùng một khóa ở cả hai nơi. |
| Thư mục làm việc | Để trống | `npx` không yêu cầu thư mục dự án cho gói này. |

Sao chép cấu hình đầy đủ sau vào các client chấp nhận đối tượng JSON `mcpServers`:

```json
{
  "mcpServers": {
    "tokenlab-model-catalog": {
      "command": "npx",
      "args": ["-y", "@tokenlabai/mcp-server"],
      "env": {
        "TOKENLAB_API_KEY": "<TOKENLAB_API_KEY>"
      }
    }
  }
}
```

Xóa khối `env` nếu bạn chỉ cần các công cụ mô hình và giá công khai. Nếu client yêu cầu một đối tượng server thay vì lớp bọc `mcpServers`, chỉ sao chép đối tượng bên trong có `command`, `args` và `env`.

<Warning>
Không đăng ảnh chụp màn hình, nhật ký hoặc tệp cấu hình có chứa khóa API thật. Hãy dùng giá trị giữ chỗ trong ví dụ và thu hồi ngay mọi khóa đã bị lộ.
</Warning>

## Cài đặt trong Codex

Thêm server danh mục công khai vào cấu hình Codex của bạn:

```bash
codex mcp add tokenlab-model-catalog -- npx -y @tokenlabai/mcp-server
```

Bắt đầu một phiên Codex mới sau khi thêm server. Các công cụ danh mục công khai không yêu cầu `TOKENLAB_API_KEY`.

Để kích hoạt các công cụ suy luận, hãy bao gồm khóa API TokenLab của bạn khi thêm server:

```bash
codex mcp add --env TOKENLAB_API_KEY=your-tokenlab-api-key tokenlab-model-catalog -- npx -y @tokenlabai/mcp-server
```

## Cài đặt trong Cline

Cài đặt server stdio đã xuất bản bằng Cline CLI:

```bash
cline mcp add tokenlab --yes -- npx -y @tokenlabai/mcp-server
```

Lệnh này đã được xác minh với Cline CLI và hoàn tất mà không có cảnh báo thiết lập. Các công cụ danh mục công khai hoạt động ngay lập tức; hãy thiết lập `TOKENLAB_API_KEY` trong môi trường Cline của bạn khi bạn cần các công cụ suy luận.

## Các cấu hình công cụ được tạo sẵn

| Cấu hình | Công cụ hiển thị | Phạm vi |
|---|---:|---|
| `catalog` | 6 | Bốn công cụ danh mục và giá công khai được tạo sẵn, cộng với `compare_models` và `get_api_overview`. Không cần khóa API. |
| `core` (mặc định) | 31 | 29 công cụ endpoint được tạo sẵn cộng với `compare_models` và `get_api_overview`. Bao gồm danh mục, giá cả, các endpoint LLM gốc, hình ảnh, video, âm nhạc, 3D, âm thanh, tác vụ, tệp tin, embedding, rerank và dịch thuật. |
| `full` | 80 | 78 công cụ endpoint được tạo sẵn cộng với hai công cụ khám phá tổng hợp. Thêm vòng đời phản hồi, lô (batches), thế giới, khám phá mô hình gốc và các hoạt động nhà phát triển khác trong danh sách cho phép. |

Tên công cụ, mô tả, lược đồ đầu vào, phương thức HTTP, đường dẫn, loại nội dung, yêu cầu xác thực và hành vi tác vụ được tạo từ bản chụp OpenAPI đã kiểm tra. Một lớp phủ chỉ dành cho MCP cung cấp các bí danh công cụ ổn định, tư cách thành viên cấu hình, ngữ nghĩa tác vụ bất đồng bộ, các biến thể multipart, lược bỏ bí mật và các ràng buộc không phát trực tuyến (non-streaming).

Phiên bản 0.6.0 cũng trả về JSON qua `structuredContent` của MCP, công bố ba tài nguyên hợp đồng và cung cấp hai mẫu prompt để chọn mô hình và xây dựng yêu cầu native. Các công cụ được tạo sẵn và công cụ tổng hợp có chú thích rủi ro tiêu chuẩn để các client tương thích có thể áp dụng chính sách phê duyệt an toàn hơn.

Các công cụ `core` phổ biến bao gồm:

| Nhóm | Công cụ đại diện |
|---|---|
| Danh mục và giá cả | `list_models`, `get_model`, `get_model_pricing`, `get_pricing`, `compare_models` |
| Endpoint LLM gốc | `create_chat_completion`, `create_response`, `create_anthropic_message`, `create_gemini_content` |
| Hình ảnh | `create_image`, `create_image_file`, `edit_image`, `edit_image_file` |
| Video, âm nhạc và 3D | `create_video`, `create_music`, `create_3d_model` |
| Âm thanh | `create_speech`, `transcribe_audio`, `translate_audio` |
| Embedding và văn bản | `create_embedding`, `create_multimodal_embedding`, `rerank_documents`, `translate_text` |
| Tệp tin và tác vụ | `upload_file`, `list_files`, `retrieve_file`, `retrieve_file_content`, `delete_file`, `get_task_status`, `cancel_task` |

Các lệnh gọi công cụ MCP trả về một kết quả cuối cùng. Các hoạt động chỉ phát trực tuyến và thời gian thực bị loại trừ, và các lược đồ yêu cầu được tạo sẵn giới hạn các trường `stream` được hỗ trợ ở mức `false`. Các phản hồi hình ảnh và âm thanh nhỏ trả về nội dung MCP gốc; các phản hồi nhị phân lớn hơn được ghi vào `TOKENLAB_ARTIFACT_DIR` và trả về cùng với đường dẫn cục bộ, loại MIME và số byte của chúng.

## Kết quả phương tiện bất đồng bộ

Việc tạo video, âm nhạc và 3D trả về các tóm tắt tác vụ bất đồng bộ. Việc tạo và chỉnh sửa hình ảnh có thể trả về kết quả đã hoàn thành hoặc một tác vụ bất đồng bộ, tùy thuộc vào mô hình và yêu cầu đã chọn.

Khi `delivery.mode` là `async`, hãy gọi `get_task_status` với `{ "id": delivery.task_id }` cho đến khi `delivery.terminal` là `true`. Xác định việc hoàn thành từ `status`; `progress` là tùy chọn và không được sử dụng làm điều kiện kết thúc.

## Quy trình làm việc khuyến nghị cho tác nhân

1. Gọi `list_models` khi người dùng chưa đặt tên cho mô hình.
2. Sử dụng `recommended_for` cho các tác vụ không phải trò chuyện, chẳng hạn như hình ảnh, video, âm nhạc, 3D, TTS, STT, embedding, rerank hoặc dịch thuật.
3. Gọi `get_model` trước khi xây dựng một yêu cầu không phải trò chuyện, thử lại một yêu cầu thất bại hoặc chuyển đổi các nhóm endpoint.
4. Gọi `get_model_pricing` khi chi phí mô hình ảnh hưởng đến lựa chọn của người dùng.
5. Sử dụng `compare_models` khi lựa chọn phụ thuộc vào một vài ứng viên.
6. Gọi công cụ được tạo sẵn khớp với hợp đồng API yêu cầu, hoặc sử dụng `get_api_overview` để có bản đồ thu gọn của các nhóm API TokenLab.

## Hướng dẫn về Endpoint gốc

TokenLab hỗ trợ các tuyến đường tương thích với OpenAI và các nhóm endpoint gốc. MCP server giúp tác nhân chọn đúng tuyến đường trước khi viết mã:

| Nhóm | Tuyến đường phổ biến |
|---|---|
| Chat tương thích OpenAI | `/v1/chat/completions` |
| Phản hồi | `/v1/responses` |
| Anthropic Messages | `/v1/messages` |
| Gemini gốc | `/v1beta/models/{model}:generateContent` |
| Hình ảnh | `/v1/images/generations`, `/v1/images/edits` |
| Video | `/v1/videos/generations` |
| Âm nhạc | `/v1/music/generations` |
| 3D | `/v1/3d/generations` |
| Âm thanh | `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/audio/translations` |
| Embedding và rerank | `/v1/embeddings`, `/v1/rerank` |
| Dịch văn bản | `/v1/translations` |

## Trình khám phá mô hình được lưu trữ

Các client hỗ trợ HTTP có thể phát trực tuyến có thể kết nối tới:

```text
https://tokenlab-model-explorer.vercel.app/mcp
```

Trình khám phá được lưu trữ là công khai và hiển thị `open_tokenlab_model_explorer`, `compare_tokenlab_models` và `generate_tokenlab_endpoint_example`. Hãy sử dụng server npm cục bộ ở trên khi bạn cần các cấu hình core/full được tạo sẵn, tải lên tệp tin cục bộ hoặc các hoạt động API được xác thực.

## Sử dụng với các kỹ năng TokenLab

MCP server hữu ích tại thời điểm chạy, trong khi [kho lưu trữ kỹ năng TokenLab](https://github.com/hedging8563/tokenlab-skills) dạy các tác nhân lập trình cách tạo và sửa mã tích hợp.

Sử dụng cả hai khi có sẵn:

- MCP server: khám phá các mô hình hiện tại, giá cả và chi tiết endpoint.
- Kỹ năng `tokenlab-api-integration`: tạo các ví dụ API có thể chạy được và xử lý các lỗi TokenLab có cấu trúc.
- Kỹ năng `tokenlab-model-picker`: chọn các mô hình mạnh mẽ cho tác vụ của người dùng.
- Kỹ năng `tokenlab-native-endpoints`: quyết định khi nào nên sử dụng các tuyến đường Responses, Anthropic Messages, Gemini, phương tiện, âm thanh, embedding, rerank hoặc dịch thuật.
