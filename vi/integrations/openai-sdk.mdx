## Tổng quan

LemonData hoạt động với các SDK OpenAI chính thức bằng cách trỏ client đến `https://api.lemondata.cc/v1`.

Đối với các dự án mới, ưu tiên **Responses API**. Chỉ giữ **Chat Completions** khi framework, plugin hoặc luồng mã legacy vẫn còn yêu cầu.

<Note>
Python, JavaScript và Go có các SDK OpenAI chính thức. PHP hoạt động tốt với các client cộng đồng tương thích OpenAI, nhưng đây không phải là SDK OpenAI chính thức.
</Note>

<Note>
**Loại**: SDK native

**Đường chính**: OpenAI-compatible / OpenAI Responses

**Mức hỗ trợ**: Đường lõi được hỗ trợ
</Note>

Đây là đường SDK OpenAI-compatible mặc định trên LemonData, nhưng không có nghĩa là mọi trường Responses-native-only sẽ hoạt động giống hệt nhau trên mọi model và kênh được định tuyến.

## Cấu hình Client

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## Khuyến nghị: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

<Note>
Một số hosted tools, cùng với `include`, `service_tier` và `truncation_strategy`, phụ thuộc vào hỗ trợ native `/v1/responses` passthrough của model đã chọn và channel được route. Nếu thiếu hỗ trợ này, LemonData sẽ trả về `400` hoặc `503` rõ ràng thay vì giả như trường đó đã hoạt động.
</Note>

## Streaming với Responses

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Công cụ / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## Tương thích Chat Completions

Nếu framework hoặc plugin của bạn vẫn yêu cầu Chat Completions, LemonData cũng hỗ trợ đường dẫn chuẩn tương thích OpenAI:

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
Chỉ sử dụng Chat Completions cho mục đích tương thích. Đối với các tích hợp mới, ưu tiên `client.responses.create(...)`.
</Warning>

## Khắc phục sự cố

<AccordionGroup>
  <Accordion title="Lỗi kết nối">
    - Xác minh base URL chính xác là `https://api.lemondata.cc/v1`
    - Kiểm tra sự can thiệp của proxy hoặc các ghi đè custom HTTP client
    - Đảm bảo phiên bản SDK của bạn là phiên bản hiện tại trước khi debug hành vi của provider
  </Accordion>

  <Accordion title="Xác thực thất bại">
    - Kiểm tra API key của bạn bắt đầu bằng `sk-`
    - Xác minh key đang hoạt động trong bảng điều khiển LemonData
    - Xác nhận SDK đang gửi `Authorization: Bearer ...`
  </Accordion>

  <Accordion title="Sai đường dẫn API">
    - `responses.create(...)` gửi request đến `/v1/responses`
    - `chat.completions.create(...)` gửi request đến `/v1/chat/completions`
    - Nếu ứng dụng của bạn hiện chỉ hỗ trợ Chat Completions, hãy giữ nó trên đường dẫn tương thích đó
  </Accordion>
</AccordionGroup>
