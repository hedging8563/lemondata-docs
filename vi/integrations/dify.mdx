## Tổng quan

Dify hoạt động tốt với LemonData thông qua luồng provider mô hình tương thích với OpenAI.

Đối với các phiên bản Dify hiện tại, cách an toàn nhất thường là:
- chọn provider **OpenAI** tích hợp sẵn
- đặt API key LemonData của bạn
- đặt base URL tùy chỉnh là `https://api.lemondata.cc/v1`

<Note>
Một số bản dựng Dify cũ hơn hiển thị tùy chọn này là `OpenAI-API-compatible` thay vì provider `OpenAI` tích hợp sẵn có trường base URL tùy chỉnh. Nếu giao diện Dify của bạn trông khác, hãy sử dụng luồng provider tùy chỉnh tương thích OpenAI gần nhất có sẵn trong phiên bản đó.
</Note>

## Điều kiện tiên quyết

- Tài khoản LemonData có quyền truy cập API
- Dify Cloud hoặc Dify tự host

## Các bước cấu hình

### Bước 1: Lấy API Key của bạn

1. Đăng nhập vào [LemonData Dashboard](https://lemondata.cc/dashboard)
2. Mở [API Keys](https://lemondata.cc/dashboard/api)
3. Tạo hoặc sao chép một API key bắt đầu bằng `sk-`

### Bước 2: Cấu hình Provider

<Steps>
  <Step title="Mở Model Providers">
    Trong Dify, đi đến **Settings** → **Model Providers**
  </Step>
  <Step title="Chọn OpenAI">
    Mở phần cài đặt provider **OpenAI**. Nếu phiên bản Dify của bạn không cung cấp base URL tùy chỉnh ở đây, hãy sử dụng tùy chọn provider tùy chỉnh tương thích OpenAI được cung cấp trong phiên bản đó.
  </Step>
  <Step title="Nhập cài đặt LemonData">
    Sử dụng các giá trị sau:

    | Field | Value |
    |-------|-------|
    | API Key | `sk-your-lemondata-key` |
    | API Base URL / Custom Base URL | `https://api.lemondata.cc/v1` |
  </Step>
  <Step title="Thêm mô hình">
    Thêm các mô hình bạn muốn sử dụng, ví dụ:
    - `gpt-5.4`
    - `gpt-5-mini`
    - `gpt-4o`
    - `claude-sonnet-4-6`
    - `claude-opus-4-6`
    - `gemini-2.5-flash`
    - `gemini-2.5-pro`
    - `deepseek-r1`
  </Step>
</Steps>

### Bước 3: Kiểm tra kết nối

1. Chọn một mô hình như `gpt-5-mini` hoặc `gpt-4o`
2. Gửi một prompt kiểm tra
3. Xác nhận rằng Dify nhận được phản hồi hợp lệ

## Embeddings cho Knowledge Base

Đối với RAG và lập chỉ mục knowledge base, hãy thêm một mô hình embedding như:
- `text-embedding-3-small`
- `text-embedding-3-large`

Sau đó đặt mô hình đó làm mô hình embedding mặc định trong knowledge base hoặc phần cài đặt ứng dụng tương ứng.

## Vai trò mô hình được khuyến nghị

| Use Case | Suggested Models |
|----------|------------------|
| Chat mặc định | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| Suy luận chuyên sâu | `gpt-5.4`, `claude-opus-4-6`, `deepseek-r1` |
| Nhanh/rẻ | `gpt-5-mini`, `gemini-2.5-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |
