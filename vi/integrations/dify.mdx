## Tổng quan

Dify hoạt động tốt với LemonData thông qua luồng provider model tương thích OpenAI.

Đối với các phiên bản Dify hiện tại, cách an toàn nhất thường là:
- chọn provider **OpenAI** tích hợp sẵn
- đặt API key LemonData của bạn
- đặt base URL tùy chỉnh là `https://api.lemondata.cc/v1`

<Note>
Một số bản dựng Dify cũ hơn hiển thị tùy chọn này là `OpenAI-API-compatible` thay vì provider `OpenAI` tích hợp sẵn với trường base URL tùy chỉnh. Nếu giao diện Dify của bạn trông khác, hãy sử dụng luồng provider tùy chỉnh tương thích OpenAI gần nhất có sẵn trong phiên bản đó.
</Note>

## Điều kiện tiên quyết

- Tài khoản LemonData có quyền truy cập API
- Dify Cloud hoặc Dify self-hosted

## Các bước cấu hình

### Bước 1: Lấy API Key của bạn

1. Đăng nhập vào [LemonData Dashboard](https://lemondata.cc/dashboard)
2. Mở [API Keys](https://lemondata.cc/dashboard/api)
3. Tạo hoặc sao chép một API key bắt đầu bằng `sk-`

### Bước 2: Cấu hình Provider

<Steps>
  <Step title="Mở Model Providers">
    Trong Dify, đi tới **Settings** → **Model Providers**
  </Step>
  <Step title="Chọn OpenAI">
    Mở phần cài đặt provider **OpenAI**. Nếu phiên bản Dify của bạn không cung cấp base URL tùy chỉnh tại đây, hãy sử dụng tùy chọn provider tùy chỉnh tương thích OpenAI mà phiên bản đó cung cấp.
  </Step>
  <Step title="Nhập cài đặt LemonData">
    Sử dụng các giá trị sau:

    | Field | Value |
    |-------|-------|
    | API Key | `sk-your-lemondata-key` |
    | API Base URL / Custom Base URL | `https://api.lemondata.cc/v1` |
  </Step>
  <Step title="Thêm model">
    Thêm các model bạn muốn sử dụng, ví dụ:
    - `gpt-5.4`
    - `gpt-5-mini`
    - `gpt-4o`
    - `claude-sonnet-4-6`
    - `claude-opus-4-6`
    - `gemini-2.5-flash`
    - `gemini-2.5-pro`
    - `deepseek-r1`
  </Step>
</Steps>

### Bước 3: Kiểm tra kết nối

1. Chọn một model như `gpt-5-mini` hoặc `gpt-4o`
2. Gửi một prompt thử nghiệm
3. Xác nhận rằng Dify nhận được phản hồi hợp lệ

## Embeddings cho knowledge base

Đối với RAG và lập chỉ mục knowledge base, hãy thêm một embedding model như:
- `text-embedding-3-small`
- `text-embedding-3-large`

Sau đó đặt model đó làm embedding model mặc định trong knowledge base hoặc phần cài đặt ứng dụng liên quan.

## Vai trò model được khuyến nghị

| Use Case | Suggested Models |
|----------|------------------|
| Chat mặc định | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| Suy luận sâu | `gpt-5.4`, `claude-opus-4-6`, `deepseek-r1` |
| Nhanh/rẻ | `gpt-5-mini`, `gemini-2.5-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## Thực tiễn tốt nhất

<AccordionGroup>
  <Accordion title="Bắt đầu với provider OpenAI tích hợp sẵn">
    Trong các phiên bản Dify mới hơn, provider OpenAI tích hợp sẵn với base URL tùy chỉnh thường là cách thiết lập gọn gàng nhất cho LemonData.
  </Accordion>

  <Accordion title="Sử dụng model rẻ hơn để lặp lại">

  </Accordion>

  <Accordion title="Lưu ý rằng Dify thường hướng đến chat-completions">
    Hầu hết các luồng Dify sử dụng hành vi chat tương thích OpenAI. Nếu bạn cần Responses hoặc hành vi WebSocket dành riêng cho Codex, hãy sử dụng các tích hợp Codex chuyên dụng thay vì Dify.
  </Accordion>
</AccordionGroup>
