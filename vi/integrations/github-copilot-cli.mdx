## Tổng quan

<Note>
**Loại**: tác nhân lập trình CLI

**Đường dẫn chính**: Chat Completions tương thích OpenAI

**Mức hỗ trợ**: đường dẫn BYOK chính thức
</Note>

[GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models) có thể kết nối với mọi endpoint tương thích OpenAI Chat Completions.

## Cài đặt và cấu hình

```bash
npm install -g @github/copilot
copilot --version
```

Cài đặt qua npm yêu cầu Node.js 22 trở lên. GitHub hiện yêu cầu gói Copilot đang hoạt động; tài khoản do tổ chức quản lý cũng cần bật chính sách Copilot CLI.

```bash
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.tokenlab.sh/v1"
export COPILOT_PROVIDER_API_KEY="sk-your-tokenlab-key"
export COPILOT_MODEL="kimi-k3"

copilot
```

Mô hình phải hỗ trợ streaming và gọi công cụ. `kimi-k3` hỗ trợ công cụ và có ngữ cảnh lớn hơn mức 128K GitHub khuyến nghị.

Hãy bắt đầu bằng tác vụ chỉ đọc, không sửa tệp. Nếu không tìm thấy mô hình, dùng ID logic từ [danh mục TokenLab hiện tại](https://tokenlab.sh/vi/models), không thêm tiền tố nhà cung cấp.

<Warning>
Không lưu API Key trong tệp được Git theo dõi. Hãy xoay mọi Key đã xuất hiện trong lịch sử terminal, ảnh chụp hoặc log.
</Warning>
