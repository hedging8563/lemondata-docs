## Tổng quan

OpenHands có thể sử dụng TokenLab thông qua cấu hình mô hình tương thích với LiteLLM/OpenAI, đặc biệt là đối với CLI và các quy trình làm việc headless, nơi bạn cung cấp mô hình, API key và base URL.

<Note>
**Loại**: Tác nhân lập trình (Coding Agent)

**Đường dẫn chính**: Cấu hình mô hình tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Hỗ trợ đường dẫn endpoint tùy chỉnh
</Note>

## Môi trường

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Cài đặt mô hình

Sử dụng:

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

Tiền tố `openai/` cho biết đường dẫn được hỗ trợ bởi LiteLLM sẽ sử dụng cấu hình nhà cung cấp tương thích với OpenAI.

## Thiết lập Headless

Nếu bạn đang chuẩn bị các mặc định cục bộ cho CLI hoặc sử dụng headless, hãy chạy quy trình thiết lập OpenHands và nhập:

```bash
make setup-config
```

Khi được nhắc nhập chi tiết mô hình, hãy sử dụng ID mô hình TokenLab với tiền tố `openai/` và base URL `/v1` của TokenLab.

## Gợi ý mô hình

Sử dụng `claude-sonnet-5` hoặc `gpt-5.4` cho việc lập kế hoạch của tác nhân lập trình, `gpt-5.4-mini` cho các vòng lặp thông thường nhanh hơn, và `deepseek-v4-pro` khi bạn muốn một mô hình suy luận thay thế mạnh mẽ.
