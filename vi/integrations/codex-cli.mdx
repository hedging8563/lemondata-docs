## Tổng quan

OpenAI Codex là một công cụ dòng lệnh mã nguồn mở (CLI), hoạt động như một coding agent gọn nhẹ, có khả năng đọc, chỉnh sửa và chạy mã trong terminal. Công cụ này được xây dựng trên các mô hình GPT và được tối ưu hóa cho việc sinh mã.

## Yêu cầu hệ thống

- **OS**: macOS, Linux (hỗ trợ chính thức), Windows qua WSL
- **Node.js**: Phiên bản 18+
- **npm**: Phiên bản 10.x.x trở lên

## Cài đặt

```bash
sudo npm install -g @openai/codex
```

Xác minh cài đặt:

```bash
codex --version
```

## Cấu hình

### Bước 1: Thiết lập API Key

**Tạm thời (phiên hiện tại):**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**Cấu hình vĩnh viễn:**

Thêm vào `~/.bashrc`, `~/.zshrc`, hoặc `~/.bash_profile`:

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

Sau đó tải lại:

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### Bước 2: Cấu hình config.toml

Chỉnh sửa `~/.codex/config.toml`:

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
Nếu file cấu hình chưa tồn tại, hãy chạy `codex` một lần để tạo file, sau đó chỉnh sửa file đó. Hãy khởi động lại Codex hoàn toàn sau khi thay đổi `config.toml` để các thiết lập provider mới được nạp lại.
</Note>

<Warning>
Codex đang ngừng hỗ trợ `chat/completions` cho các provider tùy chỉnh. Hãy giữ `wire_api = "responses"` cho LemonData trừ khi bạn cố ý sử dụng một đường dẫn tương thích cũ hơn.
</Warning>

## Cách sử dụng cơ bản

**Khởi động chế độ tương tác:**

```bash
codex
```

**Lệnh trực tiếp:**

```bash
codex "Fix the bug in main.py line 42"
```

**Chỉ định model:**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## Các model được khuyến nghị

| Model | Phù hợp nhất cho |
|-------|----------|
| `gpt-5.4` | Lựa chọn mặc định tốt nhất cho coding và reasoning |
| `gpt-5-mini` | Phương án dự phòng nhanh hơn, rẻ hơn cho các workflow coding |
| `claude-sonnet-4-6` | Review code, tài liệu |
| `deepseek-r1` | Thiết kế thuật toán, reasoning |

## Các lệnh tương tác

| Command | Mô tả |
|---------|-------------|
| `/help` | Hiển thị trợ giúp |
| `/exit` or `Ctrl+C` | Thoát |
| `/clear` | Xóa cuộc hội thoại |
| `/config` | Xem cấu hình |
| `/model <name>` | Chuyển model |
| `/tokens` | Xem mức sử dụng token |

## Xác minh cấu hình

```bash
# Check environment variable
echo $OPENAI_API_KEY

# Test API connection
codex "Hello, Codex!"

# View configuration
cat ~/.codex/config.toml
```

## Các trường hợp sử dụng phổ biến

**Review code:**

```bash
git diff | codex "Review these code changes"
```

**Tạo commit message:**

```bash
git diff --staged | codex "Generate a commit message for these changes"
```

**Sửa lỗi:**

```bash
codex "Fix the TypeScript errors in src/components/"
```

**Giải thích mã:**

```bash
cat main.py | codex "Explain what this code does"
```

## Khắc phục sự cố

<AccordionGroup>
  <Accordion title="Lỗi kết nối">
    - Xác minh `base_url` trong config.toml chính xác là `https://api.lemondata.cc/v1`
    - Kiểm tra kết nối mạng
    - Đảm bảo không có proxy gây can thiệp
  </Accordion>

  <Accordion title="Xác thực thất bại">
    - Xác minh `env_key = "OPENAI_API_KEY"` có trong `~/.codex/config.toml`
    - Xác minh biến môi trường `OPENAI_API_KEY` đã được thiết lập
    - Kiểm tra key bắt đầu bằng `sk-`
    - Đảm bảo key đang hoạt động trong dashboard LemonData
  </Accordion>

  <Accordion title="Không tìm thấy model">
    - Kiểm tra tên model khớp chính xác
    - Xác minh tính khả dụng của model tại [lemondata.cc/en/models](https://lemondata.cc/vi/models)
  </Accordion>
</AccordionGroup>
