## Tổng quan

<Note>
**Loại**: tác nhân desktop cho lập trình và tác vụ

**Đường dẫn chính**: Chat Completions tương thích OpenAI

**Mức hỗ trợ**: đường dẫn mô hình tùy chỉnh chính thức
</Note>

[WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) cung cấp trình chỉnh sửa trực quan cho mô hình tương thích OpenAI, không cần sửa tệp mô hình cục bộ bằng tay.

## Cấu hình TokenLab

Mở **Settings → Model**, thêm mô hình rồi chọn **Custom**.

| Trường | Giá trị |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key của bạn |
| Model name | `kimi-k3` |
| Custom Protocol | **Tắt** |

<Warning>
Giữ Custom Protocol ở trạng thái tắt. Chế độ chuẩn xác thực Base URL và tự thêm `/chat/completions`. Nếu bật nhưng chỉ nhập `/v1`, yêu cầu sẽ đi sai đường dẫn.
</Warning>

Trong phần nâng cao, bật gọi công cụ, đầu vào hình ảnh và chế độ suy luận. Tắt chế độ chỉ suy luận, để mức suy luận là Auto, đặt đầu vào `1048576` và đầu ra `131072`.

Lưu, chọn `kimi-k3` và thử kiểm tra thư mục chỉ đọc. Che API Key và endpoint riêng trước khi chia sẻ ảnh chụp.
