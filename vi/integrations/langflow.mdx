## Tổng quan

Thành phần **OpenAI** của Langflow bao gồm trường **OpenAI API Base**. Hãy trỏ trường đó đến endpoint `/v1` tương thích với OpenAI của TokenLab và sử dụng các ID mô hình của TokenLab.

<Note>
**Loại**: Trình xây dựng quy trình làm việc AI mã nguồn thấp (Low-code)

**Đường dẫn chính**: Hoàn tất trò chuyện (chat completions) tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Được hỗ trợ với các giới hạn phạm vi
</Note>

## Thành phần OpenAI

1. Thêm một thành phần mô hình ngôn ngữ **OpenAI**.
2. Đặt **OpenAI API Key** thành khóa TokenLab của bạn.
3. Mở rộng các cài đặt nâng cao.
4. Đặt **OpenAI API Base** thành `https://api.tokenlab.sh/v1`.
5. Đặt **Model Name** thành ID mô hình của TokenLab.
6. Kết nối đầu ra của mô hình với tác nhân (agent), chuỗi (chain) hoặc quy trình làm việc của bạn.

## Các giá trị

| Trường | Giá trị |
|-------|-------|
| OpenAI API Base | `https://api.tokenlab.sh/v1` |
| OpenAI API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

## Các mô hình được đề xuất

- `gpt-5.4-mini` cho hầu hết các thử nghiệm quy trình làm việc
- `claude-sonnet-5` cho khả năng viết và lập luận mạnh mẽ hơn
- `gemini-3.5-flash` cho các quy trình làm việc đa phương thức nhanh chóng
- `deepseek-v4-flash` cho các vòng lặp lập trình và lập luận nhanh

Sử dụng thành phần LiteLLM Proxy của Langflow nếu quá trình triển khai của bạn đã tập trung hóa việc định tuyến nhà cung cấp thông qua proxy LiteLLM.
