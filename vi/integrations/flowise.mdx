## Tổng quan

Flowise có thể gọi TokenLab thông qua một node chat TokenLab khi có sẵn, hoặc thông qua một node mô hình chat tương thích với OpenAI trỏ đến TokenLab.

<Note>
**Loại**: Trình xây dựng quy trình làm việc (Workflow Builder)

**Phương thức chính**: Hoàn thiện chat tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Được hỗ trợ với các giới hạn phạm vi
</Note>

## Node TokenLab

Nếu bản dựng Flowise của bạn bao gồm node mô hình chat **TokenLab**:

1. Thêm **Chat Models** -> **TokenLab**
2. Tạo thông tin xác thực API TokenLab
3. Đặt **Model Name** thành `gpt-5.4-mini`
4. Kết nối nó với chuỗi (chain), tác nhân (agent) hoặc quy trình làm việc của bạn
5. Chạy một prompt kiểm tra.

## Phương thức dự phòng tương thích với OpenAI

Nếu node TokenLab chưa khả dụng, hãy sử dụng node mô hình chat tương thích với OpenAI với các thông số sau:

| Trường | Giá trị |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Các mô hình được đề xuất

- `gpt-5.4-mini` cho hầu hết các bài kiểm tra quy trình làm việc
- `claude-sonnet-5` cho khả năng viết và suy luận mạnh mẽ hơn
- `gemini-3.5-flash` cho các quy trình làm việc đa phương thức nhanh chóng
- `deepseek-v4-flash` cho các vòng lặp mã nguồn hoặc suy luận nhanh
