## Tổng quan

<Note>
**Loại**: tác nhân lập trình cho IDE

**Đường dẫn chính**: Chat Completions tương thích OpenAI

**Mức hỗ trợ**: đường dẫn nhà cung cấp chính thức
</Note>

[Cline](https://docs.cline.bot/provider-config/openai-compatible) hỗ trợ nhà cung cấp tương thích OpenAI trong phần cài đặt IDE.

## Cấu hình TokenLab

1. Cài **Cline** từ kho tiện ích và mở bảng Cline.
2. Nhấp biểu tượng bánh răng và chọn **OpenAI Compatible** trong **API Provider**.
3. Nhập:

| Trường | Giá trị |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key của bạn |
| Model ID | `kimi-k3` |

4. Nhấp **Verify**.

Trong cấu hình nâng cao tùy chọn, đặt giới hạn đầu vào `1048576`, đầu ra tối đa `131072`, đồng thời bật hình ảnh và công cụ / Computer Use.

Sau khi xác minh, bắt đầu với tác vụ chỉ đọc. Nếu gặp 404, kiểm tra Base URL kết thúc bằng `/v1` và không chứa `/chat/completions`. ID là `kimi-k3`, không phải `kimi/kimi-k3`.
