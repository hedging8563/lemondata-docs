## Tổng quan

LangBot có thể gọi TokenLab thông qua trình yêu cầu LLM tương thích với OpenAI.

<Note>
**Loại**: Nền tảng Bot

**Đường dẫn chính**: Hoàn tất trò chuyện (chat completions) tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Được hỗ trợ với các giới hạn phạm vi
</Note>

## Trình yêu cầu TokenLab

Nếu bản dựng LangBot của bạn bao gồm trình yêu cầu **TokenLab**:

1. Mở cài đặt nhà cung cấp mô hình của LangBot.
2. Thêm một nhà cung cấp với trình yêu cầu **TokenLab**.
3. Đặt API key thành khóa TokenLab của bạn.
4. Chọn hoặc tạo một mô hình như `gpt-5.4-mini`.
5. Gắn mô hình vào pipeline hoặc bot cần sử dụng nó.

## Dự phòng tương thích với OpenAI

Nếu TokenLab chưa được liệt kê, hãy sử dụng trình yêu cầu tương thích với OpenAI:

| Trường | Giá trị |
|-------|-------|
| Requester | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Các mô hình được đề xuất

- `gpt-5.4-mini` cho hầu hết các tương tác bot
- `claude-sonnet-5` cho việc viết và suy luận dài hơn
- `deepseek-v4-flash` cho các vòng lặp lập trình và suy luận nhanh
- `gemini-3.5-flash` cho các quy trình làm việc chung nhanh chóng
