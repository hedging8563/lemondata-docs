## Tổng quan

Hầu hết các ứng dụng chat AI phổ thông kết nối với LemonData thông qua đường dẫn chat tiêu chuẩn tương thích OpenAI.

Trong thực tế, điều đó có nghĩa là:
- sử dụng `https://api.lemondata.cc/v1` làm base URL trừ khi ứng dụng yêu cầu rõ ràng một endpoint URL đầy đủ
- sử dụng API key LemonData của bạn làm API key theo kiểu OpenAI
- chọn các model mà ứng dụng có thể sử dụng trong quy trình chat tiêu chuẩn

<Note>
Các ứng dụng chat phổ thông thường **định hướng theo chat-completions**, không phải là client Codex Responses WebSocket. Đối với Codex CLI/App, Cursor hoặc các công cụ lập trình khác cần hành vi dành riêng cho Responses, hãy sử dụng các hướng dẫn tích hợp chuyên biệt tương ứng.
</Note>

## Ứng dụng được hỗ trợ

| Application | Platform | Notes |
|-------------|----------|-------|
| LobeChat | Web, Desktop, Self-hosted | Hỗ trợ custom-provider mạnh mẽ |
| Cherry Studio | Windows, macOS, Linux | Quy trình provider tương thích OpenAI tốt |
| Chatbox | Windows, macOS, Linux | Thiết lập tương thích OpenAI đơn giản |
| TypingMind | Web, Desktop | Sử dụng kiểu custom endpoint |
| BotGem | iOS, macOS | Cấu hình custom provider |
| OpenCat | iOS, macOS | Quy trình custom endpoint tương thích OpenAI |
| ChatWise | Windows, macOS | Mẫu custom provider tiêu chuẩn |

## Giá trị kết nối mặc định

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

Nếu một ứng dụng yêu cầu **endpoint URL đầy đủ** thay vì base URL, hãy sử dụng:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## Ví dụ thiết lập ứng dụng

<Tabs>
  <Tab title="LobeChat">
    **LobeChat Self-hosted**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. Mở **Settings** → **AI Service Provider**
    2. Chọn **OpenAI**
    3. Nhập API key LemonData của bạn
    4. Đặt custom endpoint thành `https://api.lemondata.cc/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. Mở **Settings** → **Model Provider**
    2. Thêm một provider **tương thích OpenAI**
    3. Nhập:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. Thêm các model bạn muốn sử dụng
  </Tab>

  <Tab title="Chatbox">
    1. Mở **Settings** → **AI Model**
    2. Chọn **OpenAI API Compatible**
    3. Nhập:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` hoặc `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. Mở **Settings**
    2. Chọn **Custom Endpoint**
    3. Nhập:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. Cấu hình các model bạn muốn hiển thị
  </Tab>
</Tabs>
