## Tổng quan

LemonData cung cấp quyền truy cập vào các mô hình Higgsfield AI. Tổng cộng: hiện có **3 mô hình**.

## Mô hình Chat

| Model ID | Giá cả |
|----------|--------|
| `higgsfield-lite` | Xem dashboard |
| `higgsfield-standard` | Xem dashboard |
| `higgsfield-turbo` | Xem dashboard |


## Cách sử dụng

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="higgsfield-lite",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

<Note>
Giá hiển thị là giá của nền tảng (~70% so với giá chính thức).
</Note>
