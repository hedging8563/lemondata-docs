<Note>
**Self-hosted** có nghĩa là bạn chạy LemonClaw trực tiếp trên VPS hoặc máy cá nhân của mình. Bạn chỉ trả phí sử dụng mô hình AI thông qua số dư LemonData — không tốn phí duy trì instance.
</Note>

<Tip>
Bạn thích thiết lập có sẵn (hosted)? [Tạo một Claw instance](/claw/introduction) để có cùng môi trường thực thi LemonClaw và WebUI mà không cần tự quản lý máy chủ.
</Tip>

## Cài đặt nhanh

<CodeGroup>
```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```

```bash Non-interactive
LEMONDATA_API_KEY=sk-xxx curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```
</CodeGroup>

Trình cài đặt sẽ yêu cầu bạn nhập **LemonData API Key**. Lấy mã tại [Dashboard](https://lemondata.cc/dashboard).

## Các thành phần được cài đặt

<Steps>
  <Step title="Node.js 22+">
    Tự động cài đặt nếu chưa có (thông qua NodeSource trên Linux, Homebrew trên macOS)
  </Step>
  <Step title="LemonClaw">
    Gói LemonClaw được cấu hình sẵn với LemonData API
  </Step>
  <Step title="15 mô hình AI">
    Claude, GPT-5, Gemini, DeepSeek, và nhiều hơn nữa — đã sẵn sàng sử dụng
  </Step>
  <Step title="Plugin IM">
    Các plugin DingTalk, WeCom, và QQ được cài đặt sẵn
  </Step>
  <Step title="Dịch vụ hệ thống">
    Tự động khởi chạy cùng hệ thống (systemd trên Linux, launchd trên macOS)
  </Step>
</Steps>

## Yêu cầu hệ thống

| Yêu cầu | Chi tiết |
|-------------|---------|
| **Hệ điều hành** | Linux (Ubuntu/Debian/CentOS/RHEL) hoặc macOS |
| **Kiến trúc** | x64 hoặc arm64 |
| **RAM** | Tối thiểu 1 GB, khuyến nghị 2 GB |
| **API Key** | [Lấy tại đây](https://lemondata.cc) |

## Sau khi cài đặt

Trình cài đặt sẽ hiển thị thông tin đăng nhập của bạn:

```
✓ LemonClaw installed successfully!

  WebUI:        http://your-ip:18789
  Token:        your-gateway-token
  Auto-login:   http://your-ip:18789?token=your-gateway-token
  Model:        claude-sonnet-4-6
```

<Warning>
**Hãy lưu lại token của bạn!** Bạn cần nó để truy cập WebUI và kết nối với các nền tảng nhắn tin.
</Warning>

## Các lệnh quản lý

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user status lemonclaw    # Kiểm tra trạng thái
    journalctl --user -u lemonclaw -f    # Xem nhật ký (logs)
    systemctl --user restart lemonclaw   # Khởi động lại
    systemctl --user stop lemonclaw      # Dừng
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    tail -f ~/.lemonclaw/lemonclaw.log    # Xem nhật ký (logs)
    launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # Khởi động lại
    launchctl stop cc.lemondata.lemonclaw  # Dừng
    ```
  </Tab>
</Tabs>

## Cấu hình

Vị trí tệp cấu hình: `~/.lemonclaw/config.json`

Sau khi chỉnh sửa, hãy khởi động lại dịch vụ để áp dụng các thay đổi.

### Thay đổi mô hình mặc định

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-opus-4-6"
      }
    }
  }
}
```

Các tiền tố mô hình khả dụng (tùy vào provider bạn đã bật trong [LemonData Provider Setup](/claw/lemondata-provider)):
- `lemondata/` — Tuyến tương thích OpenAI (`openai-completions`)
- `lemondata-responses/` — Tuyến OpenAI Responses (`openai-responses`)
- `lemondata-claude/` — Tuyến native Claude (`anthropic-messages`)
- `lemondata-gemini/` — Tuyến native Gemini (`google-generative-ai`)
- `lemondata-minimax/` — Tuyến native MiniMax (`anthropic-messages`)

## Nâng cấp

```bash
# Chạy lại trình cài đặt để nâng cấp lên phiên bản mới nhất
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
# Sau đó khởi động lại dịch vụ
systemctl --user restart lemonclaw  # Linux
# hoặc
launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # macOS
```

## Gỡ cài đặt

```bash
# Dừng và vô hiệu hóa dịch vụ
systemctl --user stop lemonclaw && systemctl --user disable lemonclaw  # Linux
launchctl unload ~/Library/LaunchAgents/cc.lemondata.lemonclaw.plist  # macOS

# Xóa LemonClaw
rm -rf ~/.lemonclaw
```

## Self-Hosted so với Managed

| | Self-Hosted | Managed (Claw) |
|---|---|---|
| **Chi phí instance** | Miễn phí | $20 / 30 ngày |
| **Sử dụng AI** | Trả theo mức sử dụng | Trả theo mức sử dụng |
| **Cơ sở hạ tầng** | Máy chủ của bạn | Chúng tôi quản lý mọi thứ |
| **Cập nhật** | Thủ công (chạy lại trình cài đặt) | Tự động |
| **Hỗ trợ** | Cộng đồng | Ưu tiên |
