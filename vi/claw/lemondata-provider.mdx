<Note>
Huong dan nay danh cho nguoi dung **OpenClaw tu host** muon ket noi LemonData lam provider AI.
</Note>

<Tip>
Neu ban muon dung giai phap hosted, hay [tao mot instance LemonClaw](/claw/introduction). LemonData da duoc cau hinh san theo mac dinh, vi vay ban co the bat dau ngay trong WebUI.
</Tip>

## Tong quan

OpenClaw can **3 providers rieng biet** de truy cap tat ca cac mo hinh LemonData, vi moi nhom mo hinh su dung mot dinh dang API khac nhau.

| Provider | Dinh dang API | Mo hinh | baseUrl |
|----------|-----------|--------|---------|
| `lemondata` | `openai-completions` | GPT, DeepSeek, Qwen, Gemini, v.v. | `https://api.lemondata.cc/v1` |
| `lemondata-claude` | `anthropic-messages` | Claude (Opus, Sonnet, Haiku) | `https://api.lemondata.cc` |
| `lemondata-minimax` | `anthropic-messages` | Cac mo hinh MiniMax | `https://api.lemondata.cc` |

<Warning>
Hay chu y den hau to `/v1`. Provider `lemondata` **bao gom** `/v1` vi OpenAI SDK khong tu dong them no. Hai provider con lai **khong bao gom** `/v1` vi Anthropic SDK se tu dong them no.
</Warning>

## Dieu kien can

- Mot instance OpenClaw tu host
- Mot LemonData API Key — [lay tai day](https://lemondata.cc/dashboard)

## Cau hinh

Chinh sua cau hinh provider OpenClaw cua ban:

- **Tu host**: `~/.openclaw/openclaw.json`

Them 3 providers sau vao mang `providers`:

```json
{
  "providers": [
    {
      "name": "lemondata",
      "api": "openai-completions",
      "baseUrl": "https://api.lemondata.cc/v1",
      "apiKey": "sk-your-lemondata-key"
    },
    {
      "name": "lemondata-claude",
      "api": "anthropic-messages",
      "baseUrl": "https://api.lemondata.cc",
      "apiKey": "sk-your-lemondata-key"
    },
    {
      "name": "lemondata-minimax",
      "api": "anthropic-messages",
      "baseUrl": "https://api.lemondata.cc",
      "apiKey": "sk-your-lemondata-key"
    }
  ]
}
```

<Info>
Ca 3 providers deu dung **cung mot API Key**. Ban chi can mot tai khoan LemonData.
</Info>

## Su dung mo hinh

Tham chieu mo hinh theo dinh dang `provider/model`:

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-sonnet-4-6"
      }
    }
  }
}
```

### Vi du mo hinh

| Provider | Tham chieu mo hinh | Mo ta |
|----------|----------------|-------------|
| `lemondata` | `lemondata/gpt-4o` | OpenAI GPT-4o |
| `lemondata` | `lemondata/deepseek-r1` | Mo hinh suy luan DeepSeek R1 |
| `lemondata` | `lemondata/gemini-2.5-flash` | Google Gemini |
| `lemondata-claude` | `lemondata-claude/claude-opus-4-6` | Claude Opus |
| `lemondata-claude` | `lemondata-claude/claude-sonnet-4-6` | Claude Sonnet |
| `lemondata-claude` | `lemondata-claude/claude-haiku-4-5` | Claude Haiku |
| `lemondata-minimax` | `lemondata-minimax/minimax-m1` | MiniMax M1 |

Xem tat ca cac mo hinh co san tai [lemondata.cc/models](https://lemondata.cc/vi/models).

## Loi thuong gap

<AccordionGroup>
  <Accordion title="Dung sai baseUrl cho mo hinh Claude">
    Neu dung `https://api.lemondata.cc/v1` cho `lemondata-claude`, ban se gap loi xac thuc. Anthropic SDK tu dong them `/v1`, dan den duong dan bi lap `/v1/v1`. Hay dung `https://api.lemondata.cc` (khong co `/v1`) cho providers dinh dang Anthropic.
  </Accordion>
  <Accordion title="Dung ten provider la 'openai' thay vi 'lemondata'">
    OpenClaw xac dinh API key dua tren **name** cua provider. Neu dung `"name": "openai"`, OpenClaw se co gang su dung API key cua OpenAI thay vi key LemonData cua ban. Luon dung `"name": "lemondata"` (hoac `lemondata-claude` / `lemondata-minimax`).
  </Accordion>
  <Accordion title="Loi model not found">
    Hay dam bao ban dang dung dung tien to provider. Cac mo hinh Claude phai dung `lemondata-claude/`, khong phai `lemondata/`. Kiem tra [lemondata.cc/models](https://lemondata.cc/vi/models) de lay dung model ID.
  </Accordion>
</AccordionGroup>

## Xac minh cau hinh

Sau khi luu cau hinh, hay khoi dong lai OpenClaw va thu gui mot tin nhan don gian. Neu nhan duoc phan hoi, provider da duoc cau hinh dung.

```bash
# Tu host: khoi dong lai dich vu
systemctl --user restart openclaw    # Linux
launchctl stop cc.lemondata.openclaw && launchctl start cc.lemondata.openclaw  # macOS
```
