## Bước 1: Lấy API Key của bạn

<Steps>
  <Step title="Tạo tài khoản">
    Đăng ký tại [lemondata.cc](https://lemondata.cc) bằng email, tài khoản Gmail hoặc GitHub của bạn.
  </Step>
  <Step title="Nạp credits">
    Mở dashboard và nạp credits vào tài khoản của bạn. LemonData sử dụng mô hình tính giá pay-as-you-go mà không yêu cầu cam kết tối thiểu.
  </Step>
  <Step title="Tạo API key">
    Đi đến **Dashboard → API Keys** và tạo một key mới. Sao chép và lưu trữ an toàn vì key này chỉ được hiển thị một lần.
  </Step>
</Steps>

<Warning>
Giữ API key của bạn an toàn. Không bao giờ để lộ nó trong code phía client hoặc các repository công khai.
</Warning>

## Bước 3: Thực hiện yêu cầu đầu tiên

Đối với các dự án mới, hãy bắt đầu với **Responses API**.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
Nếu framework hoặc công cụ của bạn vẫn yêu cầu Chat Completions, LemonData cũng hỗ trợ `POST /v1/chat/completions`. Đối với các integration mới, ưu tiên `POST /v1/responses`.
</Note>

## Thử các model khác nhau

LemonData hỗ trợ hơn 300 model. Chỉ cần thay đổi trường `model`:

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## Bật Streaming

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
