## Nội dung Request

<ParamField body="model" type="string" required>
  ID của model sẽ được sử dụng. Xem [Models](https://lemondata.cc/vi/models) để biết các tùy chọn khả dụng.
</ParamField>

<ParamField body="messages" type="array" required>
  Danh sách các tin nhắn cấu thành cuộc hội thoại.

  Mỗi đối tượng tin nhắn bao gồm:
  - `role` (string): `system`, `user`, hoặc `assistant`
  - `content` (string | array): Nội dung tin nhắn
</ParamField>

<ParamField body="temperature" type="number" default="1">
  Nhiệt độ lấy mẫu trong khoảng từ 0 đến 2. Giá trị cao hơn sẽ làm đầu ra ngẫu nhiên hơn.
</ParamField>

<ParamField body="max_tokens" type="integer">
  Số lượng token tối đa sẽ được tạo.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  Nếu là true, các delta tin nhắn một phần sẽ được gửi dưới dạng sự kiện SSE.
</ParamField>

<ParamField body="stream_options" type="object">
  Các tùy chọn cho streaming. Đặt `include_usage: true` để nhận thông tin sử dụng token trong các chunk stream.
</ParamField>

<ParamField body="top_p" type="number" default="1">
  Tham số lấy mẫu nucleus. Chúng tôi khuyến nghị chỉ thay đổi tham số này hoặc temperature, không thay đổi cả hai.
</ParamField>

<ParamField body="frequency_penalty" type="number" default="0">
  Một số trong khoảng từ -2.0 đến 2.0. Giá trị dương sẽ phạt các token lặp lại.
</ParamField>

<ParamField body="presence_penalty" type="number" default="0">
  Một số trong khoảng từ -2.0 đến 2.0. Giá trị dương sẽ phạt các token đã xuất hiện trong văn bản.
</ParamField>

<ParamField body="stop" type="string | array">
  Tối đa 4 chuỗi mà tại đó API sẽ dừng tạo token.
</ParamField>

<ParamField body="tools" type="array">
  Danh sách các công cụ mà model có thể gọi (function calling).
</ParamField>

<ParamField body="tool_choice" type="string | object">
  Kiểm soát cách model sử dụng công cụ. Các tùy chọn: `auto`, `none`, `required`, hoặc một đối tượng công cụ cụ thể.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  Có bật function calling song song hay không. Đặt là false để gọi hàm tuần tự.
</ParamField>

<ParamField body="max_completion_tokens" type="integer">
  Số token tối đa cho completion. Là lựa chọn thay thế cho `max_tokens`, hữu ích cho các họ model mới hơn có hỗ trợ reasoning.
</ParamField>

<ParamField body="reasoning_effort" type="string">
  Mức độ reasoning cho các model có hỗ trợ reasoning. Các tùy chọn: `low`, `medium`, `high`.
</ParamField>

<ParamField body="seed" type="integer">
  Seed ngẫu nhiên cho việc lấy mẫu tất định.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Số lượng completion cần tạo (1-128).
</ParamField>

<ParamField body="logprobs" type="boolean">
  Có trả về log probability hay không.
</ParamField>

<ParamField body="top_logprobs" type="integer">
  Số lượng log probability hàng đầu cần trả về (0-20). Yêu cầu `logprobs: true`.
</ParamField>

<ParamField body="top_k" type="integer">
  Tham số lấy mẫu Top-K (dành cho các model Anthropic/Gemini).
</ParamField>

<ParamField body="response_format" type="object">
  Đặc tả định dạng phản hồi. Sử dụng `{"type": "json_object"}` cho chế độ JSON, hoặc `{"type": "json_schema", "json_schema": {...}}` cho đầu ra có cấu trúc.
</ParamField>

<ParamField body="logit_bias" type="object">
  Điều chỉnh khả năng xuất hiện của các token được chỉ định. Ánh xạ ID token (dưới dạng string) tới các giá trị bias từ -100 đến 100.
</ParamField>

<ParamField body="user" type="string">
  Một mã định danh duy nhất đại diện cho end-user của bạn để giám sát việc lạm dụng.
</ParamField>

<ParamField body="cache_control" type="object">
  Các tùy chọn kiểm soát cache của LemonData.

  - `type` (string): Chiến lược cache - `default`, `no_cache`, `no_store`, `response_only`, `semantic_only`
  - `max_age` (integer): TTL của cache tính bằng giây (tối đa 86400)
</ParamField>

## Phản hồi

<ResponseField name="id" type="string">
  Mã định danh duy nhất của completion.
</ResponseField>

<ResponseField name="object" type="string">
  Luôn là `chat.completion`.
</ResponseField>

<ResponseField name="created" type="integer">
  Dấu thời gian Unix của thời điểm completion được tạo.
</ResponseField>

<ResponseField name="model" type="string">
  Model được sử dụng để tạo completion.
</ResponseField>

<ResponseField name="choices" type="array">
  Danh sách các lựa chọn completion.

  Mỗi lựa chọn bao gồm:
  - `index` (integer): Chỉ mục của lựa chọn
  - `message` (object): Tin nhắn được tạo
  - `finish_reason` (string): Lý do model dừng lại (`stop`, `length`, `tool_calls`)
</ResponseField>

<ResponseField name="usage" type="object">
  Thống kê sử dụng token.

  - `prompt_tokens` (integer): Token trong prompt
  - `completion_tokens` (integer): Token trong completion
  - `total_tokens` (integer): Tổng số token đã sử dụng
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/chat/completions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "temperature": 0.7,
    "max_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ],
    temperature=0.7,
    max_tokens=1000
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Hello!' }
  ],
  temperature: 0.7,
  max_tokens: 1000
});

console.log(response.choices[0].message.content);
```

```php PHP
<?php
$ch = curl_init('https://api.lemondata.cc/v1/chat/completions');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-4o',
        'messages' => [
            ['role' => 'system', 'content' => 'You are a helpful assistant.'],
            ['role' => 'user', 'content' => 'Hello!']
        ],
        'temperature' => 0.7,
        'max_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['choices'][0]['message']['content'];
```
