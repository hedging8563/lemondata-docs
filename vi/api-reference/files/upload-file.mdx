## Tổng Quan

Điểm cuối này là một phần của Batch API tương thích với OpenAI của LemonData. Các công việc theo lô sử dụng các tệp JSONL đã tải lên, chạy không đồng bộ và có thể trả về các tệp đầu ra/lỗi sau.

## Ghi Chú

- Các tệp đầu vào theo lô phải sử dụng `purpose=batch`.
- `completion_window` hiện tại là `24h`.
- Thứ tự đầu ra không được đảm bảo; luôn khớp theo `custom_id`.
- Streaming không được hỗ trợ bên trong các mục theo lô.

## Yêu Cầu / Phản Hồi

Sử dụng bảng điều khiển OpenAPI tương tác ở trên để có sơ đồ chính xác.

## Mẹo Vận Hành

- Sử dụng `custom_id` cho việc đối chiếu không thay đổi ở phía hạ nguồn.
- Mong đợi `output_file_id` và `error_file_id` chỉ sau khi công nhân hoàn tất lô.
- Giá theo lô có thể khác với giá đồng bộ vì các quy tắc giảm giá `isBatchRequest=true` áp dụng.
## Anthropic Files API Mode

This same `/v1/files` route also supports the Anthropic Files API path.

- Add `anthropic-beta: files-api-2025-04-14` to switch the route into Anthropic mode.
- In Anthropic mode, upload the original file directly and do not send `purpose=batch`.
- The returned `file_id` is bound to the same official Anthropic channel/workspace and should be reused from `/v1/messages` requests.
- If you plan to reference the uploaded file from Anthropic message content, keep using Anthropic-native headers (`x-api-key`, `anthropic-version`, and the beta header when required).
