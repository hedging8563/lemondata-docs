## Tổng quan

Sử dụng endpoint này để polling async hợp nhất trên nhiều loại tác vụ như tạo video, hình ảnh, âm nhạc và 3D.

<Info>
Nếu phản hồi create bao gồm `poll_url`, hãy gọi chính xác path đó. Đối với các workflow async mới hơn, `poll_url` có thể trỏ tới `/v1/tasks/{id}`.
</Info>

## Tham số Đường dẫn

<ParamField path="id" type="string" required>
  ID tác vụ được trả về từ yêu cầu create.
</ParamField>

## Phản hồi

<ResponseField name="id" type="string">
  Định danh tác vụ.
</ResponseField>

<ResponseField name="status" type="string">
  Trạng thái tác vụ như `pending`, `processing`, `completed` hoặc `failed`.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL asset kết quả khi tác vụ hoàn tất và tạo ra một video.
</ResponseField>

<ResponseField name="error" type="string">
  Thông báo lỗi khi tác vụ thất bại.
</ResponseField>

## Ví dụ

```bash cURL
curl "https://api.lemondata.cc/v1/tasks/video_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

poll_url = "/v1/tasks/video_abc123"
response = requests.get(
    f"https://api.lemondata.cc{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/video_abc123';
const response = await fetch(`https://api.lemondata.cc${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
