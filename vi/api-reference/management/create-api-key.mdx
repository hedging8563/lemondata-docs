## Tổng Quan

Tạo một API key mới với `type=user` trong tổ chức gắn với token quản lý hiện tại.

## Ghi Chú

- Toàn bộ giá trị key chỉ xuất hiện đúng một lần trong phản hồi.

## Yêu Cầu / Phản Hồi

Sử dụng bảng điều khiển OpenAPI tương tác ở trên để xem schema chính xác.
