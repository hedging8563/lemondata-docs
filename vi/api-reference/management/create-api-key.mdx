## Tổng quan

Endpoint này tạo một API Key mới loại `type=user` trong tổ chức gắn với management token hiện tại.

## Request body

| Trường | Kiểu | Mặc định / giới hạn | Ghi chú |
|-------|------|------------------|-------|
| name | string | required, default Default Key, length 1-50 | Display name, trimmed server-side |
| limitAmount | number \| null | min 0, max 100000 | null or omitted = unlimited, 0 = zero quota, positive = USD spending cap |
| models | string[] | default [] | Optional logical model allowlist |
| expiresAt | string \| null | RFC3339 datetime | null means no expiry |

## Lưu ý

- Giá trị đầy đủ của API Key chỉ được hiển thị một lần trong phản hồi.
- `models: []` nghĩa là key không có ràng buộc model bổ sung ngoài chính sách của tổ chức.
- `limitAmount: 0` tạo ra một key hợp lệ nhưng chưa thể tiêu quota cho đến khi được cập nhật sau đó.

## Ví dụ

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "sora-2"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>
