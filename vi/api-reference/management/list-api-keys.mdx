## Tổng Quan

Trả về danh sách API key của người dùng trong tổ chức gắn với token quản lý hiện tại.

## Ghi Chú

- Các key do hệ thống quản lý, như Playground hoặc Claw, sẽ không xuất hiện trong kết quả.

## Yêu Cầu / Phản Hồi

Sử dụng bảng điều khiển OpenAPI tương tác ở trên để xem schema chính xác.
