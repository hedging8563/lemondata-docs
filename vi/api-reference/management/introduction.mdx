## Tổng Quan

API quản lý cho phép bạn quản lý API key của tổ chức và xem usage, billing của một key cụ thể mà không cần dùng API key inference thông thường.

Hãy dùng token quản lý từ trang **Settings** trong Dashboard:

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
Management token không phải là API key dùng cho inference. Dùng `mt-...` cho `/v1/management/*` và dùng `sk-...` cho các endpoint inference như `/v1/responses`.
</Warning>

## Endpoint khả dụng

| Endpoint | Method | Mô tả |
|----------|--------|------|
| `/v1/management/api-keys` | GET | Liệt kê API key của người dùng trong tổ chức hiện tại |
| `/v1/management/api-keys` | POST | Tạo API key người dùng mới |
| `/v1/management/api-keys/{keyId}` | PATCH | Cập nhật tên, hạn mức sử dụng, model được phép, thời hạn hoặc trạng thái |
| `/v1/management/api-keys/{keyId}/usage` | GET | Lấy chi tiết usage có phân trang cho một key cụ thể |
| `/v1/management/api-keys/{keyId}/billing` | GET | Lấy các breakdown billing tổng hợp cho một key cụ thể |

## Giải thích trường

- tên model được gửi trong request (`model`)
- nhà cung cấp model công khai
- `scene`
- `accessChannel`: `platform` nghĩa là request được tính phí theo platform; `byok` nghĩa là request dùng key provider upstream của chính bạn
- số lượng usage, đơn vị tính phí và chỉ số cache
- chi phí và mốc thời gian

Phản hồi chỉ hiển thị các trường billing và reporting công khai. Chi tiết routing nội bộ và metadata của provider vật lý sẽ bị ẩn.

## Bộ lọc

`/usage` và `/billing` hiện hỗ trợ lọc theo:

- khoảng thời gian
- tên model được gửi trong request (`model`)
- nhà cung cấp model công khai
- `scene`
- `accessChannel`
- phân trang

## Ví dụ request đầy đủ

Bắt đầu bằng cách liệt kê các API key của tổ chức có thể truy cập bằng token quản lý hiện tại:

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```

```python Python
import requests

response = requests.get(
    "https://api.lemondata.cc/v1/management/api-keys",
    headers={"Authorization": "Bearer mt-your-management-token"}
)

data = response.json()
for key in data["data"]:
    print(key["name"], key["status"], key["used_amount"])
```

```javascript JavaScript
const response = await fetch(
  'https://api.lemondata.cc/v1/management/api-keys',
  {
    headers: {
      'Authorization': 'Bearer mt-your-management-token'
    }
  }
);

const data = await response.json();
for (const key of data.data) {
  console.log(key.name, key.status, key.used_amount);
}
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/management/api-keys", nil)
    req.Header.Set("Authorization", "Bearer mt-your-management-token")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)

    fmt.Println(result["object"])
}
```

```php PHP
<?php
$ch = curl_init("https://api.lemondata.cc/v1/management/api-keys");

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer mt-your-management-token'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
foreach ($data['data'] as $key) {
    echo $key["name"] . " " . $key["status"] . " " . $key["used_amount"] . PHP_EOL;
}
```
</RequestExample>
