## Tổng Quan

Endpoint này trả về chi tiết usage ở cấp key với bộ lọc theo tên model được gửi trong request (`model`), nhà cung cấp model công khai, `scene` và `accessChannel`.

## Ghi Chú

- Phản hồi chỉ bao gồm các trường billing công khai.
- Routing nội bộ và metadata của kênh vật lý sẽ được ẩn đi.

## Yêu Cầu / Phản Hồi

Sử dụng bảng điều khiển OpenAPI tương tác ở trên để xem schema chính xác.
