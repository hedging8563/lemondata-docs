## Tổng quan

Dùng endpoint này để cập nhật tên, giới hạn sử dụng, danh sách model cho phép, thời gian hết hạn hoặc trạng thái của API Key hiện có.

## Request body

Yêu cầu PATCH phải có ít nhất một trường.

| Trường | Kiểu | Mặc định / giới hạn | Ghi chú |
|-------|------|------------------|-------|
| status | enum | - | active, inactive, revoked |
| name | string | độ dài 1-50 | Tên hiển thị đã cập nhật |
| limitAmount | number \| null | min 0, max 100000 | null = unlimited, 0 = zero quota, positive = USD cap |
| models | string[] | - | Danh sách cho phép logical model đã cập nhật |
| expiresAt | string \| null | datetime RFC3339 | null sẽ xoá thời gian hết hạn |

## Lưu ý

- Management API v1 cố ý không hỗ trợ hard delete.
- `revoked` thường được xem là trạng thái cuối; nếu cần một key mới, thông thường nên tạo key khác.

## Ví dụ

<RequestExample>
```bash cURL
curl -X PATCH "https://api.lemondata.cc/v1/management/api-keys/key_abc123def456" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "inactive",
    "limitAmount": 0
  }'
```
</RequestExample>
