## Tổng Quan

Dùng endpoint này để cập nhật tên, hạn mức sử dụng, model được phép, thời hạn hoặc trạng thái của API key người dùng hiện có.

## Ghi Chú

- API quản lý v1 không hỗ trợ hard delete.

## Yêu Cầu / Phản Hồi

Sử dụng bảng điều khiển OpenAPI tương tác ở trên để xem schema chính xác.
