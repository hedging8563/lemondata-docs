Responses API là API hội thoại có trạng thái mới hơn của OpenAI. LemonData hỗ trợ định dạng này cho các model tương thích.

## Nội dung Request

<ParamField body="model" type="string" required>
  ID của model sẽ được sử dụng. Xem [Models](https://lemondata.cc/vi/models) để biết các tùy chọn khả dụng.
</ParamField>

<ParamField body="input" type="array" required>
  Danh sách các mục input cấu thành cuộc hội thoại.

  Mỗi mục có thể là:
  - `message`: Một tin nhắn hội thoại có role và content
  - `function_call`: Một yêu cầu gọi hàm
  - `function_call_output`: Output từ một lần gọi hàm
</ParamField>

<ParamField body="instructions" type="string">
  Chỉ dẫn hệ thống cho model (tương đương với system message).
</ParamField>

<ParamField body="max_output_tokens" type="integer">
  Số lượng token tối đa được tạo ra.
</ParamField>

<ParamField body="temperature" type="number" default="1">
  Nhiệt độ lấy mẫu trong khoảng từ 0 đến 2.
</ParamField>

<ParamField body="tools" type="array">
  Danh sách các công cụ mà model có thể gọi.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  Nếu là true, trả về một luồng sự kiện.
</ParamField>

<ParamField body="previous_response_id" type="string">
  ID của một response trước đó để tiếp tục cuộc hội thoại từ đó.
</ParamField>

<ParamField body="store" type="boolean" default="true">
  Có lưu response để truy xuất sau này hay không.
</ParamField>

<ParamField body="metadata" type="object">
  Metadata được đính kèm vào response cho mục đích theo dõi.
</ParamField>

<ParamField body="text" type="object">
  Các tùy chọn cấu hình tạo văn bản.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  Có cho phép nhiều lần gọi công cụ song song hay không.
</ParamField>

<ParamField body="top_p" type="number">
  Tham số nucleus sampling (0-1).
</ParamField>

<ParamField body="reasoning" type="object">
  Cấu hình reasoning cho các model hỗ trợ reasoning như các biến thể thuộc họ GPT-5.

  - `effort` (string): Mức độ nỗ lực reasoning (`low`, `medium`, `high`)
</ParamField>

## Response

<ResponseField name="id" type="string">
  Định danh duy nhất cho response.
</ResponseField>

<ResponseField name="object" type="string">
  Luôn là `response`.
</ResponseField>

<ResponseField name="created" type="integer">
  Dấu thời gian Unix của thời điểm response được tạo.
</ResponseField>

<ResponseField name="output" type="array">
  Danh sách các mục output do model tạo ra.
</ResponseField>

<ResponseField name="usage" type="object">
  Thống kê sử dụng token.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/responses" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "input": [
      {"type": "message", "role": "user", "content": "Hello!"}
    ],
    "max_output_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-4o",
    input=[
        {"type": "message", "role": "user", "content": "Hello!"}
    ],
    max_output_tokens=1000
)

print(response.output)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model": "gpt-4o",
        "input": []map[string]interface{}{
            {"type": "message", "role": "user", "content": "Hello!"},
        },
        "max_output_tokens": 1000,
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/responses", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Println(result["output"])
}
```

```php PHP
<?php
$ch = curl_init('https://api.lemondata.cc/v1/responses');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-4o',
        'input' => [
            ['type' => 'message', 'role' => 'user', 'content' => 'Hello!']
        ],
        'max_output_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
print_r($data['output']);
```
## Vision Input Example

Use image-capable models by placing images inside `message.content` as `input_image` blocks. The `image_url` value can be either a public URL or a Base64 data URL.

```json
{
  "model": "gpt-5.4",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "Please describe this image."
        },
        {
          "type": "input_image",
          "image_url": "https://example.com/demo.jpg"
        }
      ]
    }
  ]
}
```

```json
{
  "model": "gpt-5.4",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "Please describe this image."
        },
        {
          "type": "input_image",
          "image_url": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQ..."
        }
      ]
    }
  ]
}
```
