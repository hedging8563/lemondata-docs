---
title: "Cập nhật Material Asset"
openapi: "PUT /v1/videos/assets/{assetId}"
description: "Cập nhật một material asset của Seedance thuộc sở hữu của tổ chức hiện tại."
---

Cập nhật tên hoặc metadata của material. URL nguồn và loại asset là cố định sau khi tạo; hãy tạo một asset mới khi tệp nguồn thay đổi.

## Ví dụ yêu cầu

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"}}'
```

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",

  "asset_name": "Front view approved",
  "asset_type": "Image",
  "asset_url": "https://example.com/reference.png",
  "cover_url": null,
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
