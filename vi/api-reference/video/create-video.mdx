## Tổng quan

Việc sinh video là bất đồng bộ. Bạn gửi một request, nhận được task ID và `poll_url`, sau đó polling để lấy kết quả.

<Info>
Để có hành vi polling đáng tin cậy nhất, hãy làm theo chính xác `poll_url` được trả về từ request tạo.
</Info>

<Warning>
Audio output is model-dependent. In LemonData, Veo 3 family requests default to audio-on when `output_audio` is omitted. When a model supports audio control, use `output_audio` to explicitly toggle it. The camelCase alias `outputAudio` is also accepted for compatibility.
</Warning>


## Request Body

<ParamField body="model" type="string" default="sora-2">
  ID model video. Mặc định của API là `sora-2`. Xem [Hướng dẫn Sinh Video](/guides/video-generation) để biết ma trận model hiện tại và các khả năng được hỗ trợ.
</ParamField>

<ParamField body="prompt" type="string" required>
  Mô tả văn bản của video cần tạo.
</ParamField>

<ParamField body="image_url" type="string">
  URL có thể truy cập công khai của ảnh khởi đầu cho việc sinh image-to-video (I2V). Để có khả năng tương thích tốt nhất giữa các model, nên ưu tiên `image_url`.
</ParamField>

<ParamField body="image" type="string">
  Ảnh inline dưới dạng data URL (ví dụ: `data:image/jpeg;base64,...`). Được hỗ trợ bởi các model tương thích, nhưng `image_url` mang lại khả năng tương thích rộng nhất trên các model video.
</ParamField>

<ParamField body="duration" type="integer">
  Thời lượng video tính bằng giây (phụ thuộc vào model).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Tỷ lệ khung hình (ví dụ: `16:9`, `9:16`, `1:1`).
</ParamField>

<ParamField body="resolution" type="string">
  Độ phân giải video (ví dụ: `1080p`, `720p`).
</ParamField>

<ParamField body="output_audio" type="boolean">
  Model-dependent audio output toggle. In LemonData, Veo 3 family requests default to `true` when this field is omitted. Other video models follow their governed default behavior. The camelCase alias `outputAudio` is accepted for compatibility.
</ParamField>

<ParamField body="fps" type="integer">
  Số khung hình trên giây (1-120).
</ParamField>

<ParamField body="negative_prompt" type="string">
  Những gì cần tránh trong quá trình sinh video.
</ParamField>

<ParamField body="seed" type="integer">
  Seed ngẫu nhiên để tái tạo kết quả sinh.
</ParamField>

<ParamField body="cfg_scale" type="number">
  Thang hướng dẫn classifier-free (0-20).
</ParamField>

<ParamField body="motion_strength" type="number">
  Cường độ chuyển động (0-1).
</ParamField>

<ParamField body="start_image" type="string">
  URL của ảnh khung hình bắt đầu.
</ParamField>

<ParamField body="end_image" type="string">
  URL của ảnh khung hình kết thúc.
</ParamField>

<ParamField body="user" type="string">
  Một định danh duy nhất cho người dùng cuối.
</ParamField>

## Response

<ResponseField name="task_id" type="string">
  Định danh tác vụ duy nhất để polling.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling được khuyến nghị cho tác vụ này. Sử dụng chính xác đường dẫn này khi kiểm tra trạng thái.
</ResponseField>

<ResponseField name="status" type="string">
  Trạng thái ban đầu: `pending`.
</ResponseField>

<ResponseField name="model" type="string">
  Model được sử dụng.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={
        "Authorization": "Bearer sk-your-api-key",
        "Content-Type": "application/json"
    },
    json={
        "model": "sora-2",
        "prompt": "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)

data = response.json()
task_id = data["task_id"]
print(f"Poll URL: {data['poll_url']}")
print(f"Task ID: {task_id}")
```

```go Go
package main

import (
    "bytes"

    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":    "sora-2",
        "prompt":   "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/videos/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Poll URL: %s\n", result["poll_url"])
    fmt.Printf("Task ID: %s\n", result["task_id"])
}
```

## Điều khiển Keyframe

Sử dụng `start_image` và `end_image` để điều khiển khung hình đầu tiên và cuối cùng (được hỗ trợ bởi Vidu Q2 Pro):

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/day.jpg",
        "end_image": "https://example.com/night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```
