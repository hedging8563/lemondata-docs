Liên kết kết quả xác thực thành công và tạo ánh xạ nhóm tư liệu người thật TokenLab. Sử dụng `session_id` và `verification_token` từ chuyển hướng callback của TokenLab.

TokenLab xác minh rằng phiên làm việc thuộc cùng một tổ chức, chưa hết hạn và được liên kết với cùng một dịch vụ tư liệu được sử dụng bởi phiên xác thực đó. Phản hồi chỉ trả về `group_id` của TokenLab; hãy sử dụng ID này khi tạo các tư liệu `liveness_face`.

## Ví dụ yêu cầu

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## Ví dụ phản hồi

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "seedance_group_real_123",
  "material_group": {
    "id": "seedance_group_real_123",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
