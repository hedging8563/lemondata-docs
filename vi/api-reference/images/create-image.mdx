<Note>
Dành cho coding agents, hãy khám phá shortlist hình ảnh được khuyến nghị hiện tại trước bằng `GET /v1/models?recommended_for=image`, rồi gửi rõ `model` đã chọn đến endpoint này.
</Note>

<Note>
`gpt-image-2` là model GPT Image tính phí theo token. LemonData bám theo chi tiết `usage` chính thức của OpenAI để tính token đầu vào văn bản, đầu vào hình ảnh, đầu vào cache khi được báo cáo, và token đầu ra hình ảnh; model này không được tính như giá cố định cho mỗi ảnh.
</Note>

<Note>
Các model nhóm hình ảnh của Google Gemini không dùng cùng một hợp đồng selector:

- `gemini-3-pro-image-preview` và `nano-banana-pro` hỗ trợ `aspect_ratio` cùng `resolution` (`1k`, `2k`, `4k`).
- `gemini-2.5-flash-image`, `gemini-3.1-flash-image-preview`, `nano-banana`, và `nano-banana-edit` hỗ trợ `aspect_ratio` nhưng không công khai `resolution`.
- `gemini-2.0-flash-preview-image-generation` được tài liệu hoá ở đây như một mô hình text-to-image chỉ dùng prompt.

Với các model hình ảnh của Google, hãy ưu tiên `aspect_ratio` và chỉ gửi `resolution` khi model đó hỗ trợ rõ ràng.
</Note>

## Thân Yêu Cầu

<ParamField body="model" type="string" default="dall-e-3">
  Model cần dùng (ví dụ: `gpt-image-2`, `dall-e-3`, `flux-pro`, `midjourney`).
</ParamField>

<ParamField body="prompt" type="string" required>
  Mô tả bằng văn bản cho hình ảnh mong muốn.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Số lượng hình ảnh cần tạo (1-10, tùy theo model).
</ParamField>

<ParamField body="size" type="string" default="1024x1024">
  Kích thước ảnh. Dùng cho các dòng ảnh kiểu OpenAI và các model khác chấp nhận kích thước pixel chính xác.

  Với `gpt-image-2`, `size` chấp nhận `auto` hoặc `WIDTHxHEIGHT`. Kích thước tùy chỉnh phải có cả hai cạnh là bội số của 16, cạnh dài nhất không quá `3840px`, tỷ lệ cạnh dài/cạnh ngắn không quá `3:1`, và tổng số pixel nằm trong khoảng `655,360` đến `8,294,400`. `aspect_ratio` và `resolution` hiện không thuộc hợp đồng công khai của LemonData cho `gpt-image-2`.

  Với các dòng ảnh Google Gemini, `size` được xem là alias tương thích ánh xạ sang hợp đồng công khai `aspect_ratio` của model và, khi được hỗ trợ, `resolution`. Với các model này, nên gửi trực tiếp `aspect_ratio`.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Bộ chọn tỷ lệ khung hình theo từng model.

  Các giá trị phổ biến của nhóm model hình ảnh Google gồm `1:1`, `16:9`, `9:16`, `3:2`, và `2:3`.
</ParamField>

<ParamField body="resolution" type="string">
  Bộ chọn độ phân giải đầu ra theo từng model.

  Được hỗ trợ trên `gemini-3-pro-image-preview`, `nano-banana-pro`, `nano-banana-2`, và các nhóm độ phân giải cao tương tự. Giá trị thường dùng là `1k`, `2k`, và `4k`. Không gửi tham số này cho các model Gemini Flash hình ảnh trừ khi tài liệu của model đó nói rõ.
</ParamField>

<ParamField body="quality" type="string" default="standard">
  Chất lượng ảnh. Model DALL-E dùng `standard` hoặc `hd`; các model GPT Image như `gpt-image-2` dùng `auto`, `low`, `medium` hoặc `high`.
</ParamField>

<ParamField body="response_format" type="string" default="url">
  Định dạng response: `url` hoặc `b64_json`.
</ParamField>

<ParamField body="style" type="string" default="vivid">
  Phong cách cho DALL-E 3: `vivid` hoặc `natural`.
</ParamField>

<ParamField body="user" type="string">
  Một định danh duy nhất cho end-user.
</ParamField>

## Phản Hồi

### Phản Hồi Đồng Bộ

<ResponseField name="created" type="integer">
  Unix timestamp của thời điểm tạo.
</ResponseField>

<ResponseField name="data" type="array">
  Mảng các hình ảnh được tạo.

  Mỗi object chứa:
  - `url` (string): URL của hình ảnh được tạo
  - `b64_json` (string): Hình ảnh mã hoá Base64 (nếu được yêu cầu)
  - `revised_prompt` (string): Prompt đã được dùng (DALL-E 3)
</ResponseField>

### Phản Hồi Tác Vụ Bất Đồng Bộ

Một số model hình ảnh trả về ngay một task bất đồng bộ, và một số có thể hoạt động theo kiểu inline hoặc task tùy theo đường route provider. Khi response có `status: "pending"`, hãy coi đó là phản hồi tác vụ bất đồng bộ:

<Info>
Hãy dùng chính xác `poll_url` được trả về khi có. Xem `task_id` như định danh tác vụ bất đồng bộ để polling tiếp theo.
</Info>

<ResponseField name="created" type="integer">
  Unix timestamp của thời điểm tạo.
</ResponseField>

<ResponseField name="task_id" type="string">
  Định danh tác vụ duy nhất để polling.
</ResponseField>

<ResponseField name="status" type="string">
  Trạng thái ban đầu: `pending`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL tương đối để polling kết quả (ví dụ: `/v1/tasks/{id}`).
</ResponseField>

<ResponseField name="data" type="array">
  Mảng có dữ liệu tạm. `url` sẽ rỗng cho đến khi hoàn tất.
</ResponseField>

<Note>
Khi nhận được `status: "pending"`, hãy dùng endpoint [Lấy Trạng Thái Hình Ảnh](/vi/api-reference/images/get-image-status) để polling kết quả.
</Note>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/images/generations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3-pro-image-preview",
    "prompt": "A cinematic portrait of a white cat sitting on a rainy windowsill",
    "aspect_ratio": "16:9",
    "resolution": "2k",
    "n": 1
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.images.generate(
    model="gemini-3-pro-image-preview",
    prompt="A cinematic portrait of a white cat sitting on a rainy windowsill",
    aspect_ratio="16:9",
    resolution="2k",
    n=1
)

print(response.data[0].url)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.images.generate({
  model: 'gemini-3-pro-image-preview',
  prompt: 'A cinematic portrait of a white cat sitting on a rainy windowsill',
  aspect_ratio: '16:9',
  resolution: '2k',
  n: 1
});

console.log(response.data[0].url);
```

```php PHP
<?php
$ch = curl_init('https://api.lemondata.cc/v1/images/generations');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gemini-3-pro-image-preview',
        'prompt' => 'A cinematic portrait of a white cat sitting on a rainy windowsill',
        'aspect_ratio' => '16:9',
        'resolution' => '2k',
        'n' => 1
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['data'][0]['url'];
```

## Model Khả Dụng

| Model | Loại | Tính năng |
|-------|------|----------|
| `dall-e-3` | Thường là inline | Chất lượng tốt nhất, cải thiện prompt |
| `dall-e-2` | Thường là inline | Nhanh hơn, chi phí thấp hơn |
| `flux-pro` | Thường là task | Photorealistic, chất lượng cao |
| `flux-schnell` | Thường là inline | Rất nhanh |
| `midjourney` | Thường là task | Phong cách nghệ thuật |
| `ideogram-v3` | Thường là task | Xử lý chữ tốt nhất |
| `stable-diffusion-3` | Thường là inline | Mã nguồn mở, tuỳ biến cao |

<Tip>
Đừng hard-code một model là luôn đồng bộ hay luôn bất đồng bộ. Nếu response tạo ra trả về `status: "pending"`, hãy theo `poll_url` và polling đến khi hoàn tất.
</Tip>
