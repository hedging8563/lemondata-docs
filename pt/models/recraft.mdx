## Visão Geral

LemonData fornece acesso aos modelos Luma AI. Total: **2 modelos** disponíveis.

## Modelos de Chat

| ID do Modelo | Preços |
|----------|--------|
| `luma-video-api` | Ver dashboard |
| `luma-video-extend-api` | Ver dashboard |


## Uso

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="luma-video-api",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Os preços exibidos são preços da plataforma (~70% das taxas oficiais).
