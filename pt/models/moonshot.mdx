## Uso

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="SparkDesk-v2.1",
    messages=[{"role": "user", "content": "Hello!"}]
)
```
