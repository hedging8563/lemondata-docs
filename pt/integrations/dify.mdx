## Visão geral

O Dify funciona bem com o LemonData por meio do fluxo de provider de modelo compatível com OpenAI.

Nas versões atuais do Dify, o caminho mais seguro geralmente é:
- escolher o provider **OpenAI** integrado
- definir sua chave de API do LemonData
- definir uma base URL personalizada de `https://api.lemondata.cc/v1`

<Note>
Algumas versões mais antigas do Dify expõem isso como `OpenAI-API-compatible` em vez do provider `OpenAI` integrado com um campo de base URL personalizada. Se a interface do seu Dify parecer diferente, use o fluxo de provider personalizado compatível com OpenAI mais próximo disponível nessa versão.
</Note>

## Pré-requisitos

- Conta LemonData com acesso à API
- Dify Cloud ou Dify self-hosted

## Etapas de configuração

### Etapa 1: Obtenha sua chave de API

1. Faça login no [LemonData Dashboard](https://lemondata.cc/dashboard)
2. Abra [API Keys](https://lemondata.cc/dashboard/api)
3. Crie ou copie uma chave de API que comece com `sk-`

### Etapa 2: Configure o provider

<Steps>
  <Step title="Abra Model Providers">
    No Dify, vá para **Settings** → **Model Providers**
  </Step>
  <Step title="Selecione OpenAI">
    Abra as configurações do provider **OpenAI**. Se a sua versão do Dify não oferecer uma base URL personalizada aqui, use a opção de provider personalizado compatível com OpenAI exposta por essa versão.
  </Step>
  <Step title="Insira as configurações do LemonData">
    Use estes valores:

    | Field | Value |
    |-------|-------|
    | API Key | `sk-your-lemondata-key` |
    | API Base URL / Custom Base URL | `https://api.lemondata.cc/v1` |
  </Step>
  <Step title="Adicione modelos">
    Adicione os modelos que deseja usar, por exemplo:
    - `gpt-5.4`
    - `gpt-5-mini`
    - `gpt-4o`
    - `claude-sonnet-4-6`
    - `claude-opus-4-6`
    - `gemini-2.5-flash`
    - `gemini-2.5-pro`
    - `deepseek-r1`
  </Step>
</Steps>

### Etapa 3: Teste a conexão

1. Escolha um modelo como `gpt-5-mini` ou `gpt-4o`
2. Envie um prompt de teste
3. Confirme que o Dify recebe uma resposta válida

## Embeddings para bases de conhecimento

Para RAG e indexação de bases de conhecimento, adicione um modelo de embedding, como:
- `text-embedding-3-small`
- `text-embedding-3-large`

Em seguida, defina-o como o modelo de embedding padrão nas configurações da base de conhecimento ou da aplicação relevante.

## Funções de modelo recomendadas

| Use Case | Suggested Models |
|----------|------------------|
| Chat padrão | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| Raciocínio profundo | `gpt-5.4`, `claude-opus-4-6`, `deepseek-r1` |
| Rápido/barato | `gpt-5-mini`, `gemini-2.5-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## Boas práticas

<AccordionGroup>
  <Accordion title="Comece com o provider OpenAI integrado">
    Nas versões mais novas do Dify, o provider OpenAI integrado com uma base URL personalizada geralmente é a configuração mais limpa para o LemonData.
  </Accordion>

  <Accordion title="Use modelos mais baratos para iteração">
    Use `gpt-5-mini` ou `gemini-2.5-flash` durante a iteração e, em seguida, altere fluxos de trabalho mais pesados para modelos mais fortes apenas onde for necessário.
  </Accordion>

  <Accordion title="Lembre-se de que o Dify geralmente é orientado a chat-completions">
    A maioria dos fluxos do Dify usa comportamento de chat compatível com OpenAI. Se você precisar de Responses específicas do Codex ou de comportamento via WebSocket, use as integrações dedicadas do Codex em vez do Dify.
  </Accordion>
</AccordionGroup>

## Solução de problemas

<AccordionGroup>
  <Accordion title="Erro de conexão">
    - Verifique se a base URL é exatamente `https://api.lemondata.cc/v1`
    - Remova barras finais se o Dify as duplicar
    - Confirme que o servidor do Dify consegue acessar o LemonData pela internet pública
  </Accordion>

  <Accordion title="401 Unauthorized">
    - Verifique novamente a chave de API
    - Confirme que a chave está ativa no dashboard do LemonData
    - Certifique-se de que o valor colado no Dify não contém espaços extras nem quebras de linha
  </Accordion>

  <Accordion title="Modelo não encontrado">
    - Verifique o nome do modelo exatamente
    - Adicione novamente a entrada do modelo se a interface do provider tiver armazenado em cache um valor antigo
    - Verifique a disponibilidade atual de modelos na documentação ou no dashboard do LemonData
  </Accordion>
</AccordionGroup>
