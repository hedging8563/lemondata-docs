## Visão Geral

O Pydantic AI pode usar o TokenLab com `OpenAIChatModel` e `OpenAIProvider(base_url=...)`.

<Note>
**Tipo**: Framework de Agente

**Caminho Principal**: Completions de chat compatíveis com OpenAI

**Nível de Suporte**: Caminho de provedor compatível com OpenAI suportado
</Note>

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Agente Básico

```python
import os

from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "claude-sonnet-5",
    provider=OpenAIProvider(
        base_url="https://api.tokenlab.sh/v1",
        api_key=os.environ["TOKENLAB_API_KEY"],
    ),
)

agent = Agent(model)
result = agent.run_sync("Explain one benefit of OpenAI-compatible gateways.")
print(result.output)
```

## Ferramentas

```python
from pydantic_ai import Agent, RunContext

agent = Agent(model)

@agent.tool
def lookup_status(ctx: RunContext[None], service: str) -> str:
    return f"{service} is online"

result = agent.run_sync("Check the TokenLab status.")
print(result.output)
```

## Notas sobre o Endpoint

Este caminho tem como alvo a classe de modelo de OpenAI Chat Completions do Pydantic AI. Para comportamento de protocolo nativo de respostas ou nativo do provedor, escolha um caminho de cliente que exponha esse protocolo diretamente.
