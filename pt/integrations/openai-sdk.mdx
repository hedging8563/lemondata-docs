## Visão geral

O LemonData funciona com os SDKs oficiais da OpenAI ao apontar o cliente para `https://api.lemondata.cc/v1`.

Para novos projetos, prefira a **Responses API**. Mantenha **Chat Completions** apenas quando um framework, plugin ou caminho de código legado ainda exigir isso.

<Note>
Python, JavaScript e Go têm SDKs oficiais da OpenAI. PHP funciona bem com clientes comunitários compatíveis com OpenAI, mas não é um SDK oficial da OpenAI.
</Note>

<Note>
**Tipo**: SDK nativo

**Caminho principal**: OpenAI-compatible / OpenAI Responses

**Nível de suporte**: Caminho central compatível
</Note>

Este é o caminho SDK OpenAI-compatible padrão no LemonData, mas isso não significa que cada campo Responses-native-only funcione de forma idêntica em todos os modelos e canais roteados.

## Configurar o cliente

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## Recomendado: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

<Note>
Alguns hosted tools, além de `include`, `service_tier` e `truncation_strategy`, dependem do suporte a passthrough nativo `/v1/responses` do modelo escolhido e do canal roteado. Se esse suporte não existir, o LemonData retorna um `400` ou `503` explícito em vez de fingir que o campo funcionou.
</Note>

## Streaming com Responses

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Ferramentas / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## Compatibilidade com Chat Completions

Se o seu framework ou plugin ainda espera Chat Completions, o LemonData também oferece suporte ao caminho padrão compatível com OpenAI:

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
Use Chat Completions apenas para compatibilidade. Para novas integrações, prefira `client.responses.create(...)`.
</Warning>

## Solução de problemas

<AccordionGroup>
  <Accordion title="Erro de conexão">
    - Verifique se a base URL é exatamente `https://api.lemondata.cc/v1`
    - Verifique interferência de proxy ou substituições personalizadas do cliente HTTP
    - Certifique-se de que a versão do seu SDK esteja atualizada antes de depurar o comportamento do provider
  </Accordion>

  <Accordion title="Falha na autenticação">
    - Verifique se sua API key começa com `sk-`
    - Verifique se a chave está ativa no dashboard do LemonData
    - Confirme se o SDK está enviando `Authorization: Bearer ...`
  </Accordion>

  <Accordion title="Caminho de API incorreto">
    - `responses.create(...)` envia requisições para `/v1/responses`
    - `chat.completions.create(...)` envia requisições para `/v1/chat/completions`
    - Se o seu app atualmente só oferece suporte a Chat Completions, mantenha-o nesse caminho de compatibilidade
  </Accordion>
</AccordionGroup>
