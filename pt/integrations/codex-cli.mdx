## Visão geral

OpenAI Codex é uma ferramenta de linha de comando (CLI) open-source que funciona como um agente de programação leve, capaz de ler, modificar e executar código no terminal. Ela é construída sobre modelos GPT e otimizada para geração de código.

## Requisitos do sistema

- **OS**: macOS, Linux (suporte oficial), Windows via WSL
- **Node.js**: Versão 18+
- **npm**: Versão 10.x.x ou superior

## Instalação

```bash
npm install -g @openai/codex
```

Verifique a instalação:

```bash
codex --version
```

## Configuração

### Etapa 1: Definir API Key

**Temporário (sessão atual):**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**Configuração permanente:**

Adicione em `~/.bashrc`, `~/.zshrc` ou `~/.bash_profile`:

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

Em seguida, recarregue:

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### Etapa 2: Configurar config.toml

Edite `~/.codex/config.toml`:

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
Se o arquivo de configuração não existir, execute `codex` uma vez para gerá-lo e depois edite o arquivo. Reinicie o Codex completamente após alterar `config.toml` para que as novas configurações do provider sejam recarregadas.
</Note>

<Warning>
O Codex está descontinuando o suporte a `chat/completions` para providers personalizados. Mantenha `wire_api = "responses"` para LemonData, a menos que você esteja usando intencionalmente um caminho de compatibilidade mais antigo.
</Warning>

## Uso básico

**Iniciar modo interativo:**

```bash
codex
```

**Comando direto:**

```bash
codex "Fix the bug in main.py line 42"
```

**Especificar modelo:**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## Modelos recomendados

| Model | Melhor para |
|-------|-------------|
| `gpt-5.4` | Melhor escolha padrão para programação e raciocínio |
| `gpt-5-mini` | Alternativa mais rápida e barata para workflows de programação |
| `claude-sonnet-4-6` | Revisão de código, documentação |
| `deepseek-r1` | Design de algoritmos, raciocínio |

## Comandos interativos

| Command | Descrição |
|---------|-----------|
| `/help` | Exibir ajuda |
| `/exit` or `Ctrl+C` | Sair |
| `/clear` | Limpar conversa |
| `/config` | Visualizar configuração |
| `/model <name>` | Trocar modelo |
| `/tokens` | Visualizar uso de token |

## Verificar configuração

```bash
# Check environment variable
echo $OPENAI_API_KEY

# Test API connection
codex "Hello, Codex!"

# View configuration
cat ~/.codex/config.toml
```

## Solução de problemas

<AccordionGroup>
  <Accordion title="Erro de conexão">
    - Verifique se `base_url` em config.toml é exatamente `https://api.lemondata.cc/v1`
    - Verifique a conectividade de rede
    - Garanta que não haja interferência de proxy
  </Accordion>

  <Accordion title="Falha na autenticação">
    - Verifique se `env_key = "OPENAI_API_KEY"` está presente em `~/.codex/config.toml`
    - Verifique se a variável de ambiente `OPENAI_API_KEY` está definida
    - Verifique se a chave começa com `sk-`
    - Garanta que a chave esteja ativa no dashboard da LemonData
  </Accordion>

  <Accordion title="Modelo não encontrado">
    - Verifique se o nome do modelo corresponde exatamente
    - Verifique a disponibilidade do modelo em [lemondata.cc/en/models](https://lemondata.cc/pt/models)
  </Accordion>
</AccordionGroup>
