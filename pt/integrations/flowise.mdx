## Visão Geral

O Flowise pode chamar o TokenLab através de um nó de chat do TokenLab quando disponível, ou através de um nó de modelo de chat compatível com OpenAI apontado para o TokenLab.

<Note>
**Tipo**: Construtor de Fluxo de Trabalho

**Caminho Principal**: Completions de chat compatíveis com OpenAI

**Nível de Suporte**: Suportado com limites de escopo
</Note>

## Nó do TokenLab

Se a sua build do Flowise incluir um nó de modelo de chat **TokenLab**:

1. Adicione **Chat Models** -> **TokenLab**
2. Crie uma credencial de API do TokenLab
3. Defina o **Model Name** como `gpt-5.4-mini`
4. Conecte-o à sua chain, agente ou fluxo de trabalho
5. Execute um prompt de teste.

## Fallback Compatível com OpenAI

Se o nó do TokenLab ainda não estiver disponível, use um nó de modelo de chat compatível com OpenAI com:

| Campo | Valor |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Modelos Recomendados

- `gpt-5.4-mini` para a maioria dos testes de fluxo de trabalho
- `claude-sonnet-5` para escrita e raciocínio mais robustos
- `gemini-3.5-flash` para fluxos de trabalho rápidos e compatíveis com multimodal
- `deepseek-v4-flash` para iterações rápidas de código ou raciocínio
