## Visão Geral

O Opik pode registrar chamadas do TokenLab envolvendo um cliente OpenAI que aponta para o endpoint compatível com OpenAI do TokenLab.

<Note>
**Tipo**: Observabilidade

**Caminho Principal**: Wrapper de rastreamento do SDK OpenAI

**Nível de Suporte**: Caminho de rastreamento compatível com OpenAI suportado
</Note>

## Instalação

```bash
pip install opik openai
```

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export OPIK_PROJECT_NAME="tokenlab-integration-demo"
```

## Envolvendo o Cliente OpenAI

```python
import os

from openai import OpenAI
from opik.integrations.openai import track_openai

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

openai_client = track_openai(client)
```

## Registrando uma Chat Completion

```python
completion = openai_client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[
        {"role": "user", "content": "Summarize why LLM observability matters."}
    ],
)

print(completion.choices[0].message.content)
```

## Notas sobre o Endpoint

Esta configuração rastreia o caminho do SDK compatível com OpenAI. Se você utilizar endpoints nativos do TokenLab fora do SDK OpenAI, instrumente esse cliente ou fluxo de trabalho separadamente.
