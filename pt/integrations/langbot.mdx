## Visão Geral

O LangBot pode chamar o TokenLab através de um solicitante de LLM compatível com OpenAI.

<Note>
**Tipo**: Plataforma de Bot

**Caminho Principal**: Chat completions compatíveis com OpenAI

**Nível de Suporte**: Suportado com limites de escopo
</Note>

## Solicitante TokenLab

Se a sua compilação do LangBot incluir um solicitante **TokenLab**:

1. Abra as configurações de provedor de modelo do LangBot.
2. Adicione um provedor com o solicitante **TokenLab**.
3. Defina a API key com a sua chave do TokenLab.
4. Selecione ou crie um modelo, como `gpt-5.4-mini`.
5. Anexe o modelo ao pipeline ou bot que deve utilizá-lo.

## Fallback Compatível com OpenAI

Se o TokenLab ainda não estiver listado, use o solicitante compatível com OpenAI:

| Campo | Valor |
|-------|-------|
| Requester | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Modelos Recomendados

- `gpt-5.4-mini` para a maioria das interações de bot
- `claude-sonnet-5` para escrita e raciocínio mais longos
- `deepseek-v4-flash` para codificação rápida e loops de raciocínio
- `gemini-3.5-flash` para fluxos de trabalho gerais rápidos
