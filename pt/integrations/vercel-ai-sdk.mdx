## Visão geral

Para o LemonData, o padrão mais estável no Vercel AI SDK é o **provider compatível com OpenAI**.

Se você precisar especificamente de um comportamento **nativo de Responses**, pode mudar para o provider OpenAI e manter a mesma base URL do LemonData.

## Padrão recomendado: Provider compatível com OpenAI

```bash
npm install ai @ai-sdk/openai-compatible
```

```typescript
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

export const lemondata = createOpenAICompatible({
  name: 'lemondata',
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

## Gerar texto

```typescript
import { generateText } from 'ai';
import { lemondata } from './lemondata';

const { text } = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});

console.log(text);
```

## Transmitir texto em stream

```typescript
import { streamText } from 'ai';
import { lemondata } from './lemondata';

const result = await streamText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Write a short poem about coding.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## Chamada de ferramentas

```typescript
import { generateText, tool } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const result = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'What is the weather in San Francisco?',
  tools: {
    weather: tool({
      description: 'Get weather in a location',
      parameters: z.object({
        location: z.string(),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72,
        condition: 'sunny',
      }),
    }),
  },
});

console.log(result.text);
```

## Saída estruturada

```typescript
import { generateObject } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const { object } = await generateObject({
  model: lemondata.chatModel('gpt-5.4'),
  schema: z.object({
    name: z.string(),
    role: z.string(),
  }),
  prompt: 'Generate a fake developer profile.',
});

console.log(object);
```

## Se você precisar explicitamente de comportamento nativo de Responses

```bash
npm install ai @ai-sdk/openai
```

```typescript
import { createOpenAI } from '@ai-sdk/openai';

export const lemondataResponses = createOpenAI({
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```typescript
import { generateText } from 'ai';
import { lemondataResponses } from './lemondata-responses';

const { text } = await generateText({
  model: lemondataResponses('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});
```

<Note>
Use `@ai-sdk/openai-compatible` como padrão seguro para integrações no estilo proxy. Mude para `@ai-sdk/openai` somente quando você quiser explicitamente um caminho de provider construído sobre `/v1/responses`.
</Note>

## Variáveis de ambiente

```bash
# .env.local
LEMONDATA_API_KEY=sk-your-lemondata-key
```

## Boas práticas

<AccordionGroup>
  <Accordion title="Prefira openai-compatible primeiro">
    Para gateways de terceiros e backends proxy, `@ai-sdk/openai-compatible` geralmente é o ponto de partida mais previsível.
  </Accordion>

  <Accordion title="Mude para Responses somente quando necessário">
    Se você precisar de comportamento de provider vinculado a `/v1/responses`, mude deliberadamente o pacote do provider em vez de misturar os dois padrões em um único client.
  </Accordion>

  <Accordion title="Mantenha segredos no servidor">
    Nunca exponha sua chave de API do LemonData em código client-side. Coloque a configuração do provider em arquivos de servidor ou rotas de API.
  </Accordion>
</AccordionGroup>
