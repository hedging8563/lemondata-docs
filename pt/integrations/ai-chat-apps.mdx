## Visão geral

A maioria dos apps gerais de chat com AI se conecta à LemonData por meio do caminho de chat padrão compatível com OpenAI.

Na prática, isso significa:
- usar `https://api.lemondata.cc/v1` como URL base, a menos que o app solicite explicitamente uma URL de endpoint completa
- usar sua chave de API da LemonData como a chave de API no estilo OpenAI
- escolher modelos que o app possa usar em um fluxo de chat padrão

<Note>
Apps gerais de chat geralmente são **orientados a chat-completions**, não clientes WebSocket do Codex Responses. Para Codex CLI/App, Cursor ou outras ferramentas de programação que precisam de comportamento específico de Responses, use os guias de integração dedicados.
</Note>

## Aplicações compatíveis

| Application | Platform | Notes |
|-------------|----------|-------|
| LobeChat | Web, Desktop, Self-hosted | Forte suporte a provedores personalizados |
| Cherry Studio | Windows, macOS, Linux | Bom fluxo de provedor compatível com OpenAI |
| Chatbox | Windows, macOS, Linux | Configuração simples compatível com OpenAI |
| TypingMind | Web, Desktop | Usa um estilo de endpoint personalizado |
| BotGem | iOS, macOS | Configuração de provedor personalizado |
| OpenCat | iOS, macOS | Fluxo de endpoint personalizado compatível com OpenAI |
| ChatWise | Windows, macOS | Padrão de provedor personalizado padrão |

## Valores padrão de conexão

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

Se um app solicitar uma **URL de endpoint completa** em vez de uma URL base, use:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## Exemplos de configuração de apps

<Tabs>
  <Tab title="LobeChat">
    **LobeChat self-hosted**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. Abra **Settings** → **AI Service Provider**
    2. Selecione **OpenAI**
    3. Insira sua chave de API da LemonData
    4. Defina o endpoint personalizado como `https://api.lemondata.cc/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. Abra **Settings** → **Model Provider**
    2. Adicione um provedor **compatível com OpenAI**
    3. Insira:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. Adicione os modelos que deseja usar
  </Tab>

  <Tab title="Chatbox">
    1. Abra **Settings** → **AI Model**
    2. Escolha **OpenAI API Compatible**
    3. Insira:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` or `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. Abra **Settings**
    2. Escolha **Custom Endpoint**
    3. Insira:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. Configure os modelos que deseja expor
  </Tab>
</Tabs>

## Dicas

<AccordionGroup>
  <Accordion title="Prefira a URL base quando o app oferecer suporte">
    A maioria dos apps é mais fácil de configurar e menos frágil quando você fornece `https://api.lemondata.cc/v1` como URL base em vez de uma URL de endpoint completa.
  </Accordion>

  <Accordion title="Use modelos menores primeiro">
    Comece com `gpt-5-mini` ou `gpt-4o` para chat cotidiano e depois mova tarefas de raciocínio mais pesadas para `gpt-5.4` ou `claude-opus-4-6`.
  </Accordion>

  <Accordion title="Mantenha as ferramentas de programação separadas">
    Apps gerais de chat e agentes de programação frequentemente precisam de comportamentos de endpoint diferentes. Mantenha as ferramentas no estilo Codex/Cursor em suas páginas de integração dedicadas.
  </Accordion>
</AccordionGroup>

## Solução de problemas

<AccordionGroup>
  <Accordion title="Erro de conexão">
    - Verifique se a URL base é exatamente `https://api.lemondata.cc/v1`
    - Remova barras finais se o app adicionar caminhos automaticamente
    - Se o app quiser uma URL de endpoint completa, use `https://api.lemondata.cc/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Unauthorized">
    - Verifique novamente sua chave de API
    - Confirme que a chave está ativa no dashboard da LemonData
    - Certifique-se de que não há espaços extras ou quebras de linha
  </Accordion>

  <Accordion title="Modelo não disponível">
    - Verifique exatamente o nome do modelo
    - Tente um padrão amplamente compatível como `gpt-5-mini`, `gpt-4o` ou `claude-sonnet-4-6`
    - Verifique a disponibilidade atual na documentação ou no dashboard da LemonData
  </Accordion>
</AccordionGroup>
