---
title: "Criar Ativo de Material"
openapi: "POST /v1/videos/assets"
description: "Faz o upload de um ativo de material Seedance para um grupo de materiais TokenLab."
---

Importe uma URL de origem publicamente acessível para um grupo de materiais Seedance. O TokenLab armazena o material para uso posterior; utilize o `id` do ativo de material retornado para a geração, e não a URL de origem.

Para `library_type: "aigc_avatar"`, o `group_id` é opcional; o TokenLab utiliza ou cria o grupo de avatar virtual padrão da organização. Para `library_type: "liveness_face"`, o `group_id` é obrigatório e deve ser o grupo TokenLab retornado por [Vincular Resultado de Verificação de Pessoa Real](/pt/api-reference/video/bind-real-person-verification-result).

| Tipo | Entrada suportada |
|------|-----------------|
| Imagem | `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; proporção `(0.4, 2.5)`; largura e altura `(300, 6000)` px; abaixo de 30 MB. |
| Vídeo | `mp4`, `mov`; `480p`, `720p` ou `1080p`; 2-15 segundos; proporção `[0.4, 2.5]`; largura e altura `[300, 6000]` px; total de pixels entre 409600 e 2068676; até 200 MB; 24-60 FPS. |
| Áudio | `aac`, `wav`, `mp3`; 2-15 segundos; até 15 MB. |

A criação é assíncrona. Consulte [Obter Material Asset](/pt/api-reference/video/get-material-asset) até que o `status` seja `ACTIVE`. Para grupos de pessoas reais, um grupo é mapeado para uma pessoa verificada; uploads com múltiplos rostos ou um rosto que não corresponda à pessoa verificada podem falhar.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"group-20260720123456-vrt01","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view"}'
```

```json
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "PROCESSING",

```
