---
title: "Atualizar Ativo de Material"
openapi: "PUT /v1/videos/assets/{assetId}"
description: "Atualiza um ativo de material Seedance pertencente à organização atual."
---

Atualize o nome ou os metadados do material. A URL de origem e o tipo de ativo são fixos após a criação; crie um novo ativo quando o arquivo de origem for alterado.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"}}'
```

## Exemplo de Resposta

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",
  "library_type": "aigc_avatar",
  "asset_name": "Front view approved",
  "asset_type": "Image",
  "asset_url": "https://example.com/reference.png",
  "cover_url": null,
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
