## Visão geral

Estes endpoints são para equipes que já usam o formato de tarefa Seedance no estilo Volc. A autenticação usa sua API key Bearer da TokenLab. O ID retornado começa com `cgt-`; consulte o status até que `status` seja `succeeded`, `failed`, `cancelled` ou `expired`.

Veja também [Modelos de vídeo Seedance 2.0](/pt/guides/seedance-2-video) e [Geração de vídeo](/pt/guides/video-generation).

## Formato da resposta

A resposta da tarefa usa `queued`, `running`, `succeeded`, `failed`, `cancelled` ou `expired`. Tarefas bem-sucedidas retornam `content.video_url`; quando disponíveis, também aparecem `content.last_frame_url`, parâmetros refletidos como `return_last_frame` e `watermark`, `usage` e `progress`. `error` é `null` quando não há falha.

## Exemplo

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
