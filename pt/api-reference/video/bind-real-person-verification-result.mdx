---
title: "Vincular Resultado de Verificação de Pessoa Real"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "Vincula um resultado de verificação de material de pessoa real bem-sucedido a um grupo de material do TokenLab."
---

Vincule o resultado da verificação bem-sucedida e crie o mapeamento do grupo de material de pessoa real do TokenLab. Use o `session_id` e o `verification_token` do redirecionamento de callback do TokenLab.

O TokenLab verifica se a sessão pertence à mesma organização, se não expirou e se está vinculada ao mesmo serviço de material usado pela sessão de verificação. A resposta retorna apenas um `group_id` do TokenLab; use-o ao criar ativos de material `liveness_face`.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## Exemplo de Resposta

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "seedance_group_real_123",
  "material_group": {
    "id": "seedance_group_real_123",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
