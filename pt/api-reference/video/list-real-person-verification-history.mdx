---
title: "Listar Histórico de Verificação de Pessoa Real"
openapi: "GET /v1/videos/assets/visual-validation-sessions"
description: "Lista as sessões de verificação de material de pessoa real para a organização atual."
---

Liste sessões de verificação anteriores para revisão, suporte ao cliente e reconciliação. Este histórico é de longa duração, mas não substitui a etapa de vinculação (bind) de curta duração: uma verificação bem-sucedida ainda deve ser vinculada imediatamente dentro da janela de 120 segundos.

A resposta inclui apenas IDs do TokenLab e não inclui dados de credenciais. Após o sucesso de uma vinculação, `group_id` é o ID do grupo de material do TokenLab usado para uploads de `liveness_face`.

## Exemplo de Requisição

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions?page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
