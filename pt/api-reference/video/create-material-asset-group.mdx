---
title: "Criar Grupo de Ativos de Material"
openapi: "POST /v1/videos/assets/groups"
description: "Cria um grupo de material de avatar virtual da Seedance."
---

Crie um grupo de material com `library_type: "aigc_avatar"`. Use este endpoint para avatares virtuais, produtos, estilos e outras referências reutilizáveis que não exigem verificação de pessoa real.

Novos grupos de material de pessoa real são criados através da [verificação de material de pessoa real](/pt/api-reference/video/create-real-person-verification-session) e não podem ser criados diretamente com este endpoint.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_name":"Product references","description":"Reusable product shots"}'
```

## Exemplo de Resposta

```json
{
  "id": "seedance_group_virtual_123",
  "object": "seedance.material_asset_group",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
