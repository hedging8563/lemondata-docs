## Visão geral

Estes endpoints são para equipes que já usam o formato de tarefa Seedance no estilo Volc. A autenticação usa sua API key Bearer da TokenLab. O ID retornado começa com `cgt-`; consulte o status até que `status` seja `succeeded`, `failed`, `cancelled` ou `expired`.

Você também pode chamar o dispatcher Action com `CreateContentsGenerationsTasks`, `GetContentsGenerationsTask`, `ListContentsGenerationsTasks` ou `DeleteContentsGenerationsTasks`. `Action` e `Version` não diferenciam maiúsculas. `Version` pode ser omitido; se enviado, deve ser `2024-01-01`.

`callback_url` não é aceito nesta versão. Consulte o status da tarefa para não perder eventos de conclusão.

Veja também [Modelos de vídeo Seedance 2.0](/pt/guides/seedance-2-video) e [Geração de vídeo](/pt/guides/video-generation).

## Regras de conteúdo

- Use `type=text` para o texto do prompt.
- `type=image_url` sem `role` é tratado como o primeiro frame; você também pode definir `role=first_frame`.
- Use `role=last_frame` somente junto com um primeiro frame.
- Use `role=reference_image`, `reference_video` ou `reference_audio` para mídia de referência.
- Não misture entradas de primeiro/último frame com mídia de referência na mesma solicitação.

## Notas de parâmetros

- `ratio` aceita `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9` ou `adaptive`.
- `generate_audio` tem padrão `true`; defina `false` para vídeo sem áudio.
- `service_tier=default` é aceito. Tarefas compatíveis Seedance 2.0 rejeitam `service_tier=flex`, `frames` e `camera_fixed=true`.
- Quando o modelo selecionado suportar, `tools` pode incluir objetos como `{ "type": "web_search" }`. Entradas tool malformadas são rejeitadas em vez de ignoradas.

## Exemplo

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [
      {"type": "text", "text": "A cinematic forest at sunset"},
      {"type": "image_url", "role": "reference_image", "image_url": {"url": "https://example.com/ref.png"}}
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p",
    "generate_audio": true
  }'
```
