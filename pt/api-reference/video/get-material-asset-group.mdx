---
title: "Obter Grupo de Ativos de Material"
openapi: "GET /v1/videos/assets/groups/{groupId}"
description: "Recupera um grupo de material Seedance pelo ID de grupo do TokenLab."
---

Recupere um grupo de material. O `library_type` informa se o grupo é um grupo de avatar virtual ou um grupo de pessoa real.

Use este endpoint antes de fazer o upload se precisar confirmar que o grupo ainda existe e possui `status: "ACTIVE"`.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Exemplo de Resposta

```json
{
  "id": "seedance_group_virtual_123",
  "object": "seedance.material_asset_group",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
