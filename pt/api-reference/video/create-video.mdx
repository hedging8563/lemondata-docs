## Visão geral

A geração de vídeo é assíncrona. Você envia uma solicitação, recebe um ID da tarefa e `poll_url`, e então faz polling para obter o resultado.

<Info>
Para o comportamento de polling mais confiável, siga exatamente o `poll_url` retornado pela solicitação de criação.
</Info>

<Warning>
A saída de áudio depende do modelo. Na LemonData, a família Veo 3 ativa o áudio por padrão quando `output_audio` é omitido. Quando um modelo suporta controle de áudio, use `output_audio` para alternar explicitamente. O alias camelCase `outputAudio` também é aceito por compatibilidade.
</Warning>


## Corpo da solicitação

<ParamField body="model" type="string" default="sora-2">
  ID do modelo de vídeo. O padrão da API é `sora-2`. Consulte o [Guia de Geração de Vídeo](/guides/video-generation) para a matriz de modelos atual e os recursos compatíveis.
</ParamField>

<ParamField body="prompt" type="string" required>
  Descrição em texto do vídeo a ser gerado.
</ParamField>

<ParamField body="image_url" type="string">
  URL publicamente acessível da imagem inicial para geração image-to-video (I2V). Para melhor compatibilidade entre modelos, prefira `image_url`.
</ParamField>

<ParamField body="image" type="string">
  Imagem inline como uma data URL (por exemplo, `data:image/jpeg;base64,...`). Compatível com modelos compatíveis, mas `image_url` oferece a compatibilidade mais ampla entre modelos de vídeo.
</ParamField>

<ParamField body="duration" type="integer">
  Duração do vídeo em segundos (dependente do modelo).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Proporção de aspecto (por exemplo, `16:9`, `9:16`, `1:1`).
</ParamField>

<ParamField body="resolution" type="string">
  Resolução do vídeo (por exemplo, `1080p`, `720p`).
</ParamField>

<ParamField body="output_audio" type="boolean">
  Alternador de saída de áudio dependente do modelo. Na LemonData, a família Veo 3 usa `true` como padrão quando este campo é omitido. Os demais modelos de vídeo seguem seu comportamento padrão governado. O alias camelCase `outputAudio` é aceito por compatibilidade.
</ParamField>

<ParamField body="fps" type="integer">
  Quadros por segundo (1-120).
</ParamField>

<ParamField body="negative_prompt" type="string">
  O que evitar na geração do vídeo.
</ParamField>

<ParamField body="seed" type="integer">
  Seed aleatória para geração reproduzível.
</ParamField>

<ParamField body="cfg_scale" type="number">
  Escala de orientação sem classificador (0-20).
</ParamField>

<ParamField body="motion_strength" type="number">
  Intensidade de movimento (0-1).
</ParamField>

<ParamField body="start_image" type="string">
  URL da imagem do quadro inicial.
</ParamField>

<ParamField body="end_image" type="string">
  URL da imagem do quadro final.
</ParamField>

<ParamField body="user" type="string">
  Um identificador exclusivo para o usuário final.
</ParamField>

## Resposta

<ResponseField name="task_id" type="string">
  Identificador exclusivo da tarefa para polling.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling recomendada para esta tarefa. Use exatamente este caminho ao verificar o status.
</ResponseField>

<ResponseField name="status" type="string">
  Status inicial: `pending`.
</ResponseField>

<ResponseField name="model" type="string">
  Modelo usado.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/videos/generations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sora-2",
    "prompt": "A cat walking through a garden, cinematic lighting",
    "operation": "text-to-video",
    "duration": 4,
    "aspect_ratio": "16:9"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={
        "Authorization": "Bearer sk-your-api-key",
        "Content-Type": "application/json"
    },
    json={
        "model": "sora-2",
        "prompt": "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)

data = response.json()
task_id = data["task_id"]
print(f"Poll URL: {data['poll_url']}")
print(f"Task ID: {task_id}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":    "sora-2",
        "prompt":   "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/videos/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Poll URL: %s\n", result["poll_url"])
    fmt.Printf("Task ID: %s\n", result["task_id"])
}
```

## Image to Video

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/image.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)
```

## Controle de keyframe

Use `start_image` e `end_image` para controlar o primeiro e o último quadro (compatível com Vidu Q2 Pro):

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night",
        "operation": "Início-fim para vídeo",
        "start_image": "https://example.com/day.jpg",
        "end_image": "https://example.com/night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```
