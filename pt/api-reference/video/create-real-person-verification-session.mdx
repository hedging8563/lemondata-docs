---
title: "Criar Sessão de Verificação de Pessoa Real"
openapi: "POST /v1/videos/assets/visual-validation-sessions"
description: "Cria uma sessão H5 de verificação de material de pessoa real do TokenLab."
---

Crie uma sessão de verificação de curta duração e redirecione seu usuário para o link H5 retornado. O TokenLab retorna apenas campos neutros: `session_id`, `h5_link`, `callback_url`, `expires_in` e `language`.

A sessão e o link H5 expiram após 120 segundos. O token de vinculação é fornecido apenas pelo redirecionamento de callback do TokenLab. Quando o fluxo H5 é concluído, o TokenLab redireciona para sua `callback_url` original com estes parâmetros de consulta:

| Parâmetro | Significado |
|-----------|---------|
| `session_id` | ID da sessão de verificação do TokenLab. |
| `verification_token` | Token opaco usado para vincular o resultado. |
| `verification_status` | `succeeded` ou `failed`. |
| `result_code` | Código de resultado para a lógica da sua aplicação. |

Se `verification_status` for `succeeded`, chame [Vincular Resultado de Verificação de Pessoa Real](/pt/api-reference/video/bind-real-person-verification-result). O [console de teste](https://tokenlab.sh/dashboard/seedance-assets) pode ser usado para verificar o tratamento do callback antes de integrar o fluxo ao seu produto.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"callback_url":"https://yourapp.example.com/seedance/callback","language":"en"}'
```

## Exemplo de Resposta

```json
{
  "object": "seedance.visual_validation_session",
  "session_id": "svv_abc123",
  "h5_link": "https://verify.example.com/h5?lng=en",
  "callback_url": "https://yourapp.example.com/seedance/callback",
  "expires_in": 120,
  "language": "en"
}
```
