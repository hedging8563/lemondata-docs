---
title: "Atualizar Grupo de Ativos de Material"
openapi: "PUT /v1/videos/assets/groups/{groupId}"
description: "Atualiza um grupo de material Seedance pertencente à organização atual."
---

Atualize o nome de exibição, a descrição ou os metadados de um grupo de material. Para grupos de pessoas reais gerenciados, o mapeamento da pessoa verificada permanece inalterado.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"group_name":"Updated references","description":"Images approved for summer videos"}'
```

## Exemplo de Resposta

```json
{
  "id": "seedance_group_virtual_123",
  "object": "seedance.material_asset_group",
  "library_type": "aigc_avatar",
  "group_name": "Updated references",
  "description": "Images approved for summer videos",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
