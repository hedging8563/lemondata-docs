---
title: "Gerar Conteúdo"
openapi: "POST /v1beta/models/{model}:generateContent"
description: "Gera conteúdo usando o formato da API Google Gemini"
---

A LemonData suporta o formato nativo da API Google Gemini para modelos Gemini. Isso permite compatibilidade direta com os SDKs de IA do Google.

## Parâmetros de Caminho

<ParamField path="model" type="string" required>
  Nome do modelo (ex: `gemini-2.5-pro`, `gemini-2.5-flash`).
</ParamField>

## Parâmetros de Consulta

<ParamField query="key" type="string">
  Chave de API (alternativa à autenticação por cabeçalho).
</ParamField>

## Autenticação

Os endpoints do Gemini suportam múltiplos métodos de autenticação:
- `?key=YOUR_API_KEY` parâmetro de consulta
- `x-goog-api-key: YOUR_API_KEY` cabeçalho
- `Authorization: Bearer YOUR_API_KEY` cabeçalho

## Corpo da Requisição

<ParamField body="contents" type="array" required>
  Conteúdos da conversa.

  Each content object contains:
  - `role` (string): `user` or `model`
  - `parts` (array): Content parts. LemonData supports:
    - text parts: `{ "text": "..." }`
    - inline media parts: `inlineData` / `inline_data`
    - URL-based file parts: `fileData` / `file_data`

  For media parts, LemonData currently accepts image, audio, and video MIME types and forwards them through the Gemini-compatible public contract.
</ParamField>

<ParamField body="systemInstruction" type="object">
  Instrução de sistema para o modelo.
</ParamField>

<ParamField body="generationConfig" type="object">
  Configuração de geração:
  - `temperature` (number): Temperatura de amostragem
  - `topP` (number): Probabilidade de amostragem nucleus
  - `topK` (integer): Amostragem Top-K
  - `maxOutputTokens` (integer): Máximo de tokens de saída
  - `stopSequences` (array): Sequências de parada
</ParamField>

<ParamField body="safetySettings" type="array">
  Configurações de filtro de segurança.
</ParamField>

## Resposta

<ResponseField name="candidates" type="array">
  Candidatos de conteúdo gerado.
</ResponseField>

<ResponseField name="usageMetadata" type="object">
  Informações de uso de tokens.
</ResponseField>

## Multimodal Input Examples

For Gemini multimodal requests, place media inside `contents[].parts[]` using either inline bytes or URL-based file references.

Supported media categories in the public Gemini contract:
- image
- audio
- video

For inline media, use either `inlineData` or `inline_data` and pass Base64-encoded file bytes.

For URL-based media, use either `fileData` or `file_data` and pass a public `https` URL.

### Image Input Example

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Please describe this image." },
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "/9j/4AAQSkZJRgABAQ..."
          }
        }
      ]
    }
  ]
}
```

### Audio Input Example

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Transcribe and summarize this audio." },
        {
          "file_data": {
            "mime_type": "audio/mpeg",
            "file_uri": "https://example.com/sample.mp3"
          }
        }
      ]
    }
  ]
}
```

### Video Input Example

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Describe this video briefly." },
        {
          "fileData": {
            "mimeType": "video/mp4",
            "fileUri": "https://example.com/sample.mp4"
          }
        }
      ]
    }
  ]
}
```
