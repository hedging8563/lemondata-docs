title: "Obter Status da Tarefa"
description: "Recupere o status e o resultado de qualquer tarefa assíncrona usando a poll_url retornada pelos endpoints de criação"
---

## Visão geral

Use este endpoint para polling assíncrono unificado entre tipos de tarefa como geração de vídeo, imagem, música e 3D.

<Info>
Se uma resposta de criação incluir `poll_url`, chame esse caminho exato. Para workflows assíncronos mais recentes, `poll_url` pode apontar para `/v1/tasks/{id}`.
</Info>

## Parâmetros de caminho

<ParamField path="id" type="string" required>
  O ID da tarefa retornado pela requisição de criação.
</ParamField>

## Resposta

<ResponseField name="id" type="string">
  Identificador canônico da tarefa assíncrona.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias do identificador da tarefa assíncrona.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling prioritária retornada pela resposta de criação.
</ResponseField>

<ResponseField name="status" type="string">
  Status da tarefa, como `pending`, `processing`, `completed` ou `failed`.
</ResponseField>

<ResponseField name="progress" type="number">
  Porcentagem de progresso quando disponível.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL do asset resultante quando a tarefa é concluída e produz um vídeo.
</ResponseField>

<ResponseField name="video" type="object">
  Objeto único de vídeo com `url`, `duration`, `width` e `height` quando disponível.
</ResponseField>

<ResponseField name="videos" type="array">
  Array de vídeos quando o upstream retorna mais de uma saída.
</ResponseField>

<ResponseField name="error" type="string">
  Mensagem de erro quando a tarefa falha.
</ResponseField>

<ResponseField name="created" type="integer">
  Timestamp de criação quando disponível.
</ResponseField>

<ResponseField name="updated" type="integer">
  Timestamp da última atualização quando disponível.
</ResponseField>

<ResponseField name="model" type="string">
  Modelo usado quando disponível.
</ResponseField>

## Exemplos

```bash cURL
curl "https://api.lemondata.cc/v1/tasks/video_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

poll_url = "/v1/tasks/video_abc123"
response = requests.get(
    f"https://api.lemondata.cc{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/video_abc123';
const response = await fetch(`https://api.lemondata.cc${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
