---

## Visão Geral

Este endpoint retorna detalhes de uso por chave com filtros por nome do modelo solicitado (`model`), provedor público do modelo, `scene` e `accessChannel`.

## Notas

- A resposta inclui apenas campos públicos de faturamento.
- Roteamento interno e metadados do canal físico são ocultados intencionalmente.
