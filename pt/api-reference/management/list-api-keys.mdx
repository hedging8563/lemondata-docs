---

## Visão Geral

Retorna as chaves API de usuário da organização associada ao token de gerenciamento atual.

## Notas

- Chaves gerenciadas pelo sistema, como chaves do Playground e do Claw, são excluídas.
- Os campos monetários da resposta são retornados em USD e também em exibição RMB: `limit_amount` / `limit_amount_cny`, `used_amount` / `used_amount_cny`.
- `exchange_rate` indica a taxa USD→CNY usada nos campos de exibição em RMB.
