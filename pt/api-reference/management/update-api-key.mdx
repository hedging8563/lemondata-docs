## Visão Geral

Use este endpoint para atualizar nome, limite de uso, modelos permitidos, expiração ou status de uma chave API de usuário existente.

## Notas

- A exclusão permanente não é suportada na API de gerenciamento v1.

Use o painel interativo OpenAPI acima para o esquema exato.
