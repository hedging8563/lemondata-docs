## Visão geral

Use este endpoint para atualizar nome, limite de uso, modelos permitidos, expiração ou status de uma API Key existente.

## Corpo da requisição

Pelo menos um campo deve ser enviado na requisição PATCH.

| Campo | Tipo | Padrões / limites | Observações |
|-------|------|------------------|-------|
| status | enum | - | active, inactive, revoked |
| name | string | length 1-50 | Updated display name |
| limitAmount | number \| null | min 0, max 100000 | null = unlimited, 0 = zero quota, positive = USD cap |
| models | string[] | - | Updated logical model allowlist |
| expiresAt | string \| null | RFC3339 datetime | null clears the expiry |

## Observações

- Hard delete não é suportado intencionalmente na Management API v1.
- `revoked` normalmente é tratado como estado terminal; se você precisar de outra chave, geralmente é melhor criar uma nova.

## Exemplo

<RequestExample>
```bash cURL
curl -X PATCH "https://api.lemondata.cc/v1/management/api-keys/key_abc123def456" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "inactive",
    "limitAmount": 0
  }'
```
</RequestExample>
