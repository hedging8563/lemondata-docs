## Visão Geral

A API de gerenciamento permite gerenciar as chaves API da organização e consultar uso e faturamento de uma chave específica sem usar uma chave API de inferência padrão.

Use um token de gerenciamento da página **Settings** do seu Dashboard:

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
Tokens de gerenciamento não são chaves API de inferência. Use `mt-...` para `/v1/management/*` e `sk-...` para endpoints de inferência como `/v1/responses`.
</Warning>

## Endpoints disponíveis

| Endpoint | Method | Descrição |
|----------|--------|------|
| `/v1/management/api-keys` | GET | Lista as chaves API de usuário da organização atual |
| `/v1/management/api-keys` | POST | Cria uma nova chave API de usuário |
| `/v1/management/api-keys/{keyId}` | PATCH | Atualiza nome, limite de uso, modelos permitidos, expiração ou status |
| `/v1/management/api-keys/{keyId}/usage` | GET | Recupera detalhes paginados de uso para uma chave específica |
| `/v1/management/api-keys/{keyId}/billing` | GET | Recupera detalhamentos agregados de faturamento para uma chave específica |

## Significado dos campos

- nome do modelo solicitado (`model`)
- provedor público do modelo
- `scene`
- `accessChannel`: `platform` significa que a requisição foi cobrada como uma requisição da plataforma; `byok` significa que usou sua própria chave do provedor upstream
- quantidade de uso, unidade de faturamento e métricas de cache
- custos e timestamps

As respostas expõem apenas campos públicos de faturamento e relatórios. Detalhes de roteamento interno e metadados do provedor físico permanecem ocultos.

## Filtros

`/usage` e `/billing` atualmente aceitam filtros por:

- intervalo de tempo
- nome do modelo solicitado (`model`)
- provedor público do modelo
- `scene`
- `accessChannel`
- paginação

## Exemplo completo de requisição

Comece listando as chaves API da organização acessíveis com o token de gerenciamento atual:

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```

```python Python
import requests

response = requests.get(
    "https://api.lemondata.cc/v1/management/api-keys",
    headers={"Authorization": "Bearer mt-your-management-token"}
)

data = response.json()
for key in data["data"]:
    print(key["name"], key["status"], key["used_amount"])
```

```javascript JavaScript
const response = await fetch(
  'https://api.lemondata.cc/v1/management/api-keys',
  {
    headers: {
      'Authorization': 'Bearer mt-your-management-token'
    }
  }
);

const data = await response.json();
for (const key of data.data) {
  console.log(key.name, key.status, key.used_amount);
}
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/management/api-keys", nil)
    req.Header.Set("Authorization", "Bearer mt-your-management-token")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)

    fmt.Println(result["object"])
}
```

```php PHP
<?php
$ch = curl_init("https://api.lemondata.cc/v1/management/api-keys");

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer mt-your-management-token'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
foreach ($data['data'] as $key) {
    echo $key["name"] . " " . $key["status"] . " " . $key["used_amount"] . PHP_EOL;
}
```
</RequestExample>
