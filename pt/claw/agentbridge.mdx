---
title: "AgentBridge"
description: "Entregue a um coding agent um access pack pronto para a runtime de uma instância LemonClaw."
---

O AgentBridge permite que um coding agent fale diretamente com uma instância LemonClaw em execução usando o gateway token exibido no dashboard hospedado.

## Como obter o access pack

Abra Dashboard > Claw, escolha uma instância em execução, clique em AgentBridge e copie o access pack completo no modal. Ele já inclui a runtime base URL, o bearer token, a convenção de session key e os endpoints mais importantes.

## O que o token pode fazer

O gateway token copiado gerencia apenas a runtime. Ele pode ler o status da runtime, enviar requisições de chat, receber saída SSE, ler o histórico do thread, parar um thread em execução e buscar mídias retornadas pelo AgentBridge. Ele não pode renovar, reconstruir, reiniciar pela hosted control plane nem acessar rotas de faturamento ou admin da organização.

## Regra das session keys

As session keys sempre seguem o formato `agentbridge:<client_id>:<workspace_id>:<thread_id>`. Mantenha os três valores estáveis para o mesmo thread. Se mudar para outra provider family, crie um novo `thread_id` em vez de reutilizar o thread antigo.

## Principais endpoints de runtime

- `GET /api/status`
- `GET /api/usage?session=<session_key>`
- `POST /api/agentbridge/chat`
- `POST /api/agentbridge/chat/stream`
- `POST /api/agentbridge/uploads`
- `GET /api/agentbridge/messages`
- `GET /api/agentbridge/events/stream`
- `POST /api/agentbridge/stop`
- `GET /api/agentbridge/media`

```bash
curl -N https://claw-demo.lemondata.cc/api/agentbridge/chat/stream \
  -H "Authorization: Bearer <gateway_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": "codex",
    "workspace_id": "default",
    "thread_id": "demo-thread",
    "message": "Give me a short status update for this instance."
  }'
```

## Prompt para coding agents

Envie esta instrução curta ao coding agent junto com o access pack:

> Use `/api/agentbridge/chat/stream` first. Keep `client_id`, `workspace_id`, and `thread_id` stable for the same conversation. If you get `provider_family_conflict`, create a new `thread_id` instead of reusing the old one.

## Erros comuns

- `provider_family_conflict` — o thread já possui histórico em outra provider family; crie um novo `thread_id`.
- `Unauthorized` — o bearer token está ausente, expirou ou não pertence a esta instância.
- `Instance not running` — AgentBridge access packs só são emitidos para instâncias em execução.
