<Note>
**Self-hosted** significa que você executa o LemonClaw diretamente em seu próprio VPS ou máquina. Você paga apenas pelo uso do modelo de IA através do seu saldo LemonData — sem taxas de instância.
</Note>

<Tip>
Prefere uma configuração hospedada? [Crie uma instância Claw](/claw/introduction) para obter o mesmo runtime e WebUI do LemonClaw sem gerenciar servidores você mesmo.
</Tip>

## Instalação Rápida

<CodeGroup>
```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```

```bash Não interativo
LEMONDATA_API_KEY=sk-xxx curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```
</CodeGroup>

O instalador solicitará sua **LemonData API Key**. Obtenha uma em seu [Dashboard](https://lemondata.cc/dashboard).

## O Que é Instalado

<Steps>
  <Step title="Node.js 22+">
    Instalado automaticamente se estiver ausente (via NodeSource no Linux, Homebrew no macOS)
  </Step>
  <Step title="LemonClaw">
    Pacote LemonClaw pré-configurado com a API LemonData
  </Step>
  <Step title="15 Modelos de IA">
    Claude, GPT-5, Gemini, DeepSeek e mais — prontos para usar
  </Step>
  <Step title="Plugins de IM">
    Plugins de DingTalk, WeCom e QQ pré-instalados
  </Step>
  <Step title="Serviço do Sistema">
    Inicia automaticamente no boot (systemd no Linux, launchd no macOS)
  </Step>
</Steps>

## Requisitos

| Requisito | Detalhes |
|-------------|---------|
| **SO** | Linux (Ubuntu/Debian/CentOS/RHEL) ou macOS |
| **Arquitetura** | x64 ou arm64 |
| **RAM** | Mínimo de 1 GB, 2 GB recomendados |
| **API Key** | [Obtenha uma aqui](https://lemondata.cc) |

## Comandos de Gerenciamento

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user status lemonclaw    # Verificar status
    journalctl --user -u lemonclaw -f    # Visualizar logs
    systemctl --user restart lemonclaw   # Reiniciar
    systemctl --user stop lemonclaw      # Parar
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    tail -f ~/.lemonclaw/lemonclaw.log    # Visualizar logs
    launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # Reiniciar
    launchctl stop cc.lemondata.lemonclaw  # Parar
    ```
  </Tab>
</Tabs>

## Configuração

Localização do arquivo de configuração: `~/.lemonclaw/config.json`

Após editar, reinicie o serviço para aplicar as alterações.

### Alterar Modelo Padrão

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-opus-4-6"
      }
    }
  }
}
```

Prefixos de modelos disponíveis (dependendo de quais providers você habilitou em [LemonData Provider Setup](/claw/lemondata-provider)):
- `lemondata/` — Rota compatível com OpenAI (`openai-completions`)
- `lemondata-responses/` — Rota OpenAI Responses (`openai-responses`)
- `lemondata-claude/` — Rota nativa do Claude (`anthropic-messages`)
- `lemondata-gemini/` — Rota nativa do Gemini (`google-generative-ai`)
- `lemondata-minimax/` — Rota nativa do MiniMax (`anthropic-messages`)

## Atualização

```bash
# Execute o instalador novamente para atualizar para a versão mais recente
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
# Em seguida, reinicie o serviço
systemctl --user restart lemonclaw  # Linux
# ou
launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # macOS
```

## Desinstalação

```bash
# Parar e desativar o serviço
systemctl --user stop lemonclaw && systemctl --user disable lemonclaw  # Linux
launchctl unload ~/Library/LaunchAgents/cc.lemondata.lemonclaw.plist  # macOS

# Remover o LemonClaw
rm -rf ~/.lemonclaw
```

## Self-Hosted vs Gerenciado

| | Self-Hosted | Gerenciado (Claw) |
|---|---|---|
| **Custo da instância** | Grátis | $20 / 30 dias |
| **Uso de IA** | Pagamento por uso | Pagamento por uso |
| **Infraestrutura** | Seu servidor | Nós gerenciamos tudo |
| **Atualizações** | Manual (reexecutar instalador) | Automático |
| **Suporte** | Comunidade | Prioridade |
