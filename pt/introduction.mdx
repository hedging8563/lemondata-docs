## O que é LemonData?

LemonData é uma plataforma de agregação de APIs de AI que oferece acesso unificado a **mais de 300 modelos de AI** de provedores como OpenAI, Anthropic, Google, DeepSeek, Moonshot, MiniMax e outros.

## Um Bom Ponto de Partida Padrão

Para novos projetos, comece com o SDK da OpenAI junto com a **Responses API**:

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```
