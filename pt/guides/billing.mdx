## Visão geral

A LemonData usa **precificação pay-as-you-go**. Você paga apenas pelo que usa, sem assinaturas ou compromissos mínimos.

## Como a cobrança funciona

1. **Adicione créditos** à sua conta
2. **Use a API** - os custos são deduzidos por requisição
3. **Monitore o uso** no seu dashboard
4. **Recarregue** quando seu saldo estiver baixo

### Cobrança de tarefas assíncronas (Vídeo/Música/3D)

<Warning>
  **Importante**: tarefas de geração de vídeo, música e 3D são **cobradas no momento do envio**, não na conclusão.
</Warning>

Para tarefas de geração assíncrona (vídeo, música, modelos 3D):

1. A **cobrança ocorre imediatamente** quando você envia a tarefa
2. Você recebe um `task_id` para consultar o status
3. **Não há reembolsos automáticos** se a tarefa falhar

Isso acontece porque os provedores upstream nos cobram quando a tarefa é enviada, independentemente do resultado. Se você enfrentar falhas em tarefas, entre em contato com support@lemondata.cc para obter assistência.

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

task_id = response.json()["task_id"]
# Poll for status...
```

## Contagem de tokens

Tokens são as unidades básicas de processamento de texto:

- ~4 caracteres = 1 token (Inglês)
- ~1-2 caracteres = 1 token (Chinês)
- 1 imagem = varia conforme o tamanho e o nível de detalhe

### Estimando tokens

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## Otimização de custos

## Alertas de saldo baixo

Configure alertas quando seu saldo cair:

1. Vá para **Dashboard → Settings → Notifications**
2. Defina o valor do seu limite
3. Receba notificações por email

## Adicionando créditos

### Métodos de pagamento

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### Etapas

1. Faça login no [Dashboard](https://lemondata.cc/dashboard)
2. Clique em **Add Credits**
3. Selecione o valor e o método de pagamento
4. Conclua o pagamento

Os créditos são adicionados instantaneamente após a confirmação do pagamento.

## Limites de API key

Você pode definir limites de gastos em API keys individuais:

1. Vá para **Dashboard → API Keys**
2. Clique em uma chave para editar
3. Defina **Usage Limit**

Quando o limite for atingido, requisições com essa chave retornarão `402 Payment Required`.

## Faturas

Para contas empresariais, as faturas estão disponíveis:

1. Vá para **Dashboard → Billing**
2. Visualize o histórico de transações
3. Baixe as faturas em PDF
