## Visão geral

A API LemonData foi projetada para **compatibilidade imediata** com todas as principais ferramentas de desenvolvimento de AI. Este guia documenta os parâmetros suportados e as integrações verificadas.

<Note>
  Todos os parâmetros são validados, mas encaminhados para os provedores upstream. Parâmetros não suportados para modelos específicos são ignorados silenciosamente, garantindo compatibilidade máxima.
</Note>

## Formatos de API suportados

| Endpoint | Format | Caso de uso |
|----------|--------|-------------|
| `/v1/chat/completions` | OpenAI Chat | Compatibilidade universal |
| `/v1/responses` | OpenAI Responses | Conversas com estado |
| `/v1/messages` | Anthropic Messages | Recursos nativos do Claude |
| `/v1beta/models/:model:generateContent` | Google Gemini | Recursos nativos do Gemini |

## Parâmetros de Chat Completions

### Parâmetros principais

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Identificador do modelo (obrigatório) |
| `messages` | array | Mensagens da conversa (obrigatório) |
| `max_tokens` | integer | Máximo de tokens de saída |
| `temperature` | number | Temperatura de amostragem (0-2) |
| `top_p` | number | Amostragem nucleus (0-1) |
| `stream` | boolean | Habilitar streaming |

### Chamada de tool

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Opções de Tool Choice

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | Seleção simples |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | Forçar função específica |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Formato nativo Anthropic |

### Parâmetros avançados

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | `{ include_usage: true }` para contagem de tokens |
| `reasoning_effort` | string | `"low"`, `"medium"`, `"high"` para modelos GPT-5 com reasoning habilitado |
| `service_tier` | string | `"auto"` ou `"default"` |
| `seed` | integer | Saídas determinísticas |
| `logprobs` | boolean | Retornar probabilidades log |
| `top_logprobs` | integer | Número de principais probabilidades log (0-20) |
| `logit_bias` | object | Mapa de viés de token (-100 a 100) |
| `frequency_penalty` | number | Penalidade de repetição (-2 a 2) |
| `presence_penalty` | number | Penalidade de tópico (-2 a 2) |
| `stop` | string/array | Sequências de parada |
| `n` | integer | Número de completions (1-128) |
| `user` | string | Identificador do usuário para rastreamento |

### Recursos avançados do OpenAI

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | `["text", "audio"]` para multimodal |
| `audio` | object | Configuração de saída de áudio (voz, formato) |
| `prediction` | object | Saída prevista para completion mais rápida |
| `metadata` | object | Pares chave-valor para rastreamento |
| `store` | boolean | Armazenar para recuperação posterior |

### Opções específicas do provedor

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Parâmetros de Anthropic Messages

### Parâmetros principais

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Identificador do modelo |
| `messages` | array | Mensagens da conversa |
| `max_tokens` | integer | Saída máxima (até 128000) |
| `system` | string/array | Prompt de sistema |
| `stream` | boolean | Habilitar streaming |

### Chamada de tool

```json
{
  "tools": [
    {
      "name": "get_weather",
      "description": "Get weather",
      "input_schema": {
        "type": "object",
        "properties": {
          "location": { "type": "string" }
        }
      }
    }
  ],
  "tool_choice": {
    "type": "auto",
    "disable_parallel_tool_use": false
  }
}
```

### Pensamento estendido

```json
{
  "model": "claude-opus-4-6",
  "thinking": {
    "type": "enabled",
    "budget_tokens": 10000
  }
}
```

## Parâmetros da API Responses

### Parâmetros principais

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Identificador do modelo |
| `input` | string/array | Conteúdo de entrada |
| `instructions` | string | Instruções de sistema |
| `max_output_tokens` | integer | Máximo de tokens de saída |
| `previous_response_id` | string | Continuar conversa |

### Parâmetros avançados

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` ou `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | Para modelos com reasoning |
| `service_tier` | string | Nível de prioridade |

### Formato de tool

Suporta formatos de tool OpenAI e Anthropic:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## Streaming

Todos os endpoints suportam streaming via Server-Sent Events (SSE):

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## Tratamento de erros

A LemonData retorna respostas de erro compatíveis com OpenAI:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

Consulte o [Guia de tratamento de erros](/guides/error-handling) para mais detalhes.

## Boas práticas

<AccordionGroup>
  <Accordion title="Use passthrough para parâmetros desconhecidos">
    Todos os schemas usam `.passthrough()` - parâmetros desconhecidos são encaminhados para os provedores upstream.
  </Accordion>

  <Accordion title="Prefira `stream_options` para faturamento preciso">
    Habilite `stream_options.include_usage` para contagens de tokens precisas em respostas de streaming.
  </Accordion>

  <Accordion title="Use o formato de `tool_choice` apropriado">
    Corresponda ao formato esperado pelo seu SDK. A LemonData aceita formatos OpenAI e Anthropic.
  </Accordion>
</AccordionGroup>
