## Etapa 1: Obtenha sua chave de API

<Steps>
  <Step title="Crie uma conta">
    Cadastre-se em [lemondata.cc](https://lemondata.cc) usando seu email, Gmail ou conta do GitHub.
  </Step>
  <Step title="Adicione créditos">
    Abra o dashboard e adicione créditos à sua conta. A LemonData usa preços pay-as-you-go, sem compromisso mínimo.
  </Step>
  <Step title="Crie uma chave de API">
    Vá para **Dashboard → API Keys** e crie uma nova chave. Copie-a com segurança, pois ela é exibida apenas uma vez.
  </Step>
</Steps>

<Warning>
Mantenha sua chave de API segura. Nunca a exponha em código client-side ou em repositórios públicos.
</Warning>

## Etapa 3: Faça sua primeira requisição

Para novos projetos, comece com a **Responses API**.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
Se seu framework ou ferramenta ainda espera Chat Completions, a LemonData também oferece suporte a `POST /v1/chat/completions`. Para novas integrações, prefira `POST /v1/responses`.
</Note>

## Experimente diferentes modelos

A LemonData oferece suporte a mais de 300 modelos. Altere apenas o campo `model`:

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## Habilite streaming

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
