## Descripción general

Para LemonData, el valor predeterminado más estable en Vercel AI SDK es el **proveedor compatible con OpenAI**.

Si necesitas específicamente el comportamiento **nativo de Responses**, puedes cambiar al proveedor de OpenAI y mantener la misma base URL de LemonData.

## Valor predeterminado recomendado: proveedor compatible con OpenAI

```bash
npm install ai @ai-sdk/openai-compatible
```

```typescript
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

export const lemondata = createOpenAICompatible({
  name: 'lemondata',
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

## Generar texto

```typescript
import { generateText } from 'ai';
import { lemondata } from './lemondata';

const { text } = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});

console.log(text);
```

## Transmitir texto en streaming

```typescript
import { streamText } from 'ai';
import { lemondata } from './lemondata';

const result = await streamText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Write a short poem about coding.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## Llamada de herramientas

```typescript
import { generateText, tool } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const result = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'What is the weather in San Francisco?',
  tools: {
    weather: tool({
      description: 'Get weather in a location',
      parameters: z.object({
        location: z.string(),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72,
        condition: 'sunny',
      }),
    }),
  },
});

console.log(result.text);
```

## Salida estructurada

```typescript
import { generateObject } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const { object } = await generateObject({
  model: lemondata.chatModel('gpt-5.4'),
  schema: z.object({
    name: z.string(),
    role: z.string(),
  }),
  prompt: 'Generate a fake developer profile.',
});

console.log(object);
```

## Si explícitamente necesitas comportamiento nativo de Responses

```bash
npm install ai @ai-sdk/openai
```

```typescript
import { createOpenAI } from '@ai-sdk/openai';

export const lemondataResponses = createOpenAI({
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```typescript
import { generateText } from 'ai';
import { lemondataResponses } from './lemondata-responses';

const { text } = await generateText({
  model: lemondataResponses('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});
```

<Note>
Usa `@ai-sdk/openai-compatible` como valor predeterminado seguro para integraciones de estilo proxy. Cambia a `@ai-sdk/openai` solo cuando explícitamente quieras una ruta de proveedor construida sobre `/v1/responses`.
</Note>

## Variables de entorno

```bash
# .env.local
LEMONDATA_API_KEY=sk-your-lemondata-key
```

## Mejores prácticas

<AccordionGroup>
  <Accordion title="Prefiere openai-compatible primero">
    Para gateways de terceros y backends proxy, `@ai-sdk/openai-compatible` suele ser el punto de partida menos sorpresivo.
  </Accordion>

  <Accordion title="Pasa a Responses solo cuando sea necesario">
    Si necesitas un comportamiento del proveedor vinculado a `/v1/responses`, cambia deliberadamente el paquete del proveedor en lugar de mezclar ambos patrones en un solo cliente.
  </Accordion>

  <Accordion title="Mantén los secretos en el servidor">
    Nunca expongas tu clave de API de LemonData en código del lado del cliente. Coloca la configuración del proveedor en archivos del servidor o rutas de API.
  </Accordion>
</AccordionGroup>
