## Descripción general

LemonData funciona con los SDK oficiales de OpenAI apuntando el cliente a `https://api.lemondata.cc/v1`.

Para proyectos nuevos, prefiere la **Responses API**. Mantén **Chat Completions** solo cuando un framework, plugin o ruta de código heredada todavía lo requiera.

<Note>
Python, JavaScript y Go tienen SDK oficiales de OpenAI. PHP funciona bien con clientes de la comunidad compatibles con OpenAI, pero no es un SDK oficial de OpenAI.
</Note>

## Configurar el cliente

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## Recomendado: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

## Streaming con Responses

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Herramientas / Llamada a funciones

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## Compatibilidad con Chat Completions

Si tu framework o plugin todavía requiere Chat Completions, LemonData también admite la ruta estándar compatible con OpenAI:

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
Usa Chat Completions solo por compatibilidad. Para integraciones nuevas, prefiere `client.responses.create(...)`.
</Warning>

## Solución de problemas

<AccordionGroup>
  <Accordion title="Error de conexión">
    - Verifica que la URL base sea exactamente `https://api.lemondata.cc/v1`
    - Revisa si hay interferencia de proxy o sobrescrituras personalizadas del cliente HTTP
    - Asegúrate de que la versión de tu SDK esté actualizada antes de depurar el comportamiento del proveedor
  </Accordion>

  <Accordion title="Autenticación fallida">
    - Verifica que tu API key comience con `sk-`
    - Verifica que la key esté activa en el dashboard de LemonData
    - Confirma que el SDK esté enviando `Authorization: Bearer ...`
  </Accordion>

  <Accordion title="Ruta de API incorrecta">
    - `responses.create(...)` envía solicitudes a `/v1/responses`
    - `chat.completions.create(...)` envía solicitudes a `/v1/chat/completions`
    - Si tu aplicación hoy solo admite Chat Completions, mantenla en esa ruta de compatibilidad
  </Accordion>
</AccordionGroup>
