## Resumen general

La mayoría de las aplicaciones generales de chat con AI se conectan a LemonData a través de la ruta de chat estándar compatible con OpenAI.

En la práctica, eso significa:
- usar `https://api.lemondata.cc/v1` como URL base, a menos que la aplicación solicite explícitamente una URL completa del endpoint
- usar tu clave API de LemonData como la clave API de estilo OpenAI
- elegir modelos que la aplicación pueda usar en un flujo de trabajo de chat estándar

<Note>
Las aplicaciones generales de chat suelen estar **orientadas a chat-completions**, no a clientes WebSocket de Codex Responses. Para Codex CLI/App, Cursor u otras herramientas de programación que necesitan un comportamiento específico de Responses, usa en su lugar las guías de integración dedicadas.
</Note>

## Aplicaciones compatibles

| Application | Platform | Notes |
|-------------|----------|-------|
| LobeChat | Web, Desktop, Self-hosted | Sólido soporte para proveedores personalizados |
| Cherry Studio | Windows, macOS, Linux | Buen flujo de proveedor compatible con OpenAI |
| Chatbox | Windows, macOS, Linux | Configuración sencilla compatible con OpenAI |
| TypingMind | Web, Desktop | Usa un estilo de endpoint personalizado |
| BotGem | iOS, macOS | Configuración de proveedor personalizado |
| OpenCat | iOS, macOS | Flujo de endpoint personalizado compatible con OpenAI |
| ChatWise | Windows, macOS | Patrón estándar de proveedor personalizado |

## Valores de conexión predeterminados

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

Si una aplicación solicita una **URL completa del endpoint** en lugar de una URL base, usa:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## Ejemplos de configuración de aplicaciones

<Tabs>
  <Tab title="LobeChat">
    **LobeChat self-hosted**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. Abre **Settings** → **AI Service Provider**
    2. Selecciona **OpenAI**
    3. Introduce tu clave API de LemonData
    4. Establece el endpoint personalizado en `https://api.lemondata.cc/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. Abre **Settings** → **Model Provider**
    2. Agrega un proveedor **OpenAI-compatible**
    3. Introduce:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. Agrega los modelos que quieras usar
  </Tab>

  <Tab title="Chatbox">
    1. Abre **Settings** → **AI Model**
    2. Elige **OpenAI API Compatible**
    3. Introduce:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` o `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. Abre **Settings**
    2. Elige **Custom Endpoint**
    3. Introduce:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. Configura los modelos que quieras exponer
  </Tab>
</Tabs>

## Consejos

<AccordionGroup>
  <Accordion title="Prefiere la URL base cuando la aplicación la admita">
    La mayoría de las aplicaciones son más fáciles de configurar y menos frágiles cuando proporcionas `https://api.lemondata.cc/v1` como URL base en lugar de una URL completa del endpoint.
  </Accordion>

  <Accordion title="Usa primero modelos más pequeños">
    Empieza con `gpt-5-mini` o `gpt-4o` para el chat cotidiano, y luego pasa las tareas de razonamiento más pesadas a `gpt-5.4` o `claude-opus-4-6`.
  </Accordion>

  <Accordion title="Mantén separadas las herramientas de programación">
    Las aplicaciones generales de chat y los agentes de programación a menudo necesitan comportamientos de endpoint diferentes. Mantén las herramientas de estilo Codex/Cursor en sus páginas de integración dedicadas.
  </Accordion>
</AccordionGroup>

## Solución de problemas

<AccordionGroup>
  <Accordion title="Error de conexión">
    - Verifica que la URL base sea exactamente `https://api.lemondata.cc/v1`
    - Elimina las barras finales si la aplicación añade rutas automáticamente
    - Si la aplicación quiere una URL completa del endpoint, usa `https://api.lemondata.cc/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Unauthorized">
    - Vuelve a comprobar tu clave API
    - Confirma que la clave esté activa en el panel de LemonData
    - Asegúrate de que no haya espacios adicionales ni saltos de línea
  </Accordion>

  <Accordion title="Modelo no disponible">
    - Verifica el nombre del modelo exactamente
    - Prueba con un valor predeterminado ampliamente compatible como `gpt-5-mini`, `gpt-4o` o `claude-sonnet-4-6`
    - Consulta la disponibilidad actual en la documentación o el panel de LemonData
  </Accordion>
</AccordionGroup>
