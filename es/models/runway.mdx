## Descripción general

LemonData proporciona acceso a los modelos de Luma AI. Total: **2 modelos** disponibles.

## Modelos de Chat

| Model ID | Precios |
|----------|--------|
| `luma-video-api` | Ver dashboard |
| `luma-video-extend-api` | Ver dashboard |


## Uso

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="luma-video-api",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Los precios mostrados son precios de la plataforma (~70% de las tarifas oficiales).
