## Descripción general

LemonData proporciona acceso a los modelos de Higgsfield AI. Total: **3 modelos** disponibles.

## Modelos de Chat

| ID del modelo | Precios |
|----------|--------|
| `higgsfield-lite` | Ver dashboard |
| `higgsfield-standard` | Ver dashboard |
| `higgsfield-turbo` | Ver dashboard |


## Uso

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="higgsfield-lite",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

<Note>
Los precios mostrados son precios de la plataforma (~70% de las tarifas oficiales).
</Note>
