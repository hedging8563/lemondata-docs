## ¿Qué es LemonData?

LemonData es una plataforma de agregación de APIs de AI que te ofrece acceso unificado a **más de 300 modelos de AI** de proveedores como OpenAI, Anthropic, Google, DeepSeek, Moonshot, MiniMax y más.

## Capacidades Compatibles

| Capacidad | Descripción | Modelos de Ejemplo |
|------------|-------------|----------------|
| **Chat y Razonamiento** | Generación de texto, planificación, herramientas | `gpt-5.4`, `claude-sonnet-4-6`, `deepseek-r1` |
| **Visión** | Comprensión de imágenes y chat multimodal | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |
| **Generación de Imágenes** | Texto a imagen y edición de imágenes | `dall-e-3`, `flux-pro`, `midjourney` |
| **Generación de Video** | Texto/imagen a video | `sora`, `runway`, `kling` |

| **Embeddings** | Vectorización de texto | `text-embedding-3-small`, `text-embedding-3-large` |
| **Música** | Generación de música con AI | `suno` |
| **3D** | Generación de assets 3D | `tripo3d` |

## Un Buen Punto de Partida Predeterminado

Para proyectos nuevos, comienza con el SDK de OpenAI más la **Responses API**:

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```
