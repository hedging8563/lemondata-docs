## Resumen

LemonData proporciona acceso a modelos de generación de video de 11 proveedores a través de una única API unificada. La generación de video es **asíncrona**: envías una solicitud, recibes un ID de tarea y `poll_url`, y luego consultas periódicamente el resultado.

<Info>
La lista de modelos se actualiza con frecuencia. Para ver los modelos disponibles más recientes y los precios, visita la [página de Modelos](https://lemondata.cc/es/models) o usa la [API de Modelos](/api-reference/models/list-models).
</Info>

<Warning>
Audio behavior is model-dependent. Veo 3 family defaults to audio-on. Some models are silent by default or silent-only. For passthrough-governed models, pass `output_audio=true` to make a best-effort upstream audio request.
</Warning>


### Flujo asíncrono

```mermaid
sequenceDiagram
    participant Client
    participant LemonData
    participant Provider

    Client->>LemonData: POST /v1/videos/generations
    LemonData->>Provider: Forward request
    Provider-->>LemonData: task_id + pending
    LemonData-->>Client: { task_id, poll_url, status: "pending" }

    loop Poll every 5-10s
        Client->>LemonData: GET poll_url
        LemonData->>Provider: Query status
        Provider-->>LemonData: Status update
        LemonData-->>Client: { status, video_url? }
    end
```

<CodeGroup>

```python Python
import requests
import time

API_KEY = "sk-your-api-key"
BASE = "https://api.lemondata.cc/v1"
headers = {"Authorization": f"Bearer {API_KEY}"}

# Step 1: Submit generation request
resp = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
create_data = resp.json()
task_id = create_data["task_id"]
poll_url = create_data["poll_url"]

# Step 2: Poll for result
while True:
    status = requests.get(f"https://api.lemondata.cc{poll_url}", headers=headers).json()
    if status["status"] in ("completed", "succeeded"):
        print(f"Video URL: {status['video_url']}")
        break
    elif status["status"] == "failed":
        print(f"Failed: {status.get('error')}")
        break
    time.sleep(10)
```

```javascript JavaScript
const API_KEY = 'sk-your-api-key';
const BASE = 'https://api.lemondata.cc/v1';
const headers = { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' };

// Step 1: Submit
const { task_id, poll_url } = await fetch(`${BASE}/videos/generations`, {
  method: 'POST', headers,
  body: JSON.stringify({
    model: 'sora-2',
    prompt: 'A calm cinematic shot of a cat walking through a sunlit garden.',
    operation: 'text-to-video',
    duration: 4,
    aspect_ratio: '16:9'
  })
}).then(r => r.json());

// Step 2: Poll
const poll = setInterval(async () => {
  const status = await fetch(`https://api.lemondata.cc${poll_url}`, { headers }).then(r => r.json());
  if (['completed', 'succeeded'].includes(status.status)) {
    console.log('Video URL:', status.video_url);
    clearInterval(poll);
  } else if (status.status === 'failed') {
    console.error('Failed:', status.error);
    clearInterval(poll);
  }
}, 10000);
```

### Definiciones de capacidades

- **T2V (Text-to-Video)**: Genera video a partir de un prompt de texto
- **I2V (Image-to-Video)**: Anima una imagen estática y la convierte en video. Para la compatibilidad más amplia, proporciona una `image_url` pública.
- **Keyframe**: Controla los fotogramas inicial y final con `start_image` + `end_image`
- **Extension**: Extiende la duración de un video existente
- **Editing**: Modifica aspectos específicos de un video existente

## Ejemplos de uso

### Text-to-Video (T2V)

El caso de uso más común. Todos los modelos admiten esto.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
```

### Image-to-Video (I2V)

Anima una imagen estática. Para obtener la compatibilidad más amplia entre los modelos de video, aloja la imagen fuente y pasa `image_url`.

```python
# Using image URL
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/portrait.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)

```

### Control por keyframe (imagen inicial + final)

Controla tanto el primer como el último fotograma para lograr transiciones precisas. Actualmente es compatible con Seedance 2.0.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night, city lights gradually turning on",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/city-day.jpg",
        "end_image": "https://example.com/city-night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```

### Extensión de video

Extiende la duración de un video existente. Usa modelos con capacidad de extensión.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "kling-video-extend",
        "prompt": "Continue the scene naturally",
        "image_url": "https://example.com/last-frame.jpg"
    }
)
```

## Referencia de parámetros

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | ID del modelo (predeterminado: `sora-2`) |
| `prompt` | string | **Obligatorio.** Descripción de texto del video |
| `image_url` | string | URL de la imagen inicial (para I2V) |
| `image` | string | Imagen inline como data URL. Compatible con modelos compatibles, pero `image_url` ofrece la compatibilidad más amplia. |
| `duration` | integer | Duración del video en segundos (1-60, según el modelo) |
| `aspect_ratio` | string | `16:9`, `9:16`, `1:1`, etc. |
| `resolution` | string | `1080p`, `720p`, `4k` |
| `fps` | integer | Fotogramas por segundo (1-120) |
| `negative_prompt` | string | Qué se debe evitar en la generación |
| `seed` | integer | Semilla aleatoria para reproducibilidad |
| `cfg_scale` | number | Escala de guidance (0-20) |
| `motion_strength` | number | Intensidad de movimiento (0-1) |
| `start_image` | string | URL del keyframe inicial |
| `end_image` | string | URL del keyframe final |

<Warning>
No todos los parámetros son compatibles con todos los modelos. Los parámetros no compatibles se ignoran silenciosamente. Consulta la documentación del modelo para ver los parámetros compatibles.
</Warning>

## Facturación

La generación de video usa **precios fijos por generación**. Se te cobra una sola vez cuando se envía la tarea, independientemente de la duración del video. Si la generación falla, el cargo se reembolsa automáticamente.

Consulta los precios actuales en la [página de Modelos](https://lemondata.cc/es/models) o mediante la [API de precios](/api-reference/pricing/get-pricing).
