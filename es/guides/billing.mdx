## Resumen general

LemonData utiliza **precios de pago por uso**. Solo pagas por lo que usas, sin suscripciones ni compromisos mínimos.

## Cómo funciona la facturación

1. **Añade créditos** a tu cuenta
2. **Usa la API** - los costos se deducen por solicitud
3. **Supervisa el uso** en tu dashboard
4. **Recarga saldo** cuando tu balance sea bajo

### Facturación de tareas asíncronas (Video/Música/3D)

<Warning>
  **Importante**: Las tareas de generación de video, música y 3D se **facturan en el momento del envío**, no al completarse.
</Warning>

Para tareas de generación asíncrona (video, música, modelos 3D):

1. **La facturación ocurre inmediatamente** cuando envías la tarea
2. Para consultar el estado, sigue primero el `poll_url` devuelto y trata `task_id` como la identidad de la tarea asíncrona
3. **No hay reembolsos automáticos** si la tarea falla

Esto se debe a que los proveedores upstream nos cobran cuando se envía la tarea, independientemente del resultado. Si experimentas fallos en las tareas, contacta con support@lemondata.cc para obtener ayuda.

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

poll_url = response.json()["poll_url"]
task_id = response.json()["task_id"]
# Usa poll_url para consultar el estado...
```

## Conteo de tokens

Los tokens son las unidades básicas del procesamiento de texto:

- ~4 caracteres = 1 token (inglés)
- ~1-2 caracteres = 1 token (chino)
- 1 imagen = varía según el tamaño y el nivel de detalle

### Estimación de tokens

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## Optimización de costos

## Alertas de balance bajo

Configura alertas cuando tu balance disminuya:

1. Ve a **Dashboard → Settings → Notifications**
2. Establece el monto de tu umbral
3. Recibe notificaciones por correo electrónico

## Añadir créditos

### Métodos de pago

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### Pasos

1. Inicia sesión en [Dashboard](https://lemondata.cc/dashboard)
2. Haz clic en **Add Credits**
3. Selecciona el monto y el método de pago
4. Completa el pago

Los créditos se añaden al instante después de la confirmación del pago.

## Límites de API keys

Puedes establecer límites de gasto en API keys individuales:

1. Ve a **Dashboard → API Keys**
2. Haz clic en una key para editarla
3. Configura **Usage Limit**

Cuando se alcance el límite, las solicitudes con esa key devolverán `402 Payment Required`.

## Facturas

Para cuentas empresariales, hay facturas disponibles:

1. Ve a **Dashboard → Billing**
2. Consulta el historial de transacciones
3. Descarga las facturas en PDF
