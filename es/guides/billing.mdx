## Resumen

LemonData utiliza un **modelo de precios de pago por uso**. Solo paga por lo que utiliza, sin suscripciones ni compromisos mínimos.

## Cómo funciona la facturación

1. **Añada créditos** a su cuenta
2. **Use la API** - los costes se deducen por solicitud
3. **Monitoree el uso** en su panel de control
4. **Recargue** cuando su saldo sea bajo

### Facturación de tareas asíncronas (Vídeo/Música/3D y algunos modelos de imagen)

<Warning>
  **Importante**: Las tareas de generación de vídeo, música y 3D se **facturan en el momento del envío**, no al finalizar. Algunos modelos de imagen también pueden devolver respuestas basadas en tareas y deben tratarse de la misma manera cuando lo hagan.
</Warning>

Para flujos de generación basados en tareas (vídeo, música, 3D y algunos modelos de imagen):

1. **La facturación ocurre inmediatamente** al enviar la tarea
2. Siga la `poll_url` devuelta para comprobar el estado y trate `task_id` como la identidad de la tarea asíncrona
3. **No hay reembolsos automáticos** si la tarea falla

Esto se debe a que los proveedores ascendentes nos cobran cuando se envía la tarea, independientemente del resultado. Si experimenta fallos en las tareas, póngase en contacto con support@lemondata.cc para obtener ayuda.

})
# ⚠️ Se le factura AHORA, no cuando el vídeo esté listo

poll_url = response.json()["poll_url"]

### ID de transacción de facturación

Las respuestas JSON facturables y no streaming incluyen `billing_transaction_id` cuando la liquidación se completa antes de finalizar la respuesta. El mismo valor también se expone en el header `X-Billing-Transaction-ID`, para integraciones en navegador y servidor. Para tareas multimedia asíncronas, consulta el `poll_url` devuelto o `GET /v1/tasks/{id}`; la respuesta de la tarea incluye `billing_transaction_id` cuando la liquidación termina. Las respuestas streaming pueden liquidarse después de que el stream ya fue enviado; si el header no está presente, usa los logs de uso del dashboard para reconciliación.

## Conteo de tokens

Los tokens son las unidades básicas del procesamiento de texto:

- ~4 caracteres = 1 token (Inglés)
- ~1-2 caracteres = 1 token (Chino)
- 1 imagen = varía según el tamaño y el detalle

### Estimación de tokens

```python
# Estimación aproximada
def estimate_tokens(text):
    return len(text) / 4  # Aproximado para inglés

# Conteo real (para modelos de OpenAI)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

Monitoree su uso en el [Panel de control](https://lemondata.cc/dashboard):

## Optimización de costes

<AccordionGroup>
  <Accordion title="Use modelos adecuados">

  </Accordion>

    Almacene en caché las respuestas para solicitudes idénticas repetidas.

    Mantenga los prompts concisos manteniendo la claridad.

## Alertas de saldo bajo

Configure alertas para cuando su saldo disminuya:

1. Vaya a **Panel de control → Configuración → Notificaciones**
2. Establezca su cantidad de umbral
3. Reciba notificaciones por correo electrónico

## Añadir créditos

### Métodos de pago

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### Pasos

1. Inicie sesión en el [Panel de control](https://lemondata.cc/dashboard)
2. Haga clic en **Añadir créditos**
3. Seleccione la cantidad y el método de pago
4. Complete el pago

Los créditos se añaden instantáneamente tras la confirmación del pago.

## Límites de claves API

Puede establecer límites de gasto en claves API individuales:

1. Vaya a **Panel de control → Claves API**
2. Haga clic en una clave para editarla
3. Establezca el **Límite de uso**

Cuando se alcance el límite, las solicitudes con esa clave devolverán `402 Payment Required`.

## Facturas

Para cuentas de empresa, las facturas están disponibles:

1. Vaya a **Panel de control → Facturación**
2. Vea el historial de transacciones
3. Descargue las facturas como PDF
