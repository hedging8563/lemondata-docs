---
title: "Obtener estado de la tarea"
description: "Recupera el estado y el resultado de cualquier tarea async usando el poll_url devuelto por los endpoints de creación"
---

## Descripción general

Usa este endpoint para un sondeo async unificado entre tipos de tareas como generación de video, imagen, música y 3D.

<Info>
Si una respuesta de creación incluye `poll_url`, llama a esa ruta exacta. Para flujos de trabajo async más recientes, `poll_url` puede apuntar a `/v1/tasks/{id}`.
</Info>

## Parámetros de ruta

<ParamField path="id" type="string" required>
  El ID de la tarea devuelto por la solicitud de creación.
</ParamField>

## Respuesta

<ResponseField name="id" type="string">
  Identificador canónico de la tarea asíncrona.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias del identificador de tarea asíncrona.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling prioritaria devuelta por la respuesta de creación.
</ResponseField>

<ResponseField name="status" type="string">
  Estado de la tarea, como `pending`, `processing`, `completed` o `failed`.
</ResponseField>

<ResponseField name="progress" type="number">
  Porcentaje de progreso cuando está disponible.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL del recurso resultante cuando la tarea se completa y produce un video.
</ResponseField>

<ResponseField name="video" type="object">
  Objeto de video único con `url`, `duration`, `width` y `height` cuando está disponible.
</ResponseField>

<ResponseField name="videos" type="array">
  Arreglo de videos cuando el upstream devuelve más de una salida.
</ResponseField>

<ResponseField name="error" type="string">
  Mensaje de error cuando la tarea falla.
</ResponseField>

<ResponseField name="created" type="integer">
  Marca de tiempo de creación cuando está disponible.
</ResponseField>

<ResponseField name="updated" type="integer">
  Marca de tiempo de la última actualización cuando está disponible.
</ResponseField>

<ResponseField name="model" type="string">
  Modelo usado cuando está disponible.
</ResponseField>

## Ejemplos

```bash cURL
curl "https://api.lemondata.cc/v1/tasks/video_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

poll_url = "/v1/tasks/video_abc123"
response = requests.get(
    f"https://api.lemondata.cc{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/video_abc123';
const response = await fetch(`https://api.lemondata.cc${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
