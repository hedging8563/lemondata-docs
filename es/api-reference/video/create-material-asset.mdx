---
title: "Crear activo de material"
openapi: "POST /v1/videos/assets"
description: "Sube un activo de material de Seedance a un grupo de materiales de TokenLab."
---

Importe una URL de origen accesible públicamente a un grupo de materiales de Seedance. TokenLab almacena el material para su uso posterior; utilice el `id` del activo de material devuelto para la generación, no la URL de origen.

Para `library_type: "aigc_avatar"`, `group_id` es opcional; TokenLab utiliza o crea el grupo de avatares virtuales predeterminado de la organización. Para `library_type: "liveness_face"`, `group_id` es obligatorio y debe ser el grupo de TokenLab devuelto por [Obtener resultado de validación visual](/es/api-reference/video/get-visual-validation-result).

| Tipo | Entrada admitida |
|------|-----------------|
| Imagen | `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; relación de aspecto `(0.4, 2.5)`; ancho y alto `(300, 6000)` px; menos de 30 MB. |
| Video | `mp4`, `mov`; `480p`, `720p` o `1080p`; 2-15 segundos; relación de aspecto `[0.4, 2.5]`; ancho y alto `[300, 6000]` px; píxeles totales entre 409600 y 2068676; hasta 200 MB; 24-60 FPS. |
| Audio | `aac`, `wav`, `mp3`; 2-15 segundos; hasta 15 MB. |

La creación es asíncrona. Realice consultas a [Obtener activo de material](/es/api-reference/video/get-material-asset) hasta que el `status` sea `ACTIVE`. Para grupos de personas reales, un grupo se asigna a una persona verificada; las subidas con múltiples rostros o un rostro que no coincida con la persona verificada pueden fallar.

## Ejemplo de solicitud

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"group-20260720123456-vrt01","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view"}'
```

## Ejemplo de respuesta

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
