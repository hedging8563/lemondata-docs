---
title: "Vincular resultado de verificación de persona real"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "Vincula un resultado exitoso de verificación de material de persona real a un grupo de material de TokenLab."
---

Vincule el resultado exitoso de la verificación y cree la asignación del grupo de material de persona real de TokenLab. Utilice el `session_id` y el `verification_token` de la sesión de verificación o del redireccionamiento de callback de TokenLab.

TokenLab verifica que la sesión pertenezca a la misma organización, no haya expirado y esté vinculada al mismo servicio de material utilizado por la sesión de verificación. La respuesta devuelve únicamente un `group_id` de TokenLab; utilícelo al crear activos de material `liveness_face`.

## Ejemplo de solicitud

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## Ejemplo de respuesta

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "seedance_group_real_123",
  "material_group": {
    "id": "seedance_group_real_123",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
