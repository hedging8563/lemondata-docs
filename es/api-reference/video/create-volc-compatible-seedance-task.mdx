## Resumen

Estos endpoints son para equipos que ya usan la forma de tarea Seedance estilo Volc. La autenticación usa tu API key Bearer de TokenLab. El ID devuelto empieza con `cgt-`; consulta el estado hasta que `status` sea `succeeded`, `failed`, `cancelled` o `expired`.

También puedes llamar al dispatcher Action con `CreateContentsGenerationsTasks`, `GetContentsGenerationsTask`, `ListContentsGenerationsTasks` o `DeleteContentsGenerationsTasks`. `Action` y `Version` no distinguen mayúsculas. `Version` puede omitirse; si se envía, debe ser `2024-01-01`.

`callback_url` no se acepta en esta versión. Consulta el estado de la tarea para no perder eventos de finalización.

Ver también [Modelos de video Seedance 2.0](/es/guides/seedance-2-video) y [Generación de video](/es/guides/video-generation).

## Reglas de contenido

- Usa `type=text` para el texto del prompt.
- `type=image_url` sin `role` se trata como el primer frame; también puedes indicar `role=first_frame`.
- Usa `role=last_frame` solo junto con un primer frame.
- Usa `role=reference_image`, `reference_video` o `reference_audio` para medios de referencia.
- No mezcles entradas de primer/último frame con medios de referencia en una misma solicitud.

## Notas de parámetros

- `ratio` acepta `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9` o `adaptive`.
- `generate_audio` tiene valor predeterminado `true`; usa `false` para un video sin audio.
- `service_tier=default` se acepta. Las tareas compatibles con Seedance 2.0 rechazan `service_tier=flex`, `frames` y `camera_fixed=true`.
- Cuando el modelo seleccionado lo admita, `tools` puede incluir objetos como `{ "type": "web_search" }`. Las entradas tool mal formadas se rechazan en vez de ignorarse.

## Ejemplo

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [
      {"type": "text", "text": "A cinematic forest at sunset"},
      {"type": "image_url", "role": "reference_image", "image_url": {"url": "https://example.com/ref.png"}}
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p",
    "generate_audio": true
  }'
```
