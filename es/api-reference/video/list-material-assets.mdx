---
title: "Listar activos de material"
openapi: "GET /v1/videos/assets"
description: "Enumera los activos de material de Seedance propiedad de la organización actual."
---

Enumera los activos de material propiedad de la organización autenticada. Filtre por `library_type`, `group_id` o `status` cuando necesite encontrar activos para un flujo de trabajo de generación específico.

Utilice únicamente activos cuyo `status` sea `ACTIVE`. Trate `asset_url` como información de origen de carga o inspección, no como una dirección de material a largo plazo.

## Ejemplo de solicitud

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=seedance_group_virtual_123&page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Ejemplo de respuesta

```json
{
  "assets": [
    {
      "id": "seedance_asset_123",
      "object": "seedance.material_asset",
      "group_id": "seedance_group_virtual_123",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
