---
title: "Obtener activo de material"
openapi: "GET /v1/videos/assets/{assetId}"
description: "Recupera un activo de material de Seedance mediante el ID de activo de material de TokenLab."
---

Recupere un activo de material e inspeccione su estado de procesamiento. El activo solo puede utilizarse para la generación de video cuando `ready` es `true` y `status` es `ACTIVE`.

Si la generación de video devuelve `Seedance material asset not found or not accessible`, verifique que haya pasado el `id` de este activo de material y no el `group_id` del material.

## Ejemplo de solicitud

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Ejemplo de respuesta

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
