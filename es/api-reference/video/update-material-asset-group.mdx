---
title: "Actualizar grupo de activos de material"
openapi: "PUT /v1/videos/assets/groups/{groupId}"
description: "Actualiza un grupo de material de Seedance propiedad de la organización actual."
---

Actualice el nombre para mostrar, la descripción o los metadatos de un grupo de material. Para grupos de personas reales gestionados, la asignación de persona verificada permanece sin cambios.

## Ejemplo de solicitud

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"group_name":"Updated references","description":"Images approved for summer videos"}'
```

## Ejemplo de respuesta

```json
{
  "id": "seedance_group_virtual_123",
  "object": "seedance.material_asset_group",
  "library_type": "aigc_avatar",
  "group_name": "Updated references",
  "description": "Images approved for summer videos",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
