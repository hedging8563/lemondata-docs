title: "Crear video"
openapi: "POST /v1/videos/generations"
description: "Crea una tarea de generación de video"
---

## Resumen

La generación de video es asíncrona. Envías una solicitud, recibes un ID de tarea y `poll_url`, y luego haces polling para obtener el resultado.

<Info>
Para el comportamiento de polling más confiable, sigue exactamente el `poll_url` devuelto por la solicitud de creación.
</Info>

## Cuerpo de la solicitud

<ParamField body="model" type="string" default="sora-2">
  ID del modelo de video. El valor predeterminado de la API es `sora-2`. Consulta la [Guía de generación de video](/guides/video-generation) para ver la matriz actual de modelos y las capacidades compatibles.
</ParamField>

<ParamField body="prompt" type="string" required>
  Descripción de texto del video que se va a generar.
</ParamField>

<ParamField body="image_url" type="string">
  URL de acceso público de la imagen inicial para la generación de image-to-video (I2V). Para la mejor compatibilidad entre modelos, se prefiere `image_url`.
</ParamField>

<ParamField body="image" type="string">
  Imagen inline como una data URL (por ejemplo, `data:image/jpeg;base64,...`). Compatible con modelos compatibles, pero `image_url` proporciona la compatibilidad más amplia entre modelos de video.
</ParamField>

<ParamField body="duration" type="integer">
  Duración del video en segundos (depende del modelo).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Relación de aspecto (p. ej., `16:9`, `9:16`, `1:1`).
</ParamField>

<ParamField body="resolution" type="string">
  Resolución del video (p. ej., `1080p`, `720p`).
</ParamField>

<ParamField body="fps" type="integer">
  Fotogramas por segundo (1-120).
</ParamField>

<ParamField body="negative_prompt" type="string">
  Qué evitar en la generación del video.
</ParamField>

<ParamField body="seed" type="integer">
  Semilla aleatoria para una generación reproducible.
</ParamField>

<ParamField body="cfg_scale" type="number">
  Escala de guía sin clasificador (0-20).
</ParamField>

<ParamField body="motion_strength" type="number">
  Intensidad del movimiento (0-1).
</ParamField>

<ParamField body="start_image" type="string">
  URL de la imagen del fotograma inicial.
</ParamField>

<ParamField body="end_image" type="string">
  URL de la imagen del fotograma final.
</ParamField>

<ParamField body="user" type="string">
  Un identificador único para el usuario final.
</ParamField>

## Respuesta

<ResponseField name="task_id" type="string">
  Identificador único de la tarea para polling.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling recomendada para esta tarea. Usa esta ruta exacta al verificar el estado.
</ResponseField>

<ResponseField name="status" type="string">
  Estado inicial: `pending`.
</ResponseField>

<ResponseField name="model" type="string">
  Modelo usado.
</ResponseField>

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":    "sora-2",
        "prompt":   "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/videos/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Poll URL: %s\n", result["poll_url"])
    fmt.Printf("Task ID: %s\n", result["task_id"])
}

response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",

```

## Control de keyframes

Usa `start_image` y `end_image` para controlar el primer y el último fotograma (compatible con Vidu Q2 Pro):

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/day.jpg",
        "end_image": "https://example.com/night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```
