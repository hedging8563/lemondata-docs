## Resumen

Estos endpoints son para equipos que ya usan la forma de tarea Seedance estilo Volc. La autenticación usa tu API key Bearer de TokenLab. El ID devuelto empieza con `cgt-`; consulta el estado hasta que `status` sea `succeeded`, `failed`, `cancelled` o `expired`.

Ver también [Modelos de video Seedance 2.0](/es/guides/seedance-2-video) y [Generación de video](/es/guides/video-generation).

## Forma de respuesta

La respuesta de tarea usa `queued`, `running`, `succeeded`, `failed`, `cancelled` o `expired`. Las tareas exitosas devuelven `content.video_url`; cuando están disponibles también aparecen `content.last_frame_url`, parámetros reflejados como `return_last_frame` y `watermark`, `usage` y `progress`. `error` es `null` si no hay fallo.

## Ejemplo

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
