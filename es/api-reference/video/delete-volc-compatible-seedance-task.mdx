openapi: "DELETE /api/v3/contents/generations/tasks/{id}"
description: "Cancela una tarea Seedance compatible en cola cuando todavía puede cancelarse."
---

## Resumen

Estos endpoints son para equipos que ya usan la forma de tarea Seedance estilo Volc. La autenticación usa tu API key Bearer de TokenLab. El ID devuelto empieza con `cgt-`; consulta el estado hasta que `status` sea `succeeded`, `failed`, `cancelled` o `expired`.

Ver también [Modelos de video Seedance 2.0](/es/guides/seedance-2-video) y [Generación de video](/es/guides/video-generation).

## Forma de respuesta

Una cancelación exitosa devuelve HTTP 200 con cuerpo vacío. Consulta la tarea después si necesitas confirmar su estado final.

## Ejemplo

```bash
curl -X DELETE https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
