---
title: "Actualizar activo de material"
openapi: "PUT /v1/videos/assets/{assetId}"
description: "Actualiza un activo de material de Seedance propiedad de la organización actual."
---

Actualice el nombre del material o los metadatos. La URL de origen y el tipo de activo son fijos después de la creación; cree un nuevo activo cuando cambie el archivo de origen.

## Ejemplo de solicitud

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"}}'
```

## Ejemplo de respuesta

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view approved",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
