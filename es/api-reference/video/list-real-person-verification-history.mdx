---
title: "Listar historial de verificación de persona real"
openapi: "GET /v1/videos/assets/visual-validation-sessions"
description: "Enumera las sesiones de verificación de material de persona real para la organización actual."
---

Enumere las sesiones de verificación anteriores para revisión, atención al cliente y conciliación. Este historial es de larga duración, pero no reemplaza el paso de vinculación (bind) de corta duración: una verificación exitosa aún debe vincularse inmediatamente dentro de la ventana de 120 segundos.

La respuesta incluye solo IDs de TokenLab y no incluye datos de credenciales. Después de que una vinculación tiene éxito, `group_id` es el ID del grupo de material de TokenLab utilizado para las cargas de `liveness_face`.

## Ejemplo de solicitud

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions?page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
