---
title: "Crear sesión de validación visual"
openapi: "POST /api/v3"
description: "Crea una sesión de validación visual de persona real con formato compatible con Volc."
---

Cree una sesión de validación visual antes de cargar materiales `liveness_face` reutilizables. TokenLab utiliza el formato de la API Action de Volc y la autenticación Bearer de TokenLab.

## Endpoint y autenticación

```text
POST https://api.tokenlab.sh/api/v3?Action=CreateVisualValidateSession&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

No se aceptan firmas AK/SK de Volc. `CallbackURL` es obligatorio y debe ser una URL HTTPS pública. `ProjectName` es opcional y su valor predeterminado es `default`.

## Flujo

1. Guarde `Result.BytedToken` y abra `Result.H5Link` para la persona que se verificará.
2. Para seleccionar el idioma de H5, añada `lng` a `H5Link`, por ejemplo `&lng=en`. El idioma no es un campo del cuerpo de la solicitud.
3. Al finalizar el flujo H5, el navegador abre `Result.CallbackURL`. La consulta de callback puede contener `bytedToken`, `resultCode`, `algorithmBaseRespCode`, `reqMeasureInfoValue` y `verify_type`.
4. Consulte [Obtener resultado de validación visual](/es/api-reference/video/get-visual-validation-result) con el `BytedToken` guardado hasta que se devuelva `Result.GroupId`.

`BytedToken` es válido durante 30 minutos y está vinculado a la organización autenticada y a `ProjectName`. El enlace H5 admite una única verificación completada y deja de ser válido después de usarse.

Trate `Result.H5Link` como una URL de navegador opaca: ábrala como página de nivel superior y no la analice, decodifique, reescriba ni incruste. TokenLab gestiona la entrega al navegador y el puente de callback.

## Ejemplo de solicitud

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=CreateVisualValidateSession&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"CallbackURL":"https://yourapp.example.com/seedance/callback","ProjectName":"default"}'
```

## Ejemplo de respuesta

```json
{
  "ResponseMetadata": {
    "RequestId": "req_abc123",
    "Action": "CreateVisualValidateSession",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "BytedToken": "ZXhhbXBsZS10b2tlbg",
    "H5Link": "https://api.tokenlab.sh/api/v3/visual-validation/sessions/svv_example/h5?Version=2024-01-01",
    "CallbackURL": "https://yourapp.example.com/seedance/callback"
  }
}
```

Los errores utilizan la misma estructura superior. Lea `ResponseMetadata.Error.Code` y `ResponseMetadata.Error.Message` en lugar de esperar los campos de error de otras API `/v1` de TokenLab.
