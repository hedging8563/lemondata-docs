---
title: "Crear imagen"
openapi: "POST /v1/images/generations"
description: "Crea una imagen a partir de un prompt"
---

<Note>
Para agentes de código, descubre primero la lista corta recomendada de imágenes con `GET /v1/models?recommended_for=image`, y luego envía explícitamente el `model` elegido a este endpoint.
</Note>

<Note>
Los modelos de la familia de imágenes de Google Gemini no comparten el mismo contrato de selección:

- `gemini-3-pro-image-preview` y `nano-banana-pro` admiten `aspect_ratio` junto con `resolution` (`1k`, `2k`, `4k`).
- `gemini-2.5-flash-image`, `gemini-3.1-flash-image-preview`, `nano-banana` y `nano-banana-edit` admiten `aspect_ratio`, pero no exponen selección pública de `resolution`.
- `gemini-2.0-flash-preview-image-generation` se documenta aquí como texto a imagen solo por prompt.

Para las familias de imágenes de Google, prefiere `aspect_ratio` y envía `resolution` solo cuando el modelo lo admita explícitamente.
</Note>

## Cuerpo de la solicitud

<ParamField body="model" type="string" default="dall-e-3">
  Modelo a usar (por ejemplo, `dall-e-3`, `flux-pro`, `midjourney`).
</ParamField>

<ParamField body="prompt" type="string" required>
  Descripción textual de la imagen deseada.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Número de imágenes a generar (1-10, según el modelo).
</ParamField>

<ParamField body="size" type="string" default="1024x1024">
  Tamaño de la imagen. Úsalo para familias de imágenes al estilo OpenAI y otros modelos que aceptan tamaños exactos en píxeles.

  Para las familias de imágenes de Google Gemini, `size` actúa como un alias de compatibilidad que se mapea al contrato público de `aspect_ratio` y, cuando está disponible, `resolution`. Para esos modelos, prefiere enviar `aspect_ratio` directamente.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Selector de relación de aspecto dependiente del modelo.

  Los valores comunes en familias de imágenes de Google incluyen `1:1`, `16:9`, `9:16`, `3:2` y `2:3`.
</ParamField>

<ParamField body="resolution" type="string">
  Selector de resolución de salida dependiente del modelo.

  Se admite en `gemini-3-pro-image-preview`, `nano-banana-pro`, `nano-banana-2` y familias de alta resolución similares. Los valores típicos son `1k`, `2k` y `4k`. No envíes este parámetro a las familias de imágenes Flash de Gemini salvo que el modelo lo documente explícitamente.
</ParamField>

<ParamField body="quality" type="string" default="standard">
  Calidad de la imagen (`standard` o `hd`). Solo para DALL-E 3.
</ParamField>

<ParamField body="response_format" type="string" default="url">
  Formato de respuesta: `url` o `b64_json`.
</ParamField>

<ParamField body="style" type="string" default="vivid">
  Estilo para DALL-E 3: `vivid` o `natural`.
</ParamField>

<ParamField body="user" type="string">
  Un identificador único para el usuario final.
</ParamField>

## Respuesta

### Respuesta en línea

<ResponseField name="created" type="integer">
  Marca de tiempo Unix de creación.
</ResponseField>

<ResponseField name="data" type="array">
  Array de imágenes generadas.

  Cada objeto contiene:
  - `url` (string): URL de la imagen generada
  - `b64_json` (string): Imagen codificada en Base64, si se solicita
  - `revised_prompt` (string): El prompt usado (DALL-E 3)
</ResponseField>

### Respuesta de tarea asíncrona

Algunos modelos de imagen devuelven una tarea asíncrona inmediatamente, y otros pueden comportarse como inline o basados en tarea según la ruta del proveedor. Cuando la respuesta incluye `status: "pending"`, trátala como una respuesta de tarea asíncrona:

<Info>
Usa el `poll_url` devuelto exactamente cuando esté presente. Trata `task_id` como la identidad de la tarea asíncrona para el polling posterior.
</Info>

<ResponseField name="created" type="integer">
  Marca de tiempo Unix de creación.
</ResponseField>

<ResponseField name="task_id" type="string">
  Identificador único de la tarea para polling.
</ResponseField>

<ResponseField name="status" type="string">
  Estado inicial: `pending`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL relativa para consultar resultados (por ejemplo, `/v1/tasks/{id}`).
</ResponseField>

<ResponseField name="data" type="array">
  Array con datos de marcador de posición. `url` estará vacío hasta completarse.
</ResponseField>

<Note>
Cuando recibas `status: "pending"`, usa el endpoint [Get Image Status](/api-reference/images/get-image-status) para hacer polling del resultado.
</Note>

## Available Models

| Modelo | Tipo | Funciones |
|-------|------|----------|
| `dall-e-3` | Normalmente inline | Mejor calidad, mejora de prompt |
| `dall-e-2` | Normalmente inline | Más rápido, más económico |
| `flux-pro` | A menudo basado en tareas | Fotorrealista, alta calidad |
| `flux-schnell` | Normalmente inline | Muy rápido |
| `midjourney` | A menudo basado en tareas | Estilo artístico |
| `ideogram-v3` | A menudo basado en tareas | Mejor renderizado de texto |
| `stable-diffusion-3` | Normalmente inline | Código abierto, configurable |

<Tip>
No codifiques un modelo como si fuera siempre síncrono o siempre asíncrono. Si la respuesta de creación devuelve `status: "pending"`, sigue `poll_url` y haz polling hasta que termine.
</Tip>

## Manejo de respuestas basadas en tareas

Para los modelos de imagen, comprueba siempre si la respuesta contiene `status: "pending"`:

```python
import requests
import time

def generate_image(prompt, model="midjourney"):
    # Create image request
    response = requests.post(
        "https://api.lemondata.cc/v1/images/generations",
        headers={"Authorization": "Bearer sk-your-api-key"},
        json={"model": model, "prompt": prompt}
    )
    data = response.json()

    # Check if task-based
    if data.get("status") == "pending":
        task_id = data["task_id"]
        poll_url = data.get("poll_url")
        print(f"Image task started: {task_id}")

        # Poll for result
        while True:
            status_resp = requests.get(
                f"https://api.lemondata.cc{poll_url}" if poll_url else f"https://api.lemondata.cc/v1/tasks/{task_id}",
                headers={"Authorization": "Bearer sk-your-api-key"}
            )
            status_data = status_resp.json()

            if status_data["status"] == "completed":
                return status_data["data"][0]["url"]
            elif status_data["status"] == "failed":
                raise Exception(status_data.get("error", "Generation failed"))

            time.sleep(3)
    else:
        # Inline response
        return data["data"][0]["url"]

# Usage
url = generate_image("a beautiful sunset over mountains", model="midjourney")
print(f"Generated image: {url}")
```
