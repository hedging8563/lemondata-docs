## Resumen

Este endpoint devuelve detalles de uso a nivel de clave con filtros por nombre de modelo solicitado (`model`), proveedor de modelo público, `scene` y `accessChannel`.

## Notas

- La respuesta incluye solo campos públicos de facturación.
- El enrutamiento interno y los metadatos del canal físico se ocultan de forma intencionada.

## Solicitud / Respuesta

Utiliza el panel interactivo de OpenAPI arriba para el esquema exacto.
