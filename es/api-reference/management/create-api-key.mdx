---
title: "Crear clave API"
openapi: "POST /v1/management/api-keys"
description: "Crea una nueva clave API de usuario para la organización actual."
---

## Resumen

Crea una nueva clave API `type=user` en la organización asociada al token de administración actual.

## Notas

- La clave completa solo se muestra una vez en la respuesta.

## Solicitud / Respuesta

Utiliza el panel interactivo de OpenAPI arriba para el esquema exacto.
