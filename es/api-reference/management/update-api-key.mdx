title: "Actualizar clave API"
openapi: "PATCH /v1/management/api-keys/{keyId}"
description: "Actualiza una clave API de usuario existente para la organización actual."
---

## Resumen

Usa este endpoint para actualizar el nombre, el límite de uso, los modelos permitidos, la expiración o el estado de una clave API de usuario existente.

## Notas

- La eliminación definitiva no está soportada en API de administración v1.

## Solicitud / Respuesta

Utiliza el panel interactivo de OpenAPI arriba para el esquema exacto.
