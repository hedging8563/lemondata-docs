## Resumen

La API de administración te permite gestionar claves API de la organización y consultar el uso y la facturación de una clave específica sin usar una clave API de inferencia estándar.

Usa un token de administración desde la página **Settings** de tu Dashboard:

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
Los tokens de administración no son claves API de inferencia. Usa `mt-...` para `/v1/management/*` y `sk-...` para endpoints de inferencia como `/v1/responses`.
</Warning>

## Endpoints disponibles

| Endpoint | Method | Descripción |
|----------|--------|------|
| `/v1/management/api-keys` | GET | Lista las claves API de usuario de la organización actual |
| `/v1/management/api-keys` | POST | Crea una nueva clave API de usuario |
| `/v1/management/api-keys/{keyId}` | PATCH | Actualiza nombre, límite de uso, modelos permitidos, expiración o estado |
| `/v1/management/api-keys/{keyId}/usage` | GET | Recupera detalles paginados de uso para una clave específica |
| `/v1/management/api-keys/{keyId}/billing` | GET | Recupera desgloses agregados de facturación para una clave específica |

## Significado de los campos

- nombre de modelo solicitado (`model`)
- proveedor de modelo público
- `scene`
- `accessChannel`: `platform` significa que la solicitud se facturó como una solicitud de plataforma; `byok` significa que usó tu propia clave del proveedor upstream
- cantidad de uso, unidad de facturación y métricas de caché
- coste y marcas de tiempo

Las respuestas exponen solo campos públicos de facturación y reporting. Los detalles de enrutamiento interno y los metadatos del proveedor físico permanecen ocultos.

## Filtros

`/usage` y `/billing` admiten actualmente filtros por:

- rango de tiempo
- nombre de modelo solicitado (`model`)
- proveedor de modelo público
- `scene`
- `accessChannel`
- paginación

## Ejemplo completo de solicitud

Empieza listando las claves API de la organización accesibles con el token de administración actual:

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```

```python Python
import requests

response = requests.get(
    "https://api.lemondata.cc/v1/management/api-keys",
    headers={"Authorization": "Bearer mt-your-management-token"}
)

data = response.json()
for key in data["data"]:
    print(key["name"], key["status"], key["used_amount"])
```

```javascript JavaScript
const response = await fetch(
  'https://api.lemondata.cc/v1/management/api-keys',
  {
    headers: {
      'Authorization': 'Bearer mt-your-management-token'
    }
  }
);

const data = await response.json();
for (const key of data.data) {
  console.log(key.name, key.status, key.used_amount);
}
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/management/api-keys", nil)
    req.Header.Set("Authorization", "Bearer mt-your-management-token")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)

    fmt.Println(result["object"])
}
```

```php PHP
<?php
$ch = curl_init("https://api.lemondata.cc/v1/management/api-keys");

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer mt-your-management-token'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
foreach ($data['data'] as $key) {
    echo $key["name"] . " " . $key["status"] . " " . $key["used_amount"] . PHP_EOL;
}
```
</RequestExample>
