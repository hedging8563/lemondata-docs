Todos los puntos de enlace (endpoints) de la API de Claw requieren autenticación a través del encabezado `Authorization: Bearer sk-...`.

**URL base:** `https://api.lemondata.cc/v1/claw`

## Listar instancias

```
GET /v1/claw/instances
```

Devuelve todas las instancias de la organización autenticada.

<RequestExample>
```bash cURL
curl https://api.lemondata.cc/v1/claw/instances \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

resp = requests.get(
    "https://api.lemondata.cc/v1/claw/instances",
    headers={"Authorization": "Bearer sk-your-api-key"}
)
print(resp.json())
```
</RequestExample>

<ResponseExample>
```json 200
{
  "instances": [
    {
      "id": "cm5abc123",
      "subdomain": "mybot",
      "url": "https://claw-mybot.lemondata.cc",
      "status": "RUNNING",
      "paidUntil": "2026-03-10T00:00:00.000Z",
      "canRebuild": true,
      "totalPaid": 20,
      "createdAt": "2026-02-08T00:00:00.000Z"
    }
  ]
}
```
</ResponseExample>

### Valores de estado de la instancia

| Estado | Descripción |
|--------|-------------|
| `PENDING` | Recién creada, esperando provisión |
| `PROVISIONING` | El contenedor se está desplegando |
| `RUNNING` | La instancia está activa y saludable |
| `STOPPED` | Detenida por expiración (datos retenidos por 7 días) |
| `FAILED` | Error en el despliegue (reembolsado automáticamente) |
| `DELETED` | Eliminada permanentemente |

## Crear instancia

```
POST /v1/claw/instances
```

Crea una nueva instancia y cobra **$20** por 30 días del saldo de su organización.

<ParamField body="subdomain" type="string" required>
  Subdominio (3-32 caracteres, alfanuméricos en minúsculas + guiones). URL de la instancia: `https://claw-{subdomain}.lemondata.cc`
</ParamField>


<RequestExample>
```bash cURL
curl -X POST https://api.lemondata.cc/v1/claw/instances \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"subdomain": "mybot"}'
```

```python Python
import requests

resp = requests.post(
    "https://api.lemondata.cc/v1/claw/instances",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={"subdomain": "mybot"}
)
print(resp.json())
```
</RequestExample>

<ResponseExample>
```json 201
{
  "id": "cm5abc123",
  "subdomain": "mybot",
  "url": "https://claw-mybot.lemondata.cc",
  "status": "PENDING",
  "paidUntil": "2026-03-10T00:00:00.000Z",
  "charged": true,
  "chargedAmount": 20
}
```
</ResponseExample>

<Warning>
Un saldo insuficiente devuelve **402 Payment Required**. Asegúrese de que su organización tenga al menos $20 antes de crear una instancia.
</Warning>

## Obtener instancia

```
GET /v1/claw/instances/:id
```

Devuelve los detalles de una instancia específica.


---

## Reconstruir instancia

```
POST /v1/claw/instances/:id/rebuild
```

Destruye y recrea el contenedor preservando los datos (PVC). Limitado a **10 reconstrucciones por día**.

Devuelve **429 Too Many Requests** si se supera el límite diario.

---

## Renovar instancia

```
POST /v1/claw/instances/:id/renew
```

Extiende el período de facturación por 30 días ($20). Si la instancia se detuvo debido a la expiración, se reiniciará automáticamente.

<ResponseExample>
```json 200
{
  "id": "cm5abc123",
  "subdomain": "mybot",
  "status": "RUNNING",
  "paidUntil": "2026-04-09T00:00:00.000Z",
  "charged": true,
  "chargedAmount": 20
}
```
</ResponseExample>

## Health Check

```
GET /v1/claw/health
```

Devuelve el estado de salud del servicio Claw. No se requiere autenticación.

```json
{"status": "ok", "timestamp": "2026-02-08T15:00:00.000Z"}
```
