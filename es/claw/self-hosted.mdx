<Note>
**Self-hosted** significa que usted ejecuta LemonClaw directamente en su propio VPS o máquina. Solo paga por el uso del modelo de IA a través de su saldo de LemonData — sin tarifas de instancia.
</Note>

<Tip>
¿Prefiere una configuración alojada? [Cree una instancia de Claw](/claw/introduction) para obtener el mismo entorno de ejecución y WebUI de LemonClaw sin gestionar servidores usted mismo.
</Tip>

## Instalación Rápida

<CodeGroup>
```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```

```bash No interactivo
LEMONDATA_API_KEY=sk-xxx curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```
</CodeGroup>

El instalador le solicitará su **LemonData API Key**. Obtenga una desde su [Dashboard](https://lemondata.cc/dashboard).

## Qué se instala

<Steps>
  <Step title="Node.js 22+">
    Instalado automáticamente si falta (vía NodeSource en Linux, Homebrew en macOS)
  </Step>
  <Step title="LemonClaw">
    Paquete LemonClaw preconfigurado con la API de LemonData
  </Step>
  <Step title="15 Modelos de IA">
    Claude, GPT-5, Gemini, DeepSeek y más — listos para usar
  </Step>
  <Step title="Plugins de IM">
    Plugins de DingTalk, WeCom y QQ preinstalados
  </Step>
  <Step title="Servicio del Sistema">
    Inicio automático al arrancar (systemd en Linux, launchd en macOS)
  </Step>
</Steps>

## Requisitos

| Requisito | Detalles |
|-------------|---------|
| **SO** | Linux (Ubuntu/Debian/CentOS/RHEL) o macOS |
| **Arquitectura** | x64 o arm64 |
| **RAM** | 1 GB mínimo, 2 GB recomendado |
| **API Key** | [Obtenga una aquí](https://lemondata.cc) |

  Token:        your-gateway-token
  Auto-login:   http://your-ip:18789?token=your-gateway-token
  Model:        claude-sonnet-4-6

<Warning>
**¡Guarde su token!** Lo necesitará para acceder a la WebUI y conectar plataformas de mensajería.
</Warning>

## Comandos de gestión

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user status lemonclaw    # Verificar estado
    journalctl --user -u lemonclaw -f    # Ver logs
    systemctl --user restart lemonclaw   # Reiniciar
    systemctl --user stop lemonclaw      # Detener
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    tail -f ~/.lemonclaw/lemonclaw.log    # Ver logs
    launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # Reiniciar
    launchctl stop cc.lemondata.lemonclaw  # Detener
    ```
  </Tab>
</Tabs>

## Configuración

Ubicación del archivo de configuración: `~/.lemonclaw/config.json`

Después de editar, reinicie el servicio para aplicar los cambios.

### Cambiar el modelo por defecto

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-opus-4-6"
      }
    }
  }
}
```

Prefijos de modelos disponibles:
- `lemondata-claude/` — Modelos Claude (API anthropic-messages)
- `lemondata-minimax/` — Modelos MiniMax (API anthropic-messages)
- `lemondata/` — Todos los demás modelos (API openai-completions)

## Actualización

```bash
# Ejecute de nuevo el instalador para actualizar a la última versión
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
# Luego reinicie el servicio
systemctl --user restart lemonclaw  # Linux
# o
launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # macOS
```

## Desinstalación

```bash
# Detener y desactivar el servicio
systemctl --user stop lemonclaw && systemctl --user disable lemonclaw  # Linux
launchctl unload ~/Library/LaunchAgents/cc.lemondata.lemonclaw.plist  # macOS

# Eliminar LemonClaw
rm -rf ~/.lemonclaw
```

## Self-Hosted vs Gestionado

| | Self-Hosted | Gestionado (Claw) |
|---|---|---|
| **Costo de la instancia** | Gratis | $20 / 30 días |
| **Uso de IA** | Pago por uso | Pago por uso |
| **Infraestructura** | Su servidor | Nosotros gestionamos todo |
| **Actualizaciones** | Manual (re-ejecutar instalador) | Automático |
| **Soporte** | Comunidad | Prioridad |
