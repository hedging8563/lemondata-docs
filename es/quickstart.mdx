## Paso 1: Obtén tu API Key

<Steps>
  <Step title="Crear una cuenta">
    Regístrate en [lemondata.cc](https://lemondata.cc) usando tu correo electrónico, Gmail o cuenta de GitHub.
  </Step>
  <Step title="Agregar créditos">
    Abre el dashboard y agrega créditos a tu cuenta. LemonData utiliza precios de pago por uso sin compromiso mínimo.
  </Step>
  <Step title="Crear una API key">
    Ve a **Dashboard → API Keys** y crea una nueva key. Cópiala de forma segura porque solo se muestra una vez.
  </Step>
</Steps>

<Warning>
Mantén tu API key segura. Nunca la expongas en código del lado del cliente ni en repositorios públicos.
</Warning>

## Paso 3: Haz tu primera solicitud

Para proyectos nuevos, comienza con la **Responses API**.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
Si tu framework o herramienta todavía espera Chat Completions, LemonData también es compatible con `POST /v1/chat/completions`. Para integraciones nuevas, prefiere `POST /v1/responses`.
</Note>

## Prueba diferentes modelos

LemonData es compatible con más de 300 modelos. Cambia solo el campo `model`:

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## Habilita streaming

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
