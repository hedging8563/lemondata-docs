<Note>
This guide is for **self-hosted OpenClaw** users who want to connect LemonData as their AI provider.
</Note>

<Tip>
Want a hosted setup instead? [Create a LemonClaw instance](/claw/introduction) — LemonData is already configured by default, so you can start with the WebUI right away.
</Tip>

## Overview

OpenClaw requires **3 separate providers** to access all LemonData models, because different model families use different API formats:

| Provider | API Format | Models | baseUrl |
|----------|-----------|--------|---------|
| `lemondata` | `openai-completions` | GPT, DeepSeek, Qwen, Gemini, etc. | `https://api.lemondata.cc/v1` |
| `lemondata-claude` | `anthropic-messages` | Claude (Opus, Sonnet, Haiku) | `https://api.lemondata.cc` |
| `lemondata-minimax` | `anthropic-messages` | MiniMax models | `https://api.lemondata.cc` |

<Warning>
Pay attention to the `/v1` suffix. The `lemondata` provider **includes** `/v1` because the OpenAI SDK does not add it automatically. The other two providers **omit** `/v1` because the Anthropic SDK adds it automatically.
</Warning>

## Prerequisites

- A self-hosted OpenClaw instance
- A LemonData API Key — [Get one here](https://lemondata.cc/dashboard)

## Configuration

Edit your OpenClaw provider settings:

- **Self-hosted**: `~/.openclaw/openclaw.json`

Add the following 3 providers to the `providers` array:

```json
{
  "providers": [
    {
      "name": "lemondata",
      "api": "openai-completions",
      "baseUrl": "https://api.lemondata.cc/v1",
      "apiKey": "sk-your-lemondata-key"
    },
    {
      "name": "lemondata-claude",
      "api": "anthropic-messages",
      "baseUrl": "https://api.lemondata.cc",
      "apiKey": "sk-your-lemondata-key"
    },
    {
      "name": "lemondata-minimax",
      "api": "anthropic-messages",
      "baseUrl": "https://api.lemondata.cc",
      "apiKey": "sk-your-lemondata-key"
    }
  ]
}
```

<Info>
All 3 providers use the **same API Key**. You only need one LemonData account.
</Info>

## Using Models

Reference models with the `provider/model` format:

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-sonnet-4-6"
      }
    }
  }
}
```

## Common Mistakes

<AccordionGroup>
  <Accordion title="Wrong baseUrl for Claude models">
    Using `https://api.lemondata.cc/v1` for `lemondata-claude` will cause authentication errors. The Anthropic SDK automatically appends `/v1`, resulting in a double `/v1/v1` path. Use `https://api.lemondata.cc` (no `/v1`) for Anthropic-format providers.
  </Accordion>
  <Accordion title="Using provider name 'openai' instead of 'lemondata'">
    OpenClaw resolves API keys by provider **name**. Using `"name": "openai"` will try to use an OpenAI API key, not your LemonData key. Always use `"name": "lemondata"` (or `lemondata-claude` / `lemondata-minimax`).
  </Accordion>
  <Accordion title="Model not found errors">
    Make sure you're using the correct provider prefix. Claude models must use `lemondata-claude/`, not `lemondata/`. Check the model list at [lemondata.cc/models](https://lemondata.cc/en/models) for the correct model ID.
  </Accordion>
</AccordionGroup>

## Verify Setup

After saving the config, restart your OpenClaw instance and test with a simple message. If you see a response, the provider is configured correctly.

```bash
# Self-hosted: restart the service
systemctl --user restart openclaw    # Linux
launchctl stop cc.lemondata.openclaw && launchctl start cc.lemondata.openclaw  # macOS
```
