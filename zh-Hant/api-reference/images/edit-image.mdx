## 概述

根據原始圖像和提示詞建立編輯或擴展的圖像。

此路由同時支援：

- 下方文件中的經典 `multipart/form-data` DALL-E 風格上傳流程
- 為受支援的圖像到圖像模型提供 `image_url`、`image_urls` 或官方 `images` 參照的 JSON 請求

<Note>
`gpt-image-2` 已支援此端點。它支援 multipart `image` 上傳、JSON `image_url` / `image_urls`，以及官方 `images[]` 參照（`image_url` 或 `file_id`），最多 16 張來源圖。`file_id` 需先透過 `/v1/files` 建立。常用可選參數包含 `mask`、`n`、`size`、`quality`、`response_format`、`output_format` / `output_compression`、`moderation`、`partial_images` 和 `user`。
</Note>

## 請求主體

**同步請求逾時：** 某些路由到的圖片提供者會以内嵌方式返回最終圖片，並等待生成完成。高解析度或高品質請求可能接近一分鐘甚至更久，因此請將 HTTP 用戶端逾時設定為至少 `120s`。如果建立回應包含 `status: "pending"`、`task_id` 或 `poll_url`，請改為依照返回的 `poll_url` 輪詢。

當你傳送 JSON `image_url`、`image_urls` 或 `images[].image_url`，且被選中的上游只接受 multipart 上傳時，LemonData 會先抓取這些圖片 URL，再作為 multipart `image` 檔案轉發給上游。遠端 URL 必須是公網 HTTP(S) 資源，不能依賴 Cookie 或自訂請求標頭，實際內容必須是 PNG、JPEG 或 WebP 圖片位元組；抓取逾時為 `10s`，最多跟隨 `3` 次重新導向，限制為每張 `50MB`、每次請求總計 `200MB`。

<ParamField body="image" type="file">
  multipart 請求中的來源圖片檔案。GPT Image 編輯需要多張來源圖時，可以重複傳送 `image` 欄位。每個檔案必須是 PNG、JPEG 或 WebP，且小於 50MB。傳統 DALL-E 2 遮罩編輯仍要求 PNG 輸入帶透明區域，或額外提供 `mask`。
</ParamField>

<ParamField body="prompt" type="string" required>
  描述所需編輯的文字。
</ParamField>

<ParamField body="mask" type="file">
  一個附加圖像，其完全透明的區域指示應編輯圖像的位置。必須是有效的 PNG 檔案，小於 50MB，且與 `image` 具有相同的尺寸。
</ParamField>

<ParamField body="model" type="string" default="dall-e-2">
  用於圖像編輯的模型。`gpt-image-2` 已支援；傳統 DALL-E 風格編輯仍可使用 `dall-e-2`。
</ParamField>

<ParamField body="n" type="integer" default="1">
  要生成的圖像數量。必須在 1 到 10 之間。
</ParamField>

<ParamField body="size" type="string">
  生成圖像的尺寸。對於 `gpt-image-2`，使用 `auto` 或 `WIDTHxHEIGHT`；寬高必須是 16 的倍數，最長邊不超過 `3840px`，長邊/短邊比例不超過 `3:1`，總像素介於 `655,360` 和 `8,294,400` 之間。傳統 DALL-E 編輯支援 `256x256`、`512x512` 或 `1024x1024`。
</ParamField>

<ParamField body="response_format" type="string" default="url">
  回傳生成圖像的格式。必須是 `url` 或 `b64_json`。
</ParamField>

<ParamField body="user" type="string">
  代表終端使用者的唯一識別碼，用於濫用監控。
</ParamField>

## 回應

<ResponseField name="created" type="integer">
  圖像建立時間的 Unix 時間戳。
</ResponseField>

<ResponseField name="data" type="array">
  生成的圖像陣列。

  每個物件包含：
  - `url` (string): 編輯後圖像的 URL（如果 response_format 是 `url`）
  - `b64_json` (string): Base64 編碼的圖像（如果 response_format 是 `b64_json`）
</ResponseField>

```go Go
package main

import (
    "bytes"
    "fmt"
    "io"
    "mime/multipart"
    "net/http"
    "os"
)

func main() {
    body := &bytes.Buffer{}
    writer := multipart.NewWriter(body)

    image, _ := os.Open("sunlit_lounge.png")
    defer image.Close()
    part, _ := writer.CreateFormFile("image", "sunlit_lounge.png")
    io.Copy(part, image)

    mask, _ := os.Open("mask.png")
    defer mask.Close()
    maskPart, _ := writer.CreateFormFile("mask", "mask.png")
    io.Copy(maskPart, mask)

    writer.WriteField("prompt", "A sunlit indoor lounge area with a pool")
    writer.WriteField("n", "1")
    writer.WriteField("size", "1024x1024")
    writer.Close()

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/images/edits", body)
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", writer.FormDataContentType())

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    result, _ := io.ReadAll(resp.Body)
    fmt.Println(string(result))
}
```

## 注意事項

<Note>
  對 JSON `image_url`、`image_urls` 或 `images[].image_url`，LemonData 只會在所選上游渠道要求檔案上傳時，把 URL 轉成 multipart。私有 URL、需要額外請求標頭的簽名 URL、內網地址、非圖片回應和超限圖片都會在轉發上游前被拒絕。私有素材請直接使用 multipart `image` 上傳，或先建立 `/v1/files` 參照。
</Note>
