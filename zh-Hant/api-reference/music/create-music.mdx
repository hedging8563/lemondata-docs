---
title: "建立音樂"
openapi: "POST /v1/music/generations"
description: "使用 Suno 建立音樂生成任務"
---

使用 AI 生成音樂和歌詞。這是一個非同步 API。建立回應會返回任務身分，並且在可用時返回優先使用的 `poll_url`。

## 請求參數

<ParamField body="model" type="string" default="suno_music">
  要使用的模型：`suno_music` 用於音樂生成，`suno_lyrics` 僅用於歌詞。
</ParamField>

<ParamField body="prompt" type="string">
  生成音樂的描述。音樂、歌詞、upload-cover 和 upload-extend 請求必填；add-instrumental 可省略。
</ParamField>

<ParamField body="title" type="string">
  生成歌曲的標題。
</ParamField>

<ParamField body="tags" type="string">
  風格標籤（例如："pop, upbeat, electronic"）。
</ParamField>

<ParamField body="negative_tags" type="string">
  需要避開的風格。`audio_operation` 為 `add-instrumental` 時必填；會轉發給 KIE 的 `negativeTags`。
</ParamField>

<ParamField body="action" type="string">
  生成類型：`MUSIC`（預設）或 `LYRICS`。
</ParamField>

<ParamField body="mv" type="string">
  官方 Suno 模型版本。音樂生成必填（省略 `action` 或使用 `MUSIC` 時）；僅歌詞請求請省略。支持值：`chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`。
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  設為 `true` 時生成無人聲的純音樂。TokenLab 會把此公開欄位映射到 KIE 的 `instrumental`。請使用 TokenLab 欄位名，例如 `make_instrumental`、`audio_url`、`negative_tags`、`continue_at`；KIE 上游欄位名 `instrumental`、`uploadUrl`、`negativeTags`、`continueAt` 會被拒絕。
</ParamField>

<ParamField body="audio_url" type="string">
  可公開存取的參考/上傳音訊 URL。提供此欄位但不傳 `audio_operation` 時，預設使用 upload-cover 流程。
</ParamField>

<ParamField body="audio_operation" type="string">
  上傳音訊模式：`upload-cover`、`upload-extend` 或 `add-instrumental`。`upload-extend` 需要 `continue_at`；`add-instrumental` 需要 `audio_url`、`title`、`tags` 和 `negative_tags`。
</ParamField>

<ParamField body="continue_clip_id" type="string">
  要續接的前一個片段 ID。
</ParamField>

<ParamField body="continue_at" type="number">
  續寫的起始時間戳（秒）。`audio_operation` 為 `upload-extend` 時必填。
</ParamField>

## 回應

<ResponseField name="id" type="string">
  用於輪詢狀態的任務 ID。
</ResponseField>

<ResponseField name="task_id" type="string">
  適配器返回時的非同步任務 ID 別名。
</ResponseField>

<ResponseField name="poll_url" type="string">
  可用時返回的優先輪詢 URL。
</ResponseField>

<ResponseField name="status" type="string">
  任務狀態：`pending`、`processing`、`completed` 或 `failed`。
</ResponseField>

<ResponseField name="created" type="integer">
  任務建立的 Unix 時間戳記。
</ResponseField>

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno_music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
