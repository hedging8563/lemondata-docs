## 請求本文

<ParamField body="model" type="string" required>
  要使用的模型 ID。可用選項請參閱 [Models](https://lemondata.cc/zh-Hant/models)。
</ParamField>

<ParamField body="messages" type="array" required>
  構成對話的訊息清單。

  每個訊息物件包含：
  - `role` (string)：`system`、`user` 或 `assistant`
  - `content` (string | array)：訊息內容
</ParamField>

<ParamField body="temperature" type="number" default="1">
  介於 0 到 2 之間的取樣溫度。數值越高，輸出越具隨機性。
</ParamField>

<ParamField body="max_tokens" type="integer">
  要產生的最大 token 數量。
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  若為 true，部分訊息增量將以 SSE 事件傳送。
</ParamField>

<ParamField body="stream_options" type="object">
  串流選項。設定 `include_usage: true` 可在 stream chunks 中接收 token 使用量。
</ParamField>

<ParamField body="top_p" type="number" default="1">
  Nucleus sampling 參數。我們建議調整此參數或 temperature，其中之一即可，不要同時調整兩者。
</ParamField>

<ParamField body="frequency_penalty" type="number" default="0">
  介於 -2.0 到 2.0 之間的數值。正值會對重複的 token 施加懲罰。
</ParamField>

<ParamField body="presence_penalty" type="number" default="0">
  介於 -2.0 到 2.0 之間的數值。正值會對文字中已出現的 token 施加懲罰。
</ParamField>

<ParamField body="stop" type="string | array">
  最多 4 個序列，API 在遇到這些序列時會停止產生 token。
</ParamField>

<ParamField body="tools" type="array">
  模型可呼叫的工具清單（function calling）。
</ParamField>

<ParamField body="tool_choice" type="string | object">
  控制模型如何使用工具。選項：`auto`、`none`、`required`，或特定工具物件。
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  是否啟用平行 function calling。設為 false 可依序呼叫函式。
</ParamField>

<ParamField body="max_completion_tokens" type="integer">
  completion 的最大 token 數量。可作為 `max_tokens` 的替代方案，對較新的支援推理模型系列特別實用。
</ParamField>

<ParamField body="reasoning_effort" type="string">
  支援推理模型的推理強度。選項：`low`、`medium`、`high`。
</ParamField>

<ParamField body="seed" type="integer">
  用於確定性取樣的隨機種子。
</ParamField>

<ParamField body="n" type="integer" default="1">
  要產生的 completion 數量（1-128）。
</ParamField>

<ParamField body="logprobs" type="boolean">
  是否回傳對數機率。
</ParamField>

<ParamField body="top_logprobs" type="integer">
  要回傳的最高對數機率數量（0-20）。需要 `logprobs: true`。
</ParamField>

<ParamField body="top_k" type="integer">
  Top-K sampling 參數（適用於 Anthropic/Gemini 模型）。
</ParamField>

<ParamField body="response_format" type="object">
  回應格式規格。JSON 模式請使用 `{"type": "json_object"}`，結構化輸出請使用 `{"type": "json_schema", "json_schema": {...}}`。
</ParamField>

<ParamField body="logit_bias" type="object">
  修改指定 token 出現的可能性。將 token ID（以字串表示）對應到 -100 到 100 的 bias 值。
</ParamField>

<ParamField body="user" type="string">
  代表您的終端使用者的唯一識別碼，用於濫用監控。
</ParamField>

<ParamField body="cache_control" type="object">
  LemonData 快取控制選項。

  - `type` (string)：快取策略 - `default`、`no_cache`、`no_store`、`response_only`、`semantic_only`
  - `max_age` (integer)：快取 TTL（秒）（最大 86400）
</ParamField>

## 回應

<ResponseField name="id" type="string">
  completion 的唯一識別碼。
</ResponseField>

<ResponseField name="object" type="string">
  固定為 `chat.completion`。
</ResponseField>

<ResponseField name="created" type="integer">
  建立 completion 的 Unix 時間戳記。
</ResponseField>

<ResponseField name="model" type="string">
  用於 completion 的模型。
</ResponseField>

<ResponseField name="choices" type="array">
  completion 選項清單。

  每個選項包含：
  - `index` (integer)：選項索引
  - `message` (object)：產生的訊息
  - `finish_reason` (string)：模型停止的原因（`stop`、`length`、`tool_calls`）
</ResponseField>

<ResponseField name="usage" type="object">
  token 使用量統計。

  - `prompt_tokens` (integer)：prompt 中的 token 數
  - `completion_tokens` (integer)：completion 中的 token 數
  - `total_tokens` (integer)：使用的 token 總數
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/chat/completions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "temperature": 0.7,
    "max_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ],
    temperature=0.7,
    max_tokens=1000
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Hello!' }
  ],
  temperature: 0.7,
  max_tokens: 1000
});

console.log(response.choices[0].message.content);
```

```php PHP
<?php
$ch = curl_init('https://api.lemondata.cc/v1/chat/completions');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-4o',
        'messages' => [
            ['role' => 'system', 'content' => 'You are a helpful assistant.'],
            ['role' => 'user', 'content' => 'Hello!']
        ],
        'temperature' => 0.7,
        'max_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['choices'][0]['message']['content'];
```
