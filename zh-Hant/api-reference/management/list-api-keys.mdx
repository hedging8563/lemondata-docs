## 概覽

返回目前管理令牌所屬組織下的使用者 API Key 清單。

## 注意事項

- 系統代管的 Key（例如 Playground 或 Claw 專用 Key）不會出現在結果中。
- 金額欄位同時返回 USD 與人民幣展示值：`limit_amount` / `limit_amount_cny`、`used_amount` / `used_amount_cny`。
- `exchange_rate` 表示這些人民幣展示欄位使用的 USD→CNY 匯率。

## 範例

<RequestExample>
```bash cURL
curl -X GET "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>
