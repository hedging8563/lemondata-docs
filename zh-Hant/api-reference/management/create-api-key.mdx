## 概覽

此 endpoint 會在目前管理令牌所屬的組織下建立新的 `type=user` API Key。

## 請求體

| 欄位 | 型別 | 預設值 / 限制 | 說明 |
|-------|------|------------------|-------|
| name | string | 必填，預設 Default Key，長度 1-50 | 顯示名稱，伺服器端會先整理空白 |
| limitAmount | number \| null | 最小 0，最大 100000 | null 或省略 = 不限額，0 = 沒有可用額度，正數 = 美元上限 |
| models | string[] | 預設 [] | 可選的邏輯模型白名單 |
| expiresAt | string \| null | RFC3339 datetime | null 表示無到期時間 |

## 說明

- 回應中的完整 API Key 只會顯示一次。
- `models: []` 表示該 Key 除了組織層策略外，沒有額外模型限制。
- `limitAmount: 0` 會建立一把有效但無法消耗額度的 Key，後續可再更新。

## 範例

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "sora-2"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>
