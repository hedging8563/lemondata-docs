---
title: "取得 API Key 用量"
openapi: "GET /v1/management/api-keys/{keyId}/usage"
description: "返回某個使用者 API Key 的分頁用量明細。"
---

## 概覽

這個端點返回單個 API Key 的用量明細，支援按請求中的模型名（`model`）、公開模型廠商、`scene` 和 `accessChannel` 篩選。

## 注意事項

- 回應只包含面向外部的帳單欄位。
- 內部路由和物理渠道元資料會被隱藏。

## 請求 / 回應

使用上方的互動式 OpenAPI 面板以取得確切的架構。
