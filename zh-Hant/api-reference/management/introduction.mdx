## 概覽

管理 API 用於自動化管理組織級 API Key，並查詢單個 Key 維度的用量與帳單，無需使用一般推理 API Key。

管理令牌可以在 Dashboard 的 **Settings** 頁面生成和輪換：

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
管理令牌不是推理 API Key。`mt-...` 用於 `/v1/management/*`，`sk-...` 用於 `/v1/responses` 等模型推理接口。
</Warning>

## 可用接口

| Endpoint | Method | 說明 |
|----------|--------|------|
| `/v1/management/api-keys` | GET | 列出目前組織下的使用者 API Key |
| `/v1/management/api-keys` | POST | 建立新的使用者 API Key |
| `/v1/management/api-keys/{keyId}` | PATCH | 更新名稱、額度、模型白名單、過期時間或狀態 |
| `/v1/management/api-keys/{keyId}/usage` | GET | 查詢指定 Key 的分頁用量明細 |
| `/v1/management/api-keys/{keyId}/billing` | GET | 查詢指定 Key 的聚合帳單明細 |

## 欄位說明

- 請求中的模型名（`model`）
- 公開模型廠商
- `scene`
- `accessChannel`：`platform` 表示按平台方式計費，`byok` 表示使用你自己的上游 Provider Key 計費
- 用量、計費單位與快取指標
- 費用與時間

接口只返回公開可理解的帳單與報表欄位，不暴露內部路由細節或物理渠道元資料。

## 篩選維度

`/usage` 與 `/billing` 目前支援按以下維度篩選：

- 時間範圍
- 請求中的模型名（`model`）
- 公開模型廠商
- `scene`
- `accessChannel`
- 分頁

## 完整請求範例

先用目前管理令牌列出這個組織下的 API Keys：

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```

```python Python
import requests

response = requests.get(
    "https://api.lemondata.cc/v1/management/api-keys",
    headers={"Authorization": "Bearer mt-your-management-token"}
)

data = response.json()
for key in data["data"]:
    print(key["name"], key["status"], key["used_amount"])
```

```javascript JavaScript
const response = await fetch(
  'https://api.lemondata.cc/v1/management/api-keys',
  {
    headers: {
      'Authorization': 'Bearer mt-your-management-token'
    }
  }
);

const data = await response.json();
for (const key of data.data) {
  console.log(key.name, key.status, key.used_amount);
}
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/management/api-keys", nil)
    req.Header.Set("Authorization", "Bearer mt-your-management-token")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)

    fmt.Println(result["object"])
}
```

```php PHP
<?php
$ch = curl_init("https://api.lemondata.cc/v1/management/api-keys");

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer mt-your-management-token'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
foreach ($data['data'] as $key) {
    echo $key["name"] . " " . $key["status"] . " " . $key["used_amount"] . PHP_EOL;
}
```
</RequestExample>
