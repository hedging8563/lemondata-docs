## 概覽

Management API 用於自動化管理**組織級 API Key 生命週期**，以及查詢**單個 Key 維度的用量與帳單**。

它和一般推理 API 是兩套憑證體系：

- `sk-...`：用於模型推理接口，例如 `/v1/responses`
- `mt-...`：用於管理接口，即 `/v1/management/*`

管理令牌可以在 Dashboard 的 **Settings** 頁面生成和輪換。

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
Management Token 不是推理 API Key，不能用於調用模型。
</Warning>

## 能做什麼

目前 Management API 支援：

| Endpoint | Method | 說明 |
|----------|--------|------|
| `/v1/management/api-keys` | GET | 列出目前組織下的使用者 API Key |
| `/v1/management/api-keys` | POST | 建立新的使用者 API Key |
| `/v1/management/api-keys/{keyId}` | PATCH | 更新名稱、額度、模型白名單、過期時間、狀態 |
| `/v1/management/api-keys/{keyId}/usage` | GET | 查詢該 Key 的分頁用量明細 |
| `/v1/management/api-keys/{keyId}/billing` | GET | 查詢該 Key 的聚合帳單明細 |

## 暴露邊界

Management API 只暴露**公開可理解的帳單欄位**，例如：

- 邏輯模型名
- 公開模型廠商
- 介面族別 `scene`
- 公開渠道維度 `platform | byok`
- token / 計費量 / 計費單位
- 快取命中與快取 token
- 費用與時間

不會暴露以下內部實作細節：

- `physicalModel`
- `channelId`
- `channelName`
- 實際物理路由 provider
- routing / retry / selection 細節

## 帳單口徑

Management API 的帳單是**消費帳單**，不包含以下組織級財務流水：

- 充值
- 發票
- 提現
- 退款申請

如果你只想看某把 Key 花了多少錢、打了哪些模型、命中了哪些快取，這套接口就是對應入口。

## 篩選能力

`/usage` 與 `/billing` 目前支援按以下維度篩選：

- 時間範圍
- 邏輯模型
- 公開模型廠商
- `scene`
- `accessChannel`
- 分頁
