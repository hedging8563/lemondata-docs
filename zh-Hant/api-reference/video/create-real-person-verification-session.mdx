---
title: "建立真人驗證會話"
openapi: "POST /v1/videos/assets/visual-validation-sessions"
description: "建立一個 TokenLab 真人素材驗證 H5 會話。"
---

建立一個短效的驗證會話，並將您的使用者重新導向至回傳的 H5 連結。TokenLab 僅回傳中立欄位：`session_id`、`h5_link`、`callback_url`、`expires_in` 以及 `language`。

該會話與 H5 連結將在 120 秒後過期。綁定 token 只會透過 TokenLab 回調重新導向提供。當 H5 流程完成時，TokenLab 會將使用者重新導向至您原始的 `callback_url`，並附帶以下查詢參數：

| 參數 | 含義 |
|-----------|---------|
| `session_id` | TokenLab 驗證會話 ID。 |
| `verification_token` | 用於綁定結果的不透明 token。 |
| `verification_status` | `succeeded` 或 `failed`。 |
| `result_code` | 用於您應用程式邏輯的結果代碼。 |

若 `verification_status` 為 `succeeded`，請呼叫 [綁定真人驗證結果](/zh-Hant/api-reference/video/bind-real-person-verification-result)。在將此流程整合至您的產品之前，您可以使用 [測試控制台](https://tokenlab.sh/dashboard/seedance-assets) 來驗證回調處理。

## 請求範例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"callback_url":"https://yourapp.example.com/seedance/callback","language":"en"}'
```

## 回應範例

```json
{
  "object": "seedance.visual_validation_session",
  "session_id": "svv_abc123",
  "h5_link": "https://verify.example.com/h5?lng=en",
  "callback_url": "https://yourapp.example.com/seedance/callback",
  "expires_in": 120,
  "language": "en"
}
```
