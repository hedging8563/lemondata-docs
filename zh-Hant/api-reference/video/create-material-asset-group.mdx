---
title: "创建素材组"
openapi: "POST /v1/videos/assets/groups"
description: "为当前组织创建 Seedance 虚拟人像素材组。"
---

创建 `library_type: "aigc_avatar"` 的 TokenLab Seedance 素材组。

这个接口用于虚拟人像素材组。新的真人素材组必须通过 [真人素材认证](/api-reference/video/create-real-person-verification-session) 创建，不能直接用普通素材组创建接口完成。传 `library_type: "liveness_face"` 会被拒绝，以确保真人认证结果和素材库渠道映射不被绕过。

素材组归属于当前组织。返回的 `id` 可作为创建素材时的 `group_id`。
