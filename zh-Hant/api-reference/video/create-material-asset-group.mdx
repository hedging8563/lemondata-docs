---
title: "建立素材組"
openapi: "POST /v1/videos/assets/groups"
description: "建立 Seedance 虛擬人像素材組。"
---

创建 `library_type: "aigc_avatar"` 素材组，用于虚拟人像、商品、风格等不需要真人认证的参考素材。新的真人素材组必须通过 [建立真人素材認證會話](/zh-Hant/api-reference/video/create-real-person-verification-session) 创建，不能直接用普通素材组接口创建。
## 用例請求

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_name":"Product references","description":"Reusable product shots"}'
```

## 用例響應

```json
{
  "id": "seedance_group_virtual_123",
  "object": "seedance.material_group",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
