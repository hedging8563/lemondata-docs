---
title: "刪除素材資源"
openapi: "DELETE /v1/videos/assets/{assetId}"
description: "刪除當前組織擁有的 Seedance 素材資源。"
---

刪除單個素材資源。此操作不會刪除其所屬的素材組。刪除後，該資源 ID 將無法再作為 `material_asset_id` 使用。

## 請求範例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 回應範例

```json
{
  "deleted": true,
  "id": "seedance_asset_123"
}
```
