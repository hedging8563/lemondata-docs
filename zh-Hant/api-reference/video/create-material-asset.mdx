---
title: "建立素材資產"
openapi: "POST /v1/videos/assets"
description: "將 Seedance 素材資產上傳至 TokenLab 素材群組。"
---

將一個可公開存取的來源 URL 匯入至 Seedance 素材群組。TokenLab 會儲存該素材以供後續使用；請使用回傳的素材資產 `id` 進行生成，而非使用來源 URL。

對於 `library_type: "aigc_avatar"`，`group_id` 為選填；TokenLab 將使用或建立組織預設的虛擬人像群組。對於 `library_type: "liveness_face"`，`group_id` 為必填，且必須是透過 [取得視覺驗證結果](/zh-Hant/api-reference/video/get-visual-validation-result) 所回傳的 TokenLab 群組。

| 類型 | 支援的輸入 |
|------|-----------------|
| 圖片 | `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`；長寬比 `(0.4, 2.5)`；寬度和高度 `(300, 6000)` px；小於 30 MB。 |
| 影片 | `mp4`, `mov`；`480p`, `720p` 或 `1080p`；2-15 秒；長寬比 `[0.4, 2.5]`；寬度和高度 `[300, 6000]` px；總像素介於 409600 與 2068676 之間；最大 200 MB；24-60 FPS。 |
| 音訊 | `aac`, `wav`, `mp3`；2-15 秒；最大 15 MB。 |

建立過程為非同步。請輪詢 [取得素材資產](/zh-Hant/api-reference/video/get-material-asset) 直到 `status` 變為 `ACTIVE`。對於真人群組，一個群組對應一個已驗證的人員；若上傳包含多張人臉或與已驗證人員不符的人臉，可能會導致失敗。

## 請求範例

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"group-20260720123456-vrt01","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view"}'
```

## 回應範例

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
