---
title: "更新素材組"
openapi: "PUT /v1/videos/assets/groups/{groupId}"
description: "更新目前組織擁有的 Seedance 素材組。"
---

更新素材组的展示名称、描述或元数据。对于真人素材组，已认证真人和素材组的绑定关系不会改变。
## 用例請求

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"group_name":"Updated references","description":"Images approved for summer videos"}'
```

## 用例響應

```json
{
  "id": "seedance_group_virtual_123",
  "object": "seedance.material_group",
  "library_type": "aigc_avatar",
  "group_name": "Updated references",
  "description": "Images approved for summer videos",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
