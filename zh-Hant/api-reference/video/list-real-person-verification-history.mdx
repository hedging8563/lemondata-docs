---
title: "列出真人驗證歷史記錄"
openapi: "GET /v1/videos/assets/visual-validation-sessions"
description: "列出當前組織的真人素材驗證會話。"
---

列出先前的驗證會話以供審查、客戶支援及對帳使用。此歷史記錄保存時間較長，但不能取代短效的綁定步驟：成功的驗證仍應在 120 秒的視窗內立即完成綁定。

回應僅包含 TokenLab ID，不包含憑證資料。綁定成功後，`group_id` 即為用於 `liveness_face` 上傳的 TokenLab 素材群組 ID。

## 請求範例

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions?page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
