查詢目前組織長期保存的真人素材認證歷史。

這個接口適合用於客戶支援、稽核記錄和接入排障。它不能取代短時綁定流程：`session_id`、`verification_token` 和 H5 連結仍然會在 120 秒後過期；認證成功後應立即呼叫 [綁定認證結果](/api-reference/video/bind-real-person-verification-result)。

返回內容是 TokenLab 中立口徑，不包含內部憑據或底層素材庫 ID。綁定成功後，`group_id` 是 TokenLab 素材組 ID，可用於建立 `liveness_face` 真人素材。

狀態說明：

| 狀態 | 含義 |
|------|------|
| `created` | TokenLab 已建立 H5 會話，但尚未收到回調。 |
| `callback_succeeded` | TokenLab 已收到成功的 H5 回調，但尚未綁定結果。 |
| `callback_failed` | TokenLab 已收到失敗的 H5 回調。 |
| `bound` | 認證結果已綁定為 TokenLab 真人素材組。 |
| `expired` | 120 秒綁定窗口內未完成綁定。 |

[測試控制台](https://tokenlab.sh/dashboard/seedance-assets) 會在同一頁面展示長期認證歷史、素材組和素材。
