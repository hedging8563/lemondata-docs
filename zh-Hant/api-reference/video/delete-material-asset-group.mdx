---
title: "刪除素材資源群組"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "刪除當前組織擁有的 Seedance 素材群組。"
---

刪除素材群組及其內部的 TokenLab 素材資源。此操作無法復原。

若 TokenLab 素材庫因當前的授權狀態不允許而無法完成刪除，TokenLab 將返回一個中性的素材庫錯誤。刪除後，該群組及其資源將無法再用於影片生成。

## 請求範例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 回應範例

```json
{
  "deleted": true,
  "id": "seedance_group_virtual_123"
}
```
