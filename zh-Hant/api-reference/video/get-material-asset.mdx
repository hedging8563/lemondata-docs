---
title: "取得素材資源 (Get Material Asset)"
openapi: "GET /v1/videos/assets/{assetId}"
description: "透過 TokenLab 素材資源 ID 檢索單一 Seedance 素材資源。"
---

檢索單一素材資源並檢查其處理狀態。僅當 `ready` 為 `true` 且 `status` 為 `ACTIVE` 時，該資源才能用於影片生成。

如果影片生成回傳 `Seedance material asset not found or not accessible`，請確認您傳入的是此素材資源的 `id`，而非素材的 `group_id`。

## 請求範例 (Example Request)

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 回應範例 (Example Response)

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
