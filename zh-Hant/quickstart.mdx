## 步驟 1：取得您的 API Key

<Steps>
  <Step title="建立帳戶">
    使用您的電子郵件、Gmail 或 GitHub 帳戶在 [lemondata.cc](https://lemondata.cc) 註冊。
  </Step>
  <Step title="新增點數">
    開啟儀表板並為您的帳戶新增點數。LemonData 採用隨用隨付的定價模式，無最低承諾要求。
  </Step>
  <Step title="建立 API key">
    前往 **Dashboard → API Keys** 並建立新的 key。請安全地複製並保存，因為它只會顯示一次。
  </Step>
</Steps>

<Warning>
請妥善保管您的 API key。切勿將其暴露在 client-side 程式碼或公開的儲存庫中。
</Warning>

## 步驟 2：安裝 Client

<CodeGroup>

```bash Python
pip install openai
```

```bash JavaScript
npm install openai
```

```bash Go
go get github.com/openai/openai-go/v3
```

```bash PHP
composer require openai-php/client
```

</CodeGroup>

## 步驟 3：發送您的第一個請求

對於新專案，請從 **Responses API** 開始。

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
如果您的 framework 或工具仍然需要 Chat Completions，LemonData 也支援 `POST /v1/chat/completions`。對於新的整合，建議優先使用 `POST /v1/responses`。
</Note>

## 嘗試不同的模型

LemonData 支援 300+ 個模型。只需變更 `model` 欄位：

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## 啟用 Streaming

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
