## 什麼是 LemonData？

LemonData 是一個 AI API 聚合平台，讓你能以統一方式存取來自 OpenAI、Anthropic、Google、DeepSeek、Moonshot、MiniMax 等供應商的 **300+ 個 AI 模型**。

  <Card title="OpenAI 相容" icon="plug">

  </Card>
  <Card title="原生格式" icon="shuffle">

  </Card>

  </Card>
</CardGroup>

## 支援的能力

| 能力 | 說明 | 範例模型 |
|------------|-------------|----------------|
| **聊天與推理** | 文字生成、規劃、工具 | `gpt-5.4`, `claude-sonnet-4-6`, `deepseek-r1` |
| **視覺** | 圖像理解與多模態聊天 | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |
| **圖像生成** | 文字轉圖像與圖像編輯 | `dall-e-3`, `flux-pro`, `midjourney` |
| **影片生成** | 文字/圖像轉影片 | `sora`, `runway`, `kling` |
| **音訊** | TTS 與轉錄 | `gpt-4o-mini-tts`, `whisper-1`, `gpt-4o-transcribe` |
| **Embeddings** | 文字向量化 | `text-embedding-3-small`, `text-embedding-3-large` |
| **音樂** | AI 音樂生成 | `suno` |
| **3D** | 3D 資產生成 | `tripo3d` |

## 一個良好的預設起點

對於新專案，建議從 OpenAI SDK 搭配 **Responses API** 開始：

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```
