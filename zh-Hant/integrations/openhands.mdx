## 概覽

OpenHands 可以透過其 LiteLLM/OpenAI 相容的模型配置來使用 TokenLab，特別是在您需要自行提供模型、API 金鑰和 Base URL 的 CLI 與無頭工作流程中。

<Note>
**類型**: 程式設計代理 (Coding Agent)

**主要路徑**: OpenAI 相容模型配置

**支援信心**: 支援自訂端點路徑
</Note>

## 環境

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 模型設定

使用方式：

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

`openai/` 前綴會告知 LiteLLM 支援的路徑使用 OpenAI 相容的提供者配置。

## 無頭 (Headless) 設定

如果您正在為 CLI 或無頭使用準備本地預設值，請執行 OpenHands 設定流程並輸入：

```bash
make setup-config
```

當系統提示輸入模型詳細資訊時，請使用帶有 `openai/` 前綴的 TokenLab 模型 ID 以及 TokenLab 的 `/v1` Base URL。

## 模型建議

使用 `claude-sonnet-5` 或 `gpt-5.4` 進行程式設計代理規劃，使用 `gpt-5.4-mini` 進行更快速的常規迴圈，並在需要強大的替代推理模型時使用 `deepseek-v4-pro`。
