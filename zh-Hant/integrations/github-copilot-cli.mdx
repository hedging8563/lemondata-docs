## 概覽

<Note>
**類型**：程式代理 CLI

**主要路徑**：OpenAI 相容 Chat Completions

**支援級別**：官方 BYOK 路徑
</Note>

[GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models) 可連接任何 OpenAI Chat Completions 相容端點。

## 安裝與設定

```bash
npm install -g @github/copilot
copilot --version
```

npm 安裝需要 Node.js 22 或更新版本。GitHub 目前要求有效的 Copilot 方案；組織帳號也需要啟用 Copilot CLI 政策。

```bash
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.tokenlab.sh/v1"
export COPILOT_PROVIDER_API_KEY="sk-your-tokenlab-key"
export COPILOT_MODEL="kimi-k3"

copilot
```

| 變數 | TokenLab 值 |
|---|---|
| `COPILOT_PROVIDER_TYPE` | `openai` |
| `COPILOT_PROVIDER_BASE_URL` | `https://api.tokenlab.sh/v1` |
| `COPILOT_PROVIDER_API_KEY` | 你的 TokenLab API Key |
| `COPILOT_MODEL` | 即時模型 ID，例如 `kimi-k3` |

Copilot CLI 要求模型同時支援串流與工具呼叫。啟動後先要求它唯讀檢查專案。若模型不存在，請使用 [TokenLab 即時模型目錄](https://tokenlab.sh/zh-TW/models) 中的模型 ID，不要加入供應商前綴。

<Warning>
請勿將 API Key 提交到 Git 追蹤的檔案。若 Key 出現在終端歷史、截圖或日誌中，請立即輪換。
</Warning>
