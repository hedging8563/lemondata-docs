## 概覽

<Note>
**類型**：桌面程式與任務代理

**主要路徑**：OpenAI 相容 Chat Completions

**支援級別**：官方自訂模型路徑
</Note>

[WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) 提供視覺化的 OpenAI 相容自訂模型編輯器，不必手動編輯本機模型檔案。

## 設定 TokenLab

開啟 **設定 → 模型**，新增模型並選擇 **自訂 / Custom**：

| 欄位 | 值 |
|---|---|
| 介面位址 | `https://api.tokenlab.sh/v1` |
| API Key | 你的 TokenLab API Key |
| 模型名稱 | `kimi-k3` |
| 自訂協議 | **關閉** |

<Warning>
請保持「自訂協議」關閉。標準模式會驗證 Base URL 並自動補上 `/chat/completions`；若開啟後只填 `/v1`，請求會送到錯誤路徑。
</Warning>

## 進階設定

開啟工具呼叫、圖片輸入與思考模式；關閉僅思考模式；預設思考強度選自動。輸入上限設為 `1048576`，輸出上限設為 `131072`。

儲存後選擇 `kimi-k3`，先執行唯讀目錄檢查。分享設定截圖前請遮蓋 API Key 和私人端點。
