## 概覽

LemonData 可透過將用戶端指向 `https://api.lemondata.cc/v1` 來搭配官方 OpenAI SDK 使用。

對於新專案，建議優先使用 **Responses API**。僅當某個框架、plugin 或舊版程式碼路徑仍需要 **Chat Completions** 時才保留使用。

<Note>
Python、JavaScript 與 Go 擁有官方 OpenAI SDK。PHP 可良好搭配 OpenAI 相容的社群用戶端使用，但它不是官方 OpenAI SDK。
</Note>

## 設定用戶端

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## 建議使用：Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

## 使用 Responses 進行串流

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Tools / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## 使用 Responses 處理 Vision

```python
response = client.responses.create(
    model="gpt-4o",
    input=[{
        "role": "user",
        "content": [
            {"type": "input_text", "text": "What's in this image?"},
            {"type": "input_image", "image_url": "https://example.com/image.jpg"}
        ]
    }]
)

print(response.output_text)
```

## Chat Completions 相容性

如果你的框架或 plugin 仍需要 Chat Completions，LemonData 也支援標準的 OpenAI 相容路徑：

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
僅為了相容性才使用 Chat Completions。對於新的整合，請優先使用 `client.responses.create(...)`。
</Warning>

## 疑難排解

<AccordionGroup>
  <Accordion title="連線錯誤">
    - 確認 base URL 完全為 `https://api.lemondata.cc/v1`
    - 檢查是否有 proxy 干擾或自訂 HTTP 用戶端覆寫
    - 在除錯 provider 行為前，請先確認你的 SDK 版本為最新
  </Accordion>

  <Accordion title="驗證失敗">
    - 檢查你的 API key 是否以 `sk-` 開頭
    - 確認該 key 已在 LemonData dashboard 中啟用
    - 確認 SDK 有送出 `Authorization: Bearer ...`
  </Accordion>

  <Accordion title="錯誤的 API 路徑">
    - `responses.create(...)` 會將請求送至 `/v1/responses`
    - `chat.completions.create(...)` 會將請求送至 `/v1/chat/completions`
    - 如果你的應用程式目前只支援 Chat Completions，請繼續使用該相容路徑
  </Accordion>
</AccordionGroup>
