## 概覽



<Note>
**類型**: 程式工具

**主要路徑**: OpenAI Responses

**支援級別**: 支援，但依賴模型 / 渠道
</Note>

OpenAI Codex 是一個開源的命令列工具（CLI），可作為輕量級的程式編碼代理，能夠在終端機中讀取、修改並執行程式碼。它建構於 GPT 模型之上，並針對程式碼生成進行最佳化。

對 LemonData 而言，Codex CLI 最適合設定到 `/v1/responses`。這條路徑整體可用，但部分 Responses-native 功能仍依賴所選模型與路由到的渠道是否支援 native passthrough。

## 系統需求

- **OS**：macOS、Linux（官方支援）、透過 WSL 的 Windows
- **Node.js**：18+ 版本
- **npm**：10.x.x 或更高版本

## 安裝

```bash
npm install -g @openai/codex
```

驗證安裝：

```bash
codex --version
```

## 設定

### 步驟 1：設定 API Key

**暫時性（目前工作階段）：**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**永久設定：**

加入到 `~/.bashrc`、`~/.zshrc` 或 `~/.bash_profile`：

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

然後重新載入：

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### 步驟 2：設定 config.toml

編輯 `~/.codex/config.toml`：

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
如果設定檔不存在，請先執行一次 `codex` 以產生它，然後再編輯該檔案。變更 `config.toml` 後，請完整重新啟動 Codex，讓新的 provider 設定重新載入。
</Note>

<Warning>
Codex 正在淘汰對自訂 provider 的 `chat/completions` 支援。對於 LemonData，請保留 `wire_api = "responses"`，除非你有意使用較舊的相容性路徑。
</Warning>

<Note>
如果請求使用了所選模型或路由渠道不支援的 Responses-native-only 欄位，LemonData 會明確報錯，而不是靜默把請求降級。
</Note>

## 基本用法

**啟動互動模式：**

```bash
codex
```

**直接執行命令：**

```bash
codex "Fix the bug in main.py line 42"
```

**指定模型：**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## 推薦模型

| Model | Best For |
|-------|----------|
| `gpt-5.4` | 程式編碼與推理的最佳預設選擇 |
| `gpt-5-mini` | 更快、更便宜的程式編碼工作流程備援選項 |
| `claude-sonnet-4-6` | 程式碼審查、文件撰寫 |
| `deepseek-r1` | 演算法設計、推理 |

## 互動指令

| Command | Description |
|---------|-------------|
| `/help` | 顯示說明 |
| `/exit` or `Ctrl+C` | 離開 |
| `/clear` | 清除對話 |
| `/config` | 檢視設定 |
| `/model <name>` | 切換模型 |
| `/tokens` | 檢視 token 使用量 |

## 疑難排解

<AccordionGroup>
  <Accordion title="Connection Error">
    - 確認 config.toml 中的 `base_url` 完全為 `https://api.lemondata.cc/v1`
    - 檢查網路連線
    - 確保沒有代理干擾
  </Accordion>

  <Accordion title="Authentication Failed">
    - 確認 `~/.codex/config.toml` 中存在 `env_key = "OPENAI_API_KEY"`
    - 確認已設定 `OPENAI_API_KEY` 環境變數
    - 檢查 key 是否以 `sk-` 開頭
    - 確保該 key 已在 LemonData dashboard 中啟用
  </Accordion>

  <Accordion title="Model Not Found">
    - 檢查模型名稱是否完全相符
    - 在 [lemondata.cc/en/models](https://lemondata.cc/zh-Hant/models) 確認模型可用性
  </Accordion>

<Accordion title="Responses-native 欄位被拒絕">
    - 某些欄位只有在所選模型與路由到的渠道支援原生 `/v1/responses` passthrough 時才可用
    - 如果你看到包含 `unsupported_request_field` 或 native passthrough 的錯誤，請移除該欄位，或切換到相容的模型 / 渠道
  </Accordion>

</AccordionGroup>
