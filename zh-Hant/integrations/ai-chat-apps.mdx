## 概覽

大多數通用 AI 聊天應用程式都透過標準的 OpenAI 相容聊天路徑連接到 LemonData。

在實務上，這表示：
- 除非應用程式明確要求完整的 endpoint URL，否則請使用 `https://api.lemondata.cc/v1` 作為 base URL
- 使用你的 LemonData API key 作為 OpenAI 風格的 API key
- 選擇應用程式可在標準聊天工作流程中使用的 model

<Note>
通用聊天應用程式通常是**以 chat-completions 為導向**，而不是 Codex Responses WebSocket client。對於 Codex CLI/App、Cursor，或其他需要 Responses 特定行為的程式設計工具，請改用專用的整合指南。
</Note>

## 支援的應用程式

| 應用程式 | 平台 | 備註 |
|-------------|----------|-------|
| LobeChat | Web、桌面版、自行託管 | 強大的自訂 provider 支援 |
| Cherry Studio | Windows、macOS、Linux | 良好的 OpenAI 相容 provider 流程 |
| Chatbox | Windows、macOS、Linux | 簡單的 OpenAI 相容設定 |
| TypingMind | Web、桌面版 | 使用自訂 endpoint 風格 |
| BotGem | iOS、macOS | 自訂 provider 設定 |
| OpenCat | iOS、macOS | OpenAI 相容的自訂 endpoint 流程 |
| ChatWise | Windows、macOS | 標準自訂 provider 模式 |

## 預設連線值

| 欄位 | 值 |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

如果應用程式要求的是**完整的 endpoint URL**，而不是 base URL，請使用：
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## 範例應用程式設定

<Tabs>
  <Tab title="LobeChat">
    **自行託管的 LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. 開啟 **Settings** → **AI Service Provider**
    2. 選擇 **OpenAI**
    3. 輸入你的 LemonData API key
    4. 將自訂 endpoint 設為 `https://api.lemondata.cc/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. 開啟 **Settings** → **Model Provider**
    2. 新增一個 **OpenAI-compatible** provider
    3. 輸入：
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. 新增你想要使用的 model
  </Tab>

  <Tab title="Chatbox">
    1. 開啟 **Settings** → **AI Model**
    2. 選擇 **OpenAI API Compatible**
    3. 輸入：
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` 或 `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. 開啟 **Settings**
    2. 選擇 **Custom Endpoint**
    3. 輸入：
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. 設定你想要公開的 model
  </Tab>
</Tabs>

## 較安全的預設模型

| 類別 | 建議模型 |
|----------|------------------|
| 一般預設 | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| Anthropic | `claude-sonnet-4-6`, `claude-opus-4-6` |
| Google | `gemini-2.5-flash`, `gemini-2.5-pro` |
| DeepSeek | `deepseek-r1`, `deepseek-v3-2` |

## 提示

<AccordionGroup>
  <Accordion title="當應用程式支援時，優先使用 base URL">
    當你提供 `https://api.lemondata.cc/v1` 作為 base URL，而不是完整的 endpoint URL 時，大多數應用程式會更容易設定，且較不脆弱。
  </Accordion>

  <Accordion title="先使用較小的模型">
    日常聊天可先從 `gpt-5-mini` 或 `gpt-4o` 開始，之後再將較重的推理任務移到 `gpt-5.4` 或 `claude-opus-4-6`。
  </Accordion>

  <Accordion title="將程式設計工具分開">
    通用聊天應用程式與 coding agent 通常需要不同的 endpoint 行為。請將 Codex/Cursor 風格的工具保留在其專用整合頁面中。
  </Accordion>
</AccordionGroup>

## 疑難排解

<AccordionGroup>
  <Accordion title="連線錯誤">
    - 確認 base URL 完全為 `https://api.lemondata.cc/v1`
    - 如果應用程式會自動附加 path，請移除結尾的斜線
    - 如果應用程式需要完整的 endpoint URL，請使用 `https://api.lemondata.cc/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Unauthorized">
    - 再次檢查你的 API key
    - 確認該 key 在 LemonData dashboard 中為啟用狀態
    - 確保沒有多餘的空格或換行
  </Accordion>

  <Accordion title="Model 無法使用">
    - 確認 model 名稱完全正確
    - 嘗試廣泛支援的預設模型，例如 `gpt-5-mini`、`gpt-4o` 或 `claude-sonnet-4-6`
    - 在 LemonData 文件或 dashboard 中檢查目前可用性
  </Accordion>
</AccordionGroup>
