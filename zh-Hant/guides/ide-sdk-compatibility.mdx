## 概覽

LemonData 暴露了多種 API 格式，讓常見 coding 工具、SDK 與框架可以用較少的 glue code 接入。

本頁刻意比 marketing matrix 更收斂：

- **支援**：表示我們文件化了一條明確設定路徑，且 LemonData 暴露了這條路徑所需的協定形狀。
- **強原生路徑**：表示倉庫裡還存在該協定族的直接 adapter / request-format 證據。
- **Best-effort**：表示這條整合路徑可能可用，但上游客戶端並未把這種自訂 gateway 工作流視為穩定契約。

<Note>
  不支援的欄位並不是統一處理的。在相容路由上，有些欄位會被忽略或正規化；在原生 Responses 路徑上，如果所選模型或路由到的渠道不支援所需 passthrough，可能會回傳明確的 `400` 或 `503` 錯誤。
</Note>

## 支援的 API 格式

| Endpoint | Format | Use Case |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 通用相容性 |
| `/v1/responses` | OpenAI Responses | 有狀態對話 |
| `/v1/messages` | Anthropic Messages | Claude 原生功能 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini 原生功能 |

## IDE 與 CLI 相容性

### 已文件化的工具路徑

| 工具 | 支援級別 | 格式 | 說明 |
|------|----------|------|------|
| **Cursor** | 支援，但有邊界 | OpenAI-compatible | 適用於 BYOK 標準 chat/editor 流，不等於可以取代 Cursor 託管功能（如 Tab Completion） |
| **Claude Code CLI** | 強原生路徑 | Anthropic | 原生 `/v1/messages` 路徑，對 thinking 與 `tool_choice` 有 adapter 證據 |
| **Codex CLI** | 支援，但依賴模型 / 渠道 | OpenAI Responses | 最適合設定到 `/v1/responses`；部分 Responses-native 欄位依賴所選模型與渠道的 native passthrough 支援 |
| **Gemini CLI** | 實驗性 / best-effort | Gemini | 自訂 LemonData base URL 工作流不是穩定 upstream contract |
| **OpenCode** | 支援 | OpenAI-compatible | 預設使用 OpenAI-compatible provider；只有在你明確需要 Responses provider 路徑時才切換 |

<Note>
  其他 OpenAI-compatible 編輯器與 agent 工具通常也能沿用相同的 base URL 模式，但目前倉庫並沒有為 Windsurf、Aider、Continue.dev、Cline/Roo Code、GitHub Copilot 等客戶端維護專門的回歸覆蓋。
</Note>

### 設定範例

<Tabs>
  <Tab title="Cursor">
    ```
    Base URL: https://api.lemondata.cc/v1
    API Key: sk-your-lemondata-key
    ```
    Cursor 內部使用 Anthropic 風格的工具格式。LemonData 同時支援兩者：
    - OpenAI 格式：`{ type: "function", function: { name, parameters } }`
    - Anthropic 格式：`{ name, input_schema }`（無 type 欄位）
  </Tab>
  <Tab title="Claude Code">

    ```bash
    export ANTHROPIC_API_KEY="sk-your-lemondata-key"
    ```
  </Tab>
  <Tab title="OpenCode">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"
    export LOCAL_ENDPOINT="https://api.lemondata.cc/v1"
    ```
  </Tab>
  <Tab title="Aider">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"

    ```
  </Tab>

## SDK 相容性

### 已文件化的 SDK / 框架路徑

| SDK / 框架 | 語言 | 支援級別 | 說明 |
|------------|------|----------|------|
| **OpenAI SDK** | Python/JS/Go | 核心路徑支援 | 已文件化 Chat Completions、Embeddings 與常見 Responses 工作流；部分僅限 Responses-native 的欄位依賴 model/channel passthrough 支援 |
| **Anthropic SDK** | Python/JS | 強原生路徑 | 原生 Messages 路徑，對 tools、thinking 與 prompt caching 有直接證據 |
| **Vercel AI SDK** | TypeScript | 推薦整合模式 | 優先使用 `@ai-sdk/openai-compatible`；僅在明確需要 Responses-native 行為時使用 `@ai-sdk/openai` |
| **LangChain** | Python/JS | 支援標準 surface | 預期範圍是 `ChatOpenAI` 與 `OpenAIEmbeddings`；vendor-native extras 不在此頁承諾範圍 |
| **LlamaIndex** | Python | 透過 `OpenAILike` 支援 | 對 LemonData 這類第三方 gateway，應使用 `OpenAILike`，而不是內建 OpenAI 類 |
| **Dify** | - | 支援，但有邊界 | 預期路徑是 OpenAI provider 與 chat-completions 導向流程；不適合承諾 Codex 專用 Responses / WebSocket 行為 |

## Chat Completions 參數

### 核心參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型識別碼（必填） |
| `messages` | array | 對話訊息（必填） |
| `max_tokens` | integer | 最大輸出 token 數 |
| `temperature` | number | 採樣溫度（0-2） |
| `top_p` | number | Nucleus 採樣（0-1） |
| `stream` | boolean | 啟用串流 |

### 工具呼叫

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tool Choice 選項

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | 簡單選擇 |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | 強制指定特定函式 |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic 原生格式 |

### 進階參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | 用於 token 計數的 `{ include_usage: true }` |
| `reasoning_effort` | string | 適用於支援推理的 GPT-5 模型：`"low"`、`"medium"`、`"high"` |
| `service_tier` | string | `"auto"` 或 `"default"` |
| `seed` | integer | 決定性輸出 |
| `logprobs` | boolean | 回傳對數機率 |
| `top_logprobs` | integer | 最高 logprobs 數量（0-20） |
| `logit_bias` | object | Token 偏置對應表（-100 到 100） |
| `frequency_penalty` | number | 重複懲罰（-2 到 2） |
| `presence_penalty` | number | 主題懲罰（-2 到 2） |
| `stop` | string/array | 停止序列 |
| `n` | integer | completion 數量（1-128） |
| `user` | string | 用於追蹤的使用者識別碼 |

### OpenAI 進階功能

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | 多模態使用 `["text", "audio"]` |
| `audio` | object | 音訊輸出設定（voice、format） |
| `prediction` | object | 用於加快 completion 的預測輸出 |
| `metadata` | object | 用於追蹤的鍵值對 |
| `store` | boolean | 儲存以供稍後擷取 |

### 供應商特定選項

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Anthropic Messages 參數

### 核心參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型識別碼 |
| `messages` | array | 對話訊息 |
| `max_tokens` | integer | 最大輸出（最高 128000） |
| `system` | string/array | 系統提示詞 |
| `stream` | boolean | 啟用串流 |

### 工具呼叫

```json
{
  "tools": [
    {
      "name": "get_weather",
      "description": "Get weather",
      "input_schema": {
        "type": "object",
        "properties": {
          "location": { "type": "string" }
        }
      }
    }
  ],
  "tool_choice": {
    "type": "auto",
    "disable_parallel_tool_use": false
  }
}
```

### Extended Thinking

```json
{
  "model": "claude-opus-4-6",
  "thinking": {
    "type": "enabled",
    "budget_tokens": 10000
  }
}
```

## Responses API 參數

### 核心參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型識別碼 |
| `input` | string/array | 輸入內容 |
| `instructions` | string | 系統指令 |
| `max_output_tokens` | integer | 最大輸出 token 數 |
| `previous_response_id` | string | 延續對話 |

### 進階參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` 或 `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | 適用於推理模型 |
| `service_tier` | string | 優先層級 |

### 工具格式

同時支援 OpenAI 與 Anthropic 工具格式：

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

| Parameter | Type | Description |

## 串流

所有端點都支援 Server-Sent Events (SSE) 串流：

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## 錯誤處理

LemonData 會回傳與 OpenAI 相容的錯誤回應：

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

詳情請參閱 [Error Handling Guide](/guides/error-handling)。

## 最佳實務

<AccordionGroup>
  <Accordion title="對未知參數使用 passthrough">
    所有 schema 都使用 `.passthrough()`——未知參數會轉送至上游供應商。
  </Accordion>

  <Accordion title="優先使用 stream_options 以取得準確計費">
    在串流回應中啟用 `stream_options.include_usage`，以取得準確的 token 計數。
  </Accordion>

  <Accordion title="使用適當的 tool_choice 格式">
    請符合你的 SDK 預期格式。LemonData 接受 OpenAI 與 Anthropic 兩種格式。
  </Accordion>
</AccordionGroup>
