## 概覽

LemonData API 專為與所有主要 AI 開發工具**即插即用相容**而設計。本指南記錄了支援的參數與已驗證的整合。

<Note>
  所有參數都會經過驗證，但會傳遞至上游供應商。特定模型不支援的參數會被靜默忽略，以確保最大相容性。
</Note>

## 支援的 API 格式

| Endpoint | Format | Use Case |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 通用相容性 |
| `/v1/responses` | OpenAI Responses | 有狀態對話 |
| `/v1/messages` | Anthropic Messages | Claude 原生功能 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini 原生功能 |

## Chat Completions 參數

### 核心參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型識別碼（必填） |
| `messages` | array | 對話訊息（必填） |
| `max_tokens` | integer | 最大輸出 token 數 |
| `temperature` | number | 採樣溫度（0-2） |
| `top_p` | number | Nucleus 採樣（0-1） |
| `stream` | boolean | 啟用串流 |

### 工具呼叫

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tool Choice 選項

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | 簡單選擇 |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | 強制指定特定函式 |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic 原生格式 |

### 進階參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | 用於 token 計數的 `{ include_usage: true }` |
| `reasoning_effort` | string | 適用於支援推理的 GPT-5 模型：`"low"`、`"medium"`、`"high"` |
| `service_tier` | string | `"auto"` 或 `"default"` |
| `seed` | integer | 決定性輸出 |
| `logprobs` | boolean | 回傳對數機率 |
| `top_logprobs` | integer | 最高 logprobs 數量（0-20） |
| `logit_bias` | object | Token 偏置對應表（-100 到 100） |
| `frequency_penalty` | number | 重複懲罰（-2 到 2） |
| `presence_penalty` | number | 主題懲罰（-2 到 2） |
| `stop` | string/array | 停止序列 |
| `n` | integer | completion 數量（1-128） |
| `user` | string | 用於追蹤的使用者識別碼 |

### OpenAI 進階功能

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | 多模態使用 `["text", "audio"]` |
| `audio` | object | 音訊輸出設定（voice、format） |
| `prediction` | object | 用於加快 completion 的預測輸出 |
| `metadata` | object | 用於追蹤的鍵值對 |
| `store` | boolean | 儲存以供稍後擷取 |

### 供應商特定選項

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Anthropic Messages 參數

### 核心參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型識別碼 |

### 工具呼叫

```json
{
  "tools": [
    {
      "name": "get_weather",
      "description": "Get weather",
      "input_schema": {
        "type": "object",
        "properties": {
          "location": { "type": "string" }
        }
      }
    }
  ],
  "tool_choice": {
    "type": "auto",
    "disable_parallel_tool_use": false
  }
}
```

## Responses API 參數

### 核心參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型識別碼 |
| `input` | string/array | 輸入內容 |
| `instructions` | string | 系統指令 |
| `max_output_tokens` | integer | 最大輸出 token 數 |
| `previous_response_id` | string | 延續對話 |

### 進階參數

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` 或 `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | 適用於推理模型 |
| `service_tier` | string | 優先層級 |

### 工具格式

同時支援 OpenAI 與 Anthropic 工具格式：

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## 串流

所有端點都支援 Server-Sent Events (SSE) 串流：

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## 錯誤處理

LemonData 會回傳與 OpenAI 相容的錯誤回應：

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

詳情請參閱 [Error Handling Guide](/guides/error-handling)。

## 最佳實務

<AccordionGroup>
  <Accordion title="對未知參數使用 passthrough">
    所有 schema 都使用 `.passthrough()`——未知參數會轉送至上游供應商。
  </Accordion>

  <Accordion title="優先使用 stream_options 以取得準確計費">
    在串流回應中啟用 `stream_options.include_usage`，以取得準確的 token 計數。
  </Accordion>

  <Accordion title="使用適當的 tool_choice 格式">
    請符合你的 SDK 預期格式。LemonData 接受 OpenAI 與 Anthropic 兩種格式。
  </Accordion>
</AccordionGroup>
