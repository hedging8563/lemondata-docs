## 概覽

LemonData 採用 **按用量付費定價**。您只需為實際使用的部分付費，無需訂閱或最低承諾。

## 計費方式

1. 為您的帳戶 **新增點數**
2. **使用 API** - 每次請求都會扣除相應費用
3. 在您的 dashboard 中 **監控使用量**
4. 當餘額偏低時 **儲值**

### 非同步任務計費（影片/音樂/3D）

<Warning>
  **重要**：影片、音樂與 3D 生成任務會在 **提交時** 計費，而不是在完成後計費。
</Warning>

對於非同步生成任務（影片、音樂、3D 模型）：

1. 當您提交任務時，**會立即計費**
2. 您會收到一個 `task_id` 以輪詢狀態
3. 如果任務失敗，**不會自動退款**

這是因為上游供應商會在任務提交時向我們收費，而不論最終結果如何。如果您遇到任務失敗的情況，請聯絡 support@lemondata.cc 尋求協助。

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

task_id = response.json()["task_id"]
# Poll for status...
```

## Token 計數

Token 是文字處理的基本單位：

- 約 4 個字元 = 1 個 token（英文）
- 約 1-2 個字元 = 1 個 token（中文）
- 1 張圖片 = 依大小與細節而異

### 預估 Token

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

- 成本明細

```json
{

    "completion_tokens": 100,

```

## 低餘額提醒

當您的餘額下降時，設定提醒：

1. 前往 **Dashboard → Settings → Notifications**
2. 設定您的門檻金額
3. 接收電子郵件通知

## 新增點數

### 付款方式

- Alipay（支付寶）
- WeChat Pay（微信支付）
- Stripe（Visa、Mastercard）

### 步驟

1. 登入 [Dashboard](https://lemondata.cc/dashboard)
2. 點擊 **Add Credits**
3. 選擇金額與付款方式
4. 完成付款

付款確認後，點數會立即加入。

## API Key 限制

您可以為個別 API key 設定支出限制：

1. 前往 **Dashboard → API Keys**
2. 點擊某個 key 進行編輯
3. 設定 **Usage Limit**

當達到限制時，使用該 key 的請求將返回 `402 Payment Required`。

## 發票

對於企業帳戶，可提供發票：

1. 前往 **Dashboard → Billing**
2. 查看交易記錄
3. 下載 PDF 發票
