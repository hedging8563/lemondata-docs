## 概覽

LemonData 採用 **按量計費 (pay-as-you-go)**。您只需為實際使用的部分付費，無需訂閱或最低消費承諾。

## 計費運作方式

1. **儲值點數** 到您的帳戶
2. **使用 API** - 費用將按請求扣除
3. **監控用量** 在您的控制面板中
4. **餘額不足時儲值**

### 非同步任務計費 (影片/音樂/3D 及部分圖像模型)

<Warning>
  **重要提示**：影片、音樂和 3D 生成任務在 **提交時計費**，而非完成時。某些圖像模型也可能返回基於任務的響應，在這種情況下應以相同方式處理。
</Warning>

對於基於任務的生成流程（影片、音樂、3D 和部分圖像模型）：

1. **提交任務時立即計費**
2. 追蹤返回的 `poll_url` 以檢查狀態，並將 `task_id` 視為非同步任務標識
3. **任務失敗不提供自動退款**

這是因為上游供應商在提交任務時即向我們收費，無論結果如何。如果您遇到任務失敗，請聯繫 support@lemondata.cc 尋求協助。

# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

poll_url = response.json()["poll_url"]
task_id = response.json()["task_id"]
# Poll poll_url for status...

### 帳單交易 ID

已完成結算的計費型非串流 JSON 回應會返回 `billing_transaction_id`。同一個值也會透過 `X-Billing-Transaction-ID` 回應標頭暴露，方便瀏覽器與服務端整合讀取。對於非同步媒體任務，請輪詢建立回應返回的 `poll_url` 或 `GET /v1/tasks/{id}`；當結算完成後，任務回應會包含 `billing_transaction_id`。串流回應可能在內容已送出後才完成結算，因此如果回應標頭中沒有該欄位，請透過 dashboard 用量記錄進行對帳。

## Token 計數

Token 是文本處理的基本單位：

- 約 4 個字元 = 1 token (英文)
- 約 1-2 個字元 = 1 token (中文)
- 1 張圖片 = 視尺寸和細節而定

### 估算 Token

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## 餘額不足警報

配置當餘額下降時的警報：

1. 前往 **控制面板 → 設置 → 通知**
2. 設置您的閾值金額
3. 接收電子郵件通知

## 儲值點數

### 付款方式

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### 步驟

1. 登入 [控制面板](https://lemondata.cc/dashboard)
2. 點擊 **儲值點數**
3. 選擇金額和付款方式
4. 完成付款

點數將在付款確認後立即入帳。

## API Key 限制

您可以為個別 API key 設置支出限制：

1. 前往 **控制面板 → API Keys**
2. 點擊某個 key 進行編輯
3. 設置 **用量限制**

當達到限制時，使用該 key 的請求將返回 `402 Payment Required`。

## 發票

對於企業帳戶，可提供發票：

1. 前往 **控制面板 → 計費**
2. 查看交易歷史
3. 下載 PDF 格式發票
