## 概覽

LemonData 的 Agent-First API 會以結構化提示強化錯誤回應，讓 AI agent 可以立即解析並採取行動——無需網頁搜尋、無需查閱文件、無需猜測。

每個錯誤回應都會在標準的 `error` 物件中包含可選欄位，例如 `did_you_mean`、`suggestions`、`hint`、`retryable` 和 `retry_after`。這些欄位具備向後相容性——未使用它們的客戶端不會感受到任何差異。

## 錯誤提示欄位

所有提示欄位都是 `error` 物件中的可選擴充欄位：

| Field | Type | Description |
|-------|------|-------------|
| `did_you_mean` | `string` | 最接近的模型名稱 |
| `suggestions` | `array` | 附帶中繼資料的推薦模型 |
| `alternatives` | `array` | 目前可用的替代模型 |
| `hint` | `string` | 人類/agent 可讀的下一步指引 |
| `retryable` | `boolean` | 重新嘗試相同請求是否可能成功 |
| `retry_after` | `number` | 重試前應等待的秒數 |
| `balance_usd` | `number` | 目前帳戶餘額（USD） |
| `estimated_cost_usd` | `number` | 失敗請求的預估成本 |

## 錯誤代碼範例

### model_not_found (400)

當模型名稱與任何啟用中的模型都不相符時：

```json
{
  "error": {
    "message": "Model 'gpt5' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [
      {"id": "gpt-5.4"},
      {"id": "gpt-5-mini"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Did you mean 'gpt-5.4'? Use GET /v1/models to list all available models."
  }
}
```

`did_you_mean` 的解析方式使用：
1. 靜態別名映射（來自正式環境的錯誤資料）
2. 正規化字串比對（移除連字號、忽略大小寫）
3. 編輯距離比對（閾值 ≤ 3）

### insufficient_balance (402)

當帳戶餘額低於預估成本時：

```json
{
  "error": {
    "message": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200.",
    "type": "insufficient_balance",
    "code": "insufficient_balance",
    "balance_usd": 0.12,
    "estimated_cost_usd": 0.35,
    "suggestions": [
      {"id": "gpt-5-mini"},
      {"id": "deepseek-v3-2"}
    ],
    "hint": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200. Try a cheaper model, or top up at https://lemondata.cc/dashboard/billing."
  }
}
```

`suggestions` 包含成本低於預估成本、agent 可切換使用的模型。

### all_channels_failed (503)

當某個模型的所有上游通道皆不可用時：

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-6", "status": "available", "tags": []},
      {"id": "gpt-5-mini", "status": "available", "tags": []}
    ],
    "hint": "All channels for 'claude-opus-4-6' are temporarily unavailable. Retry in 30s or try an alternative model."
  }
}
```

<Note>
當原因為 `no_channels`（此模型未配置任何通道）時，`retryable` 為 `false`。只有在像是 circuit breaker 觸發或 quota 耗盡這類暫時性失敗時，才會是 `true`。
</Note>

### rate_limit_exceeded (429)

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

`retry_after` 的值是根據實際 rate limit 視窗的重置時間計算而來。

<Note>
OpenAI 相容端點使用 LemonData 穩定的公開錯誤類型，例如 `rate_limit_exceeded`、`upstream_error` 與 `all_channels_failed`。Anthropic 相容與 Gemini 相容端點則使用各自原生的回應格式。
</Note>

### context_length_exceeded (400)

當輸入超過模型的 context window 時（上游錯誤，並附加提示強化）：

```json
{
  "error": {
    "message": "This model's maximum context length is 128000 tokens...",
    "type": "invalid_request_error",
    "code": "context_length_exceeded",
    "retryable": false,
    "suggestions": [
      {"id": "gemini-2.5-pro"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Reduce your input or switch to a model with a larger context window."
  }
}
```

## 原生端點標頭

當你使用具有原生端點的模型（Anthropic 或 Gemini）呼叫 `/v1/chat/completions` 時，**成功回應** 會包含最佳化標頭：

```
X-LemonData-Hint: This model supports native Anthropic format. Use POST /v1/messages for better performance (no format conversion).
X-LemonData-Native-Endpoint: /v1/messages
```

| Model Provider | Suggested Endpoint | Benefit |
|---------------|-------------------|---------|
| Anthropic (Claude) | `/v1/messages` | 無需格式轉換、延伸思考、prompt 快取 |
| Google (Gemini) | `/v1beta/gemini` | 無需格式轉換、grounding、安全性設定 |
| OpenAI | — | Chat completions 已經是原生格式 |

這些標頭會同時出現在串流與非串流回應中。

## /v1/models 增強功能

每個模型物件中的 `lemondata` 擴充新增了三個欄位：

```json
{
  "id": "gpt-5.4",
  "lemondata": {
    "category": "chat",
    "pricing_unit": "per_token",
    "cache_pricing": {
      "cache_read_per_1m": "1.25",
      "cache_write_per_1m": "2.50",
      "platform_cache_discount": 0.9
    }
  }
}
```

| Field | Values | Description |
|-------|--------|-------------|
| `category` | `chat`, `image`, `video`, `audio`, `tts`, `stt`, `3d`, `embedding`, `rerank` | 模型類型 |
| `pricing_unit` | `per_token`, `per_image`, `per_second`, `per_request` | 模型的計費方式 |
| `cache_pricing` | object or `null` | 上游 prompt cache 價格 + 平台語意快取折扣 |

### 類別篩選

```bash
GET /v1/models?category=chat          # Chat models only
GET /v1/models?category=image         # Image generation models
GET /v1/models?tag=coding&category=chat  # Coding-optimized chat models
```

## llms.txt

可供機器讀取的 API 概覽可於下列位置取得：

```
GET https://api.lemondata.cc/llms.txt
```

其中包含：
- 附帶可運作範例的首次呼叫範本
- 常見模型名稱（根據使用資料動態產生）
- 全部 12 個 API 端點
- 用於模型探索的篩選參數
- 錯誤處理指引

在第一次 API 呼叫之前先讀取 `llms.txt` 的 AI agent，通常可以在第一次嘗試時就成功。

## 在 Agent 程式碼中的使用方式

### Python (OpenAI SDK)

```python
from openai import OpenAI, BadRequestError

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://api.lemondata.cc/v1"
)

def smart_chat(messages, model="gpt-4o"):
    try:
        return client.chat.completions.create(
            model=model, messages=messages
        )
    except BadRequestError as e:
        error = e.body.get("error", {}) if isinstance(e.body, dict) else {}
        # Use did_you_mean for auto-correction
        if error.get("code") == "model_not_found" and error.get("did_you_mean"):
            return client.chat.completions.create(
                model=error["did_you_mean"], messages=messages
            )
        raise
```

### JavaScript (OpenAI SDK)

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function smartChat(messages, model = 'gpt-4o') {
  try {
    return await client.chat.completions.create({ model, messages });
  } catch (error) {
    const err = error?.error;
    if (err?.code === 'model_not_found' && err?.did_you_mean) {
      return client.chat.completions.create({
        model: err.did_you_mean, messages
      });
    }
    throw error;
  }
}
```
