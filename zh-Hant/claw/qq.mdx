使用官方的 QQ 開放平台機器人 API 將 QQ（中國最受歡迎的即時通訊軟體）連接到您的 LemonClaw 實例。本指南適用於託管的 Claw 實例和自託管的 LemonClaw 部署。

## 前置條件

- 一個 [QQ](https://im.qq.com/) 帳號
- [QQ 開放平台](https://q.qq.com/) 的存取權限（開發者帳號）
- 一個 LemonClaw 實例：
  - 託管型：[建立一個 Claw 實例](https://lemondata.cc/dashboard/claw)
  - 自託管型：[安裝 LemonClaw](/claw/self-hosted)

## 設定指南

<Steps>
  <Step title="建立 QQ 機器人應用程式">
    1. 前往 [QQ 開放平台](https://q.qq.com/)
    2. 登入並前往 **機器人** 區塊
    3. 點擊 **建立機器人**
    4. 填寫機器人資訊（名稱、頭像、描述）
    5. 提交審核
  </Step>
  <Step title="獲取憑證">
    1. 審核通過後，前往您機器人的 **開發設置**
    2. 複製 **AppID**
    3. 複製 **AppSecret** (Client Secret)
  </Step>
  <Step title="配置沙盒（用於測試）">
    1. 在機器人設定中，前往 **沙盒配置**
    2. 將您的 QQ 號碼添加到沙盒白名單
    3. 這讓您可以在正式上線前進行測試

    <Tip>
    在提交正式環境審核之前，先使用沙盒模式驗證一切運作正常。
    </Tip>
  </Step>
  <Step title="開啟 LemonClaw WebUI">
    1. 如果您使用的是託管型 Claw，請前往您的 [Claw 控制面板](https://lemondata.cc/dashboard/claw) 並點擊 **Open WebUI**
    2. 如果您是自託管 LemonClaw，請開啟您自己的 WebUI（例如 `http://your-ip:18789`）並使用您的 token 登入
    3. 在 WebUI 中，導覽至 **Settings** → **IM Integrations**
    4. 展開 **QQ** 區塊
    5. 貼上您的 **AppID** 和 **AppSecret**
    6. 點擊 **Save**
  </Step>
  <Step title="開始聊天">
    1. 在 QQ 中搜尋您的機器人或將其新增為好友
    2. 發送一條訊息
    3. 第一個使用者將 **自動配對** 為擁有者 — 無需任何程式碼！
    4. 開始與 AI 聊天！
  </Step>
</Steps>

## 支援的訊息類型

| 類型 | 描述 |
|------|-------------|
| **C2C (私聊)** | 直接發送給機器人的訊息 |
| **群組 @提及** | 在 QQ 群組中 @提及機器人 |
| **頻道** | QQ 頻道 (频道) 中的訊息 |

## 疑難排解

<Note>
目前 LemonClaw 的 QQ 支援範圍是私聊與群內 @ 機器人的事件。未 @ 的一般群訊息，以及 QQ 頻道會話，目前都還沒有接入。
</Note>

<AccordionGroup>
  <Accordion title="機器人沒有回應">
    - 驗證 AppID 和 AppSecret 是否正確
    - 檢查您的 QQ 號碼是否在沙盒白名單中（如果正在測試）
    - 確保機器人應用程式已通過審核
  </Accordion>
  <Accordion title="'invalid appid' 錯誤">
    - 再次檢查 AppID — 它應該是一個數字字串
    - 確保您使用的是正確的 AppSecret（而非 token）
  </Accordion>
</AccordionGroup>
