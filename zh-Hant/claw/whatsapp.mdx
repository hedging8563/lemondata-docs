透過掃描 QR code 將 WhatsApp 連接至您的 LemonClaw 實例 — 就像使用 WhatsApp 網頁版一樣。本指南適用於託管型 Claw 實例及自託管型 LemonClaw 部署。

## 前置條件

- 一支安裝了 [WhatsApp](https://www.whatsapp.com/) 且擁有活躍帳號的電話
- 一個 LemonClaw 實例：
  - 託管型：[建立 Claw 實例](https://lemondata.cc/dashboard/claw)
  - 自託管型：[安裝 LemonClaw](/claw/self-hosted)

<Warning>
WhatsApp 會使用您的**真實電話號碼**。透過機器人發送的訊息將顯示為來自您的 WhatsApp 帳號。如果您希望區分身分，請使用專用號碼。
</Warning>

<Warning>
**不支援 VoIP 號碼。** WhatsApp 需要真實的 SIM 卡電話號碼。虛擬號碼（如 Google Voice、Skype 等）無法用於 QR code 配對。
</Warning>

## 設定指南

<Steps>
  <Step title="開啟 LemonClaw WebUI">
    1. 如果您使用的是託管型 Claw，請前往您的 [Claw Dashboard](https://lemondata.cc/dashboard/claw) 並點擊 **Open WebUI**
    2. 如果您是自託管 LemonClaw，請開啟您自己的 WebUI（例如 `http://your-ip:18789`）並使用您的 token 登入
    3. 在 WebUI 中，導覽至 **Settings** → **IM Integrations**
    4. 展開 **WhatsApp** 區塊
    5. 設定 **Access Policy**（建議使用白名單 allowlist）
    6. 先點擊 **Save** — 您必須在掃描 QR code 之前儲存設定
  </Step>
  <Step title="掃描 QR Code">
    1. 點擊 **Scan QR Code** 按鈕
    2. 畫面將顯示 QR code（有效期約 60 秒）
    3. 在您的手機上，開啟 WhatsApp → **Settings** → **Linked Devices** → **Link a Device**
    4. 掃描螢幕上顯示的 QR code
    5. 等待連線建立
  </Step>
  <Step title="設定存取策略">
    WhatsApp 使用 **allowlist**（白名單）策略 — 只有您指定的電話號碼才能與 AI 機器人互動。

    在 LemonClaw WebUI 中新增允許的電話號碼（國際格式，例如 `+1234567890`）。

    <Tip>
    與其他平台不同，WhatsApp 不支援配對機制。您必須明確新增允許的聯絡人。
    </Tip>
  </Step>
  <Step title="開始聊天">
    從允許的聯絡人向已連線的 WhatsApp 號碼發送訊息 — AI 將會回覆！
  </Step>
</Steps>

## 群組設定

支援 WhatsApp 群組。在 **IM Integrations** 標籤頁中設定群組行為：

| 設定 | 選項 | 描述 |
|---------|---------|-------------|
| **Group Policy** | Open (預設) / Allowlist / Disabled | 控制誰可以在群組中觸發機器人 |
| **Require @mention** | 開啟 / 關閉 | 機器人僅在被 @提及 時回覆 |
| **Group IDs** | 群組 JID 列表 | 限制於特定群組（留空 = 所有群組） |
| **Group Allowed Users** | 電話號碼列表 | 僅這些使用者可以觸發機器人（白名單模式） |

<Tip>
在群組白名單中使用 E.164 格式的電話號碼（例如 `+1234567890`）。
</Tip>

## 疑難排解

<AccordionGroup>
  <Accordion title="QR code 已過期">
    再次點擊 **Scan QR Code** 以產生新的代碼。QR code 會在約 60 秒後過期。
  </Accordion>
  <Accordion title="WhatsApp 已斷開連線">
    WhatsApp 可能會在閒置一段時間後斷開已連結的裝置。請重新掃描 QR code 以重新連線。
  </Accordion>
  <Accordion title="訊息未獲得 AI 回覆">
    - 檢查發送者的號碼是否在您的白名單中（如果使用 allowlist 策略）
    - 確認您的實例正在運行
    - 檢查您的 LemonData 餘額
  </Accordion>
</AccordionGroup>
