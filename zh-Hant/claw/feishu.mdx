將飛書 (Feishu) 或 Lark 連接至您的 LemonClaw 實例。本指南適用於託管的 Claw 實例和自託管的 LemonClaw 部署，並使用 WebSocket 模式，因此不需要公開的回調 URL。

## 前置條件

- 具備開發者權限的 [飛書](https://www.feishu.cn/) 或 [Lark](https://www.larksuite.com/) 帳號
- 一個 LemonClaw 實例：
  - 託管版：[建立 Claw 實例](https://lemondata.cc/dashboard/claw)
  - 自託管版：[安裝 LemonClaw](/claw/self-hosted)

## 設定指南

<Steps>
  <Step title="建立飛書應用程式">
    1. 前往 [飛書開放平台](https://open.feishu.cn/app) (或 [Lark Developer](https://open.larksuite.com/app))
    2. 點擊 **建立企業自建應用**
    3. 輸入應用程式名稱與描述
    4. 點擊 **建立**
  </Step>
  <Step title="添加機器人能力">
    1. 在您的應用程式設定中，前往 **添加應用能力** → **機器人**
    2. 啟用機器人能力
    3. 這將允許您的應用程式接收與發送訊息
  </Step>
  <Step title="獲取憑證">
    1. 前往 **憑證與基礎資訊**
    2. 複製 **App ID** (以 `cli_` 開頭)
    3. 複製 **App Secret**
  </Step>
  <Step title="設定事件訂閱">
    1. 前往 **事件訂閱**
    2. 選擇 **WebSocket** 模式 (推薦 — 不需要公開 URL)
    3. 如果有提示，請設定 **Encrypt Key** 與 **Verification Token**

    <Tip>
    當您在 LemonClaw WebUI 中設定飛書時，系統會為您 **自動生成** Encrypt Key 與 Verification Token。請將這些值複製到飛書開發者後台。
    </Tip>
  </Step>
  <Step title="添加事件權限">
    1. 在事件訂閱下，添加以下事件：
       - `im.message.receive_v1` — 接收訊息
    2. 前往 **權限管理** 並添加：
       - `im:message` — 發送與接收訊息
       - `im:message.group_at_msg` — 接收群組 @ 訊息
    3. 點擊 **儲存**
  </Step>
  <Step title="發佈應用程式">
    1. 前往 **版本管理與發佈** → **版本管理**
    2. 建立新版本
    3. 提交審核 (對於企業自建應用，這通常是即時的)
    4. 審核通過後，應用程式即正式上線
  </Step>
  <Step title="開啟 LemonClaw WebUI">
    1. 如果您使用的是託管版 Claw，請前往您的 [Claw 控制面板](https://lemondata.cc/dashboard/claw) 並點擊 **開啟 WebUI**
    2. 如果您是自託管 LemonClaw，請開啟您自己的 WebUI (例如 `http://your-ip:18789`) 並使用您的 token 登入
    3. 在 WebUI 中，導覽至 **Settings** → **Channels**
    4. 展開 **Feishu** 區塊
    5. 貼上您的 **App ID** 與 **App Secret**
    6. 將自動生成的 **Encrypt Key** 與 **Verification Token** 複製回飛書開發者後台
    7. 點擊 **Save**
  </Step>
  <Step title="開始聊天">
    1. 在飛書中，根據名稱搜尋您的機器人
    2. 向它發送訊息
    3. 第一個使用者將 **自動配對** 為擁有者 — 無需任何程式碼！
    4. 開始與 AI 聊天！
  </Step>
</Steps>

## 群組設定

在 LemonClaw WebUI 的 **Channels** 設定中配置群組聊天行為：

| 設定 | 選項 | 描述 |
|---------|---------|-------------|
| **Group Policy** | 開放 (預設) / 白名單 / 已停用 | 控制誰可以在群組中觸發機器人 |
| **Require @mention** | 開啟 / 關閉 | 機器人僅在被 @ 提及時回應 |
| **Group IDs** | 聊天 ID 列表 | 限制於特定群組 (留空 = 所有群組) |
| **Group Allowed Users** | Open ID 列表 | 僅這些使用者可以觸發機器人 (白名單模式) |

## 疑難排解

<AccordionGroup>
  <Accordion title="機器人收不到訊息">
    - 確認應用程式已發佈且已通過審核
    - 檢查是否已訂閱 `im.message.receive_v1` 事件
    - 確保選擇了 WebSocket 模式 (而非 HTTP)
    - 驗證飛書後台與您的 LemonClaw 設定中的 Encrypt Key 和 Verification Token 是否一致
  </Accordion>
  <Accordion title="'app_ticket' 錯誤">
    - 這通常意味著 App ID 或 App Secret 不正確
    - 請再次檢查控制面板中的憑證
  </Accordion>
</AccordionGroup>
