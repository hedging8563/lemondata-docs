<Note>
本指南適用於希望將 LemonData 作為 AI Provider 接入的 **OpenClaw** 自託管使用者。
</Note>

<Tip>
如果你想直接使用託管方案，可以[建立一個 LemonClaw 實例](/claw/introduction)；託管版預設已配置好 LemonData，可直接在 WebUI 中開始使用。
</Tip>

## 概覽

在目前的 OpenClaw 版本中，建議透過 `models.providers` 來設定 LemonData。

如果你只是想先快速跑起來，僅設定 `lemondata` 就足夠了。只有在你需要 **Responses API**、**Claude 原生**、**Gemini 原生** 或 **MiniMax 原生** 路徑時，再加入其他 provider。

| Provider | OpenClaw `api` | 適用場景 | baseUrl |
|----------|----------------|----------|---------|
| `lemondata` | `openai-completions` | GPT、DeepSeek、Qwen 以及大多數 OpenAI 相容呼叫 | `https://api.lemondata.cc/v1` |
| `lemondata-responses` | `openai-responses` | 需要 `/v1/responses` 語義的 OpenAI Responses 工作流 | `https://api.lemondata.cc/v1` |
| `lemondata-claude` | `anthropic-messages` | Claude 原生 Messages API | `https://api.lemondata.cc` |
| `lemondata-gemini` | `google-generative-ai` | Gemini 原生 API 格式 | `https://api.lemondata.cc` |
| `lemondata-minimax` | `anthropic-messages` | MiniMax 原生路徑 | `https://api.lemondata.cc` |

<Warning>
只有 `openai-completions` 與 `openai-responses` 需要使用 `/v1` 後綴。

像 `anthropic-messages`、`google-generative-ai` 這類原生 provider 應使用不帶 `/v1` 的 `https://api.lemondata.cc`；否則 OpenClaw 可能會組出錯誤的 upstream 路徑。
</Warning>

## 前置需求

- 一個自託管 OpenClaw 實例
- 一個 LemonData API Key — [在此取得](https://lemondata.cc/dashboard)

## 設定

編輯你的 OpenClaw 設定檔：

- **自託管**：`~/.openclaw/openclaw.json`

請將 LemonData provider 加入 `models.providers`：

```json5
{
  agents: {
    defaults: {
      model: {
        primary: "lemondata-claude/claude-sonnet-4-6"
      }
    }
  },
  models: {
    mode: "merge",
    providers: {
      lemondata: {
        api: "openai-completions",
        baseUrl: "https://api.lemondata.cc/v1",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "gpt-4o", name: "GPT-4o" },
          { id: "deepseek-r1", name: "DeepSeek R1" },
          { id: "qwen3-32b", name: "Qwen 3 32B" }
        ]
      },
      "lemondata-responses": {
        api: "openai-responses",
        baseUrl: "https://api.lemondata.cc/v1",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "gpt-4o", name: "GPT-4o (Responses)" },
          { id: "gpt-5.2", name: "GPT-5.2 (Responses)" }
        ]
      },
      "lemondata-claude": {
        api: "anthropic-messages",
        baseUrl: "https://api.lemondata.cc",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "claude-sonnet-4-6", name: "Claude Sonnet 4.6" },
          { id: "claude-opus-4-6", name: "Claude Opus 4.6" }
        ]
      },
      "lemondata-gemini": {
        api: "google-generative-ai",
        baseUrl: "https://api.lemondata.cc",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "gemini-2.5-flash", name: "Gemini 2.5 Flash" },
          { id: "gemini-3-flash-preview", name: "Gemini 3 Flash Preview" }
        ]
      },
      "lemondata-minimax": {
        api: "anthropic-messages",
        baseUrl: "https://api.lemondata.cc",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "minimax-m1", name: "MiniMax M1" }
        ]
      }
    }
  }
}
```

<Info>
這 5 個 provider 都使用 **同一個 API Key**。你只需要一個 LemonData 帳戶。
</Info>

<Info>
上面的 `models` 陣列只列出常見範例。你可以依需求持續往各個 provider 裡加入更多 model ID。
</Info>

## 使用模型

OpenClaw 仍然使用 `provider/model` 格式來引用模型：

```json5
{
  agents: {
    defaults: {
      model: {
        primary: "lemondata-gemini/gemini-2.5-flash"
      }
    }
  }
}
```

### 模型範例

| Provider | 模型引用 | 說明 |
|----------|----------|------|
| `lemondata` | `lemondata/gpt-4o` | OpenAI 相容路徑 |
| `lemondata` | `lemondata/deepseek-r1` | DeepSeek 推理模型 |
| `lemondata-responses` | `lemondata-responses/gpt-4o` | Responses API 路徑 |
| `lemondata-claude` | `lemondata-claude/claude-sonnet-4-6` | Claude 原生 Messages 路徑 |
| `lemondata-gemini` | `lemondata-gemini/gemini-2.5-flash` | Gemini 原生路徑 |
| `lemondata-minimax` | `lemondata-minimax/minimax-m1` | MiniMax 原生路徑 |

可在 [lemondata.cc/models](https://lemondata.cc/zh-tw/models) 瀏覽所有可用模型。

## 什麼時候該用哪個 provider？

- `lemondata`：大多數一般 chat 與 agent 場景的預設選擇。
- `lemondata-responses`：當你的 OpenClaw 工作流明確依賴 OpenAI Responses 語義時使用。
- `lemondata-claude`：當你需要 Claude Messages 的原生行為時使用。
- `lemondata-gemini`：當你需要 Gemini 原生格式，或想沿用既有的 Gemini 整合方式時使用。
- `lemondata-minimax`：當你想使用 MiniMax 的原生路徑時使用。

如果你不需要 Gemini 原生行為，也可以繼續透過 `lemondata/gemini-*` 走 OpenAI 相容路徑。

## 常見錯誤

<AccordionGroup>
  <Accordion title="仍在使用舊的頂層 providers 陣列">
    目前的 OpenClaw 文件以 `models.providers` 為準。如果你仍然沿用舊的頂層 `providers` 格式，OpenClaw 可能會忽略設定，或無法正確解析 provider 前綴。
  </Accordion>
  <Accordion title="lemondata-responses 忘了加 /v1">
    `openai-responses` 會走 LemonData 的 `/v1/responses` 路徑，因此 `lemondata-responses` 必須使用 `https://api.lemondata.cc/v1`。
  </Accordion>
  <Accordion title="在 lemondata-claude、lemondata-gemini 或 lemondata-minimax 上錯誤加了 /v1">
    `anthropic-messages` 與 `google-generative-ai` 都應使用不帶 `/v1` 的 `https://api.lemondata.cc`。如果加上 `/v1`，可能會產生錯誤的請求路徑。
  </Accordion>
  <Accordion title="OpenClaw 現在還支援 Gemini 原生嗎？">
    支援。當前 OpenClaw 文件仍保留內建 `google` provider，也支援使用 `api: &quot;google-generative-ai&quot;` 的自訂 provider。因此 `lemondata-gemini` 仍然是 OpenClaw 使用者可用的 Gemini 原生路徑。
  </Accordion>
</AccordionGroup>

## 驗證設定

儲存設定後，重新啟動你的 OpenClaw 實例，並送出一則簡單訊息測試。如果能收到回應，表示 provider 已設定完成。

```bash
# 自託管：重新啟動服務
systemctl --user restart openclaw    # Linux
launchctl stop cc.lemondata.openclaw && launchctl start cc.lemondata.openclaw  # macOS
```
