將 WeCom (企業微信 / WeChat Work) 與您的 LemonClaw 實例整合，為您的企業工作空間引入 AI。本指南適用於託管型 Claw 實例與自託管型 LemonClaw 部署。

## 前置條件

- 一個 [WeCom](https://work.weixin.qq.com/) 管理員帳號
- 一個 LemonClaw 實例：
  - 託管型：[建立一個 Claw 實例](https://lemondata.cc/dashboard/claw)
  - 自託管型：[安裝 LemonClaw](/claw/self-hosted)

## 設定指南

<Steps>
  <Step title="建立 WeCom 應用程式">
    1. 登入 [WeCom 管理後台](https://work.weixin.qq.com/wework_admin/frame)
    2. 前往 **應用管理** → **建立應用**
    3. 輸入應用程式名稱、上傳標誌並設定可見範圍
    4. 點擊 **建立**
  </Step>
  <Step title="獲取憑證">
    1. 記錄您的 **Corp ID** — 可在 **我的企業** → **企業資訊** 底部找到
    2. 在您的應用程式設定中，複製 **Secret** (Corp Secret)
  </Step>
  <Step title="設定回呼 URL">
    1. 在您的應用程式設定中，前往 **接收訊息** → **設定 API 接收**
    2. 對於託管型 Claw，當您展開 WeCom 區塊時，您的回呼 URL 會顯示在 LemonClaw WebUI 中：
    ```
    https://claw-{your-subdomain}.lemondata.cc/webhook/wecom
    ```
    3. 對於自託管型 LemonClaw，請公開您自己的 HTTPS URL，並以 `/webhook/wecom` 結尾
    4. 設定一個 **Token** (隨機字串) 與 **EncodingAESKey** (43 個字元的隨機字串)
    5. 點擊 **儲存** — WeCom 將驗證回呼 URL

    <Tip>
    託管型回呼 URL 顯示在 LemonClaw WebUI 中並附有複製按鈕。在驗證 URL 之前，請確保您的 LemonClaw 實例正在運行。
    </Tip>
  </Step>
  <Step title="打開 LemonClaw WebUI">
    1. 如果您使用的是託管型 Claw，請前往您的 [Claw 控制面板](https://lemondata.cc/dashboard/claw) 並點擊 **Open WebUI**
    2. 如果您是自託管 LemonClaw，請打開您自己的 WebUI (例如 `http://your-ip:18789`) 並使用您的 token 登入
    3. 在 WebUI 中，導覽至 **Settings** → **Channels**
    4. 展開 **WeCom** 區塊
    5. 如果您使用的是託管型 Claw，請複製頂部顯示的 **Callback URL**；如果您是自託管，請輸入您自己的公開 webhook URL
    6. 填寫：**Corp ID**、**Corp Secret**、**Token**、**EncodingAESKey**
    7. 點擊 **Save**
  </Step>
  <Step title="開始對話">
    1. 在 WeCom 中，於 **工作台** 找到您的應用程式
    2. 向應用程式發送訊息
    3. AI 將直接回應 — WeCom 不需要進行配對
  </Step>
</Steps>

<Warning>
**Token** 與 **EncodingAESKey** 在 WeCom 管理後台與您的 LemonClaw 設定之間必須完全一致。不匹配將導致訊息驗證失敗。
</Warning>

## 故障排除

<Note>
目前 LemonClaw 的企業微信支援仍以使用者級 1:1 訊息為主，完整的群提及、執行緒與回覆語義尚未提供。
</Note>

<AccordionGroup>
  <Accordion title="回呼 URL 驗證失敗">
    - 確保您的 LemonClaw 實例正在運行
    - 驗證 URL 格式：`https://claw-{subdomain}.lemondata.cc/webhook/wecom`
    - 在 WeCom 進行驗證 **之前**，檢查 Token 與 EncodingAESKey 是否已儲存在 LemonClaw 設定中
  </Accordion>
  <Accordion title="機器人沒有回應">
    - 驗證 Corp ID 與 Corp Secret 是否正確
    - 檢查應用程式對您的使用者帳號是否可見 (可見範圍設定)
    - 確保 WeCom 與 LemonClaw 之間的 Token 與 EncodingAESKey 一致
  </Accordion>
</AccordionGroup>
