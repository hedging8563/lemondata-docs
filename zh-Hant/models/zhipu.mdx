## 概览

LemonData 提供对智谱 AI (GLM) 模型的访问。总计：**6 个模型**可用。

## 对话模型

| 模型 ID | 计费 |
|----------|--------|
| `glm-4.5-air` | 见控制台 |
| `glm-4.6` | 见控制台 |
| `glm-4.6-thinking` | 见控制台 |
| `glm-4.6v` | 见控制台 |
| `glm-4.7` | 见控制台 |
| `glm-4.7-thinking` | 见控制台 |


## 使用方法

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="glm-4.5-air",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

<Note>
显示的费用为平台价格（约为官方价格的 70%）。
