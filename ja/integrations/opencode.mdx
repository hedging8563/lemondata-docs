## 概要

OpenCodeは、ターミナルで動作するオープンソースのAIコーディングアシスタントです。複数のLLMプロバイダーをサポートしており、LemonDataのAPIを使用して300以上のモデルにアクセスするように設定できます。

## インストール

<Tabs>
  <Tab title="インストールスクリプト">
    ```bash
    curl -fsSL https://opencode.ai/install | bash
    ```
  </Tab>
  <Tab title="Homebrew">
    ```bash
    brew install opencode-ai/tap/opencode
    ```

    または、コミュニティタップ（より頻繁な更新）を使用してください：
    ```bash
    brew install anomalyco/tap/opencode
    ```
  </Tab>
  <Tab title="Go">
    ```bash
    go install github.com/opencode-ai/opencode@latest
    ```
  </Tab>
</Tabs>

インストールの確認：

```bash
opencode --version
```

## 設定

### ステップ 1: 環境変数の設定

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

永続的な設定を行うには、`~/.bashrc` または `~/.zshrc` に追加してください：

```bash
echo 'export OPENAI_API_KEY="sk-your-lemondata-key"' >> ~/.zshrc
source ~/.zshrc
```

### ステップ 2: OpenCodeの設定

プロジェクトのルートディレクトリにある `~/.config/opencode/opencode.json`（グローバル）または `opencode.json` を作成または編集します：

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "lemondata": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "LemonData",
      "options": {
        "baseURL": "https://api.lemondata.cc/v1",
        "apiKey": "{env:OPENAI_API_KEY}"
      },
      "models": {
        "gpt-5.4": {
          "name": "GPT-5.4"
        },
        "gpt-4o": {
          "name": "GPT-4o"
        }
      }
    }
  },
  "model": "lemondata/gpt-5.4"
}
```

<Note>
チャット補完互換には `@ai-sdk/openai-compatible` を使用してください。`/v1/responses` が明確に必要な場合は、provider パッケージを `@ai-sdk/openai` に切り替えてください。
</Note>

## 基本的な使い方

**対話モードを開始する:**

```bash
opencode
```

**プロンプトを指定して実行する:**

```bash
opencode "Explain this codebase"
```

**モデルを指定する:**

```bash
opencode --model lemondata/gpt-5.4 "Fix the bugs in main.py"
```

## 利用可能なモデル

| モデル | 最適な用途 |
|-------|----------|
| `gpt-4o` | 複雑なタスク、コードアーキテクチャ |
| `gpt-4o-mini` | 迅速な修正、単純なクエリ |
| `claude-sonnet-4-5` | コードレビュー、ドキュメント作成 |
| `claude-opus-4-5` | 複雑な推論 |
| `gemini-2.5-flash` | 高速なレスポンス |
| `deepseek-r1` | アルゴリズム設計 |

## 一般的なコマンド

**コードを分析する:**

```bash
opencode "What does this function do?" < src/utils.ts
```

**コードを生成する:**

```bash
opencode "Create a REST API with Express"
```

**変更をレビューする:**

```bash
git diff | opencode "Review these changes"
```

**エラーを修正する:**

```bash
opencode "Fix the TypeScript errors in this project"
```

## 対話型コマンド

| コマンド | 説明 |
|---------|-------------|
| `/help` | 利用可能なコマンドを表示する |
| `/model <name>` | 別のモデルに切り替える |
| `/clear` | 会話履歴をクリアする |
| `/exit` | OpenCodeを終了する |

## トラブルシューティング

<AccordionGroup>
  <Accordion title="接続エラー">
    - `options.baseURL` が `https://api.lemondata.cc/v1` に設定されていることを確認してください
    - ネットワーク接続を確認してください
    - テストのために `curl https://api.lemondata.cc/v1/models` を試してください
  </Accordion>

  <Accordion title="認証に失敗しました">
    - `OPENAI_API_KEY` 環境変数が設定されていることを確認してください
    - キーが `sk-` で始まっていることを確認してください
    - LemonData ダッシュボードでキーが有効であることを確認してください
  </Accordion>

  <Accordion title="モデルが見つかりません">
    - 設定内のモデル名が正確に一致しているか確認してください
    - [lemondata.cc/en/models](https://lemondata.cc/ja/models) でモデルの利用可能性を確認してください
  </Accordion>
</AccordionGroup>
