## 概要

Dify は、OpenAI 互換の model provider フローを通じて LemonData と良好に連携します。

現在の Dify バージョンでは、通常、最も安全な方法は次のとおりです。
- 組み込みの **OpenAI** provider を選択する
- LemonData の API key を設定する
- カスタム base URL として `https://api.lemondata.cc/v1` を設定する

<Note>
一部の古い Dify ビルドでは、カスタム base URL フィールドを持つ組み込みの `OpenAI` provider ではなく、`OpenAI-API-compatible` として公開されている場合があります。Dify の UI が異なる場合は、そのバージョンで利用可能な OpenAI 互換のカスタム provider フローのうち、最も近いものを使用してください。
</Note>

## 前提条件

- API access を持つ LemonData アカウント
- Dify Cloud または self-hosted Dify

## 設定手順

### ステップ 1: API Key を取得する

1. [LemonData Dashboard](https://lemondata.cc/dashboard) にログインします
2. [API Keys](https://lemondata.cc/dashboard/api) を開きます
3. `sk-` で始まる API key を作成またはコピーします

### ステップ 2: Provider を設定する

<Steps>
  <Step title="Model Providers を開く">
    Dify で、**Settings** → **Model Providers** に移動します
  </Step>
  <Step title="OpenAI を選択する">
    **OpenAI** provider の設定を開きます。お使いの Dify バージョンでここにカスタム base URL が表示されない場合は、そのバージョンで公開されている OpenAI 互換のカスタム provider オプションを代わりに使用してください。
  </Step>
  <Step title="LemonData の設定を入力する">
    以下の値を使用します。

    | Field | Value |
    |-------|-------|
    | API Key | `sk-your-lemondata-key` |
    | API Base URL / Custom Base URL | `https://api.lemondata.cc/v1` |
  </Step>
  <Step title="Models を追加する">
    使用したい model を追加します。例:

    - `gpt-5.4`
    - `gpt-5-mini`
    - `gpt-4o`
    - `claude-sonnet-4-6`
    - `claude-opus-4-6`
    - `gemini-2.5-flash`
    - `gemini-2.5-pro`
    - `deepseek-r1`
  </Step>
</Steps>

### ステップ 3: 接続をテストする

1. `gpt-5-mini` または `gpt-4o` などの model を 1 つ選択します
2. テスト用の prompt を送信します
3. Dify が有効な response を受信することを確認します

## Knowledge Base 用の Embeddings

RAG と knowledge base indexing のために、次のような embedding model を追加します。
- `text-embedding-3-small`
- `text-embedding-3-large`

その後、関連する knowledge base または application settings で、それをデフォルトの embedding model として設定します。

## 推奨される Model Roles

| Use Case | Suggested Models |
|----------|------------------|
| デフォルトの chat | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| 深い reasoning | `gpt-5.4`, `claude-opus-4-6`, `deepseek-r1` |
| 高速 / 低コスト | `gpt-5-mini`, `gemini-2.5-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## ベストプラクティス

<AccordionGroup>
  <Accordion title="組み込みの OpenAI provider から始める">
    新しい Dify バージョンでは、カスタム base URL を持つ組み込みの OpenAI provider を使用する構成が、通常 LemonData にとって最もシンプルなセットアップです。
  </Accordion>

  <Accordion title="反復作業では低コストの model を使用する">
    反復中は `gpt-5-mini` または `gemini-2.5-flash` を使用し、より強力な model が必要な箇所にのみ、重い workflow を切り替えてください。
  </Accordion>

  <Accordion title="Dify は通常 chat-completions 指向であることを忘れない">
    ほとんどの Dify フローは OpenAI 互換の chat の動作を使用します。Codex 固有の Responses や WebSocket の動作が必要な場合は、Dify ではなく専用の Codex integrations を使用してください。
  </Accordion>
</AccordionGroup>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="Connection Error">
    - base URL が正確に `https://api.lemondata.cc/v1` であることを確認してください
    - Dify が末尾のスラッシュを重複させる場合は、末尾のスラッシュを削除してください
    - Dify server が public internet 経由で LemonData に到達できることを確認してください
  </Accordion>

  <Accordion title="401 Unauthorized">
    - API key を再確認してください
    - LemonData dashboard で key が有効であることを確認してください
    - Dify に貼り付けた値に余分なスペースや改行が含まれていないことを確認してください
  </Accordion>

  <Accordion title="Model Not Found">
    - model 名が完全に一致していることを確認してください
    - provider UI が古い値をキャッシュしている場合は、model エントリを再追加してください
    - 現在利用可能な model を LemonData docs または dashboard で確認してください
  </Accordion>
</AccordionGroup>
