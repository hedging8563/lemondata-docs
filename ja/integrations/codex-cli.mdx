## 概要

OpenAI Codex は、軽量なコーディングエージェントとして機能するオープンソースのコマンドラインツール（CLI）であり、ターミナル上でコードの読み取り、変更、実行が可能です。GPT モデル上に構築されており、コード生成向けに最適化されています。

## システム要件

- **OS**: macOS、Linux（公式サポート）、WSL 経由の Windows
- **Node.js**: バージョン 18+
- **npm**: バージョン 10.x.x 以上

## インストール

```bash
sudo npm install -g @openai/codex
```

インストールを確認します:

```bash
codex --version
```

## 設定

### ステップ 1: API Key を設定する

**一時的な設定（現在のセッション）:**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**永続的な設定:**

`~/.bashrc`、`~/.zshrc`、または `~/.bash_profile` に追加します:

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

その後、再読み込みします:

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### ステップ 2: config.toml を設定する

`~/.codex/config.toml` を編集します:

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
config ファイルが存在しない場合は、まず `codex` を一度実行して生成し、その後ファイルを編集してください。`config.toml` を変更した後は、新しい provider 設定が再読み込みされるように Codex を完全に再起動してください。
</Note>

<Warning>
Codex は custom provider に対する `chat/completions` のサポートを非推奨にしています。意図的に古い互換パスを使用している場合を除き、LemonData では `wire_api = "responses"` を維持してください。
</Warning>

## 基本的な使い方

**対話モードを開始する:**

```bash
codex
```

**直接コマンドを実行する:**

```bash
codex "Fix the bug in main.py line 42"
```

**モデルを指定する:**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## 推奨モデル

| Model | Best For |
|-------|----------|
| `gpt-5.4` | コーディングと推論のための最適なデフォルト選択 |
| `gpt-5-mini` | コーディングワークフロー向けの、より高速で低コストなフォールバック |
| `claude-sonnet-4-6` | コードレビュー、ドキュメント作成 |
| `deepseek-r1` | アルゴリズム設計、推論 |

## 対話コマンド

| Command | Description |
|---------|-------------|
| `/help` | ヘルプを表示 |
| `/exit` or `Ctrl+C` | 終了 |
| `/clear` | 会話をクリア |
| `/config` | 設定を表示 |
| `/model <name>` | モデルを切り替え |
| `/tokens` | token 使用量を表示 |

## 設定を確認する

```bash
# Check environment variable
echo $OPENAI_API_KEY

# Test API connection
codex "Hello, Codex!"

# View configuration
cat ~/.codex/config.toml
```

## 一般的なユースケース

**コードレビュー:**

```bash
git diff | codex "Review these code changes"
```

**コミットメッセージを生成する:**

```bash
git diff --staged | codex "Generate a commit message for these changes"
```

**エラーを修正する:**

```bash
codex "Fix the TypeScript errors in src/components/"
```

**コードを説明する:**

```bash
cat main.py | codex "Explain what this code does"
```

## トラブルシューティング

<AccordionGroup>
  <Accordion title="接続エラー">
    - config.toml 内の `base_url` が正確に `https://api.lemondata.cc/v1` であることを確認してください
    - ネットワーク接続を確認してください
    - proxy の干渉がないことを確認してください
  </Accordion>

  <Accordion title="認証失敗">
    - `~/.codex/config.toml` に `env_key = "OPENAI_API_KEY"` が存在することを確認してください
    - `OPENAI_API_KEY` 環境変数が設定されていることを確認してください
    - key が `sk-` で始まっていることを確認してください
    - LemonData ダッシュボードで key が有効であることを確認してください
  </Accordion>

  <Accordion title="モデルが見つかりません">
    - モデル名が正確に一致していることを確認してください
    - [lemondata.cc/en/models](https://lemondata.cc/ja/models) でモデルの利用可否を確認してください
  </Accordion>
</AccordionGroup>
