## 概要

Langflowの**OpenAI**コンポーネントには、**OpenAI API Base**フィールドが含まれています。このフィールドにTokenLabのOpenAI互換 `/v1` エンドポイントを指定し、TokenLabのモデルIDを使用してください。

<Note>
**タイプ**: ローコードAIワークフロービルダー

**主なパス**: OpenAI互換のチャット補完

**サポートの信頼性**: スコープ制限付きでサポート
</Note>

## OpenAIコンポーネント

1. **OpenAI**言語モデルコンポーネントを追加します。
2. **OpenAI API Key**にTokenLabのキーを設定します。
3. 詳細設定を展開します。
4. **OpenAI API Base**に `https://api.tokenlab.sh/v1` を設定します。
5. **Model Name**にTokenLabのモデルIDを設定します。
6. モデルの出力をエージェント、チェーン、またはワークフローに接続します。

## 値

| フィールド | 値 |
|-------|-------|
| OpenAI API Base | `https://api.tokenlab.sh/v1` |
| OpenAI API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

## 推奨モデル

- `gpt-5.4-mini`: ほとんどのワークフローテスト用
- `claude-sonnet-5`: より強力なライティングおよび推論用
- `gemini-3.5-flash`: 高速なマルチモーダル対応ワークフロー用
- `deepseek-v4-flash`: 高速なコーディングおよび推論の反復用

デプロイメントで既にLiteLLMプロキシを介したプロバイダーのルーティングを一元管理している場合は、LangflowのLiteLLM Proxyコンポーネントを使用してください。
