## 概要

LemonDataは、クライアントを `https://api.lemondata.cc/v1` に向けることで、公式のOpenAI SDKで動作します。

新規プロジェクトでは、**Responses API** を優先してください。フレームワーク、プラグイン、またはレガシーコードパスが引き続きそれを必要とする場合にのみ、**Chat Completions** を維持してください。

<Note>
Python、JavaScript、およびGoには公式のOpenAI SDKがあります。PHPはOpenAI互換のコミュニティクライアントで問題なく動作しますが、公式のOpenAI SDKではありません。
</Note>

## クライアントの設定

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## 推奨: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

## Responsesでのストリーミング

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Tools / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## ResponsesでのVision

```python
response = client.responses.create(

            {"type": "input_image", "image_url": "https://example.com/image.jpg"}
```

## Chat Completions 互換性

フレームワークまたはプラグインが引き続きChat Completionsを必要とする場合、LemonDataは標準のOpenAI互換パスもサポートしています。

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
Chat Completionsは互換性のためにのみ使用してください。新しい統合では、`client.responses.create(...)` を優先してください。
</Warning>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="接続エラー">
    - base URLが正確に `https://api.lemondata.cc/v1` であることを確認してください
    - プロキシの干渉やカスタムHTTPクライアントのオーバーライドを確認してください
    - プロバイダーの動作をデバッグする前に、SDKのバージョンが最新であることを確認してください
  </Accordion>

  <Accordion title="認証失敗">
    - API keyが `sk-` で始まっていることを確認してください
    - キーがLemonDataダッシュボードで有効になっていることを確認してください
    - SDKが `Authorization: Bearer ...` を送信していることを確認してください
  </Accordion>

  <Accordion title="誤ったAPIパス">
    - `responses.create(...)` は `/v1/responses` にリクエストを送信します
    - `chat.completions.create(...)` は `/v1/chat/completions` にリクエストを送信します
    - アプリが現時点でChat Completionsのみをサポートしている場合は、その互換パスを引き続き使用してください
  </Accordion>
</AccordionGroup>
