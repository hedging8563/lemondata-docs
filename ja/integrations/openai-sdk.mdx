## 概要

LemonData は、クライアントの向き先を `https://api.lemondata.cc/v1` に設定することで、公式 OpenAI SDK と連携して動作します。

新しいプロジェクトでは、**Responses API** を優先してください。フレームワーク、plugin、またはレガシーコードパスが引き続き必要としている場合にのみ、**Chat Completions** を使用してください。

<Note>
Python、JavaScript、Go には公式 OpenAI SDK があります。PHP は OpenAI 互換のコミュニティクライアントで問題なく動作しますが、公式 OpenAI SDK ではありません。
</Note>

## クライアントの設定

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## 推奨: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

## Responses でのストリーミング

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Tools / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## Responses での Vision

```python
response = client.responses.create(
```

## Chat Completions 互換性

お使いのフレームワークまたは plugin が引き続き Chat Completions を必要とする場合、LemonData は標準の OpenAI 互換パスもサポートしています。

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
互換性のためにのみ Chat Completions を使用してください。新しい統合では、`client.responses.create(...)` を優先してください。
</Warning>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="接続エラー">
    - base URL が正確に `https://api.lemondata.cc/v1` であることを確認してください
    - proxy の干渉やカスタム HTTP クライアントのオーバーライドを確認してください
    - プロバイダーの動作をデバッグする前に、SDK のバージョンが最新であることを確認してください
  </Accordion>

  <Accordion title="認証失敗">
    - API キーが `sk-` で始まっていることを確認してください
    - LemonData ダッシュボードでキーが有効になっていることを確認してください
    - SDK が `Authorization: Bearer ...` を送信していることを確認してください
  </Accordion>

  <Accordion title="誤った API パス">
    - `responses.create(...)` は `/v1/responses` にリクエストを送信します
    - `chat.completions.create(...)` は `/v1/chat/completions` にリクエストを送信します
    - 現時点でアプリが Chat Completions のみをサポートしている場合は、その互換パスを使用し続けてください
  </Accordion>
</AccordionGroup>
