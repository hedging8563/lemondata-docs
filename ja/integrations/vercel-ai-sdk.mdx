## 概要

LemonData では、Vercel AI SDK における最も安定したデフォルトは **OpenAI-compatible provider** です。

**Responses-native** の挙動が特に必要な場合は、OpenAI provider に切り替えつつ、同じ LemonData base URL を維持できます。

## 推奨デフォルト: OpenAI-Compatible Provider

```bash
npm install ai @ai-sdk/openai-compatible
```

```typescript
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

export const lemondata = createOpenAICompatible({
  name: 'lemondata',
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

## テキストを生成する

```typescript
import { generateText } from 'ai';
import { lemondata } from './lemondata';

const { text } = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});

console.log(text);
```

## テキストをストリーミングする

```typescript
import { streamText } from 'ai';
import { lemondata } from './lemondata';

const result = await streamText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Write a short poem about coding.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## Tool Calling

```typescript
import { generateText, tool } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const result = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'What is the weather in San Francisco?',
  tools: {
    weather: tool({
      description: 'Get weather in a location',
      parameters: z.object({
        location: z.string(),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72,
        condition: 'sunny',
      }),
    }),
  },
});

console.log(result.text);
```

## 構造化出力

```typescript
import { generateObject } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const { object } = await generateObject({
  model: lemondata.chatModel('gpt-5.4'),
  schema: z.object({
    name: z.string(),
    role: z.string(),
  }),
  prompt: 'Generate a fake developer profile.',
});

console.log(object);
```

## Responses-Native の挙動が明示的に必要な場合

```bash
npm install ai @ai-sdk/openai
```

```typescript
import { createOpenAI } from '@ai-sdk/openai';

export const lemondataResponses = createOpenAI({
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```typescript
import { generateText } from 'ai';
import { lemondataResponses } from './lemondata-responses';

const { text } = await generateText({
  model: lemondataResponses('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});
```

<Note>
proxy スタイルの統合では、安全なデフォルトとして `@ai-sdk/openai-compatible` を使用してください。`/v1/responses` 上に構築された provider path を明示的に利用したい場合にのみ、`@ai-sdk/openai` に切り替えてください。
</Note>

## 環境変数

```bash
# .env.local
LEMONDATA_API_KEY=sk-your-lemondata-key
```

## ベストプラクティス

<AccordionGroup>
  <Accordion title="まず openai-compatible を優先する">
    サードパーティの gateway や proxy backend では、通常 `@ai-sdk/openai-compatible` が最も意図しやすい出発点です。
  </Accordion>

  <Accordion title="必要な場合にのみ Responses に移行する">
    `/v1/responses` に結び付いた provider の挙動が必要な場合は、1 つの client で両方のパターンを混在させるのではなく、意図的に provider package を切り替えてください。
  </Accordion>

  <Accordion title="シークレットはサーバー上に保持する">
    LemonData API key をクライアントサイドのコードに決して公開しないでください。provider の設定はサーバーファイルまたは API route に配置してください。
  </Accordion>
</AccordionGroup>
