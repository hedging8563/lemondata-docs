## 概要

ほとんどの一般的なAIチャットアプリは、標準のOpenAI互換chat pathを通じてLemonDataに接続します。

実際には、これは次を意味します:
- アプリが完全なendpoint URLを明示的に要求しない限り、base URLとして`https://api.lemondata.cc/v1`を使用します
- OpenAI形式のAPI keyとして、LemonData API keyを使用します
- アプリが標準的なchat workflowで利用できるmodelsを選択します

<Note>
一般的なチャットアプリは通常、Codex Responses WebSocket clientsではなく、**chat-completions指向**です。Codex CLI/App、Cursor、またはResponses固有の動作を必要とするその他のコーディングツールについては、代わりに専用のintegration guidesを使用してください。
</Note>

## 対応アプリケーション

| Application | Platform | Notes |
|-------------|----------|-------|
| LobeChat | Web, Desktop, Self-hosted | 強力なcustom-providerサポート |
| Cherry Studio | Windows, macOS, Linux | 優れたOpenAI互換providerフロー |
| Chatbox | Windows, macOS, Linux | シンプルなOpenAI互換セットアップ |
| TypingMind | Web, Desktop | custom endpoint形式を使用 |
| BotGem | iOS, macOS | custom provider設定 |
| OpenCat | iOS, macOS | OpenAI互換custom endpointフロー |
| ChatWise | Windows, macOS | 標準的なcustom providerパターン |

## デフォルト接続値

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

アプリがbase URLではなく**完全なendpoint URL**を要求する場合は、次を使用してください:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## アプリ設定例

<Tabs>
  <Tab title="LobeChat">
    **Self-hosted LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. **Settings** → **AI Service Provider** を開きます
    2. **OpenAI** を選択します
    3. LemonData API keyを入力します
    4. custom endpointを `https://api.lemondata.cc/v1` に設定します
  </Tab>

  <Tab title="Cherry Studio">
    1. **Settings** → **Model Provider** を開きます
    2. **OpenAI-compatible** providerを追加します
    3. 次を入力します:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. 使用したいmodelsを追加します
  </Tab>

  <Tab title="Chatbox">
    1. **Settings** → **AI Model** を開きます
    2. **OpenAI API Compatible** を選択します
    3. 次を入力します:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` または `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. **Settings** を開きます
    2. **Custom Endpoint** を選択します
    3. 次を入力します:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. 公開したいmodelsを設定します
  </Tab>
</Tabs>

## より安全なデフォルトmodel

| Category | Suggested Models |
|----------|------------------|
| 一般的なデフォルト | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| Anthropic | `claude-sonnet-4-6`, `claude-opus-4-6` |

## ヒント

<AccordionGroup>
  <Accordion title="アプリが対応している場合はbase URLを優先する">
    ほとんどのアプリは、完全なendpoint URLではなく、base URLとして`https://api.lemondata.cc/v1`を指定したほうが、設定が容易で壊れにくくなります。
  </Accordion>

  <Accordion title="まずは小さいmodelsを使う">
    日常的なチャットには`gpt-5-mini`または`gpt-4o`から始め、その後、より重いreasoningタスクを`gpt-5.4`または`claude-opus-4-6`に移してください。
  </Accordion>

  <Accordion title="コーディングツールは分けておく">
    一般的なチャットアプリとcoding agentsでは、必要となるendpointの動作が異なることがよくあります。Codex/Cursorスタイルのツールは、専用のintegration pagesで分けて管理してください。
  </Accordion>
</AccordionGroup>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="接続エラー">
    - base URLが正確に`https://api.lemondata.cc/v1`であることを確認してください
    - アプリがpathを自動追加する場合は、末尾のスラッシュを削除してください
    - アプリが完全なendpoint URLを要求する場合は、`https://api.lemondata.cc/v1/chat/completions`を使用してください
  </Accordion>

  <Accordion title="401 Unauthorized">
    - API keyを再確認してください
    - LemonData dashboardでkeyが有効であることを確認してください
    - 余分なスペースや改行がないことを確認してください
  </Accordion>

  <Accordion title="Model Not Available">
    - model名が正確であることを確認してください
    - `gpt-5-mini`、`gpt-4o`、または`claude-sonnet-4-6`のような広くサポートされているデフォルトを試してください
    - LemonData docsまたはdashboardで現在の利用可否を確認してください
  </Accordion>
</AccordionGroup>
