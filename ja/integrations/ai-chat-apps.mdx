## 概要

ほとんどの汎用 AI チャットアプリは、標準の OpenAI-compatible chat path を通じて LemonData に接続します。

実際には、これは次のことを意味します:
- アプリが完全な endpoint URL を明示的に要求しない限り、base URL として `https://api.lemondata.cc/v1` を使用します
- OpenAI-style API key として、LemonData API key を使用します
- アプリが標準的な chat workflow で使用できる model を選択します

<Note>
一般的なチャットアプリは通常、**chat-completions 指向**であり、Codex Responses WebSocket client ではありません。Codex CLI/App、Cursor、または Responses 固有の動作を必要とするその他の coding tool については、代わりに専用の integration guide を使用してください。
</Note>

## 対応アプリケーション

| Application | Platform | Notes |
|-------------|----------|-------|
| LobeChat | Web、Desktop、Self-hosted | 強力な custom-provider サポート |
| Cherry Studio | Windows、macOS、Linux | 優れた OpenAI-compatible provider フロー |
| Chatbox | Windows、macOS、Linux | シンプルな OpenAI-compatible セットアップ |
| TypingMind | Web、Desktop | custom endpoint スタイルを使用 |
| BotGem | iOS、macOS | custom provider 設定 |
| OpenCat | iOS、macOS | OpenAI-compatible custom endpoint フロー |
| ChatWise | Windows、macOS | 標準的な custom provider パターン |

## デフォルト接続値

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

アプリが base URL ではなく**完全な endpoint URL**を要求する場合は、次を使用してください:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## アプリ設定例

<Tabs>
  <Tab title="LobeChat">
    **Self-hosted LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. **Settings** → **AI Service Provider** を開きます
    2. **OpenAI** を選択します
    3. LemonData API key を入力します
    4. custom endpoint を `https://api.lemondata.cc/v1` に設定します
  </Tab>

  <Tab title="Cherry Studio">
    1. **Settings** → **Model Provider** を開きます
    2. **OpenAI-compatible** provider を追加します
    3. 次を入力します:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. 使用したい model を追加します
  </Tab>

  <Tab title="Chatbox">
    1. **Settings** → **AI Model** を開きます
    2. **OpenAI API Compatible** を選択します
    3. 次を入力します:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` または `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. **Settings** を開きます
    2. **Custom Endpoint** を選択します
    3. 次を入力します:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. 公開したい model を設定します
  </Tab>
</Tabs>

## ヒント

<AccordionGroup>
  <Accordion title="アプリが対応している場合は base URL を優先する">
    ほとんどのアプリでは、完全な endpoint URL ではなく、base URL として `https://api.lemondata.cc/v1` を指定する方が設定しやすく、壊れにくくなります。
  </Accordion>

  <Accordion title="まずは小さな model から使う">
    日常的なチャットには `gpt-5-mini` または `gpt-4o` から始めて、その後、より重い reasoning task には `gpt-5.4` または `claude-opus-4-6` に移行してください。
  </Accordion>

  <Accordion title="coding tool は分けて運用する">
    一般的なチャットアプリと coding agent では、必要な endpoint の動作が異なることがよくあります。Codex/Cursor-style tool は専用の integration page で管理してください。
  </Accordion>
</AccordionGroup>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="接続エラー">
    - base URL が正確に `https://api.lemondata.cc/v1` であることを確認してください
    - アプリが path を自動追加する場合は、末尾の slash を削除してください
    - アプリが完全な endpoint URL を必要とする場合は、`https://api.lemondata.cc/v1/chat/completions` を使用してください
  </Accordion>

  <Accordion title="401 Unauthorized">
    - API key を再確認してください
    - key が LemonData dashboard で有効になっていることを確認してください
    - 余分な空白や改行が含まれていないことを確認してください
  </Accordion>

  <Accordion title="Model Not Available">
    - model 名が正確であることを確認してください
    - `gpt-5-mini`、`gpt-4o`、または `claude-sonnet-4-6` のような広くサポートされているデフォルトを試してください
    - 現在の利用可否を LemonData docs または dashboard で確認してください
  </Accordion>
</AccordionGroup>
