## 概要

LemonDataはMetaモデルへのアクセスを提供します。合計で**7つのモデル**が利用可能です。

## チャットモデル

| モデルID | 料金 |
|----------|--------|
| `llama-3.1-8b` | ダッシュボードを参照 |
| `llama-3.2-11b-vision-instruct` | ダッシュボードを参照 |
| `llama-3.2-1b-instruct` | ダッシュボードを参照 |
| `llama-3.2-3b-instruct` | ダッシュボードを参照 |
| `llama-3.2-90b-vision-instruct` | ダッシュボードを参照 |
| `llama-4-maverick` | ダッシュボードを参照 |
| `llama-4-scout` | ダッシュボードを参照 |


## 使い方

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="llama-3.1-8b",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

表示されている価格はプラットフォーム価格です（公式料金の約70%）。
