---
title: "Embedding の作成"
api: "POST /v1/embeddings"
description: "入力テキストを表す Embedding ベクトルを作成します"
---

## リクエストボディ

<ParamField body="model" type="string" required>
  使用する Embedding モデルの ID（例：`text-embedding-3-small`）。
</ParamField>

<ParamField body="input" type="string | array" required>
  Embedding する入力テキスト。文字列または文字列の配列を指定できます。
</ParamField>

<ParamField body="encoding_format" type="string" default="float">
  Embedding の形式：`float` または `base64`。
</ParamField>

<ParamField body="dimensions" type="integer">
  出力の次元数（モデル固有）。
</ParamField>

<ParamField body="user" type="string">
  不正利用の監視を目的とした、エンドユーザーを表す一意の識別子。
</ParamField>

## 利用可能なモデル

| モデル | 次元数 | 説明 |
|-------|------------|-------------|
| `text-embedding-3-large` | 3072 | 最高品質 |
| `text-embedding-3-small` | 1536 | バランス重視 |
| `text-embedding-ada-002` | 1536 | レガシー |

## レスポンス

<ResponseField name="object" type="string">
  常に `list`。
</ResponseField>

<ResponseField name="data" type="array">
  Embedding オブジェクトの配列。

  各オブジェクトには以下が含まれます：
  - `object` (string): `embedding`
  - `index` (integer): 入力配列内のインデックス
  - `embedding` (array): Embedding ベクトル
</ResponseField>

<ResponseField name="model" type="string">
  使用されたモデル。
</ResponseField>

<ResponseField name="usage" type="object">
  `prompt_tokens` および `total_tokens` を含む Token 使用量。
</ResponseField>
