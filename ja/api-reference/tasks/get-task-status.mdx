---
title: "タスクステータスを取得"
description: "create エンドポイントで返される poll_url を使用して、任意の async タスクのステータスと結果を取得します"
---

## 概要

video、image、music、3D generation などのタスクタイプ全体で統一された async ポーリングを行うには、このエンドポイントを使用します。

<Info>
create レスポンスに `poll_url` が含まれている場合は、その完全に一致するパスを呼び出してください。新しい async ワークフローでは、`poll_url` は `/v1/tasks/{id}` を指す場合があります。
</Info>

## パスパラメータ

<ParamField path="id" type="string" required>
  create リクエストによって返されるタスク ID。
</ParamField>

## レスポンス

<ResponseField name="id" type="string">
  タスク識別子。
</ResponseField>

<ResponseField name="status" type="string">
  `pending`、`processing`、`completed`、または `failed` などのタスクステータス。
</ResponseField>

<ResponseField name="video_url" type="string">
  タスクが完了して video を生成した場合の結果アセット URL。
</ResponseField>

<ResponseField name="error" type="string">
  タスクが失敗した場合のエラーメッセージ。
</ResponseField>

## 例

```bash cURL
curl "https://api.lemondata.cc/v1/tasks/video_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

poll_url = "/v1/tasks/video_abc123"
response = requests.get(
    f"https://api.lemondata.cc{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/video_abc123';
const response = await fetch(`https://api.lemondata.cc${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
