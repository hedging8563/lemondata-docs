---
title: "マテリアルアセットの削除"
openapi: "DELETE /v1/videos/assets/{assetId}"
description: "現在の組織が所有するSeedanceマテリアルアセットを削除します。"
---

マテリアルアセットを1つ削除します。これによって、そのアセットを含むマテリアルグループが削除されることはありません。削除後、そのアセットIDを `material_asset_id` として使用することはできなくなります。

## リクエスト例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## レスポンス例

```json
{
  "deleted": true,
  "id": "asset-20260720123456-qn7wr"
}
```
