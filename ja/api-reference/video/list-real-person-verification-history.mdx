---
title: "実在人物確認履歴の一覧取得"
openapi: "GET /v1/videos/assets/visual-validation-sessions"
description: "現在の組織における実在人物の素材確認セッションを一覧表示します。"
---

レビュー、カスタマーサポート、および照合のために、過去の確認セッションを一覧表示します。この履歴は長期保存されますが、短期間のバインドステップの代わりにはなりません。確認が成功した場合は、引き続き120秒のウィンドウ内で直ちにバインドを行う必要があります。

レスポンスには TokenLab ID のみが含まれ、認証データは含まれません。バインドが成功した後、`group_id` は `liveness_face` アップロードに使用される TokenLab 素材グループ ID となります。

## リクエスト例

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions?page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
