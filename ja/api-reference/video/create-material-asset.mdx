---
title: "マテリアルアセットの作成"
openapi: "POST /v1/videos/assets"
description: "SeedanceマテリアルアセットをTokenLabマテリアルグループにアップロードします。"
---

公開されているソースURLからSeedanceマテリアルグループにインポートします。TokenLabは後で使用するためにマテリアルを保存します。生成時にはソースURLではなく、返されたマテリアルアセットの `id` を使用してください。

`library_type: "aigc_avatar"` の場合、`group_id` は任意です。TokenLabは組織のデフォルトのバーチャルアバターグループを使用または作成します。`library_type: "liveness_face"` の場合、`group_id` は必須であり、[実在人物確認結果の紐付け](/ja/api-reference/video/bind-real-person-verification-result)によって返されるTokenLabグループである必要があります。

| タイプ | サポートされている入力 |
|------|-----------------|
| 画像 | `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; アスペクト比 `(0.4, 2.5)`; 幅と高さ `(300, 6000)` px; 30 MB未満。 |
| 動画 | `mp4`, `mov`; `480p`, `720p`, または `1080p`; 2〜15秒; アスペクト比 `[0.4, 2.5]`; 幅と高さ `[300, 6000]` px; 総画素数 409600〜2086876; 50 MBまで; 24〜60 FPS。 |
| 音声 | `wav`, `mp3`; 2〜15秒; 15 MBまで。 |

作成は非同期で行われます。`status` が `ACTIVE` になるまで [マテリアルアセットの取得](/ja/api-reference/video/get-material-asset) をポーリングしてください。実在人物グループの場合、1つのグループは1人の認証済み人物に対応します。複数の顔が含まれている場合や、認証済みの人物と一致しない顔がアップロードされた場合は失敗する可能性があります。

## リクエスト例

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"seedance_group_virtual_123","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view"}'
```
