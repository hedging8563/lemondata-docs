---
title: "マテリアルアセットグループの削除"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "現在の組織が所有するSeedanceマテリアルグループを削除します。"
---

マテリアルグループおよびその内部にあるTokenLabマテリアルアセットを削除します。この操作は取り消すことができません。

現在の認証状態が許可されていないためにTokenLabマテリアルライブラリが削除を完了できない場合、TokenLabはニュートラルなマテリアルライブラリエラーを返します。削除後、そのグループおよびアセットは動画生成に使用できなくなります。

## リクエスト例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## レスポンス例

```json
{
  "deleted": true,
  "id": "seedance_group_virtual_123"
}
```
