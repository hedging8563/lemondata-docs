openapi: "POST /v1/videos/generations"
description: "動画生成タスクを作成します"
---

## 概要

動画生成は非同期です。リクエストを送信すると、task ID と `poll_url` を受け取り、その後結果を取得するためにポーリングを行います。

<Info>
最も信頼性の高いポーリング動作を実現するには、作成リクエストで返された正確な `poll_url` に従ってください。
</Info>

<Warning>
音声出力はモデル依存です。LemonData では、Veo 3 ファミリーは `output_audio` を省略すると既定で音声オンとして扱われます。モデルが音声制御に対応している場合は、`output_audio` を使って明示的に切り替えてください。camelCase の別名 `outputAudio` も互換性のために受け付けます。
</Warning>


## リクエストボディ

<ParamField body="model" type="string" default="sora-2">
  動画モデル ID。API のデフォルトは `sora-2` です。現在のモデル対応表とサポートされている機能については、[動画生成ガイド](/guides/video-generation)を参照してください。
</ParamField>

<ParamField body="prompt" type="string" required>
  生成する動画のテキスト説明。
</ParamField>

<ParamField body="image_url" type="string">
  image-to-video（I2V）生成用の開始画像の公開アクセス可能な URL。モデル間の互換性を最大化するには、`image_url` の使用を推奨します。
</ParamField>

<ParamField body="image" type="string">
  data URL としてのインライン画像（例: `data:image/jpeg;base64,...`）。互換性のあるモデルでサポートされていますが、`image_url` は動画モデル全体で最も広い互換性を提供します。
</ParamField>

<ParamField body="duration" type="integer">
  動画の長さ（秒）（モデル依存）。
</ParamField>

<ParamField body="aspect_ratio" type="string">
  アスペクト比（例: `16:9`、`9:16`、`1:1`）。
</ParamField>

<ParamField body="resolution" type="string">
  動画解像度（例: `1080p`、`720p`）。
</ParamField>

<ParamField body="output_audio" type="boolean">
  モデル依存の音声出力トグルです。LemonData では、この項目を省略すると Veo 3 ファミリーは既定で `true` として扱われます。他の動画モデルは、それぞれ定義されたデフォルト動作に従います。camelCase の別名 `outputAudio` も互換性のために受け付けます。
</ParamField>

<ParamField body="fps" type="integer">
  1 秒あたりのフレーム数（1～120）。
</ParamField>

<ParamField body="negative_prompt" type="string">
  動画生成で避けたい内容。
</ParamField>

<ParamField body="seed" type="integer">
  再現可能な生成のためのランダム seed。
</ParamField>

<ParamField body="cfg_scale" type="number">
  Classifier-free guidance scale（0～20）。
</ParamField>

<ParamField body="motion_strength" type="number">
  モーション強度（0～1）。
</ParamField>

<ParamField body="start_image" type="string">
  開始フレーム画像の URL。
</ParamField>

<ParamField body="end_image" type="string">
  終了フレーム画像の URL。
</ParamField>

<ParamField body="user" type="string">
  エンドユーザー向けの一意識別子。
</ParamField>

## レスポンス

<ResponseField name="task_id" type="string">
  ポーリング用の一意なタスク識別子。
</ResponseField>

<ResponseField name="poll_url" type="string">
  このタスクに推奨されるポーリング URL。ステータス確認時にはこの正確なパスを使用してください。
</ResponseField>

<ResponseField name="status" type="string">
  初期ステータス: `pending`。
</ResponseField>

<ResponseField name="model" type="string">
  使用されたモデル。
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={
        "Authorization": "Bearer sk-your-api-key",
        "Content-Type": "application/json"
    },
    json={
        "model": "sora-2",
        "prompt": "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)

data = response.json()
task_id = data["task_id"]
print(f"Poll URL: {data['poll_url']}")
print(f"Task ID: {task_id}")
```

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Poll URL: %s\n", result["poll_url"])
    fmt.Printf("Task ID: %s\n", result["task_id"])
}

## 画像から動画

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/image.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)
```

## キーフレーム制御

最初と最後のフレームを制御するには `start_image` と `end_image` を使用します（Vidu Q2 Pro でサポート）:

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night",
        "operation": "開始・終了フレームから動画",
        "start_image": "https://example.com/day.jpg",
        "end_image": "https://example.com/night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```
