---
title: "実在人物確認セッションの作成"
openapi: "POST /v1/videos/assets/visual-validation-sessions"
description: "TokenLabの実在人物素材確認用H5セッションを作成します。"
---

短期間有効な確認セッションを作成し、ユーザーを返されたH5リンクへリダイレクトします。TokenLabは、`session_id`、`h5_link`、`callback_url`、`expires_in`、`language`という中立的なフィールドのみを返します。

セッションとH5リンクは120秒後に期限切れとなります。紐付け用トークンはTokenLabのコールバックリダイレクトでのみ提供されます。H5フローが完了すると、TokenLabは以下のクエリパラメータを付与して、元の `callback_url` にリダイレクトします。

| パラメータ | 意味 |
|-----------|---------|
| `session_id` | TokenLab確認セッションID。 |
| `verification_token` | 結果を紐付けるために使用される不透明なトークン。 |
| `verification_status` | `succeeded` または `failed`。 |
| `result_code` | アプリケーションロジック用の結果コード。 |

`verification_status` が `succeeded` の場合は、[実在人物確認結果の紐付け](/ja/api-reference/video/bind-real-person-verification-result)を呼び出してください。フローを製品に組み込む前に、[テストコンソール](https://tokenlab.sh/dashboard/seedance-assets)を使用してコールバック処理を確認できます。

## リクエスト例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"callback_url":"https://yourapp.example.com/seedance/callback","language":"en"}'
```

## レスポンス例

```json
{
  "object": "seedance.visual_validation_session",
  "session_id": "svv_abc123",
  "h5_link": "https://verify.example.com/h5?lng=en",
  "callback_url": "https://yourapp.example.com/seedance/callback",
  "expires_in": 120,
  "language": "en"
}
```
