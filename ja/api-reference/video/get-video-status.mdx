title: "ビデオステータスの取得"
openapi: "GET /v1/tasks/{id}"
description: "ビデオ生成タスクのステータスと結果を取得します"
---

## パスパラメータ

<ParamField path="id" type="string" required>
  正規の非同期タスク ID です。`id` と `task_id` の両方がある場合は、同じタスク識別子として扱ってください。
</ParamField>

<Info>
作成レスポンスで `poll_url` が返る場合は、その URL をそのまま使ってください。`/v1/tasks/{id}` を指す場合は、それを固定の正規ステータスエンドポイントとして扱ってください。
</Info>

## レスポンス

<ResponseField name="id" type="string">
  正規の非同期タスク ID です。
</ResponseField>

<ResponseField name="task_id" type="string">
  非同期タスク ID の別名です。
</ResponseField>

<ResponseField name="poll_url" type="string">
  作成レスポンスが返す優先ポーリング URL です。
</ResponseField>

<ResponseField name="status" type="string">
  タスクのステータス: `pending`、`processing`、`completed`、`failed`。
</ResponseField>

<ResponseField name="progress" type="number">
  進捗率 (0-100)。
</ResponseField>

<ResponseField name="video_url" type="string">
  生成されたビデオのURL（完了時）。
</ResponseField>

<ResponseField name="video" type="object">
  利用可能な場合、`url`、`duration`、`width`、`height` を含む単一動画オブジェクトです。
</ResponseField>

<ResponseField name="videos" type="array">
  上流が複数出力を返す場合の動画配列です。
</ResponseField>

<ResponseField name="error" type="string">
  エラーメッセージ（失敗時）。
</ResponseField>

<ResponseField name="created" type="integer">
  作成日時のタイムスタンプ。
</ResponseField>

<ResponseField name="updated" type="integer">
  最終更新日時のタイムスタンプ。
</ResponseField>

<ResponseField name="model" type="string">
  タスクで使用されたモデルです。
</ResponseField>

<RequestExample>

curl "https://api.lemondata.cc/v1/tasks/video_abc123" \

```python Python
import requests
import time

task_id = "video_abc123"

while True:
    response = requests.get(
        f"https://api.lemondata.cc/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )

    data = response.json()
    print(f"Status: {data['status']}, Progress: {data.get('progress', 0)}%")

    if data["status"] == "completed":
        print(f"Video URL: {data['video_url']}")
        break
    elif data["status"] == "failed":
        print(f"Error: {data['error']}")
        break

    time.sleep(5)  # Poll every 5 seconds
```

## ポーリングのベストプラクティス

- 5〜10秒ごとにポーリングを行う
- 長時間のタスクにはエクスポネンシャルバックオフを実装する
- 最大タイムアウト（例：10分）を設定する
- `failed` ステータスを適切に処理する

```python
import time

def wait_for_video(task_id, max_wait=600, interval=5):
    """Wait for video with timeout."""
    start = time.time()

    while time.time() - start < max_wait:
        response = requests.get(
            f"https://api.lemondata.cc/v1/tasks/{task_id}",
            headers={"Authorization": "Bearer sk-your-api-key"}
        )
        data = response.json()

        if data["status"] == "completed":
            return data["video_url"]
        elif data["status"] == "failed":
            raise Exception(data.get("error", "Video generation failed"))

        time.sleep(interval)

    raise TimeoutError("Video generation timed out")
```
