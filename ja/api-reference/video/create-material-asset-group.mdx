---
title: "マテリアルアセットグループの作成"
openapi: "POST /v1/videos/assets/groups"
description: "Seedanceバーチャルアバターのマテリアルグループを作成します。"
---

`library_type: "aigc_avatar"` のマテリアルグループを作成します。このエンドポイントは、実在人物の認証を必要としないバーチャルアバター、製品、スタイル、およびその他の再利用可能な参照用に使用してください。

新しい実在人物のマテリアルグループは、[実在人物マテリアル認証](/ja/api-reference/video/create-real-person-verification-session)を通じて作成されるため、このエンドポイントから直接作成することはできません。

## リクエスト例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_name":"Product references","description":"Reusable product shots"}'
```

## レスポンス例

```json
{
  "id": "seedance_group_virtual_123",
  "object": "seedance.material_asset_group",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
