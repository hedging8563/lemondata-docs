---
title: "実人認証結果の紐付け"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "成功した実人認証結果をTokenLab素材グループに紐付けます。"
---

成功した認証結果を紐付け、TokenLabの実人素材グループマッピングを作成します。認証セッションまたはTokenLabのコールバックリダイレクトから取得した `session_id` および `verification_token` を使用してください。

TokenLabは、そのセッションが同一組織に属しているか、有効期限が切れていないか、および認証セッションで使用されたものと同じ素材サービスに紐付けられているかを確認します。レスポンスではTokenLabの `group_id` のみが返されます。`liveness_face` 素材アセットを作成する際にこれを使用してください。

## リクエスト例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## レスポンス例

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "seedance_group_real_123",
  "material_group": {
    "id": "seedance_group_real_123",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
