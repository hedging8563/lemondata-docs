---
title: "マテリアルアセットの取得"
openapi: "GET /v1/videos/assets/{assetId}"
description: "TokenLabマテリアルアセットIDを使用して、Seedanceマテリアルアセットを1つ取得します。"
---

マテリアルアセットを1つ取得し、その処理ステータスを確認します。アセットは、`ready` が `true` であり、かつ `status` が `ACTIVE` である場合にのみ、動画生成に使用できます。

動画生成時に `Seedance material asset not found or not accessible` というエラーが返される場合は、`group_id` ではなく、このマテリアルアセットの `id` を渡していることを確認してください。

## リクエスト例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## レスポンス例

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "asset_url": "https://example.com/reference.png",
  "cover_url": null,
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
