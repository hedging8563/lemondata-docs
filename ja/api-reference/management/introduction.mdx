## 概要

管理 API では、通常の推論 API キーを使わずに、組織の API キー管理と特定キーの使用量・請求確認を自動化できます。

Dashboard の **Settings** ページで管理トークンを取得してください：

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
管理トークンは推論用 API キーではありません。`mt-...` は `/v1/management/*` 用、`sk-...` は `/v1/responses` などの推論エンドポイント用です。
</Warning>

## 利用可能なエンドポイント

| Endpoint | Method | 説明 |
|----------|--------|------|
| `/v1/management/api-keys` | GET | 現在の組織にあるユーザー API キーを一覧表示します |
| `/v1/management/api-keys` | POST | 新しいユーザー API キーを作成します |
| `/v1/management/api-keys/{keyId}` | PATCH | 名前、利用上限、許可モデル、有効期限、状態を更新します |
| `/v1/management/api-keys/{keyId}/usage` | GET | 特定キーのページネーション付き使用量明細を取得します |
| `/v1/management/api-keys/{keyId}/billing` | GET | 特定キーの集計済み請求内訳を取得します |

## 項目の説明

- リクエストで指定するモデル名（`model`）
- 公開モデルベンダー
- `scene`
- `accessChannel`：`platform` はプラットフォーム経由で課金されたことを示し、`byok` は自分の上流 Provider キーを使ったことを示します
- 使用量、課金単位、キャッシュ指標
- コストとタイムスタンプ

レスポンスには公開されている課金・レポート項目のみが含まれ、内部ルーティングや物理チャネルの詳細は表示されません。

## フィルター

`/usage` と `/billing` では現在、以下の条件で絞り込みできます：

- 期間
- リクエストで指定するモデル名（`model`）
- 公開モデルベンダー
- `scene`
- `accessChannel`
- ページネーション

## 完全なリクエスト例

まずは現在の管理トークンで、この組織の API キー一覧を取得します：

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```

```python Python
import requests

response = requests.get(
    "https://api.lemondata.cc/v1/management/api-keys",
    headers={"Authorization": "Bearer mt-your-management-token"}
)

data = response.json()
for key in data["data"]:
    print(key["name"], key["status"], key["used_amount"])
```

```javascript JavaScript
const response = await fetch(
  'https://api.lemondata.cc/v1/management/api-keys',
  {
    headers: {
      'Authorization': 'Bearer mt-your-management-token'
    }
  }
);

const data = await response.json();
for (const key of data.data) {
  console.log(key.name, key.status, key.used_amount);
}
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/management/api-keys", nil)
    req.Header.Set("Authorization", "Bearer mt-your-management-token")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)

    fmt.Println(result["object"])
}
```

```php PHP
<?php
$ch = curl_init("https://api.lemondata.cc/v1/management/api-keys");

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer mt-your-management-token'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
foreach ($data['data'] as $key) {
    echo $key["name"] . " " . $key["status"] . " " . $key["used_amount"] . PHP_EOL;
}
```
</RequestExample>
