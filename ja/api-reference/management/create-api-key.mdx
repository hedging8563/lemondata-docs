## 概要

この endpoint は、現在の management token に紐づく組織内で新しい `type=user` API Key を作成します。

## リクエストボディ

| 項目 | 型 | 既定値 / 制約 | 説明 |
|-------|------|------------------|-------|
| name | string | 必須、既定値 Default Key、長さ 1-50 | 表示名。サーバー側で trim されます |
| limitAmount | number \| null | 最小 0、最大 100000 | null または省略 = 無制限、0 = 利用不可、正の値 = USD 上限 |
| models | string[] | 既定値 [] | 任意の logical model 許可リスト |
| expiresAt | string \| null | RFC3339 datetime | null は無期限を意味します |

## 注意事項

- 完全な API Key 値はレスポンスで一度だけ表示されます。
- `models: []` は、組織ポリシー以外の追加モデル制限がないことを意味します。
- `limitAmount: 0` は有効だが使用可能クォータのないキーを作成し、後で更新する前提になります。

## 例

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "sora-2"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>
