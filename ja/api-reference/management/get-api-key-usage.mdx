## 概要

このエンドポイントは、リクエストで指定するモデル名（`model`）、公開モデルベンダー、`scene`、`accessChannel` で絞り込めるキー単位の使用量明細を返します。

## 注意事項

- レスポンスに含まれるのは公開課金フィールドのみです。
- 内部ルーティングや物理チャネルのメタデータは非表示です。

## リクエスト / レスポンス

正確なスキーマについては、上記のインタラクティブな OpenAPI パネルを使用してください。
