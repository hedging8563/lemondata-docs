---
title: "チャット補完を作成"
openapi: "POST /v1/chat/completions"
description: "チャットメッセージの補完を作成します"
---

## リクエストボディ

<ParamField body="model" type="string" required>
  使用する model の ID。利用可能なオプションについては [Models](https://lemondata.cc/ja/models) を参照してください。
</ParamField>

<ParamField body="messages" type="array" required>
  会話を構成するメッセージのリスト。

  各メッセージオブジェクトには以下が含まれます:
  - `role` (string): `system`, `user`, または `assistant`
  - `content` (string | array): メッセージの内容
</ParamField>

<ParamField body="temperature" type="number" default="1">
  0 から 2 の間の sampling temperature。値が高いほど、出力のランダム性が高くなります。
</ParamField>

<ParamField body="max_tokens" type="integer">
  生成する token の最大数。
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  true の場合、部分的なメッセージ delta が SSE イベントとして送信されます。
</ParamField>

<ParamField body="stream_options" type="object">
  ストリーミング用のオプション。ストリームチャンク内で token 使用量を受け取るには、`include_usage: true` を設定してください。
</ParamField>

<ParamField body="top_p" type="number" default="1">
  Nucleus sampling パラメータ。これまたは temperature のどちらか一方のみを変更することを推奨します。
</ParamField>

<ParamField body="frequency_penalty" type="number" default="0">
  -2.0 から 2.0 の数値。正の値は、繰り返される token にペナルティを与えます。
</ParamField>

<ParamField body="presence_penalty" type="number" default="0">
  -2.0 から 2.0 の数値。正の値は、すでにテキスト内に存在する token にペナルティを与えます。
</ParamField>

<ParamField body="stop" type="string | array">
  API が token の生成を停止するシーケンスを最大 4 つまで指定できます。
</ParamField>

<ParamField body="tools" type="array">
  model が呼び出す可能性のあるツールのリスト（function calling）。
</ParamField>

<ParamField body="tool_choice" type="string | object">
  model がツールをどのように使用するかを制御します。オプション: `auto`, `none`, `required`, または特定のツールオブジェクト。
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  並列 function calling を有効にするかどうか。関数を順次呼び出すには false に設定します。
</ParamField>

<ParamField body="max_completion_tokens" type="integer">
  補完に使用する token の最大数。`max_tokens` の代替であり、新しい reasoning 対応 model ファミリーで有用です。
</ParamField>

<ParamField body="reasoning_effort" type="string">
  reasoning 対応 model の reasoning effort。オプション: `low`, `medium`, `high`。
</ParamField>

<ParamField body="seed" type="integer">
  決定論的 sampling のためのランダム seed。
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成する補完の数（1-128）。
</ParamField>

<ParamField body="logprobs" type="boolean">
  対数確率を返すかどうか。
</ParamField>

<ParamField body="top_logprobs" type="integer">
  返す上位の対数確率の数（0-20）。`logprobs: true` が必要です。
</ParamField>

<ParamField body="top_k" type="integer">
  Top-K sampling パラメータ（Anthropic/Gemini models 向け）。
</ParamField>

<ParamField body="response_format" type="object">
  レスポンス形式の仕様。JSON モードには `{"type": "json_object"}` を、構造化出力には `{"type": "json_schema", "json_schema": {...}}` を使用します。
</ParamField>

<ParamField body="logit_bias" type="object">
  指定した token が出現する尤度を変更します。token ID（文字列として表現）を -100 から 100 の bias 値にマッピングします。
</ParamField>

<ParamField body="user" type="string">
  不正利用の監視のための、エンドユーザーを表す一意の識別子。
</ParamField>

<ParamField body="cache_control" type="object">
  LemonData のキャッシュ制御オプション。

  - `type` (string): キャッシュ戦略 - `default`, `no_cache`, `no_store`, `response_only`, `semantic_only`
  - `max_age` (integer): 秒単位のキャッシュ TTL（最大 86400）
</ParamField>

## レスポンス

<ResponseField name="id" type="string">
  補完の一意の識別子。
</ResponseField>

<ResponseField name="object" type="string">
  常に `chat.completion`。
</ResponseField>

<ResponseField name="created" type="integer">
  補完が作成された時刻の Unix タイムスタンプ。
</ResponseField>

<ResponseField name="model" type="string">
  補完に使用された model。
</ResponseField>

<ResponseField name="choices" type="array">
  補完候補のリスト。

  各 choice には以下が含まれます:
  - `index` (integer): choice のインデックス
  - `message` (object): 生成されたメッセージ
  - `finish_reason` (string): model が停止した理由（`stop`, `length`, `tool_calls`）
</ResponseField>

<ResponseField name="usage" type="object">
  token 使用統計。

  - `prompt_tokens` (integer): prompt 内の token 数
  - `completion_tokens` (integer): 補完内の token 数
  - `total_tokens` (integer): 使用された token の合計数
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/chat/completions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "temperature": 0.7,
    "max_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ],
    temperature=0.7,
    max_tokens=1000
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Hello!' }
  ],
  temperature: 0.7,
  max_tokens: 1000
});

console.log(response.choices[0].message.content);
```

```php PHP
<?php
$ch = curl_init('https://api.lemondata.cc/v1/chat/completions');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-4o',
        'messages' => [
            ['role' => 'system', 'content' => 'You are a helpful assistant.'],
            ['role' => 'user', 'content' => 'Hello!']
        ],
        'temperature' => 0.7,
        'max_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['choices'][0]['message']['content'];
```
