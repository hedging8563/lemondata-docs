## 概要

LemonData の Agent-First API は、AI agent が即座に解析して対応できる構造化ヒントでエラーレスポンスを拡張します — Web 検索も、ドキュメント確認も、推測も不要です。

すべてのエラーレスポンスには、標準の `error` object 内に `did_you_mean`、`suggestions`、`hint`、`retryable`、`retry_after` などの任意フィールドが含まれます。これらのフィールドは後方互換です — 利用しない client には違いはありません。

## エラーヒントフィールド

すべてのヒントフィールドは `error` object 内の任意拡張です:

| Field | Type | Description |
|-------|------|-------------|
| `did_you_mean` | `string` | 最も近い一致の model 名 |
| `suggestions` | `array` | metadata 付きの推奨 model |
| `alternatives` | `array` | 現在利用可能な代替 model |
| `hint` | `string` | 人間/agent が読める次の手順のガイダンス |
| `retryable` | `boolean` | 同じ request を再試行すると成功する可能性があるか |
| `retry_after` | `number` | 再試行前に待機すべき秒数 |
| `balance_usd` | `number` | 現在の アカウント 残高（USD） |
| `estimated_cost_usd` | `number` | 失敗した request の推定コスト |

## エラーコードの例

### model_not_found (400)

model 名がどのアクティブな model とも一致しない場合:

```json
{
  "error": {
    "message": "Model 'gpt5' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [
      {"id": "gpt-5.4"},
      {"id": "gpt-5-mini"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Did you mean 'gpt-5.4'? Use GET https://api.lemondata.cc/v1/models to list all available models."
  }
}
```

`did_you_mean` の解決には以下を使用します:
1. 静的 alias マッピング（本番エラーデータ由来）
2. 正規化文字列マッチング（ハイフン除去、大文字小文字を区別しない）
3. 編集距離マッチング（しきい値 ≤ 3）

### insufficient_balance (402)

推定コストに対して アカウント 残高が低すぎる場合:

```json
{
  "error": {
    "message": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200.",
    "type": "insufficient_balance",
    "code": "insufficient_balance",
    "balance_usd": 0.12,
    "estimated_cost_usd": 0.35,
    "suggestions": [
      {"id": "gpt-5-mini"},
      {"id": "deepseek-v3-2"}
    ],
    "hint": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200. Try a cheaper model, or top up at https://lemondata.cc/dashboard/billing."
  }
}
```

`suggestions` には、推定コストより安価で、agent が切り替え可能な model が含まれます。

### all_channels_failed (503)

ある model のすべての upstream channel が利用不可の場合:

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-6", "status": "available", "tags": []},
      {"id": "gpt-5-mini", "status": "available", "tags": []}
    ],
    "hint": "All channels for 'claude-opus-4-6' are temporarily unavailable. Retry in 30s or try an alternative model."
  }
}
```

<Note>
理由が `no_channels`（この model に設定された channel がない）の場合、`retryable` は `false` です。`true` になるのは、circuit breaker の発動や quota 枯渇のような一時的障害の場合のみです。
</Note>

### rate_limit_exceeded (429)

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

`retry_after` の値は、実際の rate limit window のリセット時刻から計算されます。

<Note>
OpenAI 互換 endpoint は、`rate_limit_exceeded`、`upstream_error`、`all_channels_failed` などの LemonData の安定した公開 error type を使用します。Anthropic 互換および Gemini 互換 endpoint は、それぞれ独自の native response 形式を使用します。
</Note>

### context_length_exceeded (400)

入力が model の context window を超えた場合（upstream error、ヒントで拡張済み）:

```json
{
  "error": {
    "message": "This model's maximum context length is 128000 tokens...",
    "type": "invalid_request_error",
    "code": "context_length_exceeded",
    "retryable": false,
    "suggestions": [
      {"id": "gemini-2.5-pro"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Reduce your input or switch to a model with a larger context window."
  }
}
```

## Native Endpoint ヘッダー

`/v1/chat/completions` を native endpoint（Anthropic または Gemini）を持つ model で呼び出すと、**成功レスポンス** には最適化ヘッダーが含まれます:

```
X-LemonData-Hint: This model supports native Anthropic format. Use POST /v1/messages for better performance (no format conversion).
X-LemonData-Native-Endpoint: /v1/messages
```

| Model プロバイダー | Suggested Endpoint | Benefit |
|---------------|-------------------|---------|
| Anthropic (Claude) | `/v1/messages` | フォーマット変換なし、extended thinking、prompt caching |
| Google (Gemini) | `/v1beta/gemini` | フォーマット変換なし、grounding、安全設定 |
| OpenAI | — | Chat completions はすでに ネイティブ形式 |

これらのヘッダーは streaming と non-streaming の両方のレスポンスに含まれます。

## /v1/models の拡張

各 model object の `lemondata` 拡張に 3 つの新しいフィールドが追加されています:

```json
{
  "id": "gpt-5.4",
  "lemondata": {
    "category": "chat",
    "pricing_unit": "per_token",
    "cache_pricing": {
      "cache_read_per_1m": "1.25",
      "cache_write_per_1m": "2.50",
      "platform_cache_discount": 0.9
    }
  }
}
```

| Field | Values | Description |
|-------|--------|-------------|
| `category` | `chat`, `image`, `video`, `audio`, `tts`, `stt`, `3d`, `embedding`, `rerank` | model のタイプ |
| `pricing_unit` | `per_token`, `per_image`, `per_second`, `per_request` | model の課金単位 |
| `cache_pricing` | object or `null` | upstream prompt cache の価格 + platform semantic cache 割引 |

### Category フィルタリング

```bash
GET https://api.lemondata.cc/v1/models?category=chat          # Chat models only
GET https://api.lemondata.cc/v1/models?category=image         # Image generation models
GET https://api.lemondata.cc/v1/models?tag=coding&category=chat  # Coding-optimized chat models
```

## llms.txt

機械可読な API 概要は以下で利用できます:

```
GET https://api.lemondata.cc/llms.txt
```

含まれる内容:
- 動作する例を含む初回呼び出しテンプレート
- 一般的な model 名（使用データから動的生成）
- 12 個すべての API endpoint
- model 検索用の filter parameter
- エラーハンドリングのガイダンス

最初の API 呼び出し前に `llms.txt` を読む AI agent は、通常、最初の試行で成功できます。

## Agent コードでの利用

### Python (OpenAI SDK)

```python
from openai import OpenAI, BadRequestError

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://api.lemondata.cc/v1"
)

def smart_chat(messages, model="gpt-4o"):
    try:
        return client.chat.completions.create(
            model=model, messages=messages
        )
    except BadRequestError as e:
        error = e.body.get("error", {}) if isinstance(e.body, dict) else {}
        # Use did_you_mean for auto-correction
        if error.get("code") == "model_not_found" and error.get("did_you_mean"):
            return client.chat.completions.create(
                model=error["did_you_mean"], messages=messages
            )
        raise
```

### JavaScript (OpenAI SDK)

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function smartChat(messages, model = 'gpt-4o') {
  try {
    return await client.chat.completions.create({ model, messages });
  } catch (error) {
    const err = error?.error;
    if (err?.code === 'model_not_found' && err?.did_you_mean) {
      return client.chat.completions.create({
        model: err.did_you_mean, messages
      });
    }
    throw error;
  }
}
```
