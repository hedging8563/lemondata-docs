## 概要

LemonData API は、主要なすべての AI 開発ツールとの**ドロップイン互換性**を実現するよう設計されています。このガイドでは、サポートされているパラメータと検証済みの統合について説明します。

<Note>
  すべてのパラメータは検証されますが、そのまま上流プロバイダに渡されます。特定のモデルでサポートされていないパラメータは自動的に無視され、最大限の互換性が確保されます。
</Note>

## サポートされている API 形式

| Endpoint | Format | Use Case |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 汎用的な互換性 |
| `/v1/responses` | OpenAI Responses | ステートフルな会話 |
| `/v1/messages` | Anthropic Messages | Claude ネイティブ機能 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini ネイティブ機能 |

## Chat Completions のパラメータ

### コアパラメータ

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | モデル識別子（必須） |
| `messages` | array | 会話メッセージ（必須） |
| `max_tokens` | integer | 最大出力 token 数 |
| `temperature` | number | サンプリング温度 (0-2) |
| `top_p` | number | Nucleus sampling (0-1) |
| `stream` | boolean | ストリーミングを有効化 |

### ツール呼び出し

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tool Choice オプション

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | シンプルな選択 |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | 特定の function を強制 |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic ネイティブ形式 |

### 高度なパラメータ

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | token 数のための `{ include_usage: true }` |
| `reasoning_effort` | string | 推論対応 GPT-5 モデル向けの `"low"`、`"medium"`、`"high"` |
| `service_tier` | string | `"auto"` または `"default"` |
| `seed` | integer | 決定論的な出力 |
| `logprobs` | boolean | 対数確率を返す |
| `top_logprobs` | integer | 上位 logprobs の数 (0-20) |
| `logit_bias` | object | token バイアスマップ (-100 から 100) |
| `frequency_penalty` | number | 繰り返しペナルティ (-2 から 2) |
| `presence_penalty` | number | トピックペナルティ (-2 から 2) |
| `stop` | string/array | 停止シーケンス |
| `n` | integer | completion 数 (1-128) |
| `user` | string | 追跡用のユーザー識別子 |

### OpenAI の高度な機能

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | マルチモーダル用の `["text", "audio"]` |
| `audio` | object | 音声出力設定（voice、format） |
| `prediction` | object | より高速な completion のための予測出力 |
| `metadata` | object | 追跡用のキーと値のペア |
| `store` | boolean | 後で取得できるように保存 |

### プロバイダ固有のオプション

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Responses API のパラメータ

### コアパラメータ

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | モデル識別子 |
| `input` | string/array | 入力コンテンツ |
| `instructions` | string | system instructions |
| `max_output_tokens` | integer | 最大出力 token 数 |
| `previous_response_id` | string | 会話を継続 |

### 高度なパラメータ

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` または `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | 推論モデル向け |
| `service_tier` | string | 優先ティア |

### ツール形式

OpenAI と Anthropic の両方のツール形式をサポートします:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## ストリーミング

すべての endpoint は Server-Sent Events (SSE) ストリーミングをサポートしています:

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## エラーハンドリング

LemonData は OpenAI 互換のエラーレスポンスを返します:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

詳細は [Error Handling Guide](/guides/error-handling) を参照してください。

## ベストプラクティス

<AccordionGroup>
  <Accordion title="不明なパラメータには passthrough を使用する">
    すべての schema は `.passthrough()` を使用します。不明なパラメータは上流プロバイダに転送されます。
  </Accordion>

  <Accordion title="正確な課金のために stream_options を優先する">
    ストリーミングレスポンスで正確な token 数を得るために `stream_options.include_usage` を有効にしてください。
  </Accordion>

  <Accordion title="適切な tool_choice 形式を使用する">
    SDK が期待する形式に合わせてください。LemonData は OpenAI と Anthropic の両方の形式を受け付けます。
  </Accordion>
</AccordionGroup>
