## 概要

LemonData は複数の API 形式を提供しており、一般的な coding tool、SDK、framework を最小限の glue code で接続できます。

このページは marketing matrix よりも意図的に狭く定義しています。

- **サポート**: 明確な設定パスを文書化しており、その経路に必要な protocol shape を LemonData が公開していることを意味します。
- **強い native path**: その protocol family に対して、このリポジトリに adapter / request-format の直接的な根拠があることを意味します。
- **Best-effort**: 統合自体は可能でも、上流クライアントがこの custom gateway workflow を安定契約として扱っていないことを意味します。

<Note>
  未対応フィールドは一律には処理されません。互換ルートでは無視または正規化されるものがあり、native Responses ルートでは、選択した model や routed channel が必要な passthrough をサポートしない場合、明示的な `400` または `503` が返ることがあります。
</Note>

## サポートされている API 形式

| Endpoint | 形式 | 用途 |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 汎用的な互換性 |
| `/v1/responses` | OpenAI Responses | ステートフルな会話 |
| `/v1/messages` | Anthropic Messages | Claude ネイティブ機能 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini ネイティブ機能 |

## IDE と CLI の互換性

### 文書化されたツールパス

| ツール | サポートレベル | 形式 | 説明 |
|------|----------|------|------|
| **Cursor** | サポートあり、ただし制約あり | OpenAI-compatible | BYOK の標準 chat/editor フロー向け。Tab Completion など Cursor 管理機能の置き換えを意味しません |
| **Claude Code CLI** | 強い native path | Anthropic | native `/v1/messages` 経路。thinking と `tool_choice` に adapter 根拠あり |
| **Codex CLI** | サポートあり、ただし model / channel 依存 | OpenAI Responses | `/v1/responses` 向けが最適。一部 Responses-native フィールドは model / channel の native passthrough に依存 |
| **Gemini CLI** | 実験的 / best-effort | Gemini | LemonData 向け custom base URL フローは安定した upstream 契約ではありません |
| **OpenCode** | サポートあり | OpenAI-compatible | まず OpenAI-compatible provider を使い、明確に Responses provider が必要な場合のみ切り替えます |

<Note>
  他の OpenAI-compatible editor / agent tool も同じ base URL パターンで動くことは多いですが、このリポジトリでは Windsurf、Aider、Continue.dev、Cline/Roo Code、GitHub Copilot などの専用回帰は現在維持していません。
</Note>

## SDK の互換性

### 文書化された SDK / フレームワークパス

| SDK / フレームワーク | 言語 | サポートレベル | 説明 |
|-----------------|----------|---------------|-------|
| **OpenAI SDK** | Python/JS/Go | コア経路をサポート | Chat Completions、Embeddings、一般的な Responses ワークフローを文書化。一部の Responses-native-only フィールドは model / channel passthrough に依存 |
| **Anthropic SDK** | Python/JS | 強い native path | native Messages 経路。tools、thinking、prompt caching に直接根拠あり |
| **Vercel AI SDK** | TypeScript | 推奨統合パターン | まず `@ai-sdk/openai-compatible` を推奨。Responses-native が必要な場合のみ `@ai-sdk/openai` を使います |
| **LangChain** | Python/JS | 標準 surface をサポート | 対象範囲は `ChatOpenAI` と `OpenAIEmbeddings`。vendor-native extras は対象外 |
| **LlamaIndex** | Python | `OpenAILike` 経由でサポート | LemonData のような third-party gateway では、組み込み OpenAI クラスではなく `OpenAILike` を使います |
| **Dify** | - | サポートあり、ただし制約あり | 想定パスは OpenAI provider と chat-completions 指向フロー。Codex 専用 Responses / WebSocket の保証対象ではありません |

## Chat Completions のパラメータ

### コアパラメータ

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | モデル識別子（必須） |
| `messages` | array | 会話メッセージ（必須） |
| `max_tokens` | integer | 最大出力 token 数 |
| `temperature` | number | サンプリング温度 (0-2) |
| `top_p` | number | Nucleus sampling (0-1) |
| `stream` | boolean | ストリーミングを有効化 |

### ツール呼び出し

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tool Choice オプション

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | シンプルな選択 |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | 特定の function を強制 |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic ネイティブ形式 |

### 高度なパラメータ

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | token 数のための `{ include_usage: true }` |
| `reasoning_effort` | string | 推論対応 GPT-5 モデル向けの `"low"`、`"medium"`、`"high"` |
| `service_tier` | string | `"auto"` または `"default"` |
| `seed` | integer | 決定論的な出力 |
| `logprobs` | boolean | 対数確率を返す |
| `top_logprobs` | integer | 上位 logprobs の数 (0-20) |
| `logit_bias` | object | token バイアスマップ (-100 から 100) |
| `frequency_penalty` | number | 繰り返しペナルティ (-2 から 2) |
| `presence_penalty` | number | トピックペナルティ (-2 から 2) |
| `stop` | string/array | 停止シーケンス |
| `n` | integer | completion 数 (1-128) |
| `user` | string | 追跡用のユーザー識別子 |

### OpenAI の高度な機能

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | マルチモーダル用の `["text", "audio"]` |
| `audio` | object | 音声出力設定（voice、format） |
| `prediction` | object | より高速な completion のための予測出力 |
| `metadata` | object | 追跡用のキーと値のペア |
| `store` | boolean | 後で取得できるように保存 |

### プロバイダ固有のオプション

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Responses API のパラメータ

### コアパラメータ

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | モデル識別子 |
| `input` | string/array | 入力コンテンツ |
| `instructions` | string | system instructions |
| `max_output_tokens` | integer | 最大出力 token 数 |
| `previous_response_id` | string | 会話を継続 |

### 高度なパラメータ

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` または `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | 推論モデル向け |
| `service_tier` | string | 優先ティア |

### ツール形式

OpenAI と Anthropic の両方のツール形式をサポートします:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## ストリーミング

すべての endpoint は Server-Sent Events (SSE) ストリーミングをサポートしています:

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## エラーハンドリング

LemonData は OpenAI 互換のエラーレスポンスを返します:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

詳細は [Error Handling Guide](/guides/error-handling) を参照してください。

## ベストプラクティス

<AccordionGroup>
  <Accordion title="不明なパラメータには passthrough を使用する">
    すべての schema は `.passthrough()` を使用します。不明なパラメータは上流プロバイダに転送されます。
  </Accordion>

  <Accordion title="正確な課金のために stream_options を優先する">
    ストリーミングレスポンスで正確な token 数を得るために `stream_options.include_usage` を有効にしてください。
  </Accordion>

  <Accordion title="適切な tool_choice 形式を使用する">
    SDK が期待する形式に合わせてください。LemonData は OpenAI と Anthropic の両方の形式を受け付けます。
  </Accordion>
</AccordionGroup>
