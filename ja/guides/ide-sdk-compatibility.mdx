## 概要

TokenLab は複数の API フォーマットを公開しており、一般的なコーディングツール、SDK、フレームワークが最小限のグルーコードで統合できるようになっています。

このページは、マーケティング用のマトリックスよりも意図的に絞り込んだ内容となっています。

- **Supported (サポート済み)**: 具体的なセットアップ手順がドキュメント化されており、TokenLab がその手順で期待されるプロトコル形状を公開していることを意味します。
- **Strong native path (強力なネイティブパス)**: そのリポジトリが、当該プロトコルファミリーに対する直接的なアダプターやリクエストフォーマットの実装を備えていることを意味します。
- **Best-effort (ベストエフォート)**: 統合は可能ですが、アップストリームのクライアントがこのカスタムゲートウェイワークフローを安定したコントラクトとして扱っていないことを意味します。

<Note>
  サポートされていないフィールドの扱いは一貫していません。互換性ルートでは、一部のフィールドは無視されるか正規化されます。`/v1/responses` では、要求された動作を保証できないルートにおいて、明示的な `400` または `503` エラーが返される場合があります。
</Note>

## サポートされている API フォーマット

| エンドポイント | フォーマット | ユースケース |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 汎用的な互換性 |
| `/v1/responses` | OpenAI Responses | ステートフルな会話 |
| `/v1/messages` | Anthropic Messages | Claude ネイティブ機能 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini ネイティブ機能 |

## IDE & CLI 互換性

### ドキュメント化されたツールパス

| ツール | サポートレベル | フォーマット | 備考 |
|------|---------------|--------|-------|
| **Cursor** | 制限付きサポート | OpenAI 互換 | BYOK 標準チャット/エディタフローで動作しますが、Tab Completion のような Cursor 管理機能の代替としては機能しません |
| **Claude Code CLI** | 強力なネイティブパス | Anthropic | thinking および `tool_choice` のアダプター対応を含むネイティブな `/v1/messages` ルート |
| **Codex CLI** | モデル/パス制限付きサポート | OpenAI Responses | `/v1/responses` を Codex 特有のワークフロー向けの高度なパスとして扱ってください。Responses 専用フィールドの一部は、すべてのモデルやルーティングパスで保証されているわけではありません |
| **Gemini CLI** | ベストエフォート / 実験的 | Gemini | カスタム TokenLab ベース URL フローは、公式の Gemini CLI 統合ではありません |
| **OpenCode** | サポート済み | OpenAI 互換 | デフォルトでは OpenAI 互換プロバイダーを使用し、Responses ベースのプロバイダーが必要な場合にのみ明示的に切り替えてください |

<Note>
  他の OpenAI 互換エディタやエージェントツールも、同じベース URL パターンで動作することがよくあります。本番環境で使用する前に、ツール独自のカスタムプロバイダーサポートを確認してください。
</Note>

    - Anthropic 形式: `{ name, input_schema }` (type フィールドなし)

## SDK 互換性

### ドキュメント化された SDK & フレームワークパス

| SDK / フレームワーク | 言語 | サポートレベル | 備考 |
|-----------------|----------|---------------|-------|
| **OpenAI SDK** | Python/JS/Go | サポート済みコアパス | `/v1` Chat Completions および Embeddings の互換パス。プロバイダー固有の動作にはネイティブプロバイダーのルートを使用し、Responses 専用フィールドがすべてのモデルで動作すると想定しないでください |
| **Anthropic SDK** | Python/JS | 強力なネイティブパス | ツール、thinking、プロンプトキャッシングを直接サポートするネイティブ Messages ルート |
| **Vercel AI SDK** | TypeScript | 推奨統合パターン | `@ai-sdk/openai-compatible` を優先してください。Responses ネイティブの動作が必要な場合にのみ `@ai-sdk/openai` を使用してください |
| **LangChain** | Python/JS | サポート済み標準サーフェス | `ChatOpenAI` および `OpenAIEmbeddings` が対象範囲です。ベンダー固有の拡張機能は対象外です |
| **LlamaIndex** | Python | `OpenAILike` 経由でサポート | TokenLab のようなサードパーティゲートウェイには、組み込みの OpenAI クラスではなく `OpenAILike` を使用してください |
| **OpenAI Agents SDK** | Python | サポート済みチャット補完パス | `OpenAIChatCompletionsModel` を使用して `AsyncOpenAI(base_url="https://api.tokenlab.sh/v1")` を使用してください。ネイティブな Responses の動作は選択したモデルとルートに依存します |
| **Langflow** | Python / Web | 範囲制限付きサポート | OpenAI コンポーネントの **OpenAI API Base** フィールドに TokenLab の `/v1` エンドポイントを指定してください |
| **Dify** | - | 範囲制限付きサポート | OpenAI プロバイダーおよびチャット補完指向のフローが対象です。Codex 特有の Responses や WebSocket の動作には適していません |
| **Flowise** | Web / Node | 範囲制限付きサポート | 利用可能な場合は TokenLab チャットノードを使用するか、`https://api.tokenlab.sh/v1` を指定した ChatOpenAI 互換ノードを使用してください |
| **Agno** | Python | サポート済みパス | 利用可能な場合は TokenLab モデルラッパーを使用するか、OpenAI 互換のベース URL パスを使用してください |
| **Promptfoo** | CLI / Node | サポート済みパス | `apiBaseUrl: https://api.tokenlab.sh/v1` を指定して OpenAI チャットまたは Responses プロバイダーを使用してください |
| **Portkey Gateway** | Gateway | サポート済みパス | OpenAI 互換のチャットおよび Responses トラフィックのアップストリームプロバイダーとして TokenLab を使用してください |
| **Helicone** | Gateway / Observability | サポート済み可観測性パス | `Helicone-Target-Url: https://api.tokenlab.sh` を指定して、OpenAI 互換リクエストを Helicone Gateway 経由でルーティングしてください |
| **LangBot** | Bot Platform | サポート済みチャットパス | 利用可能な場合は TokenLab リクエスターを使用するか、TokenLab の `/v1` エンドポイントで OpenAI 互換リクエスターを設定してください |
| **Open WebUI** | Web Chat | サポート済みチャットアプリパス | OpenAI 互換 API 接続として TokenLab を追加し、モデルリストを更新してください |
| **Chatbox / DeepChat / Jan / LibreChat / Cherry Studio** | Desktop / Web | サポート済みチャットアプリパス | 各アプリの OpenAI 互換カスタムプロバイダーフローを使用してください。これらのアプリは通常チャット補完指向です |

## Chat Completions パラメータ

### コアパラメータ

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| `model` | string | モデル識別子 (必須) |
| `messages` | array | 会話メッセージ (必須) |
| `max_tokens` | integer | 最大出力トークン数 |
| `temperature` | number | サンプリング温度 (0-2) |
| `top_p` | number | 核サンプリング (0-1) |
| `stream` | boolean | ストリーミングの有効化 |

### ツール呼び出し

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### ツール選択オプション

| フォーマット | 例 | 説明 |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | 単純な選択 |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | 特定の関数を強制 |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic ネイティブ形式 |

### 高度なパラメータ

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| `stream_options` | object | Chat Completions のみ: `{ include_usage: true }` でトークン数を取得 |
| `reasoning_effort` | string | 推論対応 GPT-5 モデル用の `"low"`, `"medium"`, `"high"` |
| `service_tier` | string | `"auto"` または `"default"` |
| `seed` | integer | 決定論的な出力 |
| `logprobs` | boolean | ログ確率を返す |
| `top_logprobs` | integer | 上位ログ確率の数 (0-20) |
| `logit_bias` | object | トークンバイアスマップ (-100 ～ 100) |
| `frequency_penalty` | number | 繰り返しペナルティ (-2 ～ 2) |
| `presence_penalty` | number | トピックペナルティ (-2 ～ 2) |
| `stop` | string/array | 停止シーケンス |
| `n` | integer | 補完数 (1-128) |
| `user` | string | 追跡用ユーザー識別子 |

### OpenAI 高度な機能

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| `modalities` | array | マルチモーダル用 `["text", "audio"]` |
| `audio` | object | 音声出力設定 (音声、フォーマット) |
| `prediction` | object | 高速補完のための予測出力 |
| `metadata` | object | 追跡用キーバリューペア |
| `store` | boolean | 後で取得するために保存 |

### プロバイダー固有オプション

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

| パラメータ | 型 | 説明 |
|-----------|------|-------------|

## ストリーミング

Chat Completions や Responses を含む `stream: true` を公開する生成エンドポイントは、Server-Sent Events (SSE) を使用します：

```bash
# Chat Completions
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# Chat Completions 使用状況追跡
-d '{"...", "stream_options": {"include_usage": true}}'
```

## エラーハンドリング

TokenLab は OpenAI 互換のエラーレスポンスを返します：

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

詳細は [Error Handling Guide](/guides/error-handling) を参照してください。

## ベストプラクティス

<AccordionGroup>
  <Accordion title="不明なパラメータにはパススルーを使用する">
    不明なパラメータは、選択されたパブリックルートとモデルがサポートしている場合にのみ転送されます。
  </Accordion>

  <Accordion title="stream_options.include_usage は Chat Completions にのみ使用する">
    Chat Completions のストリーミングでは、正確なトークン数のために `stream_options.include_usage` を有効にしてください。Responses には独自のストリーミングコントラクトがあり、この Chat 専用オプションは公開されていません。
  </Accordion>

  <Accordion title="適切な tool_choice フォーマットを使用する">
    SDK が期待するフォーマットに合わせてください。TokenLab は OpenAI 形式と Anthropic 形式の両方を受け入れます。
  </Accordion>
</AccordionGroup>
