## エラーレスポンス形式

すべてのエラーは、オプションの[Agent-First ヒント](/guides/agent-first-api)を含む一貫した JSON 形式で返されます:

```json
{
  "error": {
    "message": "Human-readable error description",
    "type": "error_type",
    "code": "error_code",
    "param": "parameter_name",
    "did_you_mean": "suggested_model",
    "suggestions": [{"id": "model-id"}],
    "hint": "Next step guidance",
    "retryable": true,
    "retry_after": 30
  }
}
```

基本フィールド（`message`, `type`, `code`, `param`）は常に存在します。ヒントフィールド（`did_you_mean`, `suggestions`, `hint`, `retryable`, `retry_after`, `balance_usd`, `estimated_cost_usd`）は、AI agent の自己修正のためのオプション拡張です。詳細は [Agent-First API ガイド](/guides/agent-first-api)を参照してください。

OpenAI 互換エンドポイントは、LemonData の安定した gateway エラータイプを使用します。Anthropic 互換および Gemini 互換エンドポイントは、それぞれ独自のネイティブなエラーファミリーとレスポンス形式を使用します。

## HTTP ステータスコード

| Code | Description |
|------|-------------|
| 400 | Bad Request - 無効なパラメータ |
| 401 | Unauthorized - 無効または欠落した API key |
| 402 | Payment Required - 残高不足 |
| 403 | Forbidden - アクセス拒否または許可されていない model |
| 404 | Not Found - Model またはリソースが見つかりません |
| 413 | Payload Too Large - 入力またはファイルサイズが上限を超過 |
| 429 | Too Many Requests - rate limit 超過 |
| 500 | Internal Server Error |
| 502 | Bad Gateway - 上流 provider エラー |
| 503 | Service Unavailable - サービスは一時的に利用できません |
| 504 | Gateway Timeout - リクエストがタイムアウトしました |

## エラータイプ

### 認証エラー (401)

| Type | Code | Description |
|------|------|-------------|
| `invalid_api_key` | `invalid_api_key` | API key が欠落しているか無効です |
| `expired_api_key` | `expired_api_key` | API key は取り消されています |

```python
from openai import OpenAI, AuthenticationError

try:
    response = client.chat.completions.create(...)
except AuthenticationError as e:
    print(f"Authentication failed: {e.message}")
```

### 支払いエラー (402)

| Type | Code | Description |
|------|------|-------------|
| `insufficient_balance` | `insufficient_balance` | アカウント残高が不足しています（OpenAI 互換エンドポイント） |
| `insufficient_balance_error` | `insufficient_balance` | アカウント残高が不足しています（Anthropic 互換エンドポイント） |
| `quota_exceeded` | `quota_exceeded` | API key の使用上限に達しました |

```python
from openai import OpenAI, APIStatusError

try:
    response = client.chat.completions.create(...)
except APIStatusError as e:
    if e.status_code == 402:
        print("Please top up your account balance")
```

### アクセスエラー (403)

| Type | Code | Description |
|------|------|-------------|
| `access_denied` | `access_denied` | リソースへのアクセスが拒否されました |
| `access_denied` | `model_not_allowed` | この API key ではこの model は許可されていません |

```json
{
  "error": {
    "message": "You don't have permission to access this model",
    "type": "access_denied",
    "code": "model_not_allowed"
  }
}
```

### バリデーションエラー (400)

| Type | Description |
|------|-------------|
| `invalid_request_error` | リクエストパラメータが無効です |
| `context_length_exceeded` | 入力が model に対して長すぎます |
| `model_not_found` | 要求された model は存在しません |

```json
{
  "error": {
    "message": "Model 'invalid-model' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [{"id": "gpt-5.4"}, {"id": "gpt-5-mini"}],
    "hint": "Did you mean 'gpt-5.4'? Use GET https://api.lemondata.cc/v1/models to list all available models."
  }
}
```

### Rate Limit エラー (429)

rate limit を超過した場合:

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

**含まれるヘッダー:**

```
Retry-After: 8
```

`Retry-After` ヘッダーと `retry_after` フィールドは、再試行前に待機すべき正確な秒数を示します。

### Payload Too Large (413)

入力またはファイルサイズが上限を超えた場合:

```json
{
  "error": {
    "message": "Input size exceeds maximum allowed",
    "type": "invalid_request_error",
    "code": "payload_too_large"
  }
}
```

一般的な原因:
- 画像ファイルが大きすぎる（最大 20MB）
- 音声ファイルが大きすぎる（最大 25MB）
- 入力テキストが model の context length を超過している

### 上流エラー (502, 503)

| Type | Description |
|------|-------------|
| `upstream_error` | provider がエラーを返しました |
| `all_channels_failed` | 利用可能な provider がありません |
| `timeout_error` | リクエストがタイムアウトしました |

すべての channel が失敗した場合、レスポンスには代替 model が含まれます:

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-6", "status": "available", "tags": []},
      {"id": "gpt-5-mini", "status": "available", "tags": []}
    ],
    "hint": "Retry in 30s or switch to an available model."
  }
}
```

## Python でのエラー処理

```python
from openai import OpenAI, APIError, RateLimitError, APIConnectionError

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

def chat_with_retry(messages, max_retries=3):
    for attempt in range(max_retries):
        try:
            return client.chat.completions.create(
                model="gpt-4o",
                messages=messages
            )
        except RateLimitError as e:
            if attempt < max_retries - 1:
                import time
                time.sleep(2 ** attempt)  # Exponential backoff
                continue
            raise
        except APIConnectionError as e:
            print(f"Connection error: {e}")
            raise
        except APIError as e:
            print(f"API error: {e.status_code} - {e.message}")
            raise
```

## JavaScript でのエラー処理

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function chatWithRetry(messages, maxRetries = 3) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      return await client.chat.completions.create({
        model: 'gpt-4o',
        messages
      });
    } catch (error) {
      if (error instanceof OpenAI.RateLimitError) {
        if (attempt < maxRetries - 1) {
          await new Promise(r => setTimeout(r, 2 ** attempt * 1000));
          continue;
        }
      }
      throw error;
    }
  }
}
```

  <Accordion title="指数バックオフを実装する">
    rate limit が適用された場合は、再試行の間隔を段階的に長くしてください:
    ```python
    wait_time = 2 ** attempt  # 1s, 2s, 4s, 8s...
    ```
  </Accordion>

  <Accordion title="タイムアウトを設定する">
    リクエストが停止したままにならないよう、常に適切なタイムアウトを設定してください:
    ```python
    client = OpenAI(timeout=60.0)  # 60 second timeout
    ```
  </Accordion>

  <Accordion title="デバッグ用にエラーをログに記録する">
    サポートのために、request ID を含む完全なエラーレスポンスをログに記録してください:
    ```python
    except APIError as e:
        logger.error(f"API Error: {e.status_code} - {e.message}")
    ```
  </Accordion>
