## 概要

LemonData は **従量課金制** を採用しています。サブスクリプションや最低利用義務はなく、使用した分だけお支払いいただきます。

## 請求の仕組み

1. アカウントに **credits を追加** します
2. **API を使用** します - リクエストごとに料金が差し引かれます
3. ダッシュボードで **使用状況を監視** します
4. 残高が少なくなったら **チャージ** します

### 非同期タスクの課金（動画/音楽/3D）

<Warning>
  **重要**: 動画、音楽、3D 生成タスクは、**完了時ではなく送信時に課金** されます。
</Warning>

非同期生成タスク（動画、音楽、3D モデル）の場合:

1. タスクを送信すると **即座に課金** されます
2. ステータス確認のためにポーリングする `task_id` を受け取ります
3. タスクが失敗した場合でも **自動返金はありません**

これは、結果にかかわらず、上流プロバイダーがタスク送信時点で当社に課金するためです。タスクの失敗が発生した場合は、support@lemondata.cc までお問い合わせください。

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

task_id = response.json()["task_id"]
# Poll for status...
```

## トークン数のカウント

トークンはテキスト処理の基本単位です。

- 約4文字 = 1 token（英語）
- 約1〜2文字 = 1 token（中国語）
- 1画像 = サイズと詳細度によって異なります

### トークン数の見積もり

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## 残高不足アラート

残高がしきい値を下回ったときのアラートを設定します。

1. **Dashboard → Settings → Notifications** に移動します
2. しきい値金額を設定します
3. メール通知を受け取ります

## credits の追加

### 支払い方法

- Alipay（支付宝）
- WeChat Pay（微信支付）
- Stripe（Visa、Mastercard）

### 手順

1. [Dashboard](https://lemondata.cc/dashboard) にログインします
2. **Add Credits** をクリックします
3. 金額と支払い方法を選択します
4. 支払いを完了します

支払い確認後、credits は即時に追加されます。

## API key の制限

個別の API key に対して支出上限を設定できます。

1. **Dashboard → API Keys** に移動します
2. 編集する key をクリックします
3. **Usage Limit** を設定します

上限に達すると、その key を使用したリクエストは `402 Payment Required` を返します。

## 請求書

ビジネスアカウントでは、請求書を利用できます。

1. **Dashboard → Billing** に移動します
2. 取引履歴を表示します
3. 請求書を PDF としてダウンロードします
