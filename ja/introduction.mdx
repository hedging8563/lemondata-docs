## LemonData とは？

LemonData は AI API 集約プラットフォームであり、OpenAI、Anthropic、Google、DeepSeek、Moonshot、MiniMax などのプロバイダーが提供する **300 以上の AI モデル** への統一されたアクセスを提供します。

<CardGroup cols={2}>
  <Card title="OpenAI 互換" icon="plug">
    幅広い OpenAI スタイルのツールおよび SDK で、同じ API key と base URL を使用できます。
  </Card>
  <Card title="ネイティブ形式" icon="shuffle">
    1 つのプラットフォームから OpenAI、Anthropic、Gemini、および Responses スタイルの endpoint を呼び出せます。
  </Card>
  <Card title="従量課金" icon="coins">
    サブスクリプションは不要です。実際に使用した分だけ支払います。
  </Card>
  <Card title="高可用性" icon="shield-check">
    スマートルーティング、フェイルオーバー、マルチチャネル対応により信頼性が向上します。
  </Card>
</CardGroup>

## 対応機能

| Capability | Description | Example Models |
|------------|-------------|----------------|
| **Chat & Reasoning** | テキスト生成、計画、tools | `gpt-5.4`, `claude-sonnet-4-6`, `deepseek-r1` |
| **Vision** | 画像理解とマルチモーダル chat | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |
| **Image Generation** | テキストから画像生成および画像編集 | `dall-e-3`, `flux-pro`, `midjourney` |
| **Video Generation** | テキスト/画像から動画生成 | `sora`, `runway`, `kling` |
| **Audio** | TTS および文字起こし | `gpt-4o-mini-tts`, `whisper-1`, `gpt-4o-transcribe` |
| **Embeddings** | テキストのベクトル化 | `text-embedding-3-small`, `text-embedding-3-large` |
| **Music** | AI 音楽生成 | `suno` |
| **3D** | 3D アセット生成 | `tripo3d` |

## 最初に選ぶべき適切なデフォルト

新しいプロジェクトでは、OpenAI SDK と **Responses API** から始めることをおすすめします。

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```
