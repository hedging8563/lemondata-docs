## 概要

LemonDataは、1つのAPIキーで**3つのネイティブAPIフォーマット**をサポートしています。設定を変更することなく、ユースケースに最適なフォーマットを選択できます。

<CardGroup cols={3}>
  <Card title="OpenAIフォーマット" icon="plug">
    `/v1/chat/completions`
    標準的なフォーマット、最高の互換性
  </Card>
  <Card title="Anthropicフォーマット" icon="message">
    `/v1/messages`
    思考の拡張、ネイティブなClaude機能
  </Card>
  <Card title="Geminiフォーマット" icon="sparkles">
    `/v1beta/models/:model:generateContent`
    Googleエコシステムとの統合
  </Card>
</CardGroup>

## なぜマルチフォーマットなのか？

| メリット | 説明 |
|---------|-------------|
| **SDKの切り替えが不要** | お好みのSDKであらゆるモデルを使用可能 |
| **ネイティブ機能** | フォーマット固有の機能にアクセス |
| **簡単な移行** | ベースURLを変更するだけで公式APIから切り替え可能 |
| **一括請求** | 1つのアカウント、1つのAPIキーで全フォーマットに対応 |

## フォーマット比較

| 機能 | OpenAI | Anthropic | Gemini |
|---------|--------|-----------|--------|
| **エンドポイント** | `/v1/chat/completions` | `/v1/messages` | `/v1beta/models/:model:generateContent` |
| **認証ヘッダー** | `Authorization: Bearer` | `x-api-key` | `Authorization: Bearer` |
| **システムプロンプト** | `messages`配列内 | 独立した`system`フィールド | `systemInstruction`内 |
| **思考の拡張** | ❌ | ✅ | ❌ |
| **ストリーミング** | ✅ SSE | ✅ SSE | ✅ SSE |
| **ツール呼び出し** | ✅ | ✅ | ✅ |
| **ビジョン** | ✅ | ✅ | ✅ |

## OpenAIフォーマット

最も広く互換性のあるフォーマットです。すべてのLemonDataモデルで動作します。

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

# Works with ANY model
response = client.chat.completions.create(
    model="claude-sonnet-4-5",  # Claude via OpenAI format
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)
