---

Feishu (飞书) または Lark を LemonClaw インスタンスに接続します。このガイドは、ホスト型の Claw インスタンスとセルフホスト型の LemonClaw デプロイメントの両方に対応しており、WebSocket モードを使用するため、パブリックなコールバック URL は不要です。

## 前提条件

- 開発者アクセス権限を持つ [Feishu](https://www.feishu.cn/) または [Lark](https://www.larksuite.com/) アカウント
- LemonClaw インスタンス:
  - ホスト型: [Claw インスタンスを作成する](https://lemondata.cc/dashboard/claw)
  - セルフホスト型: [LemonClaw をインストールする](/claw/self-hosted)

## セットアップガイド

<Steps>
  <Step title="Feishu アプリを作成する">
    1. [Feishu オープンプラットフォーム](https://open.feishu.cn/app) (または [Lark デベロッパー](https://open.larksuite.com/app)) にアクセスします
    2. **Create Custom App** をクリックします
    3. アプリ名と説明を入力します
    4. **Create** をクリックします
  </Step>
  <Step title="Bot 機能を追加する">
    1. アプリ設定で、**Features** → **Bot** に移動します
    2. Bot 機能を有効にします
    3. これにより、アプリがメッセージを受信および送信できるようになります
  </Step>
  <Step title="認証情報を取得する">
    1. **Credentials & Basic Info** に移動します
    2. **App ID** (`cli_` で始まるもの) をコピーします
    3. **App Secret** をコピーします
  </Step>
  <Step title="イベント購読を設定する">
    1. **Event Subscriptions** に移動します
    2. **WebSocket** モードを選択します (推奨 — パブリック URL は不要です)
    3. プロンプトが表示されたら、**Encrypt Key** と **Verification Token** を設定します

    <Tip>
    LemonClaw WebUI で Feishu を設定すると、Encrypt Key と Verification Token が**自動生成**されます。これらの値を Feishu デベロッパーコンソールにコピーしてください。
    </Tip>
  </Step>
  <Step title="イベント権限を追加する">
    1. Event Subscriptions の下で、以下のイベントを追加します:
       - `im.message.receive_v1` — メッセージの受信
    2. **Permissions & Scopes** に移動し、以下を追加します:
       - `im:message` — メッセージの送信と受信
       - `im:message.group_at_msg` — グループ内での @メンションの受信
    3. **Save** をクリックします
  </Step>
  <Step title="アプリを公開する">
    1. **App Release** → **Version Management** に移動します
    2. 新しいバージョンを作成します
    3. レビューを申請します (社内アプリの場合、通常は即座に完了します)
    4. 承認されると、アプリが公開されます
  </Step>
  <Step title="LemonClaw WebUI を開く">
    1. ホスト型の Claw を使用している場合は、[Claw ダッシュボード](https://lemondata.cc/dashboard/claw)に移動し、**Open WebUI** をクリックします
    2. LemonClaw をセルフホストしている場合は、自身の WebUI (例: `http://your-ip:18789`) を開き、token でサインインします
    3. WebUI で、**Settings** → **IM Integrations** に移動します
    4. **Feishu** セクションを展開します
    5. **App ID** と **App Secret** を貼り付けます
    6. 自動生成された **Encrypt Key** と **Verification Token** を Feishu デベロッパーコンソールにコピーして戻します
    7. **Save** をクリックします
  </Step>
  <Step title="チャットを開始する">
    1. Feishu で、Bot を名前で検索します
    2. メッセージを送信します
    3. 最初のユーザーが**自動的にオーナーとしてペアリング**されます。コードは不要です！
    4. AI とのチャットを開始しましょう！
  </Step>
</Steps>

## グループ設定

LemonClaw WebUI の **IM Integrations** 設定で、グループチャットの動作を設定します:

| 設定 | オプション | 説明 |
|---------|---------|-------------|
| **Group Policy** | Open (デフォルト) / Allowlist / Disabled | グループ内で誰が Bot を起動できるかを制御します |
| **Require @mention** | On / Off | Bot は @メンションされた時のみ応答します |
| **Group IDs** | チャット ID のリスト | 特定のグループに制限します (空の場合はすべてのグループ) |
| **Group Allowed Users** | Open ID のリスト | これらのユーザーのみが Bot を起動できます (allowlist モード) |

## トラブルシューティング

<AccordionGroup>
  <Accordion title="Bot がメッセージを受信しない">
    - アプリが公開され、承認されているか確認してください
    - `im.message.receive_v1` イベントが購読されているか確認してください
    - WebSocket モードが選択されていることを確認してください (HTTP ではなく)
    - Feishu コンソールと LemonClaw 設定の間で Encrypt Key と Verification Token が一致しているか確認してください
  </Accordion>
  <Accordion title="'app_ticket' エラー">
    - これは通常、App ID または App Secret が正しくないことを意味します
    - ダッシュボードの認証情報を再確認してください
  </Accordion>
</AccordionGroup>
