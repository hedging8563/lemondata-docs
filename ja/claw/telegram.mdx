Telegram を LemonClaw インスタンスに接続します。このガイドは、ホスト型の Claw インスタンスとセルフホスト型の LemonClaw デプロイメントの両方に対応しています。BotFather から Bot Token を取得するだけで、2分以内に AI とのチャットを開始できます。

## 前提条件

- [Telegram](https://telegram.org/) アカウント
- LemonClaw インスタンス:
  - ホスト型: [Claw インスタンスを作成する](https://lemondata.cc/dashboard/claw)
  - セルフホスト型: [LemonClaw をインストールする](/claw/self-hosted)

## セットアップガイド

<Steps>
  <Step title="BotFather でボットを作成する">
    1. Telegram を開き、**@BotFather** を検索します
    2. `/newbot` を送信します
    3. ボットの **表示名** を選択します (例: "My AI Assistant")
    4. `bot` で終わる **ユーザー名** を選択します (例: `my_ai_assistant_bot`)
    5. BotFather が **Bot Token** を返信します。形式は以下の通りです:
    ```
    123456789:ABCdefGHIjklMNOpqrsTUVwxyz
    ```
    <Warning>
    Bot Token は秘密にしてください！この Token を知っている人は誰でもあなたのボットを操作できてしまいます。
    </Warning>
  </Step>
  <Step title="LemonClaw WebUI を開く">
    1. ホスト型の Claw を使用している場合は、[Claw Dashboard](https://lemondata.cc/dashboard/claw) に移動し、**Open WebUI** をクリックします
    2. LemonClaw をセルフホストしている場合は、自身の WebUI (例: `http://your-ip:18789`) を開き、Token でサインインします
    3. WebUI で、**Settings** → **Channels** に移動します
    4. **Telegram** セクションを展開します
    5. **Bot Token** を貼り付けます
    6. **Save** をクリックします
  </Step>
  <Step title="チャットを開始する">
    1. Telegram を開き、ユーザー名でボットを検索します
    2. 任意のメッセージを送信します (例: "こんにちは！")
    3. 最初のユーザーは自動的にオーナーとして **ペアリング** されます。コードは不要です！
    4. AI とのチャットを開始しましょう！
  </Step>
</Steps>

## オプション: ボットプロフィールのカスタマイズ

ボットを作成した後、BotFather でカスタマイズできます:

| コマンド | 目的 |
|---------|---------|
| `/setdescription` | ボットのバイオ/説明を設定する |
| `/setabouttext` | 「About」セクションを設定する |
| `/setuserpic` | プロフィール画像をアップロードする |
| `/setcommands` | コマンドの候補を追加する |

## グループでの使用

<Warning>
Telegram ボットでは **Privacy Mode がデフォルトで有効** になっています。グループチャットでは、ボットは以下のメッセージのみを認識します:
- `/` で始まるもの (コマンド)
- ボットを直接 @メンション したもの
- ボットのメッセージへの返信

ボットが **すべて** のグループメッセージを表示できるようにするには、BotFather で Privacy Mode を無効にします: `/setprivacy` を送信 → ボットを選択 → **Disable** を選択。注意: この変更を反映させるには、既存のグループからボットを **一度削除して再度追加** する必要があります。
</Warning>

### グループ設定

LemonClaw WebUI の **Channels** 設定でグループの動作を設定します:

| 設定 | オプション | 説明 |
|---------|---------|-------------|
| **Group Policy** | Open (デフォルト) / Allowlist / Disabled | グループ内で誰がボットを起動できるかを制御します |
| **Require @mention** | On / Off | ボットが @メンション されたときのみ応答します (推奨) |
| **Group IDs** | チャット ID のリスト | 特定のグループに制限します (空の場合はすべてのグループ) |
| **Group Allowed Users** | ユーザー ID のリスト | これらのユーザーのみがボットを起動できます (allowlist モード) |

<Tip>
**Group Policy** はグループ内で *誰が* ボットにメッセージを送れるかを制御し、**Group IDs** は *どの* グループでボットが応答するかを制御します。きめ細かな制御を行うには、両方を組み合わせて使用してください。
</Tip>

## DM ポリシー

ボットにダイレクトメッセージを送信できるユーザーを制御します:

| ポリシー | 動作 |
|--------|----------|
| **Pairing** (デフォルト) | 新しいユーザーにはペアリングコードが表示されます。WebUI に入力して承認してください |
| **Allowlist** | 指定したユーザー ID のみがボットにメッセージを送信できます |
| **Open** | 誰でもボットにメッセージを送信できます (注意して使用してください — AI クレジットを消費します) |

## トラブルシューティング

<AccordionGroup>
  <Accordion title="ボットが応答しない">
    - Bot Token が正しいか確認してください (余計なスペースがないか)
    - インスタンスが実行中であることを確認してください (ダッシュボードで緑色のステータス)
    - ダッシュボードからインスタンスを再起動してみてください
  </Accordion>
  <Accordion title="「ペアリングコード」が表示されない">
    - グループではなく、ボットに **ダイレクトメッセージ** を送信していることを確認してください
    - ペアリングシステムは、新しいユーザーからの最初のメッセージで有効になります
  </Accordion>
  <Accordion title="ボットの応答が遅い">
    - 応答時間は選択した AI モデルによって異なります
    - 大規模なモデル (Claude Opus, GPT-5) は数秒かかる場合があります
    - LemonData の残高を確認してください。クレジットが不足しているとエラーが発生します
  </Accordion>
</AccordionGroup>
