## Was ist LemonData?

LemonData ist eine AI-API-Aggregationsplattform, die Ihnen einheitlichen Zugriff auf **300+ AI-Modelle** von Anbietern wie OpenAI, Anthropic, Google, DeepSeek, Moonshot, MiniMax und weiteren bietet.

| **3D** | 3D-Asset-Generierung | `tripo3d` |

## Ein guter Standard-Startpunkt

Beginnen Sie bei neuen Projekten mit dem OpenAI SDK und der **Responses API**:

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```
