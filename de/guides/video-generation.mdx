## Überblick

LemonData bietet Zugriff auf Video-Generierungsmodelle von 11 Anbietern über eine einzige einheitliche API. Die Video-Generierung ist **asynchron** — Sie senden eine Anfrage, erhalten eine Task-ID und `poll_url` und pollen dann auf das Ergebnis.

<Info>
Die Modellliste wird häufig aktualisiert. Die neuesten verfügbaren Modelle und Preise finden Sie auf der [Modellseite](https://lemondata.cc/de/models) oder über die [Models API](/api-reference/models/list-models).
</Info>

<Warning>
Audio behavior is model-dependent. In LemonData, Veo 3 family requests default to audio-on when `output_audio` is omitted. Some models are silent by default or silent-only. For passthrough-governed models, pass `output_audio=true` to make a best-effort upstream audio request.
</Warning>


### Asynchroner Workflow

```mermaid
sequenceDiagram
    participant Client
    participant LemonData
    participant Provider

    Client->>LemonData: POST /v1/videos/generations
    LemonData->>Provider: Forward request
    Provider-->>LemonData: task_id + pending
    LemonData-->>Client: { task_id, poll_url, status: "pending" }

    loop Poll every 5-10s
        Client->>LemonData: GET poll_url
        LemonData->>Provider: Query status
        Provider-->>LemonData: Status update
        LemonData-->>Client: { status, video_url? }
    end
```

<CodeGroup>

```python Python
import requests
import time

API_KEY = "sk-your-api-key"
BASE = "https://api.lemondata.cc/v1"
headers = {"Authorization": f"Bearer {API_KEY}"}

# Step 1: Submit generation request
resp = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
create_data = resp.json()
task_id = create_data["task_id"]
poll_url = create_data["poll_url"]

# Step 2: Poll for result
while True:
    status = requests.get(f"https://api.lemondata.cc{poll_url}", headers=headers).json()
    if status["status"] in ("completed", "succeeded"):
        print(f"Video URL: {status['video_url']}")
        break
    elif status["status"] == "failed":
        print(f"Failed: {status.get('error')}")
        break
    time.sleep(10)
```

```javascript JavaScript
const API_KEY = 'sk-your-api-key';
const BASE = 'https://api.lemondata.cc/v1';
const headers = { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' };

// Step 1: Submit
const { task_id, poll_url } = await fetch(`${BASE}/videos/generations`, {
  method: 'POST', headers,
  body: JSON.stringify({
    model: 'sora-2',
    prompt: 'A calm cinematic shot of a cat walking through a sunlit garden.',
    operation: 'text-to-video',
    duration: 4,
    aspect_ratio: '16:9'
  })
}).then(r => r.json());

// Step 2: Poll
const poll = setInterval(async () => {
  const status = await fetch(`https://api.lemondata.cc${poll_url}`, { headers }).then(r => r.json());
  if (['completed', 'succeeded'].includes(status.status)) {
    console.log('Video URL:', status.video_url);
    clearInterval(poll);
  } else if (status.status === 'failed') {
    console.error('Failed:', status.error);
    clearInterval(poll);
  }
}, 10000);
```

### Definitionen der Fähigkeiten

- **T2V (Text-to-Video)**: Video aus einem Text-Prompt generieren
- **I2V (Image-to-Video)**: Ein statisches Bild zu einem Video animieren. Für die breiteste Kompatibilität geben Sie eine öffentliche `image_url` an.
- **Keyframe**: Start- und Endframes mit `start_image` + `end_image` steuern
- **Extension**: Die Dauer eines bestehenden Videos verlängern
- **Editing**: Bestimmte Aspekte eines bestehenden Videos ändern

## Anwendungsbeispiele

### Text-to-Video (T2V)

Der häufigste Anwendungsfall. Alle Modelle unterstützen dies.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
```

### Image-to-Video (I2V)

Animieren Sie ein statisches Bild. Für die breiteste Kompatibilität über Videomodelle hinweg hosten Sie das Quellbild und übergeben `image_url`.

```python
# Using image URL
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/portrait.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)

```

### Keyframe-Steuerung (Start + Endbild)

Steuern Sie sowohl den ersten als auch den letzten Frame für präzise Übergänge. Derzeit unterstützt von Seedance 2.0.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night, city lights gradually turning on",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/city-day.jpg",
        "end_image": "https://example.com/city-night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```

### Video-Erweiterung

Verlängern Sie die Dauer eines bestehenden Videos. Verwenden Sie Modelle mit Erweiterungsfähigkeit.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "kling-video-extend",
        "prompt": "Continue the scene naturally",
        "image_url": "https://example.com/last-frame.jpg"
    }
)
```

## Parameterreferenz

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Modell-ID (Standard: `sora-2`) |
| `prompt` | string | **Erforderlich.** Textbeschreibung des Videos |
| `image_url` | string | URL des Startbildes (für I2V) |
| `image` | string | Inline-Bild als data URL. Von kompatiblen Modellen unterstützt, aber `image_url` bietet die breiteste Kompatibilität. |
| `duration` | integer | Videodauer in Sekunden (1–60, modellabhängig) |
| `aspect_ratio` | string | `16:9`, `9:16`, `1:1` usw. |
| `resolution` | string | `1080p`, `720p`, `4k` |
| `fps` | integer | Frames pro Sekunde (1–120) |
| `negative_prompt` | string | Was bei der Generierung vermieden werden soll |
| `seed` | integer | Zufalls-Seed für Reproduzierbarkeit |
| `cfg_scale` | number | Guidance-Skala (0–20) |
| `motion_strength` | number | Bewegungsintensität (0–1) |
| `start_image` | string | URL des Start-Keyframes |
| `end_image` | string | URL des End-Keyframes |

<Warning>
Nicht alle Parameter werden von jedem Modell unterstützt. Nicht unterstützte Parameter werden stillschweigend ignoriert. Prüfen Sie die Dokumentation des Modells auf unterstützte Parameter.
</Warning>

## Abrechnung

Die Video-Generierung verwendet **feste Preise pro Generierung**. Ihnen wird einmal bei Einreichung der Task berechnet, unabhängig von der Videodauer. Falls die Generierung fehlschlägt, wird die Gebühr automatisch erstattet.

Die aktuellen Preise finden Sie auf der [Modellseite](https://lemondata.cc/de/models) oder über die [Pricing API](/api-reference/pricing/get-pricing).
