---
title: "Create Material Asset Group"
openapi: "POST /v1/videos/assets/groups"
description: "Creates a Seedance virtual-avatar material group for the current organization."
---

Creates a TokenLab Seedance material group for `library_type: "aigc_avatar"`.

Use this endpoint for virtual-avatar groups. New real-person groups are created by [real-person material verification](/api-reference/video/create-real-person-verification-session), not by direct group creation. Requests with `library_type: "liveness_face"` are rejected so verification and verified-person material mapping stay intact.

Groups are scoped to the authenticated organization. Use the returned `id` as `group_id` when creating material assets.
