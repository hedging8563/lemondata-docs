---
title: "Verlauf der Real-Person-Verifizierung auflisten"
openapi: "GET /v1/videos/assets/visual-validation-sessions"
description: "Listet die Real-Person-Materialverifizierungssitzungen für die aktuelle Organisation auf."
---

Listen Sie frühere Verifizierungssitzungen zur Überprüfung, für den Kundensupport und zur Abstimmung auf. Dieser Verlauf ist langlebig, ersetzt jedoch nicht den kurzlebigen Bind-Schritt: Eine erfolgreiche Verifizierung sollte weiterhin unmittelbar innerhalb des 120-Sekunden-Fensters gebunden werden.

Die Antwort enthält nur TokenLab-IDs und keine Anmeldedaten. Nach einem erfolgreichen Bind ist `group_id` die TokenLab-Materialgruppen-ID, die für `liveness_face`-Uploads verwendet wird.

## Beispielanfrage

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions?page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
