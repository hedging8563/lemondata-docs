---
title: "Material-Asset abrufen"
openapi: "GET /v1/videos/assets/{assetId}"
description: "Ruft ein Seedance-Material-Asset anhand der TokenLab-Material-Asset-ID ab."
---

Rufen Sie ein Material-Asset ab und überprüfen Sie dessen Verarbeitungsstatus. Das Asset kann nur dann für die Videogenerierung verwendet werden, wenn `ready` auf `true` und `status` auf `ACTIVE` gesetzt ist.

Wenn die Videogenerierung die Meldung `Seedance material asset not found or not accessible` zurückgibt, stellen Sie sicher, dass Sie die `id` dieses Material-Assets übergeben haben und nicht die `group_id` des Materials.

## Beispielanfrage

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Beispielantwort

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "asset_url": "https://example.com/reference.png",
  "cover_url": null,
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
