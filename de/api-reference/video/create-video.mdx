title: "Video erstellen"
openapi: "POST /v1/videos/generations"
description: "Erstellt eine Video-Generierungsaufgabe"
---

## Übersicht

Die Video-Generierung ist asynchron. Sie senden eine Anfrage, erhalten eine Aufgaben-ID und `poll_url` und fragen dann das Ergebnis per Polling ab.

<Info>
Für das zuverlässigste Polling-Verhalten folgen Sie genau der `poll_url`, die von der Erstellungsanfrage zurückgegeben wird.
</Info>

<Warning>
Die Audioausgabe ist modellabhängig. In LemonData aktiviert die Veo-3-Familie standardmäßig Audio, wenn `output_audio` weggelassen wird. Wenn ein Modell Audio steuern kann, verwenden Sie `output_audio`, um es explizit umzuschalten. Das camelCase-Alias `outputAudio` wird aus Kompatibilitätsgründen ebenfalls akzeptiert.
</Warning>


## Request-Body

<ParamField body="model" type="string" default="sora-2">
  Video-Modell-ID. Der API-Standardwert ist `sora-2`. Siehe den [Leitfaden zur Video-Generierung](/guides/video-generation) für die aktuelle Modellmatrix und unterstützte Funktionen.
</ParamField>

<ParamField body="prompt" type="string" required>
  Textbeschreibung des zu generierenden Videos.
</ParamField>

<ParamField body="image_url" type="string">
  Öffentlich zugängliche URL des Startbilds für die Bild-zu-Video-Generierung (I2V). Für die beste modellübergreifende Kompatibilität sollte `image_url` bevorzugt werden.
</ParamField>

<ParamField body="image" type="string">
  Inline-Bild als Data-URL (zum Beispiel `data:image/jpeg;base64,...`). Wird von kompatiblen Modellen unterstützt, aber `image_url` bietet die breiteste Kompatibilität über Video-Modelle hinweg.
</ParamField>

<ParamField body="duration" type="integer">
  Videodauer in Sekunden (modellabhängig).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Seitenverhältnis (z. B. `16:9`, `9:16`, `1:1`).
</ParamField>

<ParamField body="resolution" type="string">
  Videoauflösung (z. B. `1080p`, `720p`).
</ParamField>

<ParamField body="output_audio" type="boolean">
  Modellabhängiger Schalter für die Audioausgabe. In LemonData verwendet die Veo-3-Familie standardmäßig `true`, wenn dieses Feld weggelassen wird. Andere Videomodelle folgen ihrem jeweils definierten Standardverhalten. Das camelCase-Alias `outputAudio` wird aus Kompatibilitätsgründen akzeptiert.
</ParamField>

<ParamField body="fps" type="integer">
  Bilder pro Sekunde (1–120).
</ParamField>

<ParamField body="negative_prompt" type="string">
  Was bei der Video-Generierung vermieden werden soll.
</ParamField>

<ParamField body="seed" type="integer">
  Zufalls-Seed für reproduzierbare Generierung.
</ParamField>

<ParamField body="cfg_scale" type="number">
  Classifier-free Guidance-Skala (0–20).
</ParamField>

<ParamField body="motion_strength" type="number">
  Bewegungsintensität (0–1).
</ParamField>

<ParamField body="start_image" type="string">
  URL des Startframe-Bilds.
</ParamField>

<ParamField body="end_image" type="string">
  URL des Endframe-Bilds.
</ParamField>

<ParamField body="user" type="string">
  Eine eindeutige Kennung für den Endbenutzer.
</ParamField>

## Antwort

<ResponseField name="task_id" type="string">
  Eindeutige Aufgabenkennung für Polling.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Empfohlene Polling-URL für diese Aufgabe. Verwenden Sie beim Prüfen des Status genau diesen Pfad.
</ResponseField>

<ResponseField name="status" type="string">
  Anfangsstatus: `pending`.
</ResponseField>

<ResponseField name="model" type="string">
  Verwendetes Modell.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/videos/generations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sora-2",
    "prompt": "A cat walking through a garden, cinematic lighting",
    "operation": "text-to-video",
    "duration": 4,
    "aspect_ratio": "16:9"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={
        "Authorization": "Bearer sk-your-api-key",
        "Content-Type": "application/json"
    },
    json={
        "model": "sora-2",
        "prompt": "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)

data = response.json()
task_id = data["task_id"]
print(f"Poll URL: {data['poll_url']}")
print(f"Task ID: {task_id}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":    "sora-2",
        "prompt":   "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/videos/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Poll URL: %s\n", result["poll_url"])
    fmt.Printf("Task ID: %s\n", result["task_id"])
}
```

## Bild zu Video

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/image.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)
```

## Keyframe-Steuerung

Verwenden Sie `start_image` und `end_image`, um den ersten und letzten Frame zu steuern (unterstützt von Vidu Q2 Pro):

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night",
        "operation": "Start-Endbild-zu-Video",
        "start_image": "https://example.com/day.jpg",
        "end_image": "https://example.com/night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```
