---
title: "Material-Asset erstellen"
openapi: "POST /v1/videos/assets"
description: "Lädt ein Seedance-Material-Asset in eine TokenLab-Materialgruppe hoch."
---

Importieren Sie eine öffentlich erreichbare Quell-URL in eine Seedance-Materialgruppe. TokenLab speichert das Material für die spätere Verwendung; verwenden Sie für die Generierung die zurückgegebene Material-Asset-`id` und nicht die Quell-URL.

Für `library_type: "aigc_avatar"` ist `group_id` optional; TokenLab verwendet oder erstellt die Standard-Gruppe für virtuelle Avatare der Organisation. Für `library_type: "liveness_face"` ist `group_id` erforderlich und muss die TokenLab-Gruppe sein, die von [Bind Real-Person Verification Result](/de/api-reference/video/bind-real-person-verification-result) zurückgegeben wurde.

| Typ | Unterstützte Eingabe |
|------|-----------------|
| Bild | `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; Seitenverhältnis `(0.4, 2.5)`; Breite und Höhe `(300, 6000)` px; unter 30 MB. |
| Video | `mp4`, `mov`; `480p`, `720p` oder `1080p`; 2-15 Sekunden; Seitenverhältnis `[0.4, 2.5]`; Breite und Höhe `[300, 6000]` px; Gesamtpixel zwischen 409600 und 2086876; bis zu 50 MB; 24-60 FPS. |
| Audio | `wav`, `mp3`; 2-15 Sekunden; bis zu 15 MB. |

Die Erstellung erfolgt asynchron. Fragen Sie [Get Material Asset](/de/api-reference/video/get-material-asset) ab, bis der `status` auf `ACTIVE` steht. Bei Gruppen für echte Personen wird eine Gruppe einer verifizierten Person zugeordnet; Uploads mit mehreren Gesichtern oder einem Gesicht, das nicht mit der verifizierten Person übereinstimmt, können fehlschlagen.

## Beispielanfrage

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"seedance_group_virtual_123","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view"}'
```

## Beispielantwort

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
