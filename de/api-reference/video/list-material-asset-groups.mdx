---
title: "Material-Asset-Gruppen auflisten"
openapi: "GET /v1/videos/assets/groups"
description: "Listet Seedance-Materialgruppen auf, die der aktuellen Organisation gehören."
---

Listet Materialgruppen auf, die der authentifizierten Organisation gehören. Filtern Sie nach `library_type` und `status`, um Gruppen für virtuelle Avatare von Gruppen für echte Personen zu trennen.

Verwenden Sie eine zurückgegebene `group_id` beim Hochladen von Materialien. Übergeben Sie keine `group_id` als `material_asset_id` während der Videogenerierung; die Generierung erfordert eine `id` des Material-Assets.

## Beispielanfrage

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups?library_type=aigc_avatar&page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Beispielantwort

```json
{
  "groups": [
    {
      "id": "seedance_group_virtual_123",
      "object": "seedance.material_asset_group",
      "library_type": "aigc_avatar",
      "group_name": "Product references",
      "status": "ACTIVE",
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
