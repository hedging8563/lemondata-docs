---
title: "Videostatus abrufen"
openapi: "GET /v1/tasks/{id}"
description: "Ruft den Status und das Ergebnis einer Videogenerierungsaufgabe ab"
---

## Pfadparameter

<ParamField path="id" type="string" required>
  Kanonische asynchrone Aufgaben-ID. Wenn `id` und `task_id` beide vorhanden sind, behandeln Sie sie als dieselbe Aufgabe.
</ParamField>

<Info>
Wenn eine Create-Response `poll_url` zurückgibt, verwenden Sie genau diese URL. Wenn sie auf `/v1/tasks/{id}` zeigt, behandeln Sie sie als kanonischen festen Status-Endpunkt.
</Info>

## Antwort

<ResponseField name="id" type="string">
  Kanonische asynchrone Task-ID.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias der asynchronen Task-ID.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Bevorzugte Polling-URL aus der Create-Response.
</ResponseField>

<ResponseField name="status" type="string">
  Task-Status: `pending`, `processing`, `completed`, `failed`.
</ResponseField>

<ResponseField name="progress" type="number">
  Fortschritt in Prozent (0-100).
</ResponseField>

<ResponseField name="video_url" type="string">
  URL des generierten Videos (nach Abschluss).
</ResponseField>

<ResponseField name="video" type="object">
  Einzelnes Videoobjekt mit `url`, `duration`, `width` und `height`, falls verfügbar.
</ResponseField>

<ResponseField name="videos" type="array">
  Video-Array, wenn der Upstream mehrere Ausgaben zurückgibt.
</ResponseField>

<ResponseField name="error" type="string">
  Fehlermeldung (falls fehlgeschlagen).
</ResponseField>

<ResponseField name="created" type="integer">
  Zeitstempel der Erstellung.
</ResponseField>

<ResponseField name="updated" type="integer">
  Zeitstempel der letzten Aktualisierung.
</ResponseField>

<ResponseField name="model" type="string">
  Für die Task verwendetes Modell.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/tasks/video_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests
import time

task_id = "video_abc123"

while True:
    response = requests.get(
        f"https://api.lemondata.cc/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )

    data = response.json()
    print(f"Status: {data['status']}, Progress: {data.get('progress', 0)}%")

    if data["status"] == "completed":
        print(f"Video URL: {data['video_url']}")
        break
    elif data["status"] == "failed":
        print(f"Error: {data['error']}")
        break

    time.sleep(5)  # Poll every 5 seconds
```
