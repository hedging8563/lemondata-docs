---
title: "Ergebnis der Real-Person-Verifizierung binden"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "Bindet ein erfolgreiches Ergebnis der Real-Person-Materialverifizierung an eine TokenLab-Materialgruppe."
---

Binden Sie das erfolgreiche Verifizierungsergebnis und erstellen Sie die Zuordnung der TokenLab Real-Person-Materialgruppe. Verwenden Sie dazu die `session_id` und das `verification_token` aus der Verifizierungssitzung oder dem TokenLab-Callback-Redirect.

TokenLab überprüft, ob die Sitzung zur selben Organisation gehört, nicht abgelaufen ist und an denselben Materialdienst gebunden ist, der auch für die Verifizierungssitzung verwendet wurde. Die Antwort gibt nur eine TokenLab `group_id` zurück; verwenden Sie diese beim Erstellen von `liveness_face`-Material-Assets.

## Beispielanfrage

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## Beispielantwort

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "seedance_group_real_123",
  "material_group": {
    "id": "seedance_group_real_123",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
