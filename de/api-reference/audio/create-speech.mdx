## Anfragekörper

**Timeout für synchrone Anfragen:** Dieser Nicht-Chat-Endpunkt wartet, bis das geroutete Modell fertig ist. Große Eingaben, lange Audiodateien oder große Batches können übliche 30s-Client-Defaults überschreiten; setzen Sie das Timeout Ihres HTTP-Clients daher auf mindestens `120s`.

Unterstützte optionale Felder unterscheiden sich je nach Modellfamilie. TokenLab validiert diese Feldmatrix vor dem Routing: OpenAI TTS akzeptiert `voice`, `instructions`, `response_format`, `stream_format` und `speed`; MiniMax Speech akzeptiert `voice`, `voice_id`, `response_format`, `stream_format` und `speed`; Gemini TTS akzeptiert `prompt`, `language_code`, `voice`, `response_format`, `stream_format`, `speed` und `temperature`.

<ParamField body="model" type="string" default="tts-1">
  TTS-Modell. Beispiele sind `tts-1`, `gpt-4o-mini-tts`, `speech-02-hd` und `gemini-2.5-flash-tts`. Fragen Sie `GET /v1/models?recommended_for=tts` für die aktuelle Auswahl ab.
</ParamField>

<ParamField body="input" type="string" required>
  Der Text, für den Audio erzeugt werden soll. Maximal 4096 Zeichen.
</ParamField>

<ParamField body="voice" type="string | object">
  Stimm-Auswahl. Übergeben Sie einen integrierten Namen wie `nova`, eine Gemini-Stimme wie `Kore` oder ein Objekt wie `{ "id": "voice-id" }` für kompatible benutzerdefinierte Stimmen.
</ParamField>

<ParamField body="voice_id" type="string">
  Provider-nativer Stimm-Selector für MiniMax-kompatible Speech-Modelle.
</ParamField>

<ParamField body="instructions" type="string">
  Optionale Stil- oder Vortragsanweisungen für OpenAI-kompatible TTS-Modelle, die dieses Feld unterstützen.
</ParamField>

<ParamField body="prompt" type="string">
  Optionaler Prompt für den Sprechstil bei Gemini TTS-Modellen.
</ParamField>

<ParamField body="language_code" type="string">
  Optionaler Sprachcode, zum Beispiel `en-US`, für Gemini-, xAI- und kompatible TTS-Routen.
</ParamField>

<ParamField body="response_format" type="string">
  Audioformat. Häufige Werte sind `mp3`, `opus`, `aac`, `flac`, `wav` und `pcm`; unterstützte Werte variieren je nach Modellfamilie.
</ParamField>

<ParamField body="stream_format" type="string" default="audio">
  TokenLab-Auslieferungsformat: `audio` oder `sse`. `stream_format=sse` wird für `tts-1` und `tts-1-hd` nicht unterstützt.
</ParamField>

<ParamField body="speed" type="number">
  Sprechgeschwindigkeit für Modellfamilien, die sie unterstützen (0.25 bis 4.0).
</ParamField>

<ParamField body="temperature" type="number">
  Sampling-Temperatur für Gemini-kompatible TTS-Routen (0 bis 2).
</ParamField>

## Antwort

Gibt die Audiodatei im angeforderten Format zurück.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/speech" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-1-hd",
    "voice": "nova",
    "input": "Hello, welcome to TokenLab!"
  }' \
  --output speech.mp3
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.audio.speech.create(
    model="tts-1-hd",
    voice="nova",
    input="Hello, welcome to TokenLab!"
)

response.stream_to_file("speech.mp3")
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.speech.create({
  model: 'tts-1-hd',
  voice: 'nova',
  input: 'Hello, welcome to TokenLab!'
});

const buffer = Buffer.from(await response.arrayBuffer());
fs.writeFileSync('speech.mp3', buffer);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/speech');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'tts-1-hd',
        'voice' => 'nova',
        'input' => 'Hello, welcome to TokenLab!'
    ])
]);

$audio = curl_exec($ch);
curl_close($ch);

file_put_contents('speech.mp3', $audio);
```
</RequestExample>

## Sprachbeispiele

| Stimme | Beschreibung |
|-------|-------------|
| `alloy` | Neutral, ausgewogen |
| `ash` | Ruhig, bedacht |
| `ballad` | Melodisch, ausdrucksstark |
| `coral` | Warm, einladend |
| `echo` | Warm, dialogorientiert |
| `fable` | Ausdrucksstark, erzählerisch |
| `nova` | Freundlich, klar |
| `onyx` | Tief, autoritativ |
| `sage` | Weise, nachdenklich |
| `shimmer` | Sanft, weich |
| `verse` | Dynamisch, vielseitig |
