---
title: "API-Schlüssel erstellen"
openapi: "POST /v1/management/api-keys"
description: "Erstellt einen neuen Benutzer-API-Schlüssel für die aktuelle Organisation."
---

## Übersicht

Erstellt einen neuen `type=user` API-Schlüssel in der Organisation, die dem aktuellen Management-Token zugeordnet ist.

## Hinweise

- Der vollständige Schlüssel wird in der Antwort nur einmal angezeigt.
