## Übersicht

Mit der Verwaltungs-API können Sie Organisations-API-Schlüssel verwalten sowie Nutzung und Abrechnung für einen bestimmten Schlüssel abrufen, ohne einen normalen Inferenz-API-Schlüssel zu verwenden.

Verwenden Sie ein Management-Token aus der **Settings**-Seite im Dashboard:

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
Management-Tokens sind keine Inferenz-API-Schlüssel. Verwenden Sie `mt-...` für `/v1/management/*` und `sk-...` für Modell-Inferenz-Endpunkte wie `/v1/responses`.
</Warning>

## Verfügbare Endpunkte

| Endpoint | Method | Beschreibung |
|----------|--------|------|
| `/v1/management/api-keys` | GET | Listet benutzerverwaltete API-Schlüssel der aktuellen Organisation auf |
| `/v1/management/api-keys` | POST | Erstellt einen neuen Benutzer-API-Schlüssel |
| `/v1/management/api-keys/{keyId}` | PATCH | Aktualisiert Name, Nutzungslimit, erlaubte Modelle, Ablaufdatum oder Status |
| `/v1/management/api-keys/{keyId}/usage` | GET | Ruft paginierte Nutzungsdetails für einen bestimmten Schlüssel ab |
| `/v1/management/api-keys/{keyId}/billing` | GET | Ruft aggregierte Abrechnungsaufschlüsselungen für einen bestimmten Schlüssel ab |

## Felder erklärt

- angeforderter Modellname (`model`)
- öffentlicher Modellanbieter
- `scene`
- `accessChannel`: `platform` bedeutet, dass die Anfrage als Plattform-Anfrage abgerechnet wurde; `byok` bedeutet, dass Ihr eigener Upstream-Provider-Schlüssel verwendet wurde
- Nutzungsmenge, Abrechnungseinheit und Cache-Metriken
- Kosten und Zeitstempel

Antworten enthalten nur öffentliche Abrechnungs- und Reporting-Felder. Interne Routing-Details und physische Provider-Metadaten bleiben verborgen.

## Filter

`/usage` und `/billing` unterstützen derzeit Filter nach:

- Zeitraum
- angeforderter Modell-ID
- öffentlichem Modellanbieter
- `scene`
- `accessChannel`
- Paginierung

## Vollständiges Anfragebeispiel

Beginnen Sie damit, die API-Schlüssel der aktuellen Organisation über das aktuelle Management-Token aufzulisten:

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```

```python Python
import requests

response = requests.get(
    "https://api.lemondata.cc/v1/management/api-keys",
    headers={"Authorization": "Bearer mt-your-management-token"}
)

data = response.json()
for key in data["data"]:
    print(key["name"], key["status"], key["used_amount"])
```

```javascript JavaScript
const response = await fetch(
  'https://api.lemondata.cc/v1/management/api-keys',
  {
    headers: {
      'Authorization': 'Bearer mt-your-management-token'
    }
  }
);

const data = await response.json();
for (const key of data.data) {
  console.log(key.name, key.status, key.used_amount);
}
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/management/api-keys", nil)
    req.Header.Set("Authorization", "Bearer mt-your-management-token")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)

    fmt.Println(result["object"])
}
```

```php PHP
<?php
$ch = curl_init("https://api.lemondata.cc/v1/management/api-keys");

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer mt-your-management-token'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
foreach ($data['data'] as $key) {
    echo $key["name"] . " " . $key["status"] . " " . $key["used_amount"] . PHP_EOL;
}
```
</RequestExample>
