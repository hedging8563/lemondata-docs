## Übersicht

Dieser Endpunkt liefert nutzungsbezogene Schlüsseldetails mit Filtern für angeforderten Modellnamen (`model`), öffentlichen Modellanbieter, `scene` und `accessChannel`.

## Hinweise

- Die Antwort enthält nur öffentliche Abrechnungsfelder.
- Internes Routing und physische Kanal-Metadaten werden bewusst verborgen.
