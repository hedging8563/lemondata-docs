---
title: "API-Schlüssel aktualisieren"
openapi: "PATCH /v1/management/api-keys/{keyId}"
description: "Aktualisiert einen vorhandenen Benutzer-API-Schlüssel für die aktuelle Organisation."
---

## Übersicht

Mit diesem Endpunkt können Sie Name, Nutzungslimit, erlaubte Modelle, Ablaufdatum oder Status eines vorhandenen Benutzer-API-Schlüssels aktualisieren.

## Hinweise

- Hard Delete wird in Verwaltungs-API v1 absichtlich nicht unterstützt.
