---

## Übersicht

Gibt die Benutzer-API-Schlüssel der Organisation zurück, die dem aktuellen Management-Token zugeordnet ist.

## Hinweise

- Systemverwaltete Schlüssel wie Playground- oder Claw-Schlüssel sind ausgeschlossen.
- Monetäre Antwortfelder werden sowohl in USD als auch als RMB-Anzeigewert zurückgegeben: `limit_amount` / `limit_amount_cny`, `used_amount` / `used_amount_cny`.
- `exchange_rate` gibt den USD→CNY-Kurs an, der für die RMB-Anzeigefelder verwendet wurde.

## Beispiel

<RequestExample>
```bash cURL
curl -X GET "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>
