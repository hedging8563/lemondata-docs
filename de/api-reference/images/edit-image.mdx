## Übersicht

Erstellt ein bearbeitetes oder erweitertes Bild auf Basis eines Originalbilds und eines Prompts.

Die Route unterstützt sowohl:

- den unten dokumentierten klassischen DALL-E-Stil mit `multipart/form-data`
- JSON-Anfragen mit `image_url` für unterstützte Image-to-Image-Familien

<Note>
`gpt-image-2` wird auf diesem Endpunkt unterstützt. Send multipart `image` or JSON `image_url`; optional parameters are `mask`, `n`, `size`, `quality`, `response_format`, `output_format`, `output_compression` or `compression`, `moderation`, `partial_images`, and `user`. `background` bleibt auf den Bildgenerierungs-Pfad beschränkt und gehört nicht zum aktuellen öffentlichen `gpt-image-2`-Image-Edit-Vertrag. Billing follows the upstream usage token details, including image input tokens and any image output tokens added for partial images.
</Note>

## Request Body

<ParamField body="image" type="file" required>
  Das zu bearbeitende Bild. Muss eine gültige PNG-Datei sein, kleiner als 50MB und quadratisch. Das Bild sollte Transparenz enthalten, wo Bearbeitungen gewünscht sind.
</ParamField>

<ParamField body="prompt" type="string" required>
  Eine Textbeschreibung der gewünschten Bearbeitung.
</ParamField>

<ParamField body="mask" type="file">
  Ein zusätzliches Bild, dessen vollständig transparente Bereiche angeben, wo das Bild bearbeitet werden soll. Muss eine gültige PNG-Datei sein, kleiner als 50MB und die gleichen Abmessungen wie `image` haben.
</ParamField>

<ParamField body="model" type="string" default="dall-e-2">
  The model to use for image edit. `gpt-image-2` is supported; legacy DALL-E style edits can continue to use `dall-e-2`.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Die Anzahl der zu generierenden Bilder. Muss zwischen 1 und 10 liegen.
</ParamField>

<ParamField body="size" type="string">
  The generated image size. For `gpt-image-2`, use `auto` or `WIDTHxHEIGHT`; dimensions must be multiples of 16, longest edge at most `3840px`, long/short ratio at most `3:1`, and total pixels between `655,360` and `8,294,400`. Legacy DALL-E edits support `256x256`, `512x512`, or `1024x1024`.
</ParamField>

<ParamField body="response_format" type="string" default="url">
  Das Format der zurückgegebenen Bilder. Muss `url` oder `b64_json` sein.
</ParamField>

<ParamField body="user" type="string">
  Eine eindeutige Kennung für Ihren Endbenutzer zur Missbrauchsüberwachung.
</ParamField>

## Antwort

<ResponseField name="created" type="integer">
  Unix-Zeitstempel der Bilderstellung.
</ResponseField>

<ResponseField name="data" type="array">
  Array der generierten Bilder.

  Jedes Objekt enthält:
  - `url` (string): URL des bearbeiteten Bildes, wenn `response_format` auf `url` gesetzt ist
  - `b64_json` (string): Base64-kodiertes Bild, wenn `response_format` auf `b64_json` gesetzt ist
</ResponseField>

```go Go
package main

import (
    "bytes"
    "fmt"
    "io"
    "mime/multipart"
    "net/http"
    "os"
)

func main() {
    body := &bytes.Buffer{}
    writer := multipart.NewWriter(body)

    image, _ := os.Open("sunlit_lounge.png")
    defer image.Close()
    part, _ := writer.CreateFormFile("image", "sunlit_lounge.png")
    io.Copy(part, image)

    mask, _ := os.Open("mask.png")
    defer mask.Close()
    maskPart, _ := writer.CreateFormFile("mask", "mask.png")
    io.Copy(maskPart, mask)

    writer.WriteField("prompt", "A sunlit indoor lounge area with a pool")
    writer.WriteField("n", "1")
    writer.WriteField("size", "1024x1024")
    writer.Close()

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/images/edits", body)
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", writer.FormDataContentType())

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    result, _ := io.ReadAll(resp.Body)
    fmt.Println(string(result))
}
```

## Hinweise

<Note>
  Bildbearbeitungen sind nur mit DALL-E 2 verfügbar. Das Bild muss transparente Bereiche enthalten, die markieren, wo die Bearbeitung angewendet werden soll, oder Sie können ein separates Maskenbild angeben.
</Note>
