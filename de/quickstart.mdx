## Schritt 1: Holen Sie sich Ihren API-Schlüssel

<Steps>
  <Step title="Ein Konto erstellen">
    Registrieren Sie sich bei [lemondata.cc](https://lemondata.cc) mit Ihrer E-Mail, Ihrem Gmail- oder GitHub-Konto.
  </Step>
  <Step title="Guthaben hinzufügen">
    Öffnen Sie das Dashboard und fügen Sie Ihrem Konto Guthaben hinzu. LemonData verwendet nutzungsbasierte Preise ohne Mindestverpflichtung.
  </Step>
  <Step title="Einen API-Schlüssel erstellen">
    Gehen Sie zu **Dashboard → API Keys** und erstellen Sie einen neuen Schlüssel. Kopieren Sie ihn sicher, da er nur einmal angezeigt wird.
  </Step>
</Steps>

<Warning>
Bewahren Sie Ihren API-Schlüssel sicher auf. Legen Sie ihn niemals in clientseitigem Code oder öffentlichen Repositories offen.
</Warning>

## Schritt 3: Stellen Sie Ihre erste Anfrage

Für neue Projekte beginnen Sie mit der **Responses API**.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
Wenn Ihr Framework oder Tool noch Chat Completions erwartet, unterstützt LemonData auch `POST /v1/chat/completions`. Für neue Integrationen sollten Sie `POST /v1/responses` bevorzugen.
</Note>

## Verschiedene Modelle ausprobieren

LemonData unterstützt über 300 Modelle. Ändern Sie nur das Feld `model`:

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## Streaming aktivieren

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
