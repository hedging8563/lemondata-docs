<Note>
**Self-hosted** bedeutet, dass Sie LemonClaw direkt auf Ihrem eigenen VPS oder Rechner ausführen. Sie zahlen nur für die Nutzung der AI-Modelle über Ihr LemonData-Guthaben — keine Instanzgebühren.
</Note>

<Tip>
Bevorzugen Sie ein gehostetes Setup? [Erstellen Sie eine Claw-Instanz](/claw/introduction), um dieselbe LemonClaw-Runtime und WebUI zu erhalten, ohne selbst Server verwalten zu müssen.
</Tip>

## Schnellinstallation

<CodeGroup>
```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```

```bash Non-interactive
LEMONDATA_API_KEY=sk-xxx curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```
</CodeGroup>

Das Installationsprogramm wird Sie nach Ihrem **LemonData API Key** fragen. Erhalten Sie einen in Ihrem [Dashboard](https://lemondata.cc/dashboard).

## Was installiert wird

<Steps>
  <Step title="Node.js 22+">
    Wird automatisch installiert, falls fehlend (über NodeSource unter Linux, Homebrew unter macOS)
  </Step>
  <Step title="LemonClaw">
    LemonClaw-Paket, vorkonfiguriert mit der LemonData API
  </Step>
  <Step title="15 AI-Modelle">
    Claude, GPT-5, Gemini, DeepSeek und mehr — einsatzbereit
  </Step>
  <Step title="IM-Plugins">
    DingTalk-, WeCom- und QQ-Plugins vorinstalliert
  </Step>
  <Step title="Systemdienst">
    Automatischer Start beim Booten (systemd unter Linux, launchd unter macOS)
  </Step>
</Steps>

## Anforderungen

| Anforderung | Details |
|-------------|---------|
| **Betriebssystem** | Linux (Ubuntu/Debian/CentOS/RHEL) oder macOS |
| **Architektur** | x64 oder arm64 |

## Verwaltungsbefehle

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user status lemonclaw    # Status prüfen
    journalctl --user -u lemonclaw -f    # Logs anzeigen
    systemctl --user restart lemonclaw   # Neustart
    systemctl --user stop lemonclaw      # Stoppen
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    tail -f ~/.lemonclaw/lemonclaw.log    # Logs anzeigen
    launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # Neustart
    launchctl stop cc.lemondata.lemonclaw  # Stoppen
    ```
  </Tab>
</Tabs>

## Konfiguration

Speicherort der Konfigurationsdatei: `~/.lemonclaw/config.json`

Starten Sie den Dienst nach der Bearbeitung neu, um die Änderungen zu übernehmen.

### Standardmodell ändern

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-opus-4-6"
      }
    }
  }
}
```

Verfügbare Modell-Präfixe:
- `lemondata-claude/` — Claude-Modelle (anthropic-messages API)
- `lemondata-minimax/` — MiniMax-Modelle (anthropic-messages API)
- `lemondata/` — Alle anderen Modelle (openai-completions API)

## Upgrade

```bash
# Führen Sie das Installationsprogramm erneut aus, um auf die neueste Version zu aktualisieren
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
# Starten Sie anschließend den Dienst neu
systemctl --user restart lemonclaw  # Linux
# oder
launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # macOS
```

## Deinstallation

```bash
# Dienst stoppen und deaktivieren
systemctl --user stop lemonclaw && systemctl --user disable lemonclaw  # Linux
launchctl unload ~/Library/LaunchAgents/cc.lemondata.lemonclaw.plist  # macOS

# LemonClaw entfernen
rm -rf ~/.lemonclaw
```

| **Infrastruktur** | Ihr Server | Wir verwalten alles |
| **Updates** | Manuell (Installer erneut ausführen) | Automatisch |
| **Support** | Community | Priorität |
