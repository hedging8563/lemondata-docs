## Übersicht

LangBot kann TokenLab über einen OpenAI-kompatiblen LLM-Requester aufrufen.

<Note>
**Typ**: Bot-Plattform

**Primärer Pfad**: OpenAI-kompatible Chat-Completions

**Support-Status**: Unterstützt mit Einschränkungen im Funktionsumfang
</Note>

## TokenLab-Requester

Wenn Ihr LangBot-Build einen **TokenLab**-Requester enthält:

1. Öffnen Sie die Modell-Provider-Einstellungen von LangBot.
2. Fügen Sie einen Provider mit dem Requester **TokenLab** hinzu.
3. Setzen Sie den API-Key auf Ihren TokenLab-Key.
4. Wählen oder erstellen Sie ein Modell wie `gpt-5.4-mini`.
5. Verknüpfen Sie das Modell mit der Pipeline oder dem Bot, der es verwenden soll.

## OpenAI-kompatibler Fallback

Falls TokenLab noch nicht aufgeführt ist, verwenden Sie den OpenAI-kompatiblen Requester:

| Feld | Wert |
|-------|-------|
| Requester | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Modell | `gpt-5.4-mini` |

## Empfohlene Modelle

- `gpt-5.4-mini` für die meisten Bot-Interaktionen
- `claude-sonnet-5` für längere Texte und logisches Schlussfolgern
- `deepseek-v4-flash` für schnelles Programmieren und Reasoning-Schleifen
- `gemini-3.5-flash` für schnelle allgemeine Workflows
