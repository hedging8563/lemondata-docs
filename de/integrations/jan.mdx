## Übersicht

Jan kann eine Verbindung zu TokenLab als entfernten OpenAI-kompatiblen Anbieter herstellen.

<Note>
**Typ**: Chat-App

**Primärer Pfad**: OpenAI-kompatible Chat-Completions

**Support-Status**: Unterstützter Pfad
</Note>

## Jan konfigurieren

1. Öffnen Sie **Settings** -> **Providers**
2. Fügen Sie einen entfernten OpenAI-kompatiblen Anbieter hinzu
3. Geben Sie Folgendes ein:
   - **Name**: TokenLab
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Fügen Sie `gpt-5.4-mini` hinzu oder wählen Sie es aus
5. Speichern Sie die Einstellungen und starten Sie einen neuen Thread.

## Modell-Discovery

TokenLab stellt die Modell-Discovery unter folgendem Pfad bereit:

```text
https://api.tokenlab.sh/v1/models
```

Wenn Ihre Jan-Version die entfernte Modell-Discovery für TokenLab unterstützt, aktualisieren Sie die Modellliste. Andernfalls fügen Sie die Modell-IDs manuell hinzu.

## Empfohlene Modelle

- `gpt-5.4-mini`
- `gpt-5.4`
- `claude-sonnet-5`
- `gemini-3.5-flash`
- `deepseek-v4-flash`
