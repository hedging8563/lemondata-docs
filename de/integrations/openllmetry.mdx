## Überblick

Die OpenAI-Instrumentierung von OpenLLMetry verfolgt Aufrufe, die über das offizielle OpenAI SDK getätigt werden. Konfigurieren Sie dieses SDK mit der `/v1` Basis-URL von TokenLab.

<Note>
**Typ**: Observability

**Primärer Pfad**: OpenAI SDK-Instrumentierung

**Support-Vertrauen**: Unterstützter OpenAI-kompatibler Observability-Pfad
</Note>

## Installation

```bash
pip install opentelemetry-instrumentation-openai openai
```

## Umgebung

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Beispiel

```python
import os

from openai import OpenAI
from opentelemetry.instrumentation.openai import OpenAIInstrumentor

OpenAIInstrumentor().instrument()

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Trace this request"}],
)
```

## Hinweise zu Endpunkten

Verwenden Sie diesen Pfad für OpenAI SDK-kompatible TokenLab-Aufrufe. Für native TokenLab-Endpunkte instrumentieren Sie den HTTP- oder SDK-Client, der diese Anfragen tatsächlich sendet.
