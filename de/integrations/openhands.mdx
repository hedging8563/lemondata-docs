## Überblick

OpenHands kann TokenLab über seine LiteLLM/OpenAI-kompatible Modellkonfiguration nutzen, insbesondere für CLI- und Headless-Workflows, bei denen Sie das Modell, den API-Key und die Base URL bereitstellen.

<Note>
**Typ**: Coding Agent

**Primärer Pfad**: OpenAI-kompatible Modellkonfiguration

**Support-Vertrauen**: Unterstützter benutzerdefinierter Endpunkt-Pfad
</Note>

## Umgebung

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Modelleinstellungen

Verwenden Sie:

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

Das Präfix `openai/` weist den LiteLLM-basierten Pfad an, eine OpenAI-kompatible Provider-Konfiguration zu verwenden.

## Headless-Einrichtung

Wenn Sie lokale Standardeinstellungen für die CLI- oder Headless-Nutzung vorbereiten, führen Sie den OpenHands-Setup-Prozess aus und geben Sie Folgendes ein:

```bash
make setup-config
```

Wenn Sie nach Modelldetails gefragt werden, verwenden Sie die TokenLab-Modell-ID mit dem Präfix `openai/` und die `/v1` Base URL von TokenLab.

## Modellvorschläge

Verwenden Sie `claude-sonnet-5` oder `gpt-5.4` für die Planung von Coding-Agenten, `gpt-5.4-mini` für schnellere Routine-Schleifen und `deepseek-v4-pro`, wenn Sie ein leistungsstarkes alternatives Reasoning-Modell wünschen.
