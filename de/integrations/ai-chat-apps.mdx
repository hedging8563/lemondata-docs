## Überblick

Die meisten allgemeinen AI-Chat-Apps verbinden sich über den standardmäßigen OpenAI-kompatiblen Chat-Pfad mit LemonData.

In der Praxis bedeutet das:
- Verwenden Sie `https://api.lemondata.cc/v1` als Base URL, sofern die App nicht ausdrücklich nach einer vollständigen Endpoint-URL fragt
- Verwenden Sie Ihren LemonData API key als API key im OpenAI-Stil
- Wählen Sie Modelle aus, die die App in einem standardmäßigen Chat-Workflow verwenden kann

<Note>
Allgemeine Chat-Apps sind in der Regel **auf Chat Completions ausgerichtet** und keine Codex Responses WebSocket-Clients. Für Codex CLI/App, Cursor oder andere Coding-Tools, die Responses-spezifisches Verhalten benötigen, verwenden Sie stattdessen die dedizierten Integrationsleitfäden.
</Note>

## Standard-Verbindungswerte

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

Wenn eine App statt einer Base URL eine **vollständige Endpoint-URL** verlangt, verwenden Sie:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## Beispiel-App-Einrichtungen

<Tabs>
  <Tab title="LobeChat">
    **Self-hosted LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. Öffnen Sie **Settings** → **AI Service Provider**
    2. Wählen Sie **OpenAI**
    3. Geben Sie Ihren LemonData API key ein
    4. Setzen Sie den benutzerdefinierten Endpoint auf `https://api.lemondata.cc/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. Öffnen Sie **Settings** → **Model Provider**
    2. Fügen Sie einen **OpenAI-compatible** Provider hinzu
    3. Geben Sie ein:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. Fügen Sie die Modelle hinzu, die Sie verwenden möchten
  </Tab>

  <Tab title="Chatbox">
    1. Öffnen Sie **Settings** → **AI Model**
    2. Wählen Sie **OpenAI API Compatible**
    3. Geben Sie ein:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` oder `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. Öffnen Sie **Settings**
    2. Wählen Sie **Custom Endpoint**
    3. Geben Sie ein:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. Konfigurieren Sie die Modelle, die Sie bereitstellen möchten
  </Tab>
</Tabs>

## Tipps

<AccordionGroup>
  <Accordion title="Base URL bevorzugen, wenn die App sie unterstützt">
    Die meisten Apps lassen sich einfacher konfigurieren und sind weniger fehleranfällig, wenn Sie `https://api.lemondata.cc/v1` als Base URL statt einer vollständigen Endpoint-URL angeben.
  </Accordion>

  <Accordion title="Zuerst kleinere Modelle verwenden">
    Beginnen Sie für alltägliche Chats mit `gpt-5-mini` oder `gpt-4o` und verlagern Sie aufwendigere Reasoning-Aufgaben anschließend auf `gpt-5.4` oder `claude-opus-4-6`.
  </Accordion>

  <Accordion title="Coding-Tools getrennt halten">
    Allgemeine Chat-Apps und Coding-Agents benötigen oft unterschiedliches Endpoint-Verhalten. Lassen Sie Tools im Stil von Codex/Cursor auf ihren dedizierten Integrationsseiten.
  </Accordion>
</AccordionGroup>

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Verbindungsfehler">
    - Vergewissern Sie sich, dass die Base URL exakt `https://api.lemondata.cc/v1` ist
    - Entfernen Sie abschließende Schrägstriche, wenn die App Pfade automatisch anhängt
    - Wenn die App eine vollständige Endpoint-URL verlangt, verwenden Sie `https://api.lemondata.cc/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Unauthorized">
    - Überprüfen Sie Ihren API key erneut
    - Bestätigen Sie, dass der Schlüssel im LemonData-Dashboard aktiv ist
    - Stellen Sie sicher, dass keine zusätzlichen Leerzeichen oder Zeilenumbrüche vorhanden sind
  </Accordion>

  <Accordion title="Modell nicht verfügbar">
    - Überprüfen Sie den Modellnamen exakt
    - Versuchen Sie einen breit unterstützten Standard wie `gpt-5-mini`, `gpt-4o` oder `claude-sonnet-4-6`
    - Prüfen Sie die aktuelle Verfügbarkeit in den LemonData-Dokumenten oder im Dashboard
  </Accordion>
</AccordionGroup>
