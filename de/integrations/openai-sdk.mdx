## Überblick

LemonData funktioniert mit den offiziellen OpenAI SDKs, indem der Client auf `https://api.lemondata.cc/v1` verwiesen wird.

Für neue Projekte sollten Sie die **Responses API** bevorzugen. Behalten Sie **Chat Completions** nur bei, wenn ein Framework, Plugin oder veralteter Codepfad dies weiterhin erwartet.

<Note>
Für Python, JavaScript und Go gibt es offizielle OpenAI SDKs. PHP funktioniert gut mit OpenAI-kompatiblen Community-Clients, ist jedoch kein offizielles OpenAI SDK.
</Note>

## Den Client konfigurieren

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## Empfohlen: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

## Streaming mit Responses

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Tools / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## Vision mit Responses

```python
response = client.responses.create(
    model="gpt-4o",
    input=[{
        "role": "user",
        "content": [

            {"type": "input_image", "image_url": "https://example.com/image.jpg"}

print(response.output_text)
```

## Chat-Completions-Kompatibilität

Wenn Ihr Framework oder Plugin weiterhin Chat Completions erwartet, unterstützt LemonData auch den standardmäßigen OpenAI-kompatiblen Pfad:

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
Verwenden Sie Chat Completions nur für die Kompatibilität. Für neue Integrationen sollten Sie `client.responses.create(...)` bevorzugen.
</Warning>

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Verbindungsfehler">
    - Vergewissern Sie sich, dass die base URL exakt `https://api.lemondata.cc/v1` ist
    - Prüfen Sie auf Proxy-Interferenzen oder benutzerdefinierte HTTP-Client-Überschreibungen
    - Stellen Sie sicher, dass Ihre SDK-Version aktuell ist, bevor Sie das Provider-Verhalten debuggen
  </Accordion>

  <Accordion title="Authentifizierung fehlgeschlagen">
    - Prüfen Sie, dass Ihr API key mit `sk-` beginnt
    - Vergewissern Sie sich, dass der key im LemonData-Dashboard aktiv ist
    - Bestätigen Sie, dass das SDK `Authorization: Bearer ...` sendet
  </Accordion>

  <Accordion title="Falscher API-Pfad">
    - `responses.create(...)` sendet Anfragen an `/v1/responses`
    - `chat.completions.create(...)` sendet Anfragen an `/v1/chat/completions`
    - Wenn Ihre App heute nur Chat Completions unterstützt, belassen Sie sie auf diesem Kompatibilitätspfad
  </Accordion>
</AccordionGroup>
