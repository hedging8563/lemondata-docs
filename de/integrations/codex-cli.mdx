## Überblick

OpenAI Codex ist ein Open-Source-Befehlszeilentool (CLI), das als leichtgewichtiger Coding-Agent dient und Code im Terminal lesen, ändern und ausführen kann. Es basiert auf GPT-Modellen und ist für die Codegenerierung optimiert.

## Systemanforderungen

- **OS**: macOS, Linux (offizielle Unterstützung), Windows über WSL
- **Node.js**: Version 18+
- **npm**: Version 10.x.x oder höher

## Installation

```bash
sudo npm install -g @openai/codex
```

Installation überprüfen:

```bash
codex --version
```

## Konfiguration

### Schritt 1: API Key festlegen

**Temporär (aktuelle Sitzung):**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**Permanente Konfiguration:**

Zu `~/.bashrc`, `~/.zshrc` oder `~/.bash_profile` hinzufügen:

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

Dann neu laden:

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### Schritt 2: `config.toml` konfigurieren

`~/.codex/config.toml` bearbeiten:

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
Wenn die Konfigurationsdatei nicht existiert, führen Sie `codex` einmal aus, um sie zu erzeugen, und bearbeiten Sie dann die Datei. Starten Sie Codex nach Änderungen an `config.toml` vollständig neu, damit die neuen Provider-Einstellungen erneut geladen werden.
</Note>

<Warning>
Codex stellt die Unterstützung von `chat/completions` für benutzerdefinierte Provider ein. Behalten Sie für LemonData `wire_api = "responses"` bei, es sei denn, Sie verwenden absichtlich einen älteren Kompatibilitätspfad.
</Warning>

## Grundlegende Verwendung

**Interaktiven Modus starten:**

```bash
codex
```

**Direkter Befehl:**

```bash
codex "Fix the bug in main.py line 42"
```

**Modell angeben:**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## Empfohlene Modelle

| Modell | Am besten geeignet für |
|-------|----------|
| `gpt-5.4` | Beste Standardwahl für Coding und Reasoning |
| `gpt-5-mini` | Schnellere, günstigere Fallback-Option für Coding-Workflows |
| `claude-sonnet-4-6` | Code-Review, Dokumentation |
| `deepseek-r1` | Algorithmusdesign, Reasoning |

## Interaktive Befehle

| Befehl | Beschreibung |
|---------|-------------|
| `/help` | Hilfe anzeigen |
| `/exit` or `Ctrl+C` | Beenden |
| `/clear` | Konversation löschen |
| `/config` | Konfiguration anzeigen |
| `/model <name>` | Modell wechseln |
| `/tokens` | token-Nutzung anzeigen |

## Konfiguration überprüfen

```bash
# Check environment variable
echo $OPENAI_API_KEY

# Test API connection
codex "Hello, Codex!"

# View configuration
cat ~/.codex/config.toml
```

## Häufige Anwendungsfälle

**Code-Review:**

```bash
git diff | codex "Review these code changes"
```

**Commit-Nachrichten generieren:**

```bash
git diff --staged | codex "Generate a commit message for these changes"
```

**Fehler beheben:**

```bash
codex "Fix the TypeScript errors in src/components/"
```

**Code erklären:**

```bash
cat main.py | codex "Explain what this code does"
```

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Verbindungsfehler">
    - Prüfen Sie, ob `base_url` in config.toml exakt `https://api.lemondata.cc/v1` ist
    - Netzwerkverbindung überprüfen
    - Sicherstellen, dass keine Proxy-Interferenzen vorliegen
  </Accordion>

  <Accordion title="Authentifizierung fehlgeschlagen">
    - Prüfen Sie, ob `env_key = "OPENAI_API_KEY"` in `~/.codex/config.toml` vorhanden ist
    - Prüfen Sie, ob die Umgebungsvariable `OPENAI_API_KEY` gesetzt ist
    - Prüfen Sie, ob der Key mit `sk-` beginnt
    - Sicherstellen, dass der Key im LemonData-Dashboard aktiv ist
  </Accordion>

  <Accordion title="Modell nicht gefunden">
    - Prüfen Sie, ob der Modellname exakt übereinstimmt
    - Prüfen Sie die Modellverfügbarkeit unter [lemondata.cc/en/models](https://lemondata.cc/de/models)
  </Accordion>
</AccordionGroup>
