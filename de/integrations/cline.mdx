[Cline](https://docs.cline.bot/provider-config/openai-compatible) unterstützt OpenAI-kompatible Provider in den IDE-Einstellungen.

## TokenLab konfigurieren

1. Installiere **Cline** aus dem Erweiterungs-Marktplatz und öffne das Cline-Panel.
2. Klicke auf das Zahnrad und wähle bei **API Provider** die Option **OpenAI Compatible**.
3. Trage ein:

| Feld | Wert |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | Dein TokenLab API Key |
| Model ID | `kimi-k3` |

4. Klicke auf **Verify**.

Optional kannst du für `kimi-k3` das Eingabelimit `1048576`, die maximale Ausgabe `131072` sowie Bild- und Tool-/Computer-Use-Unterstützung aktivieren.

Beginne nach der Verifizierung mit einer schreibgeschützten Aufgabe. Bei 404 muss die Base URL mit `/v1` enden und darf `/chat/completions` nicht enthalten. Die Modell-ID lautet `kimi-k3`, nicht `kimi/kimi-k3`.
