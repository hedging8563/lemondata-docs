## Überblick

Dify funktioniert gut mit LemonData über seinen OpenAI-kompatiblen Model-Provider-Flow.

Für aktuelle Dify-Versionen ist der sicherste Weg in der Regel:
- Wählen Sie den integrierten **OpenAI**-Provider
- Legen Sie Ihren LemonData API key fest
- Legen Sie eine benutzerdefinierte Base-URL von `https://api.lemondata.cc/v1` fest

<Note>
Einige ältere Dify-Builds stellen dies als `OpenAI-API-compatible` statt als integrierten `OpenAI`-Provider mit einem Feld für eine benutzerdefinierte Base-URL bereit. Wenn Ihre Dify-UI anders aussieht, verwenden Sie den in dieser Version verfügbaren OpenAI-kompatiblen benutzerdefinierten Provider-Flow, der dem am nächsten kommt.
</Note>

## Voraussetzungen

- LemonData-Konto mit API-Zugriff
- Dify Cloud oder selbstgehostetes Dify

## Konfigurationsschritte

### Schritt 1: API key abrufen

1. Melden Sie sich im [LemonData Dashboard](https://lemondata.cc/dashboard) an
2. Öffnen Sie [API Keys](https://lemondata.cc/dashboard/api)
3. Erstellen oder kopieren Sie einen API key, der mit `sk-` beginnt

### Schritt 2: Den Provider konfigurieren

<Steps>
  <Step title="Model Providers öffnen">
    Gehen Sie in Dify zu **Settings** → **Model Providers**
  </Step>
  <Step title="OpenAI auswählen">
    Öffnen Sie die Einstellungen des **OpenAI**-Providers. Wenn Ihre Dify-Version hier keine benutzerdefinierte Base-URL anbietet, verwenden Sie stattdessen die von dieser Version bereitgestellte OpenAI-kompatible Option für benutzerdefinierte Provider.
  </Step>
  <Step title="LemonData-Einstellungen eingeben">
    Verwenden Sie diese Werte:

    | Field | Value |
    |-------|-------|
    | API Key | `sk-your-lemondata-key` |
    | API Base URL / Custom Base URL | `https://api.lemondata.cc/v1` |
  </Step>
  <Step title="Modelle hinzufügen">
    Fügen Sie die Modelle hinzu, die Sie verwenden möchten, zum Beispiel:
    - `gpt-5.4`
    - `gpt-5-mini`
    - `gpt-4o`
    - `claude-sonnet-4-6`
    - `claude-opus-4-6`
    - `gemini-2.5-flash`
    - `gemini-2.5-pro`
    - `deepseek-r1`
  </Step>
</Steps>

### Schritt 3: Verbindung testen

1. Wählen Sie ein Modell wie `gpt-5-mini` oder `gpt-4o`
2. Senden Sie einen Test-Prompt
3. Bestätigen Sie, dass Dify eine gültige Antwort erhält

## Embeddings für Wissensdatenbanken

Für RAG und die Indexierung von Wissensdatenbanken fügen Sie ein Embedding-Modell hinzu, zum Beispiel:
- `text-embedding-3-small`
- `text-embedding-3-large`

Legen Sie es dann in den entsprechenden Einstellungen der Wissensdatenbank oder Anwendung als Standard-Embedding-Modell fest.

## Empfohlene Modellrollen

| Use Case | Suggested Models |
|----------|------------------|
| Standard-Chat | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| Tiefes Schlussfolgern | `gpt-5.4`, `claude-opus-4-6`, `deepseek-r1` |
| Schnell/günstig | `gpt-5-mini`, `gemini-2.5-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## Best Practices

<AccordionGroup>
  <Accordion title="Mit dem integrierten OpenAI-Provider beginnen">
    In neueren Dify-Versionen ist der integrierte OpenAI-Provider mit einer benutzerdefinierten Base-URL in der Regel die sauberste Einrichtung für LemonData.
  </Accordion>

  <Accordion title="Günstigere Modelle für Iterationen verwenden">
    Verwenden Sie während der Iteration `gpt-5-mini` oder `gemini-2.5-flash` und stellen Sie umfangreichere Workflows erst dann auf leistungsstärkere Modelle um, wenn es nötig ist.
  </Accordion>

  <Accordion title="Beachten Sie, dass Dify in der Regel auf chat-completions ausgerichtet ist">
    Die meisten Dify-Flows verwenden OpenAI-kompatibles Chat-Verhalten. Wenn Sie Codex-spezifische Responses oder WebSocket-Verhalten benötigen, verwenden Sie statt Dify die dedizierten Codex-Integrationen.
  </Accordion>
</AccordionGroup>

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Verbindungsfehler">
    - Vergewissern Sie sich, dass die Base-URL exakt `https://api.lemondata.cc/v1` ist
    - Entfernen Sie nachgestellte Schrägstriche, falls Dify diese dupliziert
    - Bestätigen Sie, dass der Dify-Server LemonData über das öffentliche Internet erreichen kann
  </Accordion>

  <Accordion title="401 Unauthorized">
    - Überprüfen Sie den API key erneut
    - Bestätigen Sie, dass der key im LemonData-Dashboard aktiv ist
    - Stellen Sie sicher, dass der in Dify eingefügte Wert keine zusätzlichen Leerzeichen oder Zeilenumbrüche enthält
  </Accordion>

  <Accordion title="Modell nicht gefunden">
    - Überprüfen Sie den Modellnamen exakt
    - Fügen Sie den Modelleintrag erneut hinzu, falls die Provider-UI einen älteren Wert zwischengespeichert hat
    - Prüfen Sie die aktuelle Modellverfügbarkeit in der LemonData-Dokumentation oder im Dashboard
  </Accordion>
</AccordionGroup>
