## Überblick

Für LemonData ist der stabilste Standard im Vercel AI SDK der **OpenAI-kompatible Provider**.

Wenn Sie ausdrücklich **Responses-native** Funktionalität benötigen, können Sie zum OpenAI-Provider wechseln und dieselbe LemonData-Base-URL beibehalten.

## Empfohlener Standard: OpenAI-kompatibler Provider

```bash
npm install ai @ai-sdk/openai-compatible
```

```typescript
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

export const lemondata = createOpenAICompatible({
  name: 'lemondata',
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

## Text generieren

```typescript
import { generateText } from 'ai';
import { lemondata } from './lemondata';

const { text } = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});

console.log(text);
```

## Text streamen

```typescript
import { streamText } from 'ai';
import { lemondata } from './lemondata';

const result = await streamText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Write a short poem about coding.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## Tool-Aufruf

```typescript
import { generateText, tool } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const result = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'What is the weather in San Francisco?',
  tools: {
    weather: tool({
      description: 'Get weather in a location',
      parameters: z.object({
        location: z.string(),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72,
        condition: 'sunny',
      }),
    }),
  },
});

console.log(result.text);
```

## Strukturierte Ausgabe

```typescript
import { generateObject } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const { object } = await generateObject({
  model: lemondata.chatModel('gpt-5.4'),
  schema: z.object({
    name: z.string(),
    role: z.string(),
  }),
  prompt: 'Generate a fake developer profile.',
});

console.log(object);
```

## Wenn Sie ausdrücklich Responses-native Funktionalität benötigen

```bash
npm install ai @ai-sdk/openai
```

```typescript
import { createOpenAI } from '@ai-sdk/openai';

export const lemondataResponses = createOpenAI({
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```typescript
import { generateText } from 'ai';
import { lemondataResponses } from './lemondata-responses';

const { text } = await generateText({
  model: lemondataResponses('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});
```

<Note>
Verwenden Sie `@ai-sdk/openai-compatible` als sicheren Standard für Integrationen im Proxy-Stil. Wechseln Sie nur dann zu `@ai-sdk/openai`, wenn Sie ausdrücklich einen Provider-Pfad möchten, der auf `/v1/responses` basiert.
</Note>

## Best Practices

<AccordionGroup>
  <Accordion title="Bevorzugen Sie zunächst openai-compatible">
    Für Drittanbieter-Gateways und Proxy-Backends ist `@ai-sdk/openai-compatible` in der Regel der am wenigsten überraschende Ausgangspunkt.
  </Accordion>

  <Accordion title="Wechseln Sie nur bei Bedarf zu Responses">
    Wenn Sie ein Provider-Verhalten benötigen, das an `/v1/responses` gebunden ist, wechseln Sie das Provider-Paket gezielt, anstatt beide Muster in einem Client zu mischen.
  </Accordion>

  <Accordion title="Bewahren Sie Secrets auf dem Server auf">
    Stellen Sie Ihren LemonData API-Key niemals in clientseitigem Code bereit. Platzieren Sie das Provider-Setup in Server-Dateien oder API-Routen.
  </Accordion>
</AccordionGroup>
