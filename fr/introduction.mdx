## Qu’est-ce que LemonData ?

LemonData est une plateforme d’agrégation d’API d’IA qui vous donne un accès unifié à **plus de 300 modèles d’IA** de fournisseurs tels que OpenAI, Anthropic, Google, DeepSeek, Moonshot, MiniMax, et bien d’autres.

## Capacités prises en charge

| Capability | Description | Example Models |
|------------|-------------|----------------|
| **Chat & Reasoning** | Génération de texte, planification, outils | `gpt-5.4`, `claude-sonnet-4-6`, `deepseek-r1` |
| **Vision** | Compréhension d’image et chat multimodal | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |
| **Image Generation** | Texte-vers-image et édition d’image | `dall-e-3`, `flux-pro`, `midjourney` |
| **Video Generation** | Texte/image vers vidéo | `sora`, `runway`, `kling` |
| **Audio** | TTS et transcription | `gpt-4o-mini-tts`, `whisper-1`, `gpt-4o-transcribe` |
| **Embeddings** | Vectorisation de texte | `text-embedding-3-small`, `text-embedding-3-large` |
| **Music** | Génération de musique par IA | `suno` |
| **3D** | Génération d’assets 3D | `tripo3d` |

## Un bon point de départ par défaut

Pour les nouveaux projets, commencez avec le SDK OpenAI ainsi que l’**API Responses** :

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```
