## Vue d’ensemble

Dify fonctionne bien avec LemonData grâce à son flux de fournisseur de modèles compatible OpenAI.

Pour les versions actuelles de Dify, l’approche la plus sûre est généralement de :
- choisir le fournisseur intégré **OpenAI**
- définir votre clé API LemonData
- définir une URL de base personnalisée sur `https://api.lemondata.cc/v1`

<Note>
Certaines anciennes versions de Dify exposent cela sous la forme `OpenAI-API-compatible` au lieu du fournisseur intégré `OpenAI` avec un champ d’URL de base personnalisée. Si votre interface Dify est différente, utilisez le flux de fournisseur personnalisé compatible OpenAI le plus proche disponible dans cette version.
</Note>

## Prérequis

- Compte LemonData avec accès API
- Dify Cloud ou Dify auto-hébergé

## Étapes de configuration

### Étape 1 : Obtenir votre clé API

1. Connectez-vous au [tableau de bord LemonData](https://lemondata.cc/dashboard)
2. Ouvrez [API Keys](https://lemondata.cc/dashboard/api)
3. Créez ou copiez une clé API qui commence par `sk-`

### Étape 2 : Configurer le fournisseur

<Steps>
  <Step title="Ouvrir les fournisseurs de modèles">
    Dans Dify, accédez à **Settings** → **Model Providers**
  </Step>
  <Step title="Sélectionner OpenAI">
    Ouvrez les paramètres du fournisseur **OpenAI**. Si votre version de Dify ne propose pas d’URL de base personnalisée à cet endroit, utilisez à la place l’option de fournisseur personnalisé compatible OpenAI exposée par cette version.
  </Step>
  <Step title="Saisir les paramètres LemonData">
    Utilisez ces valeurs :

    | Field | Value |
    |-------|-------|
    | API Key | `sk-your-lemondata-key` |
    | API Base URL / Custom Base URL | `https://api.lemondata.cc/v1` |
  </Step>
  <Step title="Ajouter des modèles">
    Ajoutez les modèles que vous souhaitez utiliser, par exemple :
    - `gpt-5.4`
    - `gpt-5-mini`
    - `gpt-4o`
    - `claude-sonnet-4-6`
    - `claude-opus-4-6`
    - `gemini-2.5-flash`
    - `gemini-2.5-pro`
    - `deepseek-r1`
  </Step>
</Steps>

### Étape 3 : Tester la connexion

1. Choisissez un modèle tel que `gpt-5-mini` ou `gpt-4o`
2. Envoyez un prompt de test
3. Confirmez que Dify reçoit une réponse valide

## Embeddings pour les bases de connaissances

Pour le RAG et l’indexation des bases de connaissances, ajoutez un modèle d’embedding tel que :
- `text-embedding-3-small`
- `text-embedding-3-large`

Définissez-le ensuite comme modèle d’embedding par défaut dans les paramètres de la base de connaissances ou de l’application concernés.

## Rôles de modèles recommandés

| Use Case | Suggested Models |
|----------|------------------|
| Chat par défaut | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| Raisonnement approfondi | `gpt-5.4`, `claude-opus-4-6`, `deepseek-r1` |
| Rapide/économique | `gpt-5-mini`, `gemini-2.5-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## Bonnes pratiques

<AccordionGroup>
  <Accordion title="Commencer avec le fournisseur OpenAI intégré">
    Dans les versions plus récentes de Dify, le fournisseur OpenAI intégré avec une URL de base personnalisée constitue généralement la configuration la plus propre pour LemonData.
  </Accordion>

  <Accordion title="Utiliser des modèles moins coûteux pour l’itération">
    Utilisez `gpt-5-mini` ou `gemini-2.5-flash` pendant les itérations, puis basculez les workflows plus lourds vers des modèles plus puissants uniquement lorsque nécessaire.
  </Accordion>

  <Accordion title="Se rappeler que Dify est généralement orienté chat-completions">
    La plupart des flux Dify utilisent un comportement de chat compatible OpenAI. Si vous avez besoin de Responses spécifiques à Codex ou d’un comportement WebSocket, utilisez les intégrations Codex dédiées au lieu de Dify.
  </Accordion>
</AccordionGroup>

## Dépannage

<AccordionGroup>
  <Accordion title="Erreur de connexion">
    - Vérifiez que l’URL de base est exactement `https://api.lemondata.cc/v1`
    - Supprimez les slashs finaux si Dify les duplique
    - Confirmez que le serveur Dify peut atteindre LemonData via l’internet public
  </Accordion>

  <Accordion title="401 Unauthorized">
    - Vérifiez à nouveau la clé API
    - Confirmez que la clé est active dans le tableau de bord LemonData
    - Assurez-vous que la valeur collée dans Dify ne contient pas d’espaces ou de sauts de ligne supplémentaires
  </Accordion>

  <Accordion title="Modèle introuvable">
    - Vérifiez exactement le nom du modèle
    - Ajoutez à nouveau l’entrée du modèle si l’interface du fournisseur a mis en cache une ancienne valeur
    - Vérifiez la disponibilité actuelle du modèle dans la documentation LemonData ou dans le tableau de bord
  </Accordion>
</AccordionGroup>
