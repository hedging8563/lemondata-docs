## Vue d’ensemble

LemonData fonctionne avec les SDK OpenAI officiels en pointant le client vers `https://api.lemondata.cc/v1`.

Pour les nouveaux projets, privilégiez l’**API Responses**. Conservez **Chat Completions** uniquement lorsqu’un framework, un plugin ou un chemin de code legacy l’attend encore.

<Note>
Python, JavaScript et Go disposent de SDK OpenAI officiels. PHP fonctionne bien avec des clients communautaires compatibles OpenAI, mais ce n’est pas un SDK OpenAI officiel.
</Note>

## Configurer le client

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## Recommandé : API Responses

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

## Streaming avec Responses

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Outils / Appel de fonction

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## Compatibilité Chat Completions

Si votre framework ou votre plugin attend encore Chat Completions, LemonData prend également en charge le chemin standard compatible OpenAI :

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
Utilisez Chat Completions uniquement pour la compatibilité. Pour les nouvelles intégrations, privilégiez `client.responses.create(...)`.
</Warning>

## Dépannage

<AccordionGroup>
  <Accordion title="Erreur de connexion">
    - Vérifiez que l’URL de base est exactement `https://api.lemondata.cc/v1`
    - Vérifiez qu’il n’y a pas d’interférence d’un proxy ou de surcharge personnalisée du client HTTP
    - Assurez-vous que votre version du SDK est à jour avant de déboguer le comportement du provider
  </Accordion>

  <Accordion title="Échec de l’authentification">
    - Vérifiez que votre clé API commence par `sk-`
    - Vérifiez que la clé est active dans le dashboard LemonData
    - Confirmez que le SDK envoie bien `Authorization: Bearer ...`
  </Accordion>

  <Accordion title="Chemin API incorrect">
    - `responses.create(...)` envoie les requêtes vers `/v1/responses`
    - `chat.completions.create(...)` envoie les requêtes vers `/v1/chat/completions`
    - Si votre application ne prend en charge que Chat Completions aujourd’hui, conservez ce chemin de compatibilité
  </Accordion>
</AccordionGroup>
