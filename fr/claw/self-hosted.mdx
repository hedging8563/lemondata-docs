<Note>
**L'auto-hébergement** signifie que vous exécutez LemonClaw directement sur votre propre VPS ou machine. Vous ne payez que pour l'utilisation des modèles d'IA via votre solde LemonData — aucun frais d'instance.
</Note>

<Tip>
Vous préférez une configuration hébergée ? [Créez une instance Claw](/claw/introduction) pour obtenir le même runtime LemonClaw et la même WebUI sans avoir à gérer de serveurs vous-même.
</Tip>

## Installation Rapide

<CodeGroup>
```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```

```bash Non-interactif
LEMONDATA_API_KEY=sk-xxx curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```
</CodeGroup>

L'installateur vous demandera votre **Clé API LemonData**. Obtenez-en une depuis votre [Tableau de bord](https://lemondata.cc/dashboard).

## Ce qui est installé

<Steps>
  <Step title="Node.js 22+">
    Installé automatiquement s'il est manquant (via NodeSource sur Linux, Homebrew sur macOS)
  </Step>
  <Step title="LemonClaw">
    Package LemonClaw pré-configuré avec l'API LemonData
  </Step>
  <Step title="15 Modèles d'IA">
    Claude, GPT-5, Gemini, DeepSeek, et plus encore — prêts à l'emploi
  </Step>
  <Step title="Plugins IM">
    Plugins DingTalk, WeCom et QQ pré-installés
  </Step>
  <Step title="Service Système">
    Démarrage automatique au boot (systemd sur Linux, launchd sur macOS)
  </Step>
</Steps>

## Commandes de gestion

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user status lemonclaw    # Vérifier le statut
    journalctl --user -u lemonclaw -f    # Voir les logs
    systemctl --user restart lemonclaw   # Redémarrer
    systemctl --user stop lemonclaw      # Arrêter
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    tail -f ~/.lemonclaw/lemonclaw.log    # Voir les logs
    launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # Redémarrer
    launchctl stop cc.lemondata.lemonclaw  # Arrêter
    ```
  </Tab>
</Tabs>

## Configuration

Emplacement du fichier de configuration : `~/.lemonclaw/config.json`

Après modification, redémarrez le service pour appliquer les changements.

### Changer le modèle par défaut

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-opus-4-6"
      }
    }
  }
}
```

Préfixes de modèles disponibles :
- `lemondata-claude/` — Modèles Claude (API anthropic-messages)
- `lemondata-minimax/` — Modèles MiniMax (API anthropic-messages)
- `lemondata/` — Tous les autres modèles (API openai-completions)

## Mise à jour

```bash
# Relancez l'installateur pour mettre à jour vers la dernière version
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
# Puis redémarrez le service
systemctl --user restart lemonclaw  # Linux
# ou
launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # macOS
```

## Désinstallation

```bash
# Arrêter et désactiver le service
systemctl --user stop lemonclaw && systemctl --user disable lemonclaw  # Linux
launchctl unload ~/Library/LaunchAgents/cc.lemondata.lemonclaw.plist  # macOS

# Supprimer LemonClaw
rm -rf ~/.lemonclaw
```

| **Support** | Communauté | Prioritaire |
