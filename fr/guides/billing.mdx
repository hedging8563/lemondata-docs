## Vue d’ensemble

LemonData utilise une **tarification à l’usage**. Vous ne payez que ce que vous utilisez, sans abonnement ni engagement minimum.

## Fonctionnement de la facturation

1. **Ajoutez des crédits** à votre compte
2. **Utilisez l’API** - les coûts sont déduits par requête
3. **Surveillez l’utilisation** dans votre tableau de bord
4. **Rechargez** lorsque votre solde est faible

### Facturation des tâches async (Vidéo/Musique/3D)

<Warning>
  **Important** : les tâches de génération de vidéo, de musique et de 3D sont **facturées au moment de la soumission**, et non à l’achèvement.
</Warning>

Pour les tâches de génération async (vidéo, musique, modèles 3D) :

1. **La facturation a lieu immédiatement** lorsque vous soumettez la tâche
2. Vous recevez un `task_id` pour interroger le statut
3. **Aucun remboursement automatique** si la tâche échoue

Cela s’explique par le fait que les fournisseurs en amont nous facturent lorsque la tâche est soumise, quel qu’en soit le résultat. Si vous rencontrez des échecs de tâche, veuillez contacter support@lemondata.cc pour obtenir de l’aide.

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

task_id = response.json()["task_id"]
# Poll for status...
```

## Comptage des tokens

Les tokens sont les unités de base du traitement du texte :

- ~4 caractères = 1 token (anglais)
- ~1-2 caractères = 1 token (chinois)
- 1 image = varie selon la taille et le niveau de détail

### Estimation des tokens

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## Alertes de solde faible

Configurez des alertes lorsque votre solde baisse :

1. Accédez à **Dashboard → Settings → Notifications**
2. Définissez votre seuil
3. Recevez des notifications par email

## Ajout de crédits

### Moyens de paiement

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### Étapes

1. Connectez-vous au [Dashboard](https://lemondata.cc/dashboard)
2. Cliquez sur **Add Credits**
3. Sélectionnez le montant et le moyen de paiement
4. Finalisez le paiement

Les crédits sont ajoutés instantanément après la confirmation du paiement.

## Limites des clés API

Vous pouvez définir des limites de dépenses sur des clés API individuelles :

1. Accédez à **Dashboard → API Keys**
2. Cliquez sur une clé pour la modifier
3. Définissez **Usage Limit**

Lorsque la limite est atteinte, les requêtes avec cette clé renverront `402 Payment Required`.

## Factures

Pour les comptes professionnels, des factures sont disponibles :

1. Accédez à **Dashboard → Billing**
2. Consultez l’historique des transactions
3. Téléchargez les factures au format PDF
