## Vue d’ensemble

LemonData fournit un accès à des modèles de génération vidéo provenant de 11 fournisseurs via une API unifiée unique. La génération vidéo est **asynchrone** — vous soumettez une requête, recevez un ID de tâche et un `poll_url`, puis interrogez ce dernier pour obtenir le résultat.

<Info>
La liste des modèles est mise à jour fréquemment. Pour consulter les derniers modèles disponibles et leur tarification, visitez la [page des modèles](https://lemondata.cc/fr/models) ou utilisez la [Models API](/api-reference/models/list-models).
</Info>

### Flux de travail asynchrone

```mermaid
sequenceDiagram
    participant Client
    participant LemonData
    participant Provider

    Client->>LemonData: POST /v1/videos/generations
    LemonData->>Provider: Forward request
    Provider-->>LemonData: task_id + pending
    LemonData-->>Client: { task_id, poll_url, status: "pending" }

    loop Poll every 5-10s
        Client->>LemonData: GET poll_url
        LemonData->>Provider: Query status
        Provider-->>LemonData: Status update
        LemonData-->>Client: { status, video_url? }
    end
```

<CodeGroup>

```python Python
import requests
import time

API_KEY = "sk-your-api-key"
BASE = "https://api.lemondata.cc/v1"
headers = {"Authorization": f"Bearer {API_KEY}"}

# Step 1: Submit generation request
resp = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
create_data = resp.json()
task_id = create_data["task_id"]
poll_url = create_data["poll_url"]

# Step 2: Poll for result
while True:
    status = requests.get(f"https://api.lemondata.cc{poll_url}", headers=headers).json()
    if status["status"] in ("completed", "succeeded"):
        print(f"Video URL: {status['video_url']}")
        break
    elif status["status"] == "failed":
        print(f"Failed: {status.get('error')}")
        break
    time.sleep(10)
```

```javascript JavaScript
const API_KEY = 'sk-your-api-key';
const BASE = 'https://api.lemondata.cc/v1';
const headers = { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' };

// Step 1: Submit
const { task_id, poll_url } = await fetch(`${BASE}/videos/generations`, {
  method: 'POST', headers,
  body: JSON.stringify({
    model: 'sora-2',
    prompt: 'A calm cinematic shot of a cat walking through a sunlit garden.',
    operation: 'text-to-video',
    duration: 4,
    aspect_ratio: '16:9'
  })
}).then(r => r.json());

// Step 2: Poll
const poll = setInterval(async () => {
  const status = await fetch(`https://api.lemondata.cc${poll_url}`, { headers }).then(r => r.json());
  if (['completed', 'succeeded'].includes(status.status)) {
    console.log('Video URL:', status.video_url);
    clearInterval(poll);
  } else if (status.status === 'failed') {
    console.error('Failed:', status.error);
    clearInterval(poll);
  }
}, 10000);
```

### Définitions des capacités

- **T2V (Text-to-Video)** : Générer une vidéo à partir d’un prompt textuel
- **I2V (Image-to-Video)** : Animer une image statique en vidéo. Pour la compatibilité la plus large, fournissez une `image_url` publique.
- **Keyframe** : Contrôler les images de début et de fin avec `start_image` + `end_image`
- **Extension** : Étendre la durée d’une vidéo existante
- **Editing** : Modifier des aspects spécifiques d’une vidéo existante

## Exemples d’utilisation

### Text-to-Video (T2V)

Le cas d’usage le plus courant. Tous les modèles le prennent en charge.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
```

### Image-to-Video (I2V)

Animez une image statique. Pour la compatibilité la plus large entre les modèles vidéo, hébergez l’image source et transmettez `image_url`.

```python
# Using image URL
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/portrait.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)

```

### Contrôle par keyframe (image de début + image de fin)

Contrôlez à la fois la première et la dernière image pour des transitions précises. Actuellement pris en charge par Seedance 2.0.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night, city lights gradually turning on",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/city-day.jpg",
        "end_image": "https://example.com/city-night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```

### Extension vidéo

Étendez la durée d’une vidéo existante. Utilisez des modèles disposant de la capacité d’extension.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "kling-video-extend",
        "prompt": "Continue the scene naturally",
        "image_url": "https://example.com/last-frame.jpg"
    }
)
```

## Référence des paramètres

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | ID du modèle (par défaut : `sora-2`) |
| `prompt` | string | **Obligatoire.** Description textuelle de la vidéo |
| `image_url` | string | URL de l’image de départ (pour I2V) |
| `image` | string | Image inline sous forme de data URL. Pris en charge par les modèles compatibles, mais `image_url` offre la compatibilité la plus large. |
| `duration` | integer | Durée de la vidéo en secondes (1-60, selon le modèle) |
| `aspect_ratio` | string | `16:9`, `9:16`, `1:1`, etc. |
| `resolution` | string | `1080p`, `720p`, `4k` |
| `fps` | integer | Images par seconde (1-120) |
| `negative_prompt` | string | Ce qu’il faut éviter dans la génération |
| `seed` | integer | Seed aléatoire pour la reproductibilité |
| `cfg_scale` | number | Échelle de guidage (0-20) |
| `motion_strength` | number | Intensité du mouvement (0-1) |
| `start_image` | string | URL du keyframe de départ |
| `end_image` | string | URL du keyframe de fin |

<Warning>
Tous les paramètres ne sont pas pris en charge par chaque modèle. Les paramètres non pris en charge sont ignorés silencieusement. Consultez la documentation du modèle pour connaître les paramètres pris en charge.
</Warning>

## Facturation

La génération vidéo utilise une **tarification fixe par génération**. Le montant vous est facturé une seule fois lors de la soumission de la tâche, quelle que soit la durée de la vidéo. Si la génération échoue, les frais sont automatiquement remboursés.

Consultez la tarification actuelle sur la [page des modèles](https://lemondata.cc/fr/models) ou via la [Pricing API](/api-reference/pricing/get-pricing).
