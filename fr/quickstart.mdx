## Étape 1 : Obtenez votre clé API

<Steps>
  <Step title="Créer un compte">
    Inscrivez-vous sur [lemondata.cc](https://lemondata.cc) en utilisant votre e-mail, Gmail ou votre compte GitHub.
  </Step>
  <Step title="Ajouter des crédits">
    Ouvrez le tableau de bord et ajoutez des crédits à votre compte. LemonData utilise une tarification à l’usage sans engagement minimum.
  </Step>
  <Step title="Créer une clé API">
    Accédez à **Dashboard → API Keys** et créez une nouvelle clé. Copiez-la en lieu sûr, car elle n’est affichée qu’une seule fois.
  </Step>
</Steps>

<Warning>
Gardez votre clé API en sécurité. Ne l’exposez jamais dans du code côté client ou des dépôts publics.
</Warning>

## Étape 3 : Effectuez votre première requête

Pour les nouveaux projets, commencez par l’**API Responses**.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
Si votre framework ou outil attend encore Chat Completions, LemonData prend également en charge `POST /v1/chat/completions`. Pour les nouvelles intégrations, privilégiez `POST /v1/responses`.
</Note>

## Essayez différents modèles

LemonData prend en charge plus de 300 modèles. Modifiez uniquement le champ `model` :

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## Activer le streaming

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
