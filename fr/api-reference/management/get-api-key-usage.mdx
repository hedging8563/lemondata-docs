description: "Retourne les détails d'utilisation paginés d'une clé API utilisateur."
---

## Aperçu

Cet endpoint retourne les détails d'utilisation au niveau de la clé avec des filtres sur le nom de modèle demandé (`model`), le fournisseur de modèle public, `scene` et `accessChannel`.

## Remarques

- La réponse inclut uniquement des champs publics de facturation.
- Le routage interne et les métadonnées des canaux physiques sont volontairement masqués.
