---

## Aperçu

Retourne les clés API utilisateur de l'organisation associée au jeton de gestion actuel.

## Remarques

- Les clés gérées par le système, comme celles de Playground ou de Claw, sont exclues.
- Les champs monétaires de la réponse sont renvoyés à la fois en USD et en affichage RMB : `limit_amount` / `limit_amount_cny`, `used_amount` / `used_amount_cny`.
- `exchange_rate` indique le taux USD→CNY utilisé pour les champs d’affichage RMB.

## Exemple

<RequestExample>
```bash cURL
curl -X GET "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>
