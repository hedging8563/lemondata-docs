## Aperçu

Crée une nouvelle clé API `type=user` dans l'organisation associée au jeton de gestion actuel.

## Remarques

- La clé complète n'est affichée qu'une seule fois dans la réponse.

## Demande / Réponse

Utilisez le panneau OpenAPI interactif ci-dessus pour le schéma exact.
