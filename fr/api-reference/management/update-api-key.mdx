## Aperçu

Utilisez cet endpoint pour mettre à jour le nom, la limite d'usage, les modèles autorisés, l'expiration ou le statut d'une clé API utilisateur existante.

## Remarques

- La suppression définitive n'est pas prise en charge dans API de gestion v1.

## Demande / Réponse

Utilisez le panneau OpenAPI interactif ci-dessus pour le schéma exact.
