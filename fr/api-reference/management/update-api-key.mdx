## Vue d’ensemble

Utilisez cet endpoint pour mettre à jour le nom, la limite d’usage, les modèles autorisés, l’expiration ou le statut d’une API Key existante.

## Corps de la requête

Au moins un champ doit être fourni dans la requête PATCH.

| Champ | Type | Valeurs par défaut / limites | Notes |
|-------|------|------------------|-------|
| status | enum | - | active, inactive, revoked |
| name | string | longueur 1-50 | Nom affiché mis à jour |
| limitAmount | number \| null | min 0, max 100000 | null = unlimited, 0 = zero quota, positive = USD cap |
| models | string[] | - | Liste d’autorisation des modèles logiques mise à jour |
| expiresAt | string \| null | datetime RFC3339 | null efface la date d’expiration |

## Notes

- Le hard delete n’est volontairement pas pris en charge dans Management API v1.
- `revoked` est généralement considéré comme un état terminal ; si vous avez de nouveau besoin d’une clé, il vaut mieux en créer une nouvelle.

## Exemple

<RequestExample>
```bash cURL
curl -X PATCH "https://api.lemondata.cc/v1/management/api-keys/key_abc123def456" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "inactive",
    "limitAmount": 0
  }'
```
</RequestExample>
