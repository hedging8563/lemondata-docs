---

## Vue d’ensemble

Utilisez cet endpoint pour un polling async unifié entre différents types de tâches tels que la génération de vidéo, d’image, de musique et de 3D.

<Info>
Si une réponse de création inclut `poll_url`, appelez ce chemin exact. Pour les workflows async plus récents, `poll_url` peut pointer vers `/v1/tasks/{id}`.
</Info>

## Paramètres de chemin

<ParamField path="id" type="string" required>
  L’ID de tâche renvoyé par la requête de création.
</ParamField>

## Réponse

<ResponseField name="id" type="string">
  Identifiant de la tâche.
</ResponseField>

<ResponseField name="status" type="string">
  Statut de la tâche tel que `pending`, `processing`, `completed` ou `failed`.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL de l’asset de résultat lorsque la tâche est terminée et produit une vidéo.
</ResponseField>

<ResponseField name="error" type="string">
  Message d’erreur lorsque la tâche échoue.
</ResponseField>

## Exemples

```bash cURL
curl "https://api.lemondata.cc/v1/tasks/video_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

poll_url = "/v1/tasks/video_abc123"
response = requests.get(
    f"https://api.lemondata.cc{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/video_abc123';
const response = await fetch(`https://api.lemondata.cc${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
