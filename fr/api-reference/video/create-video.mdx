## Vue d’ensemble

La génération de vidéo est asynchrone. Vous soumettez une requête, recevez un ID de tâche et une `poll_url`, puis interrogez régulièrement pour obtenir le résultat.

<Info>
Pour un comportement de polling le plus fiable possible, suivez exactement la `poll_url` renvoyée par la requête de création.
</Info>

<Warning>
Audio output is model-dependent. In LemonData, Veo 3 family requests default to audio-on when `output_audio` is omitted. When a model supports audio control, use `output_audio` to explicitly toggle it. The camelCase alias `outputAudio` is also accepted for compatibility.
</Warning>


## Corps de la requête

<ParamField body="model" type="string" default="sora-2">
  ID du modèle vidéo. La valeur par défaut de l’API est `sora-2`. Consultez le [Guide de génération vidéo](/guides/video-generation) pour la matrice actuelle des modèles et les capacités prises en charge.
</ParamField>

<ParamField body="prompt" type="string" required>
  Description textuelle de la vidéo à générer.
</ParamField>

<ParamField body="image_url" type="string">
  URL publiquement accessible de l’image de départ pour la génération image-vers-vidéo (I2V). Pour une compatibilité optimale entre modèles, privilégiez `image_url`.
</ParamField>

<ParamField body="image" type="string">
  Image inline sous forme d’URL de données (par exemple, `data:image/jpeg;base64,...`). Pris en charge par les modèles compatibles, mais `image_url` offre la compatibilité la plus large entre les modèles vidéo.
</ParamField>

<ParamField body="duration" type="integer">
  Durée de la vidéo en secondes (dépend du modèle).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Ratio d’aspect (par ex., `16:9`, `9:16`, `1:1`).
</ParamField>

<ParamField body="resolution" type="string">
  Résolution vidéo (par ex., `1080p`, `720p`).
</ParamField>

<ParamField body="output_audio" type="boolean">
  Model-dependent audio output toggle. In LemonData, Veo 3 family requests default to `true` when this field is omitted. Other video models follow their governed default behavior. The camelCase alias `outputAudio` is accepted for compatibility.
</ParamField>

<ParamField body="fps" type="integer">
  Images par seconde (1-120).
</ParamField>

<ParamField body="negative_prompt" type="string">
  Ce qu’il faut éviter dans la génération vidéo.
</ParamField>

<ParamField body="seed" type="integer">
  Graine aléatoire pour une génération reproductible.
</ParamField>

<ParamField body="cfg_scale" type="number">
  Échelle de guidance sans classifieur (0-20).
</ParamField>

<ParamField body="motion_strength" type="number">
  Intensité du mouvement (0-1).
</ParamField>

<ParamField body="start_image" type="string">
  URL de l’image de l’image-clé de départ.
</ParamField>

<ParamField body="end_image" type="string">
  URL de l’image de l’image-clé de fin.
</ParamField>

<ParamField body="user" type="string">
  Un identifiant unique pour l’utilisateur final.
</ParamField>

## Réponse

<ResponseField name="task_id" type="string">
  Identifiant unique de tâche pour le polling.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling recommandée pour cette tâche. Utilisez ce chemin exact lors de la vérification du statut.
</ResponseField>

<ResponseField name="status" type="string">
  Statut initial : `pending`.
</ResponseField>

<ResponseField name="model" type="string">
  Modèle utilisé.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",

        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }

data = response.json()

print(f"Poll URL: {data['poll_url']}")
print(f"Task ID: {task_id}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":    "sora-2",
        "prompt":   "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/videos/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Poll URL: %s\n", result["poll_url"])
    fmt.Printf("Task ID: %s\n", result["task_id"])
}
```

## Image vers vidéo

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/image.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)
```

## Contrôle par images-clés

Utilisez `start_image` et `end_image` pour contrôler les premières et dernières images (pris en charge par Vidu Q2 Pro) :

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/day.jpg",
        "end_image": "https://example.com/night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```
