---
title: "Lister les ressources matérielles"
openapi: "GET /v1/videos/assets"
description: "Liste les ressources matérielles Seedance appartenant à l'organisation actuelle."
---

Liste les ressources matérielles appartenant à l'organisation authentifiée. Filtrez par `library_type`, `group_id` ou `status` lorsque vous devez trouver des ressources pour un flux de travail de génération spécifique.

Utilisez uniquement les ressources dont le `status` est `ACTIVE`. Lors de la création de vidéos, utilisez l’`id` de la ressource matérielle TokenLab renvoyée.

## Exemple de requête

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=seedance_group_virtual_123&page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Exemple de réponse

```json
{
  "assets": [
    {
      "id": "seedance_asset_123",
      "object": "seedance.material_asset",
      "group_id": "seedance_group_virtual_123",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
