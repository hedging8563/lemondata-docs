---
title: "Lister l'historique de vérification de personne réelle"
openapi: "GET /v1/videos/assets/visual-validation-sessions"
description: "Liste les sessions de vérification de matériel de personne réelle pour l'organisation actuelle."
---

Listez les sessions de vérification précédentes pour examen, support client et rapprochement. Cet historique est conservé à long terme, mais il ne remplace pas l'étape de liaison (bind) à courte durée de vie : une vérification réussie doit toujours être liée immédiatement dans la fenêtre de 120 secondes.

La réponse inclut uniquement les IDs TokenLab et n'inclut pas les données d'identification. Une fois la liaison réussie, `group_id` est l'ID de groupe de matériel TokenLab utilisé pour les téléchargements `liveness_face`.

## Exemple de requête

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions?page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
