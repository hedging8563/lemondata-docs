## Aperçu

Ces points de terminaison s’adressent aux équipes qui utilisent déjà la structure de tâche Seedance de style Volc. L’authentification utilise votre clé API TokenLab Bearer. L’ID de tâche retourné commence par `cgt-`; interrogez le statut jusqu’à ce que `status` devienne `succeeded`, `failed`, `cancelled` ou `expired`.

Vous pouvez aussi appeler le dispatcher Action avec `CreateContentsGenerationsTasks`, `GetContentsGenerationsTask`, `ListContentsGenerationsTasks` ou `DeleteContentsGenerationsTasks`. `Action` et `Version` ne tiennent pas compte de la casse. `Version` peut être omis; s’il est présent, il doit être `2024-01-01`.

`callback_url` n’est pas accepté dans cette version. Interrogez le statut de la tâche afin de ne pas manquer silencieusement les événements de fin.

Voir aussi [Modèles vidéo Seedance 2.0](/fr/guides/seedance-2-video) et [Génération vidéo](/fr/guides/video-generation).

## Règles de contenu

- Utilisez `type=text` pour le texte du prompt.
- `type=image_url` sans `role` est traité comme le premier frame; vous pouvez aussi définir `role=first_frame`.
- Utilisez `role=last_frame` uniquement avec un premier frame.
- Utilisez `role=reference_image`, `reference_video` ou `reference_audio` pour les médias de référence.
- Ne mélangez pas les entrées premier/dernier frame avec des médias de référence dans une même requête.

## Notes sur les paramètres

- `ratio` accepte `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9` ou `adaptive`.
- `generate_audio` vaut `true` par défaut; mettez `false` pour une vidéo muette.
- `service_tier=default` est accepté. Les tâches compatibles Seedance 2.0 rejettent `service_tier=flex`, `frames` et `camera_fixed=true`.
- Quand le modèle sélectionné le prend en charge, `tools` peut contenir des objets comme `{ "type": "web_search" }`. Les entrées tool mal formées sont rejetées au lieu d’être ignorées.

## Exemple

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [
      {"type": "text", "text": "A cinematic forest at sunset"},
      {"type": "image_url", "role": "reference_image", "image_url": {"url": "https://example.com/ref.png"}}
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p",
    "generate_audio": true
  }'
```
