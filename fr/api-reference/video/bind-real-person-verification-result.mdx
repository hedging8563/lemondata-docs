---
title: "Lier le résultat de la vérification de personne réelle"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "Lie un résultat de vérification de matériel de personne réelle réussi à un groupe de matériel TokenLab."
---

Lie le résultat de la vérification réussie et crée le mappage du groupe de matériel de personne réelle TokenLab. Utilisez le `session_id` et le `verification_token` provenant de la redirection de rappel TokenLab.

TokenLab vérifie que la session appartient à la même organisation, n'a pas expiré et est liée au même service de matériel utilisé par la session de vérification. La réponse renvoie uniquement un `group_id` TokenLab ; utilisez-le lors de la création d'actifs matériels `liveness_face`.

## Exemple de requête

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## Exemple de réponse

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "group-20260720123456-real1",
  "material_group": {
    "id": "group-20260720123456-real1",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
