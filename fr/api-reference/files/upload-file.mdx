## Aperçu

Ce point de terminaison fait partie de l'API Batch compatible avec OpenAI de LemonData. Les travaux en lot utilisent des fichiers JSONL téléchargés, s'exécutent de manière asynchrone et peuvent renvoyer des fichiers de sortie/d'erreur plus tard.

## Remarques

- Les fichiers d'entrée en lot doivent utiliser `purpose=batch`.
- `completion_window` est actuellement `24h`.
- L'ordre de sortie n'est pas garanti ; faites toujours correspondre par `custom_id`.
- Le streaming n'est pas pris en charge à l'intérieur des éléments de lot.

## Demande / Réponse

Utilisez le panneau OpenAPI interactif ci-dessus pour le schéma exact.

## Conseils opérationnels

- Utilisez `custom_id` pour la réconciliation idempotente en aval.
- Attendez-vous à ce que `output_file_id` et `error_file_id` ne soient disponibles qu'après que le travailleur finalise le lot.
- La tarification des lots peut différer de la tarification synchrone car les règles de remise `isBatchRequest=true` s'appliquent.
## Anthropic Files API Mode

This same `/v1/files` route also supports the Anthropic Files API path.

- Add `anthropic-beta: files-api-2025-04-14` to switch the route into Anthropic mode.
- In Anthropic mode, upload the original file directly and do not send `purpose=batch`.
- The returned `file_id` is bound to the same official Anthropic channel/workspace and should be reused from `/v1/messages` requests.
- If you plan to reference the uploaded file from Anthropic message content, keep using Anthropic-native headers (`x-api-key`, `anthropic-version`, and the beta header when required).
