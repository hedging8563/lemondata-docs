## Genel bakış

Bu endpoint’ler, Volc tarzı Seedance görev şeklini zaten kullanan ekipler içindir. Kimlik doğrulama TokenLab Bearer API key ile yapılır. Dönen görev ID’si `cgt-` ile başlar; `status` `succeeded`, `failed`, `cancelled` veya `expired` olana kadar durumu sorgulayın.

Ayrıca bkz. [Seedance 2.0 Video Modelleri](/tr/guides/seedance-2-video) ve [Video Oluşturma](/tr/guides/video-generation).

## Yanıt şekli

Görev yanıtı `queued`, `running`, `succeeded`, `failed`, `cancelled` veya `expired` kullanır. Başarılı görevler `content.video_url` döndürür; varsa `content.last_frame_url`, resmî üretim alanları ve `usage` da yer alır. `error` yalnızca başarısızlıkta eklenir. `progress`, `return_last_frame`, `watermark`, `priority` veya `camera_fixed` gibi TokenLab uzantıları eklenmez.

## Örnek

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
