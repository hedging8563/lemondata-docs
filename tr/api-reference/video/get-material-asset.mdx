---
title: "Materyal Varlığını Getir"
openapi: "GET /v1/videos/assets/{assetId}"
description: "TokenLab materyal varlık kimliğini (ID) kullanarak bir Seedance materyal varlığını getirir."
---

Bir materyal varlığını getirin ve işleme durumunu inceleyin. Varlık, yalnızca `ready` değeri `true` ve `status` değeri `ACTIVE` olduğunda video oluşturma için kullanılabilir.

Video oluşturma işlemi `Seedance material asset not found or not accessible` hatası döndürürse, materyal `group_id` değerini değil, bu materyal varlığının `id` değerini gönderdiğinizden emin olun.

## Örnek İstek

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Örnek Yanıt

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
