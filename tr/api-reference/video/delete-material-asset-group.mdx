---
title: "Materyal Varlık Grubunu Sil"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "Mevcut organizasyona ait bir Seedance materyal grubunu siler."
---

Bir materyal grubunu ve içindeki TokenLab materyal varlıklarını silin. Bu işlem geri alınamaz.

Eğer TokenLab materyal kütüphanesi, mevcut yetkilendirme durumu izin vermediği için silme işlemini tamamlayamazsa, TokenLab nötr bir materyal kütüphanesi hatası döndürür. Silme işleminden sonra, grup ve içindeki varlıklar video oluşturma sürecinde artık kullanılamaz.

## Örnek İstek

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Örnek Yanıt

```json
{
  "deleted": true,
  "id": "seedance_group_virtual_123"
}
```
