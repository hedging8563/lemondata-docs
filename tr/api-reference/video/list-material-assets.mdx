---
title: "Materyal Varlıklarını Listele"
openapi: "GET /v1/videos/assets"
description: "Mevcut organizasyona ait Seedance materyal varlıklarını listeler."
---

Kimliği doğrulanmış organizasyona ait materyal varlıklarını listeleyin. Belirli bir üretim iş akışı için varlıkları bulmanız gerektiğinde `library_type`, `group_id` veya `status` parametrelerine göre filtreleme yapın.

Yalnızca `status` değeri `ACTIVE` olan varlıkları kullanın. `asset_url` değerini uzun vadeli bir materyal adresi olarak değil, yükleme kaynağı veya inceleme bilgisi olarak değerlendirin.

## Örnek İstek

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=seedance_group_virtual_123&page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Örnek Yanıt

```json
{
  "assets": [
    {
      "id": "seedance_asset_123",
      "object": "seedance.material_asset",
      "group_id": "seedance_group_virtual_123",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
