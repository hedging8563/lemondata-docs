---
title: "Materyal Varlığını Güncelle"
openapi: "PUT /v1/videos/assets/{assetId}"
description: "Mevcut organizasyona ait bir Seedance materyal varlığını günceller."
---

Materyal adını veya meta verilerini güncelleyin. Kaynak URL ve varlık türü oluşturulduktan sonra sabittir; kaynak dosya değiştiğinde yeni bir varlık oluşturun.

## Örnek İstek

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"}}'
```

## Örnek Yanıt

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view approved",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
