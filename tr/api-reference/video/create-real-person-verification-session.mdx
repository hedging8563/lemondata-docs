openapi: "POST /v1/videos/assets/visual-validation-sessions"
description: "Bir TokenLab gerçek kişi materyal doğrulama H5 oturumu oluşturur."
---

Kısa ömürlü bir doğrulama oturumu oluşturun ve kullanıcınızı döndürülen H5 bağlantısına yönlendirin. TokenLab yalnızca nötr alanları döndürür: `session_id`, `h5_link`, `callback_url`, `expires_in` ve `language`.

Oturum ve H5 bağlantısı 120 saniye sonra sona erer. Bağlama tokenı yalnızca TokenLab callback yönlendirmesiyle sağlanır. H5 akışı tamamlandığında, TokenLab sizi orijinal `callback_url` adresinize şu sorgu parametreleriyle yönlendirir:

| Parametre | Anlamı |
|-----------|---------|
| `session_id` | TokenLab doğrulama oturumu kimliği. |
| `verification_token` | Sonucu bağlamak için kullanılan opak token. |
| `verification_status` | `succeeded` veya `failed`. |
| `result_code` | Uygulama mantığınız için sonuç kodu. |

Eğer `verification_status` değeri `succeeded` ise, [Bind Real-Person Verification Result](/tr/api-reference/video/bind-real-person-verification-result) uç noktasını çağırın. Akışı ürününüze entegre etmeden önce callback işlemlerini doğrulamak için [test konsolu](https://tokenlab.sh/dashboard/seedance-assets) kullanılabilir.

## Örnek İstek

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"callback_url":"https://yourapp.example.com/seedance/callback","language":"en"}'
```

## Örnek Yanıt

```json
{
  "object": "seedance.visual_validation_session",
  "session_id": "svv_abc123",
  "h5_link": "https://verify.example.com/h5?lng=en",
  "callback_url": "https://yourapp.example.com/seedance/callback",
  "expires_in": 120,
  "language": "en"
}
```
