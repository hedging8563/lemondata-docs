## Genel bakış

Bu endpoint’ler, Volc tarzı Seedance görev şeklini zaten kullanan ekipler içindir. Kimlik doğrulama TokenLab Bearer API key ile yapılır. Dönen görev ID’si `cgt-` ile başlar; `status` `succeeded`, `failed`, `cancelled` veya `expired` olana kadar durumu sorgulayın.

Ayrıca bkz. [Seedance 2.0 Video Modelleri](/tr/guides/seedance-2-video) ve [Video Oluşturma](/tr/guides/video-generation).

## Yanıt şekli

Liste yanıtı `items` ve `total` döndürür. Desteklenen filtreler `filter.status`, `filter.task_ids`, `filter.model` ve `filter.service_tier`; sayfalama için `page_num` ve `page_size` kullanılır.

## Örnek

```bash
curl "https://api.tokenlab.sh/api/v3/contents/generations/tasks?page_num=1&page_size=20&filter.status=succeeded" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
