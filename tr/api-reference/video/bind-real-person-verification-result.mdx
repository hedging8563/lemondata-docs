---
title: "Bind Real-Person Verification Result"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "Binds a successful real-person verification result to a TokenLab material group."
---

Binds a successful real-person material verification result and creates the TokenLab real-person material group mapping for the authenticated organization.

Pass the `session_id` and `verification_token` returned by [Create Real-Person Verification Session](/api-reference/video/create-real-person-verification-session) or by the TokenLab callback redirect. TokenLab verifies that the session belongs to the same organization, has not expired, and matches the stored verification record.

The response returns `group_id` and `material_group`. TokenLab does not expose underlying material-library IDs. Store `group_id` and pass it when creating `liveness_face` material assets.
