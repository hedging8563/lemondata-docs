---
title: "Gerçek Kişi Doğrulama Sonucunu Bağlama"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "Başarılı bir gerçek kişi materyal doğrulama sonucunu bir TokenLab materyal grubuna bağlar."
---

Başarılı doğrulama sonucunu bağlayın ve TokenLab gerçek kişi materyal grubu eşlemesini oluşturun. Doğrulama oturumundan veya TokenLab geri çağırma (callback) yönlendirmesinden elde edilen `session_id` ve `verification_token` değerlerini kullanın.

TokenLab, oturumun aynı organizasyona ait olduğunu ve süresinin dolmadığını doğrular. Yanıt yalnızca bir TokenLab `group_id` değeri döndürür; bu değeri `liveness_face` materyal varlıklarını oluştururken kullanın.

## Örnek İstek

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## Örnek Yanıt

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "group-20260720123456-real1",
  "material_group": {
    "id": "group-20260720123456-real1",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
