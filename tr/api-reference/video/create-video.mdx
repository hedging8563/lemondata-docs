## Genel Bakış

Video oluşturma asenkron olarak çalışır. Bir istek gönderirsiniz, bir görev kimliği ve `poll_url` alırsınız, ardından sonuç için polling yaparsınız.

<Info>
En güvenilir polling davranışı için, oluşturma isteği tarafından döndürülen tam `poll_url` değerini izleyin.
</Info>

<Warning>
Audio output is model-dependent. In LemonData, Veo 3 family requests default to audio-on when `output_audio` is omitted. When a model supports audio control, use `output_audio` to explicitly toggle it. The camelCase alias `outputAudio` is also accepted for compatibility.
</Warning>


## İstek Gövdesi

<ParamField body="model" type="string" default="sora-2">
  Video model kimliği. API varsayılanı `sora-2`'dir. Güncel model matrisi ve desteklenen yetenekler için [Video Oluşturma Kılavuzu](/guides/video-generation) sayfasına bakın.
</ParamField>

<ParamField body="prompt" type="string" required>
  Oluşturulacak videonun metin açıklaması.
</ParamField>

<ParamField body="image_url" type="string">
  Image-to-video (I2V) oluşturma için başlangıç görselinin herkese açık olarak erişilebilir URL'si. Modeller arası en iyi uyumluluk için `image_url` tercih edin.
</ParamField>

<ParamField body="image" type="string">
  Data URL olarak satır içi görsel (örneğin, `data:image/jpeg;base64,...`). Uyumlu modeller tarafından desteklenir, ancak `image_url` video modelleri arasında en geniş uyumluluğu sağlar.
</ParamField>

<ParamField body="duration" type="integer">
  Saniye cinsinden video süresi (modele bağlıdır).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  En-boy oranı (ör. `16:9`, `9:16`, `1:1`).
</ParamField>

<ParamField body="resolution" type="string">
  Video çözünürlüğü (ör. `1080p`, `720p`).
</ParamField>

<ParamField body="output_audio" type="boolean">
  Model-dependent audio output toggle. In LemonData, Veo 3 family requests default to `true` when this field is omitted. Other video models follow their governed default behavior. The camelCase alias `outputAudio` is accepted for compatibility.
</ParamField>

<ParamField body="fps" type="integer">
  Saniye başına kare sayısı (1-120).
</ParamField>

<ParamField body="negative_prompt" type="string">
  Video oluşturma sırasında kaçınılması gerekenler.
</ParamField>

<ParamField body="seed" type="integer">
  Tekrarlanabilir oluşturma için rastgele seed.
</ParamField>

<ParamField body="cfg_scale" type="number">
  Classifier-free guidance ölçeği (0-20).
</ParamField>

<ParamField body="motion_strength" type="number">
  Hareket yoğunluğu (0-1).
</ParamField>

<ParamField body="start_image" type="string">
  Başlangıç karesi görselinin URL'si.
</ParamField>

<ParamField body="end_image" type="string">
  Bitiş karesi görselinin URL'si.
</ParamField>

<ParamField body="user" type="string">
  Son kullanıcı için benzersiz bir tanımlayıcı.
</ParamField>

## Yanıt

<ResponseField name="task_id" type="string">
  Polling için benzersiz görev tanımlayıcısı.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Bu görev için önerilen polling URL'si. Durumu kontrol ederken bu tam yolu kullanın.
</ResponseField>

<ResponseField name="status" type="string">
  Başlangıç durumu: `pending`.
</ResponseField>

<ResponseField name="model" type="string">
  Kullanılan model.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",

        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }

print(f"Task ID: {task_id}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":    "sora-2",
        "prompt":   "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/videos/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Poll URL: %s\n", result["poll_url"])
    fmt.Printf("Task ID: %s\n", result["task_id"])
}
```

## Image to Video

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/image.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)
```

## Keyframe Kontrolü

İlk ve son kareleri kontrol etmek için `start_image` ve `end_image` kullanın (Vidu Q2 Pro tarafından desteklenir):

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/day.jpg",
        "end_image": "https://example.com/night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```
