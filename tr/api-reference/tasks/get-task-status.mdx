## Genel Bakış

Video, görsel, müzik ve 3D üretimi gibi görev türleri arasında birleşik async polling için bu endpoint'i kullanın.

<Info>
Bir create yanıtı `poll_url` içeriyorsa, tam olarak o path'i çağırın. Daha yeni async workflow'lar için `poll_url`, `/v1/tasks/{taskId}` adresini işaret edebilir.
</Info>

## Path Parametreleri

<ParamField path="taskId" type="string" required>
  Create isteğinden döndürülen görev kimliği.
</ParamField>

## Yanıt

<ResponseField name="id" type="string">
  Görev tanımlayıcısı.
</ResponseField>

<ResponseField name="status" type="string">
  `pending`, `processing`, `completed` veya `failed` gibi görev durumu.
</ResponseField>

<ResponseField name="video_url" type="string">
  Görev tamamlandığında ve bir video ürettiğinde sonuç varlığının URL'si.
</ResponseField>

<ResponseField name="error" type="string">
  Görev başarısız olduğunda hata mesajı.
</ResponseField>

## Örnekler

```bash cURL
curl "https://api.lemondata.cc/v1/tasks/video_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

poll_url = "/v1/tasks/video_abc123"
response = requests.get(
    f"https://api.lemondata.cc{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/video_abc123';
const response = await fetch(`https://api.lemondata.cc${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
