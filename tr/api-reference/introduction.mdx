## Genel Bakış

LemonData API, **OpenAI uyumludur**; bu, resmi OpenAI SDK'sını yalnızca bir temel URL değişikliği ile kullanabileceğiniz anlamına gelir. Ayrıca yerel **Anthropic** ve **Gemini** istek formatlarını da destekliyoruz.

## Temel URL

```
https://api.lemondata.cc
```

## Kimlik Doğrulama

Tüm API uç noktaları, bir Bearer token kullanarak kimlik doğrulaması gerektirir:

```bash
Authorization: Bearer sk-your-api-key
```

API anahtarınızı [Dashboard](https://lemondata.cc/dashboard) üzerinden alın.

<Warning>
**Etkileşimli Playground Hakkında**: Bu dokümantasyon sitesindeki playground yalnızca gösterim amaçlıdır ve API anahtarlarının girilmesini desteklemez. API'yi test etmek için lütfen şunları kullanın:
- **cURL** - Örnek komutları kopyalayın ve `sk-your-api-key` kısmını gerçek anahtarınızla değiştirin
- **Postman** - [OpenAPI spesifikasyonumuzu](/openapi.json) içe aktarın
- **SDK** - Temel URL'imizle OpenAI/Anthropic SDK kullanın
</Warning>

## Desteklenen Uç Noktalar

### Sohbet ve Metin Oluşturma

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1/chat/completions` | POST | OpenAI uyumlu sohbet tamamlama |
| `/v1/messages` | POST | Anthropic uyumlu mesajlar API'si |
| `/v1/responses` | POST | OpenAI Yanıtlar API'si |

### Embeddings ve Rerank

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1/embeddings` | POST | Metin embedding'leri oluşturun |
| `/v1/rerank` | POST | Belgeleri yeniden sıralayın (Rerank) |

### Görseller

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1/images/generations` | POST | Metinden görsel oluşturun |
| `/v1/images/edits` | POST | Görselleri düzenleyin |
| `/v1/images/generations/{id}` | GET | Görev tabanlı görsel yanıtları için görsel görev durumu yolu |

<Info>
Bazı görsel modelleri sonuçları satır içi (inline) döndürebilir, bazıları görev tabanlı yanıtlar döndürebilir ve bazıları yönlendirilen sağlayıcı yoluna bağlı olarak her iki şekilde de davranabilir. Eğer oluşturma yanıtı `poll_url` içeriyorsa, onu tam olarak takip edin.
</Info>

### Ses

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1/audio/speech` | POST | Metinden sese (TTS) |
| `/v1/audio/transcriptions` | POST | Sesten metne (STT) |

### Video

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1/videos/generations` | POST | Video oluşturma görevi oluşturun |
| `/v1/tasks/{id}` | GET | Video işleri için asenkron görev durumunu alın |
| `/v1/videos/generations/{id}` | GET | Eski sürümlerle uyumlu video görev durumu yolu |

<Info>
Yeni istemciler için `/v1/tasks/{id}` yolunu tercih edin ve oluşturma yanıtları tarafından döndürülen `poll_url` değerini takip edin. `/v1/videos/generations/{id}` yolunu yalnızca geriye dönük uyumluluk için saklayın.
</Info>

### Asenkron Görevler

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1/tasks/{id}` | GET | Birleştirilmiş asenkron görev durumu uç noktası. Döndürülen bir `poll_url` takip edilirken önerilir |

<Info>
Bu uç nokta video, müzik ve 3D ile sınırlı değildir. Bazı görsel görevleri de kurallı sorgulama yolu olarak `/v1/tasks/{id}` kullanabilir.
</Info>

### Müzik

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1/music/generations` | POST | Müzik oluşturma görevi oluşturun |
| `/v1/music/generations/{id}` | GET | Müziğe özel durum yolu |

<Info>
Yeni istemciler için öncelikle döndürülen `poll_url` değerini tercih edin. Sabit bir görev durumu uç noktasına ihtiyacınız varsa `/v1/tasks/{id}` kullanın; `/v1/music/generations/{id}` yolunu müziğe özel uyumluluk yolları için saklayın.
</Info>

### 3D Oluşturma

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1/3d/generations` | POST | 3D model oluşturma görevi oluşturun |
| `/v1/3d/generations/{id}` | GET | 3D'ye özel durum yolu |

<Info>
Yeni istemciler için öncelikle döndürülen `poll_url` değerini tercih edin. Sabit bir görev durumu uç noktasına ihtiyacınız varsa `/v1/tasks/{id}` kullanın; `/v1/3d/generations/{id}` yolunu 3D'ye özel uyumluluk yolları için saklayın.
</Info>

### Modeller

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1/models` | GET | Mevcut tüm modelleri listeleyin |
| `/v1/models/{model}` | GET | Belirli model bilgilerini alın |

### Gemini (v1beta)

Yerel Google Gemini API formatı desteği:

| Uç Nokta | Metot | Açıklama |
|----------|--------|-------------|
| `/v1beta/models/{model}:generateContent` | POST | İçerik oluştur (Gemini formatı) |
| `/v1beta/models/{model}:streamGenerateContent` | POST | Akışlı içerik oluştur (Gemini formatı) |

<Note>
Gemini uç noktaları, standart Bearer token'a ek olarak `?key=` sorgu parametresi kimlik doğrulamasını destekler.
</Note>

## Yanıt Formatı

Tüm yanıtlar tutarlı bir format izler:

### Başarılı Yanıt

```json
{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1234567890,
  "model": "gpt-4o",
  "choices": [...],
  "usage": {
    "prompt_tokens": 10,
    "completion_tokens": 20,
    "total_tokens": 30
  }
}
```

### Yönlendirme Şeffaflığı

Tüm yanıtlar, kanal bilgilerini içeren bir `_routing` alanı içerir:

```json
{
  "id": "chatcmpl-abc123",
  ...,
  "_routing": {
    "channel": {
      "id": "ch_xxx",
      "name": "channel-name",
      "provider": "openai",
      "channelType": "PLATFORM"
    },
    "cached": false,
    "retryCount": 0
  }
}
```

| Alan | Açıklama |
|-------|-------------|
| `channel.id` | Kullanılan kanal tanımlayıcısı |
| `channel.provider` | Üst sağlayıcı (openai, anthropic, vb.) |
| `channel.channelType` | `PLATFORM` (LemonData) veya `PRIVATE` (BYOK) |
| `cached` | Yanıtın önbellekten sunulup sunulmadığı |
| `retryCount` | Yeniden deneme sayısı (varsa) |

### Hata Yanıtı

```json
{
  "error": {
    "message": "Invalid API key provided",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

## Hız Limitleri

Hız limitleri rol tabanlıdır ve yöneticiler tarafından yapılandırılabilir. Varsayılan değerler:

| Rol | İstek/dakika |
|------|-------------|
| Kullanıcı | 60 |
| Partner | 300 |
| VIP | 1,000 |

<Note>
Özel hız limitleri için destek ekibiyle iletişime geçin. Kesin değerler hesap yapılandırmasına göre değişiklik gösterebilir.
</Note>

Hız limitleri aşıldığında, API ne kadar bekleneceğini belirten bir `Retry-After` başlığı ile birlikte `429` durum kodu döndürür.
