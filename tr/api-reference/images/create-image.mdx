title: "Görsel Oluştur"
openapi: "POST /v1/images/generations"
description: "Bir prompt verildiğinde bir görsel oluşturur"
---

<Note>
Kod üreten ajanlar için önce `GET /v1/models?recommended_for=image` ile mevcut önerilen görsel shortlist'ini keşfedin, ardından seçilen `model`i bu endpoint'e açıkça gönderin.
</Note>

<Note>
Google Gemini görsel aileleri aynı selector sözleşmesini paylaşmaz:

- `gemini-3-pro-image-preview` ve `nano-banana-pro`, `aspect_ratio` ile birlikte `resolution` (`1k`, `2k`, `4k`) destekler.
- `gemini-2.5-flash-image`, `gemini-3.1-flash-image-preview`, `nano-banana` ve `nano-banana-edit`, `aspect_ratio` destekler fakat public `resolution` seçimi sunmaz.
- `gemini-2.0-flash-preview-image-generation` burada yalnızca prompt alan text-to-image olarak belgelenmiştir.

Google görsel aileleri için `aspect_ratio` kullanmayı tercih edin ve `resolution`'ı yalnızca model açıkça destekliyorsa gönderin.
</Note>

## İstek Gövdesi

<ParamField body="model" type="string" default="dall-e-3">
  Kullanılacak model (örn. `dall-e-3`, `flux-pro`, `midjourney`).
</ParamField>

<ParamField body="prompt" type="string" required>
  İstenen görselin metin açıklaması.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Üretilecek görsel sayısı (1-10, modele bağlı).
</ParamField>

<ParamField body="size" type="string" default="1024x1024">
  Görsel boyutu. Bunu OpenAI tarzı görsel aileleri ve tam piksel boyutunu kabul eden diğer modeller için kullanın.

  Google Gemini görsel aileleri için `size`, modelin public `aspect_ratio` sözleşmesine ve destekleniyorsa `resolution` sözleşmesine eşlenen uyumluluk alias'ı olarak değerlendirilir. Bu modeller için doğrudan `aspect_ratio` göndermeyi tercih edin.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Modele bağlı en-boy oranı seçici.

  Google görsel ailelerinde yaygın değerler `1:1`, `16:9`, `9:16`, `3:2` ve `2:3`'tür.
</ParamField>

<ParamField body="resolution" type="string">
  Modele bağlı çıktı çözünürlüğü seçici.

  `gemini-3-pro-image-preview`, `nano-banana-pro`, `nano-banana-2` ve benzeri yüksek çözünürlüklü ailelerde desteklenir. Tipik değerler `1k`, `2k` ve `4k`'tür. Model bunu açıkça belgelemiyorsa bu parametreyi Gemini Flash image ailelerine göndermeyin.
</ParamField>

<ParamField body="quality" type="string" default="standard">
  Görsel kalitesi (`standard` veya `hd`). Yalnızca DALL-E 3.
</ParamField>

<ParamField body="response_format" type="string" default="url">
  Yanıt formatı: `url` veya `b64_json`.
</ParamField>

<ParamField body="style" type="string" default="vivid">
  DALL-E 3 için stil: `vivid` veya `natural`.
</ParamField>

<ParamField body="user" type="string">
  Son kullanıcı için benzersiz bir identifier.
</ParamField>

## Yanıt

### Senkron Yanıt

<ResponseField name="created" type="integer">
  Oluşturulma zamanının Unix timestamp'i.
</ResponseField>

<ResponseField name="data" type="array">
  Üretilen görsellerin dizisi.

  Her object şunları içerir:
  - `url` (string): Üretilen görselin URL'si
  - `b64_json` (string): Base64 kodlanmış görsel (istenirse)
  - `revised_prompt` (string): Kullanılan prompt (DALL-E 3)
</ResponseField>

### Asenkron Görev Yanıtı

Bazı görsel modeller hemen asenkron bir görev döndürür ve bazıları yönlendirilen provider yoluna bağlı olarak inline ya da task tabanlı davranabilir. Yanıt `status: "pending"` içerdiğinde, bunu asenkron görev yanıtı olarak değerlendirin:

<Info>
Döndürüldüğünde `poll_url`'ı aynen kullanın. `task_id`'yi takip polling'i için asenkron görev kimliği olarak değerlendirin.
</Info>

<ResponseField name="created" type="integer">
  Oluşturulma zamanının Unix timestamp'i.
</ResponseField>

<ResponseField name="task_id" type="string">
  Polling için benzersiz görev kimliği.
</ResponseField>

<ResponseField name="status" type="string">
  İlk durum: `pending`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Sonuçları polling yapmak için göreli URL (örneğin `/v1/tasks/{id}`).
</ResponseField>

<ResponseField name="data" type="array">
  Placeholder veri içeren dizi. Tamamlanana kadar `url` boş kalır.
</ResponseField>

<Note>
`status: "pending"` aldığınızda sonucu polling yapmak için [Görsel Durumunu Al](/tr/api-reference/images/get-image-status) endpoint'ini kullanın.
</Note>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/images/generations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3-pro-image-preview",
    "prompt": "A cinematic portrait of a white cat sitting on a rainy windowsill",
    "aspect_ratio": "16:9",
    "resolution": "2k",
    "n": 1
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.images.generate(
    model="gemini-3-pro-image-preview",
    prompt="A cinematic portrait of a white cat sitting on a rainy windowsill",
    aspect_ratio="16:9",
    resolution="2k",
    n=1
)

print(response.data[0].url)
```

## Kullanılabilir Modeller

| Model | Tip | Özellikler |
|-------|-----|------------|
| `dall-e-3` | Genelde inline | En iyi kalite, prompt iyileştirme |
| `dall-e-2` | Genelde inline | Daha hızlı, daha uygun maliyetli |
| `flux-pro` | Sıklıkla task tabanlı | Fotogerçekçi, yüksek kalite |
| `flux-schnell` | Genelde inline | Çok hızlı |
| `midjourney` | Sıklıkla task tabanlı | Sanatsal stil |
| `ideogram-v3` | Sıklıkla task tabanlı | En iyi metin oluşturma |
| `stable-diffusion-3` | Genelde inline | Açık kaynak, özelleştirilebilir |

<Tip>
Bir modeli her zaman senkron ya da her zaman asenkron olarak hard-code etmeyin. Create yanıtı `status: "pending"` döndürürse, `poll_url`'ı takip edin ve tamamlanana kadar polling yapın.
</Tip>
