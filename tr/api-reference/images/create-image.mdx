## Request Body

<ParamField body="model" type="string" default="dall-e-3">
  Kullanılacak model (örn. `dall-e-3`, `flux-pro`, `midjourney`).
</ParamField>

<ParamField body="prompt" type="string" required>
  İstenen görselin metin açıklaması.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Oluşturulacak görsel sayısı (1-4, modele bağlıdır).
</ParamField>

<ParamField body="size" type="string" default="1024x1024">
  Görsel boyutu. Seçenekler modele göre değişir:
  - DALL-E 3: `1024x1024`, `1792x1024`, `1024x1792`
  - Diğer modeller: `512x512`, `1024x1024` vb.
</ParamField>

<ParamField body="quality" type="string" default="standard">
  Görsel kalitesi (`standard` veya `hd`). Yalnızca DALL-E 3.
</ParamField>

<ParamField body="response_format" type="string" default="url">
  Yanıt biçimi: `url` veya `b64_json`.
</ParamField>

<ParamField body="style" type="string" default="vivid">
  DALL-E 3 için stil: `vivid` veya `natural`.
</ParamField>

<ParamField body="user" type="string">
  Son kullanıcı için benzersiz bir tanımlayıcı.
</ParamField>

## Yanıt

### Eşzamanlı Yanıt (DALL-E, Flux Schnell vb.)

<ResponseField name="created" type="integer">
  Oluşturulma zamanının Unix zaman damgası.
</ResponseField>

<ResponseField name="data" type="array">
  Oluşturulan görseller dizisi.

  Her nesne şunları içerir:
  - `url` (string): Oluşturulan görselin URL'si
  - `b64_json` (string): Base64 kodlanmış görsel (istenmişse)
  - `revised_prompt` (string): Kullanılan prompt (DALL-E 3)
</ResponseField>

### Eşzamansız Yanıt (Midjourney, Flux Pro, Ideogram vb.)

Bazı modeller daha uzun işlem süresi gerektirir ve eşzamansız bir yanıt döndürür:

<ResponseField name="created" type="integer">
  Oluşturulma zamanının Unix zaman damgası.
</ResponseField>

<ResponseField name="task_id" type="string">
  Polling için benzersiz görev tanımlayıcısı.
</ResponseField>

<ResponseField name="status" type="string">
  Başlangıç durumu: `pending`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Sonuçları sorgulamak için göreli URL (örn. `/v1/tasks/{id}`).
</ResponseField>

<ResponseField name="data" type="array">
  Yer tutucu veriler içeren dizi. İşlem tamamlanana kadar `url` boş olacaktır.
</ResponseField>

<Note>
`status: "pending"` aldığınızda, sonucu sorgulamak için [Get Image Status](/api-reference/images/get-image-status) endpoint'ini kullanın.
</Note>

## Kullanılabilir Modeller

| Model | Tür | Özellikler |
|-------|------|----------|
| `dall-e-3` | Sync | En iyi kalite, prompt iyileştirme |
| `dall-e-2` | Sync | Daha hızlı, daha uygun maliyetli |
| `flux-pro` | **Async** | Fotogerçekçi, yüksek kalite |
| `flux-schnell` | Sync | Çok hızlı |
| `midjourney` | **Async** | Sanatsal stil |
| `ideogram-v3` | **Async** | En iyi metin işleme |
| `stable-diffusion-3` | Sync | Açık kaynak, özelleştirilebilir |

<Tip>
**Async modeller** `status: "pending"` döndürür ve polling gerektirir. Sonuçların nasıl alınacağını görmek için [Get Image Status](/api-reference/images/get-image-status) bölümüne bakın.
</Tip>

## Eşzamansız Yanıtların İşlenmesi

Async modeller için, yanıtın `status: "pending"` içerip içermediğini kontrol edin:

```python
import requests
import time

def generate_image(prompt, model="midjourney"):
    # Create image request
    response = requests.post(
        "https://api.lemondata.cc/v1/images/generations",
        headers={"Authorization": "Bearer sk-your-api-key"},
        json={"model": model, "prompt": prompt}
    )
    data = response.json()

    # Check if async
    if data.get("status") == "pending":
        task_id = data["task_id"]
        poll_url = data.get("poll_url")
        print(f"Async task started: {task_id}")

        # Poll for result
        while True:
            status_resp = requests.get(
                f"https://api.lemondata.cc{poll_url}" if poll_url else f"https://api.lemondata.cc/v1/tasks/{task_id}",
                headers={"Authorization": "Bearer sk-your-api-key"}
            )
            status_data = status_resp.json()

            if status_data["status"] == "completed":
                return status_data["data"][0]["url"]
            elif status_data["status"] == "failed":
                raise Exception(status_data.get("error", "Generation failed"))

            time.sleep(3)
    else:
        # Sync response
        return data["data"][0]["url"]

# Usage
url = generate_image("a beautiful sunset over mountains", model="midjourney")
print(f"Generated image: {url}")
```
