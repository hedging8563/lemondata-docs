---
title: "Modeli Getir"
openapi: "GET /v1/models/{model}"
description: "Bir model örneğini getirir"
---

## Yol Parametreleri

<ParamField path="model" type="string" required>
  Getirilecek modelin kimliği (ör. `gpt-5.4`, `claude-sonnet-4-6`).
</ParamField>

## Yanıt

<ResponseField name="id" type="string">
  Model tanımlayıcısı.
</ResponseField>

<ResponseField name="object" type="string">
  Her zaman `model`.
</ResponseField>

<ResponseField name="created" type="integer">
  Oluşturulma zaman damgası.
</ResponseField>

<ResponseField name="owned_by" type="string">
  Model sağlayıcısı.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/models/gpt-5.4" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

model = client.models.retrieve("gpt-5.4")
print(f"Model: {model.id}, Provider: {model.owned_by}")
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const model = await client.models.retrieve('gpt-5.4');
console.log(`Model: ${model.id}, Provider: ${model.owned_by}`);
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/models/gpt-5.4", nil)
    req.Header.Set("Authorization", "Bearer sk-your-api-key")

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    var model map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&model)
    fmt.Printf("Model: %s, Provider: %s\n", model["id"], model["owned_by"])
}
```

```php PHP
<?php
$ch = curl_init('https://api.lemondata.cc/v1/models/gpt-5.4');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$model = json_decode($response, true);
echo "Model: {$model['id']}, Provider: {$model['owned_by']}\n";
```

## Hata İşleme

Model mevcut değilse, 404 hatası alırsınız:

```json
{
  "error": {
    "message": "Model 'invalid-model' not found",
    "type": "invalid_request_error",
    "code": "model_not_found"
  }
}
```
