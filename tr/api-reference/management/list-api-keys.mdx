## Genel Bakış

Geçerli yönetim belirteciyle ilişkili kuruluştaki kullanıcı API anahtarlarını döndürür.

## Notlar

- Playground veya Claw anahtarları gibi sistem tarafından yönetilen anahtarlar hariç tutulur.
- Parasal yanıt alanları hem USD hem de RMB gösterimiyle döner: `limit_amount` / `limit_amount_cny`, `used_amount` / `used_amount_cny`.
- `exchange_rate`, RMB gösterim alanlarında kullanılan USD→CNY kurunu belirtir.

## Örnek

<RequestExample>
```bash cURL
curl -X GET "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>
