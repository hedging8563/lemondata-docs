## Genel Bakış

Yönetim API'si, standart bir inference API anahtarı kullanmadan kuruluş API anahtarlarını yönetmenizi ve belirli bir anahtar için kullanım ile faturalamayı görüntülemenizi sağlar.

Dashboard içindeki **Settings** sayfasından bir yönetim belirteci kullanın:

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
Yönetim belirteçleri inference API anahtarı değildir. `/v1/management/*` için `mt-...`, `/v1/responses` gibi inference uç noktaları için `sk-...` kullanın.
</Warning>

## Kullanılabilir uç noktalar

| Endpoint | Method | Açıklama |
|----------|--------|------|
| `/v1/management/api-keys` | GET | Geçerli kuruluştaki kullanıcı API anahtarlarını listeler |
| `/v1/management/api-keys` | POST | Yeni bir kullanıcı API anahtarı oluşturur |
| `/v1/management/api-keys/{keyId}` | PATCH | Adı, kullanım limitini, izin verilen modelleri, sona erme tarihini veya durumu günceller |
| `/v1/management/api-keys/{keyId}/usage` | GET | Belirli bir anahtar için sayfalı kullanım ayrıntılarını getirir |
| `/v1/management/api-keys/{keyId}/billing` | GET | Belirli bir anahtar için toplu faturalandırma kırılımlarını getirir |

## Alan açıklamaları

- istekte gönderdiğiniz model adı (`model`)
- genel model sağlayıcısı
- `scene`
- `accessChannel`: `platform`, isteğin platform üzerinden ücretlendirildiği anlamına gelir; `byok`, kendi upstream sağlayıcı anahtarınızı kullandığınız anlamına gelir
- kullanım miktarı, faturalandırma birimi ve cache metrikleri
- maliyet ve zaman damgaları

Yanıtlar yalnızca herkese açık faturalandırma ve raporlama alanlarını gösterir. Dahili yönlendirme ayrıntıları ile fiziksel sağlayıcı metadatası gizli kalır.

## Filtreler

`/usage` ve `/billing` şu anda şu alanlarda filtrelemeyi destekler:

- zaman aralığı
- istekte gönderdiğiniz model adı (`model`)
- genel model sağlayıcısı
- `scene`
- `accessChannel`
- sayfalama

## Tam istek örneği

Önce mevcut yönetim belirteciyle erişilebilen kuruluş API anahtarlarını listeleyin:

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```

```python Python
import requests

response = requests.get(
    "https://api.lemondata.cc/v1/management/api-keys",
    headers={"Authorization": "Bearer mt-your-management-token"}
)

data = response.json()
for key in data["data"]:
    print(key["name"], key["status"], key["used_amount"])
```

```javascript JavaScript
const response = await fetch(
  'https://api.lemondata.cc/v1/management/api-keys',
  {
    headers: {
      'Authorization': 'Bearer mt-your-management-token'
    }
  }
);

const data = await response.json();
for (const key of data.data) {
  console.log(key.name, key.status, key.used_amount);
}
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/management/api-keys", nil)
    req.Header.Set("Authorization", "Bearer mt-your-management-token")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)

    fmt.Println(result["object"])
}
```

```php PHP
<?php
$ch = curl_init("https://api.lemondata.cc/v1/management/api-keys");

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer mt-your-management-token'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
foreach ($data['data'] as $key) {
    echo $key["name"] . " " . $key["status"] . " " . $key["used_amount"] . PHP_EOL;
}
```
</RequestExample>
