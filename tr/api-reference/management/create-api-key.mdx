## Genel bakış

Bu endpoint, mevcut management token ile ilişkili organizasyon içinde yeni bir `type=user` API Key oluşturur.

## İstek gövdesi

| Alan | Tür | Varsayılan / sınırlar | Notlar |
|-------|------|------------------|-------|
| name | string | zorunlu, varsayılan Default Key, uzunluk 1-50 | Görünen ad, sunucu tarafında temizlenir |
| limitAmount | number \| null | min. 0, maks. 100000 | null veya gönderilmezse = sınırsız, 0 = kullanılabilir kota yok, pozitif değer = USD sınırı |
| models | string[] | varsayılan [] | İsteğe bağlı logical model izin listesi |
| expiresAt | string \| null | RFC3339 datetime | null, son kullanma olmadığı anlamına gelir |

## Notlar

- API Key’in tam değeri yanıtta yalnızca bir kez gösterilir.
- `models: []`, organizasyon politikası dışında ek model kısıtı olmadığı anlamına gelir.
- `limitAmount: 0`, geçerli ancak kullanılabilir kotası olmayan bir anahtar oluşturur; daha sonra güncellenmesi gerekir.

## Örnek

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "sora-2"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>
