## Genel Bakış

Bu uç nokta, istekte gönderdiğiniz model adı (`model`), genel model sağlayıcısı, `scene` ve `accessChannel` filtreleriyle anahtar bazında kullanım ayrıntıları döndürür.

## Notlar

- Yanıt yalnızca herkese açık faturalandırma alanlarını içerir.
- Dahili yönlendirme ve fiziksel kanal metadatası bilerek gizlenir.
