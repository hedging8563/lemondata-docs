## Genel bakış

Bu endpoint ile mevcut bir API Key’in adını, kullanım limitini, izin verilen modellerini, son kullanma zamanını veya durumunu güncelleyebilirsiniz.

## İstek gövdesi

PATCH isteğinde en az bir alan gönderilmelidir.

| Alan | Tür | Varsayılan / sınırlar | Notlar |
|-------|------|------------------|-------|
| status | enum | - | active, inactive, revoked |
| name | string | uzunluk 1-50 | Güncellenmiş görünen ad |
| limitAmount | number \| null | min 0, max 100000 | null = unlimited, 0 = zero quota, positive = USD cap |
| models | string[] | - | Güncellenmiş logical model izin listesi |
| expiresAt | string \| null | RFC3339 datetime | null, son kullanma bilgisini temizler |

## Notlar

- Management API v1 kasıtlı olarak hard delete desteklemez.
- `revoked` genellikle terminal bir durum olarak ele alınır; tekrar erişim gerekiyorsa çoğu durumda yeni bir key oluşturmak daha uygundur.

## Örnek

<RequestExample>
```bash cURL
curl -X PATCH "https://api.lemondata.cc/v1/management/api-keys/key_abc123def456" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "inactive",
    "limitAmount": 0
  }'
```
</RequestExample>
