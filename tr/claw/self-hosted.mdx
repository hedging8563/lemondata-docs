<Note>
**Self-hosted** (kendi sunucunda barındırma), LemonClaw'ı doğrudan kendi VPS'inizde veya makinenizde çalıştırmanız anlamına gelir. Yalnızca LemonData bakiyeniz üzerinden AI model kullanımı için ödeme yaparsınız — örnek (instance) ücreti yoktur.
</Note>

<Tip>
Barındırılan bir kurulum mu tercih edersiniz? Sunucuları kendiniz yönetmek zorunda kalmadan aynı LemonClaw çalışma zamanını ve WebUI'ı elde etmek için bir [Claw örneği oluşturun](/claw/introduction).
</Tip>

## Hızlı Kurulum

<CodeGroup>
```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```

```bash Etkileşimsiz
LEMONDATA_API_KEY=sk-xxx curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```
</CodeGroup>

Yükleyici sizden **LemonData API Key** isteyecektir. [Dashboard](https://lemondata.cc/dashboard) üzerinden bir tane edinin.

## Yönetim Komutları

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user status lemonclaw    # Durumu kontrol et
    journalctl --user -u lemonclaw -f    # Günlükleri görüntüle
    systemctl --user restart lemonclaw   # Yeniden başlat
    systemctl --user stop lemonclaw      # Durdur
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    tail -f ~/.lemonclaw/lemonclaw.log    # Günlükleri görüntüle
    launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # Yeniden başlat
    launchctl stop cc.lemondata.lemonclaw  # Durdur
    ```
  </Tab>
</Tabs>

## Yapılandırma

Yapılandırma dosyası konumu: `~/.lemonclaw/config.json`

Düzenledikten sonra, değişiklikleri uygulamak için servisi yeniden başlatın.

### Varsayılan Modeli Değiştir

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-opus-4-6"
      }
    }
  }
}
```

Mevcut model önekleri:
- `lemondata-claude/` — Claude modelleri (anthropic-messages API)
- `lemondata-minimax/` — MiniMax modelleri (anthropic-messages API)
- `lemondata/` — Diğer tüm modeller (openai-completions API)

## Yükseltme

```bash
# En son sürüme yükseltmek için yükleyiciyi yeniden çalıştırın
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
# Ardından servisi yeniden başlatın
systemctl --user restart lemonclaw  # Linux
# veya
launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # macOS
```

## Kaldırma

```bash
# Servisi durdur ve devre dışı bırak
systemctl --user stop lemonclaw && systemctl --user disable lemonclaw  # Linux
launchctl unload ~/Library/LaunchAgents/cc.lemondata.lemonclaw.plist  # macOS

# LemonClaw'ı kaldır
rm -rf ~/.lemonclaw
```

## Self-Hosted vs Yönetilen

| | Self-Hosted | Yönetilen (Claw) |
|---|---|---|
| **Örnek maliyeti** | Ücretsiz | $20 / 30 gün |
| **AI kullanımı** | Kullandıkça öde | Kullandıkça öde |
| **Altyapı** | Sizin sunucunuz | Her şeyi biz yönetiyoruz |
| **Güncellemeler** | Manuel (yükleyiciyi yeniden çalıştırın) | Otomatik |
| **Destek** | Topluluk | Öncelikli |
