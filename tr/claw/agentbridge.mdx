AgentBridge, coding agent’ın hosted dashboard’da görünen instance gateway token’ını kullanarak çalışan bir LemonClaw instance’ı ile doğrudan konuşmasını sağlar.

## Access pack nasıl alınır

Dashboard > Claw sayfasını açın, çalışan bir instance seçin, AgentBridge’e tıklayın ve modal içindeki tam access pack’i kopyalayın. Bu paket zaten runtime base URL, bearer token, session key kuralı ve en önemli endpoint’leri içerir.

## Bu token ne yapabilir

Kopyalanan gateway token yalnızca runtime katmanını yönetir. Runtime durumunu okuyabilir, chat isteği gönderebilir, SSE çıktısı alabilir, thread geçmişini okuyabilir, çalışan bir thread’i durdurabilir ve AgentBridge’in döndürdüğü medyayı çekebilir. Yenileme, rebuild, hosted control plane üzerinden restart veya organizasyon billing/admin route’larına erişim yapamaz.

## Session key kuralı

Session key her zaman `agentbridge:<client_id>:<workspace_id>:<thread_id>` biçimini izler. Aynı thread için bu üç değeri sabit tutun. Farklı bir provider family’ye geçerseniz eski thread’i yeniden kullanmak yerine yeni bir `thread_id` oluşturun.

## Temel runtime endpoint’leri

- `GET /api/status`
- `GET /api/usage?session=<session_key>`
- `POST /api/agentbridge/chat`
- `POST /api/agentbridge/chat/stream`
- `POST /api/agentbridge/uploads`
- `GET /api/agentbridge/messages`
- `GET /api/agentbridge/events/stream`
- `POST /api/agentbridge/stop`
- `GET /api/agentbridge/media`

```bash
curl -N https://claw-demo.lemondata.cc/api/agentbridge/chat/stream \
  -H "Authorization: Bearer <gateway_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": "codex",
    "workspace_id": "default",
    "thread_id": "demo-thread",
    "message": "Give me a short status update for this instance."
  }'
```

## Coding agent için prompt

Bu kısa talimatı access pack ile birlikte coding agent’a verin:

> Use `/api/agentbridge/chat/stream` first. Keep `client_id`, `workspace_id`, and `thread_id` stable for the same conversation. If you get `provider_family_conflict`, create a new `thread_id` instead of reusing the old one.

## Yaygın hatalar

- `provider_family_conflict` — bu thread başka bir provider family üzerinde geçmişe sahip; yeni bir `thread_id` oluşturun.
- `Unauthorized` — bearer token eksik, süresi dolmuş ya da bu instance’a ait değil.
- `Instance not running` — AgentBridge access pack yalnızca çalışan instance’lar için verilir.
