Tüm Claw API uç noktaları `Authorization: Bearer sk-...` başlığı üzerinden kimlik doğrulaması gerektirir.

**Temel URL:** `https://api.lemondata.cc/v1/claw`

## Örnekleri Listele

```
GET /v1/claw/instances
```

Kimliği doğrulanmış organizasyon için tüm örnekleri döndürür.

<RequestExample>
```bash cURL
curl https://api.lemondata.cc/v1/claw/instances \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

resp = requests.get(
    "https://api.lemondata.cc/v1/claw/instances",
    headers={"Authorization": "Bearer sk-your-api-key"}
)
print(resp.json())
```
</RequestExample>

<ResponseExample>
```json 200
{
  "instances": [
    {
      "id": "cm5abc123",
      "subdomain": "mybot",
      "url": "https://claw-mybot.lemondata.cc",
      "status": "RUNNING",
      "paidUntil": "2026-03-10T00:00:00.000Z",
      "canRebuild": true,
      "totalPaid": 20,
      "createdAt": "2026-02-08T00:00:00.000Z"
    }
  ]
}
```
</ResponseExample>

### Örnek Durum Değerleri

| Durum | Açıklama |
|--------|-------------|
| `PENDING` | Yeni oluşturuldu, hazırlık için bekliyor |
| `PROVISIONING` | Konteyner yayına alınıyor |
| `RUNNING` | Örnek aktif ve sağlıklı |
| `STOPPED` | Süre dolumu nedeniyle durduruldu (veriler 7 gün saklanır) |
| `FAILED` | Dağıtım başarısız oldu (otomatik iade edildi) |
| `DELETED` | Kalıcı olarak kaldırıldı |

## Örnek Oluştur

```
POST /v1/claw/instances
```

Yeni bir örnek oluşturur ve organizasyon bakiyenizden 30 gün için **$20** ücretlendirir.

<ParamField body="subdomain" type="string" required>
  Subdomain (3-32 karakter, küçük harf alfanümerik + tire). Örnek URL'i: `https://claw-{subdomain}.lemondata.cc`
</ParamField>


<RequestExample>
```bash cURL
curl -X POST https://api.lemondata.cc/v1/claw/instances \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"subdomain": "mybot"}'
```

```python Python
import requests

resp = requests.post(
    "https://api.lemondata.cc/v1/claw/instances",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={"subdomain": "mybot"}
)
print(resp.json())
```
</RequestExample>

<ResponseExample>
```json 201
{
  "id": "cm5abc123",
  "subdomain": "mybot",
  "url": "https://claw-mybot.lemondata.cc",
  "status": "PENDING",
  "paidUntil": "2026-03-10T00:00:00.000Z",
  "charged": true,
  "chargedAmount": 20
}
```
</ResponseExample>

<Warning>
Yetersiz bakiye durumunda **402 Payment Required** döner. Bir örnek oluşturmadan önce organizasyonunuzda en az $20 olduğundan emin olun.
</Warning>

## Örneği Getir

```
GET /v1/claw/instances/:id
```

Belirli bir örneğin ayrıntılarını döndürür.


---

## Örneği Yeniden Oluştur

```
POST /v1/claw/instances/:id/rebuild
```

Verileri (PVC) korurken konteyneri yok eder ve yeniden oluşturur. Günlük **10 yeniden oluşturma** ile sınırlıdır.

Günlük sınır aşılırsa **429 Too Many Requests** döner.

---

## Örneği Yenile

```
POST /v1/claw/instances/:id/renew
```

Faturalandırma dönemini 30 gün ($20) uzatır. Örnek süre dolumu nedeniyle durdurulmuşsa otomatik olarak yeniden başlatılır.

<ResponseExample>
```json 200
{
  "id": "cm5abc123",
  "subdomain": "mybot",
  "status": "RUNNING",
  "paidUntil": "2026-04-09T00:00:00.000Z",
  "charged": true,
  "chargedAmount": 20
}
```
</ResponseExample>

## Sistem Durumu Kontrolü

```
GET /v1/claw/health
```

Claw servisi sistem durumu bilgisini döndürür. Kimlik doğrulaması gerekmez.

```json
{"status": "ok", "timestamp": "2026-02-08T15:00:00.000Z"}
```
