<Note>
Bu rehber, LemonData'yı AI provider olarak bağlamak isteyen **self-hosted OpenClaw** kullanıcıları içindir.
</Note>

<Tip>
Daha çok barındırılan bir çözüm istiyorsanız [bir LemonClaw instance'ı oluşturun](/claw/introduction). LemonData varsayılan olarak zaten yapılandırılmıştır; bu yüzden doğrudan WebUI üzerinden başlayabilirsiniz.
</Tip>

## Genel Bakış

Güncel OpenClaw sürümlerinde LemonData'yı bağlamanın önerilen yolu `models.providers` kullanmaktır.

Sadece hızlıca başlamak istiyorsanız tek başına `lemondata` yeterlidir. Diğer provider'ları yalnızca **Responses API**, **yerel Claude**, **yerel Gemini** veya **yerel MiniMax** davranışına ihtiyaç duyduğunuzda ekleyin.

| Provider | OpenClaw `api` | En uygun kullanım | baseUrl |
|----------|----------------|-------------------|---------|
| `lemondata` | `openai-completions` | GPT, DeepSeek, Qwen ve OpenAI uyumlu çağrıların çoğu | `https://api.lemondata.cc/v1` |
| `lemondata-responses` | `openai-responses` | `/v1/responses` semantiği bekleyen OpenAI Responses iş akışları | `https://api.lemondata.cc/v1` |
| `lemondata-claude` | `anthropic-messages` | Claude'un yerel Messages API'si | `https://api.lemondata.cc` |
| `lemondata-gemini` | `google-generative-ai` | Gemini'nin yerel API formatı | `https://api.lemondata.cc` |
| `lemondata-minimax` | `anthropic-messages` | MiniMax'in yerel rotası | `https://api.lemondata.cc` |

<Warning>
`/v1` son ekini yalnızca `openai-completions` ve `openai-responses` için kullanın.

`anthropic-messages` ve `google-generative-ai` gibi yerel provider'lar `/v1` olmadan `https://api.lemondata.cc` kullanmalıdır; aksi halde OpenClaw yanlış upstream yolu oluşturabilir.
</Warning>

## Ön Koşullar

- Bir self-hosted OpenClaw instance'ı
- Bir LemonData API Key — [buradan alın](https://lemondata.cc/dashboard)

## Yapılandırma

OpenClaw yapılandırmanızı düzenleyin:

- **Self-hosted**: `~/.openclaw/openclaw.json`

LemonData provider'larını `models.providers` altına ekleyin:

```json5
{
  agents: {
    defaults: {
      model: {
        primary: "lemondata-claude/claude-sonnet-4-6"
      }
    }
  },
  models: {
    mode: "merge",
    providers: {
      lemondata: {
        api: "openai-completions",
        baseUrl: "https://api.lemondata.cc/v1",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "gpt-4o", name: "GPT-4o" },
          { id: "deepseek-r1", name: "DeepSeek R1" },
          { id: "qwen3-32b", name: "Qwen 3 32B" }
        ]
      },
      "lemondata-responses": {
        api: "openai-responses",
        baseUrl: "https://api.lemondata.cc/v1",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "gpt-4o", name: "GPT-4o (Responses)" },
          { id: "gpt-5.2", name: "GPT-5.2 (Responses)" }
        ]
      },
      "lemondata-claude": {
        api: "anthropic-messages",
        baseUrl: "https://api.lemondata.cc",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "claude-sonnet-4-6", name: "Claude Sonnet 4.6" },
          { id: "claude-opus-4-6", name: "Claude Opus 4.6" }
        ]
      },
      "lemondata-gemini": {
        api: "google-generative-ai",
        baseUrl: "https://api.lemondata.cc",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "gemini-2.5-flash", name: "Gemini 2.5 Flash" },
          { id: "gemini-3-flash-preview", name: "Gemini 3 Flash Preview" }
        ]
      },
      "lemondata-minimax": {
        api: "anthropic-messages",
        baseUrl: "https://api.lemondata.cc",
        apiKey: "sk-your-lemondata-key",
        models: [
          { id: "minimax-m1", name: "MiniMax M1" }
        ]
      }
    }
  }
}
```

<Info>
5 provider'ın tamamı **aynı API key**'i kullanır. Yalnızca tek bir LemonData hesabına ihtiyacınız vardır.
</Info>

<Info>
Yukarıdaki `models` dizileri sadece yaygın örnekleri gösterir. Gerektikçe her provider'a daha fazla model ID ekleyebilirsiniz.
</Info>

## Model Kullanımı

OpenClaw model referansı için hâlâ `provider/model` formatını kullanır:

```json5
{
  agents: {
    defaults: {
      model: {
        primary: "lemondata-gemini/gemini-2.5-flash"
      }
    }
  }
}
```

### Model Örnekleri

| Provider | Model referansı | Açıklama |
|----------|-----------------|----------|
| `lemondata` | `lemondata/gpt-4o` | OpenAI uyumlu rota |
| `lemondata` | `lemondata/deepseek-r1` | DeepSeek akıl yürütme modeli |
| `lemondata-responses` | `lemondata-responses/gpt-4o` | Responses API rotası |
| `lemondata-claude` | `lemondata-claude/claude-sonnet-4-6` | Claude Messages yerel rotası |
| `lemondata-gemini` | `lemondata-gemini/gemini-2.5-flash` | Gemini yerel rotası |
| `lemondata-minimax` | `lemondata-minimax/minimax-m1` | MiniMax yerel rotası |

Tüm kullanılabilir modelleri [lemondata.cc/models](https://lemondata.cc/tr/models) adresinde görebilirsiniz.

## Hangi Provider Ne Zaman Kullanılır?

- `lemondata`: çoğu genel chat ve agent senaryosu için varsayılan seçim.
- `lemondata-responses`: OpenClaw iş akışınız OpenAI Responses semantiğine açıkça bağlıysa kullanın.
- `lemondata-claude`: Claude Messages'ın yerel davranışını istediğinizde kullanın.
- `lemondata-gemini`: Gemini'nin yerel formatını veya Gemini için tasarlanmış mevcut entegrasyonları istediğinizde kullanın.
- `lemondata-minimax`: MiniMax'i yerel rotası üzerinden kullanmak istediğinizde kullanın.

Gemini'nin yerel davranışına ihtiyacınız yoksa, Gemini modellerini `lemondata/gemini-*` üzerinden OpenAI uyumlu rotada çağırmaya devam edebilirsiniz.

## Yaygın Hatalar

<AccordionGroup>
  <Accordion title="Eski top-level providers dizisini kullanmaya devam etmek">
    Güncel OpenClaw belgeleri `models.providers` kullanır. Üst seviyedeki eski `providers` formatında kalırsanız, OpenClaw yapılandırmayı yok sayabilir veya provider öneklerini beklediğiniz gibi çözemeyebilir.
  </Accordion>
  <Accordion title="lemondata-responses için /v1 eklemeyi unutmak">
    `openai-responses`, LemonData'nın `/v1/responses` yoluna gider; bu yüzden `lemondata-responses` mutlaka `https://api.lemondata.cc/v1` kullanmalıdır.
  </Accordion>
  <Accordion title="lemondata-claude, lemondata-gemini veya lemondata-minimax'e /v1 eklemek">
    `anthropic-messages` ve `google-generative-ai` `/v1` olmadan `https://api.lemondata.cc` kullanmalıdır. `/v1` eklemek yanlış istek yolları oluşturabilir.
  </Accordion>
  <Accordion title="OpenClaw hâlâ yerel Gemini'yi destekliyor mu?">
    Evet. Güncel OpenClaw belgeleri hâlâ yerleşik `google` provider'ını içeriyor ve `api: &quot;google-generative-ai&quot;` kullanan özel provider'ları da destekliyor. Bu nedenle `lemondata-gemini`, OpenClaw kullanıcıları için hâlâ geçerli bir yerel Gemini rotasıdır.
  </Accordion>
</AccordionGroup>

## Yapılandırmayı Doğrulama

Yapılandırmayı kaydettikten sonra OpenClaw instance'ınızı yeniden başlatın ve basit bir mesajla test edin. Yanıt alırsanız provider doğru şekilde yapılandırılmış demektir.

```bash
# Self-hosted: servisi yeniden başlat
systemctl --user restart openclaw    # Linux
launchctl stop cc.lemondata.openclaw && launchctl start cc.lemondata.openclaw  # macOS
```
