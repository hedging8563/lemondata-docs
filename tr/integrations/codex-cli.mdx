## Genel Bakış

OpenAI Codex, terminalde kod okuyabilen, değiştirebilen ve çalıştırabilen hafif bir coding agent olarak hizmet veren açık kaynaklı bir command-line tool'dur (CLI). GPT modelleri üzerine kuruludur ve code generation için optimize edilmiştir.

## Sistem Gereksinimleri

- **OS**: macOS, Linux (resmi destek), Windows via WSL
- **Node.js**: Sürüm 18+
- **npm**: Sürüm 10.x.x veya üzeri

## Kurulum

```bash
npm install -g @openai/codex
```

Kurulumu doğrulayın:

```bash
codex --version
```

## Yapılandırma

### Adım 1: API Key Ayarlayın

**Geçici (mevcut oturum):**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**Kalıcı yapılandırma:**

`~/.bashrc`, `~/.zshrc` veya `~/.bash_profile` dosyasına ekleyin:

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

Ardından yeniden yükleyin:

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### Adım 2: config.toml Dosyasını Yapılandırın

`~/.codex/config.toml` dosyasını düzenleyin:

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
Yapılandırma dosyası mevcut değilse, oluşturmak için `codex` komutunu bir kez çalıştırın, ardından dosyayı düzenleyin. Yeni provider ayarlarının yeniden yüklenmesi için `config.toml` dosyasını değiştirdikten sonra Codex'i tamamen yeniden başlatın.
</Note>

<Warning>
Codex, custom provider'lar için `chat/completions` desteğini kullanımdan kaldırmaktadır. Özellikle eski bir compatibility path kullanmıyorsanız, LemonData için `wire_api = "responses"` ayarını koruyun.
</Warning>

## Temel Kullanım

**Interactive mode'u başlatın:**

```bash
codex
```

**Doğrudan komut:**

```bash
codex "Fix the bug in main.py line 42"
```

**Model belirtin:**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## Önerilen Modeller

| Model | En Uygun Olduğu Alan |
|-------|----------|
| `gpt-5.4` | Coding ve reasoning için en iyi varsayılan seçim |
| `gpt-5-mini` | Coding workflow'ları için daha hızlı, daha ucuz fallback |
| `claude-sonnet-4-6` | Code review, dokümantasyon |
| `deepseek-r1` | Algoritma tasarımı, reasoning |

## Interactive Komutlar

| Command | Açıklama |
|---------|-------------|
| `/help` | Yardımı görüntüle |
| `/exit` or `Ctrl+C` | Çıkış yap |
| `/clear` | Konuşmayı temizle |
| `/config` | Yapılandırmayı görüntüle |
| `/model <name>` | Model değiştir |
| `/tokens` | Token kullanımını görüntüle |

## Yapılandırmayı Doğrulayın

```bash
# Check environment variable
echo $OPENAI_API_KEY

# Test API connection
codex "Hello, Codex!"

# View configuration
cat ~/.codex/config.toml
```

## Yaygın Kullanım Senaryoları

**Code review:**

```bash
git diff | codex "Review these code changes"
```

**Commit message oluşturun:**

```bash
git diff --staged | codex "Generate a commit message for these changes"
```

**Hataları düzeltin:**

```bash
codex "Fix the TypeScript errors in src/components/"
```

**Kodu açıklayın:**

```bash
cat main.py | codex "Explain what this code does"
```
