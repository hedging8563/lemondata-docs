## Genel Bakış



<Note>
**Tür**: Kodlama aracı

**Birincil yol**: OpenAI Responses

**Destek seviyesi**: Model / kanal bağımlı olarak desteklenir
</Note>

OpenAI Codex, terminalde kod okuyabilen, değiştirebilen ve çalıştırabilen hafif bir kodlama ajanı olarak hizmet veren açık kaynaklı bir command-line tool'dur (CLI). GPT modelleri üzerine kuruludur ve code generation için optimize edilmiştir.

LemonData için Codex CLI’yi kullanmanın en doğru yolu onu `/v1/responses` adresine yönlendirmektir. Bu yol genel olarak iyi çalışır, ancak bazı Responses native özellikler hâlâ seçilen modelin ve yönlendirilen kanalın yerel aktarım desteğine bağlıdır.

## Sistem Gereksinimleri

- **OS**: macOS, Linux (resmi destek), WSL üzerinden Windows
- **Node.js**: Sürüm 18+
- **npm**: Sürüm 10.x.x veya üzeri

## Kurulum

```bash
npm install -g @openai/codex
```

Kurulumu doğrulayın:

```bash
codex --version
```

## Yapılandırma

### Adım 1: API Key Ayarlayın

**Geçici (mevcut oturum):**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**Kalıcı yapılandırma:**

`~/.bashrc`, `~/.zshrc` veya `~/.bash_profile` dosyasına ekleyin:

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

Ardından yeniden yükleyin:

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### Adım 2: config.toml Dosyasını Yapılandırın

`~/.codex/config.toml` dosyasını düzenleyin:

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
Yapılandırma dosyası mevcut değilse, oluşturmak için `codex` komutunu bir kez çalıştırın, ardından dosyayı düzenleyin. Yeni sağlayıcı ayarlarının yeniden yüklenmesi için `config.toml` dosyasını değiştirdikten sonra Codex'i tamamen yeniden başlatın.
</Note>

<Warning>
Codex, özel sağlayıcılar için `chat/completions` desteğini kullanımdan kaldırmaktadır. Özellikle eski bir uyumluluk yolu kullanmıyorsanız, LemonData için `wire_api = "responses"` ayarını koruyun.
</Warning>

<Note>
Bir istek, seçilen modelin veya yönlendirilen kanalın desteklemediği Responses-native-only alanlar kullanıyorsa LemonData isteği sessizce düşürmek yerine açık bir hata döndürür.
</Note>

## Temel Kullanım

**Interactive mode'u başlatın:**

```bash
codex
```

**Doğrudan komut:**

```bash
codex "Fix the bug in main.py line 42"
```

**Model belirtin:**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## Önerilen Modeller

| Model | En Uygun Olduğu Alan |
|-------|----------|
| `gpt-5.4` | Coding ve reasoning için en iyi varsayılan seçim |
| `gpt-5-mini` | Kodlama iş akışları için daha hızlı, daha ucuz geri dönüş seçeneği |
| `claude-sonnet-4-6` | Kod inceleme, dokümantasyon |
| `deepseek-r1` | Algoritma tasarımı, muhakeme |

## Etkileşimli Komutlar

| Command | Açıklama |
|---------|-------------|
| `/help` | Yardımı görüntüle |
| `/exit` or `Ctrl+C` | Çıkış yap |
| `/clear` | Konuşmayı temizle |
| `/config` | Yapılandırmayı görüntüle |
| `/model <name>` | Model değiştir |
| `/tokens` | Token kullanımını görüntüle |

## Yapılandırmayı Doğrulayın

```bash
# Check environment variable
echo $OPENAI_API_KEY

# Test API connection
codex "Hello, Codex!"

# View configuration
cat ~/.codex/config.toml
```

## Yaygın Kullanım Senaryoları

**Code review:**

```bash
git diff | codex "Review these code changes"
```

**Commit message oluşturun:**

```bash
git diff --staged | codex "Generate a commit message for these changes"
```

**Hataları düzeltin:**

```bash
codex "Fix the TypeScript errors in src/components/"
```

**Kodu açıklayın:**

```bash
cat main.py | codex "Explain what this code does"
```

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Bağlantı Hatası">
    - config.toml içindeki `base_url` değerinin tam olarak `https://api.lemondata.cc/v1` olduğunu doğrulayın
    - Ağ bağlantısını kontrol edin
    - Proxy kaynaklı bir müdahale olmadığından emin olun
  </Accordion>

  <Accordion title="Kimlik Doğrulama Başarısız">
    - `~/.codex/config.toml` içinde `env_key = "OPENAI_API_KEY"` satırının bulunduğunu doğrulayın
    - `OPENAI_API_KEY` environment variable'ının ayarlandığını doğrulayın
    - Anahtarın `sk-` ile başladığını kontrol edin
    - Anahtarın LemonData dashboard'da aktif olduğundan emin olun
  </Accordion>

  <Accordion title="Model Bulunamadı">
    - Model adının tam olarak eşleştiğini kontrol edin
    - Modelin [lemondata.cc/en/models](https://lemondata.cc/tr/models) adresinde kullanılabilir olduğunu doğrulayın
  </Accordion>

<Accordion title="Responses-native alanı reddedildi">
    - Bazı alanlar yalnızca seçilen model ve yönlendirilen kanal `/v1/responses` için yerel aktarım desteği sunduğunda kullanılabilir
    - `unsupported_request_field` veya yerel aktarım içeren bir hata görürseniz o alanı kaldırın ya da uyumlu bir model / kanala geçin
  </Accordion>

</AccordionGroup>
