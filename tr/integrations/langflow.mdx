## Genel Bakış

Langflow'un **OpenAI** bileşeni bir **OpenAI API Base** alanı içerir. Bu alanı TokenLab'in OpenAI uyumlu `/v1` uç noktasına yönlendirin ve TokenLab model kimliklerini (ID) kullanın.

<Note>
**Tür**: Düşük kodlu (Low-code) Yapay Zeka İş Akışı Oluşturucu

**Birincil Yol**: OpenAI uyumlu sohbet tamamlama (chat completions)

**Destek Güveni**: Kapsam sınırları dahilinde desteklenir
</Note>

## OpenAI Bileşeni

1. Bir **OpenAI** dil modeli bileşeni ekleyin.
2. **OpenAI API Key** alanını TokenLab anahtarınızla ayarlayın.
3. Gelişmiş ayarları genişletin.
4. **OpenAI API Base** alanını `https://api.tokenlab.sh/v1` olarak ayarlayın.
5. **Model Name** alanını bir TokenLab model kimliği olarak ayarlayın.
6. Model çıktısını temsilcinize, zincirinize veya iş akışınıza bağlayın.

## Değerler

| Alan | Değer |
|-------|-------|
| OpenAI API Base | `https://api.tokenlab.sh/v1` |
| OpenAI API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

## Önerilen Modeller

- Çoğu iş akışı testi için `gpt-5.4-mini`
- Daha güçlü yazma ve akıl yürütme için `claude-sonnet-5`
- Hızlı ve çok modlu (multimodal) uyumlu iş akışları için `gemini-3.5-flash`
- Hızlı kodlama ve akıl yürütme yinelemeleri için `deepseek-v4-flash`

Dağıtımınız sağlayıcı yönlendirmesini halihazırda bir LiteLLM proxy üzerinden merkezileştiriyorsa, Langflow'un LiteLLM Proxy bileşenini kullanın.
