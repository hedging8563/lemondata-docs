## Genel Bakış

OpenLIT, resmi OpenAI SDK'lerini izler (instrument), böylece TokenLab istekleri, SDK istemcisi TokenLab'in `/v1` temel URL'si ile yapılandırılarak izlenebilir.

<Note>
**Tür**: Gözlemlenebilirlik (Observability)

**Birincil Yol**: OpenAI SDK izleme (instrumentation)

**Destek Güveni**: Desteklenen OpenAI uyumlu gözlemlenebilirlik yolu
</Note>

## Kurulum

```bash
pip install openlit openai
```

## Ortam

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Örnek

```python
import os

import openlit
from openai import OpenAI

openlit.init()

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Hello from OpenLIT"}],
)
```

## Uç Nokta Notları

OpenLIT, SDK izleme yolunu takip eder. Chat Completions en güvenli entegrasyon yüzeyidir; diğer TokenLab'e özgü çağrılar, OpenLIT/OpenTelemetry kurulumunuzun ilgili SDK metodunu veya HTTP istemcisini yakalayıp yakalamadığına bağlıdır.
