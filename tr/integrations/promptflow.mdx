## Genel Bakış

Prompt flow'un OpenAI bağlantısı, özel bir `base_url` değerini destekler. Bunu TokenLab'in `/v1` uç noktasına ayarlayın ve akışınızda TokenLab model kimliklerini (ID) kullanın.

<Note>
**Tür**: Akış oluşturucu ve değerlendirme platformu

**Birincil Yol**: OpenAI uyumlu Chat Completions

**Destek Güveni**: Desteklenen OpenAI uyumlu yol
</Note>

## Bağlantı Oluşturma

```bash
pf connection create \
  --file ./my_chatbot/openai.yaml \
  --set api_key=sk-your-tokenlab-key base_url=https://api.tokenlab.sh/v1 \
  --name open_ai_connection
```

## Akış Notları

`flow.dag.yaml` dosyanızda, bağlantı adını yukarıdaki komutla uyumlu tutun:

```yaml
connection: open_ai_connection
deployment_name: claude-sonnet-5
```

Bazı Prompt flow şablonları bu değere `deployment_name` adını verir çünkü aynı şablonlar Azure OpenAI dağıtımlarını da destekler. TokenLab ile birlikte TokenLab model kimliğini kullanın.

## Uç Nokta Notları

Bu entegrasyon, Prompt flow'un OpenAI uyumlu bağlantısını kullanır. Yerel TokenLab Yanıtları, Anthropic Mesajları ve Gemini rotaları, Prompt flow araçlarını veya bu uç noktaları doğrudan çağıran özel Python düğümlerini gerektirir.
