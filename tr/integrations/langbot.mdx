## Genel Bakış

LangBot, OpenAI uyumlu bir LLM isteği (requester) aracılığıyla TokenLab'i çağırabilir.

<Note>
**Tür**: Bot Platformu

**Birincil Yol**: OpenAI uyumlu sohbet tamamlama (chat completions)

**Destek Güveni**: Kapsam sınırlarıyla desteklenmektedir
</Note>

## TokenLab istekçisi

Eğer LangBot yapınız bir **TokenLab** isteği içeriyorsa:

1. LangBot'un model sağlayıcı ayarlarını açın.
2. **TokenLab** isteği ile bir sağlayıcı ekleyin.
3. API anahtarını TokenLab anahtarınız olarak ayarlayın.
4. `gpt-5.4-mini` gibi bir model seçin veya oluşturun.
5. Modeli, kullanması gereken işlem hattına (pipeline) veya bota bağlayın.

## OpenAI Uyumlu Yedek (Fallback)

Eğer TokenLab henüz listelenmemişse, OpenAI uyumlu isteği kullanın:

| Alan | Değer |
|-------|-------|
| Requester | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Önerilen Modeller

- Çoğu bot etkileşimi için `gpt-5.4-mini`
- Daha uzun yazma ve muhakeme işlemleri için `claude-sonnet-5`
- Hızlı kodlama ve muhakeme döngüleri için `deepseek-v4-flash`
- Hızlı genel iş akışları için `gemini-3.5-flash`
