## Genel Bakış

OpenHands, özellikle model, API anahtarı ve base URL sağladığınız CLI ve headless iş akışlarında, LiteLLM/OpenAI uyumlu model yapılandırması aracılığıyla TokenLab'i kullanabilir.

<Note>
**Tür**: Kodlama Ajanı

**Birincil Yol**: OpenAI uyumlu model yapılandırması

**Destek Güveni**: Desteklenen özel uç nokta yolu
</Note>

## Ortam

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Model Ayarları

Şunları kullanın:

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

`openai/` ön eki, LiteLLM destekli yola OpenAI uyumlu bir sağlayıcı yapılandırması kullanmasını söyler.

## Headless Kurulumu

CLI veya headless kullanım için yerel varsayılanları hazırlıyorsanız, OpenHands kurulum akışını çalıştırın ve şunları girin:

```bash
make setup-config
```

Model detayları istendiğinde, `openai/` ön ekine sahip TokenLab model kimliğini ve TokenLab'in `/v1` base URL'sini kullanın.

## Model Önerileri

Kodlama ajanı planlaması için `claude-sonnet-5` veya `gpt-5.4`, daha hızlı rutin döngüler için `gpt-5.4-mini` ve güçlü bir alternatif akıl yürütme modeli istediğinizde `deepseek-v4-pro` kullanın.
