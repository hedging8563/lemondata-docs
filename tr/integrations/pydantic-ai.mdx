## Genel Bakış

Pydantic AI, TokenLab'i `OpenAIChatModel` ve `OpenAIProvider(base_url=...)` ile kullanabilir.

<Note>
**Tür**: Ajan Çerçevesi (Agent Framework)

**Birincil Yol**: OpenAI uyumlu sohbet tamamlama (chat completions)

**Destek Güveni**: Desteklenen OpenAI uyumlu sağlayıcı yolu
</Note>

## Ortam

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Temel Ajan

```python
import os

from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "claude-sonnet-5",
    provider=OpenAIProvider(
        base_url="https://api.tokenlab.sh/v1",
        api_key=os.environ["TOKENLAB_API_KEY"],
    ),
)

agent = Agent(model)
result = agent.run_sync("Explain one benefit of OpenAI-compatible gateways.")
print(result.output)
```

## Araçlar

```python
from pydantic_ai import Agent, RunContext

agent = Agent(model)

@agent.tool
def lookup_status(ctx: RunContext[None], service: str) -> str:
    return f"{service} is online"

result = agent.run_sync("Check the TokenLab status.")
print(result.output)
```

## Uç Nokta Notları

Bu yol, Pydantic AI'ın OpenAI Chat Completions model sınıfını hedefler. Responses-native veya sağlayıcıya özgü protokol davranışı için, bu protokolü doğrudan sunan bir istemci yolu seçin.
