## Genel Bakış

LemonData için Vercel AI SDK'deki en kararlı varsayılan seçenek **OpenAI-compatible provider**'dır.

Özellikle **Responses-native** davranışına ihtiyacınız varsa, OpenAI provider'a geçebilir ve aynı LemonData base URL'ini kullanmaya devam edebilirsiniz.

## Önerilen Varsayılan: OpenAI-Compatible Provider

```bash
npm install ai @ai-sdk/openai-compatible
```

```typescript
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

export const lemondata = createOpenAICompatible({
  name: 'lemondata',
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

## Metin Üretme

```typescript
import { generateText } from 'ai';
import { lemondata } from './lemondata';

const { text } = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});

console.log(text);
```

## Metni Akış Olarak Alma

```typescript
import { streamText } from 'ai';
import { lemondata } from './lemondata';

const result = await streamText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Write a short poem about coding.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## Tool Çağırma

```typescript
import { generateText, tool } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const result = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'What is the weather in San Francisco?',
  tools: {
    weather: tool({
      description: 'Get weather in a location',
      parameters: z.object({
        location: z.string(),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72,
        condition: 'sunny',
      }),
    }),
  },
});

console.log(result.text);
```

## Yapılandırılmış Çıktı

```typescript
import { generateObject } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const { object } = await generateObject({
  model: lemondata.chatModel('gpt-5.4'),
  schema: z.object({
    name: z.string(),
    role: z.string(),
  }),
  prompt: 'Generate a fake developer profile.',
});

console.log(object);
```

## Özellikle Responses-Native Davranışına İhtiyacınız Varsa

```bash
npm install ai @ai-sdk/openai
```

```typescript
import { createOpenAI } from '@ai-sdk/openai';

export const lemondataResponses = createOpenAI({
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```typescript
import { generateText } from 'ai';
import { lemondataResponses } from './lemondata-responses';

const { text } = await generateText({
  model: lemondataResponses('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});
```

<Note>
Proxy tarzı entegrasyonlar için güvenli varsayılan olarak `@ai-sdk/openai-compatible` kullanın. Yalnızca `/v1/responses` üzerine kurulu bir provider path'i özellikle istediğinizde `@ai-sdk/openai`'a geçin.
</Note>

## Ortam Değişkenleri

```bash
# .env.local
LEMONDATA_API_KEY=sk-your-lemondata-key
```

## En İyi Uygulamalar

<AccordionGroup>
  <Accordion title="Önce openai-compatible'ı tercih edin">
    Üçüncü taraf gateway'ler ve proxy backend'ler için `@ai-sdk/openai-compatible` genellikle en az sürpriz yaratan başlangıç noktasıdır.
  </Accordion>

  <Accordion title="Yalnızca gerektiğinde Responses'a geçin">
    `/v1/responses` ile ilişkili provider davranışına ihtiyacınız varsa, tek bir client içinde iki yaklaşımı karıştırmak yerine provider package'ını bilinçli olarak değiştirin.
  </Accordion>

  <Accordion title="Gizli bilgileri server tarafında tutun">
    LemonData API key'inizi asla client-side code içinde açığa çıkarmayın. Provider kurulumunu server dosyalarına veya API route'larına yerleştirin.
  </Accordion>
</AccordionGroup>
