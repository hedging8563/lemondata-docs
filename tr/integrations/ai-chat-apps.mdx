## Genel Bakış

Genel amaçlı AI sohbet uygulamalarının çoğu, standart OpenAI uyumlu sohbet yolu üzerinden LemonData'ya bağlanır.

Pratikte bu şu anlama gelir:
- uygulama açıkça tam bir endpoint URL'si istemediği sürece base URL olarak `https://api.lemondata.cc/v1` kullanın
- OpenAI tarzı API key olarak LemonData API key'inizi kullanın
- uygulamanın standart bir sohbet iş akışında kullanabildiği modelleri seçin

<Note>
Genel sohbet uygulamaları genellikle **chat-completions odaklıdır**, Codex Responses WebSocket istemcileri değildir. Responses'a özgü davranışa ihtiyaç duyan Codex CLI/App, Cursor veya diğer kodlama araçları için bunun yerine özel entegrasyon kılavuzlarını kullanın.
</Note>

| OpenCat | iOS, macOS | OpenAI uyumlu özel endpoint akışı |
| ChatWise | Windows, macOS | Standart özel sağlayıcı düzeni |

## Varsayılan Bağlantı Değerleri

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

Bir uygulama base URL yerine **tam bir endpoint URL'si** isterse, şunu kullanın:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## Örnek Uygulama Kurulumları

<Tabs>
  <Tab title="LobeChat">
    **Self-hosted LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. **Settings** → **AI Service Provider** öğesini açın
    2. **OpenAI** seçin
    3. LemonData API key'inizi girin
    4. Özel endpoint'i `https://api.lemondata.cc/v1` olarak ayarlayın
  </Tab>

  <Tab title="Cherry Studio">
    1. **Settings** → **Model Provider** öğesini açın
    2. **OpenAI-compatible** bir sağlayıcı ekleyin
    3. Şunları girin:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. Kullanmak istediğiniz modelleri ekleyin
  </Tab>

  <Tab title="Chatbox">
    1. **Settings** → **AI Model** öğesini açın
    2. **OpenAI API Compatible** seçin
    3. Şunları girin:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` veya `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. **Settings** öğesini açın
    2. **Custom Endpoint** seçin
    3. Şunları girin:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. Sunmak istediğiniz modelleri yapılandırın
  </Tab>
</Tabs>

## İpuçları

<AccordionGroup>
  <Accordion title="Uygulama destekliyorsa base URL'yi tercih edin">
    Çoğu uygulamayı, tam bir endpoint URL'si yerine base URL olarak `https://api.lemondata.cc/v1` verdiğinizde yapılandırmak daha kolaydır ve daha az kırılgandır.
  </Accordion>

  <Accordion title="Önce daha küçük modelleri kullanın">
    Günlük sohbet için `gpt-5-mini` veya `gpt-4o` ile başlayın, ardından daha ağır akıl yürütme görevlerini `gpt-5.4` veya `claude-opus-4-6` modellerine taşıyın.
  </Accordion>

  <Accordion title="Kodlama araçlarını ayrı tutun">
    Genel sohbet uygulamaları ve kodlama ajanları genellikle farklı endpoint davranışlarına ihtiyaç duyar. Codex/Cursor tarzı araçları kendi özel entegrasyon sayfalarında tutun.
  </Accordion>
</AccordionGroup>

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Bağlantı Hatası">
    - base URL'nin tam olarak `https://api.lemondata.cc/v1` olduğunu doğrulayın
    - uygulama yolları otomatik olarak ekliyorsa sondaki eğik çizgileri kaldırın
    - uygulama tam bir endpoint URL'si istiyorsa `https://api.lemondata.cc/v1/chat/completions` kullanın
  </Accordion>

  <Accordion title="401 Unauthorized">
    - API key'inizi tekrar kontrol edin
    - key'in LemonData dashboard'da aktif olduğunu doğrulayın
    - fazladan boşluk veya satır sonu olmadığından emin olun
  </Accordion>

  <Accordion title="Model Kullanılamıyor">
    - model adını birebir doğrulayın
    - `gpt-5-mini`, `gpt-4o` veya `claude-sonnet-4-6` gibi yaygın olarak desteklenen bir varsayılanı deneyin
    - LemonData docs veya dashboard içinde güncel kullanılabilirliği kontrol edin
  </Accordion>
</AccordionGroup>
