## Genel Bakış

LemonData, client'ı `https://api.lemondata.cc/v1` adresine yönlendirerek resmi OpenAI SDK'leri ile çalışır.

Yeni projelerde **Responses API** tercih edin. Bir framework, plugin veya eski kod yolu hâlâ buna ihtiyaç duyuyorsa **Chat Completions**'ı yalnızca o durumda kullanın.

<Note>
Python, JavaScript ve Go için resmi OpenAI SDK'leri vardır. PHP, OpenAI-uyumlu topluluk client'ları ile iyi çalışır, ancak resmi bir OpenAI SDK değildir.
</Note>

## Client'ı Yapılandırın

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## Önerilen: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

## Responses ile Streaming

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Tools / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## Chat Completions Uyumluluğu

Framework'ünüz veya plugin'iniz hâlâ Chat Completions bekliyorsa, LemonData standart OpenAI-uyumlu yolu da destekler:

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
Chat Completions'ı yalnızca uyumluluk için kullanın. Yeni entegrasyonlar için `client.responses.create(...)` tercih edin.
</Warning>

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Bağlantı Hatası">
    - base URL'nin tam olarak `https://api.lemondata.cc/v1` olduğunu doğrulayın
    - Proxy müdahalesi veya özel HTTP client override'ları olup olmadığını kontrol edin
    - Sağlayıcı davranışını debug etmeden önce SDK sürümünüzün güncel olduğundan emin olun
  </Accordion>

  <Accordion title="Kimlik Doğrulama Başarısız">
    - API key'inizin `sk-` ile başladığını kontrol edin
    - Key'in LemonData dashboard'da aktif olduğunu doğrulayın
    - SDK'nin `Authorization: Bearer ...` gönderdiğini onaylayın
  </Accordion>

  <Accordion title="Yanlış API Yolu">
    - `responses.create(...)` istekleri `/v1/responses` adresine gönderir
    - `chat.completions.create(...)` istekleri `/v1/chat/completions` adresine gönderir
    - Uygulamanız bugün yalnızca Chat Completions destekliyorsa, onu bu uyumluluk yolunda tutun
  </Accordion>
</AccordionGroup>
