[TokenLab MCP sunucusu](https://github.com/hedging8563/tokenlab-mcp-server), TokenLab'in herkese açık OpenAPI sözleşmesinden MCP araçları oluşturur. MCP uyumlu ajanlar; modelleri ve fiyatlandırmayı keşfedebilir, OpenAI uyumlu ve yerel LLM uç noktalarını çağırabilir, çok modlu medya oluşturabilir, dosya yükleyebilir ve asenkron görevleri yönetebilir.

Bir ajanın manuel olarak tutulan bir araç listesi yerine güncel TokenLab API sözleşmesine ihtiyaç duyduğu durumlarda kullanın. Varsayılan `core` profili, 29 adet oluşturulmuş uç nokta aracını ve iki adet bileşik keşif aracını kullanıma sunar. `full` profili ise 78 adet oluşturulmuş uç nokta aracını ve aynı iki bileşik aracı kullanıma sunar.

<Note>
Genel katalog ve fiyatlandırma araçları TokenLab API anahtarı gerektirmez. Kimlik doğrulamalı çıkarım (inference), medya, ses, dosya, görev, yerleştirme (embedding), yeniden sıralama (rerank) ve çeviri işlemleri için `TOKENLAB_API_KEY` değerini ayarlayın. API anahtarını asla araç argümanlarına yerleştirmeyin.
</Note>

## Sağladığı Özellikler

- `https://api.tokenlab.sh/v1/models` üzerinden canlı model keşfi.
- `/v1/models/{model}` üzerinden model detay sorgulama.
- `/v1/models/{model}/pricing` üzerinden fiyatlandırma sorgulama.
- `https://api.tokenlab.sh/llms.txt` üzerinden ajan tarafından okunabilir API özeti.
- OpenAI uyumlu Chat Completions ve Responses, Anthropic Messages ve Gemini generateContent; yerel istek yapılarını düzleştirmeden (flattening) destekler.
- JSON URL'leri, TokenLab dosya kimlikleri veya yerel multipart dosyaları aracılığıyla görsel oluşturma ve düzenleme.
- Video, müzik, 3D, konuşma, transkripsiyon, ses çevirisi, yerleştirmeler (embeddings), çok modlu yerleştirmeler, yeniden sıralama ve metin çevirisi.
- Görsel, video, müzik, 3D ve dünya oluşturma işlemleri için normalleştirilmiş asenkron görev özetleri.
- Her gün çalışan ve herkese açık OpenAPI belgesini getiren, araç şemalarını yeniden oluşturan, uç nokta ve dosya testlerini çalıştıran ve yalnızca tüm kontroller başarılı olduğunda `main` dalını güncelleyen bir sözleşme senkronizasyonu.

## GitHub Üzerinden Kurulum

Genel depoyu klonlayın ve bağımlılıkları yükleyin:

```bash
git clone https://github.com/hedging8563/tokenlab-mcp-server.git
cd tokenlab-mcp-server
npm install
npm test
```

Sunucuyu stdio üzerinden başlatın:

```bash
npm start
```

İsteğe bağlı `TOKENLAB_API_BASE` ortam değişkeni varsayılan olarak `https://api.tokenlab.sh` değerindedir. Bir istemcinin varsayılan `core` profili yerine daha geniş geliştirici API'sini kullanması gerektiğinde `TOKENLAB_MCP_TOOL_PROFILE=full` olarak ayarlayın.

`core` ve `full` profilleri varsayılan olarak boyut ve derinliği sınırlandırılmış `portable` araç şemaları yayımlar; sunucu ise her çağrıyı tam OpenAPI sözleşmesine göre doğrular. Tam iç içe şemalar için `TOKENLAB_MCP_SCHEMA_MODE=exact`, kapalı nesneler ve tüm özelliklerin `required` içinde olmasını isteyen provider'lar için `TOKENLAB_MCP_SCHEMA_MODE=strict` kullanın. strict modu karmaşık üst düzey değerleri JSON kodlu dizeler olarak gösterir.

## Herhangi bir stdio MCP istemcisini yapılandırma

Yerel stdio MCP sunucularını destekleyen tüm istemcilerde aynı değerleri kullanın. İstemci bunları form alanları olarak gösterebilir veya JSON, TOML ya da YAML içinde saklayabilir; alanların anlamı değişmez. Her bağımsız değişkeni ayrı bir öğe olarak ekleyin.

| Alan | Değer | Notlar |
|---|---|---|
| Sunucu adı | `tokenlab-model-catalog` | Benzersiz herhangi bir ad kullanılabilir. |
| Taşıma | `stdio` | TokenLab MCP yerel bir alt süreç olarak çalışır. |
| Başlatma komutu | `npx` | Yayımlanmış npm paketini başlatır. |
| Bağımsız değişkenler | `-y`, ardından `@tokenlabai/mcp-server` | Şu anda doğrulanmış sürümü sabitlemek için `@tokenlabai/mcp-server@0.6.15` kullanın. |
| Ortam değişkeni | `TOKENLAB_API_KEY` = `<TOKENLAB_API_KEY>` | Genel katalog araçları için isteğe bağlı, çıkarım ve medya araçları için zorunludur. |
| Ortam değişkeni aktarımı | Boş bırakın veya `TOKENLAB_API_KEY` yazın | Anahtar istemcinin yerel ortamında zaten dışa aktarılmışsa yalnızca değişken adını kullanın. Aynı anahtarı iki yerde birden yapılandırmayın. |
| Çalışma dizini | Boş bırakın | Bu paket için `npx` bir proje dizini gerektirmez. |

`mcpServers` JSON nesnesini kabul eden istemcilere aşağıdaki tam yapılandırmayı kopyalayın:

```json
{
  "mcpServers": {
    "tokenlab-model-catalog": {
      "command": "npx",
      "args": ["-y", "@tokenlabai/mcp-server"],
      "env": {
        "TOKENLAB_API_KEY": "<TOKENLAB_API_KEY>"
      }
    }
  }
}
```

Yalnızca genel model ve fiyatlandırma araçlarına ihtiyacınız varsa `env` bloğunu kaldırın. İstemci `mcpServers` sarmalayıcısı yerine tek bir sunucu nesnesi bekliyorsa yalnızca `command`, `args` ve `env` içeren iç nesneyi kopyalayın.

<Warning>
Gerçek bir API anahtarı içeren ekran görüntülerini, günlükleri veya yapılandırma dosyalarını asla yayımlamayın. Örneklerde yer tutucu kullanın ve açığa çıkan anahtarları hemen iptal edin.
</Warning>

## Codex İçinde Kurulum

Genel katalog sunucusunu Codex yapılandırmanıza ekleyin:

```bash
codex mcp add tokenlab-model-catalog -- npx -y @tokenlabai/mcp-server
```

Sunucuyu ekledikten sonra yeni bir Codex oturumu başlatın. Genel katalog araçları `TOKENLAB_API_KEY` gerektirmez.

Çıkarım (inference) araçlarını etkinleştirmek için sunucuyu eklerken TokenLab API anahtarınızı dahil edin:

```bash
codex mcp add --env TOKENLAB_API_KEY=your-tokenlab-api-key tokenlab-model-catalog -- npx -y @tokenlabai/mcp-server
```

## Cline İçinde Kurulum

Yayınlanmış stdio sunucusunu Cline CLI ile yükleyin:

```bash
cline mcp add tokenlab --yes -- npx -y @tokenlabai/mcp-server
```

Bu komut Cline CLI ile doğrulanmıştır ve kurulum uyarıları olmadan tamamlanır. Genel katalog araçları hemen çalışır; çıkarım araçlarına ihtiyaç duyduğunuzda Cline ortamınızda `TOKENLAB_API_KEY` değerini ayarlayın.

```json
{
  "mcpServers": {
    "tokenlab-model-catalog": {

    }
  }
```

## Cursor, Windsurf ve Diğer MCP İstemcileri

stdio MCP sunucularını destekleyen herhangi bir istemcide aynı komutu ve argümanları kullanın:

```json
{
  "command": "npx",
  "args": ["-y", "@tokenlabai/mcp-server"],
  "env": {
    "TOKENLAB_API_BASE": "https://api.tokenlab.sh"
  }
}
```

İstemciniz adlandırılmış sunucuları saklıyorsa, sunucu adı olarak `tokenlab-model-catalog` kullanın.

## Oluşturulan Araç Profilleri

| Profil | Kullanıma sunulan araçlar | Kapsam |
|---|---:|---|
| `catalog` | 6 | Oluşturulmuş dört genel katalog ve fiyatlandırma aracı ile `compare_models` ve `get_api_overview`. API anahtarı gerekmez. |
| `core` (varsayılan) | 31 | 29 oluşturulmuş uç nokta aracı artı `compare_models` ve `get_api_overview`. Katalog, fiyatlandırma, yerel LLM uç noktaları, görseller, video, müzik, 3D, ses, görevler, dosyalar, yerleştirmeler, yeniden sıralama ve çeviriyi kapsar. |
| `full` | 80 | 78 oluşturulmuş uç nokta aracı artı iki bileşik keşif aracı. Yanıt yaşam döngüsü, yığınlar (batches), dünyalar, yerel model keşfi ve diğer izin verilen geliştirici işlemlerini ekler. |

Araç adları, açıklamalar, girdi şemaları, HTTP yöntemleri, yollar, içerik türleri, kimlik doğrulama gereksinimleri ve görev davranışları, kayıtlı OpenAPI anlık görüntüsünden oluşturulur. Yalnızca MCP'ye özel bir katman; kararlı araç takma adları, profil üyeliği, asenkron görev semantiği, multipart varyantları, gizli veri gizleme ve akış dışı (non-streaming) kısıtlamaları sağlar.

Sürüm 0.6.0 ayrıca MCP `structuredContent` üzerinden JSON döndürür, üç sözleşme kaynağı yayımlar ve model seçimi ile yerel istek oluşturma için iki istem şablonu sunar. Oluşturulan ve bileşik araçlar, uyumlu istemcilerin daha güvenli onay politikaları uygulayabilmesi için standart risk açıklamaları içerir.

Yaygın `core` araçları şunlardır:

| Aile | Temsili araçlar |
|---|---|
| Katalog ve fiyatlandırma | `list_models`, `get_model`, `get_model_pricing`, `get_pricing`, `compare_models` |
| Yerel LLM uç noktaları | `create_chat_completion`, `create_response`, `create_anthropic_message`, `create_gemini_content` |
| Görseller | `create_image`, `create_image_file`, `edit_image`, `edit_image_file` |
| Video, müzik ve 3D | `create_video`, `create_music`, `create_3d_model` |
| Ses | `create_speech`, `transcribe_audio`, `translate_audio` |
| Yerleştirmeler ve metin | `create_embedding`, `create_multimodal_embedding`, `rerank_documents`, `translate_text` |
| Dosyalar ve görevler | `upload_file`, `list_files`, `retrieve_file`, `retrieve_file_content`, `delete_file`, `get_task_status`, `cancel_task` |

MCP araç çağrıları tek bir nihai sonuç döndürür. Yalnızca akış (streaming) ve gerçek zamanlı işlemler hariç tutulur; sunucu desteklenen `stream` argümanlarını provider bağdaştırıcılarına boolean sabiti göstermeden dahili olarak `false` değerine sabitler. Küçük görsel ve ses yanıtları yerel MCP içeriği olarak döndürülür; daha büyük ikili (binary) yanıtlar `TOKENLAB_ARTIFACT_DIR` dizinine yazılır ve yerel yolları, MIME türleri ve bayt sayıları ile döndürülür.

## Asenkron Medya Sonuçları

Video, müzik ve 3D oluşturma işlemleri asenkron görev özetleri döndürür. Görsel oluşturma ve düzenleme işlemleri, seçilen modele ve isteğe bağlı olarak tamamlanmış bir sonuç veya asenkron bir görev döndürebilir.

`delivery.mode` değeri `async` olduğunda, `delivery.terminal` değeri `true` olana kadar `{ "id": delivery.task_id }` ile `get_task_status` fonksiyonunu çağırın. Tamamlanma durumunu `status` alanından belirleyin; `progress` isteğe bağlıdır ve terminal koşulu olarak kullanılmamalıdır.

## Önerilen Ajan İş Akışı

1. Kullanıcı bir model belirtmediğinde `list_models` fonksiyonunu çağırın.
2. Görsel, video, müzik, 3D, TTS, STT, yerleştirmeler, yeniden sıralama veya çeviri gibi sohbet dışı görevler için `recommended_for` fonksiyonunu kullanın.
3. Sohbet dışı bir istek oluşturmadan, başarısız bir isteği yeniden denemeden veya uç nokta aileleri arasında geçiş yapmadan önce `get_model` fonksiyonunu çağırın.
4. Model maliyeti kullanıcının seçimini etkilediğinde `get_model_pricing` fonksiyonunu çağırın.
5. Seçim birkaç aday arasında kaldığında `compare_models` fonksiyonunu kullanın.
6. Gerekli API sözleşmesiyle eşleşen oluşturulmuş aracı çağırın veya TokenLab API ailelerinin kompakt bir haritası için `get_api_overview` fonksiyonunu kullanın.

## Yerel Uç Nokta Rehberi

TokenLab, OpenAI uyumlu rotaları ve yerel uç nokta ailelerini destekler. MCP sunucusu, bir ajan kod yazmadan önce doğru rotayı seçmesine yardımcı olur:

| Aile | Yaygın rota |
|---|---|
| OpenAI uyumlu sohbet | `/v1/chat/completions` |
| Yanıtlar | `/v1/responses` |
| Anthropic Messages | `/v1/messages` |
| Gemini yerel | `/v1beta/models/{model}:generateContent` |
| Görseller | `/v1/images/generations`, `/v1/images/edits` |
| Video | `/v1/videos/generations` |
| Müzik | `/v1/music/generations` |
| 3D | `/v1/3d/generations` |
| Ses | `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/audio/translations` |
| Yerleştirmeler ve yeniden sıralama | `/v1/embeddings`, `/v1/rerank` |
| Metin çevirisi | `/v1/translations` |

## Barındırılan Model Gezgini

Streamable HTTP destekleyen istemciler şuraya bağlanabilir:

```text
https://tokenlab-model-explorer.vercel.app/mcp
```

Barındırılan gezgin herkese açıktır ve `open_tokenlab_model_explorer`, `compare_tokenlab_models` ve `generate_tokenlab_endpoint_example` araçlarını kullanıma sunar. Oluşturulan core/full profillerine, yerel dosya yüklemelerine veya kimlik doğrulamalı API işlemlerine ihtiyaç duyduğunuzda yukarıdaki yerel npm sunucusunu kullanın.

## TokenLab Yetenekleri (Skills) ile Kullanım

MCP sunucusu çalışma zamanında yararlıyken, [TokenLab yetenekleri deposu](https://github.com/hedging8563/tokenlab-skills), kodlama ajanlarına entegrasyon kodunu nasıl oluşturacaklarını ve onaracaklarını öğretir.

Mümkün olduğunda her ikisini de kullanın:

- MCP sunucusu: güncel modelleri, fiyatlandırmayı ve uç nokta detaylarını keşfedin.
- `tokenlab-api-integration` yeteneği: çalıştırılabilir API örnekleri oluşturun ve yapılandırılmış TokenLab hatalarını yönetin.
- `tokenlab-model-picker` yeteneği: kullanıcının görevi için güçlü modeller seçin.
- `tokenlab-native-endpoints` yeteneği: Responses, Anthropic Messages, Gemini, medya, ses, yerleştirme, yeniden sıralama veya çeviri rotalarının ne zaman kullanılacağına karar verin.
