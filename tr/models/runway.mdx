## Genel Bakış

LemonData, Higgsfield AI modellerine erişim sağlar. Toplam: **3 model** mevcut.

## Sohbet Modelleri

| Model ID | Fiyatlandırma |
|----------|--------|
| `higgsfield-lite` | Paneli inceleyin |
| `higgsfield-standard` | Paneli inceleyin |
| `higgsfield-turbo` | Paneli inceleyin |


## Kullanım

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="higgsfield-lite",
    messages=[{"role": "user", "content": "Hello!"}]
)
```
