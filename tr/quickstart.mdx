## Adım 1: API Anahtarınızı Alın

<Steps>
  <Step title="Bir hesap oluşturun">
    E-posta, Gmail veya GitHub hesabınızı kullanarak [lemondata.cc](https://lemondata.cc) üzerinden kaydolun.
  </Step>
  <Step title="Kredi ekleyin">
    Kontrol panelini açın ve hesabınıza kredi ekleyin. LemonData, minimum taahhüt olmadan kullandıkça öde fiyatlandırması kullanır.
  </Step>
  <Step title="Bir API anahtarı oluşturun">
    **Dashboard → API Keys** bölümüne gidin ve yeni bir anahtar oluşturun. Yalnızca bir kez gösterildiği için güvenli bir şekilde kopyalayın.
  </Step>
</Steps>

<Warning>
API anahtarınızı güvende tutun. Bunu asla client-side kodda veya herkese açık depolarda açığa çıkarmayın.
</Warning>

## Adım 3: İlk İsteğinizi Yapın

Yeni projeler için **Responses API** ile başlayın.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
Framework veya aracınız hâlâ Chat Completions bekliyorsa, LemonData `POST /v1/chat/completions` desteği de sunar. Yeni entegrasyonlar için `POST /v1/responses` tercih edin.
</Note>

## Farklı Modelleri Deneyin

LemonData 300'den fazla modeli destekler. Yalnızca `model` alanını değiştirin:

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## Streaming Etkinleştirin

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
