| **Görü** | Görsel anlama ve çok modlu sohbet | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |

| **Müzik** | AI müzik üretimi | `suno` |

## İyi Bir Varsayılan Başlangıç Noktası

Yeni projeler için OpenAI SDK ile birlikte **Responses API** kullanarak başlayın:

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```
