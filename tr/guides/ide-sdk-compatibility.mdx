## Genel Bakış

TokenLab, yaygın kodlama araçlarının, SDK'ların ve framework'lerin minimum "glue code" (yapıştırıcı kod) ile entegre olabilmesi için birden fazla API formatı sunar.

Bu sayfa, bir pazarlama matrisinden ziyade teknik bir rehber olması amacıyla hazırlanmıştır:

- **Destekleniyor (Supported)**: Somut bir kurulum yolunu belgelediğimiz ve TokenLab'in bu yolun beklediği protokol yapısını sunduğu anlamına gelir.
- **Güçlü yerel yol (Strong native path)**: Deponun ayrıca o protokol ailesi için doğrudan adaptör veya istek formatı kanıtına sahip olduğu anlamına gelir.
- **En iyi çaba (Best-effort)**: Entegrasyonun çalışabileceği, ancak yukarı yönlü istemcinin bu özel ağ geçidi iş akışını kararlı bir sözleşme olarak görmediği anlamına gelir.

<Note>
  Desteklenmeyen alanlar tek tip bir şekilde ele alınmaz. Uyumluluk rotalarında bazı alanlar göz ardı edilir veya normalleştirilir. `/v1/responses` üzerinde, desteklenmeyen alanlar, rotanın talep edilen davranışı garanti edemediği durumlarda açık `400` veya `503` hataları döndürebilir.
</Note>

## Desteklenen API Formatları

| Uç Nokta (Endpoint) | Format | Kullanım Durumu |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | Evrensel uyumluluk |
| `/v1/responses` | OpenAI Responses | Durum bilgisi olan (stateful) konuşmalar |
| `/v1/messages` | Anthropic Messages | Claude yerel özellikleri |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini yerel özellikleri |

## IDE & CLI Uyumluluğu

### Belgelenmiş Araç Yolları

| Araç | Destek Seviyesi | Format | Notlar |
|------|---------------|--------|-------|
| **Cursor** | Sınırlı destek | OpenAI uyumlu | BYOK standart sohbet/editör akışları için çalışır, Tab Completion gibi Cursor tarafından yönetilen özelliklerin yerine geçmez |
| **Claude Code CLI** | Güçlü yerel yol | Anthropic | Düşünme (thinking) ve `tool_choice` için adaptör kapsamına sahip yerel `/v1/messages` rotası |
| **Codex CLI** | Model/yol sınırlamalarıyla desteklenir | OpenAI Responses | `/v1/responses` rotasını Codex'e özgü iş akışları için gelişmiş bir yol olarak değerlendirin; yalnızca Responses'a özel bazı alanlar her model ve rotada garanti edilmez |
| **Gemini CLI** | En iyi çaba / deneysel | Gemini | Özel TokenLab temel URL akışı, resmi bir Gemini CLI entegrasyonu değildir |
| **OpenCode** | Destekleniyor | OpenAI uyumlu | Varsayılan olarak OpenAI uyumlu bir sağlayıcı kullanın; yalnızca açıkça ihtiyaç duyduğunuzda Responses tabanlı bir sağlayıcıya geçin |

<Note>
  Diğer OpenAI uyumlu editörler ve aracı (agent) araçları genellikle aynı temel URL yapısıyla çalışır; üretim ortamında kullanmadan önce aracın kendi özel sağlayıcı desteğini kontrol edin.
</Note>

## SDK Uyumluluğu

### Belgelenmiş SDK & Framework Yolları

| SDK / Framework | Dil | Destek Seviyesi | Notlar |
|-----------------|----------|---------------|-------|
| **OpenAI SDK** | Python/JS/Go | Desteklenen temel yol | `/v1` Chat Completions ve Embeddings için uyumluluk yolu; sağlayıcıya özgü davranışlar için yerel sağlayıcı rotalarını kullanın ve Responses'a özel alanların her modelde çalıştığını varsaymayın |
| **Anthropic SDK** | Python/JS | Güçlü yerel yol | Araçlar, düşünme ve istem önbelleğe alma (prompt caching) için doğrudan kanıt içeren yerel Messages rotası |
| **Vercel AI SDK** | TypeScript | Önerilen entegrasyon modeli | `@ai-sdk/openai-compatible` tercih edin; yalnızca açıkça Responses-native davranış istediğinizde `@ai-sdk/openai` kullanın |
| **LangChain** | Python/JS | Desteklenen standart yüzeyler | `ChatOpenAI` ve `OpenAIEmbeddings` hedeflenen kapsamdır; satıcıya özgü ekstralar kapsam dışıdır |
| **LlamaIndex** | Python | `OpenAILike` ile desteklenir | TokenLab gibi üçüncü taraf ağ geçitleri için yerleşik OpenAI sınıflarını değil, `OpenAILike` kullanın |
| **OpenAI Agents SDK** | Python | Desteklenen chat-completions yolu | `OpenAIChatCompletionsModel` ile `AsyncOpenAI(base_url="https://api.tokenlab.sh/v1")` kullanın; yerel Responses davranışı seçilen modele ve rotaya bağlıdır |
| **Langflow** | Python / Web | Kapsam sınırlamalarıyla desteklenir | OpenAI bileşeninin **OpenAI API Base** alanını TokenLab'in `/v1` uç noktasıyla kullanın |
| **Dify** | - | Kapsam sınırlamalarıyla desteklenir | OpenAI sağlayıcısı ve chat-completions odaklı akışlar hedeflenen yoldur; Codex'e özgü Responses veya WebSocket davranışı için uygun değildir |
| **Flowise** | Web / Node | Kapsam sınırlamalarıyla desteklenir | Mümkünse TokenLab sohbet düğümünü veya `https://api.tokenlab.sh/v1` adresine yönlendirilmiş ChatOpenAI uyumlu bir düğüm kullanın |
| **Agno** | Python | Desteklenen yol | Mümkünse TokenLab model sarmalayıcısını (wrapper) veya OpenAI uyumlu temel URL yolunu kullanın |
| **Promptfoo** | CLI / Node | Desteklenen yol | `apiBaseUrl: https://api.tokenlab.sh/v1` ile OpenAI sohbet veya Responses sağlayıcılarını kullanın |
| **Portkey Gateway** | Gateway | Desteklenen yol | OpenAI uyumlu sohbet ve Responses trafiği için TokenLab'i yukarı yönlü sağlayıcı olarak kullanın |
| **Helicone** | Gateway / Observability | Desteklenen gözlemlenebilirlik yolu | `Helicone-Target-Url: https://api.tokenlab.sh` ile OpenAI uyumlu istekleri Helicone Gateway üzerinden yönlendirin |
| **LangBot** | Bot Platformu | Desteklenen sohbet yolu | Mümkünse TokenLab isteyicisini kullanın veya TokenLab'in `/v1` uç noktasıyla OpenAI uyumlu bir isteyici yapılandırın |
| **Open WebUI** | Web Chat | Desteklenen sohbet uygulaması yolu | TokenLab'i OpenAI uyumlu bir API bağlantısı olarak ekleyin ve model listesini yenileyin |
| **Chatbox / DeepChat / Jan / LibreChat / Cherry Studio** | Masaüstü / Web | Desteklenen sohbet uygulaması yolu | Her uygulamanın OpenAI uyumlu özel sağlayıcı akışını kullanın; bu uygulamalar genellikle chat-completions odaklıdır |

## Chat Completions Parametreleri

### Temel Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `model` | string | Model tanımlayıcısı (gerekli) |
| `messages` | array | Konuşma mesajları (gerekli) |
| `max_tokens` | integer | Maksimum çıktı token sayısı |
| `temperature` | number | Örnekleme sıcaklığı (0-2) |
| `top_p` | number | Nucleus örnekleme (0-1) |
| `stream` | boolean | Akışı (streaming) etkinleştir |

### Araç Çağırma (Tool Calling)

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Bir konum için hava durumunu al",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Araç Seçim Seçenekleri

| Format | Örnek | Açıklama |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | Basit seçim |
| OpenAI Nesnesi | `{ "type": "function", "function": { "name": "fn" } }` | Belirli fonksiyonu zorla |
| Anthropic Nesnesi | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic yerel formatı |

### Gelişmiş Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `stream_options` | object | Yalnızca Chat Completions: Token sayıları için `{ include_usage: true }` |
| `reasoning_effort` | string | Akıl yürütme özellikli GPT-5 modelleri için `"low"`, `"medium"`, `"high"` |
| `service_tier` | string | `"auto"` veya `"default"` |
| `seed` | integer | Belirleyici (deterministik) çıktılar |
| `logprobs` | boolean | Log olasılıklarını döndür |
| `top_logprobs` | integer | En iyi log olasılıklarının sayısı (0-20) |
| `logit_bias` | object | Token sapma haritası (-100 ila 100) |
| `frequency_penalty` | number | Tekrar cezası (-2 ila 2) |
| `presence_penalty` | number | Konu cezası (-2 ila 2) |
| `stop` | string/array | Durdurma dizileri |
| `n` | integer | Tamamlama sayısı (1-128) |
| `user` | string | Takip için kullanıcı tanımlayıcısı |

### OpenAI Gelişmiş Özellikleri

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `modalities` | array | Çok modlu (multimodal) için `["text", "audio"]` |
| `audio` | object | Ses çıkış yapılandırması (ses, format) |
| `prediction` | object | Daha hızlı tamamlama için tahmin edilen çıktı |
| `metadata` | object | Takip için anahtar-değer çiftleri |
| `store` | boolean | Daha sonra geri almak için sakla |

### Sağlayıcıya Özgü Seçenekler

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Anthropic Messages Parametreleri

### Temel Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `model` | string | Model tanımlayıcısı |
| `messages` | array | Konuşma mesajları |
| `max_tokens` | integer | Maksimum çıktı (128000'e kadar) |
| `system` | string/array | Sistem istemi (prompt) |
| `stream` | boolean | Akışı etkinleştir |

### Araç Çağırma

```json
{
  "tools": [
    {
      "name": "get_weather",
      "description": "Hava durumunu al",
      "input_schema": {
        "type": "object",
        "properties": {
          "location": { "type": "string" }
        }
      }
    }
  ],
  "tool_choice": {
    "type": "auto",
    "disable_parallel_tool_use": false
  }
}
```

### Genişletilmiş Düşünme (Extended Thinking)

```json
{
  "model": "claude-opus-4-6",
  "thinking": {
    "type": "enabled",
    "budget_tokens": 10000
  }
}
```

## Responses API Parametreleri

### Temel Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `model` | string | Model tanımlayıcısı |
| `input` | string/array | Girdi içeriği |
| `instructions` | string | Sistem talimatları |
| `max_output_tokens` | integer | Maksimum çıktı token sayısı |
| `previous_response_id` | string | Konuşmayı devam ettir |

### Gelişmiş Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` veya `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | Akıl yürütme modelleri için |
| `service_tier` | string | Öncelik katmanı |

### Araç Formatı

Hem OpenAI hem de Anthropic araç formatlarını destekler:

```json
// OpenAI formatı
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic formatı (Cursor uyumluluğu)
{ "name": "fn", "input_schema": {...} }
```

## Gemini API Parametreleri

### Temel Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `contents` | array | Konuşma içeriği |
| `systemInstruction` | object | Sistem istemi |
| `generationConfig` | object | Oluşturma ayarları |

### Araçlar

```json
{
  "tools": [{
    "functionDeclarations": [{
      "name": "search",
      "description": "Web'de ara",
      "parameters": {...}
    }],
    "codeExecution": {},

  }],
  "toolConfig": {
    "functionCallingConfig": {
      "mode": "AUTO"
    }
  }

```

### Güvenlik Ayarları

```json
{
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_MEDIUM_AND_ABOVE"
    }
  ]
}
```

### Ek Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `cachedContent` | string | Önbelleğe alınmış içerik referansı |
| `responseMimeType` | string | `"text/plain"` veya `"application/json"` |
| `responseSchema` | object | Yapılandırılmış çıktı için JSON şeması |

## Akış (Streaming)

Chat Completions ve Responses dahil olmak üzere `stream: true` değerini sunan oluşturma uç noktaları, Server-Sent Events (SSE) kullanır:

```bash
# Chat Completions
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# Chat Completions kullanım takibi
-d '{"...", "stream_options": {"include_usage": true}}'
```

## Hata Yönetimi

TokenLab, OpenAI uyumlu hata yanıtları döndürür:

```json
{
  "error": {
    "message": "Geçersiz API anahtarı",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

Ayrıntılar için [Hata Yönetimi Rehberi](/guides/error-handling) bölümüne bakın.
