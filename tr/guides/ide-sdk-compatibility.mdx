## Genel Bakış

LemonData API, tüm büyük AI geliştirme araçlarıyla **doğrudan uyumluluk** sağlayacak şekilde tasarlanmıştır. Bu rehber, desteklenen parametreleri ve doğrulanmış entegrasyonları belgeler.

<Note>
  Tüm parametreler doğrulanır ancak upstream sağlayıcılara aktarılır. Belirli modeller için desteklenmeyen parametreler sessizce yok sayılır; bu da maksimum uyumluluk sağlar.
</Note>

## Desteklenen API Formatları

| Endpoint | Format | Kullanım Durumu |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | Evrensel uyumluluk |
| `/v1/responses` | OpenAI Responses | Durum bilgili konuşmalar |
| `/v1/messages` | Anthropic Messages | Claude yerel özellikleri |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini yerel özellikleri |

## Chat Completions Parametreleri

### Temel Parametreler

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Model tanımlayıcısı (gerekli) |
| `messages` | array | Konuşma mesajları (gerekli) |
| `max_tokens` | integer | Maksimum çıktı token sayısı |
| `temperature` | number | Örnekleme sıcaklığı (0-2) |
| `top_p` | number | Nucleus sampling (0-1) |
| `stream` | boolean | Streaming'i etkinleştirir |

### Tool Calling

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tool Choice Seçenekleri

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | Basit seçim |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | Belirli bir function'ı zorunlu kılar |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic yerel formatı |

### Gelişmiş Parametreler

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | Token sayıları için `{ include_usage: true }` |
| `reasoning_effort` | string | Akıl yürütme etkin GPT-5 modelleri için `"low"`, `"medium"`, `"high"` |
| `service_tier` | string | `"auto"` veya `"default"` |
| `seed` | integer | Deterministik çıktılar |
| `logprobs` | boolean | Log olasılıklarını döndürür |
| `top_logprobs` | integer | En yüksek logprob sayısı (0-20) |
| `logit_bias` | object | Token bias haritası (-100 ila 100) |
| `frequency_penalty` | number | Tekrar cezası (-2 ila 2) |
| `presence_penalty` | number | Konu cezası (-2 ila 2) |
| `stop` | string/array | Durdurma dizileri |
| `n` | integer | Completion sayısı (1-128) |
| `user` | string | İzleme için kullanıcı tanımlayıcısı |

### OpenAI Gelişmiş Özellikleri

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | Multimodal için `["text", "audio"]` |
| `audio` | object | Ses çıktısı yapılandırması (voice, format) |
| `prediction` | object | Daha hızlı completion için tahmin edilen çıktı |
| `metadata` | object | İzleme için anahtar-değer çiftleri |
| `store` | boolean | Daha sonra erişmek üzere saklar |

### Sağlayıcıya Özel Seçenekler

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Responses API Parametreleri

### Temel Parametreler

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Model tanımlayıcısı |
| `input` | string/array | Girdi içeriği |
| `instructions` | string | Sistem talimatları |
| `max_output_tokens` | integer | Maksimum çıktı token sayısı |
| `previous_response_id` | string | Konuşmayı sürdürür |

### Gelişmiş Parametreler

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` veya `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | Akıl yürütme modelleri için |
| `service_tier` | string | Öncelik katmanı |

### Tool Formatı

Hem OpenAI hem de Anthropic tool formatlarını destekler:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## Gemini API Parametreleri

### Temel Parametreler

| Parameter | Type | Description |
|-----------|------|-------------|
| `contents` | array | Konuşma içeriği |
| `systemInstruction` | object | System prompt |
| `generationConfig` | object | Üretim ayarları |

### Araçlar

```json
{
  "tools": [{
    "functionDeclarations": [{
      "name": "search",
      "description": "Search the web",
      "parameters": {...}
    }],
    "codeExecution": {},
    "googleSearch": {}
  }],
  "toolConfig": {
    "functionCallingConfig": {
      "mode": "AUTO"
    }
  }
}
```

### Güvenlik Ayarları

```json
{
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_MEDIUM_AND_ABOVE"
    }
  ]
}
```

### Ek Parametreler

| Parameter | Type | Description |
|-----------|------|-------------|
| `cachedContent` | string | Önbelleğe alınmış içerik referansı |
| `responseMimeType` | string | `"text/plain"` veya `"application/json"` |
| `responseSchema` | object | Yapılandırılmış çıktı için JSON schema |

## Streaming

Tüm endpoint'ler Server-Sent Events (SSE) streaming'i destekler:

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## Hata Yönetimi

LemonData, OpenAI uyumlu hata yanıtları döndürür:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

Ayrıntılar için [Hata Yönetimi Rehberi](/guides/error-handling) bölümüne bakın.

## En İyi Uygulamalar

<AccordionGroup>
  <Accordion title="Bilinmeyen parametreler için passthrough kullanın">
    Tüm şemalar `.passthrough()` kullanır - bilinmeyen parametreler upstream sağlayıcılara iletilir.
  </Accordion>

  <Accordion title="Doğru faturalandırma için stream_options tercih edin">
    Streaming yanıtlarında doğru token sayıları için `stream_options.include_usage` seçeneğini etkinleştirin.
  </Accordion>

  <Accordion title="Uygun tool_choice formatını kullanın">
    SDK'nızın beklediği formatla eşleştirin. LemonData hem OpenAI hem de Anthropic formatlarını kabul eder.
  </Accordion>
</AccordionGroup>
