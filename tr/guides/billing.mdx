## Genel Bakış

LemonData **kullandıkça öde fiyatlandırması** kullanır. Abonelik veya minimum taahhüt olmadan yalnızca kullandığınız kadar ödersiniz.

## Faturalandırma Nasıl Çalışır

1. Hesabınıza **kredi ekleyin**
2. **API'yi kullanın** - maliyetler her istek için düşülür
3. Kontrol panelinizde **kullanımı izleyin**
4. Bakiyeniz düştüğünde **yükleme yapın**

### Async Task Faturalandırması (Video/Müzik/3D)

<Warning>
  **Önemli**: Video, müzik ve 3D üretim görevleri **tamamlandığında değil**, **gönderim anında faturalandırılır**.
</Warning>

Async üretim görevleri için (video, müzik, 3D modeller):

1. Görevi gönderdiğiniz anda **faturalandırma hemen gerçekleşir**
2. Durum sorguları için dönen `poll_url` değerini izleyin ve `task_id` alanını asenkron görev kimliği olarak değerlendirin
3. Görev başarısız olursa **otomatik iade yapılmaz**

Bunun nedeni, üst sağlayıcıların görev gönderildiğinde, sonuçtan bağımsız olarak bizden ücret almasıdır. Görev hataları yaşarsanız, yardım için lütfen support@lemondata.cc ile iletişime geçin.

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

poll_url = response.json()["poll_url"]
task_id = response.json()["task_id"]
# Durum için poll_url adresini sorgulayın...
```

## Token Sayımı

Token'lar, metin işlemenin temel birimleridir:

- ~4 karakter = 1 token (İngilizce)
- ~1-2 karakter = 1 token (Çince)
- 1 görsel = boyuta ve ayrıntı düzeyine göre değişir

### Token Tahmini

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## Kullanım Takibi

### Kontrol Paneli

Kullanımınızı [Dashboard](https://lemondata.cc/dashboard) üzerinden izleyin:

- Gerçek zamanlı bakiye
- Modele göre kullanım geçmişi
- Maliyet dökümü
- API key kullanımı

### API Yanıtı

Her yanıt kullanım bilgilerini içerir:

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Düşük Bakiye Uyarıları

Bakiyeniz düştüğünde uyarılar yapılandırın:

1. **Dashboard → Settings → Notifications** bölümüne gidin
2. Eşik tutarınızı belirleyin
3. E-posta bildirimleri alın

## Kredi Ekleme

### Ödeme Yöntemleri

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### Adımlar

1. [Dashboard](https://lemondata.cc/dashboard) üzerinde oturum açın
2. **Add Credits** seçeneğine tıklayın
3. Tutarı ve ödeme yöntemini seçin
4. Ödemeyi tamamlayın

Krediler, ödeme onayından hemen sonra eklenir.

## API Key Limitleri

Bireysel API key'ler için harcama limitleri belirleyebilirsiniz:

1. **Dashboard → API Keys** bölümüne gidin
2. Düzenlemek için bir key'e tıklayın
3. **Usage Limit** ayarlayın

Limite ulaşıldığında, o key ile yapılan istekler `402 Payment Required` döndürür.

## Faturalar

İşletme hesapları için faturalar kullanılabilir:

1. **Dashboard → Billing** bölümüne gidin
2. İşlem geçmişini görüntüleyin
3. Faturaları PDF olarak indirin

## Sorular?

Faturalandırma ile ilgili sorular için support@lemondata.cc ile iletişime geçin.
