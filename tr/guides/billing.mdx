## Genel Bakış

LemonData **kullandıkça öde fiyatlandırması** kullanır. Abonelik veya minimum taahhüt olmadan yalnızca kullandığınız kadar ödersiniz.

## Faturalandırma Nasıl Çalışır

1. Hesabınıza **kredi ekleyin**
2. **API'yi kullanın** - maliyetler istek başına düşülür
3. Panelinizden **kullanımı izleyin**
4. Bakiyeniz azaldığında **yükleme yapın**

### Asenkron Görev Faturalandırması (Video/Müzik/3D ve Bazı Görüntü Modelleri)

<Warning>
  **Önemli**: Video, müzik ve 3D oluşturma görevleri tamamlandığında değil, **gönderim anında faturalandırılır**. Bazı görüntü modelleri de görev tabanlı yanıtlar döndürebilir ve bu durumda aynı şekilde değerlendirilmelidir.
</Warning>

Görev tabanlı oluşturma akışları için (video, müzik, 3D ve bazı görüntü modelleri):

1. Görevi gönderdiğinizde **faturalandırma anında gerçekleşir**
2. Durum kontrolleri için döndürülen `poll_url` yolunu izleyin ve `task_id` değerini asenkron görev kimliği olarak kabul edin
3. Görev başarısız olursa **otomatik iade yapılmaz**

Bunun nedeni, üst sağlayıcıların sonuçtan bağımsız olarak görev gönderildiğinde bizi ücretlendirmesidir. Görev hataları yaşarsanız, yardım için lütfen support@lemondata.cc adresiyle iletişime geçin.

```python
# Örnek: Video oluşturma faturalandırması
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ Video hazır olduğunda değil, ŞİMDİ faturalandırılırsınız

poll_url = response.json()["poll_url"]
task_id = response.json()["task_id"]
# Durum için poll_url'i sorgulayın...

### Faturalama işlem ID’leri

Ücretlendirilen ve streaming olmayan JSON yanıtları, mutabakat yanıt tamamlanmadan önce bittiyse `billing_transaction_id` içerir. Aynı değer tarayıcı ve sunucu entegrasyonları için `X-Billing-Transaction-ID` yanıt header’ı olarak da sunulur. Asenkron medya görevleri için dönen `poll_url` değerini veya `GET /v1/tasks/{id}` yolunu sorgulayın; mutabakat tamamlandığında görev yanıtı `billing_transaction_id` içerir. Streaming yanıtları stream gönderildikten sonra mutabakata bağlanabilir; header yoksa mutabakat için dashboard kullanım kayıtlarını kullanın.

## Token Sayımı

Token'lar, metin işlemenin temel birimleridir:

- ~4 karakter = 1 token (İngilizce)
- ~1-2 karakter = 1 token (Çince)
- 1 görüntü = boyuta ve detaya göre değişir

### Token Tahmini

```python
# Kaba tahmin
def estimate_tokens(text):
    return len(text) / 4  # İngilizce için yaklaşık

# Gerçek sayı (OpenAI modelleri için)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Metniniz buraya")
print(f"Token sayısı: {len(tokens)}")
```

## Kullanım Takibi

### Panel

Kullanımınızı [Panel](https://lemondata.cc/dashboard) üzerinden izleyin:

- Gerçek zamanlı bakiye
- Modele göre kullanım geçmişi
- Maliyet dökümü
- API anahtarı kullanımı

### API Yanıtı

Her yanıt kullanım bilgilerini içerir:

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Düşük Bakiye Uyarıları

Bakiyeniz düştüğünde uyarıları yapılandırın:

1. **Panel → Ayarlar → Bildirimler** bölümüne gidin
2. Eşik tutarınızı belirleyin
3. E-posta bildirimleri alın

## Kredi Ekleme

### Ödeme Yöntemleri

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### Adımlar

1. [Panel](https://lemondata.cc/dashboard) hesabınıza giriş yapın
2. **Kredi Ekle** seçeneğine tıklayın
3. Tutarı ve ödeme yöntemini seçin
4. Ödemeyi tamamlayın

Krediler, ödeme onayından sonra anında eklenir.

## API Anahtarı Limitleri

Bireysel API anahtarları üzerinde harcama limitleri belirleyebilirsiniz:

1. **Panel → API Anahtarları** bölümüne gidin
2. Düzenlemek için bir anahtara tıklayın
3. **Kullanım Limiti** belirleyin

Limite ulaşıldığında, o anahtarla yapılan istekler `402 Payment Required` hatası döndürecektir.

## Faturalar

Kurumsal hesaplar için faturalar mevcuttur:

1. **Panel → Faturalandırma** bölümüne gidin
2. İşlem geçmişini görüntüleyin
3. Faturaları PDF olarak indirin
