## Genel Bakış

LemonData, 11 sağlayıcının video oluşturma modellerine tek ve birleşik bir API üzerinden erişim sağlar. Video oluşturma **asenkron**dur — bir istek gönderirsiniz, bir görev kimliği ve `poll_url` alırsınız, ardından sonuç için sorgulama yaparsınız.

<Info>
Model listesi sık sık güncellenir. Mevcut en güncel modeller ve fiyatlandırma için [Models page](https://lemondata.cc/tr/models) sayfasını ziyaret edin veya [Models API](/api-reference/models/list-models) kullanın.
</Info>

<Warning>
Audio behavior is model-dependent. In LemonData, Veo 3 family requests default to audio-on when `output_audio` is omitted. Some models are silent by default or silent-only. For passthrough-governed models, pass `output_audio=true` to make a best-effort upstream audio request.
</Warning>


### Asenkron İş Akışı

```mermaid
sequenceDiagram
    participant Client
    participant LemonData
    participant Provider

    Client->>LemonData: POST /v1/videos/generations
    LemonData->>Provider: Forward request
    Provider-->>LemonData: task_id + pending
    LemonData-->>Client: { task_id, poll_url, status: "pending" }

    loop Poll every 5-10s
        Client->>LemonData: GET poll_url
        LemonData->>Provider: Query status
        Provider-->>LemonData: Status update
        LemonData-->>Client: { status, video_url? }
    end
```

<CodeGroup>

```python Python
import requests
import time

API_KEY = "sk-your-api-key"
BASE = "https://api.lemondata.cc/v1"
headers = {"Authorization": f"Bearer {API_KEY}"}

# Step 1: Submit generation request
resp = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
create_data = resp.json()
task_id = create_data["task_id"]
poll_url = create_data["poll_url"]

# Step 2: Poll for result
while True:
    status = requests.get(f"https://api.lemondata.cc{poll_url}", headers=headers).json()
    if status["status"] in ("completed", "succeeded"):
        print(f"Video URL: {status['video_url']}")
        break
    elif status["status"] == "failed":
        print(f"Failed: {status.get('error')}")
        break
    time.sleep(10)
```

```javascript JavaScript
const API_KEY = 'sk-your-api-key';
const BASE = 'https://api.lemondata.cc/v1';
const headers = { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' };

// Step 1: Submit
const { task_id, poll_url } = await fetch(`${BASE}/videos/generations`, {
  method: 'POST', headers,
  body: JSON.stringify({
    model: 'sora-2',
    prompt: 'A calm cinematic shot of a cat walking through a sunlit garden.',
    operation: 'text-to-video',
    duration: 4,
    aspect_ratio: '16:9'
  })
}).then(r => r.json());

// Step 2: Poll
const poll = setInterval(async () => {
  const status = await fetch(`https://api.lemondata.cc${poll_url}`, { headers }).then(r => r.json());
  if (['completed', 'succeeded'].includes(status.status)) {
    console.log('Video URL:', status.video_url);
    clearInterval(poll);
  } else if (status.status === 'failed') {
    console.error('Failed:', status.error);
    clearInterval(poll);
  }
}, 10000);
```

### Yetenek Tanımları

- **T2V (Text-to-Video)**: Bir metin prompt'undan video oluşturma
- **I2V (Image-to-Video)**: Statik bir görseli videoya dönüştürme. En geniş uyumluluk için herkese açık bir `image_url` sağlayın.
- **Keyframe**: `start_image` + `end_image` ile başlangıç ve bitiş karelerini kontrol etme
- **Extension**: Mevcut bir videonun süresini uzatma
- **Editing**: Mevcut bir videonun belirli yönlerini değiştirme

## Kullanım Örnekleri

### Text-to-Video (T2V)

En yaygın kullanım senaryosu. Tüm modeller bunu destekler.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
```

### Image-to-Video (I2V)

Statik bir görseli canlandırın. Video modelleri arasında en geniş uyumluluk için kaynak görseli barındırın ve `image_url` geçin.

```python
# Using image URL
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/portrait.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)

```

### Keyframe Kontrolü (Başlangıç + Bitiş Görseli)

Hassas geçişler için hem ilk hem de son kareyi kontrol edin. Şu anda Seedance 2.0 tarafından desteklenmektedir.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night, city lights gradually turning on",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/city-day.jpg",
        "end_image": "https://example.com/city-night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```

### Video Uzatma

Mevcut bir videonun süresini uzatın. Uzatma yeteneğine sahip modelleri kullanın.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "kling-video-extend",
        "prompt": "Continue the scene naturally",
        "image_url": "https://example.com/last-frame.jpg"
    }
)
```

## Parametre Referansı

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Model kimliği (varsayılan: `sora-2`) |
| `prompt` | string | **Gerekli.** Videonun metinsel açıklaması |
| `image_url` | string | Başlangıç görselinin URL'si (I2V için) |
| `image` | string | Data URL olarak satır içi görsel. Uyumlu modeller tarafından desteklenir, ancak `image_url` en geniş uyumluluğu sağlar. |
| `duration` | integer | Video süresi saniye cinsinden (1-60, modele bağlı) |
| `aspect_ratio` | string | `16:9`, `9:16`, `1:1`, vb. |
| `resolution` | string | `1080p`, `720p`, `4k` |
| `fps` | integer | Saniye başına kare sayısı (1-120) |
| `negative_prompt` | string | Oluşturma sırasında kaçınılması gerekenler |
| `seed` | integer | Yeniden üretilebilirlik için rastgele seed |
| `cfg_scale` | number | Yönlendirme ölçeği (0-20) |
| `motion_strength` | number | Hareket yoğunluğu (0-1) |
| `start_image` | string | Başlangıç keyframe'inin URL'si |
| `end_image` | string | Bitiş keyframe'inin URL'si |

<Warning>
Tüm parametreler her model tarafından desteklenmez. Desteklenmeyen parametreler sessizce yok sayılır. Desteklenen parametreler için modelin dokümantasyonunu kontrol edin.
</Warning>

## Faturalandırma

Video oluşturma, **oluşturma başına sabit fiyatlandırma** kullanır. Video süresinden bağımsız olarak, görev gönderildiğinde bir kez ücretlendirilirsiniz. Oluşturma başarısız olursa, ücret otomatik olarak iade edilir.

Güncel fiyatlandırmayı [Models page](https://lemondata.cc/tr/models) üzerinde veya [Pricing API](/api-reference/pricing/get-pricing) aracılığıyla kontrol edin.
