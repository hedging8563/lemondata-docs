## Genel Bakış

LemonData'nın Agent-First API'si, hata yanıtlarını AI agent’larının ayrıştırıp hemen işlem yapabileceği yapılandırılmış ipuçlarıyla zenginleştirir — web araması yok, doküman araması yok, tahmin yürütme yok.

Her hata yanıtı, standart `error` nesnesi içinde `did_you_mean`, `suggestions`, `hint`, `retryable` ve `retry_after` gibi isteğe bağlı alanlar içerir. Bu alanlar geriye dönük uyumludur — bunları kullanmayan istemciler hiçbir fark görmez.

## Hata İpucu Alanları

Tüm ipucu alanları, `error` nesnesi içindeki isteğe bağlı genişletmelerdir:

| Alan | Tür | Açıklama |
|-------|------|-------------|
| `did_you_mean` | `string` | En yakın eşleşen model adı |
| `suggestions` | `array` | Metadata ile önerilen modeller |
| `alternatives` | `array` | Şu anda kullanılabilir alternatif modeller |
| `hint` | `string` | İnsan/agent tarafından okunabilir sonraki adım yönlendirmesi |
| `retryable` | `boolean` | Aynı isteğin yeniden denenmesinin başarılı olup olamayacağı |
| `retry_after` | `number` | Yeniden denemeden önce beklenecek saniye sayısı |
| `balance_usd` | `number` | USD cinsinden mevcut hesap bakiyesi |
| `estimated_cost_usd` | `number` | Başarısız isteğin tahmini maliyeti |

## Hata Kodu Örnekleri

### model_not_found (400)

Bir model adı etkin herhangi bir modelle eşleşmediğinde:

```json
{
  "error": {
    "message": "Model 'gpt5' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [
      {"id": "gpt-5.4"},
      {"id": "gpt-5-mini"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Did you mean 'gpt-5.4'? Use GET https://api.lemondata.cc/v1/models to list all available models."
  }
}
```

`did_you_mean` çözümlemesi şunları kullanır:
1. Statik alias eşlemesi (production hata verilerinden)
2. Normalize edilmiş string eşleştirme (tireleri kaldırır, büyük/küçük harf duyarsız)
3. Edit distance eşleştirmesi (eşik ≤ 3)


### model_price_not_configured (400)

Model dahili olarak mevcut ancak şu anda herkese açık istekler için açılmamışsa:

```json
{
  "error": {
    "message": "Model 'example-model' is not currently available for public requests.",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_price_not_configured",
    "retryable": false,
    "hint": "This model is not currently available for public requests. Use GET /v1/models to list publicly available model IDs."
  }
}
```

Ajanlar bunu bir yazım hatası değil, platform kullanılabilirlik sinyali olarak görmelidir. Aynı modeli ancak `GET /v1/models` içinde göründükten sonra yeniden deneyin.

### insufficient_balance (402)

Hesap bakiyesi tahmini maliyet için çok düşük olduğunda:

```json
{
  "error": {
    "message": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200.",
    "type": "insufficient_balance",
    "code": "insufficient_balance",
    "balance_usd": 0.12,
    "estimated_cost_usd": 0.35,
    "suggestions": [
      {"id": "gpt-5-mini"},
      {"id": "deepseek-v3-2"}
    ],
    "hint": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200. Try a cheaper model, or top up at https://lemondata.cc/dashboard/billing."
  }
}
```

`suggestions`, agent’ın geçebileceği, tahmini maliyetten daha ucuz modelleri içerir.

### all_channels_failed (503)

Bir model için tüm upstream kanalları kullanılamadığında:

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-6", "status": "available", "tags": []},
      {"id": "gpt-5-mini", "status": "available", "tags": []}
    ],
    "hint": "All channels for 'claude-opus-4-6' are temporarily unavailable. Retry in 30s or try an alternative model."
  }
}
```

<Note>
Nedeni `no_channels` olduğunda `retryable` değeri `false` olur (bu model için yapılandırılmış kanal yoktur). Yalnızca circuit breaker tetiklenmeleri veya kota tükenmesi gibi geçici hatalarda `true` olur.
</Note>

### rate_limit_exceeded (429)

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

`retry_after` değeri, gerçek rate limit pencere sıfırlama zamanına göre hesaplanır.

<Note>
OpenAI uyumlu endpoint’ler, `rate_limit_exceeded`, `upstream_error` ve `all_channels_failed` gibi LemonData'nın kararlı genel hata türlerini kullanır. Anthropic uyumlu ve Gemini uyumlu endpoint’ler kendi yerel yanıt biçimlerini kullanır.
</Note>

### context_length_exceeded (400)

Girdi modelin context penceresini aştığında (upstream hatası, ipuçlarıyla zenginleştirilmiş):

```json
{
  "error": {
    "message": "This model's maximum context length is 128000 tokens...",
    "type": "invalid_request_error",
    "code": "context_length_exceeded",
    "retryable": false,
    "suggestions": [
      {"id": "gemini-2.5-pro"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Reduce your input or switch to a model with a larger context window."
  }
}
```

## Yerel Endpoint Başlıkları

`/v1/chat/completions` çağrısını yerel endpoint’i olan bir modelle yaptığınızda (Anthropic veya Gemini), **başarılı yanıt** optimizasyon başlıkları içerir:

```
X-LemonData-Hint: This model supports native Anthropic format. Use POST /v1/messages for better performance (no format conversion).
X-LemonData-Native-Endpoint: /v1/messages
```

| Model Sağlayıcısı | Önerilen Endpoint | Fayda |
|---------------|-------------------|---------|
| Anthropic (Claude) | `/v1/messages` | Biçim dönüştürme yok, extended thinking, prompt caching |
| Google (Gemini) | `/v1beta/gemini` | Biçim dönüştürme yok, grounding, safety settings |
| OpenAI | — | Chat completions zaten yerel biçimdir |

Bu başlıklar hem streaming hem de non-streaming yanıtlarında görünür.

## /v1/models Geliştirmeleri

Her model nesnesinin `lemondata` uzantısındaki üç yeni alan:

```json
{
  "id": "gpt-5.4",
  "lemondata": {
    "category": "chat",
    "pricing_unit": "per_token",
    "cache_pricing": {
      "cache_read_per_1m": "1.25",
      "cache_write_per_1m": "2.50",
      "platform_cache_discount": 0.9
    }
  }
}
```

| Alan | Değerler | Açıklama |
|-------|--------|-------------|
| `category` | `chat`, `image`, `video`, `audio`, `tts`, `stt`, `3d`, `embedding`, `rerank` | Model türü |
| `pricing_unit` | `per_token`, `per_image`, `per_second`, `per_request` | Modelin nasıl ücretlendirildiği |
| `cache_pricing` | nesne veya `null` | Upstream prompt cache fiyatları + platform semantic cache indirimi |

### Kategori Filtreleme

```bash
GET https://api.lemondata.cc/v1/models?category=chat          # Chat modelleri
GET https://api.lemondata.cc/v1/models?category=image         # Görsel üretim modelleri
GET https://api.lemondata.cc/v1/models?tag=coding&category=chat  # Kodlamaya optimize edilmiş chat modelleri
```

## llms.txt

Makine tarafından okunabilir bir API genel bakışı şu adreste mevcuttur:

```
GET https://api.lemondata.cc/llms.txt
```

Şunları içerir:
- Çalışan bir örnekle ilk çağrı şablonu
- Yaygın model adları (kullanım verilerinden dinamik olarak üretilir)
- 12 API endpoint’inin tamamı
- Model keşfi için filtre parametreleri
- Hata yönetimi yönlendirmesi

İlk API çağrılarından önce `llms.txt` okuyan AI agent’ları genellikle ilk denemede başarılı olabilir.

## Agent Kodunda Kullanım

### Python (OpenAI SDK)

```python
from openai import OpenAI, BadRequestError

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://api.lemondata.cc/v1"
)

def smart_chat(messages, model="gpt-4o"):
    try:
        return client.chat.completions.create(
            model=model, messages=messages
        )
    except BadRequestError as e:
        error = e.body.get("error", {}) if isinstance(e.body, dict) else {}
        # Use did_you_mean for auto-correction
        if error.get("code") == "model_not_found" and error.get("did_you_mean"):
            return client.chat.completions.create(
                model=error["did_you_mean"], messages=messages
            )
        raise
```

### JavaScript (OpenAI SDK)

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function smartChat(messages, model = 'gpt-4o') {
  try {
    return await client.chat.completions.create({ model, messages });
  } catch (error) {
    const err = error?.error;
    if (err?.code === 'model_not_found' && err?.did_you_mean) {
      return client.chat.completions.create({
        model: err.did_you_mean, messages
      });
    }
    throw error;
  }
}
```
