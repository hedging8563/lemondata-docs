## Hata Yanıt Formatı

Tüm hatalar, isteğe bağlı [Agent-First hints](/guides/agent-first-api) ile tutarlı bir JSON formatı döndürür:

```json
{
  "error": {
    "message": "Human-readable error description",
    "type": "error_type",
    "code": "error_code",
    "param": "parameter_name",
    "did_you_mean": "suggested_model",
    "suggestions": [{"id": "model-id"}],
    "hint": "Next step guidance",
    "retryable": true,
    "retry_after": 30
  }
}
```

Temel alanlar (`message`, `type`, `code`, `param`) her zaman bulunur. İpucu alanları (`did_you_mean`, `suggestions`, `hint`, `retryable`, `retry_after`, `balance_usd`, `estimated_cost_usd`), AI agent'ların kendi kendini düzeltmesi için isteğe bağlı uzantılardır. Ayrıntılar için [Agent-First API guide](/guides/agent-first-api) bölümüne bakın.

OpenAI-uyumlu endpoint'ler LemonData'nın kararlı gateway hata türlerini kullanır. Anthropic-uyumlu ve Gemini-uyumlu endpoint'ler kendi yerel hata ailelerini ve yanıt biçimlerini kullanır.

## HTTP Durum Kodları

| Code | Description |
|------|-------------|
| 400 | Hatalı İstek - Geçersiz parametreler |
| 401 | Yetkisiz - Geçersiz veya eksik API key |
| 402 | Ödeme Gerekli - Yetersiz bakiye |
| 403 | Yasak - Erişim reddedildi veya modele izin verilmiyor |
| 404 | Bulunamadı - Model veya kaynak bulunamadı |
| 413 | Payload Çok Büyük - Girdi veya dosya boyutu aşıldı |
| 429 | Çok Fazla İstek - Rate limit aşıldı |
| 500 | Dahili Sunucu Hatası |
| 502 | Hatalı Gateway - Upstream provider hatası |
| 503 | Hizmet Kullanılamıyor - Hizmet geçici olarak kullanılamıyor |
| 504 | Gateway Zaman Aşımı - İstek zaman aşımına uğradı |

## Hata Türleri

### Kimlik Doğrulama Hataları (401)

| Type | Code | Description |
|------|------|-------------|
| `invalid_api_key` | `invalid_api_key` | API key eksik veya geçersiz |
| `expired_api_key` | `expired_api_key` | API key iptal edilmiş |

```python
from openai import OpenAI, AuthenticationError

try:
    response = client.chat.completions.create(...)
except AuthenticationError as e:
    print(f"Authentication failed: {e.message}")
```

### Ödeme Hataları (402)

| Type | Code | Description |
|------|------|-------------|
| `insufficient_balance` | `insufficient_balance` | Hesap bakiyesi çok düşük (OpenAI-uyumlu endpoint'ler) |
| `insufficient_balance_error` | `insufficient_balance` | Hesap bakiyesi çok düşük (Anthropic-uyumlu endpoint'ler) |
| `quota_exceeded` | `quota_exceeded` | API key kullanım sınırına ulaşıldı |

```python
from openai import OpenAI, APIStatusError

try:
    response = client.chat.completions.create(...)
except APIStatusError as e:
    if e.status_code == 402:
        print("Please top up your account balance")
```

### Erişim Hataları (403)

| Type | Code | Description |
|------|------|-------------|
| `access_denied` | `access_denied` | Kaynağa erişim reddedildi |
| `access_denied` | `model_not_allowed` | Bu API key için modele izin verilmiyor |

```json
{
  "error": {
    "message": "You don't have permission to access this model",
    "type": "access_denied",
    "code": "model_not_allowed"
  }
}
```

### Doğrulama Hataları (400)

| Type | Description |
|------|-------------|
| `invalid_request_error` | İstek parametreleri geçersiz |
| `context_length_exceeded` | Girdi model için fazla uzun |
| `model_not_found` | İstenen model mevcut değil |
| `model_price_not_configured` | Model dahili olarak mevcut ancak şu anda herkese açık istekler için kullanılamıyor |

```json
{
  "error": {
    "message": "Model 'invalid-model' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [{"id": "gpt-5.4"}, {"id": "gpt-5-mini"}],
    "hint": "Did you mean 'gpt-5.4'? Use GET https://api.lemondata.cc/v1/models to list all available models."
  }
}
```


Bir model dahili yönetişim veya fiyatlandırma iş akışlarında mevcut olsa da henüz herkese açık istek hedefi olarak açılmadıysa, LemonData şu yanıtı döndürür:

```json
{
  "error": {
    "message": "Model 'example-model' is not currently available for public requests.",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_price_not_configured",
    "retryable": false,
    "hint": "This model is not currently available for public requests. Use GET /v1/models to list publicly available model IDs."
  }
}
```

### Rate Limit Hataları (429)

Rate limit aşıldığında:

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

**Dahil edilen header'lar:**

```
Retry-After: 8
```

`Retry-After` header'ı ve `retry_after` alanı, yeniden denemeden önce beklenmesi gereken tam saniye sayısını belirtir.

### Payload Çok Büyük (413)

Girdi veya dosya boyutu sınırları aştığında:

```json
{
  "error": {
    "message": "Input size exceeds maximum allowed",
    "type": "invalid_request_error",
    "code": "payload_too_large"
  }
}
```

Yaygın nedenler:
- Görsel dosyası çok büyük (maks. 20MB)
- Ses dosyası çok büyük (maks. 25MB)
- Girdi metni modelin context length sınırını aşıyor

### Upstream Hataları (502, 503)

| Type | Description |
|------|-------------|
| `upstream_error` | Provider bir hata döndürdü |
| `all_channels_failed` | Kullanılabilir provider yok |
| `timeout_error` | İstek zaman aşımına uğradı |

Tüm kanallar başarısız olduğunda, yanıt alternatif modeller içerir:

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-6", "status": "available", "tags": []},
      {"id": "gpt-5-mini", "status": "available", "tags": []}
    ],
    "hint": "Retry in 30s or switch to an available model."
  }
}
```

## Python'da Hataları İşleme

```python
from openai import OpenAI, APIError, RateLimitError, APIConnectionError

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

def chat_with_retry(messages, max_retries=3):
    for attempt in range(max_retries):
        try:
            return client.chat.completions.create(
                model="gpt-4o",
                messages=messages
            )
        except RateLimitError as e:
            if attempt < max_retries - 1:
                import time
                time.sleep(2 ** attempt)  # Exponential backoff
                continue
            raise
        except APIConnectionError as e:
            print(f"Connection error: {e}")
            raise
        except APIError as e:
            print(f"API error: {e.status_code} - {e.message}")
            raise
```

## JavaScript'te Hataları İşleme

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function chatWithRetry(messages, maxRetries = 3) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      return await client.chat.completions.create({
        model: 'gpt-4o',
        messages
      });
    } catch (error) {
      if (error instanceof OpenAI.RateLimitError) {
        if (attempt < maxRetries - 1) {
          await new Promise(r => setTimeout(r, 2 ** attempt * 1000));
          continue;
        }
      }
      throw error;
    }
  }
}
```

  <Accordion title="Exponential backoff uygulayın">
    Rate limit uygulandığında, yeniden denemeler arasında kademeli olarak daha uzun bekleyin:
    ```python
    wait_time = 2 ** attempt  # 1s, 2s, 4s, 8s...
    ```
  </Accordion>

  <Accordion title="Timeout değerleri ayarlayın">
    Askıda kalan istekleri önlemek için her zaman makul timeout değerleri belirleyin:
    ```python
    client = OpenAI(timeout=60.0)  # 60 second timeout
    ```
  </Accordion>

  <Accordion title="Hataları debug için loglayın">
    Destek için istek kimliği dahil tam hata yanıtını loglayın:

    ```python
    except APIError as e:

    ```
  </Accordion>
