# LemonData Skills Factory

The LemonData Skills Factory is the internal control plane for building, validating, and distributing a large catalog of public AI agent skills.

## What this system does

- Defines the canonical 12-category portfolio
- Maintains a 288-skill launch matrix
- Enforces license, provenance, and similarity gates
- Routes distribution across fully automated, semi-automated, and curated channels
- Connects skills to LemonData docs, `llms.txt`, and API conversion paths

## Current launch shape

- 12 categories
- 6 archetypes per category
- 4 fixed variant profiles per archetype
- 24 launch candidates per category
- 288 planned launch skills total

## Core principles

1. Public skills are useful on their own; LemonData is the fast path, not a hard requirement.
2. Public distribution always starts from a canonical GitHub repo.
3. High-density rewrites only ship when they pass license and similarity checks.
4. Evaluation is always `with_skill` versus `without_skill` or a prior snapshot.
