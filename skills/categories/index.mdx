# Skill Categories

LemonData Skills Factory uses a fixed public taxonomy with 12 categories. `All` is only a combined filter view and is not treated as a category.

## Fixed categories

- [Research](/skills/categories/research)
- [Coding](/skills/categories/coding)
- [Writing](/skills/categories/writing)
- [Data & Analytics](/skills/categories/data-analytics)
- [Design](/skills/categories/design)
- [Planning](/skills/categories/planning)
- [Communication](/skills/categories/communication)
- [Productivity](/skills/categories/productivity)
- [DevOps](/skills/categories/devops)
- [AI & ML](/skills/categories/ai-ml)
- [Security](/skills/categories/security)
- [Business](/skills/categories/business)

## Shared launch pattern

Every category follows the same launch structure:

- 6 archetypes
- 4 variant profiles
- 24 launch skills
- quarter goal: 36-48 live skills

## Shared archetypes

- `audit/check`
- `generate/build`
- `integrate/migrate`
- `optimize/improve`
- `compare/select`
- `automate/ops`
