# Publishing Pipeline

The factory pipeline is designed to get from candidate idea to public-ready skill without skipping provenance or quality checks.

## Pipeline stages

1. Source intake and license normalization
2. Taxonomy mapping to category, archetype, and variant profile
3. Draft composition
4. Agent Skills spec validation
5. Similarity and near-duplicate checks
6. `with_skill` / `without_skill` evaluation runs
7. Blind judging and human spot review
8. Public sync and channel routing

## Distribution tiers

### L0

Fully automated or naturally discoverable channels:

- GitHub public repo
- skills.sh compatibility
- agentskills.in
- GitHub discovery surfaces

### L1

Semi-automated distribution channels:

- LobeHub
- AgentSkillsRepo
- Agent Skills Index
- Agent Skill Source
- AI Skills Marketplace
- mdskills.ai

### L2

Manual, curated, or brand-sensitive destinations:

- Terminal Skills
- Agensi
- SkillCreator.ai
- curated GitHub lists and newsletters
- community launches and reports

## Release policy

- Score `>= 90`: auto-publish to public repo and L0
- Score `85-89`: L0 plus L1 queue
- Score `75-84`: batch review PR
- Score `< 75`: rewrite queue

## Required artifacts

- `catalog.json`
- `provenance.json`
- `market-manifest.json`
- `evals/evals.json`

## Validation contract

All public skill directories must follow the [Agent Skills specification](https://agentskills.io/specification) and pass `skills-ref validate`.
