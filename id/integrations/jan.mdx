## Gambaran Umum

Jan dapat terhubung ke TokenLab sebagai penyedia remote yang kompatibel dengan OpenAI.

<Note>
**Tipe**: Aplikasi Chat

**Jalur Utama**: Chat completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur didukung
</Note>

## Mengonfigurasi Jan

1. Buka **Settings** -> **Providers**
2. Tambahkan penyedia remote yang kompatibel dengan OpenAI
3. Masukkan:
   - **Name**: TokenLab
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Tambahkan atau pilih `gpt-5.4-mini`
5. Simpan dan mulai thread baru.

## Penemuan Model

TokenLab menyediakan penemuan model di:

```text
https://api.tokenlab.sh/v1/models
```

Jika build Jan Anda mendukung penemuan model remote untuk TokenLab, segarkan daftar model. Jika tidak, tambahkan id model secara manual.

## Model yang Direkomendasikan

- `gpt-5.4-mini`
- `gpt-5.4`
- `claude-sonnet-5`
- `gemini-3.5-flash`
- `deepseek-v4-flash`
