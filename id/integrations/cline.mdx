## Ikhtisar

<Note>
**Tipe**: agen coding IDE

**Jalur utama**: Chat Completions kompatibel OpenAI

**Dukungan**: jalur penyedia resmi
</Note>

[Cline](https://docs.cline.bot/provider-config/openai-compatible) mendukung penyedia kompatibel OpenAI melalui pengaturan IDE.

## Konfigurasi TokenLab

1. Instal **Cline** dari marketplace ekstensi dan buka panelnya.
2. Klik ikon roda gigi lalu pilih **OpenAI Compatible** pada **API Provider**.
3. Isi:

| Kolom | Nilai |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key Anda |
| Model ID | `kimi-k3` |

4. Klik **Verify**.

Pada pengaturan lanjutan opsional, gunakan batas input `1048576`, output maksimum `131072`, dan aktifkan gambar serta alat / Computer Use.

Setelah verifikasi, mulai dengan tugas hanya-baca. Jika muncul 404, pastikan Base URL berakhir dengan `/v1` dan tidak memuat `/chat/completions`. ID model adalah `kimi-k3`, bukan `kimi/kimi-k3`.
