## Gambaran Umum

Sebagian besar aplikasi chat AI umum terhubung ke LemonData melalui path chat standar yang kompatibel dengan OpenAI.

Dalam praktiknya, itu berarti:
- gunakan `https://api.lemondata.cc/v1` sebagai base URL kecuali aplikasi secara eksplisit meminta URL endpoint lengkap
- gunakan API key LemonData Anda sebagai API key bergaya OpenAI
- pilih model yang dapat digunakan aplikasi dalam alur kerja chat standar

<Note>
Aplikasi chat umum biasanya **berorientasi pada chat-completions**, bukan klien WebSocket Codex Responses. Untuk Codex CLI/App, Cursor, atau alat coding lain yang memerlukan perilaku khusus Responses, gunakan panduan integrasi khusus sebagai gantinya.
</Note>

## Aplikasi yang Didukung

| Application | Platform | Notes |
|-------------|----------|-------|
| LobeChat | Web, Desktop, Self-hosted | Dukungan custom-provider yang kuat |
| Cherry Studio | Windows, macOS, Linux | Alur provider kompatibel OpenAI yang baik |
| Chatbox | Windows, macOS, Linux | Pengaturan kompatibel OpenAI yang sederhana |
| TypingMind | Web, Desktop | Menggunakan gaya endpoint kustom |
| BotGem | iOS, macOS | Konfigurasi provider kustom |
| OpenCat | iOS, macOS | Alur endpoint kustom yang kompatibel dengan OpenAI |
| ChatWise | Windows, macOS | Pola provider kustom standar |

## Nilai Koneksi Default

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

Jika sebuah aplikasi meminta **URL endpoint lengkap** alih-alih base URL, gunakan:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## Contoh Pengaturan Aplikasi

<Tabs>
  <Tab title="LobeChat">
    **LobeChat Self-hosted**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. Buka **Settings** → **AI Service Provider**
    2. Pilih **OpenAI**
    3. Masukkan API key LemonData Anda
    4. Atur endpoint kustom ke `https://api.lemondata.cc/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. Buka **Settings** → **Model Provider**
    2. Tambahkan provider **OpenAI-compatible**
    3. Masukkan:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. Tambahkan model yang ingin Anda gunakan
  </Tab>

  <Tab title="Chatbox">
    1. Buka **Settings** → **AI Model**
    2. Pilih **OpenAI API Compatible**
    3. Masukkan:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` atau `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. Buka **Settings**
    2. Pilih **Custom Endpoint**
    3. Masukkan:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. Konfigurasikan model yang ingin Anda tampilkan
  </Tab>
</Tabs>

## Tips

<AccordionGroup>
  <Accordion title="Prioritaskan base URL saat aplikasi mendukungnya">
    Sebagian besar aplikasi lebih mudah dikonfigurasi dan tidak terlalu rentan bermasalah saat Anda memberikan `https://api.lemondata.cc/v1` sebagai base URL alih-alih URL endpoint lengkap.
  </Accordion>

  <Accordion title="Gunakan model yang lebih kecil terlebih dahulu">
    Mulailah dengan `gpt-5-mini` atau `gpt-4o` untuk chat sehari-hari, lalu pindahkan tugas penalaran yang lebih berat ke `gpt-5.4` atau `claude-opus-4-6`.
  </Accordion>

  <Accordion title="Pisahkan alat coding">
    Aplikasi chat umum dan coding agent sering kali memerlukan perilaku endpoint yang berbeda. Simpan alat bergaya Codex/Cursor pada halaman integrasi khusus mereka.
  </Accordion>
</AccordionGroup>

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Kesalahan Koneksi">
    - Verifikasi bahwa base URL persis `https://api.lemondata.cc/v1`
    - Hapus trailing slash jika aplikasi otomatis menambahkan path
    - Jika aplikasi menginginkan URL endpoint lengkap, gunakan `https://api.lemondata.cc/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Unauthorized">
    - Periksa kembali API key Anda
    - Pastikan key tersebut aktif di dashboard LemonData
    - Pastikan tidak ada spasi atau line break tambahan
  </Accordion>

  <Accordion title="Model Tidak Tersedia">
    - Verifikasi nama model secara persis
    - Coba default yang didukung luas seperti `gpt-5-mini`, `gpt-4o`, atau `claude-sonnet-4-6`
    - Periksa ketersediaan saat ini di dokumentasi atau dashboard LemonData
  </Accordion>
</AccordionGroup>
