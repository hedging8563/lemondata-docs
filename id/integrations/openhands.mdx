## Gambaran Umum

OpenHands dapat menggunakan TokenLab melalui konfigurasi model yang kompatibel dengan LiteLLM/OpenAI, terutama untuk alur kerja CLI dan headless di mana Anda menyediakan model, API key, dan base URL.

<Note>
**Tipe**: Coding Agent

**Jalur Utama**: Konfigurasi model yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur endpoint kustom didukung
</Note>

## Lingkungan

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Pengaturan Model

Gunakan:

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

Awalan `openai/` memberi tahu jalur yang didukung LiteLLM untuk menggunakan konfigurasi penyedia yang kompatibel dengan OpenAI.

## Pengaturan Headless

Jika Anda sedang menyiapkan default lokal untuk penggunaan CLI atau headless, jalankan alur pengaturan OpenHands dan masukkan:

```bash
make setup-config
```

Saat diminta detail model, gunakan ID model TokenLab dengan awalan `openai/` dan base URL `/v1` milik TokenLab.

## Saran Model

Gunakan `claude-sonnet-5` atau `gpt-5.4` untuk perencanaan coding-agent, `gpt-5.4-mini` untuk loop rutin yang lebih cepat, dan `deepseek-v4-pro` jika Anda menginginkan model penalaran alternatif yang kuat.
