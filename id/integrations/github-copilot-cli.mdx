## Ikhtisar

<Note>
**Tipe**: agen coding CLI

**Jalur utama**: Chat Completions kompatibel OpenAI

**Dukungan**: jalur BYOK resmi
</Note>

[GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models) dapat terhubung ke endpoint yang kompatibel dengan OpenAI Chat Completions.

## Instalasi dan konfigurasi

```bash
npm install -g @github/copilot
copilot --version
```

Instalasi npm memerlukan Node.js 22 atau yang lebih baru. GitHub saat ini memerlukan paket Copilot aktif; akun organisasi juga harus mengaktifkan kebijakan Copilot CLI.

```bash
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.tokenlab.sh/v1"
export COPILOT_PROVIDER_API_KEY="sk-your-tokenlab-key"
export COPILOT_MODEL="kimi-k3"

copilot
```

Model harus mendukung streaming dan pemanggilan alat. `kimi-k3` mendukung alat dan memiliki konteks lebih besar dari rekomendasi GitHub 128K.

Mulai dengan tugas hanya-baca yang tidak mengubah berkas. Jika model tidak ditemukan, gunakan ID logis dari [katalog TokenLab terkini](https://tokenlab.sh/id/models), tanpa prefiks penyedia.

<Warning>
Jangan simpan API Key dalam berkas yang dilacak Git. Rotasi Key yang terlihat di riwayat terminal, tangkapan layar, atau log.
</Warning>
