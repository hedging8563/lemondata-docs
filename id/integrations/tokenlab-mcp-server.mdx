[Server MCP TokenLab](https://github.com/hedging8563/tokenlab-mcp-server) menghasilkan alat MCP dari kontrak OpenAPI publik TokenLab. Agen yang kompatibel dengan MCP dapat menemukan model dan harga, memanggil endpoint LLM native dan yang kompatibel dengan OpenAI, membuat media multimodal, mengunggah file, dan mengelola tugas asinkron.

Gunakan server ini saat agen memerlukan kontrak API TokenLab terkini alih-alih daftar alat yang dikelola secara manual. Profil `core` default mengekspos 29 alat endpoint yang dihasilkan ditambah dua alat penemuan komposit. Profil `full` mengekspos 78 alat endpoint yang dihasilkan ditambah dua alat komposit yang sama.

<Note>
Alat katalog publik dan harga tidak memerlukan kunci API TokenLab. Atur `TOKENLAB_API_KEY` untuk operasi inferensi, media, audio, file, tugas, embedding, rerank, dan terjemahan yang memerlukan kredensial. Jangan pernah menempatkan kunci API dalam argumen alat.
</Note>

## Apa yang Disediakan

- Penemuan model langsung dari `https://api.tokenlab.sh/v1/models`.
- Pencarian detail model dari `/v1/models/{model}`.
- Pencarian harga dari `/v1/models/{model}/pricing`.
- Ringkasan API yang dapat dibaca agen dari `https://api.tokenlab.sh/llms.txt`.
- Chat Completions dan Responses yang kompatibel dengan OpenAI, Anthropic Messages, dan Gemini generateContent tanpa mengubah bentuk permintaan native-nya.
- Pembuatan dan pengeditan gambar melalui URL JSON, ID file TokenLab, atau file multipart lokal.
- Video, musik, 3D, ucapan, transkripsi, terjemahan audio, embedding, embedding multimodal, rerank, dan terjemahan teks.
- Ringkasan tugas asinkron yang dinormalisasi untuk operasi pembuatan gambar, video, musik, 3D, dan dunia.
- Sinkronisasi kontrak harian yang mengambil dokumen OpenAPI publik, membuat ulang skema alat, menjalankan pengujian endpoint dan file, serta memperbarui `main` hanya jika setiap pemeriksaan berhasil.

## Instalasi dari GitHub

Klon repositori publik dan instal dependensi:

```bash
git clone https://github.com/hedging8563/tokenlab-mcp-server.git
cd tokenlab-mcp-server
npm install
npm test
```

Jalankan server melalui stdio:

```bash
npm start
```

Variabel lingkungan opsional `TOKENLAB_API_BASE` memiliki nilai default `https://api.tokenlab.sh`. Atur `TOKENLAB_MCP_TOOL_PROFILE=full` jika klien perlu mengekspos API pengembang yang lebih luas alih-alih profil `core` default.

## Konfigurasi untuk semua klien MCP stdio

Gunakan nilai yang sama pada setiap klien yang mendukung server MCP stdio lokal. Klien dapat menampilkannya sebagai bidang formulir atau menyimpannya dalam JSON, TOML, maupun YAML; arti setiap bidang tetap sama. Tambahkan setiap argumen sebagai item terpisah.

| Bidang | Nilai | Catatan |
|---|---|---|
| Nama server | `tokenlab-model-catalog` | Nama unik apa pun dapat digunakan. |
| Transport | `stdio` | TokenLab MCP berjalan sebagai proses anak lokal. |
| Perintah mulai | `npx` | Menjalankan paket npm yang telah dipublikasikan. |
| Argumen | `-y`, lalu `@tokenlabai/mcp-server` | Gunakan `@tokenlabai/mcp-server@0.6.13` untuk mengunci rilis yang saat ini telah diverifikasi. |
| Variabel lingkungan | `TOKENLAB_API_KEY` = `<TOKENLAB_API_KEY>` | Opsional untuk katalog publik dan wajib untuk alat inferensi serta media. |
| Penerusan variabel lingkungan | Biarkan kosong atau isi `TOKENLAB_API_KEY` | Gunakan nama variabel hanya jika kunci sudah diekspor di lingkungan lokal klien. Jangan mengatur kunci yang sama di kedua tempat. |
| Direktori kerja | Biarkan kosong | `npx` tidak memerlukan direktori proyek untuk paket ini. |

Salin konfigurasi lengkap berikut ke klien yang menerima objek JSON `mcpServers`:

```json
{
  "mcpServers": {
    "tokenlab-model-catalog": {
      "command": "npx",
      "args": ["-y", "@tokenlabai/mcp-server"],
      "env": {
        "TOKENLAB_API_KEY": "<TOKENLAB_API_KEY>"
      }
    }
  }
}
```

Hapus blok `env` jika Anda hanya memerlukan alat model dan harga publik. Jika klien mengharapkan satu objek server, bukan pembungkus `mcpServers`, salin hanya objek bagian dalam yang berisi `command`, `args`, dan `env`.

<Warning>
Jangan pernah memublikasikan tangkapan layar, log, atau file konfigurasi yang berisi kunci API asli. Gunakan placeholder pada contoh dan segera cabut kunci yang telah terekspos.
</Warning>

## Instalasi di Codex

Tambahkan server katalog publik ke konfigurasi Codex Anda:

```bash
codex mcp add tokenlab-model-catalog -- npx -y @tokenlabai/mcp-server
```

Mulai sesi Codex baru setelah menambahkan server. Alat katalog publik tidak memerlukan `TOKENLAB_API_KEY`.

Untuk mengaktifkan alat inferensi, sertakan kunci API TokenLab Anda saat menambahkan server:

```bash
codex mcp add --env TOKENLAB_API_KEY=your-tokenlab-api-key tokenlab-model-catalog -- npx -y @tokenlabai/mcp-server
```

## Instalasi di Cline

Instal server stdio yang dipublikasikan dengan Cline CLI:

```bash
cline mcp add tokenlab --yes -- npx -y @tokenlabai/mcp-server
```

Perintah ini telah diverifikasi dengan Cline CLI dan selesai tanpa peringatan pengaturan. Alat katalog publik langsung berfungsi; atur `TOKENLAB_API_KEY` di lingkungan Cline Anda saat memerlukan alat inferensi.

## Konfigurasi Claude Desktop

Tambahkan paket npm yang dipublikasikan ke konfigurasi klien MCP Anda:

```json
{
  "mcpServers": {
    "tokenlab-model-catalog": {
      "command": "npx",
      "args": ["-y", "@tokenlabai/mcp-server"]
    }
  }
}
```

Mulai ulang klien MCP setelah menyimpan konfigurasi.

## Cursor, Windsurf, dan Klien MCP Lainnya

Gunakan perintah dan argumen yang sama di klien mana pun yang mendukung server MCP stdio:

```json
{
  "command": "npx",
  "args": ["-y", "@tokenlabai/mcp-server"],
  "env": {
    "TOKENLAB_API_BASE": "https://api.tokenlab.sh"
  }
}
```

Jika klien Anda menyimpan server bernama, gunakan `tokenlab-model-catalog` sebagai nama server.

## Profil Alat yang Dihasilkan

| Profil | Alat yang diekspos | Cakupan |
|---|---:|---|
| `catalog` | 6 | Empat alat katalog dan harga publik yang dihasilkan, ditambah `compare_models` dan `get_api_overview`. Tidak memerlukan kunci API. |
| `core` (default) | 31 | 29 alat endpoint yang dihasilkan ditambah `compare_models` dan `get_api_overview`. Mencakup katalog, harga, endpoint LLM native, gambar, video, musik, 3D, audio, tugas, file, embedding, rerank, dan terjemahan. |
| `full` | 80 | 78 alat endpoint yang dihasilkan ditambah dua alat penemuan komposit. Menambahkan siklus hidup respons, batch, dunia, penemuan model native, dan operasi pengembang lain yang diizinkan. |

Nama alat, deskripsi, skema input, metode HTTP, path, tipe konten, persyaratan autentikasi, dan perilaku tugas dihasilkan dari snapshot OpenAPI yang tersimpan. Overlay khusus MCP menyediakan alias alat yang stabil, keanggotaan profil, semantik tugas asinkron, varian multipart, penghilangan rahasia, dan batasan non-streaming.

Versi 0.6.0 juga mengembalikan JSON melalui `structuredContent` MCP, menerbitkan tiga sumber daya kontrak, dan menyediakan dua templat prompt untuk pemilihan model serta penyusunan permintaan native. Alat yang dihasilkan dan komposit menyertakan anotasi risiko standar agar klien yang kompatibel dapat menerapkan kebijakan persetujuan yang lebih aman.

Alat `core` yang umum meliputi:

| Keluarga | Alat representatif |
|---|---|
| Katalog dan harga | `list_models`, `get_model`, `get_model_pricing`, `get_pricing`, `compare_models` |
| Endpoint LLM native | `create_chat_completion`, `create_response`, `create_anthropic_message`, `create_gemini_content` |
| Gambar | `create_image`, `create_image_file`, `edit_image`, `edit_image_file` |
| Video, musik, dan 3D | `create_video`, `create_music`, `create_3d_model` |
| Audio | `create_speech`, `transcribe_audio`, `translate_audio` |
| Embedding dan teks | `create_embedding`, `create_multimodal_embedding`, `rerank_documents`, `translate_text` |
| File dan tugas | `upload_file`, `list_files`, `retrieve_file`, `retrieve_file_content`, `delete_file`, `get_task_status`, `cancel_task` |

Panggilan alat MCP mengembalikan satu hasil akhir. Operasi khusus streaming dan real-time dikecualikan, dan skema permintaan yang dihasilkan membatasi bidang `stream` yang didukung menjadi `false`. Respons gambar dan audio kecil mengembalikan konten MCP native; respons biner yang lebih besar ditulis ke `TOKENLAB_ARTIFACT_DIR` dan dikembalikan dengan path lokal, tipe MIME, dan jumlah byte-nya.

## Hasil Media Asinkron

Pembuatan video, musik, dan 3D mengembalikan ringkasan tugas asinkron. Pembuatan dan pengeditan gambar dapat mengembalikan hasil yang selesai atau tugas asinkron, tergantung pada model dan permintaan yang dipilih.

Saat `delivery.mode` adalah `async`, panggil `get_task_status` dengan `{ "id": delivery.task_id }` sampai `delivery.terminal` bernilai `true`. Tentukan penyelesaian dari `status`; `progress` bersifat opsional dan tidak boleh digunakan sebagai kondisi terminal.

## Alur Kerja Agen yang Direkomendasikan

1. Panggil `list_models` saat pengguna belum menentukan model.
2. Gunakan `recommended_for` untuk tugas non-chat, seperti gambar, video, musik, 3D, TTS, STT, embedding, rerank, atau terjemahan.
3. Panggil `get_model` sebelum membuat permintaan non-chat, mencoba ulang permintaan yang gagal, atau beralih keluarga endpoint.
4. Panggil `get_model_pricing` saat biaya model memengaruhi pilihan pengguna.
5. Gunakan `compare_models` saat pilihan bergantung pada beberapa kandidat.
6. Panggil alat yang dihasilkan yang sesuai dengan kontrak API yang diperlukan, atau gunakan `get_api_overview` untuk peta ringkas keluarga API TokenLab.

## Panduan Endpoint Native

TokenLab mendukung rute yang kompatibel dengan OpenAI dan keluarga endpoint native. Server MCP membantu agen memilih rute yang tepat sebelum menulis kode:

| Keluarga | Rute umum |
|---|---|
| Chat kompatibel OpenAI | `/v1/chat/completions` |
| Respons | `/v1/responses` |
| Anthropic Messages | `/v1/messages` |
| Gemini native | `/v1beta/models/{model}:generateContent` |
| Gambar | `/v1/images/generations`, `/v1/images/edits` |
| Video | `/v1/videos/generations` |
| Musik | `/v1/music/generations` |
| 3D | `/v1/3d/generations` |
| Audio | `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/audio/translations` |
| Embedding dan rerank | `/v1/embeddings`, `/v1/rerank` |
| Terjemahan teks | `/v1/translations` |

## Penjelajah model terkelola

Klien yang mendukung HTTP Streamable dapat terhubung ke:

```text
https://tokenlab-model-explorer.vercel.app/mcp
```

Explorer yang di-host bersifat publik dan mengekspos `open_tokenlab_model_explorer`, `compare_tokenlab_models`, dan `generate_tokenlab_endpoint_example`. Gunakan server npm lokal di atas saat Anda memerlukan profil core/full yang dihasilkan, unggahan file lokal, atau operasi API dengan kredensial.

## Gunakan dengan TokenLab Skills

Server MCP berguna saat runtime, sementara [repositori TokenLab skills](https://github.com/hedging8563/tokenlab-skills) mengajarkan agen pengodean cara membuat dan memperbaiki kode integrasi.

Gunakan keduanya jika tersedia:

- Server MCP: temukan model, harga, dan detail endpoint terkini.
- Skill `tokenlab-api-integration`: buat contoh API yang dapat dijalankan dan tangani kesalahan TokenLab terstruktur.
- Skill `tokenlab-model-picker`: pilih model yang kuat untuk tugas pengguna.
- Skill `tokenlab-native-endpoints`: putuskan kapan harus menggunakan rute Responses, Anthropic Messages, Gemini, media, audio, embedding, rerank, atau terjemahan.

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Klien tidak dapat memulai server">
    Pastikan Node.js minimal versi 18.17, lalu jalankan `npx -y @tokenlabai/mcp-server` sekali di terminal untuk memunculkan kesalahan npm atau jaringan.
  </Accordion>

  <Accordion title="Daftar model kosong">
    Verifikasi bahwa mesin dapat menjangkau `https://api.tokenlab.sh/v1/models`. Jika Anda mengganti `TOKENLAB_API_BASE`, pastikan tidak menyertakan garis miring di akhir.
  </Accordion>

  <Accordion title="Agen masih memilih ID model yang kedaluwarsa">
    Minta agen untuk memanggil `list_models` atau `get_model` sebelum melakukan hardcode nama model. Memasangkan server MCP dengan `tokenlab-model-picker` memberikan hasil yang lebih baik.
  </Accordion>

  <Accordion title="Bisakah server ini memanggil API inferensi TokenLab berbayar?">
    Ya. Atur `TOKENLAB_API_KEY`, lalu gunakan alat LLM, media, audio, tugas, file, embedding, rerank, atau terjemahan yang dihasilkan. Alat katalog dan harga tetap tersedia tanpa kunci.
  </Accordion>
</AccordionGroup>
