## Gambaran Umum

DSPy dapat memanggil TokenLab dengan menggunakan prefiks penyedia `openai/` bersama endpoint `/v1` TokenLab yang kompatibel dengan OpenAI.

<Note>
**Tipe**: Kerangka Kerja Pemrograman

**Jalur Utama**: Panggilan model bahasa yang kompatibel dengan OpenAI

**Tingkat Keyakinan Dukungan**: Jalur endpoint kustom didukung
</Note>

## Lingkungan

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Konfigurasi DSPy

```python
import os

import dspy

lm = dspy.LM(
    "openai/claude-sonnet-5",
    api_key=os.environ["TOKENLAB_API_KEY"],
    api_base="https://api.tokenlab.sh/v1",
)

dspy.configure(lm=lm)
```

## Menggunakan Modul

```python
qa = dspy.ChainOfThought("question -> answer")

response = qa(question="What should I monitor in an LLM gateway?")
print(response.answer)
```

## Saran Model

Gunakan `gpt-5.4-mini` untuk eksperimen cepat, `claude-sonnet-5` untuk penelusuran penalaran yang lebih kuat, dan `deepseek-v4-flash` untuk siklus iterasi yang cepat.
