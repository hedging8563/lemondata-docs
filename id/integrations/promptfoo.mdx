## Gambaran Umum

Promptfoo dapat mengevaluasi TokenLab melalui penyedia chat dan Responses yang kompatibel dengan OpenAI.

<Note>
**Tipe**: Kerangka Kerja Evaluasi

**Jalur Utama**: Chat completions dan Responses yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur didukung
</Note>

## Lingkungan

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Contoh Konfigurasi

```yaml
description: TokenLab provider example

prompts:
  - 'Answer in one concise paragraph: {{question}}'

providers:
  - id: openai:chat:gpt-5.4-mini
    label: tokenlab-chat-gpt-5.4-mini
    config:
      apiBaseUrl: https://api.tokenlab.sh/v1
      apiKey: '{{env.TOKENLAB_API_KEY}}'
  - id: openai:responses:gpt-5.5
    label: tokenlab-responses-gpt-5.5
    config:
      apiBaseUrl: https://api.tokenlab.sh/v1
      apiKey: '{{env.TOKENLAB_API_KEY}}'

tests:
  - vars:
      question: What are two practical ways to evaluate an LLM gateway?
    assert:
      - type: contains-any
        value:
          - latency
          - reliability
          - cost
          - quality
```

## Menjalankan

```bash
promptfoo eval
```

Gunakan penyedia chat untuk kompatibilitas yang luas. Gunakan penyedia Responses jika evaluasi secara khusus bergantung pada perilaku Responses.
