## Gambaran Umum

LangBot dapat memanggil TokenLab melalui requester LLM yang kompatibel dengan OpenAI.

<Note>
**Tipe**: Platform Bot

**Jalur Utama**: Chat completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Didukung dengan batasan cakupan
</Note>

## Requester TokenLab

Jika build LangBot Anda menyertakan requester **TokenLab**:

1. Buka pengaturan penyedia model LangBot.
2. Tambahkan penyedia dengan requester **TokenLab**.
3. Atur API key ke kunci TokenLab Anda.
4. Pilih atau buat model seperti `gpt-5.4-mini`.
5. Lampirkan model tersebut ke pipeline atau bot yang akan menggunakannya.

## Fallback yang Kompatibel dengan OpenAI

Jika TokenLab belum terdaftar, gunakan requester yang kompatibel dengan OpenAI:

| Field | Value |
|-------|-------|
| Requester | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Model yang Direkomendasikan

- `gpt-5.4-mini` untuk sebagian besar interaksi bot
- `claude-sonnet-5` untuk penulisan dan penalaran yang lebih panjang
- `deepseek-v4-flash` untuk coding cepat dan loop penalaran
- `gemini-3.5-flash` untuk alur kerja umum yang cepat
