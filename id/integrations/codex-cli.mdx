## Gambaran Umum

OpenAI Codex adalah alat command-line open-source (CLI) yang berfungsi sebagai agen coding ringan, mampu membaca, memodifikasi, dan menjalankan kode di terminal. Alat ini dibangun di atas model GPT dan dioptimalkan untuk pembuatan kode.

## Persyaratan Sistem

- **OS**: macOS, Linux (dukungan resmi), Windows melalui WSL
- **Node.js**: Versi 18+
- **npm**: Versi 10.x.x atau lebih tinggi

## Instalasi

```bash
sudo npm install -g @openai/codex
```

Verifikasi instalasi:

```bash
codex --version
```

## Konfigurasi

### Langkah 1: Atur API Key

**Sementara (sesi saat ini):**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**Konfigurasi permanen:**

Tambahkan ke `~/.bashrc`, `~/.zshrc`, atau `~/.bash_profile`:

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

Lalu muat ulang:

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### Langkah 2: Konfigurasikan config.toml

Edit `~/.codex/config.toml`:

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
Jika file config belum ada, jalankan `codex` sekali untuk membuatnya, lalu edit file tersebut. Restart Codex sepenuhnya setelah mengubah `config.toml` agar pengaturan provider yang baru dimuat ulang.
</Note>

<Warning>
Codex sedang menghentikan dukungan `chat/completions` untuk provider kustom. Tetap gunakan `wire_api = "responses"` untuk LemonData kecuali Anda memang sengaja menggunakan jalur kompatibilitas yang lebih lama.
</Warning>

## Penggunaan Dasar

**Mulai mode interaktif:**

```bash
codex
```

**Perintah langsung:**

```bash
codex "Fix the bug in main.py line 42"
```

**Tentukan model:**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## Model yang Direkomendasikan

| Model | Paling Cocok Untuk |
|-------|----------|
| `gpt-5.4` | Pilihan default terbaik untuk coding dan reasoning |
| `gpt-5-mini` | Fallback yang lebih cepat dan lebih murah untuk workflow coding |
| `claude-sonnet-4-6` | Review kode, dokumentasi |
| `deepseek-r1` | Desain algoritma, reasoning |

## Perintah Interaktif

| Command | Deskripsi |
|---------|-------------|
| `/help` | Tampilkan bantuan |
| `/exit` or `Ctrl+C` | Keluar |
| `/clear` | Bersihkan percakapan |
| `/config` | Lihat konfigurasi |
| `/model <name>` | Ganti model |
| `/tokens` | Lihat penggunaan token |

## Verifikasi Konfigurasi

```bash
# Check environment variable
echo $OPENAI_API_KEY

# Test API connection
codex "Hello, Codex!"

# View configuration
cat ~/.codex/config.toml
```

## Kasus Penggunaan Umum

**Review kode:**

```bash
git diff | codex "Review these code changes"
```

**Buat pesan commit:**

```bash
git diff --staged | codex "Generate a commit message for these changes"
```

**Perbaiki error:**

```bash
codex "Fix the TypeScript errors in src/components/"
```

**Jelaskan kode:**

```bash
cat main.py | codex "Explain what this code does"
```

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Connection Error">
    - Verifikasi `base_url` di config.toml tepat `https://api.lemondata.cc/v1`
    - Periksa konektivitas jaringan
    - Pastikan tidak ada gangguan proxy
  </Accordion>

  <Accordion title="Authentication Failed">
    - Verifikasi `env_key = "OPENAI_API_KEY"` ada di `~/.codex/config.toml`
    - Verifikasi environment variable `OPENAI_API_KEY` sudah diatur
    - Periksa bahwa key diawali dengan `sk-`
    - Pastikan key aktif di dashboard LemonData
  </Accordion>

  <Accordion title="Model Not Found">
    - Periksa nama model sesuai persis
    - Verifikasi ketersediaan model di [lemondata.cc/en/models](https://lemondata.cc/id/models)
  </Accordion>
</AccordionGroup>
