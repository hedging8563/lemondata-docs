## Gambaran Umum

Instrumentasi OpenAI dari OpenLLMetry melacak panggilan yang dilakukan melalui SDK OpenAI resmi. Konfigurasikan SDK tersebut dengan URL dasar `/v1` milik TokenLab.

<Note>
**Tipe**: Observabilitas

**Jalur Utama**: Instrumentasi SDK OpenAI

**Tingkat Dukungan**: Jalur observabilitas yang kompatibel dengan OpenAI didukung
</Note>

## Instalasi

```bash
pip install opentelemetry-instrumentation-openai openai
```

## Lingkungan

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Contoh

```python
import os

from openai import OpenAI
from opentelemetry.instrumentation.openai import OpenAIInstrumentor

OpenAIInstrumentor().instrument()

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Trace this request"}],
)
```

## Catatan Endpoint

Gunakan jalur ini untuk panggilan TokenLab yang kompatibel dengan SDK OpenAI. Untuk endpoint asli TokenLab, lakukan instrumentasi pada klien HTTP atau SDK yang benar-benar mengirimkan permintaan tersebut.
