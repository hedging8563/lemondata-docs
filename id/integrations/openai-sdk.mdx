## Ringkasan

LemonData bekerja dengan OpenAI SDK resmi dengan mengarahkan klien ke `https://api.lemondata.cc/v1`.

Untuk project baru, utamakan **Responses API**. Pertahankan **Chat Completions** hanya ketika framework, plugin, atau jalur kode lama masih mengharapkannya.

<Note>
Python, JavaScript, dan Go memiliki OpenAI SDK resmi. PHP bekerja dengan baik menggunakan klien komunitas yang kompatibel dengan OpenAI, tetapi itu bukan OpenAI SDK resmi.
</Note>

## Konfigurasikan Klien

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## Direkomendasikan: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

## Streaming dengan Responses

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Tools / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## Kompatibilitas Chat Completions

Jika framework atau plugin Anda masih mengharapkan Chat Completions, LemonData juga mendukung path standar yang kompatibel dengan OpenAI:

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
Gunakan Chat Completions hanya untuk kompatibilitas. Untuk integrasi baru, utamakan `client.responses.create(...)`.
</Warning>

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Kesalahan Koneksi">
    - Verifikasi bahwa base URL tepat `https://api.lemondata.cc/v1`
    - Periksa interferensi proxy atau override klien HTTP kustom
    - Pastikan versi SDK Anda sudah terbaru sebelum men-debug perilaku provider
  </Accordion>

  <Accordion title="Autentikasi Gagal">
    - Periksa bahwa API key Anda diawali dengan `sk-`
    - Verifikasi bahwa key tersebut aktif di dashboard LemonData
    - Konfirmasikan bahwa SDK mengirim `Authorization: Bearer ...`
  </Accordion>

  <Accordion title="Path API Salah">
    - `responses.create(...)` mengirim request ke `/v1/responses`
    - `chat.completions.create(...)` mengirim request ke `/v1/chat/completions`
    - Jika aplikasi Anda saat ini hanya mendukung Chat Completions, tetap gunakan path kompatibilitas tersebut
  </Accordion>
</AccordionGroup>
