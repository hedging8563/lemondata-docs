## Gambaran Umum

Komponen **OpenAI** di Langflow menyertakan kolom **OpenAI API Base**. Arahkan kolom tersebut ke endpoint `/v1` yang kompatibel dengan OpenAI milik TokenLab dan gunakan ID model TokenLab.

<Note>
**Tipe**: Low-code AI Workflow Builder

**Jalur Utama**: Chat completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Didukung dengan batasan cakupan
</Note>

## Komponen OpenAI

1. Tambahkan komponen model bahasa **OpenAI**.
2. Atur **OpenAI API Key** ke kunci TokenLab Anda.
3. Perluas pengaturan lanjutan (advanced settings).
4. Atur **OpenAI API Base** ke `https://api.tokenlab.sh/v1`.
5. Atur **Model Name** ke ID model TokenLab.
6. Hubungkan output model ke agen, rantai (chain), atau alur kerja (workflow) Anda.

## Nilai

| Field | Value |
|-------|-------|
| OpenAI API Base | `https://api.tokenlab.sh/v1` |
| OpenAI API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

## Model yang Direkomendasikan

- `gpt-5.4-mini` untuk sebagian besar pengujian alur kerja
- `claude-sonnet-5` untuk penulisan dan penalaran yang lebih kuat
- `gemini-3.5-flash` untuk alur kerja multimodal yang cepat
- `deepseek-v4-flash` untuk iterasi pengodean dan penalaran yang cepat

Gunakan komponen LiteLLM Proxy di Langflow jika deployment Anda sudah memusatkan perutean penyedia melalui proxy LiteLLM.
