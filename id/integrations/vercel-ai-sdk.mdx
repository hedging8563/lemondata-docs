## Gambaran Umum

Untuk LemonData, default yang paling stabil di Vercel AI SDK adalah **provider OpenAI-compatible**.

Jika Anda secara spesifik membutuhkan perilaku **Responses-native**, Anda dapat beralih ke provider OpenAI dan tetap menggunakan base URL LemonData yang sama.

## Default yang Direkomendasikan: Provider OpenAI-Compatible

```bash
npm install ai @ai-sdk/openai-compatible
```

```typescript
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

export const lemondata = createOpenAICompatible({
  name: 'lemondata',
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

## Menghasilkan Teks

```typescript
import { generateText } from 'ai';
import { lemondata } from './lemondata';

const { text } = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});

console.log(text);
```

## Streaming Teks

```typescript
import { streamText } from 'ai';
import { lemondata } from './lemondata';

const result = await streamText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'Write a short poem about coding.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## Pemanggilan Tool

```typescript
import { generateText, tool } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const result = await generateText({
  model: lemondata.chatModel('gpt-5.4'),
  prompt: 'What is the weather in San Francisco?',
  tools: {
    weather: tool({
      description: 'Get weather in a location',
      parameters: z.object({
        location: z.string(),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72,
        condition: 'sunny',
      }),
    }),
  },
});

console.log(result.text);
```

## Output Terstruktur

```typescript
import { generateObject } from 'ai';
import { z } from 'zod';
import { lemondata } from './lemondata';

const { object } = await generateObject({
  model: lemondata.chatModel('gpt-5.4'),
  schema: z.object({
    name: z.string(),
    role: z.string(),
  }),
  prompt: 'Generate a fake developer profile.',
});

console.log(object);
```

## Jika Anda Secara Eksplisit Membutuhkan Perilaku Responses-Native

```bash
npm install ai @ai-sdk/openai
```

```typescript
import { createOpenAI } from '@ai-sdk/openai';

export const lemondataResponses = createOpenAI({
  apiKey: process.env.LEMONDATA_API_KEY,
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```typescript
import { generateText } from 'ai';
import { lemondataResponses } from './lemondata-responses';

const { text } = await generateText({
  model: lemondataResponses('gpt-5.4'),
  prompt: 'Explain LemonData in one sentence.',
});
```

<Note>
Gunakan `@ai-sdk/openai-compatible` sebagai default yang aman untuk integrasi bergaya proxy. Beralih ke `@ai-sdk/openai` hanya ketika Anda secara eksplisit menginginkan jalur provider yang dibangun di atas `/v1/responses`.
</Note>

## Variabel Environment

```bash
# .env.local
LEMONDATA_API_KEY=sk-your-lemondata-key
```

## Praktik Terbaik

<AccordionGroup>
  <Accordion title="Utamakan openai-compatible terlebih dahulu">
    Untuk gateway pihak ketiga dan backend proxy, `@ai-sdk/openai-compatible` biasanya merupakan titik awal yang paling minim kejutan.
  </Accordion>

  <Accordion title="Beralih ke Responses hanya saat diperlukan">
    Jika Anda memerlukan perilaku provider yang terikat ke `/v1/responses`, ganti package provider secara sengaja alih-alih mencampurkan kedua pola dalam satu client.
  </Accordion>

  <Accordion title="Simpan secret di server">
    Jangan pernah mengekspos LemonData API key Anda dalam kode sisi client. Tempatkan setup provider di file server atau route API.
  </Accordion>
</AccordionGroup>
