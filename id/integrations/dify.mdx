## Gambaran Umum

Dify bekerja dengan baik bersama LemonData melalui alur provider model yang kompatibel dengan OpenAI.

Untuk versi Dify saat ini, jalur yang paling aman biasanya adalah:
- pilih provider bawaan **OpenAI**
- atur API key LemonData Anda
- atur base URL kustom ke `https://api.lemondata.cc/v1`

<Note>
Beberapa build Dify yang lebih lama menampilkan ini sebagai `OpenAI-API-compatible` alih-alih provider bawaan `OpenAI` dengan kolom base URL kustom. Jika UI Dify Anda terlihat berbeda, gunakan alur provider kustom yang kompatibel dengan OpenAI yang paling mendekati dan tersedia di versi tersebut.
</Note>

## Prasyarat

- Akun LemonData dengan akses API
- Dify Cloud atau Dify yang di-host sendiri

## Langkah Konfigurasi

### Langkah 1: Dapatkan API Key Anda

1. Masuk ke [LemonData Dashboard](https://lemondata.cc/dashboard)
2. Buka [API Keys](https://lemondata.cc/dashboard/api)
3. Buat atau salin API key yang diawali dengan `sk-`

### Langkah 2: Konfigurasikan Provider

<Steps>
  <Step title="Buka Model Providers">
    Di Dify, buka **Settings** → **Model Providers**
  </Step>
  <Step title="Pilih OpenAI">
    Buka pengaturan provider **OpenAI**. Jika versi Dify Anda tidak menawarkan base URL kustom di sini, gunakan opsi provider kustom yang kompatibel dengan OpenAI yang tersedia di versi tersebut sebagai gantinya.
  </Step>
  <Step title="Masukkan Pengaturan LemonData">
    Gunakan nilai berikut:

    | Field | Value |
    |-------|-------|
    | API Key | `sk-your-lemondata-key` |
    | API Base URL / Custom Base URL | `https://api.lemondata.cc/v1` |
  </Step>
  <Step title="Tambahkan Model">
    Tambahkan model yang ingin Anda gunakan, misalnya:
    - `gpt-5.4`
    - `gpt-5-mini`
    - `gpt-4o`
    - `claude-sonnet-4-6`
    - `claude-opus-4-6`
    - `gemini-2.5-flash`
    - `gemini-2.5-pro`
    - `deepseek-r1`
  </Step>
</Steps>

### Langkah 3: Uji Koneksi

1. Pilih satu model seperti `gpt-5-mini` atau `gpt-4o`
2. Kirim prompt uji
3. Pastikan Dify menerima respons yang valid

## Embeddings untuk Knowledge Base

Untuk RAG dan pengindeksan knowledge base, tambahkan model embedding seperti:
- `text-embedding-3-small`
- `text-embedding-3-large`

Lalu atur model tersebut sebagai model embedding default di knowledge base yang relevan atau pada pengaturan aplikasi.

## Peran Model yang Direkomendasikan

| Use Case | Suggested Models |
|----------|------------------|
| Chat default | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| Penalaran mendalam | `gpt-5.4`, `claude-opus-4-6`, `deepseek-r1` |
| Cepat/murah | `gpt-5-mini`, `gemini-2.5-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## Praktik Terbaik

<AccordionGroup>
  <Accordion title="Mulai dengan provider OpenAI bawaan">
    Pada versi Dify yang lebih baru, provider OpenAI bawaan dengan base URL kustom biasanya merupakan pengaturan yang paling rapi untuk LemonData.
  </Accordion>

  <Accordion title="Gunakan model yang lebih murah untuk iterasi">
    Gunakan `gpt-5-mini` atau `gemini-2.5-flash` saat melakukan iterasi, lalu alihkan workflow yang lebih berat ke model yang lebih kuat hanya jika diperlukan.
  </Accordion>

  <Accordion title="Ingat bahwa Dify biasanya berorientasi pada chat-completions">
    Sebagian besar alur Dify menggunakan perilaku chat yang kompatibel dengan OpenAI. Jika Anda memerlukan Responses khusus Codex atau perilaku WebSocket, gunakan integrasi Codex khusus alih-alih Dify.
  </Accordion>
</AccordionGroup>

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Kesalahan Koneksi">
    - Verifikasi bahwa base URL persis `https://api.lemondata.cc/v1`
    - Hapus trailing slash jika Dify menduplikasinya
    - Pastikan server Dify dapat menjangkau LemonData melalui internet publik
  </Accordion>

  <Accordion title="401 Unauthorized">
    - Periksa kembali API key
    - Pastikan key aktif di dashboard LemonData
    - Pastikan nilai yang ditempel ke Dify tidak mengandung spasi tambahan atau line break
  </Accordion>

  <Accordion title="Model Tidak Ditemukan">
    - Verifikasi nama model secara persis
    - Tambahkan ulang entri model jika UI provider menyimpan cache nilai yang lebih lama
    - Periksa ketersediaan model saat ini di docs atau dashboard LemonData
  </Accordion>
</AccordionGroup>
