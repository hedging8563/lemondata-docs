## Gambaran Umum

Dify bekerja dengan baik bersama TokenLab melalui alur penyedia model yang kompatibel dengan OpenAI.

Ini adalah jalur integrasi yang berorientasi pada chat-completions. Hal ini tidak boleh dianggap sebagai jaminan bahwa Dify mengekspos Respons atau perilaku WebSocket yang sama seperti integrasi Codex khusus.

Untuk versi Dify saat ini, jalur teraman biasanya adalah:
- pilih penyedia **OpenAI** bawaan
- atur API key TokenLab Anda
- atur base URL kustom ke `https://api.tokenlab.sh/v1`

<Note>
Beberapa build Dify yang lebih lama mengekspos ini sebagai `OpenAI-API-compatible` alih-alih penyedia `OpenAI` bawaan dengan kolom base URL kustom. Jika UI Dify Anda terlihat berbeda, gunakan alur penyedia kustom yang kompatibel dengan OpenAI yang tersedia di versi tersebut.
</Note>

<Note>
**Tipe**: Framework atau Platform

**Jalur Utama**: Jalur chat yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Didukung dengan batasan cakupan
</Note>

## Prasyarat

- Akun TokenLab dengan akses API
- Dify Cloud atau Dify yang di-host sendiri (self-hosted)

## Langkah-langkah Konfigurasi

### Langkah 1: Dapatkan API Key Anda

1. Masuk ke [TokenLab Dashboard](https://tokenlab.sh/dashboard)
2. Buka [API Keys](https://tokenlab.sh/dashboard/api)
3. Buat atau salin API key yang dimulai dengan `sk-`

### Langkah 2: Konfigurasi Penyedia

<Steps>
  <Step title="Buka Model Providers">
    Di Dify, buka **Settings** → **Model Providers**
  </Step>
  <Step title="Pilih OpenAI">
    Buka pengaturan penyedia **OpenAI**. Jika versi Dify Anda tidak menawarkan base URL kustom di sini, gunakan opsi penyedia kustom yang kompatibel dengan OpenAI yang diekspos oleh versi tersebut.
  </Step>
  <Step title="Masukkan Pengaturan TokenLab">
    Gunakan nilai berikut:

    | Field | Value |
    |-------|-------|
    | API Key | `sk-your-tokenlab-key` |
    | API Base URL / Custom Base URL | `https://api.tokenlab.sh/v1` |
  </Step>
  <Step title="Tambahkan Model">
    Tambahkan model yang ingin Anda gunakan, contohnya:
    - `gpt-5.4`
    - `gpt-5.4-mini`
    - `claude-sonnet-5`
    - `claude-opus-4-8`
    - `gemini-3.5-flash`
    - `gemini-3.1-flash-lite`
    - `deepseek-v4-flash`
  </Step>
</Steps>

### Langkah 3: Uji Koneksi

1. Pilih satu model seperti `gpt-5-mini` atau `gpt-4o`
2. Kirim prompt uji
3. Konfirmasikan bahwa Dify menerima respons yang valid

## Embedding untuk Knowledge Base

Untuk RAG dan pengindeksan knowledge base, tambahkan model embedding seperti:
- `text-embedding-3-small`
- `text-embedding-3-large`

Kemudian atur sebagai model embedding default di pengaturan knowledge base atau aplikasi yang relevan.

## Peran Model yang Direkomendasikan

| Kasus Penggunaan | Model yang Disarankan |
|----------|------------------|
| Chat default | `gpt-5.4-mini`, `gpt-5.4`, `claude-sonnet-5` |
| Penalaran mendalam | `gpt-5.5`, `gpt-5.4`, `claude-opus-4-8`, `deepseek-v4-pro` |
| Cepat/murah | `gpt-5.4-mini`, `gemini-3.5-flash`, `deepseek-v4-flash` |
| Embedding | `text-embedding-3-small`, `text-embedding-3-large` |

## Praktik Terbaik

<AccordionGroup>
  <Accordion title="Mulai dengan penyedia OpenAI bawaan">
    Pada versi Dify yang lebih baru, penyedia OpenAI bawaan dengan base URL kustom biasanya merupakan pengaturan yang paling bersih untuk TokenLab.
  </Accordion>

  <Accordion title="Gunakan model yang lebih murah untuk iterasi">
    Gunakan `gpt-5.4-mini`, `gemini-3.5-flash`, atau `deepseek-v4-flash` saat melakukan iterasi, kemudian alihkan alur kerja yang lebih berat ke model yang lebih kuat hanya jika diperlukan.
  </Accordion>

  <Accordion title="Ingat bahwa Dify biasanya berorientasi pada chat-completions">
    Sebagian besar alur Dify menggunakan perilaku chat yang kompatibel dengan OpenAI. Jika Anda memerlukan Respons atau perilaku WebSocket khusus Codex, gunakan integrasi Codex khusus alih-alih Dify.
  </Accordion>
</AccordionGroup>

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Kesalahan Koneksi">
    - Pastikan base URL tepat `https://api.tokenlab.sh/v1`
    - Hapus garis miring (trailing slash) jika Dify menduplikasinya
    - Konfirmasikan bahwa server Dify dapat menjangkau TokenLab melalui internet publik
  </Accordion>

  <Accordion title="401 Unauthorized">
    - Periksa kembali API key
    - Konfirmasikan bahwa key aktif di dashboard TokenLab
    - Pastikan nilai yang ditempelkan ke Dify tidak mengandung spasi tambahan atau baris baru
  </Accordion>

  <Accordion title="Model Tidak Ditemukan">
    - Verifikasi nama model dengan tepat
    - Tambahkan kembali entri model jika UI penyedia menyimpan nilai lama
    - Periksa ketersediaan model saat ini di dokumentasi atau dashboard TokenLab
  </Accordion>
</AccordionGroup>
