## Ringkasan

OpenCode adalah asisten coding AI sumber terbuka (open-source) yang berjalan di terminal Anda. Ini mendukung berbagai penyedia LLM dan dapat dikonfigurasi untuk menggunakan LemonData API guna mengakses lebih dari 300 model.

## Instalasi

<Tabs>
  <Tab title="Skrip Instalasi">
    ```bash
    curl -fsSL https://opencode.ai/install | bash
    ```
  </Tab>
  <Tab title="Homebrew">
    ```bash
    brew install opencode-ai/tap/opencode
    ```

    Atau gunakan community tap (pembaruan lebih sering):
    ```bash
    brew install anomalyco/tap/opencode
    ```
  </Tab>
  <Tab title="Go">
    ```bash
    go install github.com/opencode-ai/opencode@latest
    ```
  </Tab>
</Tabs>

Verifikasi instalasi:

```bash
opencode --version
```

## Konfigurasi

### Langkah 1: Atur Environment Variables

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

Untuk konfigurasi permanen, tambahkan ke `~/.bashrc` atau `~/.zshrc`:

```bash
echo 'export OPENAI_API_KEY="sk-your-lemondata-key"' >> ~/.zshrc
source ~/.zshrc
```

### Langkah 2: Konfigurasi OpenCode

Buat atau edit `~/.config/opencode/opencode.json` (global) atau `opencode.json` di root proyek Anda:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "lemondata": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "LemonData",
      "options": {
        "baseURL": "https://api.lemondata.cc/v1",
        "apiKey": "{env:OPENAI_API_KEY}"
      },
      "models": {
        "gpt-5.4": {
          "name": "GPT-5.4"
        },
        "gpt-4o": {
          "name": "GPT-4o"
        }
      }
    }
  },
  "model": "lemondata/gpt-5.4"
}
```

<Note>
Gunakan `@ai-sdk/openai-compatible` untuk kompatibilitas gaya chat-completions. Jika Anda memang membutuhkan `/v1/responses`, ganti paket provider ke `@ai-sdk/openai`.
</Note>

## Penggunaan Dasar

**Mulai mode interaktif:**

```bash
opencode
```

**Jalankan dengan prompt:**

```bash
opencode "Explain this codebase"
```

**Tentukan model:**

```bash
opencode --model lemondata/gpt-5.4 "Fix the bugs in main.py"
```

## Model yang Tersedia

| Model | Terbaik Untuk |
|-------|----------|
| `gpt-4o` | Tugas kompleks, arsitektur kode |
| `gpt-4o-mini` | Perbaikan cepat, kueri sederhana |
| `claude-sonnet-4-5` | Tinjauan kode, dokumentasi |
| `claude-opus-4-5` | Penalaran kompleks |
| `gemini-2.5-flash` | Respons cepat |
| `deepseek-r1` | Desain algoritma |

## Perintah Umum

**Analisis kode:**

```bash
opencode "What does this function do?" < src/utils.ts
```

**Hasilkan kode:**

```bash
opencode "Create a REST API with Express"
```

**Tinjau perubahan:**

```bash
git diff | opencode "Review these changes"
```

**Perbaiki kesalahan:**

```bash
opencode "Fix the TypeScript errors in this project"
```

## Perintah Interaktif

| Perintah | Deskripsi |
|---------|-------------|
| `/help` | Tampilkan perintah yang tersedia |
| `/model <name>` | Beralih ke model yang berbeda |
| `/clear` | Hapus riwayat percakapan |
| `/exit` | Keluar dari OpenCode |

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Kesalahan Koneksi">
    - Verifikasi `options.baseURL` telah diatur ke `https://api.lemondata.cc/v1`
    - Periksa konektivitas jaringan
    - Coba `curl https://api.lemondata.cc/v1/models` untuk menguji
  </Accordion>

  <Accordion title="Autentikasi Gagal">
    - Verifikasi environment variable `OPENAI_API_KEY` telah diatur
    - Pastikan kunci dimulai dengan `sk-`
    - Pastikan kunci aktif di dashboard LemonData
  </Accordion>

  <Accordion title="Model Tidak Ditemukan">
    - Periksa apakah nama model di konfigurasi sudah sesuai
    - Verifikasi ketersediaan model di [lemondata.cc/en/models](https://lemondata.cc/id/models)
  </Accordion>
</AccordionGroup>

## Praktik Terbaik

<AccordionGroup>
  <Accordion title="Gunakan konteks proyek">
    Jalankan OpenCode dari root proyek Anda untuk pemahaman yang lebih baik tentang basis kode Anda.
  </Accordion>

  <Accordion title="Pilih model yang sesuai">
    Gunakan model yang lebih cepat (gpt-4o-mini) untuk tugas sederhana, model yang kuat (gpt-4o, claude) untuk tugas yang kompleks.
  </Accordion>

  <Accordion title="Tinjau kode yang dihasilkan">
    Selalu tinjau kode yang dihasilkan AI sebelum menerapkan perubahan pada proyek Anda.
  </Accordion>
</AccordionGroup>
