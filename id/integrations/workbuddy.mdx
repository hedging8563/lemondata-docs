## Ikhtisar

<Note>
**Tipe**: agen desktop untuk coding dan tugas

**Jalur utama**: Chat Completions kompatibel OpenAI

**Dukungan**: jalur model khusus resmi
</Note>

[WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) menyediakan editor visual untuk model kompatibel OpenAI, tanpa perlu mengedit berkas model lokal secara manual.

## Konfigurasi TokenLab

Buka **Settings → Model**, tambahkan model lalu pilih **Custom**.

| Kolom | Nilai |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key Anda |
| Model name | `kimi-k3` |
| Custom Protocol | **Nonaktif** |

<Warning>
Biarkan Custom Protocol nonaktif. Mode standar memvalidasi Base URL dan menambahkan `/chat/completions`. Jika diaktifkan dengan hanya `/v1`, permintaan akan memakai jalur yang salah.
</Warning>

Pada pengaturan lanjutan, aktifkan pemanggilan alat, input gambar, dan mode penalaran. Nonaktifkan mode hanya-penalaran, biarkan upaya pada Auto, gunakan input `1048576` dan output `131072`.

Simpan, pilih `kimi-k3`, lalu uji pemeriksaan folder hanya-baca. Tutupi Key dan endpoint privat sebelum membagikan tangkapan layar.
