## Gambaran Umum

Flowise dapat memanggil TokenLab melalui node chat TokenLab jika tersedia, atau melalui node model chat yang kompatibel dengan OpenAI yang diarahkan ke TokenLab.

<Note>
**Tipe**: Pembuat Alur Kerja (Workflow Builder)

**Jalur Utama**: OpenAI-compatible chat completions

**Tingkat Dukungan**: Didukung dengan batasan cakupan
</Note>

## Node TokenLab

Jika build Flowise Anda menyertakan node model chat **TokenLab**:

1. Tambahkan **Chat Models** -> **TokenLab**
2. Buat kredensial API TokenLab
3. Atur **Model Name** ke `gpt-5.4-mini`
4. Hubungkan ke chain, agen, atau alur kerja Anda
5. Jalankan prompt pengujian.

## Fallback Kompatibel dengan OpenAI

Jika node TokenLab belum tersedia, gunakan node model chat yang kompatibel dengan OpenAI dengan pengaturan berikut:

| Kolom | Nilai |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Model yang Direkomendasikan

- `gpt-5.4-mini` untuk sebagian besar pengujian alur kerja
- `claude-sonnet-5` untuk penulisan dan penalaran yang lebih kuat
- `gemini-3.5-flash` untuk alur kerja multimodal yang cepat
- `deepseek-v4-flash` untuk iterasi kode atau penalaran yang cepat
