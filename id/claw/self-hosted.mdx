<Note>
**Self-hosted** berarti Anda menjalankan LemonClaw secara langsung di VPS atau mesin Anda sendiri. Anda hanya membayar penggunaan model AI melalui saldo LemonData Anda — tanpa biaya instans.
</Note>

<Tip>
Lebih suka pengaturan ter-hosting? [Buat instans Claw](/claw/introduction) untuk mendapatkan runtime LemonClaw dan WebUI yang sama tanpa mengelola server sendiri.
</Tip>

## Instalasi Cepat

<CodeGroup>
```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```

```bash Non-interactive
LEMONDATA_API_KEY=sk-xxx curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```
</CodeGroup>

Installer akan meminta **LemonData API Key** Anda. Dapatkan satu dari [Dashboard](https://lemondata.cc/dashboard) Anda.

## Apa yang Terinstal

<Steps>
  <Step title="Node.js 22+">
    Terinstal secara otomatis jika tidak ada (melalui NodeSource di Linux, Homebrew di macOS)
  </Step>
  <Step title="LemonClaw">
    Paket LemonClaw yang telah dikonfigurasi sebelumnya dengan LemonData API
  </Step>
  <Step title="15 Model AI">
    Claude, GPT-5, Gemini, DeepSeek, dan lainnya — siap digunakan
  </Step>
  <Step title="Plugin IM">
    Plugin DingTalk, WeCom, dan QQ yang sudah terinstal sebelumnya
  </Step>
  <Step title="Layanan Sistem">
    Mulai otomatis saat booting (systemd di Linux, launchd di macOS)
  </Step>
</Steps>

## Persyaratan

| Persyaratan | Detail |
|-------------|---------|
| **OS** | Linux (Ubuntu/Debian/CentOS/RHEL) atau macOS |
| **Arsitektur** | x64 atau arm64 |
| **RAM** | Minimal 1 GB, direkomendasikan 2 GB |
| **API Key** | [Dapatkan di sini](https://lemondata.cc) |

## Perintah Manajemen

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user status lemonclaw    # Check status
    journalctl --user -u lemonclaw -f    # View logs
    systemctl --user restart lemonclaw   # Restart
    systemctl --user stop lemonclaw      # Stop
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    tail -f ~/.lemonclaw/lemonclaw.log    # View logs
    launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # Restart
    launchctl stop cc.lemondata.lemonclaw  # Stop
    ```
  </Tab>
</Tabs>

## Konfigurasi

Lokasi file konfigurasi: `~/.lemonclaw/config.json`

Setelah mengedit, restart layanan untuk menerapkan perubahan.

### Ubah Model Default

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-opus-4-6"
      }
    }
  }
}
```

Prefix model yang tersedia (tergantung provider mana yang kamu aktifkan di [LemonData Provider Setup](/claw/lemondata-provider)):
- `lemondata/` — Rute kompatibel OpenAI (`openai-completions`)
- `lemondata-responses/` — Rute OpenAI Responses (`openai-responses`)
- `lemondata-claude/` — Rute native Claude (`anthropic-messages`)
- `lemondata-gemini/` — Rute native Gemini (`google-generative-ai`)
- `lemondata-minimax/` — Rute native MiniMax (`anthropic-messages`)

## Pembaruan

```bash
# Re-run the installer to upgrade to the latest version
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
# Then restart the service
systemctl --user restart lemonclaw  # Linux
# or
launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # macOS
```

## Hapus Instalasi

```bash
# Stop and disable service
systemctl --user stop lemonclaw && systemctl --user disable lemonclaw  # Linux
launchctl unload ~/Library/LaunchAgents/cc.lemondata.lemonclaw.plist  # macOS

# Remove LemonClaw
rm -rf ~/.lemonclaw
```

## Self-Hosted vs Terkelola

| | Self-Hosted | Terkelola (Claw) |
|---|---|---|
| **Biaya instans** | Gratis | $20 / 30 hari |
| **Penggunaan AI** | Bayar sesuai penggunaan | Bayar sesuai penggunaan |
| **Infrastruktur** | Server Anda | Kami mengelola segalanya |
| **Pembaruan** | Manual (jalankan ulang installer) | Otomatis |
| **Dukungan** | Komunitas | Prioritas |
