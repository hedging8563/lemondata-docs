<Note>
**PixVerse**
- Model: `pixverse-c1`, `pixverse-v6`, `pixverse-v5.6`
- Operasi: `text-to-video`, `image-to-video`, `start-end-to-video`, `reference-to-video`
- Pemilih audio: `output_audio`, default `false`

Di TokenLab, model-model PixVerse di atas tidak mendukung `operation=video-extension`.

**HappyHorse**
- Model: `happyhorse-1.0`
- Operasi: `text-to-video`, `image-to-video`, `reference-to-video`, `video-to-video`
- Pemilih audio: Jangan kirim `output_audio`
</Note>
