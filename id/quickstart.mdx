## Langkah 1: Dapatkan API Key Anda

<Steps>
  <Step title="Buat akun">
    Daftar di [lemondata.cc](https://lemondata.cc) menggunakan email, akun Gmail, atau GitHub Anda.
  </Step>
  <Step title="Tambahkan kredit">
    Buka dashboard dan tambahkan kredit ke akun Anda. LemonData menggunakan harga pay-as-you-go tanpa komitmen minimum.
  </Step>
  <Step title="Buat API key">
    Buka **Dashboard → API Keys** dan buat key baru. Salin dan simpan dengan aman karena hanya ditampilkan sekali.
  </Step>
</Steps>

<Warning>
Jaga keamanan API key Anda. Jangan pernah mengeksposnya dalam kode client-side atau repository publik.
</Warning>

## Langkah 3: Buat Request Pertama Anda

Untuk project baru, mulailah dengan **Responses API**.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
Jika framework atau tool Anda masih mengharapkan Chat Completions, LemonData juga mendukung `POST /v1/chat/completions`. Untuk integrasi baru, gunakan `POST /v1/responses`.
</Note>

## Coba Model Berbeda

LemonData mendukung 300+ model. Ubah hanya field `model`:

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## Aktifkan Streaming

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
