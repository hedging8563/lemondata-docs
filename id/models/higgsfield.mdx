## Ringkasan

LemonData menyediakan akses ke model Higgsfield AI. Total: **3 model** tersedia.

## Model Chat

| Model ID | Harga |
|----------|--------|
| `higgsfield-lite` | Lihat dasbor |
| `higgsfield-standard` | Lihat dasbor |
| `higgsfield-turbo` | Lihat dasbor |


## Penggunaan

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="higgsfield-lite",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

<Note>
Harga yang ditampilkan adalah harga platform (~70% dari tarif resmi).
</Note>
