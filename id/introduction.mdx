## Apa itu LemonData?

LemonData adalah platform agregasi API AI yang memberi Anda akses terpadu ke **ratusan model AI** dari penyedia seperti OpenAI, Anthropic, Google, DeepSeek, Moonshot, MiniMax, dan lainnya.

## Choose the Request Format

Start with the route that matches the behavior you need. Use native Anthropic/Gemini routes for provider-native features; use OpenAI-compatible `/v1/chat/completions` when migrating existing OpenAI-style chat code.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "messages": [
      {"role": "user", "content": "Explain what LemonData does in one sentence."}
    ]
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="gpt-5.4",
    messages=[{"role": "user", "content": "Explain what LemonData does in one sentence."}]
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-5.4',
  messages: [{ role: 'user', content: 'Explain what LemonData does in one sentence.' }],
});

console.log(response.choices[0].message.content);
```

<Note>
Use `POST /v1/responses` only when you explicitly need Responses-specific behavior. It is not the default compatibility path across all models.
</Note>

</CodeGroup>
