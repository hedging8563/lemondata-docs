## Apa Itu LemonData?

LemonData adalah platform agregasi API AI yang memberi Anda akses terpadu ke **300+ model AI** dari penyedia seperti OpenAI, Anthropic, Google, DeepSeek, Moonshot, MiniMax, dan lainnya.

<CardGroup cols={2}>
  <Card title="Kompatibel dengan OpenAI" icon="plug">
    Gunakan API key dan base URL yang sama di berbagai alat dan SDK bergaya OpenAI.
  </Card>
  <Card title="Format Native" icon="shuffle">
    Panggil endpoint bergaya OpenAI, Anthropic, Gemini, dan Responses dari satu platform.
  </Card>
  <Card title="Bayar Sesuai Pemakaian" icon="coins">
    Tanpa langganan. Hanya bayar untuk yang benar-benar Anda gunakan.
  </Card>
  <Card title="Ketersediaan Tinggi" icon="shield-check">

  </Card>
</CardGroup>

## Titik Awal Default yang Baik

Untuk proyek baru, mulailah dengan OpenAI SDK ditambah **Responses API**:

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```
