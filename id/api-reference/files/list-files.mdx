## Ikhtisar

Endpoint ini adalah bagian dari Batch API yang kompatibel dengan OpenAI dari LemonData. Pekerjaan batch menggunakan berkas JSONL yang diunggah, dijalankan secara asinkron, dan dapat mengembalikan berkas keluaran/kesalahan nanti.

## Catatan

- Berkas input batch harus menggunakan `purpose=batch`.
- `completion_window` saat ini adalah `24h`.
- Urutan keluaran tidak dijamin; selalu cocokkan berdasarkan `custom_id`.
- Streaming tidak didukung di dalam item batch.

## Permintaan / Respons

Gunakan panel OpenAPI interaktif di atas untuk skema yang tepat.

## Tips Operasional

- Gunakan `custom_id` untuk rekonsiliasi downstream yang idempotent.
- Harapkan `output_file_id` dan `error_file_id` hanya setelah pekerja menyelesaikan batch.
- Harga batch mungkin berbeda dari harga sinkron karena aturan diskon `isBatchRequest=true` berlaku.
