openapi: "POST /v1/images/edits"

## Ikhtisar

Membuat gambar hasil edit atau diperluas dari gambar asli dan prompt.

Route ini mendukung:

- alur upload `multipart/form-data` gaya DALL-E klasik yang didokumentasikan di bawah
- request JSON yang menyediakan `image_url`, `image_urls`, atau referensi resmi `images` untuk keluarga image-to-image yang didukung

<Note>
`gpt-image-2` didukung pada endpoint ini. Kirim upload multipart `image`, JSON `image_url`, JSON `image_urls`, atau array JSON resmi `images` dengan referensi `image_url` atau `file_id`; GPT Image edits menerima hingga 16 gambar sumber. Nilai `file_id` harus dibuat melalui LemonData `/v1/files` dengan `purpose=user_data` atau `purpose=vision` agar gateway dapat mengikatnya ke channel edit gambar upstream yang sama. Parameter opsional mencakup `mask`, `n`, `size`, `quality`, `response_format`, `output_format`, `output_compression` atau `compression`, `moderation`, `partial_images`, dan `user`. `background` tetap khusus untuk alur generate image dan bukan bagian dari kontrak publik edit gambar `gpt-image-2` saat ini. Penagihan mengikuti detail usage token dari upstream, termasuk token input gambar dan token output gambar tambahan dari partial images.
</Note>

## Body Request

**Timeout permintaan sinkron:** beberapa penyedia gambar yang dirutekan mengembalikan gambar final secara inline dan menunggu proses generasi selesai. Permintaan resolusi tinggi atau kualitas tinggi dapat memakan waktu hampir satu menit atau lebih, jadi atur timeout HTTP client Anda minimal `120s`. Jika respons pembuatan berisi `status: "pending"`, `task_id`, atau `poll_url`, ikuti `poll_url` yang dikembalikan.

<ParamField body="image" type="file" required>
  Gambar yang ingin diedit. Harus PNG yang valid, kurang dari 50MB, dan berbentuk persegi. Gambar harus memiliki transparansi di area yang ingin diedit.
</ParamField>

<ParamField body="prompt" type="string" required>
  Deskripsi teks dari edit yang diinginkan.
</ParamField>

<ParamField body="mask" type="file">
  Gambar tambahan dengan area yang benar-benar transparan untuk menunjukkan di mana gambar harus diedit. Harus PNG yang valid, kurang dari 50MB, dan memiliki dimensi yang sama dengan `image`.
</ParamField>

<ParamField body="model" type="string" default="dall-e-2">
  The model to use for image edit. `gpt-image-2` is supported; legacy DALL-E style edits can continue to use `dall-e-2`.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Jumlah gambar yang dibuat. Harus antara 1 dan 10.
</ParamField>

<ParamField body="size" type="string">
  The generated image size. For `gpt-image-2`, use `auto` or `WIDTHxHEIGHT`; dimensions must be multiples of 16, longest edge at most `3840px`, long/short ratio at most `3:1`, and total pixels between `655,360` and `8,294,400`. Legacy DALL-E edits support `256x256`, `512x512`, or `1024x1024`.
</ParamField>

<ParamField body="response_format" type="string" default="url">
  Format tempat gambar yang dihasilkan dikembalikan. Harus `url` atau `b64_json`.
</ParamField>

<ParamField body="user" type="string">
  Identifier unik yang mewakili end-user Anda untuk monitoring abuse.
</ParamField>

## Respons

<ResponseField name="created" type="integer">
  Unix timestamp saat gambar dibuat.
</ResponseField>

<ResponseField name="data" type="array">
  Array gambar yang dihasilkan.

  Setiap object berisi:
  - `url` (string): URL gambar hasil edit (jika response_format `url`)
  - `b64_json` (string): Gambar Base64-encoded (jika response_format `b64_json`)
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/images/edits" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "image=@sunlit_lounge.png" \
  -F "mask=@mask.png" \
  -F "prompt=A sunlit indoor lounge area with a pool" \

  -F "size=1024x1024"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.images.edit(
    model="dall-e-2",
    image=open("sunlit_lounge.png", "rb"),
    mask=open("mask.png", "rb"),
    prompt="A sunlit indoor lounge area with a pool",
    n=1,
    size="1024x1024"
)

print(response.data[0].url)
```

```go Go
package main

import (
    "bytes"
    "fmt"
    "io"
    "mime/multipart"
    "net/http"
    "os"
)

func main() {
    body := &bytes.Buffer{}
    writer := multipart.NewWriter(body)

    image, _ := os.Open("sunlit_lounge.png")
    defer image.Close()
    part, _ := writer.CreateFormFile("image", "sunlit_lounge.png")
    io.Copy(part, image)

    mask, _ := os.Open("mask.png")
    defer mask.Close()
    maskPart, _ := writer.CreateFormFile("mask", "mask.png")
    io.Copy(maskPart, mask)

    writer.WriteField("prompt", "A sunlit indoor lounge area with a pool")
    writer.WriteField("n", "1")
    writer.WriteField("size", "1024x1024")
    writer.Close()

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/images/edits", body)
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", writer.FormDataContentType())

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    result, _ := io.ReadAll(resp.Body)
    fmt.Println(string(result))
}
```

## Catatan

<Note>
  Edit gambar hanya tersedia dengan DALL-E 2. Gambar harus memiliki area transparan yang menunjukkan di mana edit diterapkan, atau Anda dapat menyediakan gambar mask terpisah.
</Note>
