---

## Gambaran Umum

Gunakan endpoint ini untuk polling async terpadu di berbagai jenis task seperti pembuatan video, gambar, musik, dan 3D.

<Info>
Jika respons create menyertakan `poll_url`, panggil path tersebut secara persis. Untuk alur kerja async yang lebih baru, `poll_url` dapat mengarah ke `/v1/tasks/{id}`.
</Info>

## Parameter Path

<ParamField path="id" type="string" required>
  ID task yang dikembalikan oleh permintaan create.
</ParamField>

## Respons

<ResponseField name="id" type="string">
  Identifier tugas asinkron kanonik.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias identifier tugas asinkron.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling prioritas yang dikembalikan oleh respons create.
</ResponseField>

<ResponseField name="status" type="string">
  Status task seperti `pending`, `processing`, `completed`, atau `failed`.
</ResponseField>

<ResponseField name="progress" type="number">
  Persentase progres saat tersedia.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL aset hasil ketika task selesai dan menghasilkan video.
</ResponseField>

<ResponseField name="video" type="object">
  Objek video tunggal dengan `url`, `duration`, `width`, dan `height` saat tersedia.
</ResponseField>

<ResponseField name="videos" type="array">
  Array video saat upstream mengembalikan lebih dari satu output.
</ResponseField>

<ResponseField name="error" type="string">
  Pesan error ketika task gagal.
</ResponseField>

<ResponseField name="created" type="integer">
  Timestamp pembuatan saat tersedia.
</ResponseField>

<ResponseField name="updated" type="integer">
  Timestamp pembaruan terakhir saat tersedia.
</ResponseField>

<ResponseField name="model" type="string">
  Model yang digunakan saat tersedia.
</ResponseField>

## Contoh

```bash cURL
curl "https://api.lemondata.cc/v1/tasks/video_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

poll_url = "/v1/tasks/video_abc123"
response = requests.get(
    f"https://api.lemondata.cc{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/video_abc123';
const response = await fetch(`https://api.lemondata.cc${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
