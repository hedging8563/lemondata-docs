## Ikhtisar

API Manajemen memungkinkan Anda mengelola API key organisasi dan melihat usage serta billing untuk key tertentu tanpa memakai API key inference biasa.

Gunakan token manajemen dari halaman **Settings** di Dashboard Anda:

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
Management token bukan API key untuk inference. Gunakan `mt-...` untuk `/v1/management/*` dan gunakan `sk-...` untuk endpoint inference seperti `/v1/responses`.
</Warning>

## Endpoint yang tersedia

| Endpoint | Method | Deskripsi |
|----------|--------|------|
| `/v1/management/api-keys` | GET | Mendaftarkan API key pengguna di organisasi saat ini |
| `/v1/management/api-keys` | POST | Membuat API key pengguna baru |
| `/v1/management/api-keys/{keyId}` | PATCH | Memperbarui nama, batas penggunaan, model yang diizinkan, masa berlaku, atau status |
| `/v1/management/api-keys/{keyId}/usage` | GET | Mengambil detail usage berpaginasi untuk key tertentu |
| `/v1/management/api-keys/{keyId}/billing` | GET | Mengambil breakdown billing teragregasi untuk key tertentu |

## Arti field

- nama model yang dikirim di permintaan (`model`)
- penyedia model publik
- `scene`
- `accessChannel`: `platform` berarti permintaan ditagihkan sebagai permintaan platform; `byok` berarti memakai key provider upstream milik Anda sendiri
- jumlah usage, unit penagihan, dan metrik cache
- biaya dan timestamp

Respons hanya menampilkan field billing dan reporting yang bersifat publik. Detail routing internal dan metadata provider fisik tetap disembunyikan.

## Filter

`/usage` dan `/billing` saat ini mendukung filter berdasarkan:

- rentang waktu
- nama model yang dikirim di permintaan (`model`)
- penyedia model publik
- `scene`
- `accessChannel`
- pagination

## Contoh request lengkap

Mulailah dengan menampilkan API key organisasi yang dapat diakses oleh token manajemen saat ini:

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```

```python Python
import requests

response = requests.get(
    "https://api.lemondata.cc/v1/management/api-keys",
    headers={"Authorization": "Bearer mt-your-management-token"}
)

data = response.json()
for key in data["data"]:
    print(key["name"], key["status"], key["used_amount"])
```

```javascript JavaScript
const response = await fetch(
  'https://api.lemondata.cc/v1/management/api-keys',
  {
    headers: {
      'Authorization': 'Bearer mt-your-management-token'
    }
  }
);

const data = await response.json();
for (const key of data.data) {
  console.log(key.name, key.status, key.used_amount);
}
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/management/api-keys", nil)
    req.Header.Set("Authorization", "Bearer mt-your-management-token")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)

    fmt.Println(result["object"])
}
```

```php PHP
<?php
$ch = curl_init("https://api.lemondata.cc/v1/management/api-keys");

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer mt-your-management-token'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
foreach ($data['data'] as $key) {
    echo $key["name"] . " " . $key["status"] . " " . $key["used_amount"] . PHP_EOL;
}
```
</RequestExample>
