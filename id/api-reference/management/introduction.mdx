## Ikhtisar

Management API memungkinkan Anda mengelola API Key organisasi dan mengambil data penggunaan serta billing per key tanpa memakai inference API key biasa.

Gunakan management token dari halaman **Settings** di Dashboard:

<Warning>
Management token berbeda dari inference API key. Gunakan `mt-...` untuk `/v1/management/*`, dan `sk-...` untuk endpoint inferensi seperti `/v1/responses`.
</Warning>

## Endpoint yang tersedia

| Endpoint | Method | Description |
|----------|--------|-------------|
| /v1/management/api-keys | GET | List user-managed API keys in the current organization |
| /v1/management/api-keys | POST | Create a new user API key |
| /v1/management/api-keys/{keyId} | PATCH | Update name, usage limit, allowed models, expiry, or status |
| /v1/management/api-keys/{keyId}/usage | GET | Retrieve paginated usage details for a specific key |
| /v1/management/api-keys/{keyId}/billing | GET | Retrieve aggregated billing breakdowns for a specific key |

## Kontrak filter penggunaan

`GET /v1/management/api-keys/{keyId}/usage` mendukung parameter query berikut:

| Parameter | Tipe | Default / batas | Catatan |
|-----------|------|------------------|-------|
| page | integer | default 1, min 1 | 1-based page number |
| limit | integer | default 50, min 1, max 100 | Page size |
| logicalModel | string | max length 100 | Requested logical model name |
| modelVendor | string | max length 100 | Public model vendor |
| scene | enum | - | chat, image, audio, video, embedding, rerank, translation, music, 3d |
| accessChannel | enum | - | platform or byok |
| startDate | string | - | Inclusive lower bound; accepts RFC3339 with timezone or YYYY-MM-DD |
| endDate | string | - | Inclusive upper bound; accepts RFC3339 with timezone or YYYY-MM-DD |

Jika `startDate` dan `endDate` sama-sama dikirim, `startDate` harus lebih kecil atau sama dengan `endDate`.

## Kontrak body API Key

### POST /v1/management/api-keys

| Field | Tipe | Default / batas | Catatan |
|-------|------|------------------|-------|
| name | string | wajib, default Default Key, panjang 1-50 | Nama tampilan, dirapikan di sisi server |
| limitAmount | number \| null | min. 0, maks. 100000 | null atau dihilangkan = tanpa batas, 0 = tidak ada kuota yang bisa dipakai, angka positif = batas USD |
| models | string[] | default [] | Allowlist model logis opsional |
| expiresAt | string \| null | datetime RFC3339 | null berarti tanpa tanggal kedaluwarsa |

### PATCH /v1/management/api-keys/{keyId}

| Field | Tipe | Default / batas | Catatan |
|-------|------|------------------|-------|
| status | enum | - | active, inactive, revoked |
| name | string | panjang 1-50 | Nama tampilan yang diperbarui |
| limitAmount | number \| null | min. 0, maks. 100000 | null berarti tanpa batas, 0 berarti kuota nol |
| models | string[] | - | Allowlist model logis yang diperbarui |
| expiresAt | string \| null | datetime RFC3339 | null menghapus tanggal kedaluwarsa |

Permintaan PATCH harus menyertakan minimal satu field.

## Semantik pelaporan

- logicalModel merujuk pada nama model logis publik yang diminta oleh pemanggil.
- modelVendor merujuk pada vendor model publik, bukan rute fisik tersembunyi.
- scene adalah scene permintaan publik yang diturunkan dari endpoint atau jenis task.
- accessChannel=platform berarti permintaan ditagihkan melalui kanal platform LemonData.
- accessChannel=byok berarti permintaan menggunakan kunci provider upstream milik Anda sendiri.

Respons hanya mengekspos field billing dan reporting publik; detail routing internal dan metadata kanal fisik tetap disembunyikan.

## Catatan pagination billing

`/usage` mendukung pagination. `/billing` saat ini adalah endpoint agregat dan tidak mengembalikan metadata pagination seperti `page` / `limit`.

## Contoh cepat

Mulailah dengan menampilkan API Key yang tersedia untuk management token saat ini:

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>
