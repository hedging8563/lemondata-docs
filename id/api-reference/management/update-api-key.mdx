---
title: "Perbarui API Key"
openapi: "PATCH /v1/management/api-keys/{keyId}"
description: "Memperbarui API key pengguna yang sudah ada untuk organisasi saat ini."
---

## Ikhtisar

Gunakan endpoint ini untuk memperbarui nama, batas penggunaan, model yang diizinkan, masa berlaku, atau status dari API key pengguna yang sudah ada.

## Catatan

- Penghapusan permanen tidak didukung di API Manajemen v1.

## Permintaan / Respons

Gunakan panel OpenAPI interaktif di atas untuk skema yang tepat.
