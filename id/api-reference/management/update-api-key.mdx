---
## Ikhtisar

Gunakan endpoint ini untuk memperbarui nama, batas penggunaan, model yang diizinkan, waktu kedaluwarsa, atau status API Key yang sudah ada.

## Body request

Permintaan PATCH harus menyertakan minimal satu field.

| Field | Tipe | Default / batas | Catatan |
|-------|------|------------------|-------|
| status | enum | - | active, inactive, revoked |
| name | string | length 1-50 | Updated display name |
| limitAmount | number \| null | min 0, max 100000 | null = unlimited, 0 = zero quota, positive = USD cap |
| models | string[] | - | Updated logical model allowlist |
| expiresAt | string \| null | RFC3339 datetime | null clears the expiry |

## Catatan

- Hard delete sengaja tidak didukung di Management API v1.
- `revoked` biasanya diperlakukan sebagai status terminal; jika Anda butuh key lagi, biasanya lebih baik membuat key baru.

## Contoh

<RequestExample>
```bash cURL
curl -X PATCH "https://api.lemondata.cc/v1/management/api-keys/key_abc123def456" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "inactive",
    "limitAmount": 0
  }'
```
</RequestExample>

## Request / Response

Gunakan panel OpenAPI interaktif di atas untuk melihat schema yang tepat dan field respons.
