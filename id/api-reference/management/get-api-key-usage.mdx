title: "Lihat penggunaan API Key"
openapi: "GET /v1/management/api-keys/{keyId}/usage"
description: "Mengembalikan detail usage berpaginasi untuk API key pengguna."
---

## Ikhtisar

Endpoint ini mengembalikan detail usage per key dengan filter berdasarkan nama model yang dikirim di permintaan (`model`), penyedia model publik, `scene`, dan `accessChannel`.

## Catatan

- Respons hanya mencakup field billing publik.
- Routing internal dan metadata channel fisik disembunyikan dengan sengaja.

## Permintaan / Respons

Gunakan panel OpenAPI interaktif di atas untuk skema yang tepat.
