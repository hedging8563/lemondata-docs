## Ikhtisar

Endpoint ini membuat API Key baru bertipe `type=user` di organisasi yang terkait dengan management token saat ini.

## Body request

| Field | Tipe | Default / batas | Catatan |
|-------|------|------------------|-------|
| name | string | required, default Default Key, length 1-50 | Display name, trimmed server-side |
| limitAmount | number \| null | min 0, max 100000 | null or omitted = unlimited, 0 = zero quota, positive = USD spending cap |
| models | string[] | default [] | Optional logical model allowlist |
| expiresAt | string \| null | RFC3339 datetime | null means no expiry |

## Catatan

- Nilai penuh API Key hanya ditampilkan satu kali di respons.
- `models: []` berarti key tidak memiliki pembatasan model tambahan di luar kebijakan organisasi.
- `limitAmount: 0` membuat key yang valid tetapi tidak dapat memakai kuota sampai diperbarui kemudian.

## Contoh

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "sora-2"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>
