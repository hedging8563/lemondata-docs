---

## Ikhtisar

Membuat API key baru bertipe `type=user` di organisasi yang terkait dengan token manajemen saat ini.

## Catatan

- Nilai key lengkap hanya ditampilkan satu kali di respons.

## Permintaan / Respons

Gunakan panel OpenAPI interaktif di atas untuk skema yang tepat.
