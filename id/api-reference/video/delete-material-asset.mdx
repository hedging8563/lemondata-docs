---
title: "Menghapus Aset Material"
openapi: "DELETE /v1/videos/assets/{assetId}"
description: "Menghapus aset material Seedance yang dimiliki oleh organisasi saat ini."
---

Menghapus satu aset material. Tindakan ini tidak menghapus grup material yang memuatnya. Setelah dihapus, ID aset tidak dapat lagi digunakan sebagai `material_asset_id`.

## Contoh Permintaan

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Contoh Respons

```json
{
  "deleted": true,
  "id": "seedance_asset_123"
}
```
