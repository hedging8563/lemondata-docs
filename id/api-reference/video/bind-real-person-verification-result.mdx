---
title: "Menautkan Hasil Verifikasi Orang Asli"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "Menautkan hasil verifikasi material orang asli yang berhasil ke grup material TokenLab."
---

Tautkan hasil verifikasi yang berhasil dan buat pemetaan grup material orang asli TokenLab. Gunakan `session_id` dan `verification_token` dari pengalihan callback TokenLab.

TokenLab memverifikasi bahwa sesi tersebut milik organisasi yang sama dan belum kedaluwarsa. Respons hanya mengembalikan `group_id` TokenLab; gunakan ID tersebut saat membuat aset material `liveness_face`.

## Contoh Permintaan

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## Contoh Respons

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "seedance_group_real_123",
  "material_group": {
    "id": "seedance_group_real_123",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
