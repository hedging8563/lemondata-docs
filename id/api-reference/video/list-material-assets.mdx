---
title: "Mencantumkan Aset Material"
openapi: "GET /v1/videos/assets"
description: "Mencantumkan aset material Seedance yang dimiliki oleh organisasi saat ini."
---

Mencantumkan aset material yang dimiliki oleh organisasi yang terautentikasi. Lakukan filter berdasarkan `library_type`, `group_id`, atau `status` saat Anda perlu menemukan aset untuk alur kerja pembuatan tertentu.

Gunakan hanya aset yang memiliki `status` `ACTIVE`. Perlakukan `asset_url` sebagai sumber unggahan atau informasi inspeksi, bukan sebagai alamat material jangka panjang.

## Contoh Permintaan

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=seedance_group_virtual_123&page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Contoh Respons

```json
{
  "assets": [
    {
      "id": "seedance_asset_123",
      "object": "seedance.material_asset",
      "group_id": "seedance_group_virtual_123",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
