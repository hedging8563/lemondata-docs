## Ringkasan

Generasi video bersifat asynchronous. Anda mengirimkan request, menerima task ID dan `poll_url`, lalu melakukan polling untuk hasilnya.

<Info>
Untuk perilaku polling yang paling andal, ikuti `poll_url` yang dikembalikan oleh request pembuatan secara persis.
</Info>

<Warning>
Output audio bergantung pada model. Di LemonData, keluarga Veo 3 akan menyalakan audio secara default ketika `output_audio` dihilangkan. Jika model mendukung kontrol audio, gunakan `output_audio` untuk menyalakan atau mematikannya secara eksplisit. Alias camelCase `outputAudio` juga diterima untuk kompatibilitas.
</Warning>


## Request Body

<ParamField body="model" type="string" default="sora-2">
  ID model video. Default API adalah `sora-2`. Lihat [Panduan Generasi Video](/guides/video-generation) untuk matriks model saat ini dan kemampuan yang didukung.
</ParamField>

<ParamField body="prompt" type="string" required>
  Deskripsi teks dari video yang akan dihasilkan.
</ParamField>

<ParamField body="image_url" type="string">
  URL yang dapat diakses publik dari gambar awal untuk generasi image-to-video (I2V). Untuk kompatibilitas lintas-model terbaik, gunakan `image_url`.
</ParamField>

<ParamField body="image" type="string">
  Gambar inline sebagai data URL (misalnya, `data:image/jpeg;base64,...`). Didukung oleh model yang kompatibel, tetapi `image_url` memberikan kompatibilitas terluas di seluruh model video.
</ParamField>

<ParamField body="duration" type="integer">
  Durasi video dalam detik (bergantung pada model).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Rasio aspek (misalnya, `16:9`, `9:16`, `1:1`).
</ParamField>

<ParamField body="resolution" type="string">
  Resolusi video (misalnya, `1080p`, `720p`).
</ParamField>

<ParamField body="output_audio" type="boolean">
  Pengalih output audio yang bergantung pada model. Di LemonData, keluarga Veo 3 menggunakan `true` sebagai default ketika field ini dihilangkan. Model video lain mengikuti perilaku default yang telah ditetapkan. Alias camelCase `outputAudio` diterima untuk kompatibilitas.
</ParamField>

<ParamField body="fps" type="integer">
  Frame per detik (1-120).
</ParamField>

<ParamField body="negative_prompt" type="string">
  Hal-hal yang harus dihindari dalam generasi video.
</ParamField>

<ParamField body="seed" type="integer">
  Seed acak untuk generasi yang dapat direproduksi.
</ParamField>

<ParamField body="cfg_scale" type="number">
  Skala classifier-free guidance (0-20).
</ParamField>

<ParamField body="motion_strength" type="number">
  Intensitas gerakan (0-1).
</ParamField>

<ParamField body="start_image" type="string">
  URL dari gambar frame awal.
</ParamField>

<ParamField body="end_image" type="string">
  URL dari gambar frame akhir.
</ParamField>

<ParamField body="user" type="string">
  Pengidentifikasi unik untuk end-user.
</ParamField>

## Respons

<ResponseField name="task_id" type="string">
  Pengidentifikasi task unik untuk polling.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling yang direkomendasikan untuk task ini. Gunakan path ini secara persis saat memeriksa status.
</ResponseField>

<ResponseField name="status" type="string">
  Status awal: `pending`.
</ResponseField>

<ResponseField name="model" type="string">
  Model yang digunakan.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={
        "Authorization": "Bearer sk-your-api-key",
        "Content-Type": "application/json"
    },
    json={
        "model": "sora-2",
        "prompt": "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)

data = response.json()
task_id = data["task_id"]
print(f"Poll URL: {data['poll_url']}")
print(f"Task ID: {task_id}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":    "sora-2",
        "prompt":   "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/videos/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Poll URL: %s\n", result["poll_url"])
    fmt.Printf("Task ID: %s\n", result["task_id"])
}
```

## Image to Video

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/image.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)
```

## Kontrol Keyframe

Gunakan `start_image` dan `end_image` untuk mengontrol frame pertama dan terakhir (didukung oleh Vidu Q2 Pro):

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night",
        "operation": "Awal-akhir ke video",
        "start_image": "https://example.com/day.jpg",
        "end_image": "https://example.com/night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```
