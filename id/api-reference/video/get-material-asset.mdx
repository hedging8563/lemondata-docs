---
title: "Mendapatkan Material Asset"
openapi: "GET /v1/videos/assets/{assetId}"
description: "Mengambil satu material asset Seedance berdasarkan ID material asset TokenLab."
---

Ambil satu material asset dan periksa status pemrosesannya. Asset tersebut hanya dapat digunakan untuk pembuatan video jika `ready` bernilai `true` dan `status` bernilai `ACTIVE`.

Jika pembuatan video mengembalikan pesan `Seedance material asset not found or not accessible`, pastikan Anda telah memasukkan `id` material asset ini, bukan `group_id` material tersebut.

## Contoh Permintaan

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Contoh Respons

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
