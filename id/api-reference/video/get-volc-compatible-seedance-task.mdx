## Ringkasan

Endpoint ini ditujukan untuk tim yang sudah memakai bentuk tugas Seedance bergaya Volc. Autentikasi memakai TokenLab Bearer API key. ID tugas yang dikembalikan diawali `cgt-`; polling status sampai `status` menjadi `succeeded`, `failed`, `cancelled`, atau `expired`.

Lihat juga [Model Video Seedance 2.0](/id/guides/seedance-2-video) dan [Pembuatan Video](/id/guides/video-generation).

## Bentuk respons

Respons tugas menggunakan `queued`, `running`, `succeeded`, `failed`, `cancelled`, atau `expired`. Tugas berhasil mengembalikan `content.video_url`; jika tersedia, juga muncul `content.last_frame_url`, parameter yang dipantulkan seperti `return_last_frame` dan `watermark`, `usage`, dan `progress`. `error` bernilai `null` jika tidak ada kegagalan.

## Contoh

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
