---
title: "Membuat Sesi Verifikasi Orang Asli"
openapi: "POST /v1/videos/assets/visual-validation-sessions"
description: "Membuat sesi H5 verifikasi material orang asli TokenLab."
---

Buat sesi verifikasi berdurasi singkat dan arahkan pengguna Anda ke tautan H5 yang dikembalikan. TokenLab hanya mengembalikan kolom netral: `session_id`, `h5_link`, `callback_url`, `expires_in`, dan `language`.

Sesi dan tautan H5 akan kedaluwarsa setelah 120 detik. Token pengikatan hanya disediakan melalui pengalihan callback TokenLab. Saat alur H5 selesai, TokenLab akan mengarahkan kembali ke `callback_url` asli Anda dengan parameter kueri berikut:

| Parameter | Arti |
|-----------|---------|
| `session_id` | ID sesi verifikasi TokenLab. |
| `verification_token` | Token buram (opaque token) yang digunakan untuk mengikat hasil. |
| `verification_status` | `succeeded` atau `failed`. |
| `result_code` | Kode hasil untuk logika aplikasi Anda. |

Jika `verification_status` adalah `succeeded`, panggil [Bind Real-Person Verification Result](/id/api-reference/video/bind-real-person-verification-result). [Konsol pengujian](https://tokenlab.sh/dashboard/seedance-assets) dapat digunakan untuk memverifikasi penanganan callback sebelum Anda menghubungkan alur tersebut ke dalam produk Anda.

## Contoh Permintaan

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"callback_url":"https://yourapp.example.com/seedance/callback","language":"en"}'
```

## Contoh Respons

```json
{
  "object": "seedance.visual_validation_session",
  "session_id": "svv_abc123",
  "h5_link": "https://verify.example.com/h5?lng=en",
  "callback_url": "https://yourapp.example.com/seedance/callback",
  "expires_in": 120,
  "language": "en"
}
```
