---
title: "Memperbarui Grup Aset Material"
openapi: "PUT /v1/videos/assets/groups/{groupId}"
description: "Memperbarui grup material Seedance yang dimiliki oleh organisasi saat ini."
---

Perbarui nama tampilan, deskripsi, atau metadata untuk grup material. Untuk grup orang asli yang dikelola, pemetaan orang yang diverifikasi tetap tidak berubah.

## Contoh Permintaan

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"group_name":"Updated references","description":"Images approved for summer videos"}'
```

## Contoh Respons

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "library_type": "aigc_avatar",
  "group_name": "Updated references",
  "description": "Images approved for summer videos",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
