---
title: "Mencantumkan Riwayat Verifikasi Orang Asli"
openapi: "GET /v1/videos/assets/visual-validation-sessions"
description: "Mencantumkan sesi verifikasi material orang asli untuk organisasi saat ini."
---

Cantumkan sesi verifikasi sebelumnya untuk keperluan peninjauan, dukungan pelanggan, dan rekonsiliasi. Riwayat ini bersifat jangka panjang, namun tidak menggantikan langkah pengikatan (bind) jangka pendek: verifikasi yang berhasil harus tetap diikat segera dalam jendela waktu 120 detik.

Respons hanya mencakup ID TokenLab dan tidak menyertakan data kredensial. Setelah pengikatan berhasil, `group_id` adalah ID grup material TokenLab yang digunakan untuk unggahan `liveness_face`.

## Contoh Permintaan

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions?page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
