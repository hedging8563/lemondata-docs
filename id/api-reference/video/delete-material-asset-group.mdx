---
title: "Hapus Grup Aset Material"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "Menghapus grup material Seedance yang dimiliki oleh organisasi saat ini."
---

Hapus grup material dan aset material TokenLab di dalamnya. Tindakan ini tidak dapat dibatalkan.

Jika pustaka material TokenLab tidak dapat menyelesaikan penghapusan karena status otorisasi saat ini tidak mengizinkannya, TokenLab akan mengembalikan error pustaka material netral. Setelah dihapus, grup dan asetnya tidak dapat lagi digunakan dalam pembuatan video.

## Contoh Permintaan

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Contoh Respons

```json
{
  "deleted": true,
  "id": "seedance_group_virtual_123"
}
```
