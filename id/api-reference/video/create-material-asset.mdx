---
title: "Membuat Aset Material"
openapi: "POST /v1/videos/assets"
description: "Mengunggah aset material Seedance ke dalam grup material TokenLab."
---

Impor satu URL sumber yang dapat diakses publik ke dalam grup material Seedance. TokenLab menyimpan material tersebut untuk digunakan nanti; gunakan `id` aset material yang dikembalikan untuk pembuatan, bukan URL sumbernya.

Untuk `library_type: "aigc_avatar"`, `group_id` bersifat opsional; TokenLab menggunakan atau membuat grup virtual-avatar default organisasi. Untuk `library_type: "liveness_face"`, `group_id` wajib diisi dan harus berupa grup TokenLab yang dikembalikan oleh [Bind Real-Person Verification Result](/id/api-reference/video/bind-real-person-verification-result).

| Tipe | Input yang didukung |
|------|-----------------|
| Gambar | `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; rasio aspek `(0.4, 2.5)`; lebar dan tinggi `(300, 6000)` px; di bawah 30 MB. |
| Video | `mp4`, `mov`; `480p`, `720p`, atau `1080p`; 2-15 detik; rasio aspek `[0.4, 2.5]`; lebar dan tinggi `[300, 6000]` px; total piksel antara 409600 dan 2086876; hingga 50 MB; 24-60 FPS. |
| Audio | `wav`, `mp3`; 2-15 detik; hingga 15 MB. |

Pembuatan bersifat asinkron. Lakukan polling pada [Get Material Asset](/id/api-reference/video/get-material-asset) hingga `status` menjadi `ACTIVE`. Untuk grup orang asli (real-person), satu grup dipetakan ke satu orang yang terverifikasi; unggahan dengan banyak wajah atau wajah yang tidak cocok dengan orang yang terverifikasi dapat gagal.

## Contoh Permintaan

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"seedance_group_virtual_123","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view"}'
```

## Contoh Respons

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
