---
title: "Create Material Asset"
openapi: "POST /v1/videos/assets"
description: "Uploads a Seedance material asset into a TokenLab material group."
---

Upload one public URL into a Seedance material group.

For `library_type: "aigc_avatar"`, `group_id` is optional; TokenLab uses or creates the organization default virtual-avatar group. For `library_type: "liveness_face"`, `group_id` is required and must be the TokenLab group returned by [Bind Real-Person Verification Result](/id/api-reference/video/bind-real-person-verification-result).

| Type | Supported input |
|------|-----------------|
| Image | `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; aspect ratio `(0.4, 2.5)`; width and height `(300, 6000)` px; under 30 MB. |
| Video | `mp4`, `mov`; `480p`, `720p`, or `1080p`; 2-15 seconds; aspect ratio `[0.4, 2.5]`; width and height `[300, 6000]` px; total pixels between 409600 and 2086876; up to 50 MB; 24-60 FPS. |
| Audio | `wav`, `mp3`; 2-15 seconds; up to 15 MB. |

Creation is asynchronous. Poll [Get Material Asset](/id/api-reference/video/get-material-asset) until `status` is `ACTIVE`. For real-person groups, one group maps to one verified person; uploads with multiple faces or a face that does not match the verified person can fail.

## Example Request

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"seedance_group_virtual_123","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view"}'
```

## Example Response

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",

  "asset_url": "https://example.com/reference.png",
  "cover_url": null,
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
