---
title: "Memperbarui Aset Material"
openapi: "PUT /v1/videos/assets/{assetId}"
description: "Memperbarui aset material Seedance yang dimiliki oleh organisasi saat ini."
---

Perbarui nama material atau metadata. URL sumber dan tipe aset bersifat tetap setelah pembuatan; buat aset baru jika file sumber berubah.

## Contoh Permintaan

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"}}'
```

## Contoh Respons

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view approved",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
