## Ikhtisar

LemonData menyediakan beberapa format API sehingga coding tool, SDK, dan framework umum dapat terintegrasi dengan sedikit glue code.

Halaman ini sengaja lebih sempit daripada sekadar matriks marketing.

- **Didukung** berarti kami mendokumentasikan jalur konfigurasi yang konkret dan LemonData mengekspos protocol shape yang dibutuhkan jalur tersebut.
- **Jalur native yang kuat** berarti repo juga memiliki bukti langsung pada level adapter / request-format untuk keluarga protokol itu.
- **Best-effort** berarti integrasi bisa berjalan, tetapi klien upstream tidak memperlakukan workflow custom gateway ini sebagai kontrak yang stabil.

<Note>
  Field yang tidak didukung tidak ditangani secara seragam. Pada jalur kompatibilitas, beberapa field bisa diabaikan atau dinormalisasi. Pada jalur Responses native, error `400` atau `503` yang eksplisit dapat dikembalikan jika model yang dipilih atau channel yang dirutekan tidak mendukung passthrough yang dibutuhkan.
</Note>

## Format API yang Didukung

| Endpoint | Format | Kasus Penggunaan |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | Kompatibilitas universal |
| `/v1/responses` | OpenAI Responses | Percakapan stateful |
| `/v1/messages` | Anthropic Messages | Fitur native Claude |
| `/v1beta/models/:model:generateContent` | Google Gemini | Fitur native Gemini |

## Kompatibilitas IDE & CLI

### Jalur alat yang didokumentasikan

| Alat | Tingkat dukungan | Format | Catatan |
|------|------------------|--------|---------|
| **Cursor** | Didukung dengan batasan | OpenAI-compatible | Cocok untuk alur BYOK standar chat / editor, bukan berarti menggantikan fitur yang dikelola Cursor seperti Tab Completion |
| **Claude Code CLI** | Jalur native yang kuat | Anthropic | Jalur native `/v1/messages` dengan bukti adapter untuk thinking dan `tool_choice` |
| **Codex CLI** | Didukung tetapi bergantung pada model / channel | OpenAI Responses | Paling cocok dikonfigurasi ke `/v1/responses`; beberapa field Responses-native bergantung pada native passthrough model / channel |
| **Gemini CLI** | Eksperimental / best-effort | Gemini | Alur custom base URL dengan LemonData bukan kontrak upstream yang stabil |
| **OpenCode** | Didukung | OpenAI-compatible | Gunakan provider OpenAI-compatible terlebih dahulu, lalu pindah ke provider Responses hanya jika benar-benar dibutuhkan |

<Note>
  Banyak editor / agent tool OpenAI-compatible lain juga sering bekerja dengan pola base URL yang sama, tetapi repo ini saat ini tidak memelihara regression khusus untuk Windsurf, Aider, Continue.dev, Cline/Roo Code, atau GitHub Copilot.
</Note>

### Contoh Konfigurasi

<Tabs>
  <Tab title="Cursor">
    ```
    Base URL: https://api.lemondata.cc/v1
    API Key: sk-your-lemondata-key
    ```
    Cursor menggunakan format tool bergaya Anthropic secara internal. LemonData mendukung keduanya:
    - Format OpenAI: `{ type: "function", function: { name, parameters } }`
    - Format Anthropic: `{ name, input_schema }` (tanpa field type)
  </Tab>
  <Tab title="Claude Code">
    ```bash
    export ANTHROPIC_BASE_URL="https://api.lemondata.cc"
    export ANTHROPIC_API_KEY="sk-your-lemondata-key"
    ```
  </Tab>
  <Tab title="OpenCode">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"
    export LOCAL_ENDPOINT="https://api.lemondata.cc/v1"
    ```
  </Tab>
  <Tab title="Aider">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"
    export OPENAI_BASE_URL="https://api.lemondata.cc/v1"
    aider --model gpt-5.4
    ```
  </Tab>
</Tabs>

## Kompatibilitas SDK

### Jalur SDK / framework yang didokumentasikan

| SDK / Framework | Bahasa | Tingkat dukungan | Catatan |
|-----------------|--------|------------------|---------|
| **OpenAI SDK** | Python/JS/Go | Jalur inti didukung | Mendokumentasikan Chat Completions, Embeddings, dan alur Responses umum; beberapa field Responses-native-only bergantung pada model / channel passthrough |
| **Anthropic SDK** | Python/JS | Jalur native yang kuat | Jalur Messages native dengan bukti langsung untuk tools, thinking, dan prompt caching |
| **Vercel AI SDK** | TypeScript | Pola integrasi yang direkomendasikan | Utamakan `@ai-sdk/openai-compatible`, dan gunakan `@ai-sdk/openai` hanya saat benar-benar memerlukan Responses-native |
| **LangChain** | Python/JS | Surface standar didukung | Cakupan yang dimaksud adalah `ChatOpenAI` dan `OpenAIEmbeddings`; extra vendor-native berada di luar cakupan |
| **LlamaIndex** | Python | Didukung melalui `OpenAILike` | Untuk gateway pihak ketiga seperti LemonData, gunakan `OpenAILike` alih-alih kelas OpenAI bawaan |
| **Dify** | - | Didukung dengan batasan | Jalur yang diharapkan adalah provider OpenAI dan alur berorientasi chat-completions; tidak menjamin perilaku Codex-specific Responses / WebSocket |

## Parameter Chat Completions

### Parameter Inti

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Identifier model (wajib) |
| `messages` | array | Pesan percakapan (wajib) |
| `max_tokens` | integer | Token output maksimum |
| `temperature` | number | Temperature sampling (0-2) |
| `top_p` | number | Nucleus sampling (0-1) |
| `stream` | boolean | Aktifkan streaming |

### Pemanggilan Tool

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Opsi Tool Choice

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | Pemilihan sederhana |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | Paksa function tertentu |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Format native Anthropic |

### Parameter Lanjutan

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | `{ include_usage: true }` untuk jumlah token |
| `reasoning_effort` | string | `"low"`, `"medium"`, `"high"` untuk model GPT-5 dengan reasoning |
| `service_tier` | string | `"auto"` atau `"default"` |
| `seed` | integer | Output deterministik |
| `logprobs` | boolean | Kembalikan probabilitas log |
| `top_logprobs` | integer | Jumlah `logprobs` teratas (0-20) |
| `logit_bias` | object | Peta bias token (-100 hingga 100) |
| `frequency_penalty` | number | Penalti pengulangan (-2 hingga 2) |
| `presence_penalty` | number | Penalti topik (-2 hingga 2) |
| `stop` | string/array | Urutan stop |
| `n` | integer | Jumlah completion (1-128) |
| `user` | string | Identifier pengguna untuk pelacakan |

### Fitur Lanjutan OpenAI

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | `["text", "audio"]` untuk multimodal |
| `audio` | object | Konfigurasi output audio (voice, format) |
| `prediction` | object | Output prediksi untuk completion yang lebih cepat |
| `metadata` | object | Pasangan key-value untuk pelacakan |
| `store` | boolean | Simpan untuk pengambilan nanti |

### Opsi Khusus Provider

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Parameter Responses API

### Parameter Inti

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Identifier model |
| `input` | string/array | Konten input |
| `instructions` | string | Instruksi sistem |
| `max_output_tokens` | integer | Token output maksimum |
| `previous_response_id` | string | Lanjutkan percakapan |

### Parameter Lanjutan

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` atau `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | Untuk model reasoning |
| `service_tier` | string | Tier prioritas |

### Format Tool

Mendukung format tool OpenAI dan Anthropic:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## Streaming

Semua endpoint mendukung streaming Server-Sent Events (SSE):

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## Penanganan Error

LemonData mengembalikan respons error yang kompatibel dengan OpenAI:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

Lihat [Panduan Penanganan Error](/guides/error-handling) untuk detail.

## Praktik Terbaik

<AccordionGroup>
  <Accordion title="Gunakan passthrough untuk parameter yang tidak dikenal">
    Semua skema menggunakan `.passthrough()` - parameter yang tidak dikenal diteruskan ke provider upstream.
  </Accordion>

  <Accordion title="Utamakan stream_options untuk billing yang akurat">
    Aktifkan `stream_options.include_usage` untuk jumlah token yang akurat dalam respons streaming.
  </Accordion>

  <Accordion title="Gunakan format tool_choice yang sesuai">
    Sesuaikan dengan format yang diharapkan SDK Anda. LemonData menerima format OpenAI dan Anthropic.
  </Accordion>
</AccordionGroup>
