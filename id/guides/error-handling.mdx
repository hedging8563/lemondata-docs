## Format Respons Error

Semua error mengembalikan format JSON yang konsisten dengan [petunjuk Agent-First](/guides/agent-first-api) opsional:

```json
{
  "error": {
    "message": "Human-readable error description",
    "type": "error_type",
    "code": "error_code",
    "param": "parameter_name",
    "did_you_mean": "suggested_model",
    "suggestions": [{"id": "model-id"}],
    "hint": "Next step guidance",
    "retryable": true,
    "retry_after": 30
  }
}
```

Field dasar (`message`, `type`, `code`, `param`) selalu ada. Field petunjuk (`did_you_mean`, `suggestions`, `hint`, `retryable`, `retry_after`, `balance_usd`, `estimated_cost_usd`) adalah ekstensi opsional untuk koreksi mandiri AI agent. Lihat [panduan Agent-First API](/guides/agent-first-api) untuk detail.

Endpoint yang kompatibel dengan OpenAI menggunakan tipe error gateway stabil milik LemonData. Endpoint yang kompatibel dengan Anthropic dan Gemini menggunakan kelompok error native mereka sendiri dan bentuk respons masing-masing.

## Kode Status HTTP

| Code | Description |
|------|-------------|
| 400 | Bad Request - Parameter tidak valid |
| 401 | Unauthorized - API key tidak valid atau tidak ada |
| 402 | Payment Required - Saldo tidak mencukupi |
| 403 | Forbidden - Akses ditolak atau model tidak diizinkan |
| 404 | Not Found - Model atau resource tidak ditemukan |
| 413 | Payload Too Large - Ukuran input atau file melebihi batas |
| 429 | Too Many Requests - Batas rate limit terlampaui |
| 500 | Internal Server Error |
| 502 | Bad Gateway - Error dari provider upstream |
| 503 | Service Unavailable - Layanan sementara tidak tersedia |
| 504 | Gateway Timeout - Permintaan melebihi batas waktu |

## Tipe Error

### Error Autentikasi (401)

| Type | Code | Description |
|------|------|-------------|
| `invalid_api_key` | `invalid_api_key` | API key tidak ada atau tidak valid |
| `expired_api_key` | `expired_api_key` | API key telah dicabut |

```python
from openai import OpenAI, AuthenticationError

try:
    response = client.chat.completions.create(...)
except AuthenticationError as e:
    print(f"Authentication failed: {e.message}")
```

### Error Pembayaran (402)

| Type | Code | Description |
|------|------|-------------|
| `insufficient_balance` | `insufficient_balance` | Saldo akun terlalu rendah (endpoint yang kompatibel dengan OpenAI) |
| `insufficient_balance_error` | `insufficient_balance` | Saldo akun terlalu rendah (endpoint yang kompatibel dengan Anthropic) |
| `quota_exceeded` | `quota_exceeded` | Batas penggunaan API key tercapai |

```python
from openai import OpenAI, APIStatusError

try:
    response = client.chat.completions.create(...)
except APIStatusError as e:
    if e.status_code == 402:
        print("Please top up your account balance")
```

### Error Akses (403)

| Type | Code | Description |
|------|------|-------------|
| `access_denied` | `access_denied` | Akses ke resource ditolak |
| `access_denied` | `model_not_allowed` | Model tidak diizinkan untuk API key ini |

```json
{
  "error": {
    "message": "You don't have permission to access this model",
    "type": "access_denied",
    "code": "model_not_allowed"
  }
}
```

### Error Validasi (400)

| Type | Description |
|------|-------------|
| `invalid_request_error` | Parameter permintaan tidak valid |
| `context_length_exceeded` | Input terlalu panjang untuk model |
| `model_not_found` | Model yang diminta tidak ada |

```json
{
  "error": {
    "message": "Model 'invalid-model' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [{"id": "gpt-5.4"}, {"id": "gpt-5-mini"}],
    "hint": "Did you mean 'gpt-5.4'? Use GET /v1/models to list all available models."
  }
}
```

### Error Rate Limit (429)

Saat Anda melampaui rate limit:

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

**Header yang disertakan:**

```
Retry-After: 8
```

Header `Retry-After` dan field `retry_after` keduanya menunjukkan jumlah detik yang tepat untuk menunggu sebelum mencoba lagi.

### Payload Terlalu Besar (413)

Saat ukuran input atau file melebihi batas:

```json
{
  "error": {
    "message": "Input size exceeds maximum allowed",
    "type": "invalid_request_error",
    "code": "payload_too_large"
  }
}
```

Penyebab umum:
- File gambar terlalu besar (maks 20MB)
- File audio terlalu besar (maks 25MB)
- Teks input melebihi panjang konteks model

### Error Upstream (502, 503)

| Type | Description |
|------|-------------|
| `upstream_error` | Provider mengembalikan error |
| `all_channels_failed` | Tidak ada provider yang tersedia |
| `timeout_error` | Permintaan melebihi batas waktu |

Saat semua channel gagal, respons menyertakan model alternatif:

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-6", "status": "available", "tags": []},
      {"id": "gpt-5-mini", "status": "available", "tags": []}
    ],
    "hint": "Retry in 30s or switch to an available model."
  }
}
```

## Menangani Error di Python

```python
from openai import OpenAI, APIError, RateLimitError, APIConnectionError

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

def chat_with_retry(messages, max_retries=3):
    for attempt in range(max_retries):
        try:
            return client.chat.completions.create(
                model="gpt-4o",
                messages=messages
            )
        except RateLimitError as e:
            if attempt < max_retries - 1:
                import time
                time.sleep(2 ** attempt)  # Exponential backoff
                continue
            raise
        except APIConnectionError as e:
            print(f"Connection error: {e}")
            raise
        except APIError as e:
            print(f"API error: {e.status_code} - {e.message}")
            raise
```

## Menangani Error di JavaScript

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function chatWithRetry(messages, maxRetries = 3) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      return await client.chat.completions.create({
        model: 'gpt-4o',
        messages
      });
    } catch (error) {
      if (error instanceof OpenAI.RateLimitError) {
        if (attempt < maxRetries - 1) {
          await new Promise(r => setTimeout(r, 2 ** attempt * 1000));
          continue;
        }
      }
      throw error;
    }
  }
}
```

## Praktik Terbaik

<AccordionGroup>
  <Accordion title="Terapkan exponential backoff">
    Saat terkena rate limit, tunggu lebih lama secara bertahap di antara percobaan ulang:
    ```python
    wait_time = 2 ** attempt  # 1s, 2s, 4s, 8s...
    ```
  </Accordion>

  <Accordion title="Tetapkan timeout">
    Selalu tetapkan timeout yang wajar untuk menghindari permintaan yang menggantung:
    ```python
    client = OpenAI(timeout=60.0)  # 60 second timeout
    ```
  </Accordion>

  <Accordion title="Catat error untuk debugging">
    Catat respons error lengkap termasuk request ID untuk dukungan:
    ```python
    except APIError as e:
        logger.error(f"API Error: {e.status_code} - {e.message}")
    ```
  </Accordion>

  <Accordion title="Tangani error spesifik model">
    Beberapa model memiliki persyaratan khusus (misalnya, token maksimum, format gambar).
    Validasikan input sebelum membuat permintaan.
  </Accordion>
</AccordionGroup>
