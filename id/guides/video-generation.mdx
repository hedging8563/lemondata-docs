## Ringkasan

LemonData menyediakan akses ke model pembuatan video dari 11 penyedia melalui satu API terpadu. Pembuatan video bersifat **asinkron** — Anda mengirimkan request, menerima task ID dan `poll_url`, lalu melakukan poll untuk hasilnya.

<Info>
Daftar model sering diperbarui. Untuk model dan harga terbaru yang tersedia, kunjungi [halaman Models](https://lemondata.cc/id/models) atau gunakan [Models API](/api-reference/models/list-models).
</Info>

### Alur Kerja Async

```mermaid
sequenceDiagram
    participant Client
    participant LemonData
    participant Provider

    Client->>LemonData: POST /v1/videos/generations
    LemonData->>Provider: Forward request
    Provider-->>LemonData: task_id + pending
    LemonData-->>Client: { task_id, poll_url, status: "pending" }

    loop Poll every 5-10s
        Client->>LemonData: GET poll_url
        LemonData->>Provider: Query status
        Provider-->>LemonData: Status update
        LemonData-->>Client: { status, video_url? }
    end
```

<CodeGroup>

```python Python
import requests
import time

API_KEY = "sk-your-api-key"
BASE = "https://api.lemondata.cc/v1"
headers = {"Authorization": f"Bearer {API_KEY}"}

# Step 1: Submit generation request
resp = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "kling-v2.6-pro",
        "prompt": "A golden retriever running on a beach at sunset, cinematic 4K",
        "duration": 5,
        "aspect_ratio": "16:9"
    }
)
create_data = resp.json()
task_id = create_data["task_id"]
poll_url = create_data["poll_url"]

# Step 2: Poll for result
while True:
    status = requests.get(f"https://api.lemondata.cc{poll_url}", headers=headers).json()
    if status["status"] in ("completed", "succeeded"):
        print(f"Video URL: {status['video_url']}")
        break
    elif status["status"] == "failed":
        print(f"Failed: {status.get('error')}")
        break
    time.sleep(10)
```

```javascript JavaScript
const API_KEY = 'sk-your-api-key';
const BASE = 'https://api.lemondata.cc/v1';
const headers = { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' };

// Step 1: Submit
const { task_id, poll_url } = await fetch(`${BASE}/videos/generations`, {
  method: 'POST', headers,
  body: JSON.stringify({
    model: 'kling-v2.6-pro',
    prompt: 'A golden retriever running on a beach at sunset, cinematic 4K',
    duration: 5,
    aspect_ratio: '16:9'
  })
}).then(r => r.json());

// Step 2: Poll
const poll = setInterval(async () => {
  const status = await fetch(`https://api.lemondata.cc${poll_url}`, { headers }).then(r => r.json());
  if (['completed', 'succeeded'].includes(status.status)) {
    console.log('Video URL:', status.video_url);
    clearInterval(poll);
  } else if (status.status === 'failed') {
    console.error('Failed:', status.error);
    clearInterval(poll);
  }
}, 10000);
```

### Definisi Kapabilitas

- **T2V (Text-to-Video)**: Buat video dari prompt teks
- **I2V (Image-to-Video)**: Animasikan gambar statis menjadi video. Untuk kompatibilitas terluas, berikan `image_url` publik.
- **Keyframe**: Kendalikan frame awal dan akhir dengan `start_image` + `end_image`
- **Extension**: Perpanjang durasi video yang sudah ada
- **Editing**: Ubah aspek tertentu dari video yang sudah ada

## Contoh Penggunaan

### Text-to-Video (T2V)

Use case yang paling umum. Semua model mendukung ini.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "veo3.1-pro",
        "prompt": "Aerial drone shot of a coastal city at golden hour, waves crashing against cliffs",
        "duration": 5,
        "aspect_ratio": "16:9",
        "resolution": "1080p"
    }
)
```

### Image-to-Video (I2V)

Animasikan gambar statis. Untuk kompatibilitas terluas di berbagai model video, host gambar sumber dan kirimkan `image_url`.

```python
# Using image URL
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "wan2.6-i2v",
        "prompt": "The person slowly turns and smiles at the camera",
        "image_url": "https://example.com/portrait.jpg"
    }
)

```

### Kontrol Keyframe (Gambar Awal + Akhir)

Kendalikan frame pertama dan terakhir untuk transisi yang presisi. Saat ini didukung oleh Seedance 2.0.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "seedance-2-0",
        "prompt": "Smooth transition from day to night, city lights gradually turning on",
        "start_image": "https://example.com/city-day.jpg",
        "end_image": "https://example.com/city-night.jpg",
        "duration": 5
    }
)
```

### Perpanjangan Video

Perpanjang durasi video yang sudah ada. Gunakan model dengan kapabilitas extension.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "kling-video-extend",
        "prompt": "Continue the scene naturally",
        "image_url": "https://example.com/last-frame.jpg"
    }
)
```

## Referensi Parameter

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | ID model (default: `sora-2`) |
| `prompt` | string | **Wajib.** Deskripsi teks dari video |
| `image_url` | string | URL dari gambar awal (untuk I2V) |
| `image` | string | Gambar inline sebagai data URL. Didukung oleh model yang kompatibel, tetapi `image_url` memberikan kompatibilitas paling luas. |
| `duration` | integer | Durasi video dalam detik (1-60, bergantung pada model) |
| `aspect_ratio` | string | `16:9`, `9:16`, `1:1`, dll. |
| `resolution` | string | `1080p`, `720p`, `4k` |
| `fps` | integer | Frame per detik (1-120) |
| `negative_prompt` | string | Hal yang harus dihindari dalam pembuatan |
| `seed` | integer | Seed acak untuk reproduksibilitas |
| `cfg_scale` | number | Skala panduan (0-20) |
| `motion_strength` | number | Intensitas gerakan (0-1) |
| `start_image` | string | URL dari keyframe awal |
| `end_image` | string | URL dari keyframe akhir |

<Warning>
Tidak semua parameter didukung oleh setiap model. Parameter yang tidak didukung akan diabaikan tanpa pemberitahuan. Periksa dokumentasi model untuk parameter yang didukung.
</Warning>

## Penagihan

Pembuatan video menggunakan **harga tetap per pembuatan**. Anda dikenai biaya satu kali saat task dikirimkan, terlepas dari durasi video. Jika pembuatan gagal, biaya akan dikembalikan secara otomatis.

Periksa harga terkini di [halaman Models](https://lemondata.cc/id/models) atau melalui [Pricing API](/api-reference/pricing/get-pricing).
