## Ikhtisar

LemonData menggunakan **harga pay-as-you-go**. Anda hanya membayar sesuai penggunaan, tanpa langganan atau komitmen minimum.

## Cara Kerja Penagihan

1. **Tambahkan kredit** ke akun Anda
2. **Gunakan API** - biaya dipotong per request
3. **Pantau penggunaan** di dashboard Anda
4. **Isi ulang** saat saldo Anda rendah

### Penagihan Tugas Async (Video/Musik/3D)

<Warning>
  **Penting**: Tugas generasi video, musik, dan 3D **ditagihkan pada saat pengiriman**, bukan saat selesai.
</Warning>

Untuk tugas generasi async (video, musik, model 3D):

1. **Penagihan terjadi segera** saat Anda mengirimkan tugas
2. Anda akan menerima `task_id` untuk memeriksa status
3. **Tidak ada pengembalian dana otomatis** jika tugas gagal

Hal ini karena penyedia upstream menagih kami saat tugas dikirimkan, terlepas dari hasilnya. Jika Anda mengalami kegagalan tugas, silakan hubungi support@lemondata.cc untuk bantuan.

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

task_id = response.json()["task_id"]
# Poll for status...
```

## Penghitungan Token

Token adalah unit dasar pemrosesan teks:

- ~4 karakter = 1 token (Bahasa Inggris)
- ~1-2 karakter = 1 token (Bahasa Mandarin)
- 1 gambar = bervariasi berdasarkan ukuran dan detail

### Memperkirakan Token

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## Pelacakan Penggunaan

### Dashboard

Pantau penggunaan Anda di [Dashboard](https://lemondata.cc/dashboard):

- Saldo real-time
- Riwayat penggunaan berdasarkan model
- Rincian biaya
- Penggunaan API key

### Respons API

Setiap respons menyertakan informasi penggunaan:

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Peringatan Saldo Rendah

Konfigurasikan peringatan saat saldo Anda menurun:

1. Buka **Dashboard → Settings → Notifications**
2. Tetapkan jumlah ambang batas Anda
3. Terima notifikasi email

## Menambahkan Kredit

### Metode Pembayaran

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### Langkah-langkah

1. Masuk ke [Dashboard](https://lemondata.cc/dashboard)
2. Klik **Add Credits**
3. Pilih jumlah dan metode pembayaran
4. Selesaikan pembayaran

Kredit ditambahkan secara instan setelah konfirmasi pembayaran.

## Batas API Key

Anda dapat menetapkan batas pengeluaran pada masing-masing API key:

1. Buka **Dashboard → API Keys**
2. Klik key untuk mengedit
3. Setel **Usage Limit**

Saat batas tercapai, request dengan key tersebut akan mengembalikan `402 Payment Required`.

## Faktur

Untuk akun bisnis, faktur tersedia:

1. Buka **Dashboard → Billing**
2. Lihat riwayat transaksi
3. Unduh faktur sebagai PDF
