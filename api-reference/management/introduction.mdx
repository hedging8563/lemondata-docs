## Overview

The Management API lets you automate **organization API key lifecycle** and **key-level reporting** without using a standard inference API key.

Use a **management token** from your Dashboard Settings page:

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
Management tokens are different from standard `sk-...` inference API keys.

- Use `mt-...` for `/v1/management/*`
- Use `sk-...` for model inference endpoints such as `/v1/responses`
</Warning>

## Available Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/v1/management/api-keys` | GET | List user-managed API keys in the organization |
| `/v1/management/api-keys` | POST | Create a new user API key |
| `/v1/management/api-keys/{keyId}` | PATCH | Update name, limit, models, expiry, or status |
| `/v1/management/api-keys/{keyId}/usage` | GET | Retrieve paginated key-level usage details |
| `/v1/management/api-keys/{keyId}/billing` | GET | Retrieve aggregated key-level billing breakdowns |

## Safe Response Contract

Management API responses expose only **public billing and reporting fields** such as:

- logical model
- public model vendor
- scene
- access channel (`platform` or `byok`)
- usage unit and quantity
- cache metrics
- cost and timestamps

They do **not** expose internal routing implementation details.

## Notes

- Management API does **not** support hard-deleting API keys in v1.
- Use `PATCH` with a revoked status to disable a key.
- Key-level billing is consumption-only and does not include recharge or invoice records.
