---
title: "Update API Key"
openapi: "PATCH /v1/management/api-keys/{keyId}"
description: "Updates an existing user API key for the current organization."
---

## Overview

Use this endpoint to update:

- name
- usage limit
- allowed models
- expiry
- status (`active`, `inactive`, `revoked`)

Hard delete is intentionally not supported in the Management API v1.
