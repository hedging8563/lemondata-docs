title: "Reseller Settlement Multipliers"
description: "Private Management API endpoint for reseller settlement multipliers."
---

## Overview

`GET /v1/management/reseller/settlement-multipliers` returns the partner-specific settlement multiplier for public model IDs.

This is a private reseller endpoint. It requires a management token with:

```text
reseller_settlement:read
```

It does not return model official prices, platform prices, pricing details, upstream cost, platform profit, or gross profit.

## Query Parameters

| Parameter | Type | Default / Limits | Notes |
|-----------|------|------------------|-------|
| `page` | integer | default `1`, min `1` | 1-based page number |
| `limit` | integer | default `50`, min `1`, max `100` | Page size |
| `model` | string | max length `100` | Optional public model ID |

## Response Fields

| Field | Type | Notes |
|-------|------|-------|
| `object` | string | Always `list` |
| `organization_id` | string | Organization associated with the management token |
| `data[].object` | string | `management_reseller_settlement_multiplier` |
| `data[].model` | string | Public model ID |
| `data[].currency` | string | `USD` |
| `data[].settlement_multiplier` | string \| null | Decimal multiplier relative to provider official price |
| `data[].discount_source` | string | Organization or model discount source |
| `data[].status` | enum | `available`, `missing_price_basis`, or `inconsistent_price_basis` |
| `pagination` | object | Page, limit, total, and totalPages |

## Status Semantics

| Status | Meaning |
|--------|---------|
| `available` | Settlement multiplier is safe to use. |
| `missing_price_basis` | The model does not have a usable official-price multiplier basis. Do not publish it in the reseller catalog until pricing is fixed. |
| `inconsistent_price_basis` | Structured prices do not share one consistent multiplier. Do not publish it in the reseller catalog until pricing is fixed. |

## Example

<RequestExample>
```bash cURL

  -H "Authorization: Bearer mt-your-management-token"
```

</RequestExample>

## Security Boundary

This endpoint is intentionally absent from the public OpenAPI file. Use it only from trusted reseller backend jobs or console services. Do not call it from a browser with a management token.
