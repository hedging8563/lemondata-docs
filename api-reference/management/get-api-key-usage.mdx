---
title: "Get API Key Usage"
openapi: "GET /v1/management/api-keys/{keyId}/usage"
description: "Returns paginated usage details for a user API key."
---

## Overview

This endpoint returns key-level usage details with filters for:

- time range
- logical model
- public model vendor
- scene
- access channel (`platform` / `byok`)

## Notes

- The response includes public billing fields only.
- Internal routing and physical channel metadata are intentionally hidden.
