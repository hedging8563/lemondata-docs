---

## Overview

This endpoint returns consumption-only billing aggregates for the selected API key.

It includes:

- total cost
- total requests
- usage unit breakdown
- breakdowns by logical model, vendor, scene, access channel, and cache class
- daily cost trend

Recharge, invoices, and other organization-level financial records are intentionally excluded.
