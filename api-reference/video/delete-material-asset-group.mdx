---
title: "Delete Material Asset Group"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "Deletes a Seedance material group owned by the current organization."
---

Delete a material group and the TokenLab material assets inside it. This cannot be undone.

If the backing material service refuses deletion because the current authorization state does not allow it, TokenLab returns a neutral material-library error. After deletion, the group and its assets can no longer be used in video generation.

## Example Request

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Example Response

```json
{
  "deleted": true,
  "id": "seedance_group_virtual_123"
}
```
