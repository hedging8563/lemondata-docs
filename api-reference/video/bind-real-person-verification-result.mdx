---
title: "Bind Real-Person Verification Result"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "Binds a successful real-person material verification result to a TokenLab material group."
---

Bind the successful verification result and create the TokenLab real-person material group mapping. Use the `session_id` and `verification_token` from the TokenLab callback redirect.

TokenLab verifies that the session belongs to the same organization and has not expired. The response returns a TokenLab `group_id` only; use it when creating `liveness_face` material assets.

## Example Request

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## Example Response

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "seedance_group_real_123",
  "material_group": {
    "id": "seedance_group_real_123",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
