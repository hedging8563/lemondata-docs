title: "List Seedance Tasks (Volc Compatible)"
openapi: "GET /api/v3/contents/generations/tasks"
description: "List recent Seedance compatibility tasks for the current organization."
---

## Overview

These endpoints are for teams that already use the Volc-style Seedance task shape. Authentication uses your TokenLab Bearer API key. The returned task ID starts with `cgt-`; poll the status endpoint until `status` becomes `succeeded`, `failed`, `cancelled`, or `expired`.

See also [Seedance 2.0 Video Models](/guides/seedance-2-video) and [Video Generation](/guides/video-generation).

## Response Shape

The list response returns `items` and `total`. Supported filters are `filter.status`, `filter.task_ids`, `filter.model`, and `filter.service_tier`, with `page_num` and `page_size` for pagination.

## Example

```bash
curl "https://api.tokenlab.sh/api/v3/contents/generations/tasks?page_num=1&page_size=20&filter.status=succeeded" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
