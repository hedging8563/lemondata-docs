## Overview

These endpoints are for teams that already use the Volc-style Seedance task shape. Authentication uses your TokenLab Bearer API key. The returned task ID starts with `cgt-`; poll the status endpoint until `status` becomes `succeeded`, `failed`, `cancelled`, or `expired`.

See also [Seedance 2.0 Video Models](/guides/seedance-2-video) and [Video Generation](/guides/video-generation).

## Response Shape

The task response uses `queued`, `running`, `succeeded`, `failed`, `cancelled`, or `expired`. Successful tasks return `content.video_url`; `content.last_frame_url`, echoed request parameters such as `return_last_frame` and `watermark`, `usage`, and `progress` appear when available. `error` is `null` when there is no failure.

## Example

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
