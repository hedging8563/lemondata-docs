openapi: "DELETE /api/v3/contents/generations/tasks/{id}"
description: "Cancel a queued Seedance compatibility task when cancellation is still available."
---

## Overview

These endpoints are for teams that already use the Volc-style Seedance task shape. Authentication uses your TokenLab Bearer API key. The returned task ID starts with `cgt-`; poll the status endpoint until `status` becomes `succeeded`, `failed`, `cancelled`, or `expired`.

See also [Seedance 2.0 Video Models](/guides/seedance-2-video) and [Video Generation](/guides/video-generation).

## Response Shape

A successful cancel request returns HTTP 200 with an empty body. Query the task afterward if you need to confirm its final status.

## Example

```bash
curl -X DELETE https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
