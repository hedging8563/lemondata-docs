## نظرة عامة

توفر LemonData عدة تنسيقات API حتى تتمكن coding tools وSDKs والأطر الشائعة من التكامل مع قدر قليل من glue code.

هذه الصفحة أضيق عمدًا من مصفوفة تسويقية عامة.

- **مدعوم** يعني أننا نوثّق مسار إعداد واضحًا وأن LemonData تعرض شكل البروتوكول الذي يحتاجه هذا المسار.
- **مسار أصلي قوي** يعني أن المستودع يحتوي أيضًا على أدلة مباشرة على مستوى adapter / request-format لهذه العائلة من البروتوكولات.
- **Best-effort** يعني أن التكامل قد ينجح، لكن العميل upstream لا يتعامل مع هذا workflow الخاص بالـ gateway المخصصة على أنه عقد مستقر.

<Note>
  الحقول غير المدعومة لا تُعالج بطريقة موحّدة. في مسارات التوافق قد يتم تجاهل بعض الحقول أو تطبيعها. وفي مسارات Responses الأصلية قد تُعاد أخطاء صريحة من نوع `400` أو `503` إذا كان النموذج المختار أو القناة الموجّهة لا يدعمان passthrough المطلوب.
</Note>

## تنسيقات API المدعومة

| Endpoint | التنسيق | حالة الاستخدام |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | توافق عام |
| `/v1/responses` | OpenAI Responses | محادثات ذات حالة |
| `/v1/messages` | Anthropic Messages | ميزات Claude الأصلية |
| `/v1beta/models/:model:generateContent` | Google Gemini | ميزات Gemini الأصلية |

## توافق IDE وCLI

### مسارات الأدوات الموثقة

| الأداة | مستوى الدعم | التنسيق | ملاحظات |
|-------|-------------|---------|---------|
| **Cursor** | مدعوم مع حدود | OpenAI-compatible | مناسب لتدفقات BYOK القياسية في chat / editor، وليس بديلًا عن ميزات يديرها Cursor مثل Tab Completion |
| **Claude Code CLI** | مسار أصلي قوي | Anthropic | مسار `/v1/messages` الأصلي مع أدلة adapter على thinking و`tool_choice` |
| **Codex CLI** | مدعوم لكن يعتمد على النموذج / القناة | OpenAI Responses | الأفضل تهيئته على `/v1/responses`؛ بعض حقول Responses-native تعتمد على passthrough الأصلي للنموذج / القناة |
| **Gemini CLI** | تجريبي / best-effort | Gemini | مسار base URL المخصص مع LemonData ليس عقد upstream مستقرًا |
| **OpenCode** | مدعوم | OpenAI-compatible | استخدم أولًا provider متوافقًا مع OpenAI، ولا تنتقل إلى Responses إلا عند الحاجة الواضحة |

<Note>
  كثير من editor / agent tools المتوافقة مع OpenAI تعمل أيضًا مع نمط base URL نفسه، لكن هذا المستودع لا يحافظ حاليًا على تغطية regression مخصصة لـ Windsurf أو Aider أو Continue.dev أو Cline/Roo Code أو GitHub Copilot.
</Note>

### أمثلة الإعداد

<Tabs>
  <Tab title="Cursor">
    ```
    Base URL: https://api.lemondata.cc/v1
    API Key: sk-your-lemondata-key
    ```
    يستخدم Cursor داخليًا تنسيق أدوات بأسلوب Anthropic. يدعم LemonData كليهما:
    - تنسيق OpenAI: `{ type: "function", function: { name, parameters } }`
    - تنسيق Anthropic: `{ name, input_schema }` (بدون حقل type)
  </Tab>
  <Tab title="Claude Code">
    ```bash
    export ANTHROPIC_BASE_URL="https://api.lemondata.cc"
    export ANTHROPIC_API_KEY="sk-your-lemondata-key"
    ```
  </Tab>
  <Tab title="OpenCode">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"
    export LOCAL_ENDPOINT="https://api.lemondata.cc/v1"
    ```
  </Tab>
  <Tab title="Aider">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"
    export OPENAI_BASE_URL="https://api.lemondata.cc/v1"
    aider --model gpt-5.4
    ```
  </Tab>
</Tabs>

## توافق SDK

### مسارات SDK / frameworks الموثقة

| SDK / Framework | اللغة | مستوى الدعم | ملاحظات |
|-----------------|-------|-------------|---------|
| **OpenAI SDK** | Python/JS/Go | المسار الأساسي مدعوم | يوثّق Chat Completions وEmbeddings وتدفقات Responses الشائعة؛ بعض حقول Responses-native-only تعتمد على passthrough النموذج / القناة |
| **Anthropic SDK** | Python/JS | مسار أصلي قوي | مسار Messages أصلي مع أدلة مباشرة على tools وthinking وprompt caching |
| **Vercel AI SDK** | TypeScript | نمط تكامل موصى به | يُفضّل `@ai-sdk/openai-compatible`، ويُستخدم `@ai-sdk/openai` فقط عندما تحتاج Responses-native بشكل صريح |
| **LangChain** | Python/JS | السطح القياسي مدعوم | النطاق المقصود يشمل `ChatOpenAI` و`OpenAIEmbeddings`، أما إضافات vendor-native فهي خارج النطاق |
| **LlamaIndex** | Python | مدعوم عبر `OpenAILike` | في gateways الطرف الثالث مثل LemonData، استخدم `OpenAILike` بدلًا من فئات OpenAI المدمجة |
| **Dify** | - | مدعوم مع حدود | المسار المتوقع هو provider OpenAI وتدفقات موجهة إلى chat-completions؛ ولا توجد ضمانات لسلوكيات Codex-specific Responses / WebSocket |

## معلمات Chat Completions

### المعلمات الأساسية

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | معرّف النموذج (مطلوب) |
| `messages` | array | رسائل المحادثة (مطلوب) |
| `max_tokens` | integer | الحد الأقصى لـ tokens الناتجة |
| `temperature` | number | درجة حرارة أخذ العينات (0-2) |
| `top_p` | number | أخذ العينات النووي (0-1) |
| `stream` | boolean | تمكين البث |

### استدعاء الأدوات

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### خيارات Tool Choice

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | اختيار بسيط |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | فرض دالة محددة |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | تنسيق Anthropic الأصلي |

### المعلمات المتقدمة

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | `{ include_usage: true }` لعدد الـ tokens |
| `reasoning_effort` | string | `"low"` أو `"medium"` أو `"high"` لنماذج GPT-5 الممكّنة للاستدلال |
| `service_tier` | string | `"auto"` أو `"default"` |
| `seed` | integer | مخرجات حتمية |
| `logprobs` | boolean | إرجاع احتمالات السجل |
| `top_logprobs` | integer | عدد أعلى احتمالات السجل (0-20) |
| `logit_bias` | object | خريطة انحياز token (-100 إلى 100) |
| `frequency_penalty` | number | عقوبة التكرار (-2 إلى 2) |
| `presence_penalty` | number | عقوبة الموضوع (-2 إلى 2) |
| `stop` | string/array | تسلسلات الإيقاف |
| `n` | integer | عدد الإكمالات (1-128) |
| `user` | string | معرّف المستخدم للتتبع |

### ميزات OpenAI المتقدمة

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | `["text", "audio"]` للوسائط المتعددة |
| `audio` | object | إعدادات إخراج الصوت (الصوت، التنسيق) |
| `prediction` | object | ناتج متوقّع لإكمال أسرع |
| `metadata` | object | أزواج مفتاح-قيمة للتتبع |
| `store` | boolean | التخزين للاسترجاع لاحقًا |

### خيارات خاصة بالمزوّد

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## معلمات Anthropic Messages

### المعلمات الأساسية

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | معرّف النموذج |
| `messages` | array | رسائل المحادثة |
| `max_tokens` | integer | الحد الأقصى للإخراج (حتى 128000) |
| `system` | string/array | system prompt |
| `stream` | boolean | تمكين البث |

### استدعاء الأدوات

```json
{
  "tools": [
    {
      "name": "get_weather",
      "description": "Get weather",
      "input_schema": {
        "type": "object",
        "properties": {
          "location": { "type": "string" }
        }
      }
    }
  ],
  "tool_choice": {
    "type": "auto",
    "disable_parallel_tool_use": false
  }
}
```

### التفكير الموسّع

```json
{
  "model": "claude-opus-4-6",
  "thinking": {
    "type": "enabled",
    "budget_tokens": 10000
  }
}
```

## معلمات Responses API

### المعلمات الأساسية

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | معرّف النموذج |
| `input` | string/array | محتوى الإدخال |
| `instructions` | string | تعليمات النظام |
| `max_output_tokens` | integer | الحد الأقصى لـ tokens الناتجة |
| `previous_response_id` | string | متابعة المحادثة |

### المعلمات المتقدمة

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` أو `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | لنماذج الاستدلال |
| `service_tier` | string | طبقة الأولوية |

### تنسيق الأدوات

يدعم كلا تنسيقي الأدوات OpenAI وAnthropic:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## معلمات Gemini API

### المعلمات الأساسية

| Parameter | Type | Description |
|-----------|------|-------------|
| `contents` | array | محتوى المحادثة |
| `systemInstruction` | object | system prompt |
| `generationConfig` | object | إعدادات التوليد |

### الأدوات

```json
{
  "tools": [{
    "functionDeclarations": [{
      "name": "search",
      "description": "Search the web",
      "parameters": {...}
    }],
    "codeExecution": {},
    "googleSearch": {}
  }],
  "toolConfig": {
    "functionCallingConfig": {
      "mode": "AUTO"
    }
  }
}
```

### إعدادات الأمان

```json
{
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_MEDIUM_AND_ABOVE"
    }
  ]
}
```

### معلمات إضافية

| Parameter | Type | Description |
|-----------|------|-------------|
| `cachedContent` | string | مرجع محتوى مخزّن مؤقتًا |
| `responseMimeType` | string | `"text/plain"` أو `"application/json"` |
| `responseSchema` | object | JSON schema للإخراج المنظّم |

## البث

تدعم جميع الـ endpoints البث عبر Server-Sent Events (SSE):

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## معالجة الأخطاء

تعيد LemonData استجابات أخطاء متوافقة مع OpenAI:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

راجع [دليل معالجة الأخطاء](/guides/error-handling) للحصول على التفاصيل.
