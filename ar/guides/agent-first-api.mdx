## نظرة عامة

تعمل واجهة برمجة التطبيقات (API) المخصصة للوكلاء أولاً من LemonData على إثراء استجابات الأخطاء بتلميحات منظمة يمكن لوكلاء الذكاء الاصطناعي تحليلها والتعامل معها فوراً — دون الحاجة إلى عمليات بحث في الويب، أو مراجعة المستندات، أو التخمين.

تتضمن كل استجابة خطأ حقولاً اختيارية مثل `did_you_mean` و `suggestions` و `hint` و `retryable` و `retry_after` داخل كائن `error` القياسي. هذه الحقول متوافقة مع الإصدارات السابقة — حيث لا تلاحظ التطبيقات التي لا تستخدمها أي فرق.

## حقول تلميحات الأخطاء

جميع حقول التلميحات هي امتدادات اختيارية داخل كائن `error`:

| الحقل | النوع | الوصف |
|-------|------|-------------|
| `did_you_mean` | `string` | أقرب اسم طراز مطابق |
| `suggestions` | `array` | الطرازات الموصى بها مع البيانات الوصفية |
| `alternatives` | `array` | الطرازات البديلة المتاحة حالياً |
| `hint` | `string` | إرشادات للخطوة التالية قابلة للقراءة من قبل البشر/الوكلاء |
| `retryable` | `boolean` | ما إذا كانت إعادة محاولة نفس الطلب قد تنجح |
| `retry_after` | `number` | الثواني التي يجب انتظارها قبل إعادة المحاولة |
| `balance_usd` | `number` | رصيد الحساب الحالي بالدولار الأمريكي |
| `estimated_cost_usd` | `number` | التكلفة التقديرية للطلب الفاشل |

## أمثلة على أكواد الأخطاء

### model_not_found (400)

عندما لا يتطابق اسم الطراز مع أي طراز نشط:

```json
{
  "error": {
    "message": "Model 'gpt5' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-4o",
    "suggestions": [
      {"id": "gpt-4o"},
      {"id": "gpt-4o-mini"},
      {"id": "claude-sonnet-4-5"}
    ],
    "hint": "Did you mean 'gpt-4o'? Use GET /v1/models to list all available models."
  }
}
```

تستخدم معالجة `did_you_mean`:
1. خرائط الأسماء المستعارة الثابتة (من بيانات أخطاء الإنتاج)
2. مطابقة النصوص المعيارية (تجاهل الشرطات وحالة الأحرف)
3. مطابقة مسافة التحرير (Edit distance) (الحد الأقصى ≤ 3)

### insufficient_balance (402)

عندما يكون رصيد الحساب منخفضاً جداً بالنسبة للتكلفة التقديرية:

```json
{
  "error": {
    "message": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-5, but balance is $0.1200.",
    "type": "insufficient_balance",
    "code": "insufficient_balance",
    "balance_usd": 0.12,
    "estimated_cost_usd": 0.35,
    "suggestions": [
      {"id": "gpt-4o-mini"},
      {"id": "deepseek-chat"}
    ],
    "hint": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-5, but balance is $0.1200. Try a cheaper model, or top up at https://lemondata.cc/dashboard/billing."
  }
}
```

يحتوي `suggestions` على طرازات أرخص من التكلفة التقديرية يمكن للوكيل الانتقال إليها.

### all_channels_failed (503)

عندما تكون جميع القنوات الموفرة للطراز غير متاحة:

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-5", "status": "available", "tags": []},
      {"id": "gpt-4o", "status": "available", "tags": []}
    ],
    "hint": "All channels for 'claude-opus-4-6' are temporarily unavailable. Retry in 30s or try an alternative model."
  }
}
```

<Note>
تكون قيمة `retryable` هي `false` عندما يكون السبب هو `no_channels` (لا توجد قنوات مهيأة لهذا الطراز). وتكون `true` فقط في حالات الفشل المؤقت مثل تعطل القاطع (circuit breaker) أو استنفاد الحصة (quota).
</Note>

### rate_limit_exceeded (429)

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

يتم حساب قيمة `retry_after` بناءً على وقت إعادة تعيين نافذة حد المعدل الفعلي.

<Note>
تستخدم نقاط النهاية المتوافقة مع OpenAI أنواع أخطاء عامة مستقرة من LemonData مثل `rate_limit_exceeded` و `upstream_error` و `all_channels_failed`. أما نقاط النهاية المتوافقة مع Anthropic و Gemini فتستخدم أشكال الاستجابة الأصلية الخاصة بها.
</Note>

### context_length_exceeded (400)

عندما يتجاوز الإدخال نافذة السياق الخاصة بالطراز (خطأ من المصدر، معزز بالتلميحات):

```json
{
  "error": {
    "message": "This model's maximum context length is 128000 tokens...",
    "type": "invalid_request_error",
    "code": "context_length_exceeded",
    "retryable": false,
    "suggestions": [
      {"id": "gemini-2.5-pro"},
      {"id": "claude-sonnet-4-5"}
    ],
    "hint": "Reduce your input or switch to a model with a larger context window."
  }
}
```

## رؤوس نقاط النهاية الأصلية (Native Endpoint Headers)

عندما تستدعي `/v1/chat/completions` مع طراز يمتلك نقطة نهاية أصلية (Anthropic أو Gemini)، تتضمن **استجابة النجاح** رؤوس تحسين:

```
X-LemonData-Hint: This model supports native Anthropic format. Use POST /v1/messages for better performance (no format conversion).
X-LemonData-Native-Endpoint: /v1/messages
```

| مزود الطراز | نقطة النهاية المقترحة | الفائدة |
|---------------|-------------------|---------|
| Anthropic (Claude) | `/v1/messages` | لا يوجد تحويل للصيغة، تفكير ممتد، تخزين مؤقت للمطالبات |
| Google (Gemini) | `/v1beta/gemini` | لا يوجد تحويل للصيغة، الربط بالواقع، إعدادات الأمان |
| OpenAI | — | تنسيق Chat completions هو التنسيق الأصلي بالفعل |

تظهر هذه الرؤوس في كل من استجابات البث (streaming) وغير البث.

## تحسينات /v1/models

ثلاثة حقول جديدة في امتداد `lemondata` لكل كائن طراز:

```json
{
  "id": "gpt-4o",
  "lemondata": {
    "category": "chat",
    "pricing_unit": "per_token",
    "cache_pricing": {
      "cache_read_per_1m": "1.25",
      "cache_write_per_1m": "2.50",
      "platform_cache_discount": 0.9
    }
  }
}
```

| الحقل | القيم | الوصف |
|-------|--------|-------------|
| `category` | `chat`, `image`, `video`, `audio`, `tts`, `stt`, `3d`, `embedding`, `rerank` | فئة الطراز |
| `pricing_unit` | `per_token`, `per_image`, `per_second`, `per_request` | كيفية فوترة الطراز |
| `cache_pricing` | object أو `null` | أسعار التخزين المؤقت للمطالبات من المصدر + خصم التخزين المؤقت الدلالي للمنصة |

### تصفية الفئات

```bash
GET /v1/models?category=chat          # طرازات الدردشة فقط
GET /v1/models?category=image         # طرازات توليد الصور
GET /v1/models?tag=coding&category=chat  # طرازات الدردشة المحسنة للبرمجة
```

## llms.txt

تتوفر نظرة عامة على واجهة برمجة التطبيقات (API) قابلة للقراءة آلياً على:

```
GET https://api.lemondata.cc/llms.txt
```

وتتضمن:
- قالب المحاولة الأولى مع مثال يعمل
- أسماء الطرازات الشائعة (يتم إنشاؤها ديناميكياً من بيانات الاستخدام)
- جميع نقاط نهاية API الـ 12
- معلمات التصفية لاكتشاف الطرازات
- إرشادات معالجة الأخطاء

يمكن لوكلاء الذكاء الاصطناعي الذين يقرأون `llms.txt` قبل أول استدعاء لـ API النجاح عادةً من المحاولة الأولى.

## الاستخدام في كود الوكيل

### Python (OpenAI SDK)

```python
from openai import OpenAI, BadRequestError

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://api.lemondata.cc/v1"
)

def smart_chat(messages, model="gpt-4o"):
    try:
        return client.chat.completions.create(
            model=model, messages=messages
        )
    except BadRequestError as e:
        error = e.body.get("error", {}) if isinstance(e.body, dict) else {}
        # استخدام did_you_mean للتصحيح التلقائي
        if error.get("code") == "model_not_found" and error.get("did_you_mean"):
            return client.chat.completions.create(
                model=error["did_you_mean"], messages=messages
            )
        raise
```

### JavaScript (OpenAI SDK)

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function smartChat(messages, model = 'gpt-4o') {
  try {
    return await client.chat.completions.create({ model, messages });
  } catch (error) {
    const err = error?.error;
    if (err?.code === 'model_not_found' && err?.did_you_mean) {
      return client.chat.completions.create({
        model: err.did_you_mean, messages
      });
    }
    throw error;
  }
}
```
