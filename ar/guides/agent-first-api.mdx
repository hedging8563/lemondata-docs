## نظرة عامة

تعمل API الموجهة للوكلاء أولاً من LemonData على إثراء استجابات الأخطاء بتلميحات منظَّمة يمكن لوكلاء الذكاء الاصطناعي تحليلها والتصرف بناءً عليها فورًا — بدون بحث على الويب، وبدون الرجوع إلى الوثائق، وبدون تخمين.

تتضمن كل استجابة خطأ حقولًا اختيارية مثل `did_you_mean` و`suggestions` و`hint` و`retryable` و`retry_after` داخل كائن `error` القياسي. هذه الحقول متوافقة مع الإصدارات السابقة — والعملاء الذين لا يستخدمونها لن يلاحظوا أي فرق.

## حقول تلميحات الأخطاء

جميع حقول التلميحات هي امتدادات اختيارية داخل كائن `error`:

| Field | Type | Description |
|-------|------|-------------|
| `did_you_mean` | `string` | أقرب اسم نموذج مطابق |
| `suggestions` | `array` | النماذج الموصى بها مع البيانات الوصفية |
| `alternatives` | `array` | النماذج البديلة المتاحة حاليًا |
| `hint` | `string` | إرشاد للخطوة التالية قابل للقراءة من قبل الإنسان/الوكيل |
| `retryable` | `boolean` | ما إذا كانت إعادة محاولة الطلب نفسه قد تنجح |
| `retry_after` | `number` | عدد الثواني الواجب انتظارها قبل إعادة المحاولة |
| `balance_usd` | `number` | الرصيد الحالي للحساب بالدولار الأمريكي |
| `estimated_cost_usd` | `number` | التكلفة التقديرية للطلب الفاشل |

## أمثلة على رموز الأخطاء

### model_not_found (400)

عندما لا يتطابق اسم النموذج مع أي نموذج نشط:

```json
{
  "error": {
    "message": "Model 'gpt5' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [
      {"id": "gpt-5.4"},
      {"id": "gpt-5-mini"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Did you mean 'gpt-5.4'? Use GET /v1/models to list all available models."
  }
}
```

يستخدم حل `did_you_mean` ما يلي:
1. تعيينًا ثابتًا للأسماء البديلة (من بيانات أخطاء الإنتاج)
2. مطابقة سلاسل نصية مُطبَّعة (تزيل الشرطات وتكون غير حساسة لحالة الأحرف)
3. مطابقة مسافة التحرير (الحد ≤ 3)

### insufficient_balance (402)

عندما يكون رصيد الحساب منخفضًا جدًا مقارنة بالتكلفة التقديرية:

```json
{
  "error": {
    "message": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200.",
    "type": "insufficient_balance",
    "code": "insufficient_balance",
    "balance_usd": 0.12,
    "estimated_cost_usd": 0.35,
    "suggestions": [
      {"id": "gpt-5-mini"},
      {"id": "deepseek-v3-2"}
    ],
    "hint": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200. Try a cheaper model, or top up at https://lemondata.cc/dashboard/billing."
  }
}
```

يحتوي `suggestions` على نماذج أرخص من التكلفة التقديرية يمكن للوكيل التبديل إليها.

### all_channels_failed (503)

عندما تكون جميع قنوات upstream لنموذج ما غير متاحة:

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-6", "status": "available", "tags": []},
      {"id": "gpt-5-mini", "status": "available", "tags": []}
    ],
    "hint": "All channels for 'claude-opus-4-6' are temporarily unavailable. Retry in 30s or try an alternative model."
  }
}
```

<Note>
تكون قيمة `retryable` هي `false` عندما يكون السبب هو `no_channels` (لا توجد قنوات مُهيأة لهذا النموذج). وتكون `true` فقط في حالات الإخفاقات العابرة مثل تعثر circuit breaker أو استنفاد الحصة.
</Note>

### rate_limit_exceeded (429)

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

تُحتسب قيمة `retry_after` من وقت إعادة تعيين نافذة rate limit الفعلي.

<Note>
تستخدم endpoints المتوافقة مع OpenAI أنواع أخطاء LemonData العامة والمستقرة مثل `rate_limit_exceeded` و`upstream_error` و`all_channels_failed`. أما endpoints المتوافقة مع Anthropic وGemini فتستخدم أشكال الاستجابة الأصلية الخاصة بها.
</Note>

### context_length_exceeded (400)

عندما يتجاوز الإدخال نافذة السياق الخاصة بالنموذج (خطأ upstream معزَّز بتلميحات):

```json
{
  "error": {
    "message": "This model's maximum context length is 128000 tokens...",
    "type": "invalid_request_error",
    "code": "context_length_exceeded",
    "retryable": false,
    "suggestions": [
      {"id": "gemini-2.5-pro"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Reduce your input or switch to a model with a larger context window."
  }
}
```

## رؤوس native endpoint

عند استدعاء `/v1/chat/completions` باستخدام نموذج لديه native endpoint (Anthropic أو Gemini)، فإن **استجابة النجاح** تتضمن رؤوس تحسين:

```
X-LemonData-Hint: This model supports native Anthropic format. Use POST /v1/messages for better performance (no format conversion).
X-LemonData-Native-Endpoint: /v1/messages
```

| Model Provider | Suggested Endpoint | Benefit |
|---------------|-------------------|---------|
| Anthropic (Claude) | `/v1/messages` | بدون تحويل تنسيق، تفكير موسع، وتخزين مؤقت للـ prompt |
| Google (Gemini) | `/v1beta/gemini` | بدون تحويل تنسيق، grounding، وإعدادات الأمان |
| OpenAI | — | chat completions هو بالفعل التنسيق الأصلي |

تظهر هذه الرؤوس في كل من الاستجابات المتدفقة وغير المتدفقة.

## تحسينات /v1/models

ثلاثة حقول جديدة في امتداد `lemondata` لكل كائن نموذج:

```json
{
  "id": "gpt-5.4",
  "lemondata": {
    "category": "chat",
    "pricing_unit": "per_token",
    "cache_pricing": {
      "cache_read_per_1m": "1.25",
      "cache_write_per_1m": "2.50",
      "platform_cache_discount": 0.9
    }
  }
}
```

| Field | Values | Description |
|-------|--------|-------------|
| `category` | `chat`, `image`, `video`, `audio`, `tts`, `stt`, `3d`, `embedding`, `rerank` | نوع النموذج |
| `pricing_unit` | `per_token`, `per_image`, `per_second`, `per_request` | طريقة فوترة النموذج |
| `cache_pricing` | object or `null` | أسعار prompt cache في upstream + خصم semantic cache على مستوى المنصة |

### التصفية حسب الفئة

```bash
GET /v1/models?category=chat          # Chat models only
GET /v1/models?category=image         # Image generation models
GET /v1/models?tag=coding&category=chat  # Coding-optimized chat models
```

## llms.txt

يتوفر ملخص API قابل للقراءة آليًا على:

```
GET https://api.lemondata.cc/llms.txt
```

ويتضمن:
- قالب الاستدعاء الأول مع مثال عملي
- أسماء النماذج الشائعة (مولدة ديناميكيًا من بيانات الاستخدام)
- جميع نقاط API النهائية الاثنتي عشرة
- معاملات التصفية لاكتشاف النماذج
- إرشادات التعامل مع الأخطاء

يمكن لوكلاء الذكاء الاصطناعي الذين يقرؤون `llms.txt` قبل أول استدعاء API لهم أن ينجحوا عادةً من أول محاولة.

## الاستخدام في كود الوكيل

### Python (OpenAI SDK)

```python
from openai import OpenAI, BadRequestError

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://api.lemondata.cc/v1"
)

def smart_chat(messages, model="gpt-4o"):
    try:
        return client.chat.completions.create(
            model=model, messages=messages
        )
    except BadRequestError as e:
        error = e.body.get("error", {}) if isinstance(e.body, dict) else {}
        # Use did_you_mean for auto-correction
        if error.get("code") == "model_not_found" and error.get("did_you_mean"):
            return client.chat.completions.create(
                model=error["did_you_mean"], messages=messages
            )
        raise
```

### JavaScript (OpenAI SDK)

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function smartChat(messages, model = 'gpt-4o') {
  try {
    return await client.chat.completions.create({ model, messages });
  } catch (error) {
    const err = error?.error;
    if (err?.code === 'model_not_found' && err?.did_you_mean) {
      return client.chat.completions.create({
        model: err.did_you_mean, messages
      });
    }
    throw error;
  }
}
```
