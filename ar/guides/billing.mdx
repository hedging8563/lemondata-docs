## نظرة عامة

تستخدم LemonData **تسعير الدفع حسب الاستخدام**. أنت تدفع فقط مقابل ما تستخدمه، بدون اشتراكات أو التزامات حد أدنى.

## كيف تعمل الفوترة

1. **أضف رصيدًا** إلى حسابك
2. **استخدم الـ API** - يتم خصم التكاليف لكل طلب
3. **راقب الاستخدام** في لوحة التحكم الخاصة بك
4. **أعد التعبئة** عندما ينخفض رصيدك

### فوترة المهام غير المتزامنة (Video/Music/3D)

<Warning>
  **مهم**: تتم **فوتره** مهام توليد الفيديو والموسيقى و3D **عند وقت الإرسال**، وليس عند الاكتمال.
</Warning>

بالنسبة لمهام التوليد غير المتزامنة (الفيديو، الموسيقى، نماذج 3D):

1. **تتم الفوترة فورًا** عند إرسال المهمة
2. ستتلقى `task_id` للاستعلام عن الحالة
3. **لا توجد استردادات تلقائية** إذا فشلت المهمة

يعود ذلك إلى أن المزوّدين upstream يفرضون علينا الرسوم عند إرسال المهمة، بغض النظر عن النتيجة. إذا واجهت حالات فشل في المهام، يُرجى التواصل مع support@lemondata.cc للحصول على المساعدة.

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

task_id = response.json()["task_id"]
# Poll for status...
```

## حساب الـ Token

الـ token هي الوحدات الأساسية لمعالجة النصوص:

- حوالي 4 أحرف = 1 token (الإنجليزية)
- حوالي 1-2 حرف = 1 token (الصينية)
- 1 صورة = يختلف حسب الحجم ومستوى التفاصيل

### تقدير عدد الـ Token

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## تتبع الاستخدام

### لوحة التحكم

راقب استخدامك في [Dashboard](https://lemondata.cc/dashboard):

- الرصيد في الوقت الفعلي
- سجل الاستخدام حسب النموذج
- تفصيل التكاليف
- استخدام API key

### استجابة API

تتضمن كل استجابة معلومات الاستخدام:

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## تنبيهات انخفاض الرصيد

قم بإعداد تنبيهات عندما ينخفض رصيدك:

1. انتقل إلى **Dashboard → Settings → Notifications**
2. حدّد قيمة الحد الأدنى
3. استلم إشعارات عبر البريد الإلكتروني

## إضافة الرصيد

### طرق الدفع

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### الخطوات

1. سجّل الدخول إلى [Dashboard](https://lemondata.cc/dashboard)
2. انقر على **Add Credits**
3. اختر المبلغ وطريقة الدفع
4. أكمل الدفع

تتم إضافة الأرصدة فورًا بعد تأكيد الدفع.

## حدود API Key

يمكنك تعيين حدود إنفاق على مفاتيح API الفردية:

1. انتقل إلى **Dashboard → API Keys**
2. انقر على مفتاح لتعديله
3. اضبط **Usage Limit**

عند الوصول إلى الحد، ستُرجع الطلبات التي تستخدم ذلك المفتاح `402 Payment Required`.

## الفواتير

بالنسبة لحسابات الأعمال، تتوفر الفواتير:

1. انتقل إلى **Dashboard → Billing**
2. اعرض سجل المعاملات
3. نزّل الفواتير بصيغة PDF

## هل لديك أسئلة؟
