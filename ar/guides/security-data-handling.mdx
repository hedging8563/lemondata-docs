## نظرة عامة

تعامل بأمان مع API keys ووسائط المستخدم والسجلات والأصول المولدة في TokenLab.

استخدم واجهات TokenLab العامة وعقود النماذج؛ ولا تعتمد على تفاصيل تنفيذ المزوّد.

## قواعد أساسية

- احفظ API key scope, media URL lifetime, audit events قبل إرجاع النجاح للمستخدم.
- استخدم واجهات TokenLab العامة وعقود النماذج؛ ولا تعتمد على تفاصيل تنفيذ المزوّد.
- اجعل retries آمنة للتكرار وتجنب التوليد أو الفوترة المزدوجة.

## قائمة فحص الإنتاج

- احفظ API key scope, media URL lifetime, audit events قبل إرجاع النجاح للمستخدم.
- استخدم واجهات TokenLab العامة وعقود النماذج؛ ولا تعتمد على تفاصيل تنفيذ المزوّد.
- اجعل retries آمنة للتكرار وتجنب التوليد أو الفوترة المزدوجة.
- يجب أن تساعد logs الدعم دون تخزين أسرار أو payloads خاصة.
- تحقق من السلوك في staging قبل تغيير حركة الإنتاج.
