## نظرة عامة

توفر LemonData إمكانية الوصول إلى نماذج توليد الفيديو من 11 مزودًا من خلال API موحد واحد. توليد الفيديو **غير متزامن** — تقوم بإرسال طلب، وتستلم معرّف مهمة و`poll_url`، ثم تقوم بالاستعلام الدوري للحصول على النتيجة.

<Info>
يتم تحديث قائمة النماذج بشكل متكرر. للاطلاع على أحدث النماذج المتاحة والأسعار، قم بزيارة [صفحة النماذج](https://lemondata.cc/ar/models) أو استخدم [Models API](/api-reference/models/list-models).
</Info>

<Warning>
Audio behavior is model-dependent. In LemonData, Veo 3 family requests default to audio-on when `output_audio` is omitted. Some models are silent by default or silent-only. For passthrough-governed models, pass `output_audio=true` to make a best-effort upstream audio request.
</Warning>


### سير العمل غير المتزامن

```mermaid
sequenceDiagram
    participant Client
    participant LemonData
    participant Provider

    Client->>LemonData: POST /v1/videos/generations
    LemonData->>Provider: Forward request
    Provider-->>LemonData: task_id + pending
    LemonData-->>Client: { task_id, poll_url, status: "pending" }

    loop Poll every 5-10s
        Client->>LemonData: GET poll_url
        LemonData->>Provider: Query status
        Provider-->>LemonData: Status update
        LemonData-->>Client: { status, video_url? }
    end
```

<CodeGroup>

```python Python
import requests
import time

API_KEY = "sk-your-api-key"
BASE = "https://api.lemondata.cc/v1"
headers = {"Authorization": f"Bearer {API_KEY}"}

# Step 1: Submit generation request
resp = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
create_data = resp.json()
task_id = create_data["task_id"]
poll_url = create_data["poll_url"]

# Step 2: Poll for result
while True:
    status = requests.get(f"https://api.lemondata.cc{poll_url}", headers=headers).json()
    if status["status"] in ("completed", "succeeded"):
        print(f"Video URL: {status['video_url']}")
        break
    elif status["status"] == "failed":
        print(f"Failed: {status.get('error')}")
        break
    time.sleep(10)
```

```javascript JavaScript
const API_KEY = 'sk-your-api-key';
const BASE = 'https://api.lemondata.cc/v1';
const headers = { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' };

// Step 1: Submit
const { task_id, poll_url } = await fetch(`${BASE}/videos/generations`, {
  method: 'POST', headers,
  body: JSON.stringify({
    model: 'sora-2',
    prompt: 'A calm cinematic shot of a cat walking through a sunlit garden.',
    operation: 'text-to-video',
    duration: 4,
    aspect_ratio: '16:9'
  })
}).then(r => r.json());

// Step 2: Poll
const poll = setInterval(async () => {
  const status = await fetch(`https://api.lemondata.cc${poll_url}`, { headers }).then(r => r.json());
  if (['completed', 'succeeded'].includes(status.status)) {
    console.log('Video URL:', status.video_url);
    clearInterval(poll);
  } else if (status.status === 'failed') {
    console.error('Failed:', status.error);
    clearInterval(poll);
  }
}, 10000);
```

### تعريفات القدرات

- **T2V (Text-to-Video)**: أنشئ فيديو من مطالبة نصية
- **I2V (Image-to-Video)**: حرّك صورة ثابتة إلى فيديو. ولتحقيق أوسع توافق، وفّر `image_url` عامًا.
- **Keyframe**: التحكم في إطاري البداية والنهاية باستخدام `start_image` + `end_image`
- **Extension**: تمديد مدة فيديو موجود
- **Editing**: تعديل جوانب محددة من فيديو موجود

## أمثلة الاستخدام

### من النص إلى الفيديو (T2V)

هذه هي حالة الاستخدام الأكثر شيوعًا. جميع النماذج تدعم ذلك.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "sora-2",
        "prompt": "A calm cinematic shot of a cat walking through a sunlit garden.",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9"
    }
)
```

### من الصورة إلى الفيديو (I2V)

حرّك صورة ثابتة. ولتحقيق أوسع توافق عبر نماذج الفيديو، استضف الصورة المصدر ومرّر `image_url`.

```python
# Using image URL
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/portrait.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)

```

### التحكم بإطارات المفاتيح (صورة البداية + صورة النهاية)

تحكم في كل من الإطار الأول والأخير للحصول على انتقالات دقيقة. هذا مدعوم حاليًا بواسطة Seedance 2.0.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night, city lights gradually turning on",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/city-day.jpg",
        "end_image": "https://example.com/city-night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```

### تمديد الفيديو

قم بتمديد مدة فيديو موجود. استخدم النماذج التي تدعم قدرة التمديد.

```python
response = requests.post(f"{BASE}/videos/generations",
    headers=headers,
    json={
        "model": "kling-video-extend",
        "prompt": "Continue the scene naturally",
        "image_url": "https://example.com/last-frame.jpg"
    }
)
```

## مرجع المعلمات

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | معرّف النموذج (الافتراضي: `sora-2`) |
| `prompt` | string | **مطلوب.** وصف نصي للفيديو |
| `image_url` | string | URL لصورة البداية (لـ I2V) |
| `image` | string | صورة مضمنة كـ data URL. مدعومة بواسطة النماذج المتوافقة، لكن `image_url` يوفر أوسع توافق. |
| `duration` | integer | مدة الفيديو بالثواني (1-60، بحسب النموذج) |
| `aspect_ratio` | string | `16:9`, `9:16`, `1:1`، إلخ. |
| `resolution` | string | `1080p`, `720p`, `4k` |
| `fps` | integer | عدد الإطارات في الثانية (1-120) |
| `negative_prompt` | string | ما يجب تجنبه أثناء التوليد |
| `seed` | integer | قيمة seed عشوائية لإمكانية إعادة الإنتاج |
| `cfg_scale` | number | مقياس التوجيه (0-20) |
| `motion_strength` | number | شدة الحركة (0-1) |
| `start_image` | string | URL لإطار المفتاح الابتدائي |
| `end_image` | string | URL لإطار المفتاح النهائي |

<Warning>
ليست كل المعلمات مدعومة من كل نموذج. يتم تجاهل المعلمات غير المدعومة بصمت. راجع وثائق النموذج للاطلاع على المعلمات المدعومة.
</Warning>

## الفوترة

يستخدم توليد الفيديو **تسعيرًا ثابتًا لكل عملية توليد**. يتم تحصيل الرسوم مرة واحدة عند إرسال المهمة، بغض النظر عن مدة الفيديو. إذا فشل التوليد، يتم استرداد الرسوم تلقائيًا.

تحقق من الأسعار الحالية في [صفحة النماذج](https://lemondata.cc/ar/models) أو عبر [Pricing API](/api-reference/pricing/get-pricing).
