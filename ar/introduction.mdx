## ما هي LemonData؟

LemonData هي منصة تجميع واجهات برمجة تطبيقات الذكاء الاصطناعي تمنحك وصولاً موحّداً إلى **أكثر من 300 نموذج ذكاء اصطناعي** من مزودين مثل OpenAI وAnthropic وGoogle وDeepSeek وMoonshot وMiniMax والمزيد.

## الإمكانيات المدعومة

| الإمكانية | الوصف | أمثلة على النماذج |
|------------|-------------|----------------|
| **الدردشة والاستدلال** | توليد النصوص، التخطيط، الأدوات | `gpt-5.4`, `claude-sonnet-4-6`, `deepseek-r1` |
| **الرؤية** | فهم الصور والدردشة متعددة الوسائط | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |
| **توليد الصور** | تحويل النص إلى صورة وتحرير الصور | `dall-e-3`, `flux-pro`, `midjourney` |
| **توليد الفيديو** | تحويل النص/الصورة إلى فيديو | `sora`, `runway`, `kling` |
| **الصوت** | TTS والتفريغ الصوتي | `gpt-4o-mini-tts`, `whisper-1`, `gpt-4o-transcribe` |
| **التضمينات** | تحويل النص إلى متجهات | `text-embedding-3-small`, `text-embedding-3-large` |
| **الموسيقى** | توليد الموسيقى بواسطة AI | `suno` |
| **3D** | توليد أصول ثلاثية الأبعاد | `tripo3d` |

## نقطة بداية افتراضية جيدة

لأغلب المشاريع الجديدة، ابدأ بـ OpenAI SDK بالإضافة إلى **Chat Completions**:

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "messages": [
      {"role": "user", "content": "Explain what LemonData does in one sentence."}
    ]
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="gpt-5.4",
    messages=[{"role": "user", "content": "Explain what LemonData does in one sentence."}]
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-5.4',
  messages: [{ role: 'user', content: 'Explain what LemonData does in one sentence.' }],
});

console.log(response.choices[0].message.content);
```

<Note>
استخدم `POST /v1/responses` فقط عندما تحتاج صراحةً إلى سلوك مخصص لـ Responses. ليست هذه هي مسار التوافق الافتراضي عبر جميع النماذج.
</Note>

</CodeGroup>
