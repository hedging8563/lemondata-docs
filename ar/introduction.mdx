## ما هو LemonData؟

LemonData هي منصة تجميع API للذكاء الاصطناعي تمنحك وصولًا موحدًا إلى **أكثر من 300 نموذج AI** من مزودين مثل OpenAI وAnthropic وGoogle وDeepSeek وMoonshot وMiniMax وغيرهم.

## الإمكانات المدعومة

| الإمكانية | الوصف | أمثلة على النماذج |
|------------|-------------|----------------|
| **الدردشة والاستدلال** | توليد النصوص، التخطيط، الأدوات | `gpt-5.4`, `claude-sonnet-4-6`, `deepseek-r1` |
| **الرؤية** | فهم الصور والدردشة متعددة الوسائط | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |
| **توليد الصور** | تحويل النص إلى صورة وتحرير الصور | `dall-e-3`, `flux-pro`, `midjourney` |
| **توليد الفيديو** | تحويل النص/الصورة إلى فيديو | `sora`, `runway`, `kling` |
| **الصوت** | TTS والنسخ الصوتي | `gpt-4o-mini-tts`, `whisper-1`, `gpt-4o-transcribe` |
| **Embeddings** | تحويل النصوص إلى متجهات | `text-embedding-3-small`, `text-embedding-3-large` |
| **الموسيقى** | توليد الموسيقى بالذكاء الاصطناعي | `suno` |
| **ثلاثي الأبعاد** | توليد أصول 3D | `tripo3d` |

## نقطة بداية افتراضية جيدة

بالنسبة للمشاريع الجديدة، ابدأ باستخدام OpenAI SDK مع **Responses API**:

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

</CodeGroup>
