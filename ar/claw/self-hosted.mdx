<Note>
**الاستضافة الذاتية (Self-hosted)** تعني أنك تقوم بتشغيل LemonClaw مباشرة على VPS أو جهازك الخاص. ستدفع فقط مقابل استخدام نماذج AI من خلال رصيد LemonData الخاص بك — لا توجد رسوم على المثيل (instance).
</Note>

<Tip>
هل تفضل إعداداً مستضافاً؟ [أنشئ مثيل Claw](/claw/introduction) للحصول على نفس بيئة تشغيل LemonClaw و WebUI دون إدارة الخوادم بنفسك.
</Tip>

## التثبيت السريع

<CodeGroup>
```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```

```bash Non-interactive
LEMONDATA_API_KEY=sk-xxx curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```
</CodeGroup>

سيطلب منك برنامج التثبيت مفتاح **LemonData API Key** الخاص بك. احصل على واحد من [Dashboard](https://lemondata.cc/dashboard) الخاصة بك.

## ما الذي يتم تثبيته

<Steps>
  <Step title="Node.js 22+">
    يتم تثبيته تلقائياً إذا كان مفقوداً (عبر NodeSource على Linux، و Homebrew على macOS)
  </Step>
  <Step title="LemonClaw">
    حزمة LemonClaw مهيأة مسبقاً مع LemonData API
  </Step>
  <Step title="15 نموذج AI">
    Claude، و GPT-5، و Gemini، و DeepSeek، والمزيد — جاهزة للاستخدام
  </Step>
  <Step title="إضافات IM">
    إضافات DingTalk، و WeCom، و QQ مثبتة مسبقاً
  </Step>
  <Step title="خدمة النظام">
    يبدأ التشغيل تلقائياً عند الإقلاع (systemd على Linux، و launchd على macOS)
  </Step>
</Steps>

## المتطلبات

| المتطلب | التفاصيل |
|-------------|---------|
| **نظام التشغيل** | Linux (Ubuntu/Debian/CentOS/RHEL) أو macOS |
| **البنية** | x64 أو arm64 |
| **ذاكرة الوصول العشوائي (RAM)** | الحد الأدنى 1 جيجابايت، ويوصى بـ 2 جيجابايت |
| **API Key** | [احصل على واحد من هنا](https://lemondata.cc) |

## أوامر الإدارة

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user status lemonclaw    # التحقق من الحالة
    journalctl --user -u lemonclaw -f    # عرض السجلات
    systemctl --user restart lemonclaw   # إعادة التشغيل
    systemctl --user stop lemonclaw      # إيقاف
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    tail -f ~/.lemonclaw/lemonclaw.log    # عرض السجلات
    launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # إعادة التشغيل
    launchctl stop cc.lemondata.lemonclaw  # إيقاف
    ```
  </Tab>
</Tabs>

## التهيئة

موقع ملف التهيئة: `~/.lemonclaw/config.json`

بعد التعديل، أعد تشغيل الخدمة لتطبيق التغييرات.

### تغيير النموذج الافتراضي

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-opus-4-6"
      }
    }
  }
}
```

بادئات النماذج المتاحة (بحسب مزودي الخدمة الذين فعّلتهم في [LemonData Provider Setup](/claw/lemondata-provider)):
- `lemondata/` — مسار متوافق مع OpenAI (`openai-completions`)
- `lemondata-responses/` — مسار OpenAI Responses (`openai-responses`)
- `lemondata-claude/` — مسار Claude الأصلي (`anthropic-messages`)
- `lemondata-gemini/` — مسار Gemini الأصلي (`google-generative-ai`)
- `lemondata-minimax/` — مسار MiniMax الأصلي (`anthropic-messages`)

## الترقية

```bash
# أعد تشغيل برنامج التثبيت للترقية إلى أحدث إصدار
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
# ثم أعد تشغيل الخدمة
systemctl --user restart lemonclaw  # Linux
# أو
launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # macOS
```

## إلغاء التثبيت

```bash
# إيقاف وتعطيل الخدمة
systemctl --user stop lemonclaw && systemctl --user disable lemonclaw  # Linux
launchctl unload ~/Library/LaunchAgents/cc.lemondata.lemonclaw.plist  # macOS

# إزالة LemonClaw
rm -rf ~/.lemonclaw
```
