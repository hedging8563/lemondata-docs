## نظرة عامة

يمكن لـ OpenHands استخدام TokenLab من خلال تكوين النموذج المتوافق مع LiteLLM/OpenAI، خاصةً في سير عمل CLI وسير العمل غير المرئي (headless) حيث تقوم بتوفير النموذج، ومفتاح API، وعنوان URL الأساسي.

<Note>
**النوع**: وكيل برمجي (Coding Agent)

**المسار الأساسي**: تكوين نموذج متوافق مع OpenAI

**مستوى دعم الموثوقية**: مسار نقطة نهاية مخصص مدعوم
</Note>

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## إعدادات النموذج

استخدم:

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

تخبر البادئة `openai/` المسار المدعوم بـ LiteLLM باستخدام تكوين مزود متوافق مع OpenAI.

## الإعداد غير المرئي (Headless Setup)

إذا كنت تقوم بإعداد الإعدادات الافتراضية المحلية لاستخدام CLI أو الاستخدام غير المرئي، فقم بتشغيل تدفق إعداد OpenHands وأدخل:

```bash
make setup-config
```

عند مطالبتك بتفاصيل النموذج، استخدم معرف نموذج TokenLab مع البادئة `openai/` وعنوان URL الأساسي `/v1` الخاص بـ TokenLab.

## اقتراحات النماذج

استخدم `claude-sonnet-5` أو `gpt-5.4` لتخطيط وكيل البرمجة، و `gpt-5.4-mini` للحلقات الروتينية الأسرع، و `deepseek-v4-pro` عندما ترغب في الحصول على نموذج استنتاج بديل قوي.
