## نظرة عامة

يدعم `OpenAIChatGenerator` الخاص بـ Haystack عمليات النشر المتوافقة مع OpenAI من خلال `api_base_url`. قم بتوجيهه إلى TokenLab وقدم مفتاح API الخاص بـ TokenLab.

<Note>
**النوع**: إطار عمل RAG وخطوط المعالجة (pipeline)

**المسار الأساسي**: إكمال المحادثة المتوافق مع OpenAI

**مستوى دعم الموثوقية**: مسار متوافق مع OpenAI مدعوم
</Note>

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## المولد (Generator)

```python
from haystack.components.generators.chat import OpenAIChatGenerator
from haystack.dataclasses import ChatMessage
from haystack.utils import Secret

generator = OpenAIChatGenerator(
    api_key=Secret.from_env_var("TOKENLAB_API_KEY"),
    api_base_url="https://api.tokenlab.sh/v1",
    model="claude-sonnet-5",
)

response = generator.run(
    messages=[ChatMessage.from_user("Summarize this document in one sentence.")]
)
```

## ملاحظات حول نقطة النهاية (Endpoint)

استخدم هذا المسار لخطوط معالجة مولد المحادثة في Haystack. بالنسبة للتضمينات (embeddings)، قم بتهيئة مكون تضمين Haystack المطابق باستخدام عنوان URL الأساسي `/v1` الخاص بـ TokenLab إذا كان خط المعالجة الخاص بك يستخدم تضمينات TokenLab.
