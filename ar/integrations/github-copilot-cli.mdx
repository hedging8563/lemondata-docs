## نظرة عامة

<Note>
**النوع**: وكيل برمجة لسطر الأوامر

**المسار الرئيسي**: Chat Completions متوافق مع OpenAI

**الدعم**: مسار BYOK رسمي
</Note>

يمكن لـ [GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models) الاتصال بأي endpoint متوافق مع OpenAI Chat Completions.

## التثبيت والتهيئة

```bash
npm install -g @github/copilot
copilot --version
```

يتطلب التثبيت عبر npm إصدار Node.js 22 أو أحدث. يتطلب GitHub حاليًا خطة Copilot نشطة، كما تحتاج الحسابات المُدارة إلى تفعيل سياسة Copilot CLI.

```bash
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.tokenlab.sh/v1"
export COPILOT_PROVIDER_API_KEY="sk-your-tokenlab-key"
export COPILOT_MODEL="kimi-k3"

copilot
```

يجب أن يدعم النموذج البث واستدعاء الأدوات. يدعم `kimi-k3` الأدوات وسياقًا أكبر من 128K الموصى بها من GitHub.

ابدأ بمهمة للقراءة فقط لا تعدّل الملفات. إذا لم يوجد النموذج، استخدم المعرّف المنطقي من [كتالوج TokenLab الحالي](https://tokenlab.sh/ar/models) من دون بادئة المزوّد.

<Warning>
لا تخزّن مفاتيح API في ملفات يتتبعها Git. بدّل أي مفتاح ظهر في سجل الطرفية أو لقطة شاشة أو سجلات التطبيق.
</Warning>
