## نظرة عامة

تتصل معظم تطبيقات دردشة AI العامة بـ LemonData من خلال مسار الدردشة القياسي المتوافق مع OpenAI.

عمليًا، هذا يعني:
- استخدام `https://api.lemondata.cc/v1` كعنوان URL الأساسي ما لم يطلب التطبيق صراحةً عنوان URL كامل لنقطة النهاية
- استخدام مفتاح API الخاص بـ LemonData كمفتاح API بأسلوب OpenAI
- اختيار النماذج التي يمكن للتطبيق استخدامها ضمن سير عمل دردشة قياسي

<Note>
تكون تطبيقات الدردشة العامة عادةً **موجّهة نحو chat-completions**، وليست عملاء Codex Responses WebSocket. بالنسبة إلى Codex CLI/App أو Cursor أو أدوات البرمجة الأخرى التي تحتاج إلى سلوك خاص بـ Responses، استخدم أدلة التكامل المخصصة بدلاً من ذلك.
</Note>

## التطبيقات المدعومة

| Application | Platform | Notes |
|-------------|----------|-------|
| LobeChat | الويب، سطح المكتب، مستضاف ذاتيًا | دعم قوي لموفري الخدمة المخصصين |
| Cherry Studio | Windows، macOS، Linux | تدفق جيد لموفري الخدمة المتوافقين مع OpenAI |
| Chatbox | Windows، macOS، Linux | إعداد بسيط متوافق مع OpenAI |
| TypingMind | الويب، سطح المكتب | يستخدم نمط نقطة نهاية مخصص |
| BotGem | iOS، macOS | تهيئة موفر خدمة مخصص |
| OpenCat | iOS، macOS | تدفق نقطة نهاية مخصصة متوافق مع OpenAI |
| ChatWise | Windows، macOS | نمط موفر خدمة مخصص قياسي |

## قيم الاتصال الافتراضية

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | متوافق مع OpenAI |

إذا طلب التطبيق **عنوان URL كامل لنقطة النهاية** بدلاً من عنوان URL أساسي، فاستخدم:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## أمثلة على إعدادات التطبيقات

<Tabs>
  <Tab title="LobeChat">
    **LobeChat مستضاف ذاتيًا**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. افتح **Settings** → **AI Service Provider**
    2. اختر **OpenAI**
    3. أدخل مفتاح API الخاص بـ LemonData
    4. اضبط نقطة النهاية المخصصة على `https://api.lemondata.cc/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. افتح **Settings** → **Model Provider**
    2. أضف موفر خدمة **متوافق مع OpenAI**
    3. أدخل:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. أضف النماذج التي تريد استخدامها
  </Tab>

  <Tab title="Chatbox">
    1. افتح **Settings** → **AI Model**
    2. اختر **OpenAI API Compatible**
    3. أدخل:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` أو `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. افتح **Settings**
    2. اختر **Custom Endpoint**
    3. أدخل:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. قم بتهيئة النماذج التي تريد إتاحتها
  </Tab>
</Tabs>

## نصائح

<AccordionGroup>
  <Accordion title="فضّل استخدام عنوان URL الأساسي عندما يدعمه التطبيق">
    تكون معظم التطبيقات أسهل في التهيئة وأقل عرضة للأعطال عندما توفّر `https://api.lemondata.cc/v1` كعنوان URL أساسي بدلاً من عنوان URL كامل لنقطة النهاية.
  </Accordion>

  <Accordion title="استخدم النماذج الأصغر أولاً">
    ابدأ باستخدام `gpt-5-mini` أو `gpt-4o` للدردشة اليومية، ثم انقل مهام الاستدلال الأثقل إلى `gpt-5.4` أو `claude-opus-4-6`.
  </Accordion>

  <Accordion title="أبقِ أدوات البرمجة منفصلة">
    غالبًا ما تحتاج تطبيقات الدردشة العامة ووكلاء البرمجة إلى سلوك مختلف لنقاط النهاية. أبقِ الأدوات بأسلوب Codex/Cursor ضمن صفحات التكامل المخصصة لها.
  </Accordion>
</AccordionGroup>

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
  <Accordion title="خطأ في الاتصال">
    - تحقق من أن عنوان URL الأساسي هو بالضبط `https://api.lemondata.cc/v1`
    - أزل الشرطات المائلة اللاحقة إذا كان التطبيق يضيف المسارات تلقائيًا
    - إذا كان التطبيق يريد عنوان URL كامل لنقطة النهاية، فاستخدم `https://api.lemondata.cc/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Unauthorized">
    - تحقّق مرة أخرى من مفتاح API الخاص بك
    - أكّد أن المفتاح نشط في لوحة تحكم LemonData
    - تأكد من عدم وجود مسافات إضافية أو فواصل أسطر
  </Accordion>

  <Accordion title="النموذج غير متاح">
    - تحقق من اسم النموذج بدقة
    - جرّب نموذجًا افتراضيًا واسع الدعم مثل `gpt-5-mini` أو `gpt-4o` أو `claude-sonnet-4-6`
    - تحقق من التوفر الحالي في وثائق LemonData أو لوحة التحكم
  </Accordion>
</AccordionGroup>
