## نظرة عامة

<Note>
**النوع**: وكيل سطح مكتب للبرمجة والمهام

**المسار الرئيسي**: Chat Completions متوافق مع OpenAI

**الدعم**: مسار نموذج مخصص رسمي
</Note>

يوفر [WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) محررًا مرئيًا للنماذج المتوافقة مع OpenAI، من دون الحاجة إلى تعديل ملف النموذج المحلي يدويًا.

## تهيئة TokenLab

افتح **Settings → Model**، وأضف نموذجًا ثم اختر **Custom**.

| الحقل | القيمة |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | مفتاح TokenLab API الخاص بك |
| Model name | `kimi-k3` |
| Custom Protocol | **متوقف** |

<Warning>
اترك Custom Protocol متوقفًا. يتحقق الوضع القياسي من Base URL ويضيف `/chat/completions`. إذا فعّلته وأدخلت `/v1` فقط، فسيُستخدم مسار خاطئ.
</Warning>

في الإعدادات المتقدمة، فعّل استدعاء الأدوات وإدخال الصور ووضع الاستدلال. عطّل وضع الاستدلال فقط، واترك الجهد على Auto، واستخدم `1048576` للإدخال و`131072` للإخراج.

احفظ واختر `kimi-k3` ثم اختبر فحص مجلد للقراءة فقط. أخفِ المفاتيح وendpoints الخاصة قبل مشاركة لقطات الشاشة.
