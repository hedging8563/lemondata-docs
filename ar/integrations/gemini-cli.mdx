## نظرة عامة

Google Gemini CLI هي أداة سطر أوامر للتفاعل مع نماذج Gemini. توفر LemonData نقطة نهاية (endpoint) متوافقة تتيح لك استخدام Gemini CLI مع إمكانية الوصول إلى أكثر من 300 نموذج.

## متطلبات النظام

- **Node.js**: الإصدار 20.0+
- **نظام التشغيل**: Windows 10/11، أو macOS 10.15+، أو Ubuntu 20.04+، أو Debian 10+

## التثبيت

```bash
npm install -g @google/gemini-cli
```

التحقق من التثبيت:

```bash
gemini --version
```

## التكوين

### الخطوة 1: الحصول على مفتاح API الخاص بك

1. قم بتسجيل الدخول إلى [LemonData Dashboard](https://lemondata.cc/dashboard)
2. انتقل إلى [API Keys](https://lemondata.cc/dashboard/api)
3. قم بإنشاء ونسخ مفتاح API الخاص بك (التنسيق: `sk-...`)

### الخطوة 2: تعيين متغيرات البيئة

**مؤقت (الجلسة الحالية):**

```bash
export GEMINI_API_KEY="sk-your-lemondata-key"
export GOOGLE_GEMINI_BASE_URL="https://api.lemondata.cc"
```

**التكوين الدائم:**

أضفه إلى ملف تكوين الصدفة (shell) الخاص بك:

<Tabs>
  <Tab title="Bash">
    ```bash
    echo 'export GEMINI_API_KEY="sk-your-lemondata-key"' >> ~/.bashrc
    echo 'export GOOGLE_GEMINI_BASE_URL="https://api.lemondata.cc"' >> ~/.bashrc
    source ~/.bashrc
    ```
  </Tab>
  <Tab title="Zsh">
    ```bash
    echo 'export GEMINI_API_KEY="sk-your-lemondata-key"' >> ~/.zshrc
    echo 'export GOOGLE_GEMINI_BASE_URL="https://api.lemondata.cc"' >> ~/.zshrc
    source ~/.zshrc
    ```
  </Tab>
  <Tab title="Fish">
    ```bash
    set -Ux GEMINI_API_KEY "sk-your-lemondata-key"
    set -Ux GOOGLE_GEMINI_BASE_URL "https://api.lemondata.cc"
    ```
  </Tab>
</Tabs>

<Warning>
أعد تشغيل الجهاز الطرفي (terminal) بعد التكوين لتفعيل التغييرات.
</Warning>

<Note>
**قيد معروف**: في بعض الحالات، قد لا يلتزم Gemini CLI بـ `GOOGLE_GEMINI_BASE_URL` إذا كانت هناك جلسة Google مخزنة مؤقتاً. إذا واجهت مشكلات في الاتصال، فحاول مسح ذاكرة التخزين المؤقت لـ CLI أو بدء جلسة terminal جديدة.
</Note>

## الاستخدام الأساسي

ابدأ Gemini CLI من دليل المشروع الخاص بك:

```bash
cd your-project
gemini
```

عند التشغيل الأول، ستقوم بـ:
1. اختيار سمة (theme)
2. تأكيد إشعار السلامة
3. الوثوق بدليل العمل

| النموذج | الوصف |

| `gemini-2.5-pro` | نموذج Gemini الأكثر قدرة |
| `gemini-2.5-flash` | سريع وفعال لمعظم المهام |
| `gemini-2.0-flash` | الجيل السابق، مستقر |
