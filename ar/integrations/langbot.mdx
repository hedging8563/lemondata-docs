## نظرة عامة

يمكن لـ LangBot استدعاء TokenLab من خلال مُرسل طلبات LLM متوافق مع OpenAI.

<Note>
**النوع**: منصة بوتات

**المسار الأساسي**: إكمال المحادثات المتوافق مع OpenAI

**مستوى الدعم**: مدعوم مع قيود في النطاق
</Note>

## مُرسل طلبات TokenLab

إذا كان إصدار LangBot الخاص بك يتضمن مُرسل طلبات **TokenLab**:

1. افتح إعدادات مزود النموذج في LangBot.
2. أضف مزوداً باستخدام مُرسل الطلبات **TokenLab**.
3. قم بتعيين مفتاح API الخاص بك إلى مفتاح TokenLab.
4. اختر أو أنشئ نموذجاً مثل `gpt-5.4-mini`.
5. قم بربط النموذج بخط المعالجة (pipeline) أو البوت الذي يجب أن يستخدمه.

## خيار التراجع المتوافق مع OpenAI

إذا لم يكن TokenLab مدرجاً بعد، استخدم مُرسل الطلبات المتوافق مع OpenAI:

| الحقل | القيمة |
|-------|-------|
| Requester | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## النماذج الموصى بها

- `gpt-5.4-mini` لمعظم تفاعلات البوت
- `claude-sonnet-5` للكتابة الطويلة والاستنتاج
- `deepseek-v4-flash` للبرمجة السريعة وحلقات الاستنتاج
- `gemini-3.5-flash` لسير العمل العام السريع
