## نظرة عامة

يعمل Dify بشكل جيد مع LemonData من خلال تدفق موفر النماذج المتوافق مع OpenAI.

بالنسبة لإصدارات Dify الحالية، يكون المسار الأكثر أمانًا عادةً هو:
- اختيار موفر **OpenAI** المدمج
- تعيين مفتاح API الخاص بـ LemonData
- تعيين base URL مخصص إلى `https://api.lemondata.cc/v1`

<Note>
تعرض بعض إصدارات Dify الأقدم هذا الخيار على أنه `OpenAI-API-compatible` بدلًا من موفر `OpenAI` المدمج مع حقل base URL مخصص. إذا كانت واجهة Dify لديك تبدو مختلفة، فاستخدم أقرب تدفق لموفر مخصص متوافق مع OpenAI متاح في ذلك الإصدار.
</Note>

## المتطلبات المسبقة

- حساب LemonData مع إمكانية وصول إلى API
- Dify Cloud أو Dify مستضاف ذاتيًا

## خطوات الإعداد

### الخطوة 1: احصل على مفتاح API الخاص بك

1. سجّل الدخول إلى [لوحة تحكم LemonData](https://lemondata.cc/dashboard)
2. افتح [مفاتيح API](https://lemondata.cc/dashboard/api)
3. أنشئ أو انسخ مفتاح API يبدأ بـ `sk-`

### الخطوة 2: تكوين الموفر

<Steps>
  <Step title="افتح موفري النماذج">
    في Dify، انتقل إلى **Settings** → **Model Providers**
  </Step>
  <Step title="اختر OpenAI">
    افتح إعدادات موفر **OpenAI**. إذا كان إصدار Dify لديك لا يوفّر base URL مخصصًا هنا، فاستخدم بدلًا من ذلك خيار الموفر المخصص المتوافق مع OpenAI الذي يتيحه ذلك الإصدار.
  </Step>
  <Step title="أدخل إعدادات LemonData">
    استخدم هذه القيم:

    | الحقل | القيمة |
    |-------|-------|
    | API Key | `sk-your-lemondata-key` |
    | API Base URL / Custom Base URL | `https://api.lemondata.cc/v1` |
  </Step>
  <Step title="أضف النماذج">
    أضف النماذج التي تريد استخدامها، على سبيل المثال:
    - `gpt-5.4`
    - `gpt-5-mini`
    - `gpt-4o`
    - `claude-sonnet-4-6`
    - `claude-opus-4-6`
    - `gemini-2.5-flash`
    - `gemini-2.5-pro`
    - `deepseek-r1`
  </Step>
</Steps>

### الخطوة 3: اختبار الاتصال

1. اختر نموذجًا واحدًا مثل `gpt-5-mini` أو `gpt-4o`
2. أرسل prompt تجريبيًا
3. تأكد من أن Dify يتلقى استجابة صالحة

## Embeddings لقواعد المعرفة

بالنسبة إلى RAG وفهرسة قاعدة المعرفة، أضف نموذج embedding مثل:
- `text-embedding-3-small`
- `text-embedding-3-large`

ثم عيّنه كنموذج embedding افتراضي في إعدادات قاعدة المعرفة أو التطبيق ذات الصلة.

## أدوار النماذج الموصى بها

| حالة الاستخدام | النماذج المقترحة |
|----------|------------------|
| دردشة افتراضية | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| استدلال عميق | `gpt-5.4`, `claude-opus-4-6`, `deepseek-r1` |
| سريع/منخفض التكلفة | `gpt-5-mini`, `gemini-2.5-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
  <Accordion title="خطأ في الاتصال">
    - تحقّق من أن base URL هو بالضبط `https://api.lemondata.cc/v1`
    - أزل الشرطات المائلة اللاحقة إذا كان Dify يكررها
    - تأكد من أن خادم Dify يمكنه الوصول إلى LemonData عبر الإنترنت العام
  </Accordion>

  <Accordion title="401 Unauthorized">
    - تحقّق مرة أخرى من مفتاح API
    - تأكد من أن المفتاح نشط في لوحة تحكم LemonData
    - تأكد من أن القيمة التي تم لصقها في Dify لا تحتوي على مسافات إضافية أو فواصل أسطر
  </Accordion>

  <Accordion title="النموذج غير موجود">
    - تحقّق من اسم النموذج بدقة
    - أعد إضافة إدخال النموذج إذا كانت واجهة الموفر قد خزّنت قيمة أقدم مؤقتًا
    - تحقّق من توفّر النماذج الحالية في وثائق LemonData أو لوحة التحكم
  </Accordion>
