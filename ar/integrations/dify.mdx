## نظرة عامة

يعمل Dify بشكل جيد مع TokenLab من خلال تدفق مزود النموذج المتوافق مع OpenAI.

هذا مسار تكامل موجه نحو إكمال المحادثات (chat-completions). لا ينبغي اعتباره ضماناً بأن Dify يكشف عن نفس الاستجابات أو سلوك WebSocket مثل تكاملات Codex المخصصة.

بالنسبة لإصدارات Dify الحالية، المسار الأكثر أماناً هو عادةً:
- اختيار مزود **OpenAI** المدمج
- تعيين مفتاح API الخاص بـ TokenLab
- تعيين عنوان أساسي (Base URL) مخصص هو `https://api.tokenlab.sh/v1`

<Note>
تعرض بعض إصدارات Dify الأقدم هذا كـ `OpenAI-API-compatible` بدلاً من مزود `OpenAI` المدمج مع حقل عنوان أساسي مخصص. إذا كانت واجهة Dify الخاصة بك تبدو مختلفة، فاستخدم أقرب تدفق مزود مخصص متوافق مع OpenAI متاح في ذلك الإصدار.
</Note>

<Note>
**النوع**: إطار عمل أو منصة

**المسار الأساسي**: مسار المحادثة المتوافق مع OpenAI

**مستوى دعم الموثوقية**: مدعوم مع حدود للنطاق
</Note>

## المتطلبات الأساسية

- حساب TokenLab مع وصول إلى API
- Dify Cloud أو نسخة Dify مستضافة ذاتياً

## خطوات الإعداد

### الخطوة 1: الحصول على مفتاح API الخاص بك

1. سجل الدخول إلى [TokenLab Dashboard](https://tokenlab.sh/dashboard)
2. افتح [API Keys](https://tokenlab.sh/dashboard/api)
3. أنشئ أو انسخ مفتاح API يبدأ بـ `sk-`

### الخطوة 2: تكوين المزود

<Steps>
  <Step title="فتح مزودي النماذج">
    في Dify، انتقل إلى **Settings** ← **Model Providers**
  </Step>
  <Step title="اختيار OpenAI">
    افتح إعدادات مزود **OpenAI**. إذا كان إصدار Dify الخاص بك لا يوفر عنواناً أساسياً مخصصاً هنا، فاستخدم خيار المزود المخصص المتوافق مع OpenAI الذي يوفره ذلك الإصدار بدلاً من ذلك.
  </Step>
  <Step title="إدخال إعدادات TokenLab">
    استخدم هذه القيم:

    | الحقل | القيمة |
    |-------|-------|
    | API Key | `sk-your-tokenlab-key` |
    | API Base URL / Custom Base URL | `https://api.tokenlab.sh/v1` |
  </Step>
  <Step title="إضافة النماذج">
    أضف النماذج التي تريد استخدامها، على سبيل المثال:
    - `gpt-5.4`
    - `gpt-5.4-mini`
    - `claude-sonnet-5`
    - `claude-opus-4-8`
    - `gemini-3.5-flash`
    - `gemini-3.1-flash-lite`
    - `deepseek-v4-flash`
  </Step>
</Steps>

### الخطوة 3: اختبار الاتصال

1. اختر نموذجاً واحداً مثل `gpt-5-mini` أو `gpt-4o`
2. أرسل رسالة اختبار (prompt)
3. تأكد من أن Dify يتلقى استجابة صالحة

## التضمينات (Embeddings) لقواعد المعرفة

بالنسبة لـ RAG وفهرسة قواعد المعرفة، أضف نموذج تضمين مثل:
- `text-embedding-3-small`
- `text-embedding-3-large`

ثم قم بتعيينه كنموذج التضمين الافتراضي في قاعدة المعرفة ذات الصلة أو إعدادات التطبيق.

## أدوار النماذج الموصى بها

| حالة الاستخدام | النماذج المقترحة |
|----------|------------------|
| المحادثة الافتراضية | `gpt-5.4-mini`, `gpt-5.4`, `claude-sonnet-5` |
| الاستنتاج العميق | `gpt-5.5`, `gpt-5.4`, `claude-opus-4-8`, `deepseek-v4-pro` |
| سريع/رخيص | `gpt-5.4-mini`, `gemini-3.5-flash`, `deepseek-v4-flash` |
| التضمينات | `text-embedding-3-small`, `text-embedding-3-large` |
