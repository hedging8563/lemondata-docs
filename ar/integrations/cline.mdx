## نظرة عامة

<Note>
**النوع**: وكيل برمجة لبيئة التطوير

**المسار الرئيسي**: Chat Completions متوافق مع OpenAI

**الدعم**: مسار مزوّد رسمي
</Note>

يدعم [Cline](https://docs.cline.bot/provider-config/openai-compatible) المزوّدين المتوافقين مع OpenAI من إعدادات بيئة التطوير.

## تهيئة TokenLab

1. ثبّت **Cline** من متجر الإضافات وافتح لوحته.
2. اضغط رمز الترس واختر **OpenAI Compatible** ضمن **API Provider**.
3. أدخل:

| الحقل | القيمة |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | مفتاح TokenLab API الخاص بك |
| Model ID | `kimi-k3` |

4. اضغط **Verify**.

في الإعدادات المتقدمة الاختيارية، استخدم `1048576` لحد الإدخال و`131072` للحد الأقصى للإخراج، وفعّل الصور والأدوات / Computer Use.

بعد التحقق، ابدأ بمهمة للقراءة فقط. عند ظهور 404، تأكد من أن Base URL ينتهي بـ `/v1` ولا يتضمن `/chat/completions`. معرّف النموذج هو `kimi-k3` وليس `kimi/kimi-k3`.
