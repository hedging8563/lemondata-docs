## نظرة عامة

يعمل LemonData مع حزم SDK الرسمية الخاصة بـ OpenAI من خلال توجيه العميل إلى `https://api.lemondata.cc/v1`.

بالنسبة للمشاريع الجديدة، يُفضَّل استخدام **Responses API**. احتفظ بـ **Chat Completions** فقط عندما لا يزال إطار عمل أو plugin أو مسار كود قديم يتوقعه.

<Note>
توجد حزم SDK رسمية من OpenAI لـ Python وJavaScript وGo. يعمل PHP بشكل جيد مع عملاء المجتمع المتوافقين مع OpenAI، لكنه ليس OpenAI SDK رسميًا.
</Note>

## تهيئة العميل

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## الموصى به: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

## البث باستخدام Responses

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## الأدوات / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## التوافق مع Chat Completions

إذا كان إطار العمل أو plugin الخاص بك لا يزال يتوقع Chat Completions، فإن LemonData يدعم أيضًا المسار القياسي المتوافق مع OpenAI:

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
استخدم Chat Completions للتوافق فقط. بالنسبة لعمليات التكامل الجديدة، يُفضَّل استخدام `client.responses.create(...)`.
</Warning>

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
  <Accordion title="خطأ في الاتصال">
    - تحقق من أن base URL هو بالضبط `https://api.lemondata.cc/v1`
    - تحقق من عدم وجود تداخل من proxy أو عمليات override مخصصة لعميل HTTP
    - تأكد من أن إصدار SDK لديك محدث قبل تصحيح سلوك المزوّد
  </Accordion>

  <Accordion title="فشلت المصادقة">
    - تحقق من أن مفتاح API الخاص بك يبدأ بـ `sk-`
    - تحقق من أن المفتاح نشط في لوحة تحكم LemonData
    - تأكد من أن SDK يرسل `Authorization: Bearer ...`
  </Accordion>

  <Accordion title="مسار API غير صحيح">
    - `responses.create(...)` يرسل الطلبات إلى `/v1/responses`
    - `chat.completions.create(...)` يرسل الطلبات إلى `/v1/chat/completions`
    - إذا كان تطبيقك يدعم فقط Chat Completions حاليًا، فأبقِه على مسار التوافق هذا
  </Accordion>
</AccordionGroup>
