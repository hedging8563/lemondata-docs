<Note>
This skill teaches a coding agent how to integrate LemonData's **300+ AI APIs** by describing what you need. It is packaged as one common agent-first skill and works with any coding agent that supports skill or rules files.

The API is **[Agent-First](/guides/agent-first-api)** — even if the agent guesses a model name wrong, the error response tells it exactly how to fix it.
</Note>

## كيفية العمل

1. **تصف ما تحتاجه** — "أريد استخدام GPT-4 في مشروع Python الخاص بي"
2. **يقوم الوكيل باستدعاء API** — قد يخمن اسم نموذج أو نقطة نهاية
3. **في حال حدوث أي خطأ** — تعيد API تلميحات منظمة (`did_you_mean` ، `suggestions` ، `retry_after`)
4. **يقوم الوكيل بالتصحيح الذاتي** — يقرأ التلميحات ويعيد المحاولة بالمعلمات الصحيحة
5. **تحصل على كود يعمل** — عادةً من المحاولة الأولى أو الثانية
