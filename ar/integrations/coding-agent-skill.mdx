<Note>
تُعلّم هذه المهارة وكيل البرمجة لديك كيفية دمج **أكثر من 300 واجهة API للذكاء الاصطناعي** من LemonData بمجرد وصف ما تحتاجه. وهي مُعبأة كمهارة agent-first مشتركة وتعمل مع أي وكيل برمجة يدعم ملفات skill أو rules.

هذه الواجهة **[Agent-First](/guides/agent-first-api)** — حتى إذا خمن الوكيل اسم نموذج بشكل خاطئ، فستوضح له استجابة الخطأ بدقة كيف يصحح الطلب.
</Note>

## كيفية العمل

1. **تصف ما تحتاجه** — "I want to use GPT-4 in my Python project"
2. **يستدعي الوكيل الواجهة** — وقد يخمن اسم نموذج أو نقطة نهاية
3. **إذا حدث أي خطأ** — تعيد الواجهة تلميحات منظمة مثل (`did_you_mean`, `suggestions`, `retry_after`)
4. **يصحح الوكيل نفسه** — يقرأ التلميحات ويعيد المحاولة بالمعلمات الصحيحة
5. **تحصل على كود يعمل** — غالباً من المحاولة الأولى أو الثانية

## التثبيت

<Note>
استخدم أمر التثبيت غير التفاعلي القياسي التالي:

```bash
npx skills add https://github.com/hedging8563/lemondata-skills --skill lemondata-api-integration -y
```

يؤدي هذا إلى تثبيت المهارة المشتركة `lemondata-api-integration` من مستودع LemonData skills.

إذا كانت أداتك لا تدعم المُثبِّت، فانسخ المجلد `skills/lemondata-api-integration/` من المستودع إلى دليل skills أو rules المشترك في أداتك.
</Note>

### التحقق من التثبيت

اسأل وكيل البرمجة:
```
What skills are available?
```

إذا رأيت `lemondata-api-integration`، فهذا يعني أن التثبيت نجح.

## احصل على مفتاح API

<Steps>
  <Step title="زيارة LemonData">
    انتقل إلى [lemondata.cc](https://lemondata.cc)
  </Step>
  <Step title="تسجيل الدخول">
    أنشئ حساباً أو سجّل الدخول
  </Step>
  <Step title="الحصول على مفتاح API">
    انتقل إلى [Dashboard → API Keys](https://lemondata.cc/dashboard/api) وأنشئ مفتاحاً جديداً
  </Step>
  <Step title="نسخ المفتاح">
    يبدأ مفتاحك بـ `sk-...` — احفظه في مكان آمن
  </Step>
</Steps>

<Tip>
لا تحتاج إلى إعداد مفتاح API مسبقاً. عند استخدام هذه المهارة، سيطلب الوكيل المفتاح منك ويضمنه في الكود الذي ينشئه.
</Tip>

## أمثلة

### إكمال الدردشة

**أنت تقول:**
```
I want to use GPT-4 in my Python project
```

**ينشئ الوكيل:**
```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

إذا خمن الوكيل اسم نموذج خاطئاً (مثل `gpt5`)، فستعيد الواجهة:
```json
{
  "error": {
    "code": "model_not_found",
    "did_you_mean": "gpt-4o",
    "suggestions": [{"id": "gpt-4o"}, {"id": "gpt-4o-mini"}],
    "hint": "Did you mean 'gpt-4o'? Use GET /v1/models to list all available models."
  }
}
```

يقرأ الوكيل `did_you_mean`، ويصحح اسم النموذج، ثم يعيد المحاولة تلقائياً.

### إنشاء الصور

**أنت تقول:**
```
Generate images with Flux in Node.js
```

يستدعي الوكيل واجهة الصور، ويتعامل مع الأخطاء، ويولد كوداً كاملاً يتضمن منطق التنزيل والحفظ.

### التعرف على الكلام

**أنت تقول:**
```
Integrate speech-to-text in my app
```

يولد الوكيل كوداً يستخدم نقطة النهاية الصحيحة `/v1/audio/transcriptions` مع معالجة ملفات الصوت.

## استرداد الأخطاء بنهج Agent-First

تتضمن كل استجابة خطأ تلميحات منظمة يمكن لأي وكيل برمجة قراءتها. راجع [المرجع الكامل لواجهة Agent-First](/guides/agent-first-api) لمعرفة التفاصيل.

| الخطأ | ما الذي تعيده الواجهة | ما الذي يفعله الوكيل |
|-------|---------------------|---------------------|
| اسم نموذج خاطئ | `did_you_mean` + `suggestions` | يصحح نفسه ويعيد المحاولة |
| رصيد غير كافٍ | `balance_usd` + `suggestions` أرخص | ينتقل إلى نموذج أقل تكلفة |
| النموذج غير متاح | `alternatives` + `retry_after` | ينتقل إلى نموذج متاح |
| تجاوز الحد | `retry_after` (بالثواني) | ينتظر ثم يعيد المحاولة |
| طول السياق كبير جداً | `suggestions` مع نماذج أكبر | ينتقل إلى نموذج بسياق أكبر |

### تحسين نقاط النهاية الأصلية

عند استدعاء `/v1/chat/completions` باستخدام نموذج Claude أو Gemini، تعيد الواجهة رؤوس تحسين:

```
X-LemonData-Hint: This model supports native Anthropic format. Use POST /v1/messages for better performance.
X-LemonData-Native-Endpoint: /v1/messages
```

ينتقل الوكيل تلقائياً إلى نقطة النهاية الأصلية للحصول على أداء أفضل، من دون تحويل صيغة، ومع دعم التفكير الممتد وذاكرة التخزين المؤقت للمطالبات.

### اكتشاف النماذج

لا حاجة للبحث في الوثائق:

```bash
# نظرة عامة قابلة للقراءة آلياً عن الواجهة
curl https://lemondata.cc/llms.txt

# عرض النماذج حسب الفئة
curl "https://api.lemondata.cc/v1/models?category=chat" -H "Authorization: Bearer sk-KEY"
curl "https://api.lemondata.cc/v1/models?category=image" -H "Authorization: Bearer sk-KEY"

# التصفية حسب القدرات
curl "https://api.lemondata.cc/v1/models?tag=coding" -H "Authorization: Bearer sk-KEY"
```

## القدرات المدعومة

| المحادثة | GPT-4o, Claude, Gemini, DeepSeek |
| إنشاء الصور | Midjourney, Flux, Stable Diffusion |
