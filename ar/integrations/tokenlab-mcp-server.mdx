يقوم [خادم TokenLab MCP](https://github.com/hedging8563/tokenlab-mcp-server) بإنشاء أدوات MCP من عقد OpenAPI العام الخاص بـ TokenLab. يمكن للوكلاء المتوافقين مع MCP اكتشاف النماذج والأسعار، واستدعاء نقاط نهاية LLM الأصلية والمتوافقة مع OpenAI، وإنشاء وسائط متعددة، ورفع الملفات، وإدارة المهام غير المتزامنة.

استخدمه عندما يحتاج الوكيل إلى عقد TokenLab API الحالي بدلاً من قائمة أدوات يتم صيانتها يدوياً. يكشف ملف التعريف الافتراضي `core` عن 29 أداة لنقاط النهاية التي تم إنشاؤها بالإضافة إلى أداتين مركبتين للاكتشاف. بينما يكشف ملف التعريف `full` عن 76 أداة لنقاط النهاية التي تم إنشاؤها بالإضافة إلى نفس الأداتين المركبتين.

<Note>
لا تتطلب أدوات الكتالوج والأسعار العامة مفتاح TokenLab API. قم بتعيين `TOKENLAB_API_KEY` لعمليات الاستدلال (inference)، والوسائط، والصوت، والملفات، والمهام، والتضمين (embedding)، وإعادة الترتيب (rerank)، والترجمة المعتمدة. لا تضع أبداً مفتاح API في وسائط الأداة.
</Note>

## ما الذي يوفره

- اكتشاف مباشر للنماذج من `https://api.tokenlab.sh/v1/models`.
- البحث عن تفاصيل النموذج من `/v1/models/{model}`.
- البحث عن الأسعار من `/v1/models/{model}/pricing`.
- نظرة عامة على API قابلة للقراءة من قبل الوكيل من `https://api.tokenlab.sh/llms.txt`.
- إكمال الدردشة والاستجابات المتوافقة مع OpenAI، ورسائل Anthropic، و Gemini generateContent دون تغيير أشكال الطلبات الأصلية الخاصة بها.
- إنشاء الصور وتعديلها من خلال روابط JSON، أو معرفات ملفات TokenLab، أو ملفات multipart محلية.
- الفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد، والكلام، والنسخ، وترجمة الصوت، والتضمينات، والتضمينات متعددة الوسائط، وإعادة الترتيب، وترجمة النصوص.
- ملخصات مهام غير متزامنة موحدة لعمليات الصور، والفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد، وعمليات إنشاء العوالم.
- مزامنة يومية للعقد تقوم بجلب مستند OpenAPI العام، وإعادة إنشاء مخططات الأدوات، وتشغيل اختبارات نقاط النهاية والملفات، وتحديث `main` فقط عند اجتياز كل فحص.

## التثبيت من GitHub

قم باستنساخ المستودع العام وتثبيت التبعيات:

```bash
git clone https://github.com/hedging8563/tokenlab-mcp-server.git
cd tokenlab-mcp-server
npm install
npm test
```

ابدأ تشغيل الخادم عبر stdio:

```bash
npm start
```

متغير البيئة الاختياري `TOKENLAB_API_BASE` يفتقر افتراضياً إلى `https://api.tokenlab.sh`. قم بتعيين `TOKENLAB_MCP_TOOL_PROFILE=full` عندما يحتاج العميل إلى كشف API المطور الأوسع بدلاً من ملف التعريف الافتراضي `core`.

## إعداد أي عميل MCP يعمل عبر stdio

استخدم القيم نفسها في أي عميل يدعم خوادم MCP المحلية عبر stdio. قد يعرضها العميل كحقول نموذج أو يحفظها بصيغة JSON أو TOML أو YAML، لكن معاني الحقول تبقى نفسها. أضف كل وسيطة كعنصر مستقل.

| الحقل | القيمة | ملاحظات |
|---|---|---|
| اسم الخادم | `tokenlab-model-catalog` | يمكن استخدام أي اسم فريد. |
| وسيلة النقل | `stdio` | يعمل TokenLab MCP كعملية فرعية محلية. |
| أمر التشغيل | `npx` | يشغّل حزمة npm المنشورة. |
| الوسائط | `-y` ثم `@tokenlabai/mcp-server` | استخدم `@tokenlabai/mcp-server@0.4.2` لتثبيت الإصدار المتحقق منه حالياً. |
| متغير البيئة | `TOKENLAB_API_KEY` = `<TOKENLAB_API_KEY>` | اختياري لأدوات الكتالوج العام ومطلوب لأدوات الاستدلال والوسائط. |
| تمرير متغير البيئة | اتركه فارغاً أو أدخل `TOKENLAB_API_KEY` | استخدم اسم المتغير فقط إذا كان المفتاح مُصدَّراً مسبقاً في البيئة المحلية للعميل. لا تضبط المفتاح نفسه في المكانين. |
| دليل العمل | اتركه فارغاً | لا يحتاج `npx` إلى دليل مشروع لهذه الحزمة. |

انسخ الإعداد الكامل التالي إلى العملاء الذين يقبلون كائن JSON باسم `mcpServers`:

```json
{
  "mcpServers": {
    "tokenlab-model-catalog": {
      "command": "npx",
      "args": ["-y", "@tokenlabai/mcp-server"],
      "env": {
        "TOKENLAB_API_KEY": "<TOKENLAB_API_KEY>"
      }
    }
  }
}
```

احذف كتلة `env` إذا كنت تحتاج فقط إلى أدوات النماذج والأسعار العامة. إذا كان العميل يتوقع كائن خادم واحداً بدلاً من غلاف `mcpServers`، فانسخ الكائن الداخلي الذي يحتوي على `command` و`args` و`env` فقط.

<Warning>
لا تنشر أبداً لقطات شاشة أو سجلات أو ملفات إعداد تحتوي على مفتاح API حقيقي. استخدم قيمة نائبة في الأمثلة وألغِ فوراً أي مفتاح تم كشفه.
</Warning>

## التثبيت في Codex

أضف خادم الكتالوج العام إلى تكوين Codex الخاص بك:

```bash
codex mcp add tokenlab-model-catalog -- npx -y @tokenlabai/mcp-server
```

ابدأ جلسة Codex جديدة بعد إضافة الخادم. لا تتطلب أدوات الكتالوج العامة `TOKENLAB_API_KEY`.

لتمكين أدوات الاستدلال، قم بتضمين مفتاح TokenLab API الخاص بك عند إضافة الخادم:

```bash
codex mcp add --env TOKENLAB_API_KEY=your-tokenlab-api-key tokenlab-model-catalog -- npx -y @tokenlabai/mcp-server
```

## التثبيت في Cline

قم بتثبيت خادم stdio المنشور باستخدام Cline CLI:

```bash
cline mcp add tokenlab --yes -- npx -y @tokenlabai/mcp-server
```

تم التحقق من الأمر باستخدام Cline CLI ويكتمل دون تحذيرات إعداد. تعمل أدوات الكتالوج العامة على الفور؛ قم بتعيين `TOKENLAB_API_KEY` في بيئة Cline الخاصة بك عندما تحتاج إلى أدوات الاستدلال.

أعد تشغيل عميل MCP بعد حفظ التكوين.

{

## ملفات تعريف الأدوات التي تم إنشاؤها

| ملف التعريف | الأدوات المكشوفة | التغطية |
|---|---:|---|
| `core` (افتراضي) | 31 | 29 أداة لنقاط النهاية بالإضافة إلى `compare_models` و `get_api_overview`. تغطي الكتالوج، والأسعار، ونقاط نهاية LLM الأصلية، والصور، والفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد، والصوت، والمهام، والملفات، والتضمينات، وإعادة الترتيب، والترجمة. |
| `full` | 78 | 76 أداة لنقاط النهاية بالإضافة إلى أداتي الاكتشاف المركبتين. تضيف دورة حياة الاستجابة، والدفعات، والعوالم، واكتشاف النماذج الأصلية، وعمليات المطورين الأخرى المسموح بها. |

يتم إنشاء أسماء الأدوات، والأوصاف، ومخططات الإدخال، وطرق HTTP، والمسارات، وأنواع المحتوى، ومتطلبات المصادقة، وسلوك المهام من لقطة OpenAPI المعتمدة. يوفر تراكب MCP فقط أسماء مستعارة ثابتة للأدوات، وعضوية ملف التعريف، ودلالات المهام غير المتزامنة، ومتغيرات multipart، وحذف الأسرار، وقيود عدم البث.

تشمل أدوات `core` الشائعة:

| العائلة | أدوات تمثيلية |
|---|---|
| الكتالوج والأسعار | `list_models`, `get_model`, `get_model_pricing`, `get_pricing`, `compare_models` |
| نقاط نهاية LLM الأصلية | `create_chat_completion`, `create_response`, `create_anthropic_message`, `create_gemini_content` |
| الصور | `create_image`, `create_image_file`, `edit_image`, `edit_image_file` |
| الفيديو، الموسيقى، والنمذجة ثلاثية الأبعاد | `create_video`, `create_music`, `create_3d_model` |
| الصوت | `create_speech`, `transcribe_audio`, `translate_audio` |
| التضمينات والنصوص | `create_embedding`, `create_multimodal_embedding`, `rerank_documents`, `translate_text` |
| الملفات والمهام | `upload_file`, `list_files`, `retrieve_file`, `retrieve_file_content`, `delete_file`, `get_task_status`, `cancel_task` |

تعيد استدعاءات أدوات MCP نتيجة نهائية واحدة. يتم استبعاد العمليات التي تعتمد على البث فقط والعمليات في الوقت الفعلي، وتقوم مخططات الطلبات التي تم إنشاؤها بتقييد حقول `stream` المدعومة لتكون `false`. تعيد استجابات الصور والصوت الصغيرة محتوى MCP أصلياً؛ بينما تُكتب الاستجابات الثنائية الأكبر في `TOKENLAB_ARTIFACT_DIR` وتُعاد مع مسارها المحلي، ونوع MIME، وعدد البايتات.

## نتائج الوسائط غير المتزامنة

تعيد عمليات إنشاء الفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد ملخصات مهام غير متزامنة. يمكن أن تعيد عمليات إنشاء الصور وتعديلها إما نتيجة مكتملة أو مهمة غير متزامنة، اعتماداً على النموذج والطلب المختارين.

عندما يكون `delivery.mode` هو `async`، قم باستدعاء `get_task_status` مع `{ "id": delivery.task_id }` حتى يصبح `delivery.terminal` هو `true`. حدد الاكتمال من `status`؛ `progress` اختياري ويجب عدم استخدامه كشرط نهائي.

## سير عمل الوكيل الموصى به

1. استدعِ `list_models` عندما لا يحدد المستخدم نموذجاً.
2. استخدم `recommended_for` للمهام غير المتعلقة بالدردشة، مثل الصور، والفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد، و TTS، و STT، والتضمينات، وإعادة الترتيب، أو الترجمة.
3. استدعِ `get_model` قبل بناء طلب غير متعلق بالدردشة، أو إعادة محاولة طلب فاشل، أو التبديل بين عائلات نقاط النهاية.
4. استدعِ `get_model_pricing` عندما تؤثر تكلفة النموذج على اختيار المستخدم.
5. استخدم `compare_models` عندما يعتمد الاختيار على عدة مرشحين.
6. استدعِ الأداة التي تم إنشاؤها والتي تطابق عقد API المطلوب، أو استخدم `get_api_overview` للحصول على خريطة مضغوطة لعائلات TokenLab API.

## توجيهات نقاط النهاية الأصلية

يدعم TokenLab المسارات المتوافقة مع OpenAI وعائلات نقاط النهاية الأصلية. يساعد خادم MCP الوكيل في اختيار المسار الصحيح قبل كتابة الكود:

| العائلة | المسار الشائع |
|---|---|
| دردشة متوافقة مع OpenAI | `/v1/chat/completions` |
| الاستجابات | `/v1/responses` |
| رسائل Anthropic | `/v1/messages` |
| Gemini أصلي | `/v1beta/models/{model}:generateContent` |
| الصور | `/v1/images/generations`, `/v1/images/edits` |
| الفيديو | `/v1/videos/generations` |
| الموسيقى | `/v1/music/generations` |
| النمذجة ثلاثية الأبعاد | `/v1/3d/generations` |
| الصوت | `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/audio/translations` |
| التضمينات وإعادة الترتيب | `/v1/embeddings`, `/v1/rerank` |
| ترجمة النصوص | `/v1/translations` |

## مستكشف النماذج المستضاف

يمكن للعملاء الذين يدعمون Streamable HTTP الاتصال بـ:

```text
https://tokenlab-model-explorer.vercel.app/mcp
```

المستكشف المستضاف عام ويكشف عن `open_tokenlab_model_explorer` و `compare_tokenlab_models` و `generate_tokenlab_endpoint_example`. استخدم خادم npm المحلي أعلاه عندما تحتاج إلى ملفات تعريف core/full التي تم إنشاؤها، أو رفع الملفات المحلية، أو عمليات API المعتمدة.

## الاستخدام مع مهارات TokenLab

يعد خادم MCP مفيداً في وقت التشغيل، بينما يعلم [مستودع مهارات TokenLab](https://github.com/hedging8563/tokenlab-skills) وكلاء البرمجة كيفية إنشاء وإصلاح كود التكامل.

استخدم كلاهما عند توفرهما:

- خادم MCP: لاكتشاف النماذج الحالية، والأسعار، وتفاصيل نقاط النهاية.
- مهارة `tokenlab-api-integration`: لإنشاء أمثلة API قابلة للتشغيل ومعالجة أخطاء TokenLab المهيكلة.
- مهارة `tokenlab-model-picker`: لاختيار نماذج قوية لمهمة المستخدم.
- مهارة `tokenlab-native-endpoints`: لتقرير متى يجب استخدام الاستجابات، ورسائل Anthropic، و Gemini، والوسائط، والصوت، والتضمين، وإعادة الترتيب، أو مسارات الترجمة.
