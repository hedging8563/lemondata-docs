## نظرة عامة

يتضمن مكون **OpenAI** في Langflow حقلاً يسمى **OpenAI API Base**. قم بتوجيه هذا الحقل إلى نقطة النهاية `/v1` المتوافقة مع OpenAI الخاصة بـ TokenLab واستخدم معرفات نماذج TokenLab.

<Note>
**النوع**: منشئ سير عمل الذكاء الاصطناعي منخفض الكود (Low-code)

**المسار الأساسي**: إكمال المحادثات المتوافق مع OpenAI

**مستوى الدعم**: مدعوم مع قيود في النطاق
</Note>

## مكون OpenAI

1. أضف مكون نموذج لغة **OpenAI**.
2. اضبط **OpenAI API Key** على مفتاح TokenLab الخاص بك.
3. قم بتوسيع الإعدادات المتقدمة.
4. اضبط **OpenAI API Base** على `https://api.tokenlab.sh/v1`.
5. اضبط **Model Name** على معرف نموذج TokenLab.
6. قم بتوصيل مخرج النموذج بالوكيل (agent) أو السلسلة (chain) أو سير العمل الخاص بك.

## القيم

| الحقل | القيمة |
|-------|-------|
| OpenAI API Base | `https://api.tokenlab.sh/v1` |
| OpenAI API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

## النماذج الموصى بها

- `gpt-5.4-mini` لمعظم اختبارات سير العمل
- `claude-sonnet-5` لكتابة واستنتاج أقوى
- `gemini-3.5-flash` لسير العمل السريع والمتوافق مع الوسائط المتعددة
- `deepseek-v4-flash` للتكرارات السريعة في البرمجة والاستنتاج

استخدم مكون LiteLLM Proxy في Langflow إذا كان نشرك يعتمد بالفعل على توجيه المزود من خلال وكيل LiteLLM.
