## نظرة عامة

يقوم OpenLIT بتهيئة أدوات القياس (instrumentation) لحزم OpenAI SDK الرسمية، بحيث يمكن مراقبة طلبات TokenLab عن طريق ضبط عميل SDK باستخدام عنوان URL الأساسي `/v1` الخاص بـ TokenLab.

<Note>
**النوع**: المراقبة (Observability)

**المسار الأساسي**: أدوات قياس OpenAI SDK

**مستوى الثقة في الدعم**: مسار مراقبة مدعوم ومتوافق مع OpenAI
</Note>

## التثبيت

```bash
pip install openlit openai
```

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## مثال

```python
import os

import openlit
from openai import OpenAI

openlit.init()

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Hello from OpenLIT"}],
)
```

## ملاحظات حول نقاط النهاية (Endpoints)

يتبع OpenLIT مسار أدوات قياس SDK. تُعد Chat Completions هي واجهة التكامل الأكثر أماناً؛ أما استدعاءات TokenLab الأصلية الأخرى فتعتمد على ما إذا كان إعداد OpenLIT/OpenTelemetry الخاص بك يلتقط طريقة SDK تلك أو عميل HTTP.
