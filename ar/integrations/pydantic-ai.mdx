## نظرة عامة

يمكن لـ Pydantic AI استخدام TokenLab مع `OpenAIChatModel` و `OpenAIProvider(base_url=...)`.

<Note>
**النوع**: إطار عمل الوكيل (Agent Framework)

**المسار الأساسي**: إكمال المحادثات المتوافق مع OpenAI

**مستوى دعم الموثوقية**: مسار مزود متوافق مع OpenAI مدعوم
</Note>

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## الوكيل الأساسي

```python
import os

from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "claude-sonnet-5",
    provider=OpenAIProvider(
        base_url="https://api.tokenlab.sh/v1",
        api_key=os.environ["TOKENLAB_API_KEY"],
    ),
)

agent = Agent(model)
result = agent.run_sync("Explain one benefit of OpenAI-compatible gateways.")
print(result.output)
```

## الأدوات

```python
from pydantic_ai import Agent, RunContext

agent = Agent(model)

@agent.tool
def lookup_status(ctx: RunContext[None], service: str) -> str:
    return f"{service} is online"

result = agent.run_sync("Check the TokenLab status.")
print(result.output)
```

## ملاحظات حول نقاط النهاية

يستهدف هذا المسار فئة نموذج إكمال المحادثات (Chat Completions) الخاص بـ OpenAI في Pydantic AI. للحصول على سلوك بروتوكول أصلي للمزود أو خاص بالاستجابات (Responses-native)، اختر مسار عميل يكشف عن ذلك البروتوكول مباشرة.
