## نظرة عامة

توفر LemonData إمكانية الوصول إلى نماذج Luma AI. الإجمالي: **نموذجان** متاحان.

## نماذج الدردشة

| معرف النموذج | التسعير |
|----------|--------|
| `luma-video-api` | راجع لوحة التحكم |
| `luma-video-extend-api` | راجع لوحة التحكم |


## الاستخدام

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="luma-video-api",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

<Note>
الأسعار المعروضة هي أسعار المنصة (~70% من الأسعار الرسمية).
</Note>
