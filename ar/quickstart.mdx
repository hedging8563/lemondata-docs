## الخطوة 1: احصل على مفتاح API الخاص بك

<Steps>
  <Step title="أنشئ حسابًا">
    سجّل في [lemondata.cc](https://lemondata.cc) باستخدام بريدك الإلكتروني، أو Gmail، أو حساب GitHub.
  </Step>
  <Step title="أضف رصيدًا">
    افتح لوحة التحكم وأضف رصيدًا إلى حسابك. تستخدم LemonData تسعير الدفع حسب الاستخدام دون حد أدنى للالتزام.
  </Step>
  <Step title="أنشئ مفتاح API">
    انتقل إلى **Dashboard → API Keys** وأنشئ مفتاحًا جديدًا. انسخه واحفظه بأمان لأنه يُعرض مرة واحدة فقط.
  </Step>
</Steps>

<Warning>
حافظ على أمان مفتاح API الخاص بك. لا تقم أبدًا بكشفه في كود جهة العميل أو المستودعات العامة.
</Warning>

## الخطوة 3: أرسل أول طلب لك

بالنسبة للمشاريع الجديدة، ابدأ باستخدام **Responses API**.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
إذا كان إطار العمل أو الأداة التي تستخدمها لا تزال تتوقع Chat Completions، فإن LemonData يدعم أيضًا `POST /v1/chat/completions`. بالنسبة لعمليات التكامل الجديدة، يُفضّل استخدام `POST /v1/responses`.
</Note>

## جرّب نماذج مختلفة

تدعم LemonData أكثر من 300 نموذج. غيّر فقط الحقل `model`:

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## فعّل البث

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
