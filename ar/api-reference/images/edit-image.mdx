## نظرة عامة

إنشاء صورة معدلة أو موسعة من صورة أصلية ووصف نصي. يتطلب نوع المحتوى `multipart/form-data`.

يدعم المسار كلا النمطين:

- مسار الرفع التقليدي `multipart/form-data` على نمط DALL-E والمذكور أدناه
- طلبات JSON التي توفر `image_url` أو `image_urls` أو مراجع `images` الرسمية لعائلات الصور المدعومة من صورة إلى صورة

<Note>
`gpt-image-2` مدعوم هنا. يقبل رفع multipart باسم `image`، و JSON `image_url` / `image_urls`، ومراجع `images[]` الرسمية (`image_url` أو `file_id`) حتى 16 صورة مصدر. أنشئ قيم `file_id` أولاً عبر `/v1/files`. تشمل المعلمات الاختيارية الشائعة `mask` و `n` و `size` و `quality` و `response_format` و `output_format` / `output_compression` و `moderation` و `partial_images` و `user`.
</Note>

## جسم الطلب

**مهلة الطلبات المتزامنة:** قد يعيد بعض مزودي الصور الذين يتم التوجيه إليهم الصورة النهائية inline وينتظرون اكتمال التوليد. قد تستغرق طلبات الدقة العالية أو الجودة العالية ما يقارب دقيقة أو أكثر، لذا اضبط مهلة عميل HTTP على `120s` على الأقل. إذا احتوت استجابة الإنشاء على `status: "pending"` أو `task_id` أو `poll_url`، فاتبع `poll_url` المُعاد بدلًا من الانتظار.

When you send JSON `image_url`, `image_urls`, or `images[].image_url` and the selected upstream requires multipart upload, LemonData fetches the referenced images and forwards them as multipart `image` files. Remote URLs must be public HTTP(S) resources that do not require cookies or custom headers, must resolve to PNG, JPEG, or WebP image bytes, are fetched with a `10s` timeout and up to `3` redirects, and are limited to `50MB` per image and `200MB` total per request.

<ParamField body="image" type="file">
  Source image files for multipart requests. Send `image` multiple times for GPT Image edits when you need more than one source image. Each file must be PNG, JPEG, or WebP and less than 50MB. Legacy DALL-E 2 mask edits still expect PNG inputs with transparent areas, or a separate `mask`.
</ParamField>

<ParamField body="prompt" type="string" required>
  وصف نصي للتعديل المطلوب.
</ParamField>

<ParamField body="mask" type="file">
  صورة إضافية تشير مناطقها الشفافة بالكامل إلى أماكن التعديل. يجب أن تكون ملف PNG صالح، أقل من 50MB، وبنفس أبعاد `image`.
</ParamField>

<ParamField body="model" type="string" default="dall-e-2">
  The model to use for image edit. `gpt-image-2` is supported; legacy DALL-E style edits can continue to use `dall-e-2`.
</ParamField>

<ParamField body="n" type="integer" default="1">
  عدد الصور المراد إنشاؤها. يجب أن يكون بين 1 و 10.
</ParamField>

<ParamField body="size" type="string">
  The generated image size. For `gpt-image-2`, use `auto` or `WIDTHxHEIGHT`; dimensions must be multiples of 16, longest edge at most `3840px`, long/short ratio at most `3:1`, and total pixels between `655,360` and `8,294,400`. Legacy DALL-E edits support `256x256`, `512x512`, or `1024x1024`.
</ParamField>

<ParamField body="response_format" type="string" default="url">
  تنسيق إرجاع الصور المُنشأة. يجب أن يكون `url` أو `b64_json`.
</ParamField>

<ParamField body="user" type="string">
  معرف فريد يمثل المستخدم النهائي لمراقبة سوء الاستخدام.
</ParamField>

## الاستجابة

<ResponseField name="created" type="integer">
  الطابع الزمني Unix لوقت إنشاء الصور.
</ResponseField>

<ResponseField name="data" type="array">
  مصفوفة الصور المُنشأة.

  كل عنصر يحتوي على:
  - `url` (string): رابط الصورة المعدلة (إذا كان response_format هو `url`)
  - `b64_json` (string): الصورة بترميز Base64 (إذا كان response_format هو `b64_json`)
</ResponseField>

```go Go
package main

import (
    "bytes"
    "fmt"
    "io"
    "mime/multipart"
    "net/http"
    "os"
)

func main() {
    body := &bytes.Buffer{}
    writer := multipart.NewWriter(body)

    image, _ := os.Open("sunlit_lounge.png")
    defer image.Close()
    part, _ := writer.CreateFormFile("image", "sunlit_lounge.png")
    io.Copy(part, image)

    mask, _ := os.Open("mask.png")
    defer mask.Close()
    maskPart, _ := writer.CreateFormFile("mask", "mask.png")
    io.Copy(maskPart, mask)

    writer.WriteField("prompt", "A sunlit indoor lounge area with a pool")
    writer.WriteField("n", "1")
    writer.WriteField("size", "1024x1024")
    writer.Close()

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/images/edits", body)
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", writer.FormDataContentType())

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    result, _ := io.ReadAll(resp.Body)
    fmt.Println(string(result))
}
```

## ملاحظات

<Note>
  For JSON `image_url`, `image_urls`, or `images[].image_url`, LemonData only converts URLs to multipart when the selected upstream channel requires file upload. Private URLs, signed URLs that require extra headers, internal network addresses, non-image responses, and oversized images are rejected before the upstream request. For private assets, send multipart `image` files directly or create `/v1/files` references.
</Note>
