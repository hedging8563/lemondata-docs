---

## نظرة عامة

استخدم نقطة النهاية هذه للاستطلاع غير المتزامن الموحّد عبر أنواع المهام مثل إنشاء الفيديو والصورة والموسيقى و3D.

<Info>
إذا كانت استجابة الإنشاء تتضمن `poll_url`، فاستدعِ ذلك المسار نفسه تمامًا. بالنسبة لسير العمل غير المتزامن الأحدث، قد يشير `poll_url` إلى `/v1/tasks/{id}`.
</Info>

## معاملات المسار

<ParamField path="id" type="string" required>
  معرّف المهمة المُعاد من طلب الإنشاء.
</ParamField>

## الاستجابة

<ResponseField name="id" type="string">
  المعرّف المعياري للمهمة غير المتزامنة.
</ResponseField>

<ResponseField name="task_id" type="string">
  الاسم البديل لمعرّف المهمة غير المتزامنة.
</ResponseField>

<ResponseField name="poll_url" type="string">
  رابط polling المفضّل الذي تعيده استجابة الإنشاء.
</ResponseField>

<ResponseField name="status" type="string">
  حالة المهمة مثل `pending` أو `processing` أو `completed` أو `failed`.
</ResponseField>

<ResponseField name="progress" type="number">
  نسبة التقدم عندما تكون متاحة.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL الأصل الناتج عند اكتمال المهمة وإنتاج فيديو.
</ResponseField>

<ResponseField name="video" type="object">
  كائن فيديو واحد يتضمن `url` و`duration` و`width` و`height` عند توفره.
</ResponseField>

<ResponseField name="videos" type="array">
  مصفوفة فيديوهات عندما يعيد المصدر أكثر من نتيجة.
</ResponseField>

<ResponseField name="error" type="string">
  رسالة الخطأ عند فشل المهمة.
</ResponseField>

<ResponseField name="created" type="integer">
  الطابع الزمني للإنشاء عند توفره.
</ResponseField>

<ResponseField name="updated" type="integer">
  الطابع الزمني لآخر تحديث عند توفره.
</ResponseField>

<ResponseField name="model" type="string">
  النموذج المستخدم عند توفره.
</ResponseField>

## أمثلة

```bash cURL
curl "https://api.lemondata.cc/v1/tasks/video_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

poll_url = "/v1/tasks/video_abc123"
response = requests.get(
    f"https://api.lemondata.cc{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/video_abc123';
const response = await fetch(`https://api.lemondata.cc${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
