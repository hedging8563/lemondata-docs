## نظرة عامة

هذه الواجهات مخصصة للفرق التي تستخدم بالفعل شكل مهام Seedance بأسلوب Volc. يتم التوثيق باستخدام TokenLab Bearer API key. يبدأ معرف المهمة المرجع بـ `cgt-`؛ قم بالاستعلام عن الحالة حتى تصبح `status` إحدى `succeeded` أو `failed` أو `cancelled` أو `expired`.

انظر أيضا [نماذج فيديو Seedance 2.0](/ar/guides/seedance-2-video) و [توليد الفيديو](/ar/guides/video-generation).

## شكل الاستجابة

تستخدم استجابة المهمة `queued` أو `running` أو `succeeded` أو `failed` أو `cancelled` أو `expired`. تعيد المهام الناجحة `content.video_url`؛ وعند توفرها تظهر أيضا `content.last_frame_url` والمعلمات المعكوسة مثل `return_last_frame` و `watermark` و `usage` و `progress`. تكون `error` بقيمة `null` عند عدم وجود فشل.

## مثال

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
