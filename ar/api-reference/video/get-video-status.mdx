## معلمات المسار (Path Parameters)

<ParamField path="id" type="string" required>
  المعرّف المعياري للمهمة غير المتزامنة. عندما يظهر كلٌّ من `id` و`task_id`، فاعتبرهما نفس المهمة.
</ParamField>

<Info>
إذا أعادت استجابة الإنشاء `poll_url`، فاستدعِ هذا الرابط نفسه تمامًا. وعندما يشير إلى `/v1/tasks/{id}`، فاعتبره نقطة الحالة الثابتة المعيارية.
</Info>

## الاستجابة (Response)

<ResponseField name="id" type="string">
  المعرّف المعياري للمهمة غير المتزامنة.
</ResponseField>

<ResponseField name="task_id" type="string">
  الاسم البديل لمعرّف المهمة غير المتزامنة.
</ResponseField>

<ResponseField name="poll_url" type="string">
  رابط polling المفضّل الذي تعيده استجابة الإنشاء.
</ResponseField>

<ResponseField name="status" type="string">
  حالة المهمة: `pending`، `processing`، `completed`، `failed`.
</ResponseField>

<ResponseField name="progress" type="number">
  نسبة التقدم (0-100).
</ResponseField>

<ResponseField name="video_url" type="string">
  رابط (URL) الفيديو الذي تم إنشاؤه (عند الاكتمال).
</ResponseField>

<ResponseField name="video" type="object">
  كائن فيديو واحد يتضمن `url` و`duration` و`width` و`height` عند توفره.
</ResponseField>

<ResponseField name="videos" type="array">
  مصفوفة فيديوهات عندما يعيد المصدر أكثر من نتيجة.
</ResponseField>

<ResponseField name="error" type="string">
  رسالة الخطأ (في حال الفشل).
</ResponseField>

<ResponseField name="created" type="integer">
  الطابع الزمني للإنشاء.
</ResponseField>

<ResponseField name="updated" type="integer">
  الطابع الزمني لآخر تحديث.
</ResponseField>

<ResponseField name="model" type="string">
  النموذج المستخدم في المهمة.
</ResponseField>

```python Python
import requests
import time

task_id = "video_abc123"

while True:
    response = requests.get(
        f"https://api.lemondata.cc/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )

    data = response.json()
    print(f"Status: {data['status']}, Progress: {data.get('progress', 0)}%")

    if data["status"] == "completed":
        print(f"Video URL: {data['video_url']}")
        break
    elif data["status"] == "failed":
        print(f"Error: {data['error']}")
        break

    time.sleep(5)  # Poll every 5 seconds
```

package main

import (

            fmt.Printf("Video URL: %s\n", result["video_url"])
            break
        } else if result["status"] == "failed" {
            fmt.Printf("Error: %s\n", result["error"])
            break
        }

        time.Sleep(5 * time.Second)
    }

## أفضل ممارسات الاستقصاء (Polling)

- قم بالاستقصاء (Poll) كل 5-10 ثوانٍ
- قم بتنفيذ التراجع الأسي (exponential backoff) للمهام الطويلة
- قم بتعيين حد أقصى للمهلة (على سبيل المثال، 10 دقائق)
- تعامل مع حالة `failed` بشكل مناسب

```python
import time

def wait_for_video(task_id, max_wait=600, interval=5):
    """Wait for video with timeout."""
    start = time.time()

    while time.time() - start < max_wait:
        response = requests.get(
            f"https://api.lemondata.cc/v1/tasks/{task_id}",
            headers={"Authorization": "Bearer sk-your-api-key"}
        )
        data = response.json()

        if data["status"] == "completed":
            return data["video_url"]
        elif data["status"] == "failed":
            raise Exception(data.get("error", "Video generation failed"))

        time.sleep(interval)

    raise TimeoutError("Video generation timed out")
```
