---
title: "حذف مجموعة أصول المواد"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "حذف مجموعة مواد Seedance المملوكة للمؤسسة الحالية."
---

حذف مجموعة مواد وأصول مواد TokenLab الموجودة بداخلها. لا يمكن التراجع عن هذا الإجراء.

إذا لم تتمكن مكتبة مواد TokenLab من إكمال عملية الحذف لأن حالة التفويض الحالية لا تسمح بذلك، فستعيد TokenLab خطأً محايداً في مكتبة المواد. بعد الحذف، لن يكون بالإمكان استخدام المجموعة وأصولها في إنشاء الفيديو.

## مثال على الطلب

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## مثال على الاستجابة

```json
{
  "deleted": true,
  "id": "seedance_group_virtual_123"
}
```
