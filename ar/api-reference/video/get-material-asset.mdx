استرجع أصلاً مادياً واحداً وافحص حالة معالجته. لا يمكن استخدام الأصل في إنشاء الفيديو إلا عندما تكون قيمة `ready` هي `true` وحالة `status` هي `ACTIVE`.

إذا أرجع إنشاء الفيديو رسالة `Seedance material asset not found or not accessible`، فتأكد من أنك قمت بتمرير `id` الخاص بهذا الأصل المادي، وليس `group_id` الخاص بالمادة.

## مثال على الطلب

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## مثال على الاستجابة

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",

  "asset_name": "Front view",
  "asset_type": "Image",
  "asset_url": "https://example.com/reference.png",
  "cover_url": null,
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
