openapi: "GET /v1/videos/assets/visual-validation-sessions"
description: "سرد جلسات التحقق من المواد الخاصة بالشخص الحقيقي للمؤسسة الحالية."
---

قم بسرد جلسات التحقق السابقة للمراجعة، ودعم العملاء، والمطابقة. هذا السجل طويل الأمد، لكنه لا يغني عن خطوة الربط (bind) قصيرة الأمد: يجب أن يتم ربط التحقق الناجح فوراً ضمن نافذة الـ 120 ثانية.

تتضمن الاستجابة معرفات TokenLab فقط ولا تتضمن بيانات الاعتماد. بعد نجاح عملية الربط، يكون `group_id` هو معرف مجموعة مواد TokenLab المستخدم لعمليات رفع `liveness_face`.

## مثال على الطلب

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions?page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
