---
title: "إنشاء مجموعة أصول المواد"
openapi: "POST /v1/videos/assets/groups"
description: "إنشاء مجموعة مواد للصور الرمزية الافتراضية (virtual-avatar) في Seedance."
---

قم بإنشاء مجموعة مواد من النوع `library_type: "aigc_avatar"`. استخدم نقطة النهاية (endpoint) هذه للصور الرمزية الافتراضية، والمنتجات، والأنماط، والمراجع الأخرى القابلة لإعادة الاستخدام التي لا تتطلب تحققاً من شخص حقيقي.

يتم إنشاء مجموعات المواد الخاصة بالأشخاص الحقيقيين من خلال [التحقق من مواد الأشخاص الحقيقيين](/ar/api-reference/video/create-real-person-verification-session) ولا يمكن إنشاؤها مباشرة باستخدام نقطة النهاية هذه.

## مثال على الطلب

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_name":"Product references","description":"Reusable product shots"}'
```

## مثال على الاستجابة

```json
{
  "id": "seedance_group_virtual_123",
  "object": "seedance.material_asset_group",

  "status": "ACTIVE",

}
```
