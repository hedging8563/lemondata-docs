---
title: "تحديث أصل المادة (Material Asset)"
openapi: "PUT /v1/videos/assets/{assetId}"
description: "تحديث أصل مادة Seedance المملوك للمؤسسة الحالية."
---

قم بتحديث اسم المادة أو البيانات الوصفية (metadata). عنوان URL المصدر ونوع الأصل ثابتان بعد الإنشاء؛ قم بإنشاء أصل جديد عند تغيير الملف المصدر.

## مثال على الطلب

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"}}'
```

## مثال على الاستجابة

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view approved",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
