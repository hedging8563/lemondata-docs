قم بربط نتيجة التحقق الناجحة وإنشاء تعيين مجموعة مواد الشخصية الحقيقية في TokenLab. استخدم `session_id` و `verification_token` من إعادة توجيه رد الاتصال (callback) الخاص بـ TokenLab.

تتحقق TokenLab من أن الجلسة تنتمي إلى نفس المؤسسة، ولم تنتهِ صلاحيتها، ومرتبطة بنفس خدمة المواد المستخدمة في جلسة التحقق. تُرجع الاستجابة `group_id` الخاص بـ TokenLab فقط؛ استخدمه عند إنشاء أصول مواد `liveness_face`.

## مثال على الطلب

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## مثال على الاستجابة

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "seedance_group_real_123",
  "material_group": {
    "id": "seedance_group_real_123",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
