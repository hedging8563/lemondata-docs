---

قم بإنشاء جلسة تحقق قصيرة العمر وقم بتوجيه المستخدم الخاص بك إلى رابط H5 الذي تم إرجاعه. يُرجع TokenLab الحقول المحايدة فقط: `session_id` و `verification_token` و `h5_link` و `callback_url` و `expires_in` و `language`.

تنتهي صلاحية الجلسة والرمز (token) ورابط H5 بعد 120 ثانية. عند اكتمال تدفق H5، يقوم TokenLab بإعادة التوجيه إلى `callback_url` الخاص بك مع معاملات الاستعلام (query parameters) التالية:

| المعامل (Parameter) | المعنى |
|-----------|---------|
| `session_id` | معرف جلسة التحقق في TokenLab. |
| `verification_token` | رمز مبهم (opaque token) يُستخدم لربط النتيجة. |
| `verification_status` | `succeeded` أو `failed`. |
| `result_code` | رمز النتيجة لمنطق تطبيقك الخاص. |

إذا كانت حالة التحقق `verification_status` هي `succeeded`، قم باستدعاء [Bind Real-Person Verification Result](/ar/api-reference/video/bind-real-person-verification-result). يمكن استخدام [وحدة تحكم الاختبار](https://tokenlab.sh/dashboard/seedance-assets) للتحقق من معالجة رد الاتصال (callback) قبل ربط التدفق بمنتجك.

## مثال على الطلب

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"callback_url":"https://yourapp.example.com/seedance/callback","language":"en"}'
```

## مثال على الاستجابة

```json
{
  "object": "seedance.visual_validation_session",
  "session_id": "svv_abc123",
  "verification_token": "svvt_def456",
  "h5_link": "https://verify.example.com/h5?lng=en",
  "callback_url": "https://yourapp.example.com/seedance/callback",
  "expires_in": 120,
  "language": "en"
}
```
