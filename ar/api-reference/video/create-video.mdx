## نظرة عامة

توليد الفيديو يتم بشكل غير متزامن. تقوم بإرسال طلب، وتتلقى معرّف مهمة و `poll_url`، ثم تجري polling للحصول على النتيجة.

<Info>
للحصول على سلوك polling الأكثر موثوقية، اتبع `poll_url` المُعاد من طلب الإنشاء بشكل مطابق.
</Info>

<Warning>
Audio output is model-dependent. Veo 3 family defaults to audio-on. Use `output_audio` to explicitly request audio when supported. The camelCase alias `outputAudio` is also accepted for compatibility.
</Warning>


## جسم الطلب

<ParamField body="model" type="string" default="sora-2">
  معرّف نموذج الفيديو. القيمة الافتراضية في API هي `sora-2`. راجع [دليل توليد الفيديو](/guides/video-generation) لمعرفة مصفوفة النماذج الحالية والقدرات المدعومة.
</ParamField>

<ParamField body="prompt" type="string" required>
  وصف نصي للفيديو المطلوب توليده.
</ParamField>

<ParamField body="image_url" type="string">
  URL متاح للوصول العام لصورة البداية من أجل توليد image-to-video (I2V). لتحقيق أفضل توافق بين النماذج، يُفضّل استخدام `image_url`.
</ParamField>

<ParamField body="image" type="string">
  صورة مضمنة بصيغة data URL (على سبيل المثال، `data:image/jpeg;base64,...`). مدعومة من النماذج المتوافقة، لكن `image_url` يوفّر أوسع توافق عبر نماذج الفيديو.
</ParamField>

<ParamField body="duration" type="integer">
  مدة الفيديو بالثواني (تعتمد على النموذج).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  نسبة الأبعاد (مثلًا، `16:9`، `9:16`، `1:1`).
</ParamField>

<ParamField body="resolution" type="string">
  دقة الفيديو (مثلًا، `1080p`، `720p`).
</ParamField>

<ParamField body="output_audio" type="boolean">
  Model-dependent audio output toggle. Veo 3 family defaults to `true` when omitted. Other video models follow their governed default behavior. The camelCase alias `outputAudio` is accepted for compatibility.
</ParamField>

<ParamField body="fps" type="integer">
  عدد الإطارات في الثانية (1-120).
</ParamField>

<ParamField body="negative_prompt" type="string">
  ما الذي يجب تجنبه في توليد الفيديو.
</ParamField>

<ParamField body="seed" type="integer">
  seed عشوائي لتوليد قابل لإعادة الإنتاج.
</ParamField>

<ParamField body="cfg_scale" type="number">
  مقياس التوجيه بدون مصنّف (0-20).
</ParamField>

<ParamField body="motion_strength" type="number">
  شدة الحركة (0-1).
</ParamField>

<ParamField body="start_image" type="string">
  URL لصورة الإطار الابتدائي.
</ParamField>

<ParamField body="end_image" type="string">
  URL لصورة الإطار النهائي.
</ParamField>

<ParamField body="user" type="string">
  معرّف فريد للمستخدم النهائي.
</ParamField>

## الاستجابة

<ResponseField name="task_id" type="string">
  معرّف مهمة فريد لاستخدامه في polling.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling الموصى به لهذه المهمة. استخدم هذا المسار المطابق عند التحقق من الحالة.
</ResponseField>

<ResponseField name="status" type="string">
  الحالة الأولية: `pending`.
</ResponseField>

<ResponseField name="model" type="string">
  النموذج المستخدم.
</ResponseField>

```go Go
package main

import (
    "bytes"

    "fmt"

func main() {
    payload := map[string]interface{}{

        "prompt":   "A cat walking through a garden, cinematic lighting",
        "operation": "text-to-video",
        "duration": 4,
        "aspect_ratio": "16:9",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/videos/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Poll URL: %s\n", result["poll_url"])
    fmt.Printf("Task ID: %s\n", result["task_id"])
}
```

## من صورة إلى فيديو

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "hailuo-2.3-fast",
        "prompt": "The scene begins from the provided image and adds gentle natural motion.",
        "operation": "image-to-video",
        "image_url": "https://example.com/image.jpg",
        "duration": 6,
        "aspect_ratio": "16:9"
    }
)
```

## التحكم في الإطارات المفتاحية

استخدم `start_image` و `end_image` للتحكم في الإطارين الأول والأخير (مدعوم بواسطة Vidu Q2 Pro):

```python
response = requests.post(
    "https://api.lemondata.cc/v1/videos/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "viduq2-pro",
        "prompt": "Smooth transition from day to night",
        "operation": "start-end-to-video",
        "start_image": "https://example.com/day.jpg",
        "end_image": "https://example.com/night.jpg",
        "duration": 5,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
)
```
