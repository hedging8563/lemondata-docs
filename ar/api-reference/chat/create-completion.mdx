## جسم الطلب

<ParamField body="model" type="string" required>
  معرّف النموذج المراد استخدامه. راجع [Models](https://lemondata.cc/ar/models) للاطلاع على الخيارات المتاحة.


  When `content` is an array, LemonData supports structured multimodal blocks for compatible models:
  - text: `{ "type": "text", "text": "..." }`
  - image: `{ "type": "image_url", "image_url": { "url": "https://..." } }`
  - video: `{ "type": "video_url", "video_url": { "url": "https://..." } }`
  - audio: `{ "type": "audio_url", "audio_url": { "url": "https://..." } }`

  For multimodal production traffic, prefer public `https` URLs. LemonData will translate these media blocks into the provider-specific request shape required by the routed physical model.

</ParamField>

<ParamField body="messages" type="array" required>
  قائمة من الرسائل التي تكوّن المحادثة.

  يحتوي كل كائن رسالة على:
  - `role` (string): `system` أو `user` أو `assistant`
  - `content` (string | array): محتوى الرسالة
</ParamField>

<ParamField body="temperature" type="number" default="1">
  درجة حرارة أخذ العينات بين 0 و2. تجعل القيم الأعلى المخرجات أكثر عشوائية.
</ParamField>

<ParamField body="max_tokens" type="integer">
  الحد الأقصى لعدد tokens المطلوب إنشاؤها.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  إذا كانت القيمة true، فسيتم إرسال الفروقات الجزئية للرسائل كأحداث SSE.
</ParamField>

<ParamField body="stream_options" type="object">
  خيارات البث. اضبط `include_usage: true` لتلقي استخدام token ضمن أجزاء البث.
</ParamField>

<ParamField body="top_p" type="number" default="1">
  معلمة أخذ العينات Nucleus. نوصي بتعديل هذا أو temperature، وليس كليهما.
</ParamField>

<ParamField body="frequency_penalty" type="number" default="0">
  رقم بين -2.0 و2.0. تعاقب القيم الموجبة tokens المتكررة.
</ParamField>

<ParamField body="presence_penalty" type="number" default="0">
  رقم بين -2.0 و2.0. تعاقب القيم الموجبة tokens الموجودة بالفعل في النص.
</ParamField>

<ParamField body="stop" type="string | array">
  ما يصل إلى 4 تسلسلات سيتوقف عندها الـ API عن إنشاء tokens.
</ParamField>

<ParamField body="tools" type="array">
  قائمة بالأدوات التي قد يستدعيها النموذج (function calling).
</ParamField>

<ParamField body="tool_choice" type="string | object">
  يتحكم في كيفية استخدام النموذج للأدوات. الخيارات: `auto` أو `none` أو `required` أو كائن أداة محدد.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  ما إذا كان سيتم تمكين استدعاء الدوال بشكل متوازٍ. اضبطه على false لاستدعاء الدوال بشكل تسلسلي.
</ParamField>

<ParamField body="max_completion_tokens" type="integer">
  الحد الأقصى لـ tokens الخاصة بالـ completion. بديل لـ `max_tokens`، ومفيد لعائلات النماذج الأحدث الممكّنة للاستدلال.
</ParamField>

<ParamField body="reasoning_effort" type="string">
  مستوى الجهد الاستدلالي للنماذج الممكّنة للاستدلال. الخيارات: `low` أو `medium` أو `high`.
</ParamField>

<ParamField body="seed" type="integer">
  seed عشوائي لأخذ عينات حتمي.
</ParamField>

<ParamField body="n" type="integer" default="1">
  عدد الـ completions المطلوب إنشاؤها (1-128).
</ParamField>

<ParamField body="logprobs" type="boolean">
  ما إذا كان سيتم إرجاع الاحتمالات اللوغاريتمية.
</ParamField>

<ParamField body="top_logprobs" type="integer">
  عدد أعلى الاحتمالات اللوغاريتمية المطلوب إرجاعها (0-20). يتطلب `logprobs: true`.
</ParamField>

<ParamField body="top_k" type="integer">
  معلمة أخذ العينات Top-K (لنماذج Anthropic/Gemini).
</ParamField>

<ParamField body="response_format" type="object">
  مواصفات تنسيق الاستجابة. استخدم `{"type": "json_object"}` لوضع JSON، أو `{"type": "json_schema", "json_schema": {...}}` للمخرجات المنظمة.
</ParamField>

<ParamField body="logit_bias" type="object">
  عدّل احتمالية ظهور tokens محددة. اربط معرّفات token (كسلاسل نصية) بقيم انحياز من -100 إلى 100.
</ParamField>

<ParamField body="user" type="string">
  معرّف فريد يمثّل المستخدم النهائي لديك لمراقبة إساءة الاستخدام.
</ParamField>

<ParamField body="cache_control" type="object">
  خيارات التحكم في التخزين المؤقت الخاصة بـ LemonData.

  - `type` (string): استراتيجية التخزين المؤقت - `default` أو `no_cache` أو `no_store` أو `response_only` أو `semantic_only`
  - `max_age` (integer): مدة صلاحية التخزين المؤقت بالثواني (الحد الأقصى 86400)
</ParamField>

## الاستجابة

<ResponseField name="id" type="string">
  معرّف فريد للـ completion.
</ResponseField>

<ResponseField name="object" type="string">
  دائمًا `chat.completion`.
</ResponseField>

<ResponseField name="created" type="integer">
  طابع زمني Unix لوقت إنشاء الـ completion.
</ResponseField>

<ResponseField name="model" type="string">
  النموذج المستخدم للـ completion.
</ResponseField>

<ResponseField name="choices" type="array">
  قائمة بخيارات الـ completion.

  يحتوي كل خيار على:
  - `index` (integer): فهرس الخيار
  - `message` (object): الرسالة المُنشأة
  - `finish_reason` (string): سبب توقف النموذج (`stop` أو `length` أو `tool_calls`)
</ResponseField>

<ResponseField name="usage" type="object">
  إحصاءات استخدام token.

  - `prompt_tokens` (integer): tokens في الـ prompt
  - `completion_tokens` (integer): tokens في الـ completion
  - `total_tokens` (integer): إجمالي tokens المستخدمة
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/chat/completions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "temperature": 0.7,
    "max_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ],
    temperature=0.7,
    max_tokens=1000
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Hello!' }
  ],
  temperature: 0.7,
  max_tokens: 1000
});

console.log(response.choices[0].message.content);
```

```php PHP
<?php
$ch = curl_init('https://api.lemondata.cc/v1/chat/completions');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-4o',
        'messages' => [
            ['role' => 'system', 'content' => 'You are a helpful assistant.'],
            ['role' => 'user', 'content' => 'Hello!']
        ],
        'temperature' => 0.7,
        'max_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['choices'][0]['message']['content'];
```
</RequestExample>
