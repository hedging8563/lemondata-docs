## نظرة عامة

استخدم نقطة النهاية هذه لتحديث الاسم أو حد الاستخدام أو النماذج المسموح بها أو الانتهاء أو الحالة لمفتاح API موجود للمستخدم.

## ملاحظات

- الحذف النهائي غير مدعوم عمدًا في واجهة برمجة تطبيقات الإدارة v1.

## الطلب / الاستجابة

استخدم لوحة OpenAPI التفاعلية أعلاه للحصول على المخطط الدقيق.
