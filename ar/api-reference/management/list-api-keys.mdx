## نظرة عامة

يعيد مفاتيح API الخاصة بالمستخدم في المؤسسة المرتبطة برمز الإدارة الحالي.

## ملاحظات

- يتم استبعاد المفاتيح المُدارة من النظام مثل مفاتيح Playground وClaw.
- يتم إرجاع الحقول المالية في الاستجابة بكلٍّ من قيمة USD وقيمة العرض بالرنمينبي: `limit_amount` / `limit_amount_cny` و `used_amount` / `used_amount_cny`.
- يوضح `exchange_rate` سعر USD→CNY المستخدم لحقول العرض بالرنمينبي.

## الطلب / الاستجابة

استخدم لوحة OpenAPI التفاعلية أعلاه للحصول على المخطط الدقيق.
