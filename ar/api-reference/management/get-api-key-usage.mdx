## نظرة عامة

تعيد نقطة النهاية هذه تفاصيل استخدام على مستوى المفتاح مع عوامل تصفية حسب اسم النموذج المطلوب (`model`) ومزوّد النموذج العام و`scene` و`accessChannel`.

## ملاحظات

- تتضمن الاستجابة حقول الفوترة العامة فقط.
- يتم إخفاء التوجيه الداخلي وبيانات القناة الفعلية عمدًا.

## الطلب / الاستجابة

استخدم لوحة OpenAPI التفاعلية أعلاه للحصول على المخطط الدقيق.
