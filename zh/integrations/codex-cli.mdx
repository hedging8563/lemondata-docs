## 概述

OpenAI Codex 是一个开源命令行工具（CLI），可作为轻量级编码代理，能够在终端中读取、修改和运行代码。它基于 GPT 模型构建，并针对代码生成进行了优化。

## 系统要求

- **操作系统**：macOS、Linux（官方支持）、通过 WSL 使用 Windows
- **Node.js**：18+ 版本
- **npm**：10.x.x 或更高版本

## 安装

```bash
npm install -g @openai/codex
```

验证安装：

```bash
codex --version
```

## 配置

### 步骤 1：设置 API Key

**临时（当前会话）：**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**永久配置：**

添加到 `~/.bashrc`、`~/.zshrc` 或 `~/.bash_profile` 中：

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

然后重新加载：

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### 步骤 2：配置 config.toml

编辑 `~/.codex/config.toml`：

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
如果配置文件不存在，请先运行一次 `codex` 以生成该文件，然后再进行编辑。修改 `config.toml` 后，请完全重启 Codex，以便重新加载新的 provider 设置。
</Note>

<Warning>
Codex 正在弃用针对自定义 provider 的 `chat/completions` 支持。对于 LemonData，请保持 `wire_api = "responses"`，除非你明确要使用较旧的兼容路径。
</Warning>

## 基本用法

**启动交互模式：**

```bash
codex
```

**直接执行命令：**

```bash
codex "Fix the bug in main.py line 42"
```

**指定模型：**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## 推荐模型

| 模型 | 最佳用途 |
|-------|----------|
| `gpt-5.4` | 用于编码和推理的最佳默认选择 |
| `gpt-5-mini` | 更快、更便宜的编码工作流备用选择 |
| `claude-sonnet-4-6` | 代码审查、文档编写 |
| `deepseek-r1` | 算法设计、推理 |

## 交互命令

| 命令 | 说明 |
|---------|-------------|
| `/help` | 显示帮助 |
| `/exit` or `Ctrl+C` | 退出 |
| `/clear` | 清除对话 |
| `/config` | 查看配置 |
| `/model <name>` | 切换模型 |
| `/tokens` | 查看 token 使用情况 |

## 验证配置

```bash
# Check environment variable
echo $OPENAI_API_KEY

# Test API connection
codex "Hello, Codex!"

# View configuration
cat ~/.codex/config.toml
```

## 常见使用场景

**代码审查：**

```bash
git diff | codex "Review these code changes"
```

**生成提交信息：**

```bash
git diff --staged | codex "Generate a commit message for these changes"
```

**修复错误：**

```bash
codex "Fix the TypeScript errors in src/components/"
```

**解释代码：**

```bash
cat main.py | codex "Explain what this code does"
```

## 故障排查

<AccordionGroup>
  <Accordion title="连接错误">
    - 验证 config.toml 中的 `base_url` 是否严格为 `https://api.lemondata.cc/v1`
    - 检查网络连接
    - 确保没有代理干扰
  </Accordion>

  <Accordion title="身份验证失败">
    - 验证 `~/.codex/config.toml` 中存在 `env_key = "OPENAI_API_KEY"`
    - 验证已设置 `OPENAI_API_KEY` 环境变量
    - 检查 key 是否以 `sk-` 开头
    - 确保该 key 已在 LemonData 控制台中激活
  </Accordion>

  <Accordion title="找不到模型">
    - 检查模型名称是否完全匹配
    - 在 [lemondata.cc/en/models](https://lemondata.cc/zh/models) 验证模型是否可用
  </Accordion>
</AccordionGroup>
