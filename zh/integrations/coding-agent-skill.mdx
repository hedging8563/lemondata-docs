<Note>
这个技能会教你的 coding agent 只需通过描述你的需求，就能集成 LemonData 的 **300+ AI API**。它被打包为一个共享的 agent-first 技能，并适用于任何支持 skill 或 rules 文件的 coding agent。

该 API 是 **[Agent-First](/guides/agent-first-api)** —— 即使 agent 猜错了 model 名称，错误响应也会准确告诉它该如何修复。
</Note>

## 工作原理

1. **你描述你的需求** —— “我想在我的 Python 项目中使用 GPT-4”
2. **agent 调用 API** —— 它可能会猜测一个 model 名称或 endpoint
3. **如果出现任何问题** —— API 会返回结构化提示（`did_you_mean`, `suggestions`, `retry_after`）
4. **agent 自我纠正** —— 读取提示并使用正确参数重试
5. **你获得可运行的代码** —— 通常在第一次或第二次尝试时即可完成

## 安装

<Note>
请使用规范的非交互式安装命令：

```bash
npx skills add https://github.com/hedging8563/lemondata-skills --skill lemondata-api-integration -y
```

这会从 LemonData skills 仓库安装共享的 `lemondata-api-integration` 技能。

如果你的工具不支持安装器，请将仓库中的 `skills/lemondata-api-integration/` 文件夹复制到你工具的共享 skills 或 rules 目录中。
</Note>

### 验证安装

询问你的 coding agent：
```
What skills are available?
```

如果你看到了 `lemondata-api-integration`，则表示安装成功。

## 获取你的 API Key

<Steps>
  <Step title="访问 LemonData">
    前往 [lemondata.cc](https://lemondata.cc)
  </Step>
  <Step title="登录">
    创建账户或登录
  </Step>
  <Step title="获取 API Key">

  </Step>
  <Step title="复制 key">
    你的 key 以 `sk-...` 开头——请安全保存
  </Step>

<Tip>
你不需要提前配置 API Key。当你使用该技能时，agent 会向你请求 key，并将其包含在生成的代码中。
</Tip>

## 示例

### Chat Completion

**你说：**
```
I want to use GPT-4 in my Python project
```

**agent 生成：**
```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="gpt-5.4",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

如果 agent 猜错了 model 名称（例如 `gpt5`），API 会返回：
```json
{
  "error": {
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [{"id": "gpt-5.4"}, {"id": "gpt-5-mini"}],
    "hint": "Did you mean 'gpt-5.4'? Use GET https://api.lemondata.cc/v1/models to list all available models."
  }
}
```

agent 会读取 `did_you_mean`，修正 model 名称，并重新尝试——这一切都会自动完成。

## Agent-First 错误恢复

每个错误响应都包含任何 coding agent 都可以解析的结构化提示。详情请参阅[完整的 Agent-First API 参考](/guides/agent-first-api)。

| 错误 | API 返回内容 | agent 的处理方式 |
|-------|---------------------|---------------------|
| 错误的 model 名称 | `did_you_mean` + `suggestions` | 自动纠正并重试 |
| 余额不足 | `balance_usd` + 更便宜的 `suggestions` | 切换到可负担的 model |
| model 不可用 | `alternatives` + `retry_after` | 切换到可用的 model |
| 触发速率限制 | `retry_after`（精确秒数） | 等待后重试 |
| 上下文过长 | `suggestions` 包含更大的 model | 切换到更大上下文的 model |

### 原生 Endpoint 优化

当你使用 Claude 或 Gemini model 调用 `/v1/chat/completions` 时，API 会返回优化 header：

```
X-LemonData-Hint: This model supports native Anthropic format. Use POST /v1/messages for better performance.
X-LemonData-Native-Endpoint: /v1/messages
```

agent 会自动切换到原生 endpoint 以获得更好的性能（无需格式转换、支持 extended thinking、支持 prompt caching）。

### Model 发现

无需搜索文档：

```bash
# Machine-readable API overview
curl https://lemondata.cc/llms.txt

# Filter by capability
curl "https://api.lemondata.cc/v1/models?tag=coding" -H "Authorization: Bearer sk-KEY"
```

## FAQ

<AccordionGroup>
  <Accordion title="技能没有自动触发？">
    尝试在你的请求中提及 “LemonData” 或 “LemonData API”：
    ```
    Use LemonData to integrate GPT-4 in my project
    ```
  </Accordion>

  <Accordion title="API 如何帮助 agent 找到正确的 model？">
    LemonData 的 [Agent-First API](/guides/agent-first-api) 会返回结构化错误提示。如果 agent 猜错了 model 名称，错误中会包含带有正确名称的 `did_you_mean` 以及带有替代项的 `suggestions`。agent 会读取这些信息，并在下一次尝试时自动纠正。
  </Accordion>

  <Accordion title="支持哪些 coding agent？">
    任何支持共享 skill 或 rules 目录的 coding agent 都可以。当支持安装器时，`npx skills add` 会自动将共享的 `lemondata-api-integration` 技能放置到检测到的位置。
  </Accordion>

  <Accordion title="如何更新技能？">
    重新运行安装器：
    ```bash
    npx skills add https://github.com/hedging8563/lemondata-skills --skill lemondata-api-integration -y
    ```
  </Accordion>
</AccordionGroup>
