## 概述

大多数通用 AI 聊天应用都通过标准的 OpenAI-compatible 聊天路径连接到 LemonData。

在实际使用中，这意味着：
- 除非应用明确要求提供完整的 endpoint URL，否则使用 `https://api.lemondata.cc/v1` 作为 base URL
- 使用你的 LemonData API key 作为 OpenAI 风格的 API key
- 选择应用可在标准聊天工作流中使用的模型

<Note>
通用聊天应用通常是**面向 chat-completions**的，而不是 Codex Responses WebSocket 客户端。对于 Codex CLI/App、Cursor 或其他需要 Responses 特定行为的编码工具，请改用专门的集成指南。
</Note>

## 支持的应用

| Application | Platform | Notes |
|-------------|----------|-------|
| LobeChat | Web、Desktop、Self-hosted | 强大的自定义 provider 支持 |
| Cherry Studio | Windows、macOS、Linux | 良好的 OpenAI-compatible provider 流程 |
| Chatbox | Windows、macOS、Linux | 简单的 OpenAI-compatible 配置 |
| TypingMind | Web、Desktop | 使用自定义 endpoint 样式 |
| BotGem | iOS、macOS | 自定义 provider 配置 |
| OpenCat | iOS、macOS | OpenAI-compatible 自定义 endpoint 流程 |
| ChatWise | Windows、macOS | 标准自定义 provider 模式 |

## 默认连接值

| Field | Value |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

如果应用要求提供**完整的 endpoint URL**而不是 base URL，请使用：
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## 示例应用配置

<Tabs>
  <Tab title="LobeChat">
    **Self-hosted LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. 打开 **Settings** → **AI Service Provider**
    2. 选择 **OpenAI**
    3. 输入你的 LemonData API key
    4. 将自定义 endpoint 设置为 `https://api.lemondata.cc/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. 打开 **Settings** → **Model Provider**
    2. 添加一个 **OpenAI-compatible** provider
    3. 输入：
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. 添加你想使用的模型
  </Tab>

  <Tab title="Chatbox">
    1. 打开 **Settings** → **AI Model**
    2. 选择 **OpenAI API Compatible**
    3. 输入：
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` 或 `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. 打开 **Settings**
    2. 选择 **Custom Endpoint**
    3. 输入：
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. 配置你希望公开的模型
  </Tab>
</Tabs>

## 提示

<AccordionGroup>
  <Accordion title="在应用支持时优先使用 base URL">
    当你提供 `https://api.lemondata.cc/v1` 作为 base URL 而不是完整的 endpoint URL 时，大多数应用更容易配置，也更不容易出错。
  </Accordion>

  <Accordion title="先使用较小的模型">
    日常聊天可先从 `gpt-5-mini` 或 `gpt-4o` 开始，然后再将更重的推理任务切换到 `gpt-5.4` 或 `claude-opus-4-6`。
  </Accordion>

  <Accordion title="将编码工具分开配置">
    通用聊天应用和编码 agent 往往需要不同的 endpoint 行为。请将 Codex/Cursor 风格的工具保留在各自专用的集成页面中。
  </Accordion>
</AccordionGroup>

## 故障排查

<AccordionGroup>
  <Accordion title="连接错误">
    - 确认 base URL 完全等于 `https://api.lemondata.cc/v1`
    - 如果应用会自动追加路径，请移除末尾的斜杠
    - 如果应用需要完整的 endpoint URL，请使用 `https://api.lemondata.cc/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Unauthorized">
    - 再次检查你的 API key
    - 确认该 key 已在 LemonData dashboard 中激活
    - 确保没有多余的空格或换行
  </Accordion>

  <Accordion title="模型不可用">
    - 确认模型名称完全正确
    - 尝试使用广泛支持的默认模型，例如 `gpt-5-mini`、`gpt-4o` 或 `claude-sonnet-4-6`
    - 在 LemonData 文档或 dashboard 中检查当前可用性
  </Accordion>
</AccordionGroup>
