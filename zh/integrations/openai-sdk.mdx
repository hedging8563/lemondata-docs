## 概述

LemonData 可通过将客户端指向 `https://api.lemondata.cc/v1` 来配合官方 OpenAI SDK 使用。

对于新项目，优先使用 **Responses API**。仅当某个框架、插件或遗留代码路径仍然依赖 **Chat Completions** 时，才保留使用它。

<Note>
Python、JavaScript 和 Go 拥有官方 OpenAI SDK。PHP 可通过 OpenAI 兼容的社区客户端良好运行，但它不是官方 OpenAI SDK。
</Note>

<Note>
**类型**: 原生 SDK

**主要路径**: OpenAI-compatible / OpenAI Responses

**支持级别**: 核心路径支持
</Note>

这是 LemonData 默认的 OpenAI-compatible SDK 路径，但这并不意味着每个 Responses-native-only 字段都会在所有模型和路由到的渠道上表现完全一致。

## 配置客户端

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## 推荐：Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

<Note>
部分 hosted tools、`include`、`service_tier`、`truncation_strategy` 等 Responses-native-only 字段，依赖所选模型和路由到的渠道具备原生 `/v1/responses` passthrough 支持。如果这类支持不可用，LemonData 会明确返回 `400` 或 `503`，而不是假装该字段已经生效。
</Note>

## 使用 Responses 进行流式输出

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Tools / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## 使用 Responses 处理视觉输入

```python
response = client.responses.create(
    model="gpt-4o",
    input=[{
        "role": "user",
        "content": [
            {"type": "input_text", "text": "What's in this image?"},
            {"type": "input_image", "image_url": "https://example.com/image.jpg"}
        ]
    }]
)

print(response.output_text)
```

## Chat Completions 兼容性

如果你的框架或插件仍然依赖 Chat Completions，LemonData 也支持标准的 OpenAI 兼容路径：

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
仅为兼容性使用 Chat Completions。对于新的集成，优先使用 `client.responses.create(...)`。
</Warning>

## 故障排查

<AccordionGroup>
  <Accordion title="连接错误">
    - 确认 base URL 完全等于 `https://api.lemondata.cc/v1`
    - 检查是否存在代理干扰或自定义 HTTP 客户端覆盖
    - 在调试 provider 行为之前，确保你的 SDK 版本为最新
  </Accordion>

  <Accordion title="身份验证失败">
    - 检查你的 API key 是否以 `sk-` 开头
    - 确认该 key 已在 LemonData dashboard 中激活
    - 确认 SDK 正在发送 `Authorization: Bearer ...`
  </Accordion>

  <Accordion title="错误的 API 路径">
    - `responses.create(...)` 会将请求发送到 `/v1/responses`
    - `chat.completions.create(...)` 会将请求发送到 `/v1/chat/completions`
    - 如果你的应用当前仅支持 Chat Completions，请继续使用该兼容路径
  </Accordion>
</AccordionGroup>
