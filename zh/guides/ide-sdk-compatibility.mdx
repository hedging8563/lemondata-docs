## 概述

LemonData API 的设计目标是与所有主流 AI 开发工具实现**即插即用兼容**。本指南记录了受支持的参数和已验证的集成。

<Note>
  所有参数都会被验证，但会透传给上游提供商。特定模型不支持的参数会被静默忽略，以确保最大兼容性。
</Note>

## 支持的 API 格式

| Endpoint | 格式 | 用例 |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 通用兼容性 |
| `/v1/responses` | OpenAI Responses | 有状态对话 |
| `/v1/messages` | Anthropic Messages | Claude 原生功能 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini 原生功能 |

## Chat Completions 参数

### 核心参数

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型标识符（必填） |
| `messages` | array | 对话消息（必填） |
| `max_tokens` | integer | 最大输出 token 数 |
| `temperature` | number | 采样温度（0-2） |
| `top_p` | number | 核采样（0-1） |
| `stream` | boolean | 启用流式传输 |

### 工具调用

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tool Choice 选项

| 格式 | 示例 | 说明 |
|--------|---------|-------------|
| 字符串 | `"auto"`、`"none"`、`"required"` | 简单选择 |
| OpenAI 对象 | `{ "type": "function", "function": { "name": "fn" } }` | 强制指定特定函数 |
| Anthropic 对象 | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic 原生格式 |

### 高级参数

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | 用于 token 计数的 `{ include_usage: true }` |
| `reasoning_effort` | string | 用于支持推理的 GPT-5 模型的 `"low"`、`"medium"`、`"high"` |
| `service_tier` | string | `"auto"` 或 `"default"` |
| `seed` | integer | 确定性输出 |
| `logprobs` | boolean | 返回对数概率 |
| `top_logprobs` | integer | top logprobs 数量（0-20） |
| `logit_bias` | object | token 偏置映射（-100 到 100） |
| `frequency_penalty` | number | 重复惩罚（-2 到 2） |
| `presence_penalty` | number | 主题惩罚（-2 到 2） |
| `stop` | string/array | 停止序列 |
| `n` | integer | completion 数量（1-128） |
| `user` | string | 用于跟踪的用户标识符 |

### OpenAI 高级功能

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | 用于多模态的 `["text", "audio"]` |
| `audio` | object | 音频输出配置（voice、format） |
| `prediction` | object | 用于更快 completion 的预测输出 |
| `metadata` | object | 用于跟踪的键值对 |
| `store` | boolean | 存储以供后续检索 |

### 提供商特定选项

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Responses API 参数

### 核心参数

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型标识符 |
| `input` | string/array | 输入内容 |
| `instructions` | string | 系统指令 |
| `max_output_tokens` | integer | 最大输出 token 数 |
| `previous_response_id` | string | 继续对话 |

### 高级参数

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` 或 `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | 用于推理模型 |
| `service_tier` | string | 优先级层级 |

### 工具格式

同时支持 OpenAI 和 Anthropic 工具格式：

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## 流式传输

所有 endpoint 都支持 Server-Sent Events (SSE) 流式传输：

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## 错误处理

LemonData 返回与 OpenAI 兼容的错误响应：

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

详见 [错误处理指南](/guides/error-handling)。

## 最佳实践

<AccordionGroup>
  <Accordion title="对未知参数使用透传">
    所有 schema 都使用 `.passthrough()`——未知参数会被转发到上游提供商。
  </Accordion>

  <Accordion title="优先使用 stream_options 以获得准确计费">
    启用 `stream_options.include_usage` 以在流式响应中获得准确的 token 计数。
  </Accordion>

  <Accordion title="使用合适的 tool_choice 格式">
    请匹配你的 SDK 所期望的格式。LemonData 同时接受 OpenAI 和 Anthropic 格式。
  </Accordion>
</AccordionGroup>
