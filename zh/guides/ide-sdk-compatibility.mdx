## 概述

LemonData 暴露了多种 API 格式，让常见 coding 工具、SDK 和框架可以用较少胶水代码接入。

本页刻意比 marketing matrix 更收敛：

- **支持**：表示我们文档化了一条明确配置路径，且 LemonData 暴露了这条路径所需的协议形状。
- **强原生路径**：表示仓库里还存在该协议族的直接 adapter / request-format 证据。
- **Best-effort**：表示这条集成路径可能可用，但上游客户端并未把这种自定义网关工作流视为稳定契约。

<Note>
  不支持的字段并不是统一处理的。在兼容路由上，有些字段会被忽略或归一化；在原生 Responses 路径上，如果所选模型或路由到的渠道不支持所需 passthrough，可能会返回明确的 `400` 或 `503` 错误。
</Note>

## 支持的 API 格式

| Endpoint | 格式 | 用例 |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 通用兼容性 |
| `/v1/responses` | OpenAI Responses | 有状态对话 |
| `/v1/messages` | Anthropic Messages | Claude 原生功能 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini 原生功能 |

## IDE 与 CLI 兼容性

### 已文档化的工具路径

| 工具 | 支持级别 | 格式 | 说明 |
|------|----------|------|------|
| **Cursor** | 支持，但有边界 | OpenAI-compatible | 适用于 BYOK 标准 chat/editor 流，不等于可以替代 Cursor 托管功能（如 Tab Completion） |
| **Claude Code CLI** | 强原生路径 | Anthropic | 原生 `/v1/messages` 路径，对 thinking 和 `tool_choice` 有 adapter 证据 |
| **Codex CLI** | 支持，但依赖模型 / 渠道 | OpenAI Responses | 最适合配置到 `/v1/responses`；部分 Responses-native 字段依赖所选模型与渠道的 native passthrough 支持 |
| **Gemini CLI** | 实验性 / best-effort | Gemini | 自定义 LemonData base URL 工作流不是稳定 upstream contract |
| **OpenCode** | 支持 | OpenAI-compatible | 默认使用 OpenAI-compatible provider；只有在你明确需要 Responses provider 路径时才切换 |

<Note>
  其他 OpenAI-compatible 编辑器和 agent 工具通常也能沿用同样的 base URL 模式，但当前仓库并没有为 Windsurf、Aider、Continue.dev、Cline/Roo Code、GitHub Copilot 等客户端维护专门的回归覆盖。
</Note>

## SDK 兼容性

### 已文档化的 SDK / 框架路径

| SDK / 框架 | 语言 | 支持级别 | 说明 |
|------------|------|----------|------|
| **OpenAI SDK** | Python/JS/Go | 核心路径支持 | 已文档化 Chat Completions、Embeddings 与常见 Responses 工作流；部分仅限 Responses-native 的字段依赖 model/channel passthrough 支持 |
| **Anthropic SDK** | Python/JS | 强原生路径 | 原生 Messages 路径，对 tools、thinking 和 prompt caching 有直接证据 |
| **Vercel AI SDK** | TypeScript | 推荐集成模式 | 优先使用 `@ai-sdk/openai-compatible`；仅在明确需要 Responses-native 行为时使用 `@ai-sdk/openai` |
| **LangChain** | Python/JS | 支持标准 surface | 预期范围是 `ChatOpenAI` 与 `OpenAIEmbeddings`；vendor-native extras 不在此页承诺范围 |
| **LlamaIndex** | Python | 通过 `OpenAILike` 支持 | 对 LemonData 这类第三方 gateway，应使用 `OpenAILike`，而不是内置 OpenAI 类 |
| **Dify** | - | 支持，但有边界 | 预期路径是 OpenAI provider 与 chat-completions 导向流程；不适合承诺 Codex 专用 Responses / WebSocket 行为 |

## Chat Completions 参数

### 核心参数

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型标识符（必填） |
| `messages` | array | 对话消息（必填） |
| `max_tokens` | integer | 最大输出 token 数 |
| `temperature` | number | 采样温度（0-2） |
| `top_p` | number | 核采样（0-1） |
| `stream` | boolean | 启用流式传输 |

### 工具调用

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tool Choice 选项

| 格式 | 示例 | 说明 |
|--------|---------|-------------|
| 字符串 | `"auto"`、`"none"`、`"required"` | 简单选择 |
| OpenAI 对象 | `{ "type": "function", "function": { "name": "fn" } }` | 强制指定特定函数 |
| Anthropic 对象 | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic 原生格式 |

### 高级参数

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | 用于 token 计数的 `{ include_usage: true }` |
| `reasoning_effort` | string | 用于支持推理的 GPT-5 模型的 `"low"`、`"medium"`、`"high"` |
| `service_tier` | string | `"auto"` 或 `"default"` |
| `seed` | integer | 确定性输出 |
| `logprobs` | boolean | 返回对数概率 |
| `top_logprobs` | integer | top logprobs 数量（0-20） |
| `logit_bias` | object | token 偏置映射（-100 到 100） |
| `frequency_penalty` | number | 重复惩罚（-2 到 2） |
| `presence_penalty` | number | 主题惩罚（-2 到 2） |
| `stop` | string/array | 停止序列 |
| `n` | integer | completion 数量（1-128） |
| `user` | string | 用于跟踪的用户标识符 |

### OpenAI 高级功能

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | 用于多模态的 `["text", "audio"]` |
| `audio` | object | 音频输出配置（voice、format） |
| `prediction` | object | 用于更快 completion 的预测输出 |
| `metadata` | object | 用于跟踪的键值对 |
| `store` | boolean | 存储以供后续检索 |

### 提供商特定选项

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Responses API 参数

### 核心参数

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | 模型标识符 |
| `input` | string/array | 输入内容 |
| `instructions` | string | 系统指令 |
| `max_output_tokens` | integer | 最大输出 token 数 |
| `previous_response_id` | string | 继续对话 |

### 高级参数

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` 或 `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | 用于推理模型 |
| `service_tier` | string | 优先级层级 |

### 工具格式

同时支持 OpenAI 和 Anthropic 工具格式：

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## 流式传输

所有 endpoint 都支持 Server-Sent Events (SSE) 流式传输：

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## 错误处理

LemonData 返回与 OpenAI 兼容的错误响应：

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

详见 [错误处理指南](/guides/error-handling)。

## 最佳实践

<AccordionGroup>
  <Accordion title="对未知参数使用透传">
    所有 schema 都使用 `.passthrough()`——未知参数会被转发到上游提供商。
  </Accordion>

  <Accordion title="优先使用 stream_options 以获得准确计费">
    启用 `stream_options.include_usage` 以在流式响应中获得准确的 token 计数。
  </Accordion>

  <Accordion title="使用合适的 tool_choice 格式">
    请匹配你的 SDK 所期望的格式。LemonData 同时接受 OpenAI 和 Anthropic 格式。
  </Accordion>
</AccordionGroup>
