## 概述

LemonData 的 Agent-First API 通过结构化提示增强错误响应，AI agent 可以立即解析并采取行动——无需网页搜索、无需查阅文档、无需猜测。

每个错误响应都在标准 `error` 对象中包含可选字段，例如 `did_you_mean`、`suggestions`、`hint`、`retryable` 和 `retry_after`。这些字段是向后兼容的——不使用它们的客户端不会看到任何差异。

## 错误提示字段

所有提示字段都是 `error` 对象中的可选扩展：

| Field | Type | Description |
|-------|------|-------------|
| `did_you_mean` | `string` | 最接近匹配的模型名称 |
| `suggestions` | `array` | 带有元数据的推荐模型 |
| `alternatives` | `array` | 当前可用的替代模型 |
| `hint` | `string` | 人类/agent 可读的下一步指导 |
| `retryable` | `boolean` | 重试相同请求是否可能成功 |
| `retry_after` | `number` | 重试前需要等待的秒数 |
| `balance_usd` | `number` | 当前账户余额（USD） |
| `estimated_cost_usd` | `number` | 失败请求的预估成本 |

## 错误代码示例

### model_not_found (400)

当模型名称与任何活跃模型都不匹配时：

```json
{
  "error": {
    "message": "Model 'gpt5' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [
      {"id": "gpt-5.4"},
      {"id": "gpt-5-mini"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Did you mean 'gpt-5.4'? Use GET /v1/models to list all available models."
  }
}
```

`did_you_mean` 的解析使用以下方式：
1. 静态别名映射（来自生产错误数据）
2. 归一化字符串匹配（去除连字符、忽略大小写）
3. 编辑距离匹配（阈值 ≤ 3）

### insufficient_balance (402)

当账户余额低于预估成本时：

```json
{
  "error": {
    "message": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200.",
    "type": "insufficient_balance",
    "code": "insufficient_balance",
    "balance_usd": 0.12,
    "estimated_cost_usd": 0.35,
    "suggestions": [
      {"id": "gpt-5-mini"},
      {"id": "deepseek-v3-2"}
    ],
    "hint": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200. Try a cheaper model, or top up at https://lemondata.cc/dashboard/billing."
  }
}
```

`suggestions` 包含成本低于预估成本、agent 可以切换到的模型。

### all_channels_failed (503)

当某个模型的所有上游通道都不可用时：

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-6", "status": "available", "tags": []},
      {"id": "gpt-5-mini", "status": "available", "tags": []}
    ],
    "hint": "All channels for 'claude-opus-4-6' are temporarily unavailable. Retry in 30s or try an alternative model."
  }
}
```

<Note>
当原因为 `no_channels`（此模型未配置任何通道）时，`retryable` 为 `false`。只有在断路器触发或配额耗尽等暂时性故障情况下，它才为 `true`。
</Note>

### rate_limit_exceeded (429)

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

`retry_after` 的值是根据实际限流窗口的重置时间计算得出的。

<Note>
兼容 OpenAI 的 endpoint 使用 LemonData 稳定的公开错误类型，例如 `rate_limit_exceeded`、`upstream_error` 和 `all_channels_failed`。兼容 Anthropic 和兼容 Gemini 的 endpoint 使用它们各自原生的响应格式。
</Note>

### context_length_exceeded (400)

当输入超过模型的上下文窗口时（上游错误，并附加提示增强）：

```json
{
  "error": {
    "message": "This model's maximum context length is 128000 tokens...",
    "type": "invalid_request_error",
    "code": "context_length_exceeded",
    "retryable": false,
    "suggestions": [
      {"id": "gemini-2.5-pro"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Reduce your input or switch to a model with a larger context window."
  }
}
```

## 原生 Endpoint 响应头

当你使用带有原生 endpoint 的模型（Anthropic 或 Gemini）调用 `/v1/chat/completions` 时，**成功响应**会包含优化响应头：

```
X-LemonData-Hint: This model supports native Anthropic format. Use POST /v1/messages for better performance (no format conversion).
X-LemonData-Native-Endpoint: /v1/messages
```

| Model Provider | Suggested Endpoint | Benefit |
|---------------|-------------------|---------|
| Anthropic (Claude) | `/v1/messages` | 无需格式转换，支持 extended thinking、prompt caching |
| Google (Gemini) | `/v1beta/gemini` | 无需格式转换，支持 grounding、安全设置 |
| OpenAI | — | Chat completions 已经是原生格式 |

这些响应头会同时出现在流式和非流式响应中。

## /v1/models 增强功能

每个模型对象中的 `lemondata` 扩展新增了三个字段：

```json
{
  "id": "gpt-5.4",
  "lemondata": {
    "category": "chat",
    "pricing_unit": "per_token",
    "cache_pricing": {
      "cache_read_per_1m": "1.25",
      "cache_write_per_1m": "2.50",
      "platform_cache_discount": 0.9
    }
  }
}
```

| Field | Values | Description |
|-------|--------|-------------|
| `category` | `chat`, `image`, `video`, `audio`, `tts`, `stt`, `3d`, `embedding`, `rerank` | 模型类型 |
| `pricing_unit` | `per_token`, `per_image`, `per_second`, `per_request` | 模型的计费方式 |
| `cache_pricing` | object or `null` | 上游 prompt cache 价格 + 平台语义缓存折扣 |

### 按类别筛选

```bash
GET /v1/models?category=chat          # Chat 模型
GET /v1/models?category=image         # 图像生成模型
GET /v1/models?tag=coding&category=chat  # 为编码优化的 Chat 模型
```

## llms.txt

可机器读取的 API 概览可通过以下地址获取：

```
GET https://api.lemondata.cc/llms.txt
```

其内容包括：
- 首次调用模板及一个可运行示例
- 常见模型名称（根据使用数据动态生成）
- 全部 12 个 API endpoint
- 用于模型发现的筛选参数
- 错误处理指南

在第一次 API 调用之前先读取 `llms.txt` 的 AI agent，通常可以在首次尝试时成功。

## 在 Agent 代码中的用法

### Python (OpenAI SDK)

```python
from openai import OpenAI, BadRequestError

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://api.lemondata.cc/v1"
)

def smart_chat(messages, model="gpt-4o"):
    try:
        return client.chat.completions.create(
            model=model, messages=messages
        )
    except BadRequestError as e:
        error = e.body.get("error", {}) if isinstance(e.body, dict) else {}
        # Use did_you_mean for auto-correction
        if error.get("code") == "model_not_found" and error.get("did_you_mean"):
            return client.chat.completions.create(
                model=error["did_you_mean"], messages=messages
            )
        raise
```

### JavaScript (OpenAI SDK)

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function smartChat(messages, model = 'gpt-4o') {
  try {
    return await client.chat.completions.create({ model, messages });
  } catch (error) {
    const err = error?.error;
    if (err?.code === 'model_not_found' && err?.did_you_mean) {
      return client.chat.completions.create({
        model: err.did_you_mean, messages
      });
    }
    throw error;
  }
}
```
