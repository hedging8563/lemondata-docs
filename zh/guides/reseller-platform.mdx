## 概览

代理控制台是 partner 组织的白标运营面。运营方在这里管理本地下游客户记录、在 partner 组织下创建 API Key、设置模型上架倍率，并完成用量与账务对账。

下游客户是代理系统里的本地记录，不是主站用户账号，也不登录主站 Dashboard。下游客户只使用为其创建的 API Key。

## 运营模型

| 模块 | 归属系统 | 说明 |
|------|--------|------|
| Partner 结算余额 | 主站组织余额 | API Key 消耗和额度上限使用 partner 组织余额。 |
| 客户运营账务余额 | 代理控制台 | 这是代理方自己的内部账务余额，用于运营和客户对账，不会生成上游授信。 |
| API Key | Management API | Key 创建在 partner 组织下，并绑定到本地下游客户记录。 |
| 模型上架 | 代理模型中心 | 上架状态会同步到 active Key 的模型白名单。 |
| 零售价 | 模型官方价 × 售价倍率 | 公开模型页向下游客户展示最终 USD 售价。 |
| 结算条款 | Partner 结算倍率 | 代理专用令牌只能读取结算倍率，不读取上游成本或平台利润。 |

## 推荐流程

1. 在代理控制台创建或更新本地下游客户。
2. 如果使用预付费内部账务，调整客户运营账务余额。
3. 为客户创建 API Key，并设置正数 USD 结算消耗上限。
4. 在模型中心设置模型上架和售价倍率。`1` 表示模型厂商官方价，`0.7` 表示官方价的 70%。
5. 通过用量、账单和毛利报表做对账。
6. 需要停用客户时，active Key 会随客户一起停用；恢复客户不会自动恢复 Key，需要运营方手动处理。

## Management API 边界

管理令牌只应在你的服务端或控制台后端使用：

```bash
Authorization: Bearer mt-your-management-token
```

普通 Management API 支持组织余额、Key 创建、Key 更新、Key 级用量和账单。代理结算倍率使用单独的私有能力：

```text
reseller_settlement:read
```

Dashboard 普通管理令牌不会自动获得这个能力。

## 定价边界

代理控制台和公开模型页不应展示上游执行成本、平台利润、总利润、旧分润池或旧分润字段。

请统一使用这些口径：

| 术语 | 含义 |
|------|------|
| 官方价 | 模型厂商官方价格，也是代理零售定价基准。 |
| 售价倍率 | 代理给下游客户的售价倍率，范围 `0` 到 `1`。 |
| 结算倍率 | partner 私有结算倍率。 |
| 毛利倍率 | `售价倍率 - 结算倍率`；如果低于结算成本，可以为负。 |
| 结算消耗上限 | 作用在 partner 组织 Key 上的 USD 消耗上限。 |
| 运营账务余额 | 代理方自有的客户账务余额，用于运营和对账。 |

## 不支持的内容

- 没有二级代理层级和二级代理分润。
- 没有独立于 partner 组织余额的代理钱包。
- 不创建下游主站用户账号。
- Management API 不提供平台利润或上游成本接口。
- 私有代理结算条款不进入公开 OpenAPI。
