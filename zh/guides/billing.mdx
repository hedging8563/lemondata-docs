## 概述

LemonData 使用**按量付费定价**。您只需为实际使用的部分付费，无需订阅或最低消费承诺。

## 计费方式

1. 向您的账户**充值 credits**
2. **使用 API** - 费用按每次请求扣除
3. 在您的仪表盘中**监控使用情况**
4. 当余额较低时**充值**

## 定价模型

### 按请求定价

图像、视频和音频模型按每次请求计费：

|-------|-------------------|
| DALL-E 3 (1024x1024) | $0.04 |
| Midjourney | $0.05 |
| Sora Video (5s) | $0.20 |
| Whisper (per minute) | $0.006 |
| TTS-1 | $0.015 |

### 异步任务计费（视频/音乐/3D）

<Warning>
  **重要**：视频、音乐和 3D 生成任务是**在提交时计费**，而不是在完成后计费。
</Warning>

对于异步生成任务（视频、音乐、3D 模型）：

1. 当您提交任务时，**会立即计费**
2. 请优先跟随返回的 `poll_url` 轮询状态，并将 `task_id` 视为异步任务身份
3. 如果任务失败，**不会自动退款**

这是因为上游提供商会在任务提交时向我们收费，而不论最终结果如何。如果您遇到任务失败，请联系 support@lemondata.cc 获取帮助。

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

poll_url = response.json()["poll_url"]
task_id = response.json()["task_id"]
# 轮询 poll_url 获取状态...
```

## Token 计数

Token 是文本处理的基本单位：

- ~4 个字符 = 1 个 token（英文）
- ~1-2 个字符 = 1 个 token（中文）
- 1 张图像 = 取决于尺寸和细节

### 估算 Token 数量

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## 使用情况跟踪

### 仪表盘

在 [Dashboard](https://lemondata.cc/dashboard) 中监控您的使用情况：

## 低余额提醒

当您的余额下降时配置提醒：

1. 前往 **Dashboard → Settings → Notifications**
2. 设置您的阈值金额
3. 接收电子邮件通知

## 充值 Credits

### 支付方式

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### 步骤

1. 登录 [Dashboard](https://lemondata.cc/dashboard)
2. 点击 **Add Credits**
3. 选择金额和支付方式
4. 完成支付

支付确认后，credits 会立即添加到账户中。

## API Key 限额

您可以为单独的 API key 设置支出限额：

1. 前往 **Dashboard → API Keys**
2. 点击某个 key 进行编辑
3. 设置 **Usage Limit**

当达到限额时，使用该 key 的请求将返回 `402 Payment Required`。

## 发票

对于企业账户，可获取发票：

1. 前往 **Dashboard → Billing**
2. 查看交易历史
3. 以 PDF 格式下载发票
