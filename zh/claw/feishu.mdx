将飞书 (Feishu) 或 Lark 连接到您的 LemonClaw 实例。本指南适用于托管的 Claw 实例和私有化部署的 LemonClaw，并使用 WebSocket 模式，因此不需要公网回调 URL。

## 前提条件

- 拥有开发者权限的 [飞书](https://www.feishu.cn/) 或 [Lark](https://www.larksuite.com/) 账号
- 一个 LemonClaw 实例：
  - 托管版：[创建一个 Claw 实例](https://lemondata.cc/dashboard/claw)
  - 私有化部署：[安装 LemonClaw](/claw/self-hosted)

## 设置指南

<Steps>
  <Step title="创建飞书应用">
    1. 前往 [飞书开放平台](https://open.feishu.cn/app) (或 [Lark Developer](https://open.larksuite.com/app))
    2. 点击 **创建企业自建应用**
    3. 输入应用名称和描述
    4. 点击 **创建**
  </Step>
  <Step title="添加机器人能力">
    1. 在应用设置中，前往 **添加应用能力** → **机器人**
    2. 启用机器人能力
    3. 这允许您的应用接收和发送消息
  </Step>
  <Step title="获取凭据">
    1. 前往 **凭据与基础信息**
    2. 复制 **App ID** (以 `cli_` 开头)
    3. 复制 **App Secret**
  </Step>
  <Step title="配置事件订阅">
    1. 前往 **事件订阅**
    2. 选择 **WebSocket** 模式 (推荐 — 无需公网 URL)
    3. 如果系统提示，请设置 **Encrypt Key** 和 **Verification Token**

    <Tip>
    当您在 LemonClaw WebUI 中配置飞书时，系统会为您 **自动生成** Encrypt Key 和 Verification Token。请将这些值复制到飞书开发者控制台中。
    </Tip>
  </Step>
  <Step title="添加事件权限">
    1. 在事件订阅下，添加以下事件：
       - `im.message.receive_v1` — 接收消息
    2. 前往 **权限管理** 并添加：
       - `im:message` — 发送和接收消息
       - `im:message.group_at_msg` — 接收群组 @ 消息
    3. 点击 **保存**
  </Step>
  <Step title="发布应用">
    1. 前往 **应用发布** → **版本管理与发布**
    2. 创建一个新版本
    3. 提交审核 (对于企业自建应用，这通常是即时的)
    4. 审核通过后，应用即处于启用状态
  </Step>
  <Step title="打开 LemonClaw WebUI">
    1. 如果您使用的是托管版 Claw，请前往您的 [Claw Dashboard](https://lemondata.cc/dashboard/claw) 并点击 **Open WebUI**
    2. 如果您是私有化部署 LemonClaw，请打开您自己的 WebUI (例如 `http://your-ip:18789`) 并使用您的 token 登录
    3. 在 WebUI 中，导航至 **Settings** → **IM Integrations**
    4. 展开 **Feishu** 部分
    5. 粘贴您的 **App ID** 和 **App Secret**
    6. 将自动生成的 **Encrypt Key** 和 **Verification Token** 复制回飞书开发者控制台
    7. 点击 **Save**
  </Step>
  <Step title="开始聊天">
    1. 在飞书中，通过名称搜索您的机器人
    2. 向它发送一条消息
    3. 第一个用户将 **自动配对** 为所有者 — 无需代码！
    4. 开始与 AI 聊天！
  </Step>
</Steps>

## 群组设置

在 LemonClaw WebUI 的 **IM Integrations** 设置中配置群聊行为：

| 设置 | 选项 | 描述 |
|---------|---------|-------------|
| **Group Policy** | 开放 (默认) / 白名单 / 已禁用 | 控制谁可以在群组中触发机器人 |
| **Require @mention** | 开启 / 关闭 | 机器人仅在被 @ 时响应 |
| **Group IDs** | 会话 ID 列表 | 限制在特定群组 (留空 = 所有群组) |
| **Group Allowed Users** | Open ID 列表 | 仅这些用户可以触发机器人 (白名单模式) |

## 故障排除

<AccordionGroup>
  <Accordion title="机器人收不到消息">
    - 确认应用已发布并审核通过
    - 检查是否已订阅 `im.message.receive_v1` 事件
    - 确保选择了 WebSocket 模式 (而非 HTTP)
    - 验证飞书控制台与 LemonClaw 配置中的 Encrypt Key 和 Verification Token 是否匹配
  </Accordion>
  <Accordion title="'app_ticket' 错误">
    - 这通常意味着 App ID 或 App Secret 不正确
    - 请仔细检查仪表板中的凭据
  </Accordion>
</AccordionGroup>
