使用官方的 QQ 开放平台机器人 API 将 QQ（中国最流行的即时通讯应用）连接到您的 LemonClaw 实例。本指南适用于托管的 Claw 实例和私有部署的 LemonClaw。

## 先决条件

- 一个 [QQ](https://im.qq.com/) 账号
- 访问 [QQ 开放平台](https://q.qq.com/)（开发者账号）
- 一个 LemonClaw 实例：
  - 托管版：[创建一个 Claw 实例](https://lemondata.cc/dashboard/claw)
  - 私有部署：[安装 LemonClaw](/claw/self-hosted)

## 设置指南

<Steps>
  <Step title="创建 QQ 机器人应用">
    1. 前往 [QQ 开放平台](https://q.qq.com/)
    2. 登录并前往 **机器人** 板块
    3. 点击 **创建机器人**
    4. 填写机器人信息（名称、头像、描述）
    5. 提交审核
  </Step>
  <Step title="获取凭据">
    1. 审核通过后，前往机器人的 **开发设置**
    2. 复制 **AppID**
    3. 复制 **AppSecret** (Client Secret)
  </Step>
  <Step title="配置沙箱（用于测试）">
    1. 在机器人设置中，前往 **沙箱配置**
    2. 将您的 QQ 号添加到沙箱白名单
    3. 这允许您在正式上线前进行测试

    <Tip>
    在提交生产审核之前，先使用沙箱模式验证一切功能正常。
    </Tip>
  </Step>
  <Step title="打开 LemonClaw WebUI">
    1. 如果您使用的是托管版 Claw，请前往您的 [Claw Dashboard](https://lemondata.cc/dashboard/claw) 并点击 **Open WebUI**
    2. 如果您是私有部署 LemonClaw，请打开您自己的 WebUI（例如 `http://your-ip:18789`）并使用您的 token 登录
    3. 在 WebUI 中，导航至 **Settings** → **IM Integrations**
    4. 展开 **QQ** 板块
    5. 粘贴您的 **AppID** 和 **AppSecret**
    6. 点击 **Save**
  </Step>
  <Step title="开始聊天">
    1. 在 QQ 中搜索您的机器人或将其添加为好友
    2. 发送一条消息
    3. 第一个用户将**自动配对**为所有者 —— 无需代码！
    4. 开始与 AI 聊天！
  </Step>
</Steps>

## 支持的消息类型

| 类型 | 描述 |
|------|-------------|
| **C2C (私聊)** | 直接向机器人发送消息 |
| **群聊 @提及** | 在 QQ 群中 @机器人 |
| **频道** | QQ 频道中的消息 |

## 故障排除

<AccordionGroup>
  <Accordion title="机器人没有响应">
    - 验证 AppID 和 AppSecret 是否正确
    - 检查您的 QQ 号是否在沙箱白名单中（如果正在测试）
    - 确保机器人应用已通过审核
  </Accordion>
  <Accordion title="'invalid appid' 错误">
    - 仔细检查 AppID —— 它应该是一个数字字符串
    - 确保您使用的是正确的 AppSecret（而不是 token）
  </Accordion>
</AccordionGroup>
