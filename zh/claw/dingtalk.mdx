使用 Stream 模式将钉钉 (DingTalk) 连接到您的 LemonClaw 实例 —— 这是一种基于 WebSocket 的连接方式，不需要公网 URL。本指南适用于托管的 Claw 实例和自托管的 LemonClaw 部署。

## 前提条件

- 拥有企业管理员权限的 [DingTalk](https://www.dingtalk.com/) 账号
- 一个 LemonClaw 实例：
  - 托管版：[创建一个 Claw 实例](https://lemondata.cc/dashboard/claw)
  - 自托管版：[安装 LemonClaw](/claw/self-hosted)

## 设置指南

<Steps>
  <Step title="创建钉钉应用">
    1. 前往 [钉钉开放平台](https://open-dev.dingtalk.com/)
    2. 点击 **应用开发** → **企业内部开发**
    3. 点击 **创建应用**
    4. 输入应用名称和描述
    5. 点击 **确定**
  </Step>
  <Step title="启用机器人能力">
    1. 在您的应用中，前往 **应用能力** → **机器人**
    2. 启用机器人配置
    3. 选择 **Stream 模式**（推荐 —— 无需公网 URL）
    4. 点击 **发布**

    <Tip>
    Stream 模式使用 WebSocket，因此您的 LemonClaw 实例不需要公开可访问的 webhook URL。这是最简单的设置方式。
    </Tip>
  </Step>
  <Step title="获取凭据">
    1. 前往 **基础信息** → **凭据信息**
    2. 复制 **AppKey** 和 **AppSecret**
  </Step>
  <Step title="发布应用">
    1. 前往 **版本管理与发布**
    2. 创建新版本（至少为测试版本）
    3. 设置可见范围（哪些用户/部门可以看到该机器人）
    4. 提交并发布
  </Step>
  <Step title="打开 LemonClaw WebUI">
    1. 如果您使用的是托管版 Claw，请前往您的 [Claw Dashboard](https://lemondata.cc/dashboard/claw) 并点击 **Open WebUI**
    2. 如果您是自托管 LemonClaw，请打开您自己的 WebUI（例如 `http://your-ip:18789`）并使用您的 token 登录
    3. 在 WebUI 中，导航至 **Settings** → **Channels**
    4. 展开 **DingTalk** 部分
    5. 粘贴您的 **AppKey** 和 **AppSecret**
    6. 点击 **Save**
  </Step>
  <Step title="开始聊天">
    1. 在钉钉中，通过名称搜索您的机器人
    2. 向它发送一条消息
    3. 第一个用户将 **自动配对** 为所有者 —— 无需代码！
    4. 开始与 AI 聊天！
  </Step>
</Steps>

## 群聊行为

<Note>
当前 LemonClaw 的钉钉支持还不是完整的群工作台集成：

- 群消息只有在 **@ 提及机器人** 时才会进入 AI 处理链
- 回复会优先回到原 `sessionWebhook` 会话
- 完整的群策略 / 白名单 / thread 语义 **尚未提供**
</Note>

## 故障排除

<Note>
当前 LemonClaw 的钉钉支持还不是完整的群工作台集成。群消息只有在 @ 提及机器人时才会进入 AI 处理链，回复会优先走原 sessionWebhook 会话。
</Note>

<AccordionGroup>
  <Accordion title="机器人没有响应">
    - 验证 AppKey 和 AppSecret 是否正确
    - 检查应用是否已发布（至少是测试版本）
    - 确保在机器人配置中选择了 Stream 模式
    - 验证机器人对您的用户账号可见
  </Accordion>
  <Accordion title="连接频繁断开">
    - Stream 模式维持一个持久的 WebSocket 连接
    - 短暂的断开连接是正常的 —— 机器人会自动重新连接
    - 如果问题持续存在，请尝试从控制面板重启实例
  </Accordion>
</AccordionGroup>
