Responses API 是 OpenAI 较新的有状态对话 API。LemonData 为兼容的模型支持此格式。

## 请求体

<ParamField body="model" type="string" required>
  要使用的模型 ID。可用选项请参见 [Models](https://lemondata.cc/zh/models)。
</ParamField>

<ParamField body="input" type="array" required>
  构成对话的输入项列表。

  每个项可以是：
  - `message`：带有角色和内容的对话消息
  - `function_call`：函数调用请求
  - `function_call_output`：函数调用的输出

  对于多模态输入，`message.content` 可以是纯字符串，也可以是内容块数组。对于支持图片理解的模型（例如 GPT-5.4 系列变体），请将图片作为 `input_image` 内容块传入，而不是把 URL 或 Base64 直接塞进纯文本里。

  内容块示例：
  - `{ "type": "input_text", "text": "请描述这张图片" }`
  - `{ "type": "input_image", "image_url": "https://example.com/image.jpg" }`
  - `{ "type": "input_image", "image_url": "data:image/png;base64,..." }`
</ParamField>

<ParamField body="instructions" type="string">
  模型的系统指令（等同于 system message）。
</ParamField>

<ParamField body="max_output_tokens" type="integer">
  要生成的最大 token 数。
</ParamField>

<ParamField body="temperature" type="number" default="1">
  介于 0 和 2 之间的采样温度。
</ParamField>

<ParamField body="tools" type="array">
  模型可调用的工具列表。
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  如果为 true，则返回事件流。
</ParamField>

<ParamField body="previous_response_id" type="string">
  用于从中继续对话的先前响应 ID。
</ParamField>

<ParamField body="store" type="boolean" default="true">
  是否存储该响应以供后续检索。
</ParamField>

<ParamField body="metadata" type="object">
  附加到响应上的元数据，用于跟踪目的。
</ParamField>

<ParamField body="text" type="object">
  文本生成配置选项。
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  是否允许并行进行多个工具调用。
</ParamField>

<ParamField body="top_p" type="number">
  Nucleus sampling 参数（0-1）。
</ParamField>

<ParamField body="reasoning" type="object">
  适用于启用 reasoning 的模型（例如 GPT-5 系列变体）的 reasoning 配置。

  - `effort` (string)：reasoning 工作强度级别（`low`、`medium`、`high`）
</ParamField>

## 响应

<ResponseField name="id" type="string">
  响应的唯一标识符。
</ResponseField>

<ResponseField name="object" type="string">
  始终为 `response`。
</ResponseField>

<ResponseField name="created" type="integer">
  响应创建时间的 Unix 时间戳。
</ResponseField>

<ResponseField name="output" type="array">
  模型生成的输出项列表。
</ResponseField>

<ResponseField name="usage" type="object">
  token 使用统计信息。
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/responses" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "input": [
      {"type": "message", "role": "user", "content": "Hello!"}
    ],
    "max_output_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-4o",
    input=[
        {"type": "message", "role": "user", "content": "Hello!"}
    ],
    max_output_tokens=1000
)

print(response.output)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-4o',
  input: [
    { type: 'message', role: 'user', content: 'Hello!' }

  max_output_tokens: 1000
});

console.log(response.output);
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model": "gpt-4o",
        "input": []map[string]interface{}{
            {"type": "message", "role": "user", "content": "Hello!"},
        },
        "max_output_tokens": 1000,
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.lemondata.cc/v1/responses", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Println(result["output"])
}
```

```php PHP
<?php
$ch = curl_init('https://api.lemondata.cc/v1/responses');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-4o',
        'input' => [
            ['type' => 'message', 'role' => 'user', 'content' => 'Hello!']
        ],
        'max_output_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
print_r($data['output']);
```
## 图片输入示例

对于支持图片理解的模型，请将图片放在 `message.content` 中，作为 `input_image` 内容块传入。`image_url` 既可以是公网 URL，也可以是 Base64 Data URL。

```json
{
  "model": "gpt-5.4",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "请描述这张图片。"
        },
        {
          "type": "input_image",
          "image_url": "https://example.com/demo.jpg"
        }
      ]
    }
  ]
}
```

```json
{
  "model": "gpt-5.4",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "请描述这张图片。"
        },
        {
          "type": "input_image",
          "image_url": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQ..."
        }
      ]
    }
  ]
}
```
