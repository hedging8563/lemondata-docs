---
title: "取消 Seedance 任务（火山兼容）"
openapi: "DELETE /api/v3/contents/generations/tasks/{id}"
description: "在任务仍可取消时取消排队中的 Seedance 兼容任务。"
---

## 概览

这些接口面向已经使用火山风格 Seedance 任务结构的团队。鉴权使用 TokenLab Bearer API Key。返回的任务 ID 以 `cgt-` 开头；请轮询状态接口，直到 `status` 变为 `succeeded`、`failed`、`cancelled` 或 `expired`。

另见 [Seedance 2.0 视频模型](/zh/guides/seedance-2-video) 和 [视频生成](/zh/guides/video-generation).

## 响应结构

取消成功时返回 HTTP 200，响应体为空。需要确认最终状态时，请继续查询任务。

## 示例

```bash
curl -X DELETE https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
