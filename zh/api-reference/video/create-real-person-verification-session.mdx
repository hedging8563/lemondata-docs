为下游自建 H5 流程创建真人素材认证会话。

TokenLab 返回中立字段：`session_id`、`verification_token`、`h5_link`、`callback_url`、`expires_in`、`language`。不会返回上游凭证。会话、token 和 H5 链接有效期均为 120 秒。

把用户引导到 `h5_link`。H5 流程结束后，TokenLab 会跳转到你传入的 `callback_url`，并携带：

| 参数 | 含义 |
|------|------|
| `session_id` | TokenLab 认证会话 ID。 |
| `verification_token` | 绑定认证结果用的 TokenLab 不透明 token。 |
| `verification_status` | `succeeded` 或 `failed`。 |
| `result_code` | 标准化结果码，用于排查。 |

当 `verification_status` 为 `succeeded` 时，调用 [绑定真人素材认证结果](/api-reference/video/bind-real-person-verification-result)。需要人工检查重定向和绑定流程时，可使用 [测试控制台](https://tokenlab.sh/dashboard/seedance-assets)。
