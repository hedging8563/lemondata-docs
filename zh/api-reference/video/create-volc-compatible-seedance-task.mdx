## 概览

这些接口面向已经使用火山风格 Seedance 任务结构的团队。鉴权使用 TokenLab Bearer API Key。返回的任务 ID 以 `cgt-` 开头；请轮询状态接口，直到 `status` 变为 `succeeded`、`failed`、`cancelled` 或 `expired`。

也可以调用 Action 分发入口，支持 `CreateContentsGenerationsTasks`、`GetContentsGenerationsTask`、`ListContentsGenerationsTasks` 和 `DeleteContentsGenerationsTasks`。`Action` 和 `Version` 大小写不敏感。`Version` 可省略；如传入则必须为 `2024-01-01`。

这一版不接受 `callback_url`。请通过轮询查询任务状态，避免接入方误以为回调已经生效。

另见 [Seedance 2.0 视频模型](/zh/guides/seedance-2-video) 和 [视频生成](/zh/guides/video-generation).

## 内容规则

- `type=text` 用于提示词文本。
- `type=image_url` 不传 `role` 时按首帧处理，也可以显式传 `role=first_frame`。
- `role=last_frame` 必须和首帧一起使用。
- `role=reference_image`、`reference_video`、`reference_audio` 用于参考素材。
- 同一个请求里不要混用首尾帧输入和参考素材。

## 参数说明

- `ratio` 支持 `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9` 或 `adaptive`。
- `generate_audio` 默认是 `true`；需要静音视频时传 `false`。
- `service_tier=default` 可用。Seedance 2.0 兼容任务会拒绝 `service_tier=flex`、`frames` 和 `camera_fixed=true`。
- 当所选模型支持时，`tools` 可以传入类似 `{ "type": "web_search" }` 的对象。格式错误的 tool 项会被拒绝，而不是静默忽略。

## 示例

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [
      {"type": "text", "text": "A cinematic forest at sunset"},
      {"type": "image_url", "role": "reference_image", "image_url": {"url": "https://example.com/ref.png"}}
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p",
    "generate_audio": true
  }'
```
