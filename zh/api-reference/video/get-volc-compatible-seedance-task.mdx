## 概览

这些接口面向已经使用火山风格 Seedance 任务结构的团队。鉴权使用 TokenLab Bearer API Key。返回的任务 ID 以 `cgt-` 开头；请轮询状态接口，直到 `status` 变为 `succeeded`、`failed`、`cancelled` 或 `expired`。

另见 [Seedance 2.0 视频模型](/zh/guides/seedance-2-video) 和 [视频生成](/zh/guides/video-generation).

## 响应结构

任务状态使用 `queued`、`running`、`succeeded`、`failed`、`cancelled` 或 `expired`。成功任务返回 `content.video_url`；可用时还会返回 `content.last_frame_url`、`return_last_frame` 和 `watermark` 等请求参数、`usage` 和 `progress`。没有失败时 `error` 为 `null`。

## 示例

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
