---
title: "查询素材组详情"
openapi: "GET /v1/videos/assets/groups/{groupId}"
description: "通过 TokenLab 素材组 ID 查询一个 Seedance 素材组。"
---

查询一个素材组。上传素材前可以用它确认素材组仍然存在且状态为 `ACTIVE`。
## 用例请求

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 用例响应

```json
{
  "id": "seedance_group_virtual_123",
  "object": "seedance.material_asset_group",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
