---
title: "删除素材组"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "删除当前组织拥有的 Seedance 素材组。"
---

删除素材组以及 TokenLab 中该组下的素材。此操作不可恢复。

如果素材服务因当前授权状态不允许删除，TokenLab 会返回中立的素材库错误。删除后，该素材组和组内素材不能再用于视频生成。
## 用例请求

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/seedance_group_virtual_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 用例响应

```json
{
  "deleted": true,
  "id": "seedance_group_virtual_123"
}
```
