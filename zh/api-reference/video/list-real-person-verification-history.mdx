查询当前组织长期保存的真人素材认证历史。

这个接口适合用于客户支持、审计记录和接入排障。它不能替代短时绑定流程：`session_id`、`verification_token` 和 H5 链接仍然会在 120 秒后过期；认证成功后应立即调用 [绑定认证结果](/api-reference/video/bind-real-person-verification-result)。

返回内容是 TokenLab 中立口径，不包含内部凭据或底层素材库 ID。绑定成功后，`group_id` 是 TokenLab 素材组 ID，可用于创建 `liveness_face` 真人素材。

状态说明：

| 状态 | 含义 |
|------|------|
| `created` | TokenLab 已创建 H5 会话，但尚未收到回调。 |
| `callback_succeeded` | TokenLab 已收到成功的 H5 回调，但尚未绑定结果。 |
| `callback_failed` | TokenLab 已收到失败的 H5 回调。 |
| `bound` | 认证结果已绑定为 TokenLab 真人素材组。 |
| `expired` | 120 秒绑定窗口内未完成绑定。 |

[测试控制台](https://tokenlab.sh/dashboard/seedance-assets) 会在同一页面展示长期认证历史、素材组和素材。
