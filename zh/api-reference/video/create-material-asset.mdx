---
title: "创建素材"
openapi: "POST /v1/videos/assets"
description: "将 Seedance 素材上传到 TokenLab 素材组。"
---

每次导入一个可公开访问的来源 URL。TokenLab 会保存素材用于后续生成；视频生成请使用返回的素材 `id`，不要依赖来源 URL。`aigc_avatar` 可省略 `group_id`；TokenLab 会使用或创建组织默认虚拟人像素材组。`liveness_face` 必须传入 [绑定真人素材认证结果](/zh/api-reference/video/bind-real-person-verification-result) 返回的 TokenLab `group_id`。

| 类型 | 支持输入 |
|------|----------|
| 图片 | `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`；宽高比 `(0.4, 2.5)`；宽高 `(300, 6000)` px；小于 30 MB。 |
| 视频 | `mp4`, `mov`；`480p`, `720p`, `1080p`；2-15 秒；宽高比 `[0.4, 2.5]`；宽高 `[300, 6000]` px；总像素 409600 到 2086876；最大 50 MB；24-60 FPS。 |
| 音频 | `wav`, `mp3`；2-15 秒；最大 15 MB。 |

素材入库是异步的。轮询 [查询素材详情](/zh/api-reference/video/get-material-asset) 直到 `status` 为 `ACTIVE`。真人素材组中，一个组对应一个已认证真人；多人脸或人脸不一致的素材可能失败。
## 用例请求

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"seedance_group_virtual_123","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view"}'
```

## 用例响应

```json
{
  "id": "seedance_asset_123",
  "object": "seedance.material_asset",
  "group_id": "seedance_group_virtual_123",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "asset_url": "https://example.com/reference.png",
  "cover_url": null,
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
