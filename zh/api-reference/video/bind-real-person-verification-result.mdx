---
title: "绑定真人素材认证结果"
openapi: "POST /v1/videos/assets/visual-validation-results"
description: "把成功的真人素材认证结果绑定为 TokenLab 素材组。"
---

绑定成功的真人素材认证结果，并为当前组织创建 TokenLab 真人素材组映射。

传入 [创建真人素材认证会话](/api-reference/video/create-real-person-verification-session) 或 TokenLab 回调中拿到的 `session_id` 和 `verification_token`。TokenLab 会校验会话属于同一组织、未过期，并且匹配创建会话时记录的素材库渠道。

响应返回 `group_id` 和 `material_group`，不会暴露上游素材组 ID。请保存 `group_id`，后续创建 `liveness_face` 素材时必须传它。
