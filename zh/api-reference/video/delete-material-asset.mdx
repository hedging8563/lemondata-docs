---
title: "删除素材"
openapi: "DELETE /v1/videos/assets/{assetId}"
description: "删除当前组织拥有的 Seedance 素材。"
---

删除一个素材。此操作不会删除所在素材组。删除后，该素材 ID 不能再作为 `material_asset_id` 使用。
## 用例请求

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 用例响应

```json
{
  "deleted": true,
  "id": "seedance_asset_123"
}
```
