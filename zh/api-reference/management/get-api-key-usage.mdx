## 概览

这个端点返回单个 API Key 的用量明细，支持按请求中的模型名（`model`）、公开模型厂商、`scene` 和 `accessChannel` 筛选。

## 注意事项

- 响应只包含面向外部的账单字段。
- 内部路由和物理渠道元数据会被隐藏。
