## 概览

管理 API 用于自动化管理组织级 API Key，并查询单个 Key 维度的用量与账单，无需使用普通推理 API Key。

管理令牌可以在 Dashboard 的 **Settings** 页面生成和轮换：

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
管理令牌不是推理 API Key。`mt-...` 用于 `/v1/management/*`，`sk-...` 用于 `/v1/responses` 等模型推理接口。
</Warning>

## 可用接口

| Endpoint | Method | 说明 |
|----------|--------|------|
| `/v1/management/api-keys` | GET | 列出当前组织下的用户 API Key |
| `/v1/management/api-keys` | POST | 创建新的用户 API Key |
| `/v1/management/api-keys/{keyId}` | PATCH | 更新名称、额度、模型白名单、过期时间或状态 |
| `/v1/management/api-keys/{keyId}/usage` | GET | 查询指定 Key 的分页用量明细 |
| `/v1/management/api-keys/{keyId}/billing` | GET | 查询指定 Key 的聚合账单明细 |

## 字段说明

- 请求中的模型名（`model`）
- 公开模型厂商
- `scene`
- `accessChannel`：`platform` 表示按平台方式计费，`byok` 表示使用你自己的上游 Provider Key 计费
- 用量、计费单位与缓存指标
- 费用与时间

接口只返回公开可理解的账单与报表字段，不暴露内部路由细节或物理渠道元数据。

## 筛选维度

`/usage` 与 `/billing` 目前支持按以下维度筛选：

- 时间范围
- 请求中的模型名（`model`）
- 公开模型厂商
- `scene`
- `accessChannel`
- 分页

## 完整请求示例

先用当前管理令牌列出这个组织下的 API Keys：

<RequestExample>
```bash cURL
curl "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```

```python Python
import requests

response = requests.get(
    "https://api.lemondata.cc/v1/management/api-keys",
    headers={"Authorization": "Bearer mt-your-management-token"}
)

data = response.json()
for key in data["data"]:
    print(key["name"], key["status"], key["used_amount"])
```

```javascript JavaScript
const response = await fetch(
  'https://api.lemondata.cc/v1/management/api-keys',
  {
    headers: {
      'Authorization': 'Bearer mt-your-management-token'
    }
  }
);

const data = await response.json();
for (const key of data.data) {
  console.log(key.name, key.status, key.used_amount);
}
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    req, _ := http.NewRequest("GET", "https://api.lemondata.cc/v1/management/api-keys", nil)
    req.Header.Set("Authorization", "Bearer mt-your-management-token")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)

    fmt.Println(result["object"])
}
```

```php PHP
<?php
$ch = curl_init("https://api.lemondata.cc/v1/management/api-keys");

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer mt-your-management-token'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
foreach ($data['data'] as $key) {
    echo $key["name"] . " " . $key["status"] . " " . $key["used_amount"] . PHP_EOL;
}
```
</RequestExample>
