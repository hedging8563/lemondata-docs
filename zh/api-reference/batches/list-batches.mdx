## 概览

该接口属于 LemonData 的 OpenAI 兼容 Batch API。Batch 使用上传的 JSONL 文件异步执行，并在完成后产出 output/error 文件。

## 注意事项

- Batch 输入文件必须使用 `purpose=batch`。
- 当前 `completion_window` 仅支持 `24h`。
- 输出行序不保证与输入一致，请始终使用 `custom_id` 对齐。
- Batch item 内不支持流式请求。

## 请求与响应

具体字段请以上方的交互式 OpenAPI 面板为准。

## 运维建议

- 下游对账务必以 `custom_id` 作为幂等键。
- 只有在 worker 完成收尾后，`output_file_id` / `error_file_id` 才会出现。
- Batch 计费可能不同于同步请求，因为会应用 `isBatchRequest=true` 的折扣规则。
