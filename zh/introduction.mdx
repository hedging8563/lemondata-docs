## 什么是 LemonData？

LemonData 是一个 AI API 聚合平台，可为你统一访问来自 OpenAI、Anthropic、Google、DeepSeek、Moonshot、MiniMax 等提供商的 **300+ AI 模型**。

  </Card>
  <Card title="原生格式" icon="shuffle">

  </Card>

## 支持的能力

| 能力 | 描述 | 示例模型 |
|------------|-------------|----------------|
| **聊天与推理** | 文本生成、规划、工具调用 | `gpt-5.4`, `claude-sonnet-4-6`, `deepseek-r1` |
| **视觉** | 图像理解与多模态聊天 | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |

| **音乐** | AI 音乐生成 | `suno` |
| **3D** | 3D 资产生成 | `tripo3d` |

## 一个良好的默认起点

对于新项目，建议从 OpenAI SDK 加 **Responses API** 开始：

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```
