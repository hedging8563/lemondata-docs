## 개요

LemonData는 Mistral AI 모델에 대한 액세스를 제공합니다. 총 **3개의 모델**을 사용할 수 있습니다.

## Chat 모델

| Model ID | 가격 |
|----------|--------|
| `Dolphin3.0-R1-Mistral-24B` | 대시보드 확인 |
| `mistral-large` | 대시보드 확인 |
| `mistral-small` | 대시보드 확인 |


## 사용법

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="Dolphin3.0-R1-Mistral-24B",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

<Note>
표시된 가격은 플랫폼 가격입니다 (공식 요금의 약 70%).
</Note>
