## 개요

LemonData는 Luma AI 모델에 대한 액세스를 제공합니다. 총 **2개의 모델**을 사용할 수 있습니다.

## 채팅 모델

| 모델 ID | 가격 |
|----------|--------|
| `luma-video-api` | 대시보드 참조 |
| `luma-video-extend-api` | 대시보드 참조 |


## 사용법

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="luma-video-api",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

<Note>
표시된 가격은 플랫폼 가격입니다(공식 요금의 약 70%).
</Note>
