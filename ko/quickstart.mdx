## 1단계: API 키 받기

<Steps>
  <Step title="계정 생성">
    이메일, Gmail 또는 GitHub 계정을 사용하여 [lemondata.cc](https://lemondata.cc)에서 가입하세요.
  </Step>
  <Step title="크레딧 추가">
    대시보드를 열고 계정에 크레딧을 추가하세요. LemonData는 최소 약정 없이 종량제 요금을 사용합니다.
  </Step>
  <Step title="API 키 생성">
    **Dashboard → API Keys**로 이동하여 새 키를 생성하세요. 한 번만 표시되므로 안전하게 복사해 두세요.
  </Step>
</Steps>

<Warning>
API 키를 안전하게 보호하세요. 클라이언트 측 코드나 공개 저장소에 절대 노출하지 마세요.
</Warning>

## 3단계: 첫 요청 보내기

새 프로젝트의 경우 **Responses API**로 시작하세요.

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "What is the capital of France?"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="What is the capital of France?"
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'What is the capital of France?',
});

console.log(response.output_text);
```

</CodeGroup>

<Note>
프레임워크나 도구가 여전히 Chat Completions를 기대하는 경우, LemonData는 `POST /v1/chat/completions`도 지원합니다. 새로운 통합에는 `POST /v1/responses`를 우선 사용하세요.
</Note>

## 다양한 모델 사용해보기

LemonData는 300개 이상의 모델을 지원합니다. `model` 필드만 변경하면 됩니다:

```python
response = client.responses.create(model="gpt-5.4", input="Hello")
response = client.responses.create(model="gpt-5-mini", input="Hello")
response = client.responses.create(model="claude-sonnet-4-6", input="Hello")
response = client.responses.create(model="gemini-2.5-flash", input="Hello")
response = client.responses.create(model="deepseek-r1", input="Hello")
```

## 스트리밍 활성화

```python
stream = client.responses.create(
    model="gpt-5.4",
    input="Tell me a short story.",
    stream=True
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```
