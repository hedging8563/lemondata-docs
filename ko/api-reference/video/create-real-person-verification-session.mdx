description: "TokenLab 실제 인물 자료 인증 H5 세션을 생성합니다."
---

단기 인증 세션을 생성하고 사용자를 반환된 H5 링크로 리다이렉트합니다. TokenLab은 `session_id`, `h5_link`, `callback_url`, `expires_in`, `language`와 같은 중립적인 필드만 반환합니다.

세션과 H5 링크는 120초 후에 만료됩니다. 바인딩 토큰은 TokenLab 콜백 리다이렉트에서만 제공됩니다. H5 흐름이 완료되면 TokenLab은 다음 쿼리 매개변수와 함께 원래의 `callback_url`로 리다이렉트합니다.

| 매개변수 | 의미 |
|-----------|---------|
| `session_id` | TokenLab 인증 세션 ID. |
| `verification_token` | 결과를 바인딩하는 데 사용되는 불투명 토큰. |
| `verification_status` | `succeeded` 또는 `failed`. |
| `result_code` | 애플리케이션 로직을 위한 결과 코드. |

`verification_status`가 `succeeded`인 경우, [실제 인물 인증 결과 바인딩](/ko/api-reference/video/bind-real-person-verification-result)을 호출하십시오. [테스트 콘솔](https://tokenlab.sh/dashboard/seedance-assets)을 사용하여 제품에 흐름을 연결하기 전에 콜백 처리를 검증할 수 있습니다.

## 요청 예시

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"callback_url":"https://yourapp.example.com/seedance/callback","language":"en"}'
```

## 응답 예시

```json
{
  "object": "seedance.visual_validation_session",
  "session_id": "svv_abc123",
  "h5_link": "https://verify.example.com/h5?lng=en",
  "callback_url": "https://yourapp.example.com/seedance/callback",
  "expires_in": 120,
  "language": "en"
}
```
