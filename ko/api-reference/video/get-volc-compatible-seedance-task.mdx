## 개요

이 엔드포인트는 Volc 스타일 Seedance 작업 구조를 이미 사용하는 팀을 위한 것입니다. 인증은 TokenLab Bearer API Key를 사용합니다. 반환되는 작업 ID는 `cgt-`로 시작하며, `status`가 `succeeded`, `failed`, `cancelled`, `expired` 중 하나가 될 때까지 폴링하세요.

같이 보기 [Seedance 2.0 비디오 모델](/ko/guides/seedance-2-video) 및 [비디오 생성](/ko/guides/video-generation).

## 응답 형식

작업 상태는 `queued`, `running`, `succeeded`, `failed`, `cancelled`, `expired`를 사용합니다. 성공한 작업은 `content.video_url`을 반환합니다. 가능한 경우 `content.last_frame_url`, `return_last_frame` 및 `watermark` 같은 요청 파라미터, `usage`, `progress`도 반환됩니다. 실패가 없으면 `error`는 `null`입니다.

## 예시

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-0123456789abcdef0123456789abcdef \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
