---
title: "머티리얼 에셋 생성"
openapi: "POST /v1/videos/assets"
description: "Seedance 머티리얼 에셋을 TokenLab 머티리얼 그룹에 업로드합니다."
---

공개적으로 접근 가능한 소스 URL을 Seedance 머티리얼 그룹으로 가져옵니다. TokenLab은 나중에 사용할 수 있도록 머티리얼을 저장합니다. 생성 시에는 소스 URL이 아닌 반환된 머티리얼 에셋 `id`를 사용하십시오.

`library_type: "aigc_avatar"`의 경우 `group_id`는 선택 사항이며, TokenLab은 조직의 기본 가상 아바타 그룹을 사용하거나 생성합니다. `library_type: "liveness_face"`의 경우 `group_id`는 필수이며, [시각 인증 결과 조회](/ko/api-reference/video/get-visual-validation-result)에서 반환된 TokenLab 그룹이어야 합니다.

| 유형 | 지원되는 입력 |
|------|-----------------|
| 이미지 | `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; 가로세로 비율 `(0.4, 2.5)`; 너비 및 높이 `(300, 6000)` px; 30 MB 미만. |
| 비디오 | `mp4`, `mov`; `480p`, `720p` 또는 `1080p`; 2-15초; 가로세로 비율 `[0.4, 2.5]`; 너비 및 높이 `[300, 6000]` px; 총 픽셀 수 409600 ~ 2068676; 최대 200 MB; 24-60 FPS. |
| 오디오 | `aac`, `wav`, `mp3`; 2-15초; 최대 15 MB. |

생성 과정은 비동기식으로 진행됩니다. `status`가 `ACTIVE`가 될 때까지 [머티리얼 에셋 가져오기](/ko/api-reference/video/get-material-asset)을 폴링하십시오. 실존 인물 그룹의 경우, 하나의 그룹은 한 명의 인증된 인물과 매핑됩니다. 여러 얼굴이 포함되어 있거나 인증된 인물과 일치하지 않는 얼굴이 포함된 경우 업로드가 실패할 수 있습니다.

## 요청 예시

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"group-20260720123456-vrt01","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view"}'
```
