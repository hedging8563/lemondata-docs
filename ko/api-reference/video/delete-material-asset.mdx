---
title: "머티리얼 에셋 삭제"
openapi: "DELETE /v1/videos/assets/{assetId}"
description: "현재 조직이 소유한 Seedance 머티리얼 에셋을 삭제합니다."
---

하나의 머티리얼 에셋을 삭제합니다. 이 작업은 포함된 머티리얼 그룹을 삭제하지는 않습니다. 삭제 후에는 해당 에셋 ID를 `material_asset_id`로 사용할 수 없습니다.

## 요청 예시

```bash
curl https://api.tokenlab.sh/v1/videos/assets/seedance_asset_123 \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 응답 예시

```json
{
  "deleted": true,
  "id": "seedance_asset_123"
}
```
