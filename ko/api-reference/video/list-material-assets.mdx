---
title: "머티리얼 에셋 목록 조회"
openapi: "GET /v1/videos/assets"
description: "현재 조직이 소유한 Seedance 머티리얼 에셋 목록을 조회합니다."
---

인증된 조직이 소유한 머티리얼 에셋 목록을 조회합니다. 특정 생성 워크플로우를 위한 에셋을 찾아야 할 경우 `library_type`, `group_id` 또는 `status`를 사용하여 필터링할 수 있습니다.

`status`가 `ACTIVE`인 에셋만 사용하십시오. `asset_url`은 업로드 소스나 검사용 정보로 취급해야 하며, 장기적인 머티리얼 주소로 사용해서는 안 됩니다.

## 요청 예시

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=seedance_group_virtual_123&page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 응답 예시

```json
{
  "assets": [
    {
      "id": "seedance_asset_123",
      "object": "seedance.material_asset",
      "group_id": "seedance_group_virtual_123",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
