title: "실제 인물 인증 기록 목록 조회"
openapi: "GET /v1/videos/assets/visual-validation-sessions"
description: "현재 조직의 실제 인물 자료 인증 세션 목록을 조회합니다."
---

검토, 고객 지원 및 조정을 위해 이전 인증 세션 목록을 조회합니다. 이 기록은 장기간 보관되지만, 단기 바인딩 단계를 대체하지는 않습니다. 즉, 인증이 성공하면 여전히 120초 이내에 즉시 바인딩을 완료해야 합니다.

응답에는 TokenLab ID만 포함되며 자격 증명 데이터는 포함되지 않습니다. 바인딩이 성공하면 `group_id`는 `liveness_face` 업로드에 사용되는 TokenLab 자료 그룹 ID가 됩니다.

## 요청 예시

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/visual-validation-sessions?page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
