---
title: "Delete Material Asset Group"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "Deletes a Seedance material group owned by the current organization."
---

Deletes an organization-owned material group. Deleting a group also deletes the material assets inside it and cannot be undone.

If the underlying material library refuses deletion because the current authorization state does not allow it, TokenLab returns a neutral material-library error. Treat delete as a destructive operation and stop referencing assets in the deleted group immediately.
