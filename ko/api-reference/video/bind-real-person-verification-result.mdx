description: "성공한 실제 인물 소재 인증 결과를 TokenLab 소재 그룹에 바인딩합니다."
---

성공한 인증 결과를 바인딩하고 TokenLab 실제 인물 소재 그룹 매핑을 생성합니다. 인증 세션 또는 TokenLab 콜백 리다이렉트에서 얻은 `session_id`와 `verification_token`을 사용하십시오.

TokenLab은 해당 세션이 동일한 조직에 속해 있는지, 만료되지 않았는지, 그리고 인증 세션에서 사용된 동일한 소재 서비스에 바인딩되어 있는지 확인합니다. 응답은 TokenLab `group_id`만 반환하며, `liveness_face` 소재 에셋을 생성할 때 이를 사용하십시오.

## 요청 예시

```bash
curl https://api.tokenlab.sh/v1/videos/assets/visual-validation-results \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"svv_abc123","verification_token":"svvt_def456","group_name":"Creator A"}'
```

## 응답 예시

```json
{
  "object": "seedance.visual_validation_result",
  "group_id": "seedance_group_real_123",
  "material_group": {
    "id": "seedance_group_real_123",
    "library_type": "liveness_face",
    "status": "ACTIVE",
    "group_name": "Creator A"
  }
}
```
