## 개요

이 엔드포인트는 관리 토큰에 연결된 조직의 현재 잔액 합계를 반환합니다. 과금 및 정산과 동일한 조직 잔액 단일 사실원을 사용합니다.

## 주의 사항

- 금액 필드는 USD로 반환됩니다. 표시에는 `balance`, `total_recharge`, `total_used`를 사용하고, 정확한 청구 대조에는 `balance_decimal`, `total_recharge_decimal`, `total_used_decimal`을 사용하세요.

## 예시

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/balance" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 요청 / 응답

정확한 스키마를 위해 위의 대화형 OpenAPI 패널을 사용하세요.

## 응답 예시

<ResponseExample>
```json 200 OK
{
  "object": "organization_balance",
  "organization_id": "org_123",
  "balance": 42.5,
  "balance_decimal": "42.50",
  "total_recharge": 100,
  "total_recharge_decimal": "100",
  "total_used": 57.5,
  "total_used_decimal": "57.50"
}
```
</ResponseExample>

## 중요 필드

<ResponseField name="object" type="string">항상 `organization_balance`입니다.</ResponseField>
<ResponseField name="organization_id" type="string">현재 Management token에 연결된 조직입니다.</ResponseField>
<ResponseField name="balance" type="number">현재 조직 잔액입니다. USD JSON number이며 표시용입니다.</ResponseField>
<ResponseField name="balance_decimal" type="string">현재 조직 잔액입니다. USD decimal string이며 정확한 대조용입니다.</ResponseField>
<ResponseField name="total_recharge" type="number">성공한 조직 충전 총액입니다. USD JSON number이며 표시용입니다.</ResponseField>
<ResponseField name="total_recharge_decimal" type="string">성공한 조직 충전 총액입니다. USD decimal string이며 정확한 대조용입니다.</ResponseField>
<ResponseField name="total_used" type="number">조직 누적 사용 지출입니다. USD JSON number이며 표시용입니다.</ResponseField>
<ResponseField name="total_used_decimal" type="string">조직 누적 사용 지출입니다. USD decimal string이며 정확한 대조용입니다.</ResponseField>
