## 개요

이 endpoint 는 현재 management token에 연결된 조직 안에 새로운 `type=user` API Key를 생성합니다.

## 요청 본문

| 필드 | 타입 | 기본값 / 제한 | 설명 |
|-------|------|------------------|-------|
| name | string | required, default Default Key, length 1-50 | Display name, trimmed server-side |
| limitAmount | number \| null | min 0, max 100000 | null or omitted = unlimited, 0 = zero quota, positive = USD spending cap |
| models | string[] | default [] | Optional logical model allowlist |
| expiresAt | string \| null | RFC3339 datetime | null means no expiry |

## 참고 사항

- 전체 API Key 값은 응답에서 한 번만 표시됩니다.
- `models: []` 는 조직 정책 외에 추가 모델 제한이 없음을 의미합니다.
- `limitAmount: 0` 은 유효하지만 사용할 수 있는 쿼터가 없는 키를 생성하며, 이후 업데이트가 필요합니다.

## 예시

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "sora-2"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>
