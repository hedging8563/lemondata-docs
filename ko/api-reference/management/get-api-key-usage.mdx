## 개요

이 엔드포인트는 요청에 넣는 모델 이름(`model`), 공개 모델 벤더, `scene`, `accessChannel` 기준으로 필터링할 수 있는 키 단위 사용량 상세를 반환합니다.

## 주의 사항

- 응답에는 공개 청구 필드만 포함됩니다.
- 내부 라우팅 및 물리 채널 메타데이터는 숨겨집니다.

## 요청 / 응답

정확한 스키마를 위해 위의 대화형 OpenAPI 패널을 사용하세요.
