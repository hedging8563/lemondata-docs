---

## 요청 본문

<ParamField body="model" type="string" required>
  사용할 model의 ID입니다. 사용 가능한 옵션은 [Models](https://lemondata.cc/ko/models)를 참조하세요.
</ParamField>

<ParamField body="messages" type="array" required>
  대화를 구성하는 메시지 목록입니다.

  각 메시지 객체는 다음을 포함합니다:
  - `role` (string): `system`, `user`, 또는 `assistant`
  - `content` (string | array): 메시지 내용
</ParamField>

<ParamField body="temperature" type="number" default="1">
  0에서 2 사이의 sampling temperature입니다. 값이 높을수록 출력이 더 무작위적이 됩니다.
</ParamField>

<ParamField body="max_tokens" type="integer">
  생성할 최대 token 수입니다.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  true인 경우, 부분 메시지 delta가 SSE 이벤트로 전송됩니다.
</ParamField>

<ParamField body="stream_options" type="object">
  streaming에 대한 옵션입니다. stream chunk에서 token 사용량을 받으려면 `include_usage: true`로 설정하세요.
</ParamField>

<ParamField body="top_p" type="number" default="1">
  Nucleus sampling parameter입니다. 이것 또는 temperature 중 하나만 조정하고 둘 다 함께 조정하지 않는 것을 권장합니다.
</ParamField>

<ParamField body="frequency_penalty" type="number" default="0">
  -2.0에서 2.0 사이의 숫자입니다. 양수 값은 반복된 token에 페널티를 부여합니다.
</ParamField>

<ParamField body="presence_penalty" type="number" default="0">
  -2.0에서 2.0 사이의 숫자입니다. 양수 값은 텍스트에 이미 존재하는 token에 페널티를 부여합니다.
</ParamField>

<ParamField body="stop" type="string | array">
  API가 token 생성을 중지할 최대 4개의 시퀀스입니다.
</ParamField>

<ParamField body="tools" type="array">
  model이 호출할 수 있는 도구 목록입니다(function calling).
</ParamField>

<ParamField body="tool_choice" type="string | object">
  model이 도구를 사용하는 방식을 제어합니다. 옵션: `auto`, `none`, `required`, 또는 특정 도구 객체.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  병렬 function calling을 활성화할지 여부입니다. 함수를 순차적으로 호출하려면 false로 설정하세요.
</ParamField>

<ParamField body="max_completion_tokens" type="integer">
  completion에 대한 최대 token 수입니다. `max_tokens`의 대안이며, 최신 reasoning 지원 model 계열에서 유용합니다.
</ParamField>

<ParamField body="reasoning_effort" type="string">
  reasoning 지원 model에 대한 reasoning effort입니다. 옵션: `low`, `medium`, `high`.
</ParamField>

<ParamField body="seed" type="integer">
  결정적 sampling을 위한 난수 seed입니다.
</ParamField>

<ParamField body="n" type="integer" default="1">
  생성할 completion 수입니다(1-128).
</ParamField>

<ParamField body="logprobs" type="boolean">
  log probability를 반환할지 여부입니다.
</ParamField>

<ParamField body="top_logprobs" type="integer">
  반환할 상위 log probability 수입니다(0-20). `logprobs: true`가 필요합니다.
</ParamField>

<ParamField body="top_k" type="integer">
  Top-K sampling parameter입니다(Anthropic/Gemini model용).
</ParamField>

<ParamField body="response_format" type="object">
  응답 형식 명세입니다. JSON mode에는 `{"type": "json_object"}`를 사용하고, 구조화된 출력에는 `{"type": "json_schema", "json_schema": {...}}`를 사용하세요.
</ParamField>

<ParamField body="logit_bias" type="object">
  지정된 token이 나타날 가능성을 수정합니다. token ID(문자열)를 -100에서 100 사이의 bias 값에 매핑합니다.
</ParamField>

<ParamField body="user" type="string">
  abuse monitoring을 위한 최종 사용자를 나타내는 고유 식별자입니다.
</ParamField>

<ParamField body="cache_control" type="object">
  LemonData cache control 옵션입니다.

  - `type` (string): cache 전략 - `default`, `no_cache`, `no_store`, `response_only`, `semantic_only`
  - `max_age` (integer): 초 단위 cache TTL(최대 86400)
</ParamField>

## 응답

<ResponseField name="id" type="string">
  completion의 고유 식별자입니다.
</ResponseField>

<ResponseField name="object" type="string">
  항상 `chat.completion`입니다.
</ResponseField>

<ResponseField name="created" type="integer">
  completion이 생성된 시점의 Unix timestamp입니다.
</ResponseField>

<ResponseField name="model" type="string">
  completion에 사용된 model입니다.
</ResponseField>

<ResponseField name="choices" type="array">
  completion 선택지 목록입니다.

  각 선택지는 다음을 포함합니다:
  - `index` (integer): 선택지의 인덱스
  - `message` (object): 생성된 메시지
  - `finish_reason` (string): model이 중지한 이유 (`stop`, `length`, `tool_calls`)
</ResponseField>

<ResponseField name="usage" type="object">
  token 사용 통계입니다.

  - `prompt_tokens` (integer): prompt의 token 수
  - `completion_tokens` (integer): completion의 token 수
  - `total_tokens` (integer): 총 사용 token 수
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lemondata.cc/v1/chat/completions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "temperature": 0.7,
    "max_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ],
    temperature=0.7,
    max_tokens=1000
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Hello!' }
  ],
  temperature: 0.7,
  max_tokens: 1000
});

console.log(response.choices[0].message.content);
```

```php PHP
<?php
$ch = curl_init('https://api.lemondata.cc/v1/chat/completions');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-4o',
        'messages' => [
            ['role' => 'system', 'content' => 'You are a helpful assistant.'],
            ['role' => 'user', 'content' => 'Hello!']
        ],
        'temperature' => 0.7,
        'max_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['choices'][0]['message']['content'];
```
