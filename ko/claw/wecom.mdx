---

WeCom (企业微信 / WeChat Work)을 LemonClaw 인스턴스와 통합하여 기업 워크스페이스에 AI를 도입하세요. 이 가이드는 호스팅된 Claw 인스턴스와 셀프 호스팅된 LemonClaw 배포 모두에 적용됩니다.

## 사전 요구 사항

- [WeCom](https://work.weixin.qq.com/) 관리자 계정
- LemonClaw 인스턴스:
  - 호스팅형: [Claw 인스턴스 생성](https://lemondata.cc/dashboard/claw)
  - 셀프 호스팅형: [LemonClaw 설치](/claw/self-hosted)

## 설정 가이드

<Steps>
  <Step title="WeCom 앱 생성">
    1. [WeCom 관리 콘솔](https://work.weixin.qq.com/wework_admin/frame)에 로그인합니다.
    2. **App Management** → **Create App**으로 이동합니다.
    3. 앱 이름을 입력하고, 로고를 업로드한 후 공개 범위를 설정합니다.
    4. **Create**를 클릭합니다.
  </Step>
  <Step title="자격 증명 가져오기">
    1. 하단의 **My Enterprise** → **Enterprise Info**에서 **Corp ID**를 확인합니다.
    2. 앱 설정에서 **Secret** (Corp Secret)을 복사합니다.
  </Step>
  <Step title="Callback URL 설정">
    1. 앱 설정에서 **Receive Messages** → **Set API Receive**로 이동합니다.
    2. 호스팅된 Claw의 경우, WeCom 섹션을 확장하면 LemonClaw WebUI에 callback URL이 표시됩니다:
    ```
    https://claw-{your-subdomain}.lemondata.cc/webhook/wecom
    ```
    3. 셀프 호스팅된 LemonClaw의 경우, `/webhook/wecom`으로 끝나는 본인의 공용 HTTPS URL을 노출시킵니다.
    4. **Token** (임의의 문자열)과 **EncodingAESKey** (43자의 임의 문자열)를 설정합니다.
    5. **Save**를 클릭합니다. WeCom에서 callback URL을 확인합니다.

    <Tip>
    호스팅된 callback URL은 LemonClaw WebUI에서 복사 버튼과 함께 표시됩니다. URL을 확인하기 전에 LemonClaw 인스턴스가 실행 중인지 확인하세요.
    </Tip>
  </Step>
  <Step title="LemonClaw WebUI 열기">
    1. 호스팅된 Claw를 사용하는 경우, [Claw Dashboard](https://lemondata.cc/dashboard/claw)로 이동하여 **Open WebUI**를 클릭합니다.
    2. 셀프 호스팅 중인 경우, 본인의 WebUI(예: `http://your-ip:18789`)를 열고 token으로 로그인합니다.
    3. WebUI에서 **Settings** → **IM Integrations**로 이동합니다.
    4. **WeCom** 섹션을 확장합니다.
    5. 호스팅된 Claw를 사용하는 경우 상단에 표시된 **Callback URL**을 복사하거나, 셀프 호스팅 중인 경우 본인의 공용 webhook URL을 입력합니다.
    6. 다음 항목을 입력합니다: **Corp ID**, **Corp Secret**, **Token**, **EncodingAESKey**
    7. **Save**를 클릭합니다.
  </Step>
  <Step title="채팅 시작하기">
    1. WeCom의 **Workbench**에서 생성한 앱을 찾습니다.
    2. 앱에 메시지를 보냅니다.
    3. AI가 즉시 응답합니다. WeCom은 별도의 페어링이 필요하지 않습니다.
  </Step>
</Steps>

<Warning>
**Token**과 **EncodingAESKey**는 WeCom 관리 콘솔과 LemonClaw 설정 간에 정확히 일치해야 합니다. 불일치할 경우 메시지 검증에 실패합니다.
</Warning>

## 문제 해결

<AccordionGroup>
  <Accordion title="Callback URL 확인 실패">
    - LemonClaw 인스턴스가 실행 중인지 확인하세요.
    - URL 형식을 확인하세요: `https://claw-{subdomain}.lemondata.cc/webhook/wecom`
    - WeCom에서 확인하기 **전에** LemonClaw 설정에 Token과 EncodingAESKey가 저장되었는지 확인하세요.
  </Accordion>
  <Accordion title="봇이 응답하지 않음">
    - Corp ID와 Corp Secret이 올바른지 확인하세요.
    - 사용자 계정에서 앱이 보이는지 확인하세요 (공개 범위 설정).
    - WeCom과 LemonClaw 간에 Token 및 EncodingAESKey가 일치하는지 확인하세요.
  </Accordion>
</AccordionGroup>
