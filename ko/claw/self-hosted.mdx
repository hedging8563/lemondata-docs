<Note>
**셀프 호스팅**은 본인의 VPS 또는 머신에서 LemonClaw를 직접 실행하는 것을 의미합니다. LemonData 잔액을 통해 AI 모델 사용료만 지불하면 되며, 인스턴스 비용은 발생하지 않습니다.
</Note>

<Tip>
호스팅된 설정을 선호하시나요? 서버를 직접 관리할 필요 없이 동일한 LemonClaw 런타임과 WebUI를 사용하려면 [Claw 인스턴스 생성](/claw/introduction)을 확인하세요.
</Tip>

## 빠른 설치

<CodeGroup>
```bash Linux / macOS
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```

```bash Non-interactive
LEMONDATA_API_KEY=sk-xxx curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
```
</CodeGroup>

설치 프로그램이 **LemonData API Key** 입력을 요청합니다. [대시보드](https://lemondata.cc/dashboard)에서 키를 발급받으세요.

## 설치 항목

<Steps>
  <Step title="Node.js 22+">
    누락된 경우 자동으로 설치됩니다 (Linux는 NodeSource, macOS는 Homebrew 사용)
  </Step>
  <Step title="LemonClaw">
    LemonData API로 사전 구성된 LemonClaw 패키지
  </Step>
  <Step title="15개의 AI 모델">
    Claude, GPT-5, Gemini, DeepSeek 등 — 즉시 사용 가능
  </Step>
  <Step title="IM 플러그인">
    DingTalk, WeCom, QQ 플러그인 사전 설치
  </Step>
  <Step title="시스템 서비스">
    부팅 시 자동 시작 (Linux는 systemd, macOS는 launchd 사용)
  </Step>
</Steps>

## 요구 사항

| 요구 사항 | 상세 정보 |
|-------------|---------|
| **OS** | Linux (Ubuntu/Debian/CentOS/RHEL) 또는 macOS |
| **아키텍처** | x64 또는 arm64 |
| **RAM** | 최소 1 GB, 2 GB 권장 |
| **API Key** | [여기에서 발급](https://lemondata.cc) |

## 설치 후

설치 프로그램이 액세스 자격 증명을 출력합니다:

```
✓ LemonClaw installed successfully!

  WebUI:        http://your-ip:18789
  Token:        your-gateway-token
  Auto-login:   http://your-ip:18789?token=your-gateway-token
  Model:        claude-sonnet-4-6
```

<Warning>
**Token을 저장하세요!** WebUI에 액세스하고 메시징 플랫폼을 연결하는 데 필요합니다.
</Warning>

## 메시징 플랫폼 연결

Token을 사용하여 `http://your-ip:18789`에서 WebUI에 접속한 후, 플랫폼별 가이드를 따르세요:

<Note>
이 섹션의 플랫폼 가이드는 호스팅된 Claw 인스턴스와 셀프 호스팅된 LemonClaw 설치 모두에서 사용되는 동일한 LemonClaw WebUI를 다룹니다. 가이드에서 Claw Dashboard를 언급하는 경우, 셀프 호스팅 사용자는 대신 자신의 WebUI를 직접 열어야 합니다.
</Note>

## 관리 명령어

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user status lemonclaw    # Check status
    journalctl --user -u lemonclaw -f    # View logs
    systemctl --user restart lemonclaw   # Restart
    systemctl --user stop lemonclaw      # Stop
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    tail -f ~/.lemonclaw/lemonclaw.log    # View logs
    launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # Restart
    launchctl stop cc.lemondata.lemonclaw  # Stop
    ```
  </Tab>
</Tabs>

## 설정

설정 파일 위치: `~/.lemonclaw/config.json`

수정 후 변경 사항을 적용하려면 서비스를 재시작하세요.

### 기본 모델 변경

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "lemondata-claude/claude-opus-4-6"
      }
    }
  }
}
```

사용 가능한 모델 접두사([LemonData 제공자 Setup](/claw/lemondata-provider)에서 어떤 제공자를 활성화했는지에 따라 다름):
- `lemondata/` — OpenAI 호환 경로 (`openai-completions`)
- `lemondata-responses/` — OpenAI Responses 경로 (`openai-responses`)
- `lemondata-claude/` — Claude 네이티브 경로 (`anthropic-messages`)
- `lemondata-gemini/` — Gemini 네이티브 경로 (`google-generative-ai`)
- `lemondata-minimax/` — MiniMax 네이티브 경로 (`anthropic-messages`)

## 업그레이드

```bash
# Re-run the installer to upgrade to the latest version
curl -fsSL https://raw.githubusercontent.com/hedging8563/lemonclaw/main/deploy/self-hosted/install.sh | bash
# Then restart the service
systemctl --user restart lemonclaw  # Linux
# or
launchctl stop cc.lemondata.lemonclaw && launchctl start cc.lemondata.lemonclaw  # macOS
```

## 삭제

```bash
# Stop and disable service
systemctl --user stop lemonclaw && systemctl --user disable lemonclaw  # Linux
launchctl unload ~/Library/LaunchAgents/cc.lemondata.lemonclaw.plist  # macOS

# Remove LemonClaw
rm -rf ~/.lemonclaw
```
