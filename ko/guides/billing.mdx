## 개요

LemonData는 **종량제 가격 정책**을 사용합니다. 구독이나 최소 약정 없이, 사용한 만큼만 비용을 지불합니다.

## 청구 방식

1. 계정에 **크레딧 추가**
2. **API 사용** - 요청당 비용이 차감됩니다
3. 대시보드에서 **사용량 모니터링**
4. 잔액이 부족할 때 **충전**

### Async Task 청구 (Video/Music/3D)

<Warning>
  **중요**: 비디오, 음악 및 3D 생성 작업은 **완료 시점이 아니라 제출 시점에 청구**됩니다.
</Warning>

Async 생성 작업(비디오, 음악, 3D 모델)의 경우:

1. 작업을 제출하는 즉시 **바로 청구가 발생합니다**
2. 상태 조회에는 반환된 `poll_url` 을 우선 사용하고, `task_id` 는 비동기 작업 식별자로 취급합니다
3. 작업이 실패해도 **자동 환불은 없습니다**

이는 작업 결과와 관계없이, 상위 제공업체가 작업 제출 시점에 비용을 청구하기 때문입니다. 작업 실패를 겪는 경우 support@lemondata.cc로 문의해 주세요.

```python
# Example: Video generation billing
response = client.post("/v1/videos/generations", json={
    "model": "sora-2",
    "prompt": "A sunset over the ocean"
})
# ⚠️ You are billed NOW, not when the video is ready

poll_url = response.json()["poll_url"]
task_id = response.json()["task_id"]
# poll_url 로 상태 조회...
```

## Token 계산

Token은 텍스트 처리의 기본 단위입니다:

- 약 4자 = 1 token (영어)
- 약 1-2자 = 1 token (중국어)
- 이미지 1개 = 크기와 디테일에 따라 다름

### Token 수 추정

```python
# Rough estimation
def estimate_tokens(text):
    return len(text) / 4  # Approximate for English

# Actual count (for OpenAI models)
import tiktoken
encoder = tiktoken.encoding_for_model("gpt-4o")
tokens = encoder.encode("Your text here")
print(f"Token count: {len(tokens)}")
```

## 사용량 추적

### 대시보드

[Dashboard](https://lemondata.cc/dashboard)에서 사용량을 모니터링하세요:

- 실시간 잔액
- 모델별 사용 이력
- 비용 분석
- API key 사용량

### API 응답

각 응답에는 사용량 정보가 포함됩니다:

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## 잔액 부족 알림

잔액이 감소할 때 알림을 설정하세요:

1. **Dashboard → Settings → Notifications**로 이동
2. 임계 금액 설정
3. 이메일 알림 수신

## 크레딧 추가

### 결제 방법

- Alipay (支付宝)
- WeChat Pay (微信支付)
- Stripe (Visa, Mastercard)

### 단계

1. [Dashboard](https://lemondata.cc/dashboard)에 로그인
2. **Add Credits** 클릭
3. 금액과 결제 방법 선택
4. 결제 완료

결제 확인 후 크레딧은 즉시 추가됩니다.

## API Key 한도

개별 API key에 지출 한도를 설정할 수 있습니다:

1. **Dashboard → API Keys**로 이동
2. 편집할 key 클릭
3. **Usage Limit** 설정

한도에 도달하면 해당 key를 사용하는 요청은 `402 Payment Required`를 반환합니다.

## 청구서

비즈니스 계정의 경우 청구서를 사용할 수 있습니다:

1. **Dashboard → Billing**으로 이동
2. 거래 내역 확인
3. PDF로 청구서 다운로드
