## 개요

LemonData는 여러 API 형식을 제공하므로 일반적인 coding tool, SDK, 프레임워크를 최소한의 glue code로 연결할 수 있습니다.

이 페이지는 marketing matrix보다 의도적으로 더 좁은 의미를 사용합니다.

- **지원**: 명확한 설정 경로를 문서화했고, 그 경로에 필요한 protocol shape를 LemonData가 노출한다는 뜻입니다.
- **강한 네이티브 경로**: 해당 protocol family에 대해 이 저장소에 직접적인 adapter / request-format 근거가 있다는 뜻입니다.
- **Best-effort**: 통합은 가능할 수 있지만, 상위 클라이언트가 이 custom gateway workflow를 안정적인 계약으로 보지 않는다는 뜻입니다.

<Note>
  미지원 필드는 일괄적으로 처리되지 않습니다. 호환 경로에서는 무시되거나 정규화될 수 있고, native Responses 경로에서는 선택한 model 또는 routed channel이 필요한 passthrough를 지원하지 않으면 명시적인 `400` 또는 `503` 오류가 반환될 수 있습니다.
</Note>

## 지원되는 API 형식

| Endpoint | 형식 | 용도 |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 범용 호환성 |
| `/v1/responses` | OpenAI Responses | 상태 유지 대화 |
| `/v1/messages` | Anthropic Messages | Claude 고유 기능 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini 고유 기능 |

## IDE 및 CLI 호환성

### 문서화된 도구 경로

| 도구 | 지원 수준 | 형식 | 설명 |
|------|----------|------|------|
| **Cursor** | 지원되지만 제약 있음 | OpenAI-compatible | BYOK 표준 chat/editor 흐름용이며, Tab Completion 같은 Cursor 관리 기능을 대체한다는 뜻은 아닙니다 |
| **Claude Code CLI** | 강한 네이티브 경로 | Anthropic | native `/v1/messages` 경로. thinking과 `tool_choice`에 대한 adapter 근거가 있습니다 |
| **Codex CLI** | 지원되지만 model / channel 의존 | OpenAI Responses | `/v1/responses` 설정이 가장 적합합니다. 일부 Responses-native 필드는 model / channel의 native passthrough에 의존합니다 |
| **Gemini CLI** | 실험적 / best-effort | Gemini | LemonData용 custom base URL 흐름은 안정적인 upstream 계약이 아닙니다 |
| **OpenCode** | 지원 | OpenAI-compatible | 기본은 OpenAI-compatible 제공자를 사용하고, Responses 제공자가 명확히 필요할 때만 전환합니다 |

<Note>
  다른 OpenAI-compatible editor / agent tool도 같은 base URL 패턴으로 동작하는 경우가 많지만, 이 저장소는 Windsurf, Aider, Continue.dev, Cline/Roo Code, GitHub Copilot 등에 대한 전용 회귀를 현재 유지하지 않습니다.
</Note>

### 구성 예시

<Tabs>
  <Tab title="Cursor">
    ```
    Base URL: https://api.lemondata.cc/v1
    API Key: sk-your-lemondata-key
    ```
    Cursor는 내부적으로 Anthropic 스타일 tool 형식을 사용합니다. LemonData는 둘 다 지원합니다:
    - OpenAI 형식: `{ type: "function", function: { name, parameters } }`
    - Anthropic 형식: `{ name, input_schema }` (type field 없음)
  </Tab>
  <Tab title="Claude Code">
    ```bash

    export ANTHROPIC_API_KEY="sk-your-lemondata-key"
    ```
  </Tab>
  <Tab title="OpenCode">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"
    export LOCAL_ENDPOINT="https://api.lemondata.cc/v1"
    ```
  </Tab>
  <Tab title="Aider">
    ```bash
    export OPENAI_API_KEY="sk-your-lemondata-key"
    export OPENAI_BASE_URL="https://api.lemondata.cc/v1"
    aider --model gpt-5.4
    ```
  </Tab>
</Tabs>

## SDK 호환성

### 문서화된 SDK / 프레임워크 경로

| SDK / 프레임워크 | 언어 | 지원 수준 | 설명 |
|-----------------|----------|---------------|-------|
| **OpenAI SDK** | Python/JS/Go | 핵심 경로 지원 | Chat Completions, Embeddings, 일반적인 Responses 워크플로를 문서화합니다. 일부 Responses-native-only 필드는 model / channel passthrough에 의존합니다 |
| **Anthropic SDK** | Python/JS | 강한 네이티브 경로 | native Messages 경로. tools, thinking, prompt caching에 직접적인 근거가 있습니다 |
| **Vercel AI SDK** | TypeScript | 권장 통합 패턴 | 먼저 `@ai-sdk/openai-compatible`를 권장하며, Responses-native가 명확히 필요할 때만 `@ai-sdk/openai`를 사용합니다 |
| **LangChain** | Python/JS | 표준 surface 지원 | 범위는 `ChatOpenAI`와 `OpenAIEmbeddings`입니다. vendor-native extras는 범위 밖입니다 |
| **LlamaIndex** | Python | `OpenAILike` 경유 지원 | LemonData 같은 third-party gateway에서는 내장 OpenAI 클래스 대신 `OpenAILike`를 사용합니다 |
| **Dify** | - | 지원되지만 제약 있음 | 예상 경로는 OpenAI 제공자와 chat-completions 지향 흐름입니다. Codex 전용 Responses / WebSocket 보장은 아닙니다 |

## Chat Completions Parameters

### 핵심 Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Model 식별자 (필수) |
| `messages` | array | 대화 message (필수) |
| `max_tokens` | integer | 최대 출력 token 수 |
| `temperature` | number | 샘플링 temperature (0-2) |
| `top_p` | number | Nucleus sampling (0-1) |
| `stream` | boolean | streaming 활성화 |

### Tool Calling

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tool Choice 옵션

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | 단순 선택 |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | 특정 function 강제 |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic 기본 형식 |

### 고급 Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | token 수를 위한 `{ include_usage: true }` |
| `reasoning_effort` | string | reasoning이 활성화된 GPT-5 model용 `"low"`, `"medium"`, `"high"` |
| `service_tier` | string | `"auto"` 또는 `"default"` |
| `seed` | integer | 결정론적 출력 |
| `logprobs` | boolean | log probability 반환 |
| `top_logprobs` | integer | 상위 logprobs 개수 (0-20) |
| `logit_bias` | object | token bias map (-100 ~ 100) |
| `frequency_penalty` | number | 반복 penalty (-2 ~ 2) |
| `presence_penalty` | number | 주제 penalty (-2 ~ 2) |
| `stop` | string/array | 중지 sequence |
| `n` | integer | completion 개수 (1-128) |
| `user` | string | 추적용 사용자 식별자 |

### OpenAI 고급 기능

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | multi모달용 `["text", "audio"]` |
| `audio` | object | 오디오 출력 config (voice, format) |
| `prediction` | object | 더 빠른 completion을 위한 예측 출력 |
| `metadata` | object | 추적용 key-value 쌍 |
| `store` | boolean | 나중에 조회할 수 있도록 저장 |

### 제공자별 옵션

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Responses API Parameters

### 핵심 Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Model 식별자 |
| `input` | string/array | 입력 content |
| `instructions` | string | 시스템 instruction |
| `max_output_tokens` | integer | 최대 출력 token 수 |
| `previous_response_id` | string | 대화 이어가기 |

### 고급 Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` 또는 `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | reasoning model용 |
| `service_tier` | string | 우선순위 tier |

### Tool 형식

OpenAI 및 Anthropic tool 형식을 모두 지원합니다:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## Streaming

모든 endpoint는 Server-Sent Events (SSE) streaming을 지원합니다:

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## 오류 처리

LemonData는 OpenAI 호환 오류 응답을 반환합니다:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

자세한 내용은 [오류 처리 가이드](/guides/error-handling)를 참조하세요.
