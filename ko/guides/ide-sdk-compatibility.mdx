## 개요

LemonData API는 모든 주요 AI 개발 도구와 **즉시 대체 가능한 호환성**을 제공하도록 설계되었습니다. 이 가이드는 지원되는 parameter와 검증된 integration을 문서화합니다.

<Note>
  모든 parameter는 검증되지만 upstream provider로 그대로 전달됩니다. 특정 model에서 지원되지 않는 parameter는 조용히 무시되어 최대 호환성을 보장합니다.
</Note>

## 지원되는 API 형식

| Endpoint | Format | Use Case |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 범용 호환성 |
| `/v1/responses` | OpenAI Responses | 상태 유지 대화 |
| `/v1/messages` | Anthropic Messages | Claude 고유 기능 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini 고유 기능 |

## Chat Completions Parameters

### 핵심 Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Model 식별자 (필수) |
| `messages` | array | 대화 message (필수) |
| `max_tokens` | integer | 최대 출력 token 수 |
| `temperature` | number | 샘플링 temperature (0-2) |
| `top_p` | number | Nucleus sampling (0-1) |
| `stream` | boolean | streaming 활성화 |

### Tool Calling

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Tool Choice 옵션

| Format | Example | Description |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | 단순 선택 |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | 특정 function 강제 |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic 기본 형식 |

### 고급 Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `stream_options` | object | token 수를 위한 `{ include_usage: true }` |
| `reasoning_effort` | string | reasoning이 활성화된 GPT-5 model용 `"low"`, `"medium"`, `"high"` |
| `service_tier` | string | `"auto"` 또는 `"default"` |
| `seed` | integer | 결정론적 출력 |
| `logprobs` | boolean | log probability 반환 |
| `top_logprobs` | integer | 상위 logprobs 개수 (0-20) |
| `logit_bias` | object | token bias map (-100 ~ 100) |
| `frequency_penalty` | number | 반복 penalty (-2 ~ 2) |
| `presence_penalty` | number | 주제 penalty (-2 ~ 2) |
| `stop` | string/array | 중지 sequence |
| `n` | integer | completion 개수 (1-128) |
| `user` | string | 추적용 사용자 식별자 |

### OpenAI 고급 기능

| Parameter | Type | Description |
|-----------|------|-------------|
| `modalities` | array | multimodal용 `["text", "audio"]` |
| `audio` | object | 오디오 출력 config (voice, format) |
| `prediction` | object | 더 빠른 completion을 위한 예측 출력 |
| `metadata` | object | 추적용 key-value 쌍 |
| `store` | boolean | 나중에 조회할 수 있도록 저장 |

### Provider별 옵션

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Responses API Parameters

### 핵심 Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Model 식별자 |
| `input` | string/array | 입력 content |
| `instructions` | string | 시스템 instruction |
| `max_output_tokens` | integer | 최대 출력 token 수 |
| `previous_response_id` | string | 대화 이어가기 |

### 고급 Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` 또는 `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | reasoning model용 |
| `service_tier` | string | 우선순위 tier |

### Tool 형식

OpenAI 및 Anthropic tool 형식을 모두 지원합니다:

```json
// OpenAI format
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic format (Cursor compatibility)
{ "name": "fn", "input_schema": {...} }
```

## Streaming

모든 endpoint는 Server-Sent Events (SSE) streaming을 지원합니다:

```bash
# Chat Completions
curl https://api.lemondata.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# With usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## 오류 처리

LemonData는 OpenAI 호환 오류 응답을 반환합니다:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

자세한 내용은 [오류 처리 가이드](/guides/error-handling)를 참조하세요.
