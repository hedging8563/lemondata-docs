## 개요

LemonData의 Agent-First API는 AI agent가 즉시 파싱하고 조치할 수 있는 구조화된 힌트로 error 응답을 강화합니다 — 웹 검색도, 문서 조회도, 추측도 필요 없습니다.

모든 error 응답에는 표준 `error` 객체 내부에 `did_you_mean`, `suggestions`, `hint`, `retryable`, `retry_after` 같은 선택적 필드가 포함됩니다. 이러한 필드는 하위 호환됩니다 — 이를 사용하지 않는 클라이언트는 아무런 차이를 보지 못합니다.

## Error Hint 필드

모든 hint 필드는 `error` 객체 내부의 선택적 확장 필드입니다:

| Field | Type | Description |
|-------|------|-------------|
| `did_you_mean` | `string` | 가장 근접하게 일치하는 model 이름 |
| `suggestions` | `array` | 메타데이터가 포함된 권장 model |
| `alternatives` | `array` | 현재 사용 가능한 대체 model |
| `hint` | `string` | 사람이거나 agent가 읽을 수 있는 다음 단계 안내 |
| `retryable` | `boolean` | 동일한 요청을 재시도하면 성공할 수 있는지 여부 |
| `retry_after` | `number` | 재시도 전 대기할 초 단위 시간 |
| `balance_usd` | `number` | 현재 계정 잔액(USD) |
| `estimated_cost_usd` | `number` | 실패한 요청의 예상 비용 |

## Error 코드 예시

### model_not_found (400)

model 이름이 어떤 활성 model과도 일치하지 않을 때:

```json
{
  "error": {
    "message": "Model 'gpt5' not found",
    "type": "invalid_request_error",
    "param": "model",
    "code": "model_not_found",
    "did_you_mean": "gpt-5.4",
    "suggestions": [
      {"id": "gpt-5.4"},
      {"id": "gpt-5-mini"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Did you mean 'gpt-5.4'? Use GET https://api.lemondata.cc/v1/models to list all available models."
  }
}
```

`did_you_mean` 해석은 다음을 사용합니다:
1. 정적 alias 매핑(프로덕션 error 데이터 기반)
2. 정규화된 문자열 매칭(하이픈 제거, 대소문자 구분 없음)
3. 편집 거리 매칭(임계값 ≤ 3)

### insufficient_balance (402)

계정 잔액이 예상 비용보다 너무 낮을 때:

```json
{
  "error": {
    "message": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200.",
    "type": "insufficient_balance",
    "code": "insufficient_balance",
    "balance_usd": 0.12,
    "estimated_cost_usd": 0.35,
    "suggestions": [
      {"id": "gpt-5-mini"},
      {"id": "deepseek-v3-2"}
    ],
    "hint": "Insufficient balance: need ~$0.3500 for claude-sonnet-4-6, but balance is $0.1200. Try a cheaper model, or top up at https://lemondata.cc/dashboard/billing."
  }
}
```

`suggestions`에는 agent가 전환할 수 있는, 예상 비용보다 저렴한 model이 포함됩니다.

### all_channels_failed (503)

model에 대한 모든 upstream channel을 사용할 수 없을 때:

```json
{
  "error": {
    "message": "Model claude-opus-4-6 temporarily unavailable",
    "code": "all_channels_failed",
    "retryable": true,
    "retry_after": 30,
    "alternatives": [
      {"id": "claude-sonnet-4-6", "status": "available", "tags": []},
      {"id": "gpt-5-mini", "status": "available", "tags": []}
    ],
    "hint": "All channels for 'claude-opus-4-6' are temporarily unavailable. Retry in 30s or try an alternative model."
  }
}
```

<Note>
이유가 `no_channels`(이 model에 대해 구성된 channel이 없음)인 경우 `retryable`은 `false`입니다. circuit breaker trip 또는 quota 소진 같은 일시적 실패에 대해서만 `true`입니다.
</Note>

### rate_limit_exceeded (429)

```json
{
  "error": {
    "message": "Rate limit: 60 rpm exceeded",
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "retryable": true,
    "retry_after": 8,
    "hint": "Rate limited. Retry after 8s. Current limit: 60/min for user role."
  }
}
```

`retry_after` 값은 실제 rate limit window 재설정 시점으로부터 계산됩니다.

<Note>
OpenAI 호환 endpoint는 `rate_limit_exceeded`, `upstream_error`, `all_channels_failed`와 같은 LemonData의 안정적인 공개 error type을 사용합니다. Anthropic 호환 및 Gemini 호환 endpoint는 각자의 native 응답 형식을 사용합니다.
</Note>

### context_length_exceeded (400)

입력이 model의 context window를 초과할 때(upstream error, 힌트로 보강됨):

```json
{
  "error": {
    "message": "This model's maximum context length is 128000 tokens...",
    "type": "invalid_request_error",
    "code": "context_length_exceeded",
    "retryable": false,
    "suggestions": [
      {"id": "gemini-2.5-pro"},
      {"id": "claude-sonnet-4-6"}
    ],
    "hint": "Reduce your input or switch to a model with a larger context window."
  }
}
```

## Native Endpoint 헤더

native endpoint(Anthropic 또는 Gemini)가 있는 model로 `/v1/chat/completions`를 호출하면 **성공 응답**에 최적화 헤더가 포함됩니다:

```
X-LemonData-Hint: This model supports native Anthropic format. Use POST /v1/messages for better performance (no format conversion).
X-LemonData-Native-Endpoint: /v1/messages
```

| Model Provider | Suggested Endpoint | Benefit |
|---------------|-------------------|---------|
| Anthropic (Claude) | `/v1/messages` | 형식 변환 없음, extended thinking, prompt caching |
| Google (Gemini) | `/v1beta/gemini` | 형식 변환 없음, grounding, safety 설정 |
| OpenAI | — | Chat completions가 이미 native 형식임 |

이 헤더는 streaming 및 non-streaming 응답 모두에 나타납니다.

## /v1/models 개선 사항

각 model 객체의 `lemondata` 확장에 세 가지 새로운 필드가 추가됩니다:

```json
{
  "id": "gpt-5.4",
  "lemondata": {
    "category": "chat",
    "pricing_unit": "per_token",
    "cache_pricing": {
      "cache_read_per_1m": "1.25",
      "cache_write_per_1m": "2.50",
      "platform_cache_discount": 0.9
    }
  }
}
```

| Field | Values | Description |
|-------|--------|-------------|
| `category` | `chat`, `image`, `video`, `audio`, `tts`, `stt`, `3d`, `embedding`, `rerank` | model 유형 |
| `pricing_unit` | `per_token`, `per_image`, `per_second`, `per_request` | model 과금 방식 |
| `cache_pricing` | object or `null` | upstream prompt cache 가격 + platform semantic cache 할인 |

### Category 필터링

```bash
GET https://api.lemondata.cc/v1/models?category=chat          # Chat models only
GET https://api.lemondata.cc/v1/models?category=image         # Image generation models
GET https://api.lemondata.cc/v1/models?tag=coding&category=chat  # Coding-optimized chat models
```

## llms.txt

기계가 읽을 수 있는 API 개요는 다음 위치에서 확인할 수 있습니다:

```
GET https://api.lemondata.cc/llms.txt
```

포함 내용:
- 동작하는 예제가 포함된 첫 호출 template
- 일반적인 model 이름(사용 데이터에서 동적으로 생성)
- 총 12개의 API endpoint
- model 검색을 위한 filter parameter
- error 처리 가이드

첫 API 호출 전에 `llms.txt`를 읽는 AI agent는 일반적으로 첫 번째 시도에서 성공할 수 있습니다.

## Agent 코드에서의 사용

### Python (OpenAI SDK)

```python
from openai import OpenAI, BadRequestError

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://api.lemondata.cc/v1"
)

def smart_chat(messages, model="gpt-4o"):
    try:
        return client.chat.completions.create(
            model=model, messages=messages
        )
    except BadRequestError as e:
        error = e.body.get("error", {}) if isinstance(e.body, dict) else {}
        # Use did_you_mean for auto-correction
        if error.get("code") == "model_not_found" and error.get("did_you_mean"):
            return client.chat.completions.create(
                model=error["did_you_mean"], messages=messages
            )
        raise
```

### JavaScript (OpenAI SDK)

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

async function smartChat(messages, model = 'gpt-4o') {
  try {
    return await client.chat.completions.create({ model, messages });
  } catch (error) {
    const err = error?.error;
    if (err?.code === 'model_not_found' && err?.did_you_mean) {
      return client.chat.completions.create({
        model: err.did_you_mean, messages
      });
    }
    throw error;
  }
}
```
