## LemonData란 무엇인가요?

LemonData는 OpenAI, Anthropic, Google, DeepSeek, Moonshot, MiniMax 등과 같은 provider의 **300개 이상의 AI 모델**에 통합된 방식으로 액세스할 수 있게 해주는 AI API 집계 플랫폼입니다.

## 지원 기능

| 기능 | 설명 | 예시 모델 |
|------------|-------------|----------------|
| **채팅 및 추론** | 텍스트 생성, 계획, 도구 사용 | `gpt-5.4`, `claude-sonnet-4-6`, `deepseek-r1` |
| **비전** | 이미지 이해 및 멀티모달 채팅 | `gpt-4o`, `claude-sonnet-4-6`, `gemini-2.5-flash` |
| **이미지 생성** | 텍스트-이미지 생성 및 이미지 편집 | `dall-e-3`, `flux-pro`, `midjourney` |
| **비디오 생성** | 텍스트/이미지를 비디오로 변환 | `sora`, `runway`, `kling` |

| **음악** | AI 음악 생성 | `suno` |
| **3D** | 3D asset 생성 | `tripo3d` |

## 시작하기에 좋은 기본 선택

새 프로젝트의 경우 OpenAI SDK와 **Responses API**로 시작하는 것을 권장합니다:

<CodeGroup>

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.lemondata.cc/v1"
)

response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.lemondata.cc/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

</CodeGroup>
