## 개요

대부분의 범용 AI 채팅 앱은 표준 OpenAI-compatible chat path를 통해 LemonData에 연결됩니다.

실제로 이는 다음을 의미합니다:
- 앱이 전체 endpoint URL을 명시적으로 요구하지 않는 한 base URL로 `https://api.lemondata.cc/v1`를 사용합니다
- OpenAI 스타일 API key로 LemonData API key를 사용합니다
- 앱이 표준 채팅 워크플로우에서 사용할 수 있는 모델을 선택합니다

<Note>
일반 채팅 앱은 보통 **chat-completions 지향적**이며, Codex Responses WebSocket 클라이언트가 아닙니다. Responses 전용 동작이 필요한 Codex CLI/App, Cursor 또는 기타 코딩 도구의 경우 전용 integration guide를 대신 사용하세요.
</Note>

## 지원 애플리케이션

| 애플리케이션 | 플랫폼 | 참고 |
|-------------|----------|-------|
| LobeChat | Web, Desktop, Self-hosted | 강력한 custom-provider 지원 |
| Cherry Studio | Windows, macOS, Linux | 우수한 OpenAI-compatible provider 흐름 |
| Chatbox | Windows, macOS, Linux | 간단한 OpenAI-compatible 설정 |
| TypingMind | Web, Desktop | custom endpoint 스타일 사용 |
| BotGem | iOS, macOS | custom provider 구성 |
| OpenCat | iOS, macOS | OpenAI-compatible custom endpoint 흐름 |
| ChatWise | Windows, macOS | 표준 custom provider 패턴 |

## 기본 연결 값

| 필드 | 값 |
|-------|-------|
| Base URL | `https://api.lemondata.cc/v1` |
| API Key | `sk-your-lemondata-key` |
| API Type | OpenAI Compatible |

앱이 base URL 대신 **전체 endpoint URL**을 요구하는 경우 다음을 사용하세요:
- Chat Completions: `https://api.lemondata.cc/v1/chat/completions`

## 예시 앱 설정

<Tabs>
  <Tab title="LobeChat">
    **Self-hosted LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-lemondata-key
    OPENAI_PROXY_URL=https://api.lemondata.cc/v1
    ```

    **LobeChat Cloud**
    1. **Settings** → **AI Service Provider**를 엽니다
    2. **OpenAI**를 선택합니다
    3. LemonData API key를 입력합니다
    4. custom endpoint를 `https://api.lemondata.cc/v1`로 설정합니다
  </Tab>

  <Tab title="Cherry Studio">
    1. **Settings** → **Model Provider**를 엽니다
    2. **OpenAI-compatible** provider를 추가합니다
    3. 다음을 입력합니다:
       - **Name**: LemonData
       - **API Base URL**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
    4. 사용하려는 모델을 추가합니다
  </Tab>

  <Tab title="Chatbox">
    1. **Settings** → **AI Model**을 엽니다
    2. **OpenAI API Compatible**을 선택합니다
    3. 다음을 입력합니다:
       - **API Host**: `https://api.lemondata.cc/v1`
       - **API Key**: `sk-your-lemondata-key`
       - **Model**: `gpt-5-mini` 또는 `gpt-4o`
  </Tab>

  <Tab title="TypingMind">
    1. **Settings**를 엽니다
    2. **Custom Endpoint**를 선택합니다
    3. 다음을 입력합니다:
       - **Endpoint URL**: `https://api.lemondata.cc/v1/chat/completions`
       - **API Key**: `sk-your-lemondata-key`
    4. 노출하려는 모델을 구성합니다
  </Tab>
</Tabs>

## 팁

<AccordionGroup>
  <Accordion title="앱이 지원하면 base URL을 우선 사용하세요">
    대부분의 앱은 전체 endpoint URL 대신 base URL로 `https://api.lemondata.cc/v1`를 제공할 때 더 쉽게 구성할 수 있고 더 안정적으로 동작합니다.
  </Accordion>

  <Accordion title="먼저 더 작은 모델을 사용하세요">
    일상적인 채팅에는 `gpt-5-mini` 또는 `gpt-4o`로 시작한 다음, 더 무거운 추론 작업은 `gpt-5.4` 또는 `claude-opus-4-6`로 옮기세요.
  </Accordion>

  <Accordion title="코딩 도구는 분리해서 유지하세요">
    일반 채팅 앱과 coding agent는 종종 서로 다른 endpoint 동작이 필요합니다. Codex/Cursor 스타일 도구는 해당 전용 integration 페이지에서 따로 유지하세요.
  </Accordion>
</AccordionGroup>

## 문제 해결

<AccordionGroup>
  <Accordion title="연결 오류">
    - base URL이 정확히 `https://api.lemondata.cc/v1`인지 확인하세요
    - 앱이 path를 자동으로 추가하는 경우 끝의 슬래시를 제거하세요
    - 앱이 전체 endpoint URL을 요구하면 `https://api.lemondata.cc/v1/chat/completions`를 사용하세요
  </Accordion>

  <Accordion title="401 Unauthorized">
    - API key를 다시 확인하세요
    - LemonData dashboard에서 key가 활성 상태인지 확인하세요
    - 불필요한 공백이나 줄바꿈이 없는지 확인하세요
  </Accordion>

  <Accordion title="모델을 사용할 수 없음">
    - 모델 이름이 정확한지 확인하세요
    - `gpt-5-mini`, `gpt-4o` 또는 `claude-sonnet-4-6` 같은 널리 지원되는 기본 모델을 시도해 보세요
    - LemonData 문서 또는 dashboard에서 현재 사용 가능 여부를 확인하세요
  </Accordion>
</AccordionGroup>
