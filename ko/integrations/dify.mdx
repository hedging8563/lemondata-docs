## 개요

Dify는 OpenAI 호환 model provider 흐름을 통해 LemonData와 잘 작동합니다.

현재 Dify 버전에서는 일반적으로 가장 안전한 방법은 다음과 같습니다:
- 기본 제공 **OpenAI** provider 선택
- LemonData API key 설정
- `https://api.lemondata.cc/v1`의 사용자 지정 base URL 설정

<Note>
일부 구형 Dify 빌드에서는 사용자 지정 base URL 필드가 있는 기본 제공 `OpenAI` provider 대신 이를 `OpenAI-API-compatible`로 노출합니다. Dify UI가 다르게 보인다면, 해당 버전에서 사용 가능한 가장 가까운 OpenAI 호환 사용자 지정 provider 흐름을 사용하세요.
</Note>

## 사전 요구 사항

- API access가 가능한 LemonData account
- Dify Cloud 또는 self-hosted Dify

## 구성 단계

### 1단계: API Key 가져오기

1. [LemonData Dashboard](https://lemondata.cc/dashboard)에 로그인합니다
2. [API Keys](https://lemondata.cc/dashboard/api)를 엽니다
3. `sk-`로 시작하는 API key를 생성하거나 복사합니다

### 2단계: Provider 구성

<Steps>
  <Step title="Model Providers 열기">
    Dify에서 **Settings** → **Model Providers**로 이동합니다
  </Step>
  <Step title="OpenAI 선택">
    **OpenAI** provider 설정을 엽니다. 사용 중인 Dify 버전에서 여기에서 사용자 지정 base URL을 제공하지 않는 경우, 대신 해당 버전에서 노출하는 OpenAI 호환 사용자 지정 provider 옵션을 사용하세요.
  </Step>
  <Step title="LemonData 설정 입력">
    다음 값을 사용합니다:

    | Field | Value |
    |-------|-------|
    | API Key | `sk-your-lemondata-key` |
    | API Base URL / Custom Base URL | `https://api.lemondata.cc/v1` |
  </Step>
  <Step title="Model 추가">
    사용하려는 model을 추가합니다. 예를 들면 다음과 같습니다:
    - `gpt-5.4`
    - `gpt-5-mini`
    - `gpt-4o`
    - `claude-sonnet-4-6`
    - `claude-opus-4-6`
    - `gemini-2.5-flash`
    - `gemini-2.5-pro`
    - `deepseek-r1`
  </Step>
</Steps>

### 3단계: 연결 테스트

1. `gpt-5-mini` 또는 `gpt-4o`와 같은 model 하나를 선택합니다
2. 테스트 prompt를 전송합니다
3. Dify가 유효한 응답을 받는지 확인합니다

## Knowledge Base용 Embeddings

RAG 및 knowledge base indexing의 경우, 다음과 같은 embedding model을 추가합니다:
- `text-embedding-3-small`
- `text-embedding-3-large`

그런 다음 관련 knowledge base 또는 application 설정에서 이를 기본 embedding model로 설정합니다.

## 권장 Model 역할

| Use Case | Suggested Models |
|----------|------------------|
| 기본 chat | `gpt-5.4`, `gpt-5-mini`, `gpt-4o` |
| 심층 추론 | `gpt-5.4`, `claude-opus-4-6`, `deepseek-r1` |
| 빠름/저렴함 | `gpt-5-mini`, `gemini-2.5-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## 모범 사례

<AccordionGroup>
  <Accordion title="기본 제공 OpenAI provider로 시작">
    최신 Dify 버전에서는 사용자 지정 base URL이 있는 기본 제공 OpenAI provider가 일반적으로 LemonData를 위한 가장 깔끔한 설정입니다.
  </Accordion>

  <Accordion title="반복 작업에는 더 저렴한 model 사용">
    반복 작업 중에는 `gpt-5-mini` 또는 `gemini-2.5-flash`를 사용하고, 이후 더 무거운 workflow는 필요한 경우에만 더 강력한 model로 전환하세요.
  </Accordion>

  <Accordion title="Dify는 일반적으로 chat-completions 중심이라는 점을 기억하세요">
    대부분의 Dify 흐름은 OpenAI 호환 chat 동작을 사용합니다. Codex 전용 Responses 또는 WebSocket 동작이 필요하다면 Dify 대신 전용 Codex integration을 사용하세요.
  </Accordion>
</AccordionGroup>

## 문제 해결

<AccordionGroup>
  <Accordion title="연결 오류">
    - base URL이 정확히 `https://api.lemondata.cc/v1`인지 확인합니다
    - Dify가 후행 슬래시를 중복 추가하는 경우 이를 제거합니다
    - Dify server가 public internet을 통해 LemonData에 도달할 수 있는지 확인합니다
  </Accordion>

  <Accordion title="401 Unauthorized">
    - API key를 다시 확인합니다
    - LemonData dashboard에서 key가 활성 상태인지 확인합니다
    - Dify에 붙여넣은 값에 불필요한 공백이나 줄바꿈이 포함되지 않았는지 확인합니다
  </Accordion>

  <Accordion title="Model을 찾을 수 없음">
    - model 이름이 정확한지 확인합니다
    - provider UI가 이전 값을 캐시한 경우 model 항목을 다시 추가합니다
    - LemonData docs 또는 dashboard에서 현재 사용 가능한 model을 확인합니다
  </Accordion>
</AccordionGroup>
