## 개요

LemonData는 클라이언트가 `https://api.lemondata.cc/v1`를 가리키도록 설정하면 공식 OpenAI SDK와 함께 작동합니다.

새 프로젝트에서는 **Responses API**를 우선 사용하세요. 프레임워크, 플러그인 또는 레거시 코드 경로에서 여전히 이를 기대하는 경우에만 **Chat Completions**를 유지하세요.

<Note>
Python, JavaScript, Go에는 공식 OpenAI SDK가 있습니다. PHP는 OpenAI 호환 커뮤니티 클라이언트와 잘 작동하지만, 공식 OpenAI SDK는 아닙니다.
</Note>

<Note>
**유형**: 네이티브 SDK

**주요 경로**: OpenAI 호환 / OpenAI Responses

**지원 수준**: 핵심 경로 지원
</Note>

이 경로는 LemonData에서 기본으로 사용하는 OpenAI 호환 SDK 경로이지만, 모든 Responses-native-only 필드가 모든 모델과 라우팅된 채널에서 동일하게 동작한다는 뜻은 아닙니다.

## 클라이언트 구성

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lemondata-key",
    base_url="https://api.lemondata.cc/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-lemondata-key',
  baseURL: 'https://api.lemondata.cc/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-lemondata-key"),
        option.WithBaseURL("https://api.lemondata.cc/v1"),
    )

    _ = client
}
```

</CodeGroup>

## 권장: Responses API

<CodeGroup>

```python Python
response = client.responses.create(
    model="gpt-5.4",
    input="Explain what LemonData does in one sentence."
)

print(response.output_text)
```

```javascript JavaScript
const response = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Explain what LemonData does in one sentence.',
});

console.log(response.output_text);
```

```bash cURL
curl https://api.lemondata.cc/v1/responses \
  -H "Authorization: Bearer sk-your-lemondata-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Explain what LemonData does in one sentence."
  }'
```

</CodeGroup>

<Note>
일부 호스팅형 tools, `include`, `service_tier`, `truncation_strategy` 같은 Responses-native-only 필드는 선택한 모델과 라우팅된 채널의 native `/v1/responses` passthrough 지원에 따라 달라집니다. 지원되지 않으면 LemonData는 조용히 성공한 것처럼 보이게 하지 않고 명시적인 `400` 또는 `503` 오류를 반환합니다.
</Note>

## Responses 스트리밍

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.4",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.4',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## Tools / Function Calling

```python
response = client.responses.create(
    model="gpt-5.4",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## Responses를 사용한 Vision

```python
response = client.responses.create(
```

## Chat Completions 호환성

프레임워크 또는 플러그인이 여전히 Chat Completions를 기대하는 경우, LemonData는 표준 OpenAI 호환 경로도 지원합니다:

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

<Warning>
호환성을 위해서만 Chat Completions를 사용하세요. 새 통합에서는 `client.responses.create(...)`를 우선 사용하세요.
</Warning>

## 문제 해결

<AccordionGroup>
  <Accordion title="연결 오류">
    - base URL이 정확히 `https://api.lemondata.cc/v1`인지 확인하세요
    - 프록시 간섭 또는 사용자 정의 HTTP 클라이언트 override가 있는지 확인하세요
    - 제공자 동작을 디버깅하기 전에 SDK 버전이 최신인지 확인하세요
  </Accordion>

  <Accordion title="인증 실패">
    - API key가 `sk-`로 시작하는지 확인하세요
    - LemonData 대시보드에서 key가 활성 상태인지 확인하세요
    - SDK가 `Authorization: Bearer ...`를 전송하고 있는지 확인하세요
  </Accordion>

  <Accordion title="잘못된 API 경로">
    - `responses.create(...)`는 요청을 `/v1/responses`로 보냅니다
    - `chat.completions.create(...)`는 요청을 `/v1/chat/completions`로 보냅니다
    - 앱이 현재 Chat Completions만 지원하는 경우, 해당 호환 경로를 계속 사용하세요
  </Accordion>
</AccordionGroup>
