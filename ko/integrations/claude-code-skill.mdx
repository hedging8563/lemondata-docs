<Note>
이 스킬을 사용하면 자연어(영어)로 필요한 내용을 설명하는 것만으로 LemonData의 **수백 개의 AI API**를 통합할 수 있습니다!
</Note>

## 이 스킬은 무엇을 할 수 있나요?

코드에서 AI 기능(GPT-4, 이미지 생성, 음성 인식 등)을 사용하고 싶을 때, 이 스킬은 다음을 수행합니다:

1. ✅ LemonData의 수백 개의 API를 **자동으로 검색**합니다
2. ✅ 요구 사항에 **가장 적합한 API를 찾습니다**
3. ✅ **완전하고 실행 가능한 코드를 생성**합니다
4. ✅ **API Key를 설정**합니다
5. ✅ **사용 예시** 및 모범 사례를 제공합니다

**요약하자면: 자연어로 요구 사항을 설명하기만 하면 완전한 API 통합 코드를 얻을 수 있습니다!**
