## 개요

OpenAI Codex는 터미널에서 코드를 읽고, 수정하고, 실행할 수 있는 경량 코딩 에이전트 역할을 하는 오픈 소스 명령줄 도구(CLI)입니다. GPT 모델을 기반으로 구축되었으며 코드 생성에 최적화되어 있습니다.

## 시스템 요구 사항

- **OS**: macOS, Linux(공식 지원), WSL을 통한 Windows
- **Node.js**: 버전 18+
- **npm**: 버전 10.x.x 이상

## 설치

```bash
npm install -g @openai/codex
```

설치 확인:

```bash
codex --version
```

## 구성

### 1단계: API Key 설정

**임시(현재 세션):**

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

**영구 구성:**

`~/.bashrc`, `~/.zshrc`, 또는 `~/.bash_profile`에 추가:

```bash
export OPENAI_API_KEY="sk-your-lemondata-key"
```

그런 다음 다시 로드합니다:

```bash
source ~/.zshrc  # or source ~/.bashrc
```

### 2단계: config.toml 구성

`~/.codex/config.toml`을 편집합니다:

```toml
model_provider = "lemondata"
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
plan_mode_reasoning_effort = "xhigh"
fast_mode = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000
sandbox_mode = "danger-full-access"
approval_policy = "never"

disable_response_storage = false
personality = "friendly"
service_tier = "fast"

[model_providers.lemondata]
env_key = "OPENAI_API_KEY"
name = "lemondata"
base_url = "https://api.lemondata.cc/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000

[features]
responses_websockets = true
responses_websockets_v2 = true
```

<Note>
config 파일이 없으면 `codex`를 한 번 실행하여 생성한 다음 파일을 편집하세요. `config.toml`을 변경한 후에는 새 provider 설정이 다시 로드되도록 Codex를 완전히 재시작하세요.
</Note>

<Warning>
Codex는 custom provider에 대한 `chat/completions` 지원을 단계적으로 폐지하고 있습니다. 의도적으로 이전 호환 경로를 사용하는 경우가 아니라면 LemonData에서는 `wire_api = "responses"`를 유지하세요.
</Warning>

## 기본 사용법

**대화형 모드 시작:**

```bash
codex
```

**직접 명령:**

```bash
codex "Fix the bug in main.py line 42"
```

**모델 지정:**

```bash
codex -m gpt-5.4 "Build a REST API server"
```

## 권장 모델

| Model | Best For |
|-------|----------|
| `gpt-5.4` | 코딩 및 추론을 위한 최고의 기본 선택 |
| `gpt-5-mini` | 코딩 워크플로우를 위한 더 빠르고 저렴한 대체 옵션 |
| `claude-sonnet-4-6` | 코드 리뷰, 문서화 |
| `deepseek-r1` | 알고리즘 설계, 추론 |

## 대화형 명령어

| Command | Description |
|---------|-------------|
| `/help` | 도움말 표시 |
| `/exit` or `Ctrl+C` | 종료 |
| `/clear` | 대화 지우기 |
| `/config` | 구성 보기 |
| `/model <name>` | 모델 전환 |
| `/tokens` | token 사용량 보기 |

## 구성 확인

```bash
# Check environment variable
echo $OPENAI_API_KEY

# Test API connection
codex "Hello, Codex!"

# View configuration
cat ~/.codex/config.toml
```

## 일반적인 사용 사례

**코드 리뷰:**

```bash
git diff | codex "Review these code changes"
```

**커밋 메시지 생성:**

```bash
git diff --staged | codex "Generate a commit message for these changes"
```

**오류 수정:**

```bash
codex "Fix the TypeScript errors in src/components/"
```

**코드 설명:**

```bash
cat main.py | codex "Explain what this code does"
```

## 문제 해결

<AccordionGroup>
  <Accordion title="연결 오류">
    - config.toml의 `base_url`이 정확히 `https://api.lemondata.cc/v1`인지 확인하세요
    - 네트워크 연결 상태를 확인하세요
    - proxy 간섭이 없는지 확인하세요
  </Accordion>

  <Accordion title="인증 실패">
    - `~/.codex/config.toml`에 `env_key = "OPENAI_API_KEY"`가 있는지 확인하세요
    - `OPENAI_API_KEY` 환경 변수가 설정되어 있는지 확인하세요
    - key가 `sk-`로 시작하는지 확인하세요
    - LemonData dashboard에서 key가 활성 상태인지 확인하세요
  </Accordion>

  <Accordion title="모델을 찾을 수 없음">
    - 모델 이름이 정확히 일치하는지 확인하세요
    - [lemondata.cc/en/models](https://lemondata.cc/ko/models)에서 모델 사용 가능 여부를 확인하세요
  </Accordion>
</AccordionGroup>
